# 教学版帮助视频：清单与新剧本（给录制施工用）

> 第 30 轮 H-4。做法照那边（freecad-ai-parts，ADR-0065）：`tools/help_videos.py` 用浏览器自动化在演示厂（本地版、教学模式）里操作并录制，
> 字幕叠在画面上，**不配音**。每段 30–90 秒，1280×720。
> 本文件原在 `web/src/help/teach/`，第 30 轮第 4 步已挪到这里（理由见 `_anchors.md` 开头）。`teach-publish` 已从 videos.json 删掉。

```json
{
  "teach-labs": { "edition": "teach", "title": "实验与任务" },
  "teach-director": { "edition": "teach", "title": "情景导演" },
  "teach-maint": { "edition": "teach", "title": "设备维护：保养工单、挂牌上锁" }

```

录制时用本地版登录：本地版里每个人都是老师权限（`hub/app.py` 的本地登录写死 `teacher: True`），所以实验页显示的是老师视图
（有“老师”一块，没有比对模式的黄色标签）。下面的剧本按老师视图写。

## 二、沿用剧本要改的地方

- `teach-login`：第二句字幕“选一个岗位：计划员、工艺员、操作工、质检员”改为“选一个岗位：计划员、操作工、质检员、维修工……”（这边有 11 个角色）。
  最后一步指向的 `a.nav:has-text('帮助')` 在这边左栏“资源”组里，选择器不变。
- `teach-anomaly`：点开异常后，在 `[data-help=ont-actions]` 之后加一步：
  `point("[data-help=ont-options]")`，字幕“右栏下方是推演与建议：每个方案的交期和花费，第一个标‘建议’”（停 4 秒）。
- 各段原来用的 `data-help` 选择器，这边加了同名标记后都能用（见 `_anchors.md`）。

## 三、新剧本

格式：每一步“操作 → 画面上的字幕（停留秒数）”。选择器写成 Playwright 的写法；`[data-help=…]` 见 `_anchors.md`。

### teach-labs：实验与任务（约 60 秒，角色：厂长 / 老师）

片头：标题“实验与任务”，副标题“一个入口：选实验、做任务、看得分”。

1. 打开 `/labs`，等 2 秒。
2. 光标移到 `[data-help=labs-grid]` → “左栏‘教学 → 实验与任务’：实验 7、15–23 每个一张卡片”（3.5 秒）
3. 光标移到第一张卡片的 `.sc` → “每张卡片：领域、学时、任务数，自动评的得分和报告分”（3.5 秒）
4. 光标移到第一张卡片的 `a:has-text('指导书')` → “指导书在这里直接下载”（2.5 秒）
5. 点 `a.lab:has-text('实验 18')`，等 2 秒。
6. 光标移到 `[data-help=lab-links]` → “实验页顶上：指导书、报告模板”（3 秒）
7. 光标移到 `[data-help=lab-sum]` → “得分条：平台按事实自动评 60 分，报告 40 分由老师批”（3.5 秒）
8. 如果有 `h2:has-text('老师：设置')`：光标移过去 → “老师在这里设置情景，学生看不到；下面是全班得分表”（3.5 秒）
9. 光标移到 `[data-help=lab-task]` → “任务一个一个做：读说明和提示，填表提交，马上给分”（3.5 秒）
10. 字幕（不移光标）→ “学生先自己选方案、提交；提交之前，指挥台不显示中枢的建议——这叫比对模式”（4 秒）
11. 点 `a:has-text('打开这台设备的异常')`（有就点，没有跳过），等 2.5 秒 → “提交以后，到指挥台和中枢的建议对比”（3.5 秒）

### teach-director：情景导演（约 90 秒，角色：厂长 / 老师）

片头：标题“情景导演”，副标题“一张急单串起七个领域：八幕、复盘、教师控制台”。

1. 打开 `/director`，等 2 秒。
2. 光标移到 `[data-help=dir-timeline]` → “八幕的时间线：每一幕的旁白、讲解要点、去看的页面、谁处理”（4 秒）
3. 光标移到 `[data-help=dir-bar] select[aria-label='车间倍速']`，选 `30` → “先选倍速：课堂 20–30×，演示 30–60×”（2.5 秒）
4. 光标移到 `label:has-text('自动收尾')`，勾上 → “勾‘自动收尾’：整改、保养到时没人收尾，由情景里的人做完”（3.5 秒）
5. 点 `button:has-text('开始两周情景')`（会弹确认框的话接受）→ “开始：清空教学模式的车间历史、重新载入情景；学生得分保留”（3 秒）；
   等到 `button:has-text('下一幕')` 可点（最多 40 秒；等待时字幕“载入中，十几秒”）。
6. 点 `button:has-text('下一幕')` → “第 1 幕：客户下急单，订单、工单、请购单进 ERPNext”（4 秒）；等到第 1 幕显示打勾（最多 40 秒）。
7. 点 `button:has-text('下一幕')` → “第 2 幕：缺料。厂情中枢 20 秒内报出异常”（3 秒）；
   等到第 2 幕出现 `.seen .pill a`（最多 60 秒），光标移过去 → “点异常名，直接打开指挥台”（3 秒）。
8. 点这个异常链接，等 2.5 秒；光标移到 `[data-help=ont-options]` → “学生在这里比较方案、采纳生成动作；老师在动作收件箱批准”（4 秒）。
9. 回 `/director`，等 2 秒；光标移到 `button:has-text('复盘')` → “订单做完后点‘复盘’：毛利分解、每一幕花的钱、跨领域因果链”（4 秒）
10. 光标移到 `label:has-text('自动演示')` → “演示时勾‘自动演示’：异常出来后停一会儿自动进下一幕”（3.5 秒）
11. 滚到 `[data-help=dir-console]` → “页面最下面是教师控制台：倍速、注入故障、车间班次、重置实验 7 情景”（4 秒）
12. 收尾：点 `button:has-text('结束')`（有就点，接受确认框），不要留着情景在跑。

页面上的“开始”“结束”都会弹 `confirm()` 确认框，剧本里先 `page.on('dialog', d => d.accept())`。

注意：第 5 步会重置教学模式的数据。这段要排在其他教学版视频**最后**录，或录完再重置一次。

### teach-maint：设备维护（约 90 秒，角色：厂长 / 老师；保养完成用维修工也可以）

片头：标题“设备维护”，副标题“保养工单、挂牌上锁、另一个人验收解锁”。

准备（录制前，用界面或接口，不录进画面也行）：打开 `/lab18`，在“老师：设置”里选可靠性“正常”、设备 `GRD-01`、运行小时 `650`，点“设置”。

1. 打开 `/maint`，等 2 秒。
2. 光标移到 `[data-help=maint-kpis]` → “上方：保养逾期、维修单、故障停机、平均故障间隔、点检异常”（3.5 秒）
3. 光标移到 `[data-help=maint-assets]` → “设备台账：自上次保养运行了多少小时、保养周期、坏的概率、预期损失”（4 秒）
4. 点 GRD-01 那一行的 `button:has-text('详情')`，等 1.5 秒；光标移到 `svg.curve` → “失效率曲线：越过保养周期，坏的概率涨得越快”（4 秒）
5. 打开 `/ont?view=anomalies`；等左栏出现含“保养逾期”的异常（最多 60 秒），点它，等 2.5 秒 →
   “厂情中枢报‘保养逾期’，因果链连到排在磨床上的工单和订单”（4 秒）
6. 光标移到 `[data-help=ont-options]` → “三个方案：不做、现在保养、下班后保养；每个算交期和‘花费 + 预期损失’”（4.5 秒）
7. 点“现在保养”方案下的 `button:has-text('采纳，生成动作')` → “采纳，生成保养工单；要厂长批准”（3 秒）
8. 打开 `/ont/actions`，点第一个 `button:has-text('批准并执行')`，等 2 秒 → “批准后，到时间设备挂牌上锁停下”（3 秒）
9. 打开 `/maint`，等到 GRD-01 一行出现 🔒（最多 30 秒）→ “设备显示 🔒：车间终端不能复位”（3.5 秒）
10. 打开 `/maint?tab=pm`；光标移到 `[data-help=maint-pm]`；点 `button:has-text('保养完成')` → “维修工做完点‘保养完成’”（3 秒）
11. 如果出现 `button:has-text('验收解锁')`：光标移过去 → “另一个人点‘验收解锁’：做活的人、申请这把锁的人不能自己解锁”（4 秒）。
    能点就点，等 2 秒 → “设备恢复，‘自上次保养’回到 0，ERPNext 多一条保养记录”（4 秒）。
    点了报“不能自己解锁”的话，字幕改为“要换一个人来验收”（3 秒）结束。
12. 收尾：在 `/lab18` 把可靠性设回“关”。

## 四、要和视频一起注意的界面

- 录制用的倍速：`teach-maint`、`teach-director` 等异常和挂锁，建议先在教师控制台把倍速设到 60×，录完设回。
- `teach-director` 会重置情景，影响其他段；排在最后。
