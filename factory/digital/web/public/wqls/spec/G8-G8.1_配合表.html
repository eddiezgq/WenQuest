WQ-LS 配合表（G8.1 第二步）#

按 GB/T 1800（ISO 286）算；滚动轴承按普通级（P0）。间隙为正、过盈为负，单位 μm。由 tools/wqls/g81_fits.py 生成，改配合改那个文件再重出。

组 配合处 公称 孔 轴 / 外件 极限（μm） 性质 来源 说明
上轴 前轴承 6203 外圈 / 机壳前轴承孔 Ø40 H7 轴承外径 P0 0 … +36 间隙 G5 机加工 〇′ 外圈不转、轻载，允许游动；同轴度 Ø0.02 见 G5 精度分析（73%）
上轴 前轴承 6203 内圈 / 上轴前端 Ø17 轴承内径 P0 k5 -17 … -1 过盈 G8.1 定 内圈随轴转，k5 是轻载转动内圈的常用配合
上轴 后轴承 6201 外圈 / 机壳后轴承孔 Ø32 H7 轴承外径 P0 0 … +36 间隙 G3 外观与机壳铸件 同上
上轴 后轴承 6201 内圈 / 上轴后端 Ø12 轴承内径 P0 k5 -17 … -1 过盈 G8.1 定 同前轴承内圈
