一、模型与输入 · Model and inputs

机构几何：G1 定的参数（tools/wqls/spec.py）：

  • 刺布曲柄滑块：r = 15.5 mm，l = 55 mm。
  • 挑线四连杆：设计软件第 4 章参数。
  • 送布：偏心距 1.1 mm，送布定时提前 6°。

方法：主轴匀速 ω。每个运动构件质心的位置和转角都是主轴转角 φ 的函数，对 φ 数值求导，按虚功率求驱动力矩：

$$T(\varphi) = \sum_i \left( m_i\,\mathbf{x}_i'\cdot\mathbf{x}_i'' + I_i\,\theta_i'\theta_i'' \right)\omega^2 + \sum_i m_i g\, y_i' + \sum_j F_j\,|s_j'| $$

上轴受的力用牛顿—欧拉方程求：

  • 针杆—连杆一组、挑线杆一组，分别解出销上的力。连杆和挑线杆有质量；摇杆按二力杆。
  • 再加上曲柄销当量质量和平衡块的离心力。

质量与转动惯量（估计值，G4 用实体零件的计算值替换）：

构件 质量 说明
针杆组件（针杆、针夹、机针、线钩） 0.09 kg 设计软件 mr = 0.12 kg 里扣掉连杆往复的那一部分
连杆 0.040 kg，质心距曲柄销 0.38 l，I_G = 1.3×10⁻⁵ kg·m² 钢锻件估计
曲柄销当量 0.06 kg 设计软件 mo
挑线杆 0.025 kg，质心在 P→线眼 0.45 处 设计软件 mt、link_com
送布当量 0.05 kg 设计软件 mf

缝纫阻力（示例估计）：

  • 机针穿布 4 N、出布摩擦 1.5 N。文献里 Nm 80–120 的机针穿刺力为几牛量级，没有查到可以直接引用的数值。
  • 压脚压力 50 N，布与压脚摩擦系数 0.25（设计软件棉布值）。
  • 挑线收紧时，线张力从 1.0 N 升到 1.4 N（设计软件的收紧峰值）。
  • 旋梭摩擦 0.02 N·m；轴承、油封、油泵、同步带合计 0.05 N·m。

阻力都是估计值，所以做了 0.5 倍和 2 倍的敏感性分析（第二节）。

三、用 MuJoCo 对照 · Cross-check with MuJoCo　（图 2_MuJoCo对照.png）

用数字工厂的多体动力学引擎 MuJoCo 搭同一个刺布机构：曲柄、连杆、针杆，质量和转动惯量都相同。曲柄用运动约束驱动，以 5000 r/min 匀速转两圈，取第二圈的约束力矩，和本计算逐点比较：

  • 599 个点里，最大差 0.009 N·m、均方根差 0.004 N·m，是峰值 4.70 N·m 的 0.2%。
  • 两种方法互相独立：一种是公式加数值求导，一种是约束多体动力学。结果一致，说明惯性力矩的算法没错。

四、平衡 · Balancing　（图 3_平衡率.png）

平衡块随曲柄转动，产生离心力，抵消针杆一阶往复惯性力的 k 倍。代价是在水平方向引入同样大小的力。扫 k = 0…1，5000 r/min：

平衡率 k 0 0.30 0.45 0.60 1.0
整机振动力最大值 N 503 372 330 377 543
铅垂一阶 N 399 267 201 137 70
水平一阶 N 109 242 309 376 554
铅垂二阶 N 103 103 103 103 103
  • 取 0.45：合力最小。与教材《机械设计》33.11 取的值相同，也在教材“工程师笔记”说的 0.4–0.6 之内。
  • 二阶惯性力（103 N，频率为转速的 2 倍，即 167 Hz）平衡块管不了。所以 G1 定的机壳一阶固有频率 ≥ 210 Hz 很要紧：这一条在 G3 用机壳实体做模态分析时验证。
  • 平衡块折算到曲柄半径处为 132 g，G4 设计曲柄时按这个值配重。

G4 修订（2026-11-10）：平衡率改 0.35。 机壳模态做出来后，最低一阶是机头前后摆（Y 向，约 129 Hz），对它起作用的是水平一阶力。k 从 0.45 降到 0.35：合力最大值 330 → 351 N（+6%），水平一阶 309 → 264 N，机头前后摆振动约降 10%。平衡块折算到曲柄半径处 132 g → 103 g。G4 装上机构后用谐响应再定一次。

六、电机、惯量与控制方式（交给 GC）· Motor, inertia and control strategy

上轴一转里需要 −4.3 … +5.0 N·m 的力矩，平均却只有 0.12 N·m。电机和控制器有两种做法：

做法 电机要出的力矩 结果
(a) 速度环很硬，电机补齐每一转的起伏 均方根 2.73 N·m，峰值 5.0 N·m + 加速 550 W 电机的额定力矩只有 1.05 N·m，要大一号以上的电机，铜损大、发热大
(b) 速度环带宽低于两倍转频，起伏由转动惯量吸收（建议） 只出平均力矩和加减速力矩 转速有小的波动，见下表

负载侧转动惯量合计 1.24×10⁻⁴ kg·m²，包括上轴、下轴、旋梭（转速 2 倍，折算乘 4）、带轮，以及机构的平均当量惯量 0.26×10⁻⁴。按做法 (b)，再加不同的转子（含手轮）惯量：

转子 + 手轮惯量 kg·m² 转速波动（5000 r/min） 0.10 s 加速到 5000 r/min 要的力矩
1×10⁻⁴ ±3.3% 1.2 N·m
2×10⁻⁴ ±2.3% 1.7 N·m
4×10⁻⁴ ±1.4% 2.7 N·m
8×10⁻⁴ ±0.8% 4.8 N·m

建议的电机规格（交给 GC 选型）：

  • 额定 550 W / 5000 r/min（1.05 N·m），峰值力矩 ≥ 3 N·m。
  • 转子加手轮惯量约 4×10⁻⁴ kg·m²。
  • 按每 2 s 起停一次估算（加速、减速各 0.1 s，缝 1.3 s，停 0.5 s）：力矩均方根约 0.9 N·m，在额定力矩之内。

GC 要仿真验证三件事：

  1. 速度环怎么设：带宽要低于 167 Hz 的二倍频。
  2. 能不能按转角查表，给已知的负载力矩加前馈：力矩起伏的形状是确定的，补一部分能进一步减小转速波动，但要权衡电机发热。
  3. 0.1 s 起动、停针定位、剪线时序。
