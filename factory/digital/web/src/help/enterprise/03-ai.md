# AI 设置

> 国内部署只用 DeepSeek；其他地方缺省用 Claude，一家出错自动换另一家。

## 怎么选

| 设置 | 说明 |
| --- | --- |
| 自动（缺省） | 看部署地区：国内用 DeepSeek，其他用 Claude。地区由服务器 `.env` 的 `WQ_AI_REGION`（`cn` 或 `intl`）定；没写时按时区判断，中国时区算国内 |
| 固定 Claude / DeepSeek | 厂长或管理员在“厂情中枢 · AI 运行记录”里改，存在库里，重启后照样生效 |
| 国内部署 | 只用 DeepSeek（已备案模型）：选 Claude 也不会调用；DeepSeek 出错时不换 Claude，AI 助手改用规则回答 |
| 出错换另一家 | 国外部署、两家都配了密钥时，首选的那家出错（网络、额度、超时）自动换另一家，运行记录里注明 |
| 都没配 | AI 助手改用规则回答，其他功能照常 |

密钥写在服务器工厂目录的 `.env` 里（`WQ_CLAUDE_KEY`、`WQ_DEEPSEEK_KEY`），只放在服务器上。改完运行 `deploy/update.sh`（不带参数）重启生效。
