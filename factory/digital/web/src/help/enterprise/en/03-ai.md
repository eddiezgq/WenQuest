# AI settings

> Deployments in China use only DeepSeek; elsewhere Claude is the default, and if one provider fails the other takes over automatically.

## How to choose

| Setting | Notes |
| --- | --- |
| Automatic (default) | By deployment region: DeepSeek in China, Claude elsewhere. The region comes from `WQ_AI_REGION` (`cn` or `intl`) in the server `.env`; if unset it is judged by time zone, a China time zone counting as China |
| Fixed Claude / DeepSeek | The plant manager or an admin changes it in “Plant Insight Hub · AI run log”; it is stored in the database and survives restarts |
| China deployment | Only DeepSeek (a filed model): choosing Claude does not call it; when DeepSeek fails it does not switch to Claude, and the AI assistant answers by rules |
| Fail over to the other | Outside China, with keys for both, if the preferred provider fails (network, quota, timeout) it switches automatically, noted in the run log |
| Neither configured | The AI assistant answers by rules; everything else works as usual |

Keys go in `.env` in the factory directory on the server (`WQ_CLAUDE_KEY`, `WQ_DEEPSEEK_KEY`), and only on the server. After changing them run `deploy/update.sh` (no arguments) to restart.
