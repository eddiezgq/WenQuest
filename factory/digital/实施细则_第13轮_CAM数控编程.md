## 一、目标

在“专业软件”里加第三个工具 **“数控编程”**（CAM），教学平台先用。打通“设计 → 工艺 → 编程 → 仿真 → 车间加工”：

- 从**工艺规程的一道工序**出发（零件、机床、刀具、切削参数都已经在工艺规程里），生成刀路和 G 代码；
- 在浏览器里**仿真**：刀路回放、去除材料、和设计模型比对（过切 / 欠切）、估算加工时间；
- 检查通过后**随工艺规程下发**：ERPNext 的工序附上程序，车间终端派工时把程序发给对应机床，3D 车间按程序回放。

## 二、决定（待确认）

| 编号 | 决定 | 理由 |
|---|---|---|
| C1 | **第一期两类加工**：① 数控车（两轴）：车端面、外圆粗车（分层）、精车轮廓（含轴肩、倒角）、切槽；② 2.5 轴铣：键槽（已有，改进）、型腔、外轮廓、钻孔（含啄钻）。三轴曲面加工（模具类）**不做**，以后可用 OpenCAMLib（LGPL）加 | 覆盖 WQR-105 零件的主要工序（轴类车削、键槽、箱体平面和孔）；曲面加工教学用得少、难度大 |
| C2 | **自己写刀路算法**（Python，轮廓偏置用 shapely），不在服务器上跑 FreeCAD。会用 FreeCAD CAM 的同学，照旧可以在桌面 FreeCAD 里编程，再用“我的 CAD 宏包”提交 G 代码 | 和键槽一样，每一步学生读得懂；服务器不装 FreeCAD（体积大、慢） |
| C3 | **几何从哪来**：车削从 STEP 自动提取回转轮廓（复用第 11 轮的读面功能：圆柱、圆锥、端面）；铣削从 STEP 识别平面型腔、外轮廓、孔。SH-301 直接用设计台的参数。识别不了的，可以在模型上点面指定 | 任何 CAD 的零件都能用；识别不准时有人工兜底 |
| C4 | **参数从工艺规程来**：切削速度 vc、进给 f、切深 ap、刀具、毛坯都取自这道工序；转速、进给速度由程序算（S = 1000·vc / πD，F = f·S）。可以改，改了会提示与工艺规程不一致 | 工艺和程序一致，不各写一套 |
| C5 | **后处理**：输出 FANUC 风格 G 代码（车床 G18 / G96 恒线速 / G50 限速 / T0101；铣床 G54 / G43 / M06 / G83 啄钻），按机床（CNC-L01、KEY-01、VMC-01、HMC-01）带行程、最高转速检查。程序头写零件、版本、工序、刀具表 | 国内教学、企业最常见的格式 |
| C6 | **仿真与检查**（浏览器里）：刀路回放（快移虚线、切削实线，可拖进度）；去除材料（车削按回转轮廓、铣削按高度图）；和设计模型比对，标出过切 / 欠切；检查超程、快移撞工件、转速 / 功率超限（功率按工艺规程现有的切削功率公式）；估算加工时间，与工艺规程的工时比较 | 程序上机前先在电脑上“试切” |
| C7 | **一句话编程与 AI 讲解**：一句话例如“粗车外圆，每刀 2.5，留 0.3 精车余量”“铣键槽，分 5 层”，AI 只填参数表、人确认后才生成。AI 可以**逐段讲解 G 代码**（这段在干什么、为什么这样写）、指出风险（如快移离工件太近）。走现有 AI 通道（国内 DeepSeek，Claude 只在美国） | AI 原生；“讲解程序”对教学特别有用 |
| C8 | **下发**：程序检查通过后，挂到工艺规程这道工序上，走工艺规程已有的“提交 → 审批 → 生效”。生效后 ERPNext 工序附上程序；车间终端派工时把程序发给机床（总线消息沿用 `design.gcode`）；3D 车间按程序回放 | 不另起一套流程 |
| C9 | **教学**：实验 10“输出轴数控车削与键槽铣削编程”。学生按工艺规程给 SH-301 的粗车、精车、铣键槽三道工序编程，仿真检查，算加工时间，与工艺规程工时对比，提交审批。指导书、报告模板，挂课程接口 | 每个工具都要能进课 |
| C10 | **合规与许可**：自写代码 + shapely（BSD）；不引入 GPL 的 CAM 库到在线服务里 | 总规矩 |

## 三、交付物与验收

| 交付物 | 验收 |
|---|---|
| 车削 | SH-301 粗车、精车：刀路覆盖全部外圆和轴肩；仿真后的轮廓与精车工序尺寸（含余量）的差 ≤ 0.01 mm；不过切 |
| 2.5 轴铣 | 键槽、一个带型腔和孔的平板零件（零件库或测试件）：仿真高度图与设计模型比对，过切为 0、残留在刀具半径以内 |
| G 代码 | 两种后处理输出能被本平台的解析器和一个独立的开源 G 代码解析器读通；行程、转速超限能查出来 |
| 加工时间 | 估算值与按长度、进给手算一致（误差 < 2%）；与工艺规程工时对比给出提示 |
| 下发 | 程序挂到工艺规程工序 → 审批生效 → 车间终端派工时机床收到程序、3D 车间能回放（演练闭环里走一遍） |
| 一句话与讲解 | 示范句能正确填表；没配模型时规则兜底；讲解覆盖程序的每一段 |
| 教学与帮助 | 实验 10 指导书、报告模板；帮助《数控编程》 |

## 四、施工顺序

1. 刀路核心：车削（端面、粗车分层、精车轮廓、切槽）和铣削（键槽、型腔、外轮廓、钻孔）；后处理两种；加工时间；自动测试。
2. 几何识别：STEP → 回转轮廓 / 型腔、轮廓、孔；从工艺规程取参数。
3. 网页：选工序 → 参数 → 生成 → 仿真（回放、去除材料、比对、检查）→ 下载程序。
4. 下发：挂到工艺规程工序，审批生效，ERPNext、车间终端、3D 车间。
5. 一句话编程、AI 讲解程序。
6. 实验 10、帮助、验收。

每步完成即上线。

## 五、不在这一轮

- 三轴及以上曲面加工、五轴。
- 螺纹车削、滚齿（齿轮由滚齿机按齿轮参数加工，不需要 G 代码编程）。
- 刀具磨损、切削振动的仿真。
