# 问渠数字工厂 · 实施细则 · 第 18 轮 E5：供应链深化领域包

2026-10-07 · 依据：`docs/方案/厂情中枢架构与方案.md` 第九节“领域包”E5；承接第 17 轮厂情中枢（缺料 W1、采购逾期 W2、紧急采购动作）、E1（客户投诉 → 数字主线追溯）、E3（备件）。

> 状态：**已确认，施工中（2026-10-07，Eddie：“按建议”）**。六个问题都按建议。

## 一、目标

现在的供应链只走到一半：平台能算料、起草请购单（ERPNext Material Request），“紧急采购”也只是把请购单的到货日提前。之后的事情都没有：没有向哪家供应商下采购单，货什么时候真的到、到了多少，来料合不合格，这批料用到了哪些零件——全都缺。规则只有 W1（缺料）、W2（采购逾期），厂情中枢“供应链”一块的供应商评价、来料检验、批次还是“待采集 / ERPNext 可启用”。

E5 把料的一生接进工厂：**请购 → 采购单（选供应商）→ 供应商发货 → 收货 → 来料检验 → 批次入库 → 用到哪些零件 → 供应商评价**。核心是两个取舍：
- 货晚了或来料不合格，是催货、换备选供应商下急单（贵、快），还是调整生产顺序先做别的；
- 一类料只靠一家供应商（单一来源），平时便宜，出事时没有退路。

按领域包的标准做齐六样：采集应用、教学模拟器、规则、动作、态势卡、帮助；再加 AI 代理的工具和评测题、一个新实验。

这一轮结束时，两个验收故事要能在网页上完整走通：

**故事一：轴承来料不合格，生产要停**
1. 五大湖轴承的一批 BRG-6207（40 件）到货。来料检验抽 8 件，2 件游隙超差，判不合格（来料检验 + 批次进 ERPNext）。
2. 厂情中枢开异常“来料检验不合格”：这批货进不合格品库，库存不够装配，排在后面的工单、订单列出来。
3. 右栏方案，用车间推演算：
   - 退货，等原供应商补发（7 天）；
   - 向备选供应商下急单（贵 20%，3 天到）；
   - 让步接收、全检挑用（检验工时，能用的件先用）；
   - 不处理（对照）：装配等料，订单晚几天。
4. 采纳“备选供应商急单”：ERPNext 生成采购单；到货、检验合格后入库，装配继续。供应商评价里五大湖的合格率下降。

**故事二：铸件供应商老是晚**
1. 东岳铸造近 30 天 4 张采购单晚到 3 张，准时率 25%。厂情中枢开“供应商准时率低”和“单一来源”两条异常。
2. 看供应商评分卡（准时、质量、价格三项），采纳“开发备选供应商”：给箱座铸件加一家备选，以后缺料方案里就多一个选择。

## 二、决定（已确认）

| 编号 | 决定 | 理由 |
|---|---|---|
| E5-1 | **采购单、收货、来料检验、批次以 ERPNext 为准**：Purchase Order（提交）、Purchase Receipt（带批号）、Quality Inspection（Incoming，沿用现有的进货检验模板）、Batch。平台经桥接写、轮询读回。**供应商评价、备选供应商、发货模拟在平台** | 这些单据要进财务和库存；ERPNext 现成 |
| E5-2 | **采集应用：新页“采购与来料”**（计划员、质量、厂长默认可见；手机好用）。四个标签：<br>① **采购单**：在途、到货、逾期；从请购单一键转采购单（按物料的默认供应商，可改选备选）；<br>② **收货与来料检验**：到货 → 收货 → 抽检（按模板逐项填，合格 / 不合格 / 让步接收）；<br>③ **批次**：每个批次的来源（供应商、采购单、收货日）、检验结果、用到了哪些零件和工单；<br>④ **供应商**：评分卡（准时率、合格率、价格指数）、每类物料的默认和备选供应商 | 方案“每个领域都有采集应用” |
| E5-3 | **供应商与备选**：6 家现有供应商保留；每类关键物料（轴承、铸件、锻坯、钢材）加一家**备选供应商**：贵 10–25%、提前期短。油封、润滑油等保持单一来源（教学上留单一来源的例子） | 有备选，缺料时才有“换供应商”这个选项 |
| E5-4 | **教学模拟器（供应商会出问题）**：下采购单后，供应商按提前期发货，每家有自己的“准时率”和“合格率”参数（例如东岳铸造准时率低、五大湖轴承偶尔有一批不合格）；会晚几天、偶尔少发；到货后来料检验的结果按合格率抽签。老师可以注入“这家下一批晚 N 天”“下一批不合格”。**教学模式默认开，载入实验 7 情景时关闭**（和以前一样：情景里的料按原来的方式到），生产模式不模拟（货由真实供应商发） | 和 E3“会坏”、E4“要有人”同一个做法 |
| E5-5 | **批次追溯**：外购件和原材料按批次入库；车间每做一件，记下它用了哪个批次（零件出厂档案里加“原料批次”）。来料不合格或客户投诉时，能从批次查到零件、工单、现场设备，反过来也能从设备查到料的批次和供应商（接上 E1 的数字主线） | 质量追溯的另一半 |
| E5-6 | **规则（5 条新，加原有 W1、W2）**：<br>W3 来料检验不合格未处理；<br>W4 供应商准时率低（近 30 天低于 80%，至少 3 张单）；<br>W5 供应商来料合格率低（近 30 天低于 95%）；<br>W6 单一来源的关键物料（只有一家供应商、近期用量大）；<br>W7 批次风险：已判不合格的批次有料已经用到了零件上（要追查）。<br>W2 采购逾期加上“影响到哪些工单、订单” | 覆盖交付、质量、结构、追溯 |
| E5-7 | **处理预案与新动作（4 种）**：<br>· 预案：W2 / W3 ——“催货或退货等补发 / 备选供应商急单 / 让步接收全检（仅 W3）/ 不处理（对照）”，用车间推演（推演里的到货日按选择改）+ 采购费用；W7 ——“扣住在制品复检 / 通知受影响客户（沿用 E1）”；W6 ——“开发备选供应商”；<br>· 新动作：① **采购单**（ERPNext Purchase Order，可选供应商）；② **退货**（ERPNext 退货单，计入供应商评价）；③ **让步接收**（全检工时，按件放行）；④ **开发备选供应商**（建 ERPNext 供应商、设为某类物料的备选）；<br>· 审批：采购单、退货计划员发起、厂长批；让步接收要质量批；开发备选厂长批。原有的“紧急采购”保留（向原供应商加急） | 沿用 17C 的动作框架 |
| E5-8 | **新实验 20“供应链：来料不合格与供应商选择”**（4 学时）：看供应商评分卡 → 老师注入一批不合格的轴承 → 学生做来料检验（填数据、判定）→ 追这批料用到了哪里 → 比较“退货等补发 / 备选急单 / 让步接收 / 不处理”（比对模式）→ 执行 → 算两家供应商的“总拥有成本”（价格 + 晚到 + 不合格的代价），写开发备选供应商的建议。自动评分 + 报告；指导书、报告模板、课程接口 | 每个领域包配一个实验；和实验 16（客户投诉追溯）一头一尾 |

## 三、存储

平台新增 4 张表：

```
supplier_profile (mode, supplier, category, role, price_index, lead_days, on_time_p, pass_p, active)   —— 默认 / 备选供应商与模拟参数
supply_sim       (mode, state jsonb)                                                                   —— 在途批次、老师注入
batch_use        (mode, batch, item_code, part_serial, work_order, unit, at)                           —— 批次用到了哪个零件
supplier_score   (mode, supplier, day, on_time, pass_rate, price_index)                                —— 每天的评分（趋势）
```

ERPNext 侧：桥接新增写 Purchase Order（从请购单转、可指定供应商）、Purchase Receipt（带批号）、Quality Inspection（Incoming）、Batch、Purchase Return、Supplier；轮询读 Purchase Receipt、Quality Inspection、Batch。本体里收货、来料检验、批次、供应商评价转为“已有数据”。

## 四、接口

- `GET /api/supply/pos`、`POST /api/supply/pos`（从请购单转采购单，经动作）
- `GET /api/supply/receipts`、`POST /api/supply/receipts/{id}/inspect`（来料检验）
- `GET /api/supply/batches`、`GET /api/supply/batches/{batch}`（来源、检验、用在哪）
- `GET /api/supply/suppliers`（评分卡、默认与备选）
- 教学：`POST /api/supply/sim`（老师开关、注入延期 / 不合格）、`/api/lab20/*`

## 六、施工顺序

1. 供应商档案与备选、采购单（从请购单转）、桥接 Purchase Order / Receipt / Batch。
2. 发货模拟（默认关，现有测试不变）、收货、来料检验（ERPNext Quality Inspection）。
3. 批次入库与车间用料记录、追溯接上 E1 数字主线。
4. 规则 W3–W7、处理预案、4 种动作；“采购与来料”页四个标签；态势卡、日报。
5. 老师注入；AI 代理工具与评测题。
6. 实验 20、帮助、方案；闭环测试第 17 段；服务器演练；上线。
