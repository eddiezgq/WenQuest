# 问渠数字工厂 · 实施细则 · 第 16 轮：流体分析（CFD）

2026-10-04 · 承接：《企业数字化解决方案》（`docs/方案/`）“以后：流体（OpenFOAM）”；第 11 轮（计算服务、排队、一句话设置、报告）；第 14 轮（温度场：散热系数靠教材经验值）；第 15 轮（数字孪生的“假如加风扇”）

> 状态：**待 Eddie 确认**

## 一、目标

第 14、15 轮算温度时，最关键的散热系数 h 是从教材表里查的（通风良好 17.45、轴端风扇 31……），谁也说不清“我这台、这样吹”到底是多少。流体分析补上这一块：

1. **看见风怎么走**：风扇吹过减速器箱体、气流穿过 CPU 散热片，哪里风大、哪里是死角。
2. **算出散热系数**：每个面的 h 由流场算出来，一键送进“仿真与分析”的温度场，代替查表——设计、温度、孪生三处都用上真实的数。
3. **会做最基本的流体题**：管流压降、绕圆柱阻力、平板换热，和教材公式核对，这是流体力学、传热学课的标准实验。

## 二、决定（待确认）

| 编号 | 决定 | 理由 |
|---|---|---|
| F1 | **求解器用 OpenFOAM**（GPL，同 CalculiX 一样作为独立程序在计算服务里调用，不改它的源码），装 Debian 12 自带的 OpenFOAM 软件包（ESI 版，第 1 步先核实版本和镜像大小）。网格用 OpenFOAM 自带的 blockMesh + snappyHexMesh（STEP → 表面 STL → 贴体网格） | 工业界最常用的开源 CFD；许可和第 11 轮一样干净 |
| F2 | **第一期只做三维、不可压、定常**：① 冷态流场（simpleFoam，k-ω SST 湍流模型，层流可选）；② **强制对流换热**：流场算完再解能量方程（固定壁温或热流，空气物性按 25 ℃），输出每个面的平均散热系数 h 和散热量。自然对流（浮力）、瞬态、两相、燃烧不做 | 覆盖“风扇吹 / 风道 / 外流阻力 / 散热系数”这几类最常见的机械设计问题；单次计算控制在几分钟 |
| F3 | **算例形式“虚拟风洞 / 风道”**：零件放进一个长方体风洞（外流）或给定风道（内流），用户只填：风速或风扇风量、来流方向、空气温度、零件表面温度；平台自动定风洞尺寸、网格（教学上限约 50 万单元、10 分钟）、边界条件 | 学生和工程师都不用写 OpenFOAM 字典；可以任意上传 STEP |
| F4 | **教学主例：WQR-105 箱体轴端风扇冷却**——第 14 轮的简化箱体（可带散热筋），风从轴端吹来；算出外表面各面的 h，和教材 K_s = 31–38 比；“送到温度场”后箱体油温和第 14 轮查表结果对比；数字孪生的“假如加风扇”改用这次算出的 h。**生活例子：电脑 CPU 散热片在风道里**（第 14 轮的散热片），片数、风速对 h 和压降的影响。**机器人例子**：AGV 小车电控箱的通风（进出风口位置对散热的影响） | 与前两轮首尾相接；三个例子分别是外流、内流、箱内通风 |
| F5 | **标准题验收**（全部和教材公式比）：① 圆管层流（Hagen–Poiseuille 压降）；② 绕圆柱（Re = 20–40 定常，阻力系数和教材 / 文献值比）；③ 平板层流强制对流（Nu = 0.664 Re^½ Pr^⅓）；④ 方腔或管道湍流压降（Moody 图 / Blasius 公式） | 每个数都能和书对上，才敢给学生用 |
| F6 | **新页“流体分析 CFD”**（专业软件新增一项）：选零件（示例 / 已发布物料 / 上传 STEP）→ 风洞或风道、来流 → 换不换热 → 计算（排队，同有限元）。结果：三维的速度截面云图、流线、表面压力和表面 h 着色（沿用“仿真与分析”的三维查看器）；卡片：阻力 / 压降、平均 h、散热量、网格和收敛；每个面的 h 表；“送到温度场”；Word 报告 | 用法和“仿真与分析”一致，少学一套 |
| F7 | **一句话与 AI 解释**：“轴端风扇 5 m/s 从左边吹，空气 25 ℃，箱体表面 70 ℃”能填表；结果由 AI 解释（风从哪走、哪里是死角、h 为什么比查表高 / 低、怎么改：加导流罩、移风扇、改筋的方向）；走现有 AI 通道（国内 DeepSeek，美国 Claude） | AI 原生 |
| F8 | **教学**：实验 14“减速器风扇冷却的流体与传热分析”：标准题核对（管流压降、平板换热）→ 箱体风扇冷却：流场、各面 h、与 K_s 比 → 送到温度场看油温 → 改筋的方向 / 风速比较 → 选做 CPU 散热片风道、AGV 电控箱。指导书、报告模板，挂课程接口 | 每个工具都要能进课 |
| F9 | **合规与许可**：OpenFOAM（GPL）作为独立程序调用、以在线服务方式提供（同 CalculiX）；网格转换、后处理自写（numpy、已有的 Gmsh / trimesh） | 总规矩 |

## 三、交付物与验收

| 交付物 | 验收 |
|---|---|
| CFD 核心 | 四道标准题：管流压降与 Hagen–Poiseuille 差 < 3%；绕圆柱 Re = 40 阻力系数与文献值（约 1.5）差 < 5%；平板层流平均 Nu 与 0.664 Re^½ Pr^⅓ 差 < 5%；湍流管流压降与 Blasius 差 < 10% |
| 任意零件 | 上传的 STEP 能自动进风洞、出网格、算完；网格超限、不收敛时有明确提示 |
| 箱体风扇冷却 | 各面 h 和教材 K_s 同量级（差异和原因写进报告）；送到温度场后油温比“通风良好 17.45”明显低，与第 14 轮“风扇 31”的结果可比 |
| 网页 | 选件、设置、排队、速度截面、流线、表面 h、卡片、h 表、送到温度场、报告；浏览器走一遍 |
| 一句话与解释 | 示范句能正确填表；没配模型时规则兜底 |
| 教学与帮助 | 实验 14 指导书、报告模板、课程接口；帮助新增《流体分析》 |

## 四、施工顺序

1. CFD 核心：计算服务装 OpenFOAM、核实版本；STEP → STL → 风洞 / 风道网格；simpleFoam 冷态流场；四道标准题测试。
2. 换热：能量方程、每个面的 h 与散热量；平板换热标准题；“送到温度场”的接口。
3. “流体分析”网页：设置、排队、三维结果（截面、流线、表面着色）、卡片、h 表、报告。
4. 示例：箱体风扇冷却、CPU 散热片风道、AGV 电控箱；数字孪生“假如加风扇”改用算出的 h。
5. 一句话与 AI 解释。
6. 实验 14、帮助、验收、方案更新。

每步完成即上线。

## 五、不在这一轮

- 自然对流（浮力驱动）、瞬态流动（涡脱落的时间历程）、多相流、燃烧、旋转机械（风扇叶片本身用“给定风量”代替）。
- 流固共轭传热（固体内部和流体一起算）：本轮用“CFD 算 h → 温度场用 h”两步走。
- 大规模网格（> 50 万单元）和并行计算。
