设计优化（参数优化、平面拓扑优化）

数字工厂工作台左侧“专业软件 → 设计优化”。人只定目标（越轻越好、越凉越好）和要求（安全系数、疲劳寿命、最高温度），平台自己改尺寸、跑几十次真实的有限元 / 温度场，找出满足要求的最好方案；结果送回设计台或“仿真与分析”。教学模式、生产模式都能用；公共工厂、演示工厂、各班级工厂都有。

配套实验：实验 11 减速器热平衡与输出轴轻量化，页面右上角可下载指导书和报告模板（Word），课程接口里也有链接。

页面顶部分两块：参数优化（改尺寸）和拓扑优化（平面件：材料该放在哪）。

一、参数优化

1. 优化什么

问题 可以改的尺寸 每次评估做什么 默认目标和要求
输出轴 SH-301 齿轮位直径（36–46，每档 0.5）、两端轴伸直径（26–33）；轴承位 Ø35 由轴承定死，不参加 先过设计台校核（不过的直接算“不可行”），再按示范题（两处轴承、轴伸限制转动、键槽侧面 350 N·m）做有限元，算安全系数；按 0 → 350 N·m 脉动算疲劳寿命 最轻；安全系数 ≥ 1.3、无限寿命
WQR-105 箱体 每侧散热筋数、筋高、壁厚 按示例零件生成箱体，自动设热边界，算温度场 又轻又凉（两个目标）；最高温度 ≤ 80 ℃
CPU 散热片 片数、片高、片厚 同上 最轻；最高温度 ≤ 85 ℃

页面会显示现行尺寸。输出轴总是以设计台的现行参数为起点（最近批准的设计）。

2. 设置

  • 一句话：例如“输出轴越轻越好，安全系数不小于 1.5，寿命无限，齿轮位只能在 38 到 44 之间，算 30 次”，点“AI 填表”。规则能认“越轻 / 最凉 / 又轻又凉”“安全系数不小于 x”“寿命无限 / 至少 x 小时”“不超过 x 度”“某尺寸 a 到 b”“算 n 次”。
  • 勾选：勾上要改的尺寸，改范围；选目标；填要求；次数（最多 60 次，每次优化最多 15 分钟）。
  • 点“开始优化”。优化和有限元共用一个计算服务、一起排队，一次优化会占住计算服务几分钟，别人的计算要排在后面。

3. 看结果

结果一行行出来（不用等全部做完）：

  • 第 1 次固定是现行设计，方便对比；同一组尺寸只算一次。
  • 最好的一组：尺寸、质量（或温度）、比现行变化多少、安全系数、寿命。
  • 图：一个目标时画每次的值和“到这次为止最好的”（看第几次以后很难再变好）；两个目标时画质量—温度散点和帕累托前沿（再轻就一定更热，再凉就一定更重的那一串方案）。
  • 表：每次的尺寸和结果，满足 / 不满足要求及原因。
  • AI 解释：比现行好多少、哪个要求卡住了最优解、两个目标怎么取舍、下一步做什么。
  • 用这组：
  • 输出轴 →“送到设计台”：打开设计与工艺页，参数和改动说明已经填好，还没发布；看过校核和三维再走发布流程。
  • 箱体、散热片 →“到仿真与分析”：按这组参数重新生成零件、填好热边界，直接点计算看温度云图。

算法：Optuna（MIT 许可）的 TPE 贝叶斯优化——先随机试几组，再根据已算结果猜“哪里更可能更好”；约束用 Optuna 的约束机制。

二、拓扑优化（平面件）

不改尺寸，而是回答“材料该放在哪”：给定板件外形、支承和载荷、材料用量，算出刚度最大的形状。

  1. 选板件：MBB 梁（简支梁的一半，经典算例）、悬臂梁、桥 / 简支梁、支架。下面有支承和载荷示意图。
  2. 材料用量（体积比，20–70%）和网格（最多 6000 格）。“算法参数”里可以改惩罚指数 p（越大越黑白分明）和过滤半径（决定最细的杆有多粗，太小会出现棋盘格），一般不用改。
  3. 实际尺寸：长、板厚、载荷、材料——只在“拉伸成板件做有限元校核”时用。
  4. 点“开始拓扑优化”，一般几秒到二十秒。

结果：黑白密度图（黑 = 有材料；MBB 梁同时画出镜像的另一半，看整根梁），可播放生长过程、拖动看某一次迭代；柔度（越小越刚）、迭代次数、灰色单元比例三张卡片；柔度—迭代曲线；解释（形状为什么是桁架 / 拱）。

拉伸成板件，去有限元校核 →：按密度 0.5 取轮廓、拉伸成板，在支承和载荷处加一小块垫块（避免点载荷的奇异应力），跳到“仿真与分析”，零件、约束、载荷、材料、网格都已填好，直接点“开始计算”。拓扑优化只管刚度，强度要靠这一步校核。

算法：SIMP（固体各向同性材料惩罚），按 Andreassen 等 2011 年“88 行程序”的经典方法自写（平面应力四节点单元、灵敏度过滤、最优准则法），MBB 梁 60 × 20、体积比 0.5 得到柔度约 203，与文献一致。

两块各有记录表（老师看到本厂所有人的），点“看”随时打开。

四、限制

  • 参数优化里每次评估用“中”等网格；键槽尖角处的最大应力随网格变化几个百分点，选定方案后要在“仿真与分析”里用细网格复核。
  • 输出轴只改直径，不改轴承位、长度和键槽；轴变细后键要不要换、齿轮内孔要不要改，要在设计台和装配里一起看。
  • 温度场只算导热和表面对流（散热片没有算片间空气流动），结果用于比较方案。
  • 拓扑优化只做平面件、只管刚度（柔度最小），不做三维拓扑优化和形状优化；轮廓是锯齿状的，做零件前要修圆、按加工方法调整。
  • 有限元校核时简支梁两端的垫块都按“固定”（比真正的简支略刚）。
