招标抓取

每天北京时间 06 点，国内服务器自动抓取中国政府采购网、全国公共资源交易平台的公开招标公告，按关键词筛选， 07:10 结果自动取回到 GitHub，每日招标判断任务从这里读取。

看结果

GitHub 仓库 → Actions → 左侧 tender-crawler → 最新一次运行：页面上直接显示当天摘要；下方附件 tender-feed 可下载 latest.json / latest.md（保留 7 天）。日志里 =====TENDER-FEED-JSON-BEGIN===== 与 END 之间是同一份 latest.json（给读不了附件的环境用）。

手动操作（都在 Actions → tender-crawler → Run workflow 里选）

选项 作用
fetch 取回最新结果（默认）
run 立即抓一次并取回
status 看定时任务、最后运行日期、日志
install 程序有更新时重新安装（配置和历史数据保留）

改关键词、地区、来源

改仓库里的 ops/tender-crawler/config.yaml 只影响新装的服务器。服务器上真正使用的是 ~/tender-crawler/config.local.yaml（第一次安装时复制，以后升级不覆盖）。要改，登录服务器以 deploy 用户编辑该文件，下次运行自动生效。

出问题

  • 某来源 blocked：对方拦截或出验证码。按规矩当天停止访问该网站，不重试、不绕过；第二天会再试。
  • 某来源 error 或长期 0 条：网站改版，需要改 ops/tender-crawler/tender_crawler/sources.py，再运行 install。
  • 预算、截止时间是规则识别，可能不准，以公告原文为准。

规矩

只访问公开页面、控制频率、不登录、不绕过验证码、不报名、不发邮件、不联系任何人；只用规则提取，不调用大模型（以后若用，只能用国内已备案模型）。
