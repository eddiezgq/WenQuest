仿真与分析（有限元强度、疲劳寿命、温度场与热应力）

数字工厂工作台左侧“专业软件 → 仿真与分析”。不用装软件，在浏览器里设置，服务器计算（Gmsh 划网格、CalculiX 求解、pyLife 算疲劳；温度场也用 CalculiX）。教学模式、生产模式都能用；公共工厂、演示工厂、各班级工厂都有。

配套实验：实验 8 输出轴强度与疲劳校核、实验 11 减速器热平衡与输出轴轻量化、实验 12 一根轴的数字化设计与两个典型案例，页面右上角可下载指导书和报告模板（Word）。

一、四步算一次强度

  1. 零件：下拉框里是已经发布过三维模型的物料（输出轴 SH-301 总有；《机械设计》第 33 章的两根案例轴——协作机器人关节空心轴 RJ-201、平缝机上轴 LS-101——也总有，没人发布新版本时是第 1 版），选好点“读入”；也可以直接上传任何 CAD 导出的 STEP（30 MB 以内）。
  2. 材料：12 种常用材料（45 钢、40Cr、20CrMnTi、Q235、Q345、HT200、QT500-7、6061-T6、7075-T6、304、ABS、PA66）。点“出处”能看到每个数值来自哪本标准或手册。
  3. 约束与载荷，两种方法：
  4. 一句话：在框里写，例如“两个 Ø35 轴承位支承（左边那个止推），右端 Ø30 轴伸限制转动，键槽侧面加 350 N·m 扭矩，45 钢调质”，点“AI 填表”。AI 只填表，下面会列出它把哪句话理解成了哪个面；没看懂的会标出来，请手动补上。
  5. 点选：点“+ 固定 / 轴承支承 / 限制转动 / 力 / 压力 / 扭矩 / 力矩”加一行，再到右边模型上点面（再点一次取消）。鼠标停在面上会显示面号、类型、直径和面积。
种类 什么时候用
固定 焊死、夹紧，三个方向都不能动
轴承支承 圆柱面，只限制径向（轴能转）；勾“止推”再限制轴向。一根轴至少一个止推。勾“只限中间一圈（铰支）”：只限制轴承位中间约 1 mm 宽的一圈，止推只限一个节点——算固有频率时要勾（见下）

压力 垂直压在面上（MPa）

SH-301 还有“填入示范题”按钮，一键填好额定工况。 4. 网格：粗（快）、中、细（慢），也可以在“或指定单元尺寸”里直接填（细长、小直径的零件用，例如平缝机上轴填 3 mm）。点“开始计算”。

一次算一个任务，其余排队，页面会显示前面还有几个。中等网格一般 5–20 秒。教学版上限约 20 万个单元、5 分钟，超了会提示把网格调粗。

二、看结果

  • 云图：Von Mises 应力 / 位移 / 疲劳寿命切换；“变形放大”拖动看变形；“剖切”看内部；鼠标停在哪里就显示那里的应力、位移。粉点是最大应力，青点是最大位移。
  • 四张卡片：最大应力（在哪几个面）、安全系数（强度 ÷ 最大应力；小于 1 红、小于 1.5 黄）、最大位移、网格规模和用时。脆性材料（HT200）没有屈服强度，按抗拉强度算。
  • 两点要注意：
  • 约束面附近的高应力是理想约束造成的，评估最大值时已经避开（页面会写出避开前的数值）。
  • 没有圆角的内角（尖角）处应力理论上没有上限，网格越细数值越大。看“位置”和“趋势”，并按规范的应力集中系数校核。
  • AI 解释与建议：点“请 AI 解释结果”，AI 讲最危险在哪、为什么、怎么改，并给出可以一键执行的建议：
  • “换成 40Cr 重算”：同一零件、同一工况，换材料直接重算；
  • “到设计台试：键槽轴段 Ø40 → Ø44”：打开设计与工艺页，参数已经填好、改动说明已经写好；看过校核和三维再发布，回来重新读入零件再算。
  • 下载计算报告（Word）：设置、材料出处、网格、结果表、应力和位移云图（算过疲劳的还有疲劳一节和疲劳云图）、结论、AI 解释。

三、疲劳寿命

结果下方的“疲劳寿命”：

  1. 载荷谱：
  2. 恒幅：最大、最小值和频率。计算工况里有扭矩时按 N·m 填；没有扭矩时按“计算工况的倍数”（1 = 计算时的载荷，−1 = 反向）。
  3. 关节力矩记录：选一次“运动与动力分析”的计算（自己算完的）和一个关节，用这个关节的驱动力矩随时间的变化作载荷谱，按计算工况的扭矩线性缩放。要求计算工况里有扭矩。用于机器人关节轴（教材 33.10 节）。
  4. 上传 CSV：一列数（有几列时取最后一列），单位与计算工况相同（有扭矩时按 N·m），再填“这一段多少秒”。整段当作一个块不断重复。注意：载荷谱是把计算工况按比例放大缩小，表达不了“轴在转、力也在转”的弯曲（高速轴的弯曲应力循环要手算，教材 33.11.3 节）。
  5. 跑合试验台转矩记录：仿真车间每台减速器跑合试验时记录的输出轴转矩（带式输送机 启动—运行—停机 × 3，75 秒）。选一条记录能看到曲线。载入或重置实验 7 情景时，会补上最近交付的几台减速器的记录。
  6. 表面状态（磨削、精车……）、尺寸系数（直径 30–50 mm 约 0.85）、附加缺口系数 Kf（有限元已经算出形状造成的应力集中，一般填 1）。
  7. Haibach：勾上时，低于疲劳极限的应力幅也计损伤（偏安全）；不勾就是原始 Miner。
  8. 点“计算疲劳寿命”，得到最危险点的寿命（小时、循环次数，或“无限寿命”）、修正后的疲劳极限，以及最危险点损伤最大的几个循环（可以照着手算核对）。云图切到“疲劳寿命”看各处寿命，红色寿命最短。

算法：线弹性比例加载 → 载荷谱当作重复的块做雨流计数（pyLife 四点法）→ Goodman 平均应力修正 → 修正后的 S-N 曲线 → Miner 线性累积损伤。

四、固有频率（模态分析）

算完一次强度以后，结果下方“固有频率”→“计算固有频率”：用同样的零件、材料、网格和支承，求前几阶固有频率和对应的转速（Hz × 60），载荷不起作用。填“工作转速”，表里列出各阶相当转速与工作转速之比（工作转速及其 2 倍要离开固有频率）。结果进 Word 报告。

  • 轴承支承怎样加：单列深沟球轴承允许轴在轴承里转一点角度，接近铰支。整个轴承位都限径向，相当于把轴夹住，固有频率会偏高很多（平缝机上轴的例子高出一倍）。所以算固有频率时，轴承支承都勾“只限中间一圈（铰支）”。做强度计算时两种都可以。
  • 不计装在轴上的零件（齿轮、带轮、转子）的质量；要计入时用梁单元法（教材 33.7、33.11 节）。
  • 只用支承，零件能绕轴线转、沿轴线移动时，这些“刚体运动”的频率接近 0，已经去掉。

五、示例零件：WQ-CR5 大臂（强度与模态）

《机器人学》第 31 章的算例在这里能再算一遍。

  1. 零件下拉框选“示例 · WQ-CR5 大臂（铝管 + 法兰，强度与模态）”。参数：关节间距（大臂长，默认 400 mm）、铝管外径（90）、壁厚（3）、端部法兰厚（10）、法兰中间的线缆孔（50）、负载（5 kg）。点“读入”，系统按参数现做三维模型。
  2. 读入后自动切到“强度”，约束、载荷、材料、网格都已填好：J2 端的法兰端面固定；J3 端的法兰端面受力（J3 以外的部分——J3 模组、小臂、手腕、负载——的重量，约 120 N 向下）和力矩（弯矩约 41 N·m、扭矩约 7 N·m）。这组力取自机器人厂的 WQ-CR5 模型：手臂水平伸直、工具朝下、带所填的负载；零件坐标 x 沿 J2 的轴、y 朝上、z 沿管轴。材料 6061-T6，网格 8 mm。
  3. 点“开始计算”（约半分钟）。结果下方“和教材公式比”列出梁理论：根部弯矩、当量应力和安全系数、J3 端的下沉、这根管一端固定时的一阶固有频率（计入 / 不计法兰的质量）。有限元的最大应力多在法兰与管的内角——那是应力集中，网格越细越大；管中段的应力、端部的位移与梁理论相差几个百分点以内。
  4. 点“计算固有频率”：前两阶是一对上下、左右的弯曲振型（圆管两个方向一样硬）。这是这根管自己的频率，装到机器人上以后整机的第一阶只有十几赫兹（教材 31.5 节）。
  5. 改参数重算：壁厚 3 → 2、外径 90 → 110，看下沉、应力、频率怎样变；换材料（7075-T6、Q345）对照教材表 31.4.1。

七、温度场与热应力

第 3 步“算什么”有三种：强度 / 温度 / 温度 + 热应力。

  1. 零件：除了已发布的物料和上传的 STEP，下拉框里还有两个可改参数的示例零件：
  2. WQR-105 简化箱体（减速器热平衡）：外形、壁厚、每侧散热筋（数量、筋高、筋厚）、负载率。发热按传动效率算：η = 0.97²（两级齿轮）× 0.99³（三对轴承）= 0.913，额定时 482.6 W。
  3. 电脑 CPU 散热片（生活例子）：底板、片数、片高、片厚、CPU 接触面、发热功率。 改了参数点“读入”重新生成。示例零件有“填入示范题”，一键填好热边界、材料和网格，并附教材公式估算。
  4. 材料：材料行会显示导热系数、比热、线膨胀系数，出处同样可查。
  5. 热边界，两种方法：
  6. 一句话：例如“箱体内壁发热 480 W，外表面自然对流（通风良好），环境 20 度”或“CPU 接触面发热 65 W，其余所有面风扇直吹散热，室温 25 ℃，算 30 分钟瞬态”，点“AI 填热边界”。AI 只填表并列出理解；没说怎么散热时会自动补“其余所有面自然对流”。
  7. 点选：
种类 什么时候用
固定温度 面的温度已知（贴着热源、冷却水套）
对流散热 向空气 / 液体散热：散热系数 h 和环境温度。h 可从参考表选（通风差 8.15、通风良好 17.45、风扇 31 / 38、强制风冷 50、油 100、水 1000 W/(m²·K)），也可自己填；勾“其余所有面”就不用一个个点
面发热 这个面上总共进来多少瓦（芯片贴合面、摩擦面、箱体内壁）
整体发热 整个零件体积内均匀发热（线圈），不用选面

至少要有一个固定温度或对流的面，否则热量散不出去。 4. 温度可勾“瞬态”，填时长和初温，看温度随时间怎样升上去；温度 + 热应力还要加约束（至少一个固定或支承面，机械载荷可以不加），并填无应力参考温度（装配时的温度）。

结果：温度云图（最高温度点标红；热应力时还有应力、变形云图）；卡片有最高 / 最低 / 表面平均温度、热平衡（进来的热量和对流散走的热量应相等）、各对流面的面积、平均温度和散热量；示例零件还有和教材公式的对比；瞬态画最高、平均温度随时间的曲线。AI 解释说明最热在哪、为什么、是否超限，超限时给出可一键执行的建议（“加 8 条散热筋重算”）。Word 报告有温度场 / 热—结构耦合两种版式。

单位和方法：稳态、瞬态（后向欧拉）、热—结构耦合（CalculiX *COUPLED TEMPERATURE-DISPLACEMENT）。热分析不在发热面附近加密网格（温度场平滑）。

八、限制

  • 温度场只算导热和表面对流，不算辐射和空气 / 油的流动（散热系数是经验值，差 10–20% 很正常，重要的是比较方案）。
  • 线弹性、小变形；不考虑接触（键与槽、过盈配合）、塑性、残余应力、表面硬化。用于教学和方案比较，正式设计请按标准复核。
  • 一个 STEP 里可以有多个实体，但它们之间没有连接关系（不算装配体接触）。
  • AI：国内部署用 DeepSeek，美国用 Claude；没配模型时用规则理解一句话和写解释，规则能认端面、轴肩、外圆 / 孔 Øxx、键槽侧面 / 底面、面编号、方向和材料；热边界能认发热 / 功率、对流 / 风扇 / 自然 / 水冷、散热系数、环境温度、固定温度、瞬态时长和初温、内壁 / 外表面 / 底面 / 接触面 / 其余所有面。用到模型时，次数计入每人每小时的 AI 上限。

运动与动力分析（多体动力学，类 ADAMS）

工作台左侧“专业软件 → 运动与动力”。求解器 MuJoCo，在服务器上算，和有限元共用一个计算队列。配套实验：实验 9 机械臂关节力矩与电机选型，页面右上角下载指导书和报告模板。

一、选模型

  • 零件库机构（10 种）：曲柄摇杆（四杆）、曲柄滑块、盘形凸轮、两级齿轮系、WQR-105 减速器传动链、槽轮、棘轮、蜗杆蜗轮、带传动、丝杠。参数默认取零件库的值，可以改。构件按钢的密度算质量。
  • 机械臂：UR5e、UR10e、Franka FR3（MuJoCo Menagerie 的公开模型）。
  • 上传：MJCF（.xml）、URDF（.urdf），或带网格文件的 zip（100 MB 以内）。

二、设置

  • 一句话：例如“曲柄 60 rpm 匀速转，滑块上有 200 N 阻力，仿真 3 秒”“底座转 90°，大臂抬 30°，1.2 秒，末端带 4 kg”“输入轴 1450 rpm，输出轴负载 350 N·m”。点“AI 填表”，看看它填得对不对，再计算。
  • 驱动：
  • 机构只驱动主动件，其他构件由机构带动；从动件上可以加工作阻力或负载力矩（与运动方向相反填负值）。
  • 机械臂每个关节一行：自由、保持、匀速、点到点（梯形速度，可改加速段比例）、正弦、给定力矩。角度用度，转速用 r/min，移动用 mm。
  • 负载与重力：末端负载（质量）、外力、是否计重力。
  • 记录点：要看轨迹的点（例如四杆的连杆中点，画出来就是连杆曲线）。
  • 仿真时长：最多 60 秒。

三、看结果

  • 动画：播放、拖进度、调速度，记录点的轨迹画成线。
  • 驱动汇总：每个驱动的峰值、均方根、最高速度、峰值功率、平均功率。平均功率为负说明电机在“发电”（下放、制动）。
  • 曲线：驱动力矩、功率、位置、速度、加速度、关节反力、反力矩、点坐标，按组切换。鼠标停在曲线上看数值，点一下动画跳到那一刻。
  • 导出曲线（CSV）、下载报告（Word）：报告带设置、汇总、各构件受力峰值、动画截图、当前显示的曲线、电机选型和 AI 解释。
  • AI 解释与建议：说明峰值出现在什么时候、为什么（惯性、重力、阻力），给出可一键执行的建议，例如“运动时间放长到 1.5 倍重算”。

四、电机选型

结果页点“按这次的力矩、转速选电机和减速器”，可选安全系数。

  • 每个驱动关节推荐一组“交流伺服电机 + 谐波减速器 + 传动比”，并给出裕量和最紧的一项。
  • 校核三项：峰值力矩、均方根力矩、转速。电机侧力矩计入转子惯量。
  • 参数表是通用典型值，实际选型以厂家目录为准。
  • 机构只给主动件选电机。

五、和强度、寿命接起来

  • 四杆、曲柄滑块的结果页有“把杆件受力最大的时刻送去有限元：曲柄 / 连杆 / 摇杆 →”。打开“仿真与分析”时，杆件模型、约束（A 端销孔固定）和载荷（B 端销孔受动力学算出的最大力）都已填好，确认后计算。
  • 这样送来的有限元任务，疲劳寿命多一种载荷谱“动力学受力记录”：这根杆在整个运动中的受力变化。

六、限制

  • 刚体模型：不计构件弹性、关节间隙；默认不算碰撞。摩擦、阻尼可在设置里加。
  • 凸轮、槽轮、棘轮按理想的“函数耦合”算（从动件始终跟着主动件），不模拟脱开和撞击的细节；棘轮啮合瞬间有冲击尖峰。
  • 杆件送有限元时按二力杆近似，略去惯性力和自重。
