在线编辑 Word 和 Excel

电脑上不用装 Office 或 WPS：在问渠的经典界面（classic. 子域名）里，Word、Excel、PPT 直接在浏览器里打开、编辑、多人同时改，文件存在我们自己的服务器上（国内、美国各一套，不出境）。

自己写的教案、指导书、通知，更省事的是 网页文档（AI 可写初稿、可发布给学生、可导出 Word / PDF），见《老师用网页文档》。这里的在线 Word 适合外面拿来的文件、必须按对方模板排版的文件。

背后是开源的 OnlyOffice 文档服务（官方社区版，不限同时在线人数），地址是 learn.<主域名>/docs/，只给学习平台自己用，单独打开没有内容。

老师：在课程里放一份可以在线编辑的文档

  1. 经典界面打开课程 → 右上角“编辑模式” → 在某一节点“添加活动或资源” → 选 ONLYOFFICE 文档。
  2. 填名称；文件可以：
  3. 点图标新建空白的 文档（Word）、电子表格（Excel）、演示文稿或表单；
  4. 或者 上传文件（外来的 docx、xlsx、pptx 都行）。
  5. 保存后点开就是编辑器。几个人同时打开会看到彼此的光标和修改，自动保存。
  6. 需要下载时，编辑器里“文件 → 下载为”，可选 docx、pdf 等。

老师：让学生在作业里直接在线写 Word

  1. 添加“作业”，在“提交类型”里勾 ONLYOFFICE 文档。
  2. “格式（ONLYOFFICE）”选文档或表格；“文件模板（ONLYOFFICE）”可以：
  3. 从空白文档开始；
  4. 编辑默认模板：把模板内容放进去，每个学生拿到的都是这份模板的副本。学生提交后模板不能再改。（教材实验的报告不用这样做，直接用“在线实验报告”。）
  5. 可选：允许学生在评分后在文档里留评论。
  6. 批改：在作业的提交列表里点开学生的文档，直接看、批注、打分。

学生那边：打开作业 → “添加提交” → 在页面里直接写 → 保存并提交，不用下载、不用上传。

说明

  • 主要方式是网页文档：实验报告已经可以在问渠页面上写、一键导出 Word / PDF，教学文件等以后陆续做。在线 Office 主要用来处理外来文件和必须按对方模板填写的文件。
  • AI：编辑器自带的 AI 插件已关闭（国内只能用已备案模型）；需要 AI 帮忙写，用问渠自己的 AI 入口。
  • 服务器资源：文档服务最多占 2 GB 内存。大量老师同时使用前，先告诉运维（可能需要给服务器加配置）。

运维

  • 健康：https://learn.<主域名>/api/health 里 docs 为 ok；或在服务器上 docker compose ps docs。
  • 密钥：.env 的 DOCS_JWT_SECRET，第一次部署时 deploy/update.sh 自动生成；Moodle 启动时 setup_wenquest.php 把地址和密钥填进插件设置（经典界面“网站管理 → 插件 → 活动模块 → ONLYOFFICE 文档”可以看到，“检查连接”按钮可测）。改密钥要重启 docs 和 moodle 两个容器。
  • 版本：只在 docker-compose.yml 的 docs 服务写一处（现为 onlyoffice/documentserver:10.0.0.1），升级时同时改 deploy.yml 的国内同步清单 BASE（CI 会核对两处一致、镜像存在）。国内服务器的镜像自动改用国内镜像仓库里的同名镜像。
  • 打不开编辑器时先看：docs 容器是否健康；浏览器能否打开 https://learn.<主域名>/docs/healthcheck（应显示 true）；Moodle 插件设置页“检查连接”。
