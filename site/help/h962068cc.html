三维仿真视频使用说明

一句话要一段工程级三维仿真视频：机构怎么动、零件里面发生了什么，可以剖开、透视、慢放，带中英标注和读数。动作由程序算出（机械臂按逆运动学，缝纫机按虚拟样机的机构），不是手调的动画，读数可以写进课件和报告。

负担在 AI： 你说要什么，AI 写场景；你提意见，AI 改。AI 只用平台已有的模型，不凭空造形状。

一、谁能用

账号 怎样用
老师（能建课的账号） 直接能用，左边菜单 三维视频
企业客户 在官网“三维仿真视频”页点 申请开通；管理员开通后，左边菜单出现 三维视频
开通了缝纫机设计软件的企业 在缝纫机设计软件“导出 → 出三维讲解片”按自己的设计一键出片（平缝机、包缝机；第 76 轮起绷缝机；第 89 轮起花样机、刺绣机、横机，六种都有），然后在这里看、改自己的讲解片、出小样和高清；不能在这里另起别的视频
学生 不能用（看不到菜单，接口也拒绝）

收费：老师开课免费；其他用途按租用机器的时间收费，11 月上线。现在都不收费，平台只记下每次用了多少机器时间。

二、出一段视频

  1. 左边菜单 三维视频。两种开始方式：
  2. 在上面的框里写一句要求，点 AI 写场景，例如“讲清楚平缝机旋梭怎样钩住线环、在布里扣成线结，先整机再特写”；
  3. 在 从样片开始 里挑一段，点 照这个改（复制一份给你改，原样片不变）。
  4. 进入工作页：
  5. 左边是和 AI 编导的对话；
  6. 中间是出片区，有三个标签：关键画面、小样、高清；
  7. 下面是时间线（每条标注在第几秒出现）。
  8. 出关键画面：6 张静帧，约 1–2 分钟，先看构图和镜头对不对。点图片可以放大。
  9. 不满意就在左边 提意见，例如“镜头再近一点”“第 3 步慢一点”“这里加剖面”“标注改成……”，点 按意见改。AI 改完场景，再出关键画面看。
  10. 出小样（960×540，整段）：平台临时租一台渲染机器，约 6–10 分钟，其中开机约 3–5 分钟。可以离开页面，回来看进度（等机器 → 开机 → 准备环境 → 已渲染多少帧 → 合成）。
  11. 出高清（1920×1080，MP4 和 WebM）：约 15–30 分钟。出完点 下载。
  12. 场景改过以后，旧的关键画面和视频会标“场景改过了，这一版是旧的”，需要时重出。

机器出完视频就自动关机。正在出的可以点 取消出片，机器马上关掉。

二之〇、旁白

所有三维视频都能配中文（或英文）旁白，用平台本地的语音服务（国内、美国都能用，不调外部模型）。

  • 念什么：一句话让 AI 写的视频，AI 写场景时顺带写好解说词——每段镜头一两句，讲“现在看什么、为什么这样”，比标题、字幕多讲一层；解说词里的数只能用画面上已有的数（平台会查，不合格让 AI 重写）。从样片复制、没有解说词的视频，念画面上的标题和底部字幕。
  • 新建默认配：写要求的框下面有“配旁白”，默认勾上；从样片开始也按这个勾。AI 写完（或样片复制好）就自动配。
  • 老视频：工作页“关键画面 / 小样 / 高清”下面有“配旁白”开关，打开就配一次；关掉以后出的小样、高清没有声音，场景退回配旁白前那一版（配好以后又改过的，节奏保持现在的样子）。
  • 段落跟着旁白走：旁白比画面长的段整段放慢拉长（镜头、动作、字幕、关键画面一起顺延），读完再进下一段。配了旁白的片子最长 150 秒（不配的 120 秒）。
  • 改片：提意见、直接改场景文件以后，旁白自动重配；每句话都缓存，没变的句子不重新合成，几秒钟就好。
  • 时间线：蓝色“旁白”标签的那几行是解说词，写着从第几秒念到第几秒，和标注一条一条对上。
  • 关键画面没有声音；小样、高清里有。国内站暂时只出关键画面，声音先在美国站的小样、高清里听到。这台服务器没装语音服务、或语音服务出错时，照无声的出，对话里会说明。

二之一、缝纫机设计软件的讲解片

在缝纫机设计软件里点 出三维讲解片，平台按当前这组设计参数自动写好场景，不用写一句话：整机 → 各机构（平缝机刺布、挑线、钩线、送布；包缝机刺布、下弯针、上弯针、送布与差动、切边）→ 红黄灯项（最多三项，在出问题的主轴转角慢放，标题标红 / 标黄）→ 结论，约 40–70 秒。零件、尺寸、每个转角的位置都由设计软件的计算核心给，和网页三维、STEP、计算书是同一套。

花样机、刺绣机、横机讲的是“一个花样 / 一片衣片怎么走完”：整机 → 一针（一趟）慢放讲清楚 → 两轴 / 绷架 / 机头一趟 → 快放走完整个花样（横机每隔若干趟看一趟），途中在最紧的一针（刺绣机最难的一针）和红黄灯项出问题的那一针 / 那一趟停下慢放 → 结论。针迹、每针转速、每趟走法同设计软件的“样机”页签；机构尺寸是示意（教材模型 15-1、16-1、17-1）。上传的花样文件、意匠图不写进场景，场景里带抽样后的轨迹（最多 800 针 / 趟，压缩成一串字，也锁定）。

旁白：默认配（设计软件里可以取消）。讲解片不写解说词，念的是画面上每一段的标题和底部字幕（口语读法，数不变），用平台本地的语音服务；旁白比画面长的段放慢拉长，读完再进下一段，关键画面仍停在原来那一刻。配好以后页面上写“这一版配了旁白”，小样、高清里有声音。改了字幕、节奏（AI 改或直接改场景文件），旁白自动重配；这台服务器没装语音服务、或语音服务出错时，照无声的出，对话里会说明。

之后照上面第 3–6 步出关键画面、小样、高清，也可以提意见改。锁定的东西：这台设计的机型和参数（每次都改回原样）；不能删掉或换掉这台设计、不能加别的模型（只能加方块、圆柱做标示）；字幕和标题里的数只能用计算核心给的那些（原字幕里有的）。镜头、节奏、透视剖开、字幕措辞都能改。

三、用到课里

  • 白板课：编辑白板课时点 插入，在“我的三维视频”里选（有高清用高清，没有就用小样）。
  • 网页课件、其他地方：下载 MP4 后上传。

四、高级：直接改场景文件

工作页下方点 直接改场景文件（高级），改完点 检查并保存。平台会先检查： - 只能用已有模型； - 时间不能超出视频长度； - 标注不能太长（中文 46 字以内，否则会出框）； - 镜头关键点要写全； - 缝纫机讲解片另有上面说的锁定。

不合格会列出哪里不对，不保存。格式见仓库 tools/blender/场景格式.md。

五、管理员

三维视频 页最下面是 管理：开通账号与用机记录： - 填企业客户的账号名或邮箱（备注写公司名），点 开通；取消开通 后对方就看不到菜单了。 - 用机记录：每次出片用的机型、用时、花费，以及合计。

服务器上的设置（.env）： - VIDEO3D_LAMBDA_KEY：Lambda 的 API 密钥。不填就用云端 GPU 实验的 WQ_GPU_LAMBDA_KEY。两个都没有时，只能出关键画面，页面上会提示。 - 同时最多开 2 台机器，一台最长 3 小时，没有空闲机器最多等 60 分钟。这些在网关设置里可改（WQ_VIDEO3D_MAX_MACHINES 等）。

六、它是怎么做的（给维护的人）

  • 关键画面：服务器上的 blender 容器（Blender 4.2 + 渲染器 + 平缝机虚拟样机网页）。这个容器没有密钥、不能上网，一次只出一个。
  • 小样和高清：网关在 Lambda 上租一台机器（按 WQ_VIDEO3D_LAMBDA_TYPES 的顺序挑有空的机型，默认先 A10）。经 JupyterLab 传上去渲染器包、场景文件和 run.sh，在后台运行。网关每 15 秒读一次进度，出完取回视频，然后关机。
  • 每次开机都记在 video3d.db 的 run 表里。网关重启后，会接着跟进没出完的。
