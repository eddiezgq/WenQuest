虚拟实验与实验报告使用说明

适用：大学物理A（上）第 1 章 · 读者：教师、学生

学生

  1. 打开实验：在问渠课程页点“虚拟实验”，或在课件实验页点“打开虚拟实验”。电脑、手机都能用。右上角 EN / 中文 切换语言。
  2. 读指导书：每个实验都有一份《实验指导书》（中英对照），写明目的、原理、参数范围、步骤、数据表和思考题。先读再做。
  3. 做任务：每个实验右侧有任务清单，完成后自动打勾。标“机器人”的任务对应本节的机器人实际问题。进度只保存在你这台设备的浏览器里，换设备需要重做。
  4. 记数据：按指导书的表格记录测量值；读数在小球落地、抓取或航行结束后显示。
  5. 写报告：首选 在线写报告——在教材的实验下面或作业里点“在线写报告”，在页面上写，虚拟实验里点“记入报告”把数据记进去，写完点“提交”。详见《网页文档与在线实验报告》。
  6. 也可以照旧下载《实验报告模板》（Word），填好后在问渠“作业”中上传。
  7. 报告第六部分“实际问题的建模与求解” 是重点，按五步写：① 问题 ② 模型（写出简化假设）③ 求解 ④ 用虚拟实验检验 ⑤ 模型在哪里失效、怎样改进。
  8. AI 使用声明：如果用了 AI，如实勾选并写明用在哪里。

教师

  1. 课堂：每节课按“实际问题 → 概念 → 动画 → 虚拟实验 → 建模求解”讲。动画页点击画面播放；实验页投屏演示机器人场景。
  2. 布置：每节课的实验任务课后完成；本章至少交一份实验报告（任选一个机器人问题）。
  3. 批改：按《实验报告评分量规》评分，满分 100：原理 20、数据 25、分析 25、实际问题 20、规范 10。AI 给出评分建议，由教师复核后发布。
  4. 登记：量规表格的“成绩登记”页自动求总分和等级，示例行替换为本班数据即可。
  5. 参考数值（与虚拟实验一致）：

常见问题

  • 任务没有打勾：看任务的条件（如偏差范围）是否满足；数值滑块步长有限，把计算值四舍五入到滑块的步长。
  • 课件里的视频放不了：在问渠里演示时，动画在课件原位置播放；自己用 WPS 或较旧的 PowerPoint 打开时可能不支持嵌入视频，改用课程文件夹“动画”里的原片。
  • 实验链接打不开：在问渠里打开课件，点“去做实验 1.x”或课件上的“打开虚拟实验”按钮，会直接切到本章的虚拟实验，不需要另外的链接。
  • 课件和实验来回切换：课件演示页上方的“课件 | 虚拟实验”切换是瞬间的；切回课件停在原来那一页，实验里调好的参数也不丢。

给制作实验页面的老师：问渠实验约定

实验页面（一个 HTML 文件里有多个实验，如 1.1–1.5）只要做到下面两点，就能被问渠课件直接“跳到实验 1.3”，而且不重新加载页面：

  1. 每个实验有编号，网址带 #lab-1-3 打开时直接显示实验 1.3。
  2. 页面监听两种切换信号，收到就切到对应实验、保留其他实验的参数：
  3. 平台发来的消息：{type: "wq-lab", lab: "1.3"}；
  4. 网址里的 #lab-1-3 发生变化（hashchange）。

第 1 章实验页里的写法（放在切换函数 show() 定义之后）：

const pickLab = (v) => { const k = String(v || "").replace(".", "-"); if (LABS[k] && k !== active) show(k); };
addEventListener("message", (e) => { const d = e.data || {}; if (d && d.type === "wq-lab") pickLab(d.lab); });
addEventListener("hashchange", () => pickLab((location.hash.match(/lab-(\d+-\d+)/) || [])[1]));

课件里只要写“1.3 虚拟实验”“实验 1.3”或“Lab 1.3”，或者按钮链接带 #lab-1-3，问渠就会在那一页显示“去做实验 1.3”。

For students (English)

Open the lab from the course page or the “Open virtual lab” button in the slides, and switch language with EN / 中文 at the top right. Read the lab guide first, complete the tasks (they tick themselves), record your data in the guide’s tables, and write the report either in the Word template or online in WenQuest. Section 6, “Modelling a real problem”, follows five steps: problem, model and assumptions, solution, check with the lab, and where the model fails. Declare any AI use honestly.

AI 做的虚拟实验

AI 建课时，“实验师”为每节课写一个虚拟实验，放进本章的实验页（每章一页，每节一个标签）。它们和第 1 章标杆同一版式：机器人场景和生活场景两个按钮、参数滑块、测量读数、任务自动打勾、中英切换，并遵守上面的“问渠实验约定”。

  • 怎么保证能用：每个实验发布前都在服务器上自动试运行一遍：页面不报错，每个场景都有画面，每个参数都能调，每个任务按 AI 写的“示范做法”操作后真能打勾。任何一项不过就交回 AI 修改，最多两次。
  • 安全：实验页不能联网、不能读取账号信息；学生打开时在独立沙箱里运行。
  • 任务进度：只保存在学生自己的浏览器里（和第 1 章一样）。
  • 技术备注：实验骨架是 services/gateway/app/production/labkit/（kit.js、kit.css，示范实验 demo_lab_2_1.js）；试运行服务是 services/labcheck/（无界面 Chromium，和动画服务一样不带密钥、不能上网）。

量子力学部件与画势能

实验工具包新增两样东西，平台上 AI 做的实验和教材实验都能用：

  • api.qm：一维薛定谔方程求解台。单位：长度 nm，能量 eV，时间 fs；电子质量可乘有效质量因子。
  • api.qm.levels(V, dx, n, mr)：给定格点上的势能，求最低 n 个能级和归一化的波函数（有限差分 + 三对角本征值；简并的能级也能得到相互正交的波函数）。几千个格点在浏览器里瞬时算完。
  • api.qm.packet(x, x0, sigma, k0)、api.qm.step(psi, V, dx, dt, mr)：高斯波包和克兰克–尼科尔森法的一步时间演化，概率始终守恒。
  • api.qm.prob(psi, dx, i0, i1)：某一区间内找到粒子的概率；api.qm.k(E, mr)：自由粒子的波数。
  • 与教材程序里的 _qm.py 是同一算法，书中的数与实验读数一致（实验格点较少，差别在 1% 以内）。
  • 画布指针：实验写了 pointer(kind, x, y, api, state)，学生在画面上按下、拖动、松开时就会调用它（鼠标和手指都可以），例如实验 44.3 让学生“自己画势能”。自动试运行只操作参数和按钮，所以靠画图完成的内容不设自动打勾的任务。

物理仿真实验

有的实验用真正的物理引擎算：转动的物体、下落的连杆、举着负载的机械臂。浏览器里跑的是 MuJoCo 官方的网页版（3.14.0），和教材里的程序用的是同一个版本，所以网页上看到的数字和书里的数字一样。

学生： - 打开这类实验时，上方会先显示“正在加载物理引擎”。引擎约 3 MB，只在第一次下载，之后浏览器会记住。 - 按“开始”后，画面按真实时间运动，下方曲线同步画出角速度、力矩等，可以拖动画面换角度。 - 有的场景不用按“开始”：拖动滑块，机械臂马上摆到新姿态，右侧直接显示各关节要出的力矩。 - 手机上也能用；手机较慢时，画面里的时间会比真实时间走得慢一点，结果不变。

写实验的老师（写法与普通实验相同，多三项）： - view: "physics"； - physics.xml(api)：返回 MuJoCo 模型（MJCF）。滑块改的量写进模型里，例如质量、尺寸；模型变了平台会自动重建。 - 书中的机器人用 api.mjcf("ur5e", {tool, world, option, actuator}) 取，目前有 UR5e 和 Franka FR3。 - 这两台的模型来自 MuJoCo Menagerie，去掉了网格，碰撞形状换成胶囊，质量、惯量不变。 - 外观用零件库的模型：在 models: ["B-ARM-UR5E"] 里写上即可。 - 仿真数据在 api.sim（mj、m、d）。reset 里可以设初始状态，update 里读状态、判任务，chart 画下方曲线。 - 样板见 services/gateway/app/production/labkit/demo_physics.js（网球拍定理）和 demo_physics_ur5e.js（UR5e 关节重力矩）。 - 机器人模型由 textbook/tools/mjcf_web.py 从 Menagerie 生成。 - 教材构建会在无头浏览器里试做每个任务。textbook/tools/tests/test_mujoco_web.py 检查网页版和 Python 版逐位一致。

安全： 这类实验页只允许从本站 /vendor/ 取 MuJoCo 文件，其余网络访问仍然全部禁止。MuJoCo 的网页版需要动态生成函数，所以这类页面放开了这一项。因此目前只用于书中写好、审过的实验；AI 建课自动写的实验暂不能用物理仿真。
