注册、登录与审核（管理员和老师看）

一、大家怎么注册、登录

  • 入口：官网 wenquestrobotics.com 右上角“登录 / 注册”，或直接打开 https://learn.wenquestrobotics.com 。
  • 注册：
  • 选“我是学生”或“我是教师”，填姓、名、邮箱。
  • 点“发送验证码”，把邮件里的 6 位数字填进来（10 分钟有效），再设密码（至少 8 位，含字母和数字）。
  • 勾选同意《用户协议》《隐私说明》。
  • 开通规则：
  • 学生：注册完马上能用。
  • 教师 + 学校邮箱（.edu、.edu.cn、.ac.cn、.ac.uk 等）：注册完马上是教师，可以 AI 建课。
  • 教师 + 其他邮箱（qq、163、gmail…）：先按学生开通，同时提交教师申请（可以上传工作证、聘书照片）。AI 马上预审，结果等管理员一键批准。
  • 登录：邮箱（或学校发的用户名）+ 密码。忘记密码点“忘记密码？”，用邮箱验证码重设。
  • 一个账号到处通用：在任何一处登录后，官网右上角显示你的名字；学习平台、虚拟实验室不用再登录。在官网右上角点“退出”，或在学习平台“账户 → 退出登录”，都会在所有地方一起退出。
  • 学生想当老师：学习平台“账户 → 申请成为教师”，填写单位、上传材料即可。

二、管理员：只需一键批准

学习平台左边栏多了“管理”（只有管理员看得到，红色数字 = 待办数）。

  1. 教师审核：
  2. 每份申请上方有 AI 的建议（建议批准 / 建议补材料 / 建议拒绝）和一句理由，下面是申请人上传的材料，点一下可以放大看。
  3. 点 ✓ 批准：对方立即成为教师，系统自动发邮件通知。
  4. 点 拒绝：AI 已写好礼貌的理由，可以直接发，也可以改一下再发。
  5. AI 觉得证据不足时，会自动发邮件请申请人补材料（只发一次）；申请人补完，AI 重新审。
  6. 有新申请时，系统给你发一封汇总邮件，同一小时最多一封，邮件里有“去审核”链接。
  7. 课程报名：学生报名收费课后出现在这里，确认收到钱后点 ✓ 开通，学生会收到开通邮件。
  8. 用户：查找任何人，可以设为/取消教师、停用/恢复账号、给他发重设密码的邮件。

页面右上角显示“邮件：已开通 / 未配置”和当前 AI 模型，方便检查。

三、老师：把课程放进课程目录

课程 → 单元模块 → 编辑 → ⚙ 课程设置 → “课程目录”：

  • 不公开（默认）：只有你拉进来的学生能看到。
  • 公开 · 免费：出现在课程目录，任何注册用户点一下就能加入。
  • 公开 · 收费：填价格（人民币或美元）。学生点“报名”并留言（如缴费方式），管理员确认后开通。在线支付以后接入。

可以写一句话介绍，显示在目录卡片上。课程目录不登录也能看：https://learn.wenquestrobotics.com/pages/catalog/catalog

四、一次性设置：发信邮箱（Eddie 做一次）

服务器在 DigitalOcean，它封了常用的发信端口，所以用 Brevo（免费每天 300 封，支持 2525 端口）发信，发件人 noreply@wenquestrobotics.com。域名在 Cloudflare。

  1. 打开 brevo.com 注册免费账号。
  2. 右上角账号菜单 → Senders, Domains & Dedicated IPs → Domains → Add a domain，填 wenquestrobotics.com，页面列出几条 DNS 记录。
  3. Cloudflare → wenquestrobotics.com → DNS → Records → Add record，逐条照抄。CNAME 记录要点成灰云（DNS only）。回 Brevo 点 Verify。
  4. 一个域名只能有一条 v=spf1 开头的 TXT 记录；已经有的话，把 include:spf.brevo.com 加进原来那条。
  5. Brevo → Senders → 添加发件人 noreply@wenquestrobotics.com，名称“问渠机器人学院”。
  6. Brevo → SMTP & API → SMTP → Generate a new SMTP key，记下 Login 和 key（不要发给任何人）。
  7. 登录服务器执行 nano /opt/wenquest/.env，填： SMTP_HOST=smtp-relay.brevo.com SMTP_PORT=2525 SMTP_SECURE=tls SMTP_USER=<第5步的 Login> SMTP_PASSWORD=<第5步的 SMTP key> MOODLE_NOREPLY_EMAIL=noreply@wenquestrobotics.com WQ_ADMIN_EMAIL=<接收审核通知的邮箱> 保存后执行 cd /opt/wenquest && deploy/update.sh。
  8. 检查：学习平台 → 管理，右上角应显示“邮件：已开通”。用一个新邮箱注册一次，看能否收到验证码。

没配好之前：注册时验证码不会发出，只写进服务器日志（docker compose logs gateway | grep 验证码），可用来自己测试。

可选：收信。官网写的联系邮箱是 info@wenquestrobotics.com。想收到寄给它的信，在 Cloudflare → Email → Email Routing 开启，把 info@ 转发到你的常用邮箱。开启时 Cloudflare 会加 MX 记录和它自己的 SPF，要和 Brevo 的 SPF 合并成一条，例如 v=spf1 include:_spf.mx.cloudflare.net include:spf.brevo.com ~all。

五、技术备注

  • 账号在 Moodle 里；注册、审核走插件的 local_wenquest_account_* 接口，只有网关的服务账号 wqservice 能调用。它的令牌由 WQ_SECRET_KEY 自动推导，容器启动时自动建好，不用填。
  • 验证码、教师申请、AI 意见、课程目录设置存在网关数据卷 accounts.db，每日备份（gateway.tgz），deploy/restore.sh 会一并恢复。
  • 密码规则：Moodle 的密码策略同步改成“至少 8 位、含数字”，字母由问渠注册页检查。
