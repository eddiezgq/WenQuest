安装Install

  1. 下载 WenQuestCAD-…-Setup.exe（约 1.4 GB）。可以用页面上的校验码核对文件是否完整。Download WenQuestCAD-…-Setup.exe (about 1.4 GB); you can check it against the SHA-256 shown.
  2. 双击运行。测试版没有买代码签名证书，Windows 多半会拦一下——照下面“Windows 不让装怎么办”一步步做，几分钟就能装上。Run it. The beta has no code-signing certificate, so Windows will probably stop it once — follow “Windows won't let me install” below; it takes a few minutes.
  3. 选语言 → 同意使用说明与许可 → 选安装位置（默认即可）→ 安装，约 3–5 分钟。Pick a language → accept the terms → choose a folder (the default is fine) → Install, about 3–5 minutes.
  4. 装完桌面上有问渠 CAD，双击打开；窗口标题是 “WenQuest CAD 1.1.4”。A WenQuest CAD shortcut appears on the desktop; the window title reads “WenQuest CAD 1.1.4”.

Windows 不让装怎么办（按你看到的提示找）Windows won't let me install (find the message you see)

  1. 浏览器下载完就提示“通常不会下载此文件 / 可能有害”The browser says the file “isn't commonly downloaded / might be harmful”
    Edge：在下载列表里这个文件右边点 … → 保留 → 再点 显示详细信息 → 仍然保留。Chrome：点 保留。Edge: in the downloads list click … next to the file → Keep → Show more → Keep anyway. Chrome: click Keep.
  2. 双击后蓝色框“Windows 已保护你的电脑”Blue box “Windows protected your PC”
    先点框里的小字 更多信息，下面才会出现 仍要运行 按钮，点它。Click the small More info link first; a Run anyway button appears — click it.
  3. 框里只有“不运行 / 确定”，没有“仍要运行”Only “Don't run / OK”, no “Run anyway”
    在下载文件夹里右键安装包 → 属性 → “常规”页最下面勾上 解除锁定 → 确定，再双击。In the downloads folder right-click the installer → Properties → at the bottom of the General tab tick Unblock → OK, then double-click again.
  4. 提示“智能应用控制已阻止此应用”，或者双击没有任何反应“Smart App Control blocked this app”, or nothing happens
    这是 Windows 11 的“智能应用控制”，它只放行有签名的软件。打开 Windows 安全中心 → 应用和浏览器控制 → 智能应用控制设置 → 选 关闭，再装。注意：在不少 Windows 11 版本上，关掉后不能自己再打开（要重装系统才能恢复）；介意的话先别关，等有签名的正式版。This is Windows 11 Smart App Control, which only allows signed software. Open Windows Security → App & browser control → Smart App Control settings → Off, then install. Note: on many Windows 11 versions it cannot be turned back on without reinstalling Windows; if that matters to you, wait for the signed release.
  5. 杀毒软件报毒，或者安装包不见了The antivirus flags it, or the installer disappears
    Windows 自带的：Windows 安全中心 → 病毒和威胁防护 → 保护历史记录 → 点这条记录 → 操作 → 还原（或“允许”）。别的杀毒软件在它的“隔离区 / 信任区”里恢复并信任。可以先用页面上的 SHA-256 核对文件没被改过（PowerShell：Get-FileHash 文件名）。Windows Defender: Windows Security → Virus & threat protection → Protection history → open the entry → Actions → Restore (or Allow). Other antivirus: restore it from quarantine and trust it. You can first check the file against the SHA-256 on this page (PowerShell: Get-FileHash file).
  6. 公司或学校的电脑Company or school computer
    这类电脑常常不准装没签名的软件，请找管理员。These often block unsigned software; ask your administrator.

安装教程 · FreeCAD 工作台（缝纫机、轴承、凸轮）Install guide · FreeCAD workbenches (Sewing, Bearing, Cam)

  1. 装好问渠 CAD（自带这些工作台的运行环境），或装官方 FreeCAD 1.1（Windows、macOS、Linux 都行）。Install WenQuest CAD, or the official FreeCAD 1.1 (Windows, macOS or Linux).
  2. 下载工作台的 zip，解压。Download the workbench zip and unzip it.
  3. 在 FreeCAD 里打开 Python 控制台（菜单 视图 → 面板 → Python 控制台），输入 App.getUserAppDataDir() 回车，显示的就是你的用户数据文件夹。In FreeCAD open the Python console (View → Panels → Python console), type App.getUserAppDataDir() and press Enter: that is your user data folder.
  4. 把 zip 里的 Mod 文件夹里的东西复制到这个文件夹下的 Mod（没有就新建；FreeCAD 1.1 里通常是 …\FreeCAD\v1-1\Mod）。Copy the contents of the zip’s Mod folder into Mod under that folder (create it if missing; in FreeCAD 1.1 it is usually …/FreeCAD/v1-1/Mod).
  5. 重启 FreeCAD，在工作台列表里选它；首次会要授权码，同上。Restart FreeCAD and pick the workbench; the first time it asks for the licence code as above.

工作台里的问渠程序是编译过的（不含源代码），要用 FreeCAD 1.1 自带的 Python 3.11。WenQuest code inside is compiled (no source) and needs FreeCAD 1.1’s Python 3.11.
