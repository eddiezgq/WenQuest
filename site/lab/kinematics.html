质点运动学实验台

场景
所选参考系中的轨迹
实验目的：换不同的观察者看同一个运动，观察轨迹和速度怎样变化。

参数

测量

任务

    思考：车厢里的人说小球“竖直下落”，地面上的人说它“做平抛运动”，谁对？

    位矢 r 位移 Δr 路程 Δs 速度 v 加速度 a
    实验目的：从运动方程 r(t) 出发，比较位移与路程；把 Δt 调小，看平均速度怎样变成切线方向的瞬时速度。

    运动方程

    测量（SI 单位）

    任务

      场景
      实验目的：改变初速度、抛射角、抛出高度和重力加速度，测量射程与最大高度，与理论公式比较；再打开空气阻力，看理想模型在哪里失效。

      参数

      在哪里做实验

      最近一次发射

      任务

        理论：R = v₀² sin2θ / g（h₀ = 0，无空气阻力）。

        类型
        速度 v 切向 aₜ 法向 aₙ 合加速度 a
        实验目的：观察切向加速度改变速率、法向加速度改变方向；验证 aₙ = v²/R 与 aₜ = Rα。箭头长度按比例压缩显示，数值看右侧读数。

        参数

        R = 0.10 m，θ = 2 + 4t³（rad）。按“跳到 t = 2 s”读出 aₜ 和 aₙ，与讲义例1-3的答案对照。
        载货 AGV：质心高 0.6 m，轮距 0.5 m，轮胎与地面摩擦因数 μ = 0.6。

        测量（SI 单位）

        任务

          场景
          实验目的：用伽利略速度变换 v(A 对 C) = v(A 对 B) + v(B 对 C) 预测航迹，再出发验证。

          参数

          测量

          任务

            水速大于船速时，船对岸的速度总有向下游的分量，不可能正对岸靠岸。此时航程最短的船头方向满足 sinφ = v船 / v水。
