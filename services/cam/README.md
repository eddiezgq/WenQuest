# 问渠凸轮 · 计算内核 camkit（第 39 轮）

凸轮设计与制造软件的计算内核。纯计算：不联网、不调用 AI；网页版和 FreeCAD 工作台共用它。方案见
`docs/实施细则/第39轮_2026-10-17_凸轮设计与制造软件.md`。

## 第 1 步已有

| 模块 | 内容 |
| --- | --- |
| `laws.py` | 运动规律：等速、等加速等减速、简谐、摆线、修正梯形、修正正弦、3-4-5、4-5-6-7；Cv、Ca、Cj |
| `program.py` | 运动程序（升、停、回）或点表（周期样条）；刚性冲击、柔性冲击检查 |
| `disk.py` | 盘形凸轮与槽凸轮：直动 / 摆动，滚子 / 平底 / 尖顶；理论廓线、实际廓线、槽两侧、曲率、压力角 |
| `dynamics.py` | 惯性力、弹簧、载荷；接触力、驱动力矩、赫兹接触应力、跳离转速 |
| `analyze.py` | 一个项目进来，曲线和校核出去（合格 / 不合格 / 未知 / 不适用）；最小基圆搜索 |

## 用法

```bash
pip install -r requirements-dev.txt
python -m pytest -q                               # 标准题
python -m camkit examples/sewing-takeup-groove.json   # 看一个示例的校核
```

单位：mm、rad（输入里角度用度）、s、N、MPa。缺数据的校核是“未知”，不算合格。每条测试写明对照的专著或推导。
