起草台怎么用

起草台把一句话需求变成一份电路板设计描述。AI 只起草，判定都由代码做；草稿不存服务器，你确认后下载。

一、写需求

写清楚电压、电流、电机、接口。例如：“给 400 W、48 V 的机器人关节伺服电机做一块驱动板，额定相电流 8.5 A，峰值 30 A，带 2500 线增量编码器和 CAN。”需求框下面有三个示例可以点。

本版只做三相电机驱动板：九种功能单元（母线输入、辅助电源、半桥、栅极驱动、电流采样、MCU、增量编码器、SSI 编码器、CAN），拓扑固定。别的板子、别的接口会列在“目录里做不了的”里。

二、看草稿：每个数都有来源

  • 需求原文你写的需求里有这个数，下面是引用的原话。代码会核对：引用的话必须真在需求里，并且含有这个数。
  • 规则推出由需求里的数按规则算出来，下面写着用了哪些数。
  • AI 假设需求没说、AI 先提的，整行标成铜色，下面是要你回答的问题。请逐个看过。
  • 人填你在页面上改过的数。
  • 模板默认没人动过，沿用驱动板模板的值。

必须有的规格（母线电压、额定和峰值相电流）AI 不许假设：需求里没有，就留空、提问，页面上方会提示“缺必须有的规格”，你填上再重算。

“被代码退回的数”是 AI 给了、但没通过校验的数：不在目录里、超出范围、来源不成立。这些数没有进设计。

三、看结论、改数、重算

上方四个数是所有判定的结论：通过、不通过、待核对（用到的器件数据还没人对照规格书核对，不算通过）、未知（缺数据）。展开“计算书”能看到每个功能块怎么算的、仿真对照、出处。

在规格表和功能块参数里改数，点“按改过的数重算”。只列 AI 可以改的参数，范围以外的数会被拒绝并说明原因。

四、板子检查

计算书下面是“板子检查”：用驱动板模板已经布好线的板子，按你这份草稿的规格再查一遍。不重新布线（服务器上布一次线要几十分钟），所以规格改了、板子没跟着改的地方会在这里报出来。例如额定相电流改大，“大电流走线宽度”会变成不通过：电机线、母线要的线宽按 IPC-2221 跟着电流变。

  • 工艺：线宽、线距、孔、孔环、阻焊桥、铜到板边、器件外框、极性方向、器件到板边、ICT 测试点覆盖、大电流线宽。门槛来自示例贴片厂的工艺能力表（虚构）和设计描述里的设计规则。
  • 布局约束：功率回路面积、采样电阻的开尔文接法、去耦电容离芯片电源脚的距离、发热件离怕热件的距离、接插件在板边。限值是示例值，出处写在每一条后面。
  • 热：先算每个功率管的导通、开关损耗和采样电阻的损耗，再把板子当一块平板算温度，得出结温和上限比。这是布局阶段的保守估算，不替代样板实测；功率管导通电阻用的是 25 ℃ 的值，没超上限时只能判“未知”。

不通过、未知的项排在前面；通过的收在“通过的 N 项”里。完整的报告（带温度分布图）由工程师用 python3 -m wqeda.report 生成。

五、确认并下载

勾选“我已看过标成‘AI 假设’的数”，再点“下载设计描述（YAML）”。文件里 draft.provenance 记着每个数的来源。板子层（摆放、铺铜）本版沿用驱动板模板，按新规格重新布局在下一期做。

六、次数与记录

AI 起草要登录问渠账号，每人每天有次数上限。每次调用模型都有记录：谁、需求摘要、用的模型、是否通过代码校验。美国站用 Claude，国内站用已备案的 DeepSeek。

English, in brief

Write a requirement; AI drafts the specification and block parameters with a source for every number (requirement quote, derived rule, AI assumption, entered by you, template default). Code checks the draft, expands the circuit and runs the calculations and simulations; required values the requirement does not give are left empty with a question, never guessed. Edit, recalculate, tick the confirmation and download the design description. Board checks re-check the template's routed board against your specification (process, layout constraints, thermal estimate) without re-routing, so a larger current shows up as a failing trace width. This version covers one board family (three-phase motor drive). Example design, not for production.
