# 《机械制造技术》符号约定（v0.1，2026-10-02，待 Eddie 审阅）

全书统一使用本约定。写作、程序、插图、动画、实验、工艺数据表都以它为准。新增符号先登记在这里，再在正文中使用。

## 一、总原则

1. **国内写法为主，注明国际写法**：本书服务国内“机械制造技术基础”等课程和考研，正文用国内教材和国标（GB/T 12204 切削术语、GB/T 4863 工艺术语）的通行符号；一个符号第一次出现时，用一句话注明 Kalpakjian、Altintas、Shaw 等英文教材的写法。第十二节列出全部对照。英文版改用英文教材写法，并在符号表里注明中文版写法。
2. **一个符号只表示一种东西**。确有冲突时（如 $\kappa$ 既是主偏角又是导热系数，$a$ 既是背吃刀量又是热扩散率），在该节开头说明，或按本约定第二节的“冲突处理”改写。
3. **程序与书一致**：程序中的变量名与书中符号对应，加单位后缀，例如 `vc_m_min`、`f_mm_r`、`ap_mm`、`Fc_N`、`kc11_MPa`、`T_min`、`Ra_um`。工艺数据表的列名也用这种写法（与零件库 `library/std_tables/` 一致）。
4. **单位写在符号后面的方括号里只用于表头**；正文写成“切削速度 $v_c = 120\ \mathrm{m/min}$”。

## 二、字体、排版与冲突处理

| 对象 | 写法 | 例 |
|---|---|---|
| 物理量 | 斜体 | $v_c$, $F_c$, $T$, $\sigma$ |
| 下标是物理量或变量 | 斜体 | $F_x$, $\sigma_{ij}$ |
| 下标是说明性文字的缩写 | 正体 | $v_\mathrm{c}$（cutting）可简写为 $v_c$；$T_\mathrm{m}$（melting）、$T_\mathrm{g}$（glass）、$h_\mathrm{eq}$ |
| 向量、矩阵 | 粗斜体 / 斜体大写（同《线性代数》） | $\boldsymbol F$, $K$ |
| 单位 | 正体，数与单位之间空一格 | $120\ \mathrm{m/min}$, $0.2\ \mathrm{mm/r}$ |
| 函数名 | 正体 | $\exp$, $\ln$, $\operatorname{erf}$ |

切削部分的小写下标（$v_c$、$F_c$、$k_c$）沿用国标和 ISO 3002 的习惯写成斜体，不再区分。

**冲突处理**：
- 主偏角用 $\kappa_r$，副偏角 $\kappa_r'$；导热系数一律用 $\lambda$（本书不用 $k$ 表示导热系数，$k$ 留给刚度和比切削力）。刃倾角用 $\lambda_s$，与导热系数 $\lambda$ 靠下标区分；同一节同时出现时，导热系数写 $\lambda_\mathrm{th}$。
- 背吃刀量 $a_p$、侧吃刀量 $a_e$；热扩散率用 $\alpha_\mathrm{th}$（不用 $a$）。
- 后角 $\alpha_o$ 与线膨胀系数：线膨胀系数写 $\alpha_\mathrm{L}$。
- 温度一律 $T$（°C 或 K 注明）；刀具寿命也是 $T$（min）——这是国内外都通行的写法，不改。两者同时出现的节（第 35、37 章）把温度写成 $\theta$，并在节首说明。
- 时间 $t$；切削厚度用 $h_D$（国标）而不是 $t$。

## 十五、与另五本书的关系

- 应力、应变、安全系数、公差配合的符号与《机械设计》一致（$\sigma$、$\tau$、$[\sigma]$、$ES/EI$、$IT$ 等级）。

- 机器人坐标系、位姿记号用《机器人学》的写法（第 23、49、55、59 章）。
