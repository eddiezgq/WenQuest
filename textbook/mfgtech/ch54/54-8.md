### 54.8.1 诊断的思路

54.2–54.6 节是从“原因”推“结果”：尾座偏了，工件就成锥形。车间里遇到的是反过来的问题：零件超差了、Cpk 降了，原因不知道。原因往往不止一种可能，而不同的原因在零件上留下不同的“指纹”。诊断就是读指纹：

1. 看哪个特性变了，哪个没变：两个轴承位一起变，还是只变一个；直径变了，圆跳动变没变；
2. 看怎么变：沿轴向是锥度、鼓形还是鞍形；截面是椭圆还是棱圆；逐件是整体偏移、线性漂移、锯齿、开机后的指数变化、某一件起的跳变，还是分散变大；
3. 看从什么时候开始：从某一件、某一班、某一批料、某次修整或换刀以后；
4. 列出能产生这种形态的原因（表 54.8.1），用其他数据逐个排除；
5. 选纠正措施，实施后用数据验证：措施对症，数据会恢复；不对症，数据不变（54.9 节、工程任务单 TS-54-1）。

数字工厂加工精度库的 diagnose（hub/accuracy.py）就是按这个思路写的：它把三类数据——沿轴向各截面的直径、一个截面的圆度、逐件的测量序列——分别判别形态，再给出可能原因的清单。程序只能做前四步里“算”的部分，判断和验证要人来做。

| 形态 | 常见来源 | 怎样进一步区分 |
|---|---|---|
| 锥形 | 两顶尖连线与导轨不平行（尾座偏移）；导轨在水平面内与主轴轴线不平行；长走刀中刀具磨损；头架、尾座刚度相差大 | 尾座偏移：头架端不变、向尾座线性增大，且从某一时刻起；刀具磨损：每件都有、换刀后消失；刚度：随切深、切削力变 |
| 鼓形（中间大） | 工件刚度低（细长轴）中间让刀多；工件热伸长被顶尖顶住而弯曲 | 让刀：切深减小时变小，用跟刀架消失；热伸长：开始车时没有、越车越大 |
| 鞍形（中间小） | 头架、尾座刚度低于工件；导轨在水平面内向工件一侧中凸 | 刚度：切深、进给改变时跟着变；导轨：与切削用量无关，各件一样 |
| 弯曲 | 残余应力释放（铣键槽、淬火后）；工件热伸长；校直后回弹 | 放置后加剧的是残余应力；与工序顺序有关 |
| 椭圆（二阶） | 车削时主轴颈不圆；中心孔不圆或两中心孔不同轴；两点、对置夹紧变形；镗削时轴承孔不圆 | 换一台机床是否消失；修研中心孔后是否消失 |
| 三棱形（三阶） | 三爪卡盘夹紧薄壁件后回弹；无心磨削的棱圆；三点支承的夹具夹紧变形 | 棱数等于卡爪、支承点数 |
| 多棱形（高阶） | 振动（颤振）留下的波纹；砂轮不平衡或修整不良；主轴轴承滚动体误差 | 棱数与转速、频率的关系 |
| 尺寸逐件线性漂移 | 刀具（砂轮）尺寸磨损；冷却液温度逐渐升高 | 换刀、修整后回落的是磨损 |
| 锯齿形 | 刀具磨损加定期换刀、修整或补偿 | 斜率比正常大：砂轮太软、修整不良；锯齿变长、峰值出界：修整间隔太长 |
| 开机后逐件变化、渐趋稳定 | 机床未达到热平衡；刀具热伸长 | 每天开机或长时间停机后重复出现 |
| 某一件起整体跳变 | 换刀、修整、调刀补后的调整误差；换了一批毛坯；换了操作工或量具；夹具、定位元件松动或更换 | 对照跳变时刻的事件记录 |
| 分散变大 | 中心孔质量差、顶尖磨损；机床零件松动、间隙变大；振动；测量系统变差 | 测量系统分析排除量具；圆跳动一起变大的是中心孔 |

### 54.8.3 截面的形状：圆度的谐波分析

圆度仪绕工件转一圈，测得一个截面上等角度间隔的半径偏差 r(θ)，把它分解为各阶谐波 $r(\theta) = \sum_k A_k\cos(k\theta - \varphi_k)$：一阶是测量时的偏心（安装误差，不算圆度误差），二阶是椭圆，三阶是三棱，更高阶是多棱和波纹。主导的阶次直接指向来源（表 54.8.1）。

**算例 54.8.1** 一个截面的测得值（图 54.8.2(a)）：峰谷值 {{ex54_8.rd_um:.1f}} µm，其中包括偏心。谐波分析（hub/accuracy.py 的 harmonics）给出一阶 {{ex54_8.h1_um:.1f}} µm（偏心）、二阶 {{ex54_8.h2_um:.1f}} µm、三阶 {{ex54_8.h3_um:.1f}} µm（峰谷值 2Aₖ），二阶为主——椭圆，先查主轴颈和中心孔（图 54.8.2(b)）。

### 54.8.4 逐件序列的形态

三坐标、主动测量仪逐件记下的数据，按加工顺序排开，形态最能说明问题。hub/accuracy.py 的 sequence 依次判别：有修整点时先求各段共同的斜率（锯齿），减去它；再看开机后的指数段（预热）、两段均值差最显著的一点（跳变）、与正常时比较的整体偏移和分散。

### 54.8.5 案例：SH-301 右轴承位偏大

回到本章提要里的那一批（图 54.0.1）。按 54.8.1 节的步骤：

1. 哪个特性变了：从第 {{ex54_8.jump_at}} 件起，左轴承位、齿轮位、右轴承位都变大了，分别大 {{ex54_8.dL:.1f}}、{{ex54_8.dG:.1f}}、{{ex54_8.dR:.1f}} µm；圆跳动没有变。左轴承位的序列交给 diagnose，判出“{{ex54_8.labels_left}}”——锯齿是正常的砂轮磨损，跳变就是问题。
2. 怎么变：三处都在同一件起跳变，但变得不一样多。把右减左逐件画出来（图 54.8.4(a)），两处一样变的砂轮磨损、热变形都被消掉，剩下一个干净的台阶。把三处的变化画在轴向位置上（图 54.8.4(b)），三个点落在一条过头架顶尖（z = 0）的直线上：变化与到头架的距离成正比，diagnose 判为锥度，两轴承位差 {{ex54_8.taper_um:.1f}} µm。
3. 可能的原因（表 54.8.1 的锥形一行）：尾座偏移、导轨与主轴不平行、刀具磨损、头尾架刚度不等。磨削的“刀具磨损”就是砂轮磨损，它让各处一样变，排除；导轨与主轴不平行、刚度不等是机床固有的，不会从某一件起突然出现，排除。变化在头架端为零、向尾座线性增大，正是工件绕头架顶尖偏斜的样子。
4. 结论：两顶尖连线在第 {{ex54_8.jump_at}} 件前后被改变了——尾座被碰、松动或者修研中心孔后没有校。由直线的斜率和式 (54.3.2) 估算尾座偏移约 {{ex54_8.e_est_um:.1f}} µm（离开砂轮）。措施：用标准检验棒和千分表校正尾座。

**机器人的例子**：机器人厂的关节测试台测出某个工位装的关节背隙偏大——是装配工位的扭矩不对，还是一批谐波减速器来料不好？看“从哪一台开始”和“只有这个工位还是所有工位”：只有一个工位、各批料都有，是工位；所有工位、从某一批料起，是来料。数字工厂的机器人厂就有这两个问题情景。

**生活中的例子**：医生看病也是读“指纹”：发烧加咳嗽和发烧加腹泻，指向的病因不一样；先问什么时候开始、吃过什么，再化验排除，最后对症下药，吃完药还要复查。
