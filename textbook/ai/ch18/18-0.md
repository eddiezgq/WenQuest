前面十七章讲的都是人工智能自己的事：怎么训、怎么评、怎么用、怎么让它动手。从本章起换一个问法：**把它放进一门真科学里，它到底帮上了什么忙，又没帮上什么忙。**

蛋白质结构是这件事最有说服力的例子，原因不在于它最难，而在于它有一个公开的考场。CASP 每两年一届，靶标的实验结构在建模期内还没公开，成绩由独立评估人判。这件事在人工智能的其他应用里几乎找不到第二例——大多数时候，模型好不好是出模型的人自己说的。

本章贯穿的实际问题是**生物制造里的一件具体麻烦：一个酶不够耐热**。它在实验室好用，放进 50 ℃ 的反应釜里半小时就失活，车间用不了。要改造它，得先知道它长什么样、哪几个位点碰得、改完还折不折得起来。这条线把本章串上了：结构怎么预测、预测得准不准、可信度怎么读（18.1、18.2、18.7）；它和底物怎么结合（18.3）；改哪几个位点、怎么设计（18.4）；顺带把"找一个小分子抑制剂"那条路也讲清楚（18.5）；最后用测序数据看改造后的菌株表达得怎么样（18.6）。

本章的内容安排如下：

- 18.1 节讲问题与评测：序列比实验结构多两个量级、CASP 的盲测口径、四个指标各测什么，以及它们为什么会给出相反的结论；
- 18.2 节讲 AlphaFold2 的几个关键想法：多序列比对为什么是关键输入、接触信息到底值多少、自评分数是怎么训出来的；
- 18.3 节讲复合物：难处在界面，不在单链；
- 18.4 节讲蛋白质设计：大多数形状根本没有序列能折成；
- 18.5 节讲虚拟筛选与分子性质预测：富集因子与命中率是两回事，随机划分与骨架划分是两个问题；
- 18.6 节讲基因组与单细胞：批次效应不校正看不见真结构，校正过度看见的是假结构；
- 18.7 节是案例：拿到一个预测结构，哪几段能信、能拿去做什么。

本章的数据与算例全部由程序生成（`code/_ch18.py`）。理由与前两章一样，但换了个面貌：**这一章要讲清的几件事都是几何与概率问题，不是生物问题。** "三个指标为什么会给出相反的结论""接触信息值多少""自评分数高到底意味着什么""命中率看着高是因为阳性本来就少"——这些在真蛋白上做不了对照实验（没有"同一个蛋白的另一种折叠"可比），而退到二维格点与可控的模拟上，每一条都能算到底，还能与解析值核对。真模型上的对照放在两个云端 GPU 实验里。

书中引用的公开数字一律只取论文正文、官方技术报告、官方公告或官方文档给出的原始值；来源逐条记在 `docs/教材/人工智能/参考/第18章_蛋白质结构与药物发现原始数字资料_2026-11.md`。这一章的数字被引错的频率比前两章还高，所以有四条自律要先说清楚：

1. **本书不写"人工智能解决了蛋白质折叠问题"。** 凡写 CASP 成绩，哪一届、哪一类靶标、中位数还是平均数、什么指标，四件事一起写。要引官方可核的差距，就引官方的 z-score 之和，而不是那个流传最广的 92.4——它是**中位 domain GDT_TS**，分母是 92 个 domain，出自做模型那一家自己的论文，不是 CASP 官方公布的数。
2. **自评分数（pLDDT）不是"对的概率"。** 它是模型对自己的估计，训练时回归的是真实的 lDDT-Cα；论文给的拟合相关系数只有 0.76。本书不给官方文档编一句"pLDDT 不是实验置信度"的引文——那句原话核不到。能引的是官方论文的那句"it is incumbent upon the user to interpret the model prudently"。
3. **lDDT 与 GDT_TS 之间不存在换算。** 一个不叠合、测局部，一个要叠合、测整体，测的根本不是同一件事。pLDDT 与 lDDT 之间也只有一条线性拟合，$r = 0.76$ 意味着单个残基上偏差可以很大，不能当等式用。
4. **"人工智能把药物研发周期缩短了 X 倍"这类数，本书一个都不印。** 这类说法没有可核对的口径。药物发现那一节只写公开论文里有原始值的东西：筛了多少、测了多少、成了多少，连分母一起写。

实验有两个不需要显卡的浏览器实验（18.2 接触信息值多少，18.7 读懂预测结构的可信度）和两个云端 GPU 实验（18.2 用 ESMFold 预测几条小蛋白并读它的自评分数，18.5 同一个图神经网络在随机划分与骨架划分上的两个成绩）。

学完本章，读者应能：

1. 说清 CASP 的盲测口径，并指出一个公开的结构预测成绩要问哪四件事；
2. 说出 GDT_TS、lDDT、TM-score、RMSD 各测什么，并举出一个它们给出相反结论的例子；
3. 解释共进化信息为什么关键：一条正确的接触值多少，一条错的接触有多贵；
4. 正确地读一张自评分数图：哪几段能信，"分数 90 以上"到底意味着什么；
5. 说明复合物预测的难处为什么在界面，并说出 DockQ 的四个档位；
6. 解释"可设计性"：为什么大多数形状没有序列能折成，以及这对蛋白质设计意味着什么；
7. 区分富集因子与命中率，说出为什么三项研究的命中率不能并排比；
8. 为一个分子性质预测任务选对划分口径，并说明随机划分会把什么样的模型捧上去。
