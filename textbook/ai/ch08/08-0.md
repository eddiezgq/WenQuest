title: 本章提要
---

前几章的程序几乎都用单精度。可 A10 的半精度张量核心峰值（125 TFLOP/s）是单精度（31.2 TFLOP/s）的 4 倍，INT8 张量核心（250 TOPS）又翻一倍；大模型逐词生成受读权重的时间限制（3.8.4 节），权重的位数减半，时间就几乎减半。少用几位，能换来速度、显存与带宽——代价是精度。本章讨论怎样在不明显损失精度的前提下少用位数：训练时的混合精度，部署时的量化；并学习 Triton，用 Python 写出融合的核函数，补上第 7 章留下的“小运算”问题。

贯穿本章的实际问题是：检测工位的小型 Transformer 要训练得更快、部署得更省。

本章的内容安排如下：

- 8.1 节讲浮点格式：FP32、TF32、BF16、FP16、FP8 与 FP4 的位分配、范围与精度，舍入，按块缩放；
- 8.2 节讲混合精度训练：哪些运算用低精度、为什么要保留单精度的主权重、损失缩放；
- 8.3 节讲量化原理：对称与非对称、逐张量与逐通道、校准，整数矩阵乘法；
- 8.4 节讲训练后量化与量化感知训练；
- 8.5 节讲大模型的量化：仅权重量化、激活中的离群特征、FP8 推理；
- 8.6 节讲 Triton 的编程模型；
- 8.7 节用 Triton 写融合的注意力 softmax 与“残差加法 + 层归一化”。

本章的 PyTorch 与 Triton 程序在云端 A10 上实测，还没有实测的数字显示为“〔待实测〕”。Python 算例不依赖 PyTorch，在实测之前写下预期。实验有三个：浏览器实验 8.1（浮点格式的精度与范围），云端 GPU 实验 8.5（把小型 Transformer 量化到 INT8 和 INT4）与 8.7（用 Triton 写融合的 softmax）。

学完本章，读者应能：

1. 说出各种浮点格式的位分配，算出它们的范围与相对精度，判断一个数存进去会怎样；
2. 解释混合精度训练中主权重、单精度累加与损失缩放的作用，在 PyTorch 中用 autocast 训练；
3. 写出对称与非对称量化的公式，比较逐张量、逐通道与分组量化，说明整数矩阵乘法怎样得到浮点结果；
4. 区分训练后量化与量化感知训练，说明直通估计；
5. 说明大模型量化的难点（激活中的离群特征）与常见的对策，估算量化后的显存与生成速度；
6. 用 Triton 写简单的核函数，说明它与 CUDA 编程模型的区别；
7. 用 Triton 写融合的核函数，并按显存流量评估它的收益。
