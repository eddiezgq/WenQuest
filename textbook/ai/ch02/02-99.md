title: 本章小结
---

本章的主线是：深度学习的一切，最后都落到少数几种运算上，其中运算量最大的是矩阵乘法，而最容易被忽视的是逐元素运算对显存带宽的消耗。

我们先建立了监督学习的框架：用损失衡量预测的好坏，把学习写成经验风险最小化，用梯度下降求解；训练集、验证集、测试集各有分工。一维二次函数的例子说明，学习率必须小于 $2/\lambda_{\max}$，收敛快慢取决于条件数。线性回归有正规方程，几何上是正交投影；特征的尺度相差悬殊会使条件数极大，标准化能把梯度下降的步数从十几万降到一步。逻辑回归用逻辑函数输出概率，用交叉熵作损失，梯度简洁地等于“预测概率减标签”乘以输入；softmax 把它推广到多类。

张量是这些计算在程序中的表示。行主序与步长决定了数据在内存中的排列，转置、切片只改步长不搬数据，但会使读取变得跳跃；广播让不同形状的张量逐元素运算而不复制数据；一批数据的全连接层是一次矩阵乘法，注意力是批量矩阵乘法。

多层感知机在线性变换之间插入非线性激活函数，否则多层等于一层。万能逼近定理说明单隐藏层网络能以任意精度逼近连续函数；一维 ReLU 网络的构造性证明给出误差界 $Mh^2/8$，同时揭示了维数灾难，深层结构的组合能力是深度学习有效的重要原因。

反向传播按计算图的逆序，把伴随值乘以局部导数逐节点传回，一次求出损失对全部参数的梯度，代价约为前向的两倍；全连接层的反向是 $\bar W = X^{\mathsf T}\bar Y$、$\bar X = \bar YW^{\mathsf T}$ 两次同样规模的矩阵乘法，这就是 $C\approx 6ND$ 中 6 的来由。前向的激活值要保存到反向时用完，这是大模型显存的一大开销。

优化方面，随机梯度下降用小批量估计梯度，动量法把条件数“开平方”，Adam 为每个参数自动缩放步长，代价是参数、梯度和优化器状态合计每个参数约 16 字节；初始化要使各层输出的方差保持不变；学习率先预热再余弦下降。正则化方面，过拟合表现为训练误差小而测试误差大，权重衰减、丢弃法、早停、数据增广各有作用；层归一化稳定了深层网络的训练，但它的计算强度很低。

卷积网络用局部连接和权重共享处理图像，经 im2col 变成矩阵乘法；循环网络沿时间串行计算，难以并行且有梯度消失的问题。Transformer 用缩放点积注意力让每个位置直接关注所有位置，整个序列并行计算；多头注意力、位置嵌入、前置层归一化、残差连接和前馈网络组成它的基本块。本书的小型 Transformer 有约 1150 万个参数。

最后，逐项统计小型 Transformer 的一次前向计算：矩阵乘法占运算量的 99% 以上，但在 H100 上，逐元素运算因为受带宽限制而占去了接近一半的耗时下限；模型较小时，就连线性层的计算强度也只在平衡点附近。这两点分别是第 5 章和第 8、9 章的出发点。

| 概念 | 一句话 |
|---|---|
| 经验风险最小化 | 用训练数据上的平均损失代替期望损失来选参数 |
| 随机梯度下降 | 用小批量的平均梯度代替全体的梯度 |
| 张量的步长 | 某一维下标加 1 时地址前进的元素个数 |
| 广播 | 长度为 1 的维度被重复使用，不复制数据 |
| 激活函数 | 层与层之间的非线性，没有它多层等于一层 |
| 反向传播 | 按计算图的逆序，伴随值乘局部导数逐节点传回 |
| 激活值 | 前向的中间结果，反向时要用，需要保存 |
| 过拟合 | 训练误差小、测试误差大 |
| 权重共享 | 卷积在空间、循环网络在时间上重复使用同一组权重 |
| 自注意力 | 查询、键、值都来自同一个序列 |
| 因果掩码 | 每个位置只能关注自己和之前的位置 |

### 部分习题答案与提示

2.1.1 $\eta = 1/a$ 时 $1 - \eta a = 0$，一步收敛。只知 $a\le 10$ 时取 $\eta < 0.2$ 即可保证收敛。

2.1.2 学习率上限为 $2/100 = 0.02$。取 0.01 时，$w_2$ 方向的因子为 0（一步到位），$w_1$ 方向为 0.99，每步只缩小 1%。

2.2.3 改用 kN·m 后，$H$ 的特征值约为 $3.76\times10^{-4}$ 和 2.00，条件数约 5300，仍然很大：尺度失衡的方向反了过来（现在是常数列远大于特征列），收敛同样很慢。标准化后条件数与单位无关。

2.3.1 步长 $(150\,528,\ 50\,176,\ 224,\ 1)$，约 36.8 MiB；通道在后时步长为 $(150\,528,\ 672,\ 3,\ 1)$。

2.3.2 (1) $(5, 3, 4)$；(2) 不能（右端对齐后 3 与 8 不兼容）；(3) $(2, 5, 6)$。

2.3.4 `pred - y` 广播成 $n\times n$ 矩阵，结果是 $\tfrac1{n^2}\sum_{i,j}(\hat y_i - y_j)^2$，即预测与所有标签两两之差的平方均值，远大于均方误差。

2.4.3 参数量 $319\,498$；乘加次数 $64\times(100\times512 + 512\times512 + 512\times10) = 20\,381\,696$。

2.4.5 $t$ 在 $[0, \tfrac12]$ 上升到 1、在 $[\tfrac12, 1]$ 下降到 0；复合 $k$ 次得到 $2^{k-1}$ 个尖峰、$2^k$ 段的锯齿函数。单隐藏层 ReLU 网络的函数在每个单元处至多折一次，至少需要约 $2^k - 1$ 个单元。

2.5.1 $f = -2$；$\partial f/\partial x = \max(x, 0) + (x + y)\cdot 1 = 2 - 1 = 1$，$\partial f/\partial y = \max(x, 0) = 2$。

2.6.1 梯度下降约 69 000 步，最优参数的动量法约 691 步。

2.6.5 $7\times10^9\times16 = 1.12\times10^{11}$ 字节，即 112 GB，放不下单块 80 GB 的 H100。

2.7.4 每个元素约 8 次运算，$d = 384$ 时约 3072 FLOP；读写各 768 字节（另有少量参数），计算强度约 2 FLOP/B，远低于 295，受带宽限制。

2.8.1 依次为 $28\times28\times16$、$14\times14\times16$、$10\times10\times32$、$5\times5\times32$；两个卷积层的参数量为 1216 和 12 832。

2.8.3 矩阵乘法 $3136\times576$ 乘 $576\times128$，运算量约 $4.62\times10^8$ FLOP；展开矩阵约 3.45 MiB。

2.8.4 每步 $512\times512 + 512\times256 = 393\,216$ 次乘加；批大小为 1 时每个权重每步只用一次，单精度下计算强度约 0.5 FLOP/B。

2.9.1 不缩放时分数为 $(1, 1, 2, -1)$，权重约 $(0.206,\ 0.206,\ 0.560,\ 0.028)$，比缩放时更集中。
