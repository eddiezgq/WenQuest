### 19.1.1 预报是怎么做出来的

数值天气预报的想法一句话说得清：大气服从一组已知的方程（动量、质量、能量、水汽），把今天的状态代进去往前积分，就得到明天。这个想法 1922 年就写在纸上了，1950 年第一次在计算机上实现。它不是统计，是解方程。

于是整件事只剩三个环节：

1. 今天的状态从哪里来——几千万条观测（卫星、探空、地面站、飞机、船舶）拼不成一个完整的场，得靠**数据同化**：把观测与上一次预报的短期结果按各自的误差权重拼起来。这一步是整条业务链里最贵的，也是本章后面反复要提的那一句“人工智能省掉的不是这一步”的由来。
2. 把它往前积分——把大气切成格子，一步一步推。
3. 结果拿去怎么用——后处理、产品、分发。

本节讲第二环节的两道硬墙。它们一道来自数值方法，一道来自物理本身，而且第二道墙谁也拆不掉。

### 19.1.2 第一道墙：一步走不过一格

把大气切成格距 $\Delta x$ 的格子，时间步取 $\Delta t$，风速 $u$。一个时间步里信息走了 $u\Delta t$ 这么远。显式格式算新值时只看自己和邻居，所以这段距离不能超过一个格距，否则格子根本不知道那些信息来过。这就是库朗—弗里德里希斯—列维条件，写成

$$C = \frac{u\,\Delta t}{\Delta x} \le C_{\max}, \qquad \text{显式格式 } C_{\max} \approx 1 \tag{19.1.1}$$

式 (19.1.1) 里的 $C$ 叫**库朗数**。它不是经验规则，可以直接算给你看。

**算例 19.1.1** 一维平流方程，初值是一个高斯包，用显式迎风格式走 {{ex19_1.n_step}} 步，看峰值变成多少（出发时是 {{ex19_1.peak0:.1f}}）：

| 库朗数 | 走完 200 步之后的峰值 |
|---|---|
| 0.5 | {{ex19_1.up_c0p5:.3f}} |
| 0.9 | {{ex19_1.up_c0p9:.3f}} |
| 1.0 | {{ex19_1.up_c1p0:.1f}} |
| 1.1 | {{ex19_1.up_c1p1:.2f}} |
| 1.5 | {{ex19_1.up_c1p5:.2e}} |

库朗数 1.1 就已经在涨，1.5 时峰值是 {{ex19_1.up_c1p5:.2e}}——**不是“精度变差”，是解本身指数放大**。而且要注意 0.5 与 0.9 那两行：它们没炸，可峰值掉到了 {{ex19_1.up_c0p5:.3f}} 与 {{ex19_1.up_c0p9:.3f}}。**稳定与准确，是两件事**。迎风格式自带数值耗散，把场一步步抹平。这个毛病本章后面还会以另一副面孔出现。

### 19.1.3 可这条约束是谁的约束

读到这里很容易推出一条漂亮的结论：既然 $\Delta t \propto \Delta x$，那么把水平分辨率翻一倍，格点数涨 $2^2$、垂直层数涨 2、时间步数再涨 2，总共 $2^4 = {{ex19_1.cost_full}}$ 倍。这条结论在教科书里到处都是。

**本书把它印出来，同时把它的前提和反例一起印出来。**

量纲分析给出的是：

| 哪些前提成立 | 算力涨几倍 |
|---|---|
| 层数跟着翻 + 受 CFL 约束 | {{ex19_1.cost_full}} |
| 层数不变 + 受 CFL 约束 | {{ex19_1.cost_no_cfl}} |
| 层数跟着翻 + 不受 CFL 约束 | {{ex19_1.cost_no_levels}} |
| 层数不变 + 不受 CFL 约束 | {{ex19_1.cost_neither}} |

这张表是**本书做的量纲分析，不是任何业务中心的成本标度律**。两条前提在真实业务里都不成立：

**第一，业务模式用的不是显式格式。** 欧洲中期天气预报中心的官方技术文档明说它的半拉格朗日方案“{{ex19_1.ecmwf_unconditional}}”，而且承认业务运行中“{{ex19_1.ecmwf_courant_gt1}}”。半拉格朗日的做法是沿轨迹回溯到上游点再插值——回溯多远都行，插值总能给出一个值。

**算例 19.1.2** 同一个初值、同样 200 步，换成半拉格朗日格式：

| 库朗数 | 走完 200 步之后的峰值 |
|---|---|
| 0.5 | {{ex19_1.sl_c0p5:.4f}} |
| 1.1 | {{ex19_1.sl_c1p1:.4f}} |
| 2.5 | {{ex19_1.sl_c2p5:.4f}} |
| 5.0 | {{ex19_1.sl_c5p0:.4f}} |

库朗数 5 照样有界。**所以“CFL 卡住了业务模式”这句话是错的**；CFL 卡住的是显式格式。

**第二，“层数跟着翻”也不成立。** {{ex19_1.counterexample}}。

那为什么业务模式还是慢？因为开销来自别处：物理过程参数化、同化系统、集合成员数，以及“每天要按时发出去”这条硬约束。**两家主要业务中心都不公布一次预报跑多久、花多少核时**，本书也核不到任何口径完整的第三方数字，所以本章不印业务模式的绝对耗时。

能印的只有公开文档给的两个口径：业务模式垂直 {{ex19_1.ifs_levels}} 层，时间步 {{ex19_1.era5_timestep_min}} 分钟，再分析资料的原生水平分辨率约 {{ex19_1.era5_res_km}} km。

### 19.1.4 第二道墙：误差指数增长

第二道墙与格式、与算力都无关。

大气是混沌的：两个几乎一模一样的初值，差别会按指数增长，而且是指数。洛伦兹 1963 年那三个方程就是从一个简化的对流模型里来的，它把这件事剥到最干净。

**算例 19.1.3** 洛伦兹系统，两条轨迹初值只差 $\varepsilon$，看误差涨到 2 要多久（取 60 组平均）：

| 初值误差 | 还能信多久 |
|---|---|
| $10^{-2}$ | {{ex19_1.lead_e2:.2f}} |
| $10^{-3}$ | {{ex19_1.lead_e3:.2f}} |
| $10^{-4}$ | {{ex19_1.lead_e4:.2f}} |
| $10^{-5}$ | {{ex19_1.lead_e5:.2f}} |

误差翻倍时间是 {{ex19_1.t_double:.3f}}。**初值精度每提高一个数量级，可信时长只多出 {{ex19_1.lead_gain_per_decade:.2f}}**（理论值 $\log_2 10$ 个翻倍时间，即 {{ex19_1.theory_gain:.2f}}，两者对得上）。

这条结论的形状要记住：**提高初值精度的回报是对数的，不是线性的**。观测加密一倍，初值误差大致小一半，买回来的只是**一个翻倍时间，不是一倍的时长**。所以有人说“再加一倍观测就能把预报做到两周”，拿这个数就能反驳他。

两道墙的分工也要记清：**第一道墙决定一次预报要花多少钱，第二道墙决定再多的钱也买不到什么**。人工智能模型动的是第一道墙，第二道墙它一寸也没动——这是读下一节之前必须先摆正的前提。

### 19.1.5 数据同化：最贵的那一步

把这一节收在数据同化上，因为后面每一节都要用到它。

初始场不是“观测拼出来的”。观测在时间和空间上都是零散的：卫星辐射率不是温度、探空一天两次、海上几乎没有站点。同化要做的是把这些零散的、各自带误差的信息，与上一次预报的短期结果按误差权重拼成一个完整、协调的场。业务中心用的是四维变分或集合卡尔曼一类的方法，一次同化要处理几千万条质控过的观测。

记住两件事就够：

- **这一步的成本与积分那一步同量级，甚至更贵**，而且它不随“用什么模式往前推”而改变；
- 所以**任何“预报只要两分钟”的说法，说的都是积分那一步**，不含产生初始场的同化。本章每次引用推理耗时都会把这句话带上。
