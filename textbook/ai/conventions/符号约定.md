# 《人工智能》符号约定（v0.1，2026-10-02，待 Eddie 审阅）

全书统一使用本约定。写作、程序、插图、动画、实验都以它为准。新增符号先登记在这里，再在正文中使用。

## 一、总原则

1. **深度学习文献通行的写法为主**：正文记号与 Bishop《Deep Learning: Foundations and Concepts》、Prince《Understanding Deep Learning》、Goodfellow 等《Deep Learning》大体一致；CUDA 部分的名称与 NVIDIA《CUDA C++ Programming Guide》一致（`threadIdx`、`blockDim` 等保留原文，用等宽字体）。
2. **一个符号只表示一种东西**。确有冲突时（如 $N$ 在上篇第 1、9 章表示参数量，在第 5 章表示矩阵阶数），在该节开头说明。
3. **程序与书一致**：程序中的变量名尽量与书中符号对应，例如 `N_params`、`D_tokens`、`M, N, K`（矩阵乘法 $C_{M\times N} = A_{M\times K}B_{K\times N}$）。
4. **前沿数字注明时间与出处**：凡模型规模、芯片规格、榜单成绩，正文注明出处，并在“截至某年某月”后给出；书中的数字由程序从登记在 `code/` 的数据表读出，数据表里写明每个数的来源。

## 二、字体与排版

| 对象 | 写法（LaTeX） | 例 |
|---|---|---|
| 数（标量） | 斜体小写 | $a$, $\eta$, $b$ |
| 向量 | 粗斜体小写 `\boldsymbol{x}` | $\boldsymbol x$, $\boldsymbol w$, $\boldsymbol h^{(l)}$ |
| 矩阵 | 斜体大写 | $W$, $A$, $Q$, $K$, $V$ |
| 张量（三阶及以上） | 无衬线粗体 `\mathsf{\mathbf{X}}` | $\mathsf{\mathbf X}$ |
| 集合、数据集 | 花体大写 | $\mathcal D = \{(\boldsymbol x_i, y_i)\}_{i=1}^n$ |
| 数集 | 黑板粗体 | $\mathbb R$, $\mathbb R^{d}$, $\mathbb R^{m\times n}$ |
| 函数与算子名 | 正体 | $\operatorname{sign}$, $\operatorname{softmax}$, $\operatorname{ReLU}$, $\max$ |
| 程序中的名称 | 等宽字体 `` `name` `` | `threadIdx.x`, `__global__`, `torch.matmul` |

向量默认是列向量；行向量写成转置 $\boldsymbol x^{\mathsf T}$。一批样本按行排成矩阵 $X\in\mathbb R^{B\times d}$（每行一个样本，与 PyTorch、NumPy 的习惯一致），这时全连接层写成 $Y = XW^{\mathsf T} + \boldsymbol 1\boldsymbol b^{\mathsf T}$ 或 $Y = XW + \boldsymbol 1\boldsymbol b^{\mathsf T}$，在用到的节里写明 $W$ 的形状。

## 四、运算量、显存与性能

| 符号或单位 | 含义 | 首次出现 |
|---|---|---|
| FLOP | 一次浮点运算（一次加法或一次乘法） | 1.4 |
| FLOPs | 浮点运算次数（复数，是“量”） | 1.4 |
| FLOP/s | 每秒浮点运算次数（是“速率”）；正文不写成 FLOPS，以免与 FLOPs 混淆 | 1.4 |
| MAC | 一次乘加（$a \leftarrow a + b\times c$），**1 MAC = 2 FLOP** | 1.5 |
| $N$ | 模型的参数量（不含嵌入层时另行说明） | 1.4 |
| $D$ | 训练用的词元数 | 1.4 |
| $C$ | 训练算力（总 FLOPs），$C\approx 6ND$ | 1.4 |
| $P$ | 硬件的峰值算力，FLOP/s | 1.5 |
| $\beta$ | 显存带宽，B/s | 1.5 |
| $I$ | 计算强度，FLOP/B | 1.5 |
| $u$ | 算力利用率（实际算力 / 峰值算力，0 到 1） | 1.4 |

**数量词头**：k = $10^3$，M = $10^6$，G = $10^9$，T = $10^{12}$，P = $10^{15}$，E = $10^{18}$（十进制，按 SI）。显存和内存的容量按厂商习惯写 GB（$10^9$ 字节）；需要二进制时写 GiB（$2^{30}$ 字节），并在该处说明。带宽一律 B/s 的十进制倍数（如 3.35 TB/s）。

**计数约定**：
1. 一次乘加记 2 FLOP。若引用的文献把一次乘加记作 1 次“FLOP”（例如 ResNet 论文表 1），引用时注明并换算。
2. 矩阵乘法 $C_{M\times N} = A_{M\times K}B_{K\times N}$ 的运算量记为 $2MNK$ FLOP（忽略 $MN$ 次的加偏置等低阶项，除非特别说明）。
3. 峰值算力注明数值格式（FP32、TF32、FP16、BF16、FP8、INT8）以及是否计入结构化稀疏；本书默认引用**稠密**峰值。

## 五、GPU 与 CUDA

| 名称 | 含义 | 首次出现 |
|---|---|---|
| `__global__` | 核函数限定符：在设备上执行、由主机启动 | 1.6 |
| `threadIdx`, `blockIdx`, `blockDim`, `gridDim` | 线程在块内的编号、块在网格内的编号、块的尺寸、网格的尺寸（各有 `.x .y .z`） | 1.6 |
| `<<<g, b>>>` | 核函数的执行配置：$g$ 个线程块，每块 $b$ 个线程 | 1.6 |
| SM | 流多处理器（streaming multiprocessor） | 1.6 |
| warp | 线程束：同时执行同一条指令的 32 个线程 | 1.6 |
| HBM | 高带宽显存（high-bandwidth memory） | 1.5 |

中文名称与英文的对照以《术语表》为准。正文第一次出现时中英并列，此后用中文名；代码与 API 名称保留英文原文。

## 六、单位与数字

1. SI 单位；时间 s、ms、μs、ns；能量用 J、kWh（1 kWh = 3.6 MJ）；功率 W。
2. 大数按三位分节，中文版用空格（如 1 281 167），英文版用逗号（GB/T 15835 的做法）。
3. 科学记数法写成 $3.15\times10^{23}$，程序输出交给正文时由 `bookout` 统一格式。
4. 百分数保留到能说明问题的位数，误差和增长率写明是相对还是绝对。

## 七、英文缩写

缩写第一次出现时给出全称与中文名，例如“图形处理器（graphics processing unit，GPU）”。常用缩写：AI、ML、DL、GPU、CPU、TPU、NPU、CUDA、SIMT、SIMD、HBM、PCIe、LLM、CNN、RNN、MLP。
