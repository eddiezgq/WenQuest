title: 本章提要
---

第 1、2 章说明了两件事：深度学习的计算几乎全部归结为矩阵乘法等少数几种高度规则的运算；这些运算的数量巨大，彼此大量独立。本章回答下一个问题：GPU 为什么正好适合这样的计算，它的内部是怎样组织的，一段程序在它上面执行时，时间究竟花在了哪里。这是第 4—9 章 CUDA 编程与性能优化的基础：不了解硬件怎样执行，就无法理解为什么同一个算法的两种写法速度能差几十倍。

本章的内容安排如下：

- 3.1 节讲并行计算的基本概念：并发与并行、弗林分类、数据并行与任务并行，并用“工作量与跨度”衡量一个算法能并行到什么程度；
- 3.2 节讲阿姆达尔定律与古斯塔夫森定律：串行部分怎样限制加速比，问题规模扩大后结论为什么不同；
- 3.3 节比较 CPU 与 GPU 的设计哲学：面向延迟与面向吞吐，引入利特尔定律，算出要用满 GPU 的显存带宽需要多少数据“在路上”；
- 3.4 节回顾 GPU 从图形流水线到通用计算、再到张量核心的演进，用历代规格看算力与带宽的增长；
- 3.5 节以 H100 为例讲 GPU 的硬件组成：流多处理器、线程束调度器、寄存器堆、共享内存、L2 缓存与高带宽显存；
- 3.6 节讲 SIMT 执行模型与线程束分化，用 GPU 执行模拟器量出一个分支的代价；
- 3.7 节讲延迟隐藏与占用率：多少个线程束才能把显存延迟藏住，寄存器和共享内存怎样限制常驻的线程束；
- 3.8 节讲计算强度与屋顶线模型，把第 2 章小型 Transformer 的各层画到屋顶线上。

本章第一次用到**GPU 执行模拟器**：它是一个能看到每个时钟周期的教学模型，书中的算例由它的 Python 版算出，实验 3.6 用它的网页版，两者逐行对应、结果相同。它不是真实 GPU 的仿真，简化之处在 3.6、3.7 节和实验指导书中写明；真实的速度数字留到第 4 章起在云端 GPU 上实测。本章引用的 GPU 规格都来自厂商公布的白皮书和数据手册，集中登记在一张表里（表 3.4.1），每个数注明出处。

学完本章，读者应能：

1. 区分并发与并行、数据并行与任务并行，用弗林分类说明 CPU 和 GPU 属于哪一类；算出一个算法的工作量与跨度，用布伦特定理估计它在 $p$ 个处理器上的时间；
2. 用阿姆达尔定律和古斯塔夫森定律估计加速比，找出限制加速比的串行部分；
3. 说明 CPU 面向延迟、GPU 面向吞吐的设计取舍，用利特尔定律算出用满带宽所需的在途数据量；
4. 说出 GPU 演进中的几个关键节点，读懂一块 GPU 的规格表，核对峰值算力的来历；
5. 画出一个流多处理器的组成，说明寄存器堆、共享内存、L2 缓存与显存的容量和带宽差别；
6. 解释 SIMT 执行与线程束分化，计算一个分支的 SIMT 效率；
7. 用式 (3.7.1) 估计隐藏延迟所需的线程束数，按寄存器、共享内存、线程块数计算占用率；
8. 计算一个运算的计算强度，用屋顶线模型判断它受算力还是受带宽限制。
