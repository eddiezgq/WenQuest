title: 本章提要
---

第 4—6 章从零写核函数，是为了弄懂 GPU 怎样工作。实际做深度学习，几乎没有人从零写起：矩阵乘法调 cuBLAS，卷积调 cuDNN，多 GPU 通信调 NCCL，这一切又被 PyTorch 这样的框架包起来，用户写的只是 `model(x)` 和 `loss.backward()`。本章打开这些库和框架，看前几章的原理怎样落实在其中：一行 Python 代码怎样一路变成 GPU 上的核函数，时间和显存花在了哪里，什么时候该调库、什么时候该自己写算子、什么时候交给编译器。

贯穿本章的实际问题是：用 PyTorch 训练第 2 章的小型 Transformer（批大小 32、每条 256 个词元、单精度），一个训练步里发生了什么。

本章的内容安排如下：

- 7.1 节是 CUDA 库的全景，并估算一个训练步的时间花在矩阵乘法和其余运算上各多少；
- 7.2 节讲 cuBLAS 与 cuBLASLt：列主序约定、数学模式、批量矩阵乘法、尾处理融合；
- 7.3 节讲 cuDNN：同一个卷积层的各种算法，数据布局；
- 7.4 节讲 CUTLASS：矩阵乘法分块的层次，CuTe 的布局；
- 7.5 节讲 PyTorch 的结构：分派器、ATen、缓存分配器，一次运算的开销；
- 7.6 节讲自动微分在 GPU 上怎样执行，训练时显存花在哪里，用重计算换显存；
- 7.7 节为 PyTorch 写一个自定义 CUDA 算子并接入自动微分；
- 7.8 节讲图编译 `torch.compile`：TorchDynamo、AOTAutograd、TorchInductor。

本章的 C++/CUDA 程序与 PyTorch 程序在云端 A10 上实测，还没有实测的数字显示为“〔待实测〕”。Python 算例不依赖 PyTorch，用来在实测之前写下预期。本章有两个云端 GPU 实验：7.6 节用性能分析器看一次训练迭代调用了哪些核函数，7.7 节为 PyTorch 写一个自定义 CUDA 算子。

学完本章，读者应能：

1. 说出深度学习常用的 CUDA 库各管什么，判断一个运算该交给哪个库；
2. 用 cuBLAS 计算行主序的矩阵乘法，选择数学模式，用批量矩阵乘法与尾处理减少启动和显存往返；
3. 说明 cuDNN 各种卷积算法的代价，理解为什么要实测挑选、为什么用 NHWC；
4. 读懂 CUTLASS 的分块层次，用 CuTe 的布局描述数据与线程的对应；
5. 说明 PyTorch 一次运算经过的各层与它们的开销，读懂显存统计中“已分配”与“已保留”的区别；
6. 估算训练时参数、梯度、优化器状态与激活值各占多少显存，用重计算换显存并估计代价；
7. 写一个自定义 CUDA 算子，接入自动微分并用梯度检查验证；
8. 说明 `torch.compile` 三个阶段各做什么，判断它在什么情况下能加速。
