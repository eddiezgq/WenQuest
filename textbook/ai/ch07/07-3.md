### 7.3.1 问题的提出

5.5 节讲了卷积的几种算法：im2col 加矩阵乘法、隐式矩阵乘法、维诺格拉德、快速傅里叶变换，并把实测留到了这里。检测工位识别划痕、压痕的卷积网络（第 11 章），每一层都要在这些算法中选一个。纸面上省乘法最多的算法，在 GPU 上是不是最快？

### 7.3.2 cuDNN 的用法

cuDNN 是 NVIDIA 的深度神经网络库（2014 年发布），提供卷积、池化、归一化、激活函数、循环网络和注意力等运算。用法与 cuBLAS 类似：先创建句柄，再用描述符说明每个张量（数据类型、形状、布局）、卷积核、卷积本身（补零、步长、膨胀、计算类型、数学模式），然后调用：

```cpp
cudnnSetTensor4dDescriptor(xd, CUDNN_TENSOR_NHWC, CUDNN_DATA_HALF, N, C, H, W);
cudnnSetFilter4dDescriptor(wd, CUDNN_DATA_HALF, CUDNN_TENSOR_NHWC, K, C, R, S);
cudnnSetConvolution2dDescriptor(cd, 1, 1, 1, 1, 1, 1, CUDNN_CROSS_CORRELATION, CUDNN_DATA_FLOAT);
cudnnSetConvolutionMathType(cd, CUDNN_TENSOR_OP_MATH);              // 允许用张量核心
cudnnGetConvolutionForwardWorkspaceSize(h, xd, wd, cd, yd, algo, &bytes);
cudnnConvolutionForward(h, &alpha, xd, x, wd, w, cd, algo, ws, bytes, &beta, yd, y);
```

前向卷积有 8 种算法（`cudnnConvolutionFwdAlgo_t`）：隐式矩阵乘法两种（是否预先算好下标）、显式矩阵乘法（im2col）、直接卷积、快速傅里叶变换两种（整张图变换，或切块变换）、维诺格拉德两种（融合在一个核函数里，或分步做）。有的算法要借一块临时显存，称为**工作区**，大小由 `cudnnGetConvolutionForwardWorkspaceSize` 查出。不是每种算法都支持每种形状和数据类型，不支持的会返回错误。

cuDNN 8（2020 年）起另有一套基于“运算图”的接口（常经 C++ 的 `cudnn_frontend` 或 Python 的 `cudnn` 包使用）：用户把卷积、加偏置、激活等几个运算连成一张小图，cuDNN 为整张图挑选或生成一个融合的核函数；cuDNN 9 把上面的传统接口标为弃用。PyTorch 的卷积如今默认走运算图接口，但两者在概念上一一对应——描述符、算法、工作区、实测挑选——本节用传统接口，因为它写起来短，每一步都看得见。

### 7.3.3 各种算法的代价

PyTorch 中设置 `torch.backends.cudnn.benchmark = True`，第一次遇到某个形状的卷积时就像程序 7.3.1 那样把可用的算法都试一遍，记住最快的，以后同样的形状直接用。输入形状固定的网络（如检测工位上固定分辨率的相机）应当打开它；形状经常变的（如每批长度不同的序列）则每遇到新形状都要重试一遍，反而更慢。还要注意，试出来的最快算法未必是确定性的（多次运行结果逐位相同），需要逐位可复现时设置 `torch.backends.cudnn.deterministic = True`。

### 7.3.5 数据布局：NCHW 与 NHWC

PyTorch 的张量默认按 NCHW 存放（批、通道、高、宽，通道在外层）。张量核心做卷积时，要求沿通道方向连续（通道在最内层，NHWC）：隐式矩阵乘法的 $K$ 维就是 $C\times R\times S$，通道连续，从显存读进共享内存时才能合并访问、按 128 位读。所以输入是 NCHW 时，cuDNN 要先把它转成 NHWC，算完再转回来。

**算例 7.3.2** 算例 7.3.1 的卷积层，若网络其余部分是 NCHW，每层前后把输入转成 NHWC、把输出转回 NCHW，读写共需 {{ex7_3.t_layout_us:.0f}} μs，是卷积本身按峰值所需时间的 {{ex7_3.layout_ratio:.1f}} 倍。实测（程序 7.3.1）：把输入在两种布局之间转换一次（`cudnnTransformTensor`，NHWC → NCHW，反方向的代价相同）要 {{run7_3.transform_us:.0f}} μs（{{run7_3.transform_GBs:.0f}} GB/s）。

所以用半精度训练卷积网络时，应当让整个网络都用 NHWC：PyTorch 中 `model.to(memory_format=torch.channels_last)`，输入也转一次。张量的形状仍写作 $(N, C, H, W)$，只是步长变了（2.3.3 节），用户代码不用改。

**工程师笔记**

- 固定形状的卷积网络打开 `cudnn.benchmark`；形状多变的不要开。
- 半精度、张量核心的卷积用 NHWC（`channels_last`），整个网络一致，避免每层来回转换。
- 维诺格拉德、傅里叶变换省乘法，但多搬数据、多占显存、有舍入误差；谁快以实测为准。
- 需要逐位可复现时打开 `cudnn.deterministic`，代价是可能放弃最快的算法。
