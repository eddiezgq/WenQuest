title: 本章提要
---

人工智能这个名称出现在 1955 年的一份会议申请书中，随 1956 年的达特茅斯会议确立，七十年来几经起落；近十多年，它以前所未有的速度进入了图像识别、语音、翻译、科学研究、工业生产和日常生活。这一轮突破从哪里来？本章是全书的导论，要回答三个问题：人工智能是什么，它是怎样走到今天的，以及为什么今天的人工智能离不开 GPU 和 CUDA。

本章的内容安排如下：

- 1.1 节比较几种有代表性的定义，引入全书使用的框架——智能体与理性，并用一个算例说明性能度量的选择怎样决定一个系统的好坏；
- 1.2 节介绍符号主义、连接主义、行为主义三条研究路线，对连接主义最基本的模型——感知机——给出学习规则、收敛定理的完整证明以及它的局限；
- 1.3 节按六个阶段回顾人工智能的历史，用 ImageNet 竞赛的数据看深度学习的突破有多大；
- 1.4 节讨论数据、算法、算力三要素，推导训练算力的估算公式 $C\approx 6ND$，并用公开数据看训练算力增长得有多快；
- 1.5 节以 AlexNet 为例逐层数出一次推理的运算量，比较 CPU 与 GPU，引入计算强度，说明为什么大模型的逐词生成受显存带宽限制；
- 1.6 节讲 GPU 怎样从图形处理器变成通用计算平台，CUDA 的基本编程模型，以及 CUDA 与深度学习怎样互相成就；
- 1.7 节给出全书的路线图、课程路线和实验环境。

本章要求读者会 C 和 Python 编程、学过线性代数；用到的其他知识都在书中讲清。本章的每一个计算结果都由程序算出，读者可以展开程序查看和改动。本章的概念在后面各章中反复出现：感知机在第 2 章发展为多层网络与反向传播；运算量与计算强度的分析在第 3、6 章发展为屋顶线模型；CUDA 的线程层次在第 4、5 章展开为完整的编程方法；训练算力的估算在第 9 章用于规划大模型的训练。

学完本章，读者应能：

1. 说出智能体、理性智能体、性能度量、机器学习的定义，为一个具体的系统写出它的观测、动作和性能度量，用混淆矩阵计算准确率、精确率、召回率和代价；
2. 比较三条研究路线的根基、长处和困难，写出感知机的学习规则，证明感知机收敛定理，并说明感知机为什么不能学会异或；
3. 按阶段讲述人工智能历史上的主要事件，用相对改进和年均变化率解读竞赛数据；
4. 区分 FLOP、FLOPs、FLOP/s 和 MAC，用 $C\approx 6ND$ 和 $T = C/(nPu)$ 估算一个模型的训练算力和训练时间；
5. 逐层统计一个卷积网络的乘加次数和参数量，计算一项计算的计算强度，判断它受算力限制还是受显存带宽限制；
6. 读懂一个最简单的 CUDA 核函数，算出线程块数和每个线程负责的元素，说明 GPU 算力与带宽的发展趋势；
7. 按自己的目标选择本书的阅读路径和课程路线。
