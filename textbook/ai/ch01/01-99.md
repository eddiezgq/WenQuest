本章的主线可以概括为一句话：人工智能是构造理性智能体的科学与工程，而近十多年它的突破，主要来自同样的思想在数据和算力上规模的扩大，GPU 与 CUDA 是这一扩大的物质基础。

我们先给人工智能下了一个可以检验的定义：智能体通过传感器感知环境、通过执行器作用于环境，其行为由智能体函数 $f$ 完全描述；理性智能体选择使性能度量期望值最大的动作。性能度量评价的是环境状态，而且决定一切——算例 1.1.1 中，换一个代价设定，“好”的过滤器就变成了“坏”的。机器学习是从经验中得到好的 $f$ 的方法，深度学习用多层神经网络表示 $f$。

构造 $f$ 有三条路线：符号主义把知识写成规则，连接主义从数据中学出连接的权重，行为主义在与环境的交互中试错。感知机是连接主义的起点，它的学习规则 $\boldsymbol w\leftarrow\boldsymbol w + \eta y\tilde{\boldsymbol x}$ 简单而有效：对线性可分的数据，更新次数不超过 $(R/\gamma)^2$，证明的关键是投影线性增长而长度只按平方根增长；对异或这类线性不可分的问题，它永远停不下来，要靠多层网络解决。今天成功的系统常把三条路线结合在一起。

七十年的历史经过了孕育、早期的乐观、第一次低谷、专家系统的兴衰与第二次低谷、统计学习、深度学习和大模型几个阶段。2012 年 AlexNet 把 ImageNet 竞赛的前五错误率相对降低了四成，它用的方法早已存在，不同的是一百多万张标注图像和两块 GPU。

数据、算法、算力三要素中，算力的增长最为迅猛。训练一个 $N$ 参数、$D$ 词元的模型约需 $C\approx 6ND$ 次浮点运算，这个公式与 GPT-3、Llama 3 论文公布的数相差不到百分之一；用 $n$ 块峰值为 $P$、利用率为 $u$ 的 GPU 训练，需要 $C/(nPu)$ 的时间。训练算力在深度学习时代每年增长约四到五倍，远远超过摩尔定律。

神经网络的运算数量巨大、大量独立、高度规则，适合 GPU 用成千上万个简单单元并行完成。但速度不只取决于算力：一项计算的耗时至少是 $\max(W/P, Q/\beta)$，计算强度 $I = W/Q$ 低于硬件的 $P/\beta$ 时，计算受显存带宽限制。大矩阵乘法受算力限制；大模型逐词生成的计算强度只有 1 FLOP/B 左右，严重受带宽限制，要靠批处理和压缩权重提高效率。GPU 的算力比带宽增长得快，$P/\beta$ 越来越大，让运算单元保持忙碌越来越难，这是上篇各章反复面对的核心问题。

CUDA 让程序员只写一个线程做的事，由 GPU 启动成千上万个线程执行；线程组成线程块，线程块组成网格，每个线程由自己的编号算出负责的数据。CUDA 与深度学习互相成就，形成了今天人工智能的主要软件生态；它的基本概念同样适用于其他 GPU 和国产加速器。

### 部分习题答案与提示

1.1.3 乙的代价为 $150c + 20$ 元，甲为 200 元；$c < 1.2$ 元时乙更好。

1.1.4 $\mathrm{TP} = 45$，$\mathrm{FP} = 35$，$\mathrm{FN} = 5$，$\mathrm{TN} = 9915$；准确率 99.6%，精确率 56.3%，召回率 90%，$F_1\approx 0.692$。准确率很高却说明不了什么。漏检代价高时应调低判为“有缺陷”的门槛，以提高召回率，并按代价重新评价。

1.2.1 与：$w_1 = w_2 = 1$，$b = -1.5$；或：$w_1 = w_2 = 1$，$b = -0.5$（输入取 0、1）。

1.2.2 第一层 $h_1$ 实现或、$h_2$ 实现与（输出取 $\pm1$）；第二层 $\hat y = \operatorname{sign}(h_1 - h_2 - 1)$。

1.2.3 估计 $\lVert\boldsymbol w_j\rVert^2$ 时，中间项 $2\eta y\,\boldsymbol w_{j-1}^{\mathsf T}\tilde{\boldsymbol x}\le 0$ 用到了“判错”。对分对的样本也更新，这一项可能为正，长度的界不再成立。

1.2.4 输入放大 10 倍时，增广的常数分量 1 不变，所以增广向量不是整体放大，数据在增广空间中的几何形状变了，$R$ 与 $\gamma$ 不再同比例变化，界一般会改变（通常变大）。若把增广向量整体（含常数分量）放大 10 倍，$R$ 与 $\gamma$ 同比例放大，界不变。只放大 $x_1$ 同样改变形状。

1.3.2 $(3.57/15.3)^{1/3} - 1\approx -38.4\%$，比 2010—2015 年下降得更快。

1.4.1 $C\approx 8.4\times10^{22}$ FLOP；约 $8.3\times10^5$ s，即约 9.6 天。

1.4.3 $C = 6N\cdot 20N = 120N^2$，$N = \sqrt{C/120}$；$C = 10^{24}$ 时 $N\approx 9.1\times10^{10}$，$D\approx 1.8\times10^{12}$。

1.4.4 三次矩阵乘法的运算量都是 $2Bd_{\text{in}}d_{\text{out}}$：前向 $Y = XW$，对输入的梯度 $\partial\mathcal L/\partial X = (\partial\mathcal L/\partial Y)W^{\mathsf T}$，对权重的梯度 $\partial\mathcal L/\partial W = X^{\mathsf T}(\partial\mathcal L/\partial Y)$。
