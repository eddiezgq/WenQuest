### 4.2.1 问题的提出

向量加法的数据是一维的，线程按编号一一对应元素即可。检测相机的图像是二维的：3840 列、2160 行。让线程也排成二维，每个线程处理一个像素，写起来更自然。本节说明 CUDA 怎样组织线程，以及每个线程怎样算出自己负责哪个数据。

### 4.2.2 三层结构

CUDA 的线程分三层组织。启动一个核函数产生一个**网格**；网格由若干**线程块**组成；每个线程块由若干**线程**组成。线程块和网格都可以是一维、二维或三维的，用类型 `dim3` 描述。这三层与硬件的对应在 3.5.8 节已经说明：一个线程块整个驻留在一个 SM 上，块内的线程可以通过共享内存交换数据、可以同步；不同的线程块之间没有执行顺序的保证。计算能力 9.0（H100）起还可以在网格与线程块之间加一层可选的“线程块簇”：同一簇的线程块同时驻留在相邻的几个 SM 上，可以互相访问共享内存、一起同步，第 5、8 章会用到。

每层的规模有上限（计算能力 7.0 及以上的 GPU）：一个线程块最多 1024 个线程，x、y 方向各不超过 1024、z 方向不超过 64；网格的 x 方向最多 $2^{31} - 1$ 个线程块，y、z 方向各不超过 65 535 个。

核函数中可以读到四个内置变量：`gridDim`（网格有多少个线程块）、`blockIdx`（本线程块的编号）、`blockDim`（线程块有多少个线程）、`threadIdx`（本线程在块内的编号），各有 `.x`、`.y`、`.z` 三个分量。

### 4.2.3 一维索引

一维时，线程的全局编号是

$$
i = \text{blockIdx.x}\cdot\text{blockDim.x} + \text{threadIdx.x} , \tag{4.2.1}
$$

即前面所有线程块的线程数，加上本线程在块内的编号。要覆盖 $n$ 个元素，每块 $b$ 个线程时需要

$$
\left\lceil\frac nb\right\rceil = \frac{n + b - 1}{b}\ \text{（整数除法）} \tag{4.2.2}
$$

个线程块。

**线程块取多大？**每块的线程数应当是 32 的倍数，否则最后一个线程束不满，白白浪费运算通道。太小（如 32）时，一个 SM 最多驻留的线程块数（视计算能力为 16～32 个，A10 为 16 个）限制了驻留的线程数，藏不住延迟（3.7 节）；太大（如 1024）时，一个线程块占用的寄存器、共享内存多，资源不够时一个 SM 只能放下一个，块内同步时大家一起等。128～512 是常用的范围，256 是一个稳妥的起点。GPU 实验 4.1 的第 4 步让读者实际测量。

### 4.2.4 二维索引

处理图像时，线程块和网格都排成二维：

$$
\text{col} = \text{blockIdx.x}\cdot\text{blockDim.x} + \text{threadIdx.x} , \qquad \text{row} = \text{blockIdx.y}\cdot\text{blockDim.y} + \text{threadIdx.y} , \tag{4.2.3}
$$

像素在行主序的数组中的位置是 $p = \text{row}\cdot w + \text{col}$（$w$ 为图像宽度）。习惯上 x 方向对应列、y 方向对应行，这样相邻的线程（`threadIdx.x` 相邻）处理同一行中相邻的像素，访问相邻的内存地址——这一点对速度至关重要（4.6 节）。

### 4.2.5 网格跨步循环

“每个线程一个元素”要求线程数不少于元素数。数据很大时，也可以只启动适量的线程，让每个线程处理多个元素：

```cpp
__global__ void vadd_loop(const float* a, const float* b, float* c, int n) {
    int stride = gridDim.x * blockDim.x;                  // 整个网格的线程数
    for (int i = blockIdx.x * blockDim.x + threadIdx.x; i < n; i += stride)
        c[i] = a[i] + b[i];
}
```

这称为**网格跨步循环**。第一轮，所有线程处理前 $\text{stride}$ 个元素；第二轮处理接下来的 $\text{stride}$ 个……每一轮中相邻线程仍访问相邻的地址。它有三个好处：任意长度的数据都能用固定大小的网格处理；网格大小可以按 SM 数选（比如每个 SM 若干个线程块），刚好铺满 GPU；每个线程处理多个元素，分摊了算索引、启动线程的开销。

**例** $n = {{ex4_2.n_big_e}}$ 个元素，网格 {{ex4_2.grid_small}} 个线程块（H100 的 132 个 SM 每个 8 块）、每块 256 个线程，每个线程循环至多 {{ex4_2.per_thread}} 次。

**工程师笔记**

- 二维数据让 x 对应最内层（变化最快）的维度，相邻线程访问相邻地址。
- 每块线程数取 32 的倍数，一般从 256 开始试；网格大小用式 (4.2.2) 计算，或用网格跨步循环按 SM 数选定。
- 越界检查不能省：最后一个线程块、图像的边缘几乎总有多出来的线程。
