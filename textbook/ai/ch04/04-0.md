title: 本章提要
---

第 3 章从硬件的角度说明了 GPU 怎样执行程序：成千上万个线程，每 32 个组成一个线程束同步执行，靠大量线程的并发藏住显存的延迟，而数据怎样在存储层次中流动决定了速度。本章开始动手写程序。CUDA 是 NVIDIA 为自家 GPU 设计的编程模型：在 C++ 的基础上加了少量扩展，让程序员写出在 GPU 上由成千上万个线程执行的函数，并管理主机与设备两边的内存。本章讲 CUDA 编程最基本的概念和最常用的写法，以及第一个、也是最重要的性能问题：怎样访问内存。

本章贯穿一个实际问题：数字工厂检测工位的相机每秒拍 60 帧 3840×2160 的彩色图像，要在 GPU 上变成灰度、找出暗斑。从最简单的向量加法开始，逐步写出灰度化、矩阵转置（相机旋转后图像要转置）和灰度直方图的核函数。

本章的内容安排如下：

- 4.1 节讲开发环境，写出第一个核函数——向量加法，说明一个 CUDA 程序的组成；
- 4.2 节讲线程层次：线程、线程块、网格，一维与二维的索引计算，网格跨步循环；
- 4.3 节讲主机与设备之间的内存：显存分配、数据传输、锁页内存与统一内存，说明数据传输为什么常常比计算还慢；
- 4.4 节讲错误处理与调试：检查每个调用、异步错误、compute-sanitizer；
- 4.5 节讲 CUDA 的存储空间：寄存器、本地内存、共享内存、常量内存与全局内存；
- 4.6 节讲全局内存的合并访问，用 GPU 执行模拟器的第三部分看一个线程束要搬多少数据；
- 4.7 节讲共享内存与存储体冲突，用矩阵转置把前两节的知识用在一起；
- 4.8 节讲同步与原子操作，以灰度直方图为例说明数据竞争和原子操作的争用，介绍协作组；
- 4.9 节讲在 Python 中写 CUDA：Numba 与 CuPy。

本章的程序有三类。CUDA 程序（.cu）都经过编译检查，在云端 GPU 上运行与计时；书中的耗时与带宽由程序在云端 GPU 上实测得出，写明 GPU 型号与日期，还没有实测的数字暂时显示为“〔待实测〕”。Python 程序计算理论值和参照结果；Numba 程序在构建时用 Numba 自带的 CUDA 模拟器在 CPU 上核对。本章有两个云端 GPU 实验（4.1、4.7 节）和一个浏览器实验（4.6 节）。

学完本章，读者应能：

1. 写出、编译、运行一个完整的 CUDA 程序，说明主机代码与设备代码、核函数与启动配置；
2. 为一维、二维数据计算线程的全局索引，选择线程块大小与网格大小，写出网格跨步循环；
3. 在主机与设备之间分配、传输数据，解释锁页内存与统一内存的作用，估计传输的耗时；
4. 检查 CUDA 调用与核函数的错误，用 compute-sanitizer 找出越界访问与数据竞争；
5. 说明各种存储空间的作用范围、生存期与速度，用对限定符；
6. 判断一个访问模式是否合并，计算一个线程束要搬运的扇区数，改写结构体数组；
7. 用共享内存做分块，判断并消除存储体冲突，写出合并访问的矩阵转置；
8. 正确使用 `__syncthreads()` 与原子操作，用共享内存私有化减少原子操作的争用；
9. 用 Numba 或 CuPy 在 Python 中写出简单的核函数。
