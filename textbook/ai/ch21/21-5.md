### 21.5.1 两条线，两个问题

车间的图上常常画着两组水平线，很多人把它们当成一回事：

- **规格限**（$LSL$、$USL$）来自图纸，回答“这一件合不合格”；
- **控制限**来自过程自己的波动，回答“过程有没有变”。

休哈特均值图的控制限是

$$\bar{\bar{x}} \pm A_2 \bar{R} \tag{21.5.1}$$

其中 $\bar R$ 是子组极差的平均，$A_2$ 是随子组大小取值的标准系数（子组大小 5 时 $A_2 = {{tab21_1.a2_5}}$）。极差图的上限是 $D_4 \bar R$（$D_4 = {{tab21_1.d4_5}}$）；由极差估过程标准差用 $\hat\sigma = \bar R / d_2$（$d_2 = {{tab21_1.d2_5}}$）。

**这几个数里没有一个与规格限有关。** 规格限是设计给的，控制限是过程给的，两者宽窄的比例随过程能力浮动。

**算例 21.5.1** 同一条产线，规格限 ±3：控制限算出来是 {{ex21_6.lcl:+.3f}} … {{ex21_6.ucl:+.3f}}（宽 {{ex21_6.ctrl_width:.3f}}），规格限宽 {{ex21_6.spec_width:.1f}}，后者是前者的 {{ex21_6.width_ratio:.1f}} 倍。注意控制限管的是**子组均值**的波动（所以要除以 $\sqrt{n}$），规格限管的是单件——连单位都不是一回事。

### 21.5.2 受控与能力，是两件事

**算例 21.5.2** 两个过程：

- **过程甲**：规格很窄，过程能力指数 $C_{pk} = {{ex21_6.cpk_A:.2f}}$，按正态估算超差 {{ex21_6.ppm_A:,.0f}} ppm——做出来的东西一大半不合格，而它的报警率只有 {{ex21_6.alarm_A:.1f}}%，完全“受控”；
- **过程乙**：规格很宽，$C_{pk} = {{ex21_6.cpk_B:.2f}}$，超差几乎为零——做得出好件，可是均值隔一阵跳一下，报警率 {{ex21_6.alarm_B:.1f}}%，天天报警。

所以两件事要分开问：做得出合格品吗（能力，对规格限）与过程有没有变（受控，对控制限）。把控制限当合格判据，两边都答错：合格的件被判不合格，不合格的过程被说成“受控”。

### 21.5.3 控制图会虚发警报，而且比教科书更频繁

三倍标准差控制限下，过程完全没变时每个子组报警的概率约 {{tab21_1.false_alarm_p}}，即平均每 {{tab21_1.arl0_theory}} 个子组虚发一次。这是教科书值。

**算例 21.5.3** 把它模拟一遍：{{ex21_6.n_sub}} 件一组、用前 50 个子组定控制限，{{ex21_6.false_alarm_rate:.5f}} 的报警概率，即平均每 **{{ex21_6.arl0:.0f}}** 个子组一次，是教科书值的 {{ex21_6.arl0_ratio:.2f}} 倍。

差在哪？控制限是估出来的。用有限个子组估 $\bar R$，估偏了控制限就偏窄或偏宽；平均起来，虚发警报比理论值更频繁。这条在现场很实际：有人抱怨“控制图天天报警”，原因常常不是过程不稳，而是**定控制限时用的那几十个子组本身不够稳或不够多**。

### 21.5.4 抓得到什么，抓不到什么

**算例 21.5.4** 过程在某一处变了，均值图要多久才发现（中位）：

| 变化 | 多少个子组后报警 |
|---|---|
| 均值漂移 0.5σ | {{ex21_6.arl_shift05:.0f}} |
| 均值漂移 1.0σ | {{ex21_6.arl_shift10:.0f}} |
| 均值漂移 1.5σ | {{ex21_6.arl_shift15:.0f}} |
| 均值漂移 2.0σ | {{ex21_6.arl_shift20:.0f}} |
| 方差变 1.5 倍 | {{ex21_6.arl_spread15:.0f}} |
| 方差变 2.0 倍 | {{ex21_6.arl_spread20:.0f}} |

**同样是“过程变了”，方差变大比均值漂移难发现得多**：方差 1.5 倍要等 {{ex21_6.arl_spread15:.0f}} 个子组，而 1σ 漂移只要 {{ex21_6.arl_shift10:.0f}} 个。道理不难：方差变大时子组均值的分布变宽，但中心没动，只能等某个均值碰巧出界。

所以均值图必须配极差图一起看。只看均值图的车间，方差问题会拖很久——而方差变大往往正是刀具磨损、夹具松动的早期信号。

### 21.5.5 那么机器学习能补什么

把同一段数据交给一个最朴素的学习式报警器（用稳定期估出每个量的中心与散布，再看新子组离中心多远），它与控制图的分工大致是这样：

| | 控制图 | 学习式报警 |
|---|---|---|
| 看几个量 | 一次一个（均值、极差各一张） | 可以同时看很多个 |
| 要不要标注 | 不要 | 不要（用稳定期当参照） |
| 报警之后 | 知道该查什么（均值跑了还是波动大了） | 只知道“不对劲” |
| 对“均值没动但别的变了” | 慢 | 快 |
| 虚发警报 | 可算、可调（三倍标准差） | 取决于阈值分位数，常被忽略 |

所以不是替代关系。实践中的次序通常是：先把控制图做对（控制限估准、均值图配极差图、判据写清楚），再用学习式报警去补那些“均值没动”的异常，并且**给它一个与三倍标准差同量级的虚发警报预算**。

还有一条容易被忽略：学习式报警的“稳定期”要是本身就带着一个没被发现的异常，它会把那个异常学成正常。控制图也有这个毛病（控制限会被算宽），但控制图至少把这件事摆在明处——$\bar R$ 是多少、用哪几个子组算的，都写在纸上。

### 21.5.6 这一节要记住的

- **控制限来自过程，规格限来自图纸**，两者没有固定比例，连单位都不同；
- **受控 ≠ 有能力**：$C_{pk}$ {{ex21_6.cpk_A:.2f}} 的过程可以一个警报不报，{{ex21_6.cpk_B:.2f}} 的过程可以天天报警；
- 控制图必然虚发警报，而且因为控制限是估出来的，现场比教科书更频繁（本例 {{ex21_6.arl0:.0f}} 对 {{tab21_1.arl0_theory}} 个子组）；
- 均值图对方差变化钝，必须配极差图；
- 学习式报警是补充不是替代，而且要给它一个明确的虚发警报预算。
