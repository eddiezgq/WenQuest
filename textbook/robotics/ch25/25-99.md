title: 本章小结
---

本章的主线可以用一句话概括：**前向传运动，反向传力——每个连杆用一次牛顿-欧拉方程，从基座到末端算出 $\mathcal V_i$、$\dot{\mathcal V}_i$，再从末端到基座算出 $\mathcal F_i$，关节力矩就是 $\mathcal A_i^{\mathsf T}\mathcal F_i$；计算量与关节数成正比，结果与拉格朗日方程完全相同。**

25.1 节在每个连杆上取原点在关节轴上的连杆坐标系，关节旋量轴 $\mathcal A_i = (\omega_i, 0)$ 是常数，相邻连杆的位姿 $T_{i,i-1} = e^{-[\mathcal A_i]\theta_i}M_{i,i-1}$。证明了运动旋量的递推 $\mathcal V_i = [\mathrm{Ad}_{T_{i,i-1}}]\mathcal V_{i-1} + \mathcal A_i\dot\theta_i$ 和加速度的递推，后者多出一项 $[\mathrm{ad}_{\mathcal V_i}]\mathcal A_i\dot\theta_i$，关节匀速转动时连杆也有加速度；连杆原点的加速度是 $\dot v + \omega\times v$。重力用 $\dot{\mathcal V}_0 = (0, -\boldsymbol{\mathfrak g})$ 代替，MuJoCo 也这样做。上下料动作中 TCP 速度最大 {{ex25_1.v_pk:.2f}} m/s，各关节的贡献部分抵消。

25.2 节写出连杆的受力方程 $\mathcal F_i = [\mathrm{Ad}_{T_{i+1,i}}]^{\mathsf T}\mathcal F_{i+1} + \mathcal G_i\dot{\mathcal V}_i - [\mathrm{ad}_{\mathcal V_i}]^{\mathsf T}\mathcal G_i\mathcal V_i$，证明理想关节的电机力矩是 $\mathcal A_i^{\mathsf T}\mathcal F_i$，再加转子的惯性力矩，合成算法 25.2.1。同一个递推把输入置零，就分出重力项、速度项、惯性项。UR5e 带 3.8 kg 走上下料动作，递推与 MuJoCo 的逆动力学相差 ${{ex25_2.err_mj:sci1}}$ N·m。关节力旋量的其余五个分量由轴承和减速器承受：静止时关节 1 的轴向力就是整台手臂和负载的重力，弯曲力矩远大于它的关节力矩；动起来以后，关节 2 的弯曲力矩峰值由只有重力时的 {{ex25_2.mb2_st:.1f}} N·m 增加到 {{ex25_2.mb2_pk:.1f}} N·m。

25.3 节把递推排成矩阵形式：$\mathcal W$ 幂零，$\mathcal L = (I - \mathcal W)^{-1}$ 是块下三角矩阵，$\mathcal L\mathcal A$ 由各连杆的物体雅可比组成，于是 $M = \mathcal A^{\mathsf T}\mathcal L^{\mathsf T}\mathcal G\mathcal L\mathcal A = \sum J_i^{\mathsf T}\mathcal G_iJ_i$，与拉格朗日方程相同。用 n + 1 次递推可以求出 M 和 $c + g$，从而做正动力学；用逆动力学算出的力矩做正动力学积分，UR5e 回到原轨迹，偏差只有 RK4 的截断误差。

25.4 节数了运算次数：递推的乘法是 {{ex25_4.a_m}}n − {{ex25_4.nb_m}} 次，拉格朗日-欧拉的 4×4 矩阵写法是 n 的四次式，n = 6 时是递推的 {{ex25_4.ratio6:.0f}} 倍。1980 年的递推在 PDP-11/45 上算斯坦福臂只要 4.5 ms，今天 MuJoCo 算 UR5e 只要几微秒。

25.5 节沿上下料轨迹核算了 UR5e：带 3.8 kg 时用得最多的是关节 2（{{ex25_5.util2:.0f}}%）和关节 4（{{ex25_5.util4:.0f}}%）；负载加到 {{ex25_5.lim4:.1f}} kg 时先到上限的是腕关节 4，而不是肩；负载重心离法兰越远，能拿的越少，这就是厂家负载曲线的来历。手臂水平伸直时，关节 2 的力矩中手臂自重的部分（{{ex25_5.arm2:.1f}} N·m）比 5 kg 负载的部分（{{ex25_5.load2:.1f}} N·m）还大，兑现了 1.6 节的预告。

| 概念 | 一句话 |
|---|---|
| 连杆坐标系、关节旋量轴 | 固定在连杆上、原点在关节轴上的坐标系；关节轴在其中的常数坐标 $\mathcal A_i$ |
| 牛顿-欧拉递推 | 前向传运动旋量与加速度、反向传力旋量，求关节力矩的 O(n) 算法 |
| 逆动力学、正动力学 | 由运动求力矩；由力矩求运动 |
| 关节力旋量 | 父连杆经关节作用在子连杆上的力旋量；绕轴分量由电机出，其余由轴承、减速器承受 |
| 弯曲（倾覆）力矩 | 关节力旋量中垂直于关节轴的力矩分量 |
| 伪惯量矩阵 | 4×4 的 $\int\bar r\bar r^{\mathsf T}\mathrm dm$，拉格朗日-欧拉写法中的惯性参数 |
| 复合刚体算法 | 把末端起的若干连杆看成一个刚体，直接求质量矩阵的算法（CRBA） |
| 铰接体算法 | 不解方程、运算量与 n 成正比的正动力学算法（ABA） |
| 负载曲线 | 负载质量与重心偏移的允许范围，主要由腕关节的力矩上限决定 |
