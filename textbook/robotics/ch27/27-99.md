title: 本章小结
---

本章的主线可以用一句话概括：**接触力只能压不能拉，切向力受摩擦锥限制；判断一组接触能不能抓住物体，就是看它们在摩擦锥内能产生的力旋量能否抵消任意外力旋量，而所需的夹紧力由一个线性规划给出。**

27.1 节讲法向的接触模型。刚体之间的接触满足互补条件 φ ≥ 0、λ ≥ 0、φλ = 0，接触力由运动方程和其余约束共同决定，几个接触同时受力时可能不唯一。弹性体按赫兹理论接触：钢毛坯放在 V 形块上，接触带半宽 {{ex27_1.a_um:.1f}} μm，最大压强 {{ex27_1.p0_MPa:.1f}} MPa；同样的载荷压在钢球上，压入量 {{ex27_1.dl_ball_um:.2f}} μm，压强高一百倍。仿真中常用罚函数代替互补条件；MuJoCo 的软接触规定的是加速度，静止物体的穿透量与质量无关，默认参数下约 {{ex27_1.pen_pred_mm:.2f}} mm，比钢的真实变形大两个数量级。

27.2 节讲摩擦。库仑摩擦要求接触力在半顶角为 arctan μ 的摩擦锥内；用 k 条母线的内接棱锥线性化时，最窄处只有 μ cos(π/k)，MuJoCo 默认的 4 条母线棱锥斜着推时提前打滑（{{ex27_2.s_py45:.3f}} 倍）。MuJoCo 的摩擦是软的，夹住的东西会蠕滑，要用圆锥、impratio 和 noslip。竖直提起毛坯，平口夹爪需要 $m(\mathfrak g + a)/(2\mu)$，V 形夹爪再乘 cos γ；毛坯横过来，平口夹爪要用接触线两端的摩擦力偶平衡绕夹紧方向的重力矩，所需的力增大到 {{ex27_2.F_flat_h:.0f}} N（竖直时的 {{ex27_2.h_over_v:.1f}} 倍），V 形夹爪靠斜面的法向力兜住重力，只要 {{ex27_2.mj_v_h:.0f}} N 左右。这些都在 MuJoCo 中逐一验证，误差不到 1%。

27.3 节讲碰撞。恢复系数 e 描述碰撞的结果，冲量 $(1 + e)\bar mv^-$ 和能量损失 $\frac12\bar mv^2(1 - e^2)$ 由它和约化质量决定。赫兹弹性碰撞中，Ø10 mm 钢球从 0.1 m 高落到钢板上，峰值力 {{ex27_3.Fmax:.0f}} N，只持续 {{ex27_3.tc_us:.0f}} μs，仿真要微秒级的步长才算得出来。线性弹簧-阻尼器的恢复系数只由阻尼比决定，与速度、质量无关；MuJoCo 的 solref 就是这样一个弹簧-阻尼器，默认的阻尼比 1 使物体不反弹。亨特-克罗斯利模型的接触力从零开始，e 随撞击速度增大而减小，更符合实际，阻尼系数可按弗洛雷斯公式由 e 定出。协作机器人撞人时，机器人用它在碰撞方向上的有效质量 $(u^{\mathsf T}JM^{-1}J^{\mathsf T}u)^{-1}$ 代表：UR5e 在 B 点为 {{ex27_3.m_min:.1f}}～{{ex27_3.m_max:.1f}} kg，比 ISO/TS 15066 的近似值 {{ex27_3.m_iso:.1f}} kg 小；撞手时允许约 {{ex27_3.v_hand_iso:.2f}} m/s，撞胸时只有 0.3～0.4 m/s。

27.4 节把接触合起来。接触力换成物体上的力旋量，排成抓取矩阵 G；平衡外力旋量之外，G 的零空间中的接触力是内力，夹紧力就是内力。形封闭只靠无摩擦接触，平面至少 4 个、空间至少 7 个，旋转体（如圆柱毛坯）不可能形封闭；力封闭计入摩擦，可以用“母线力旋量能否正张成整个空间”的线性规划判断（定理 27.4.1），平面两指的判据是连线在两个摩擦锥内（定理 27.4.2）。夹毛坯的两个点接触不是力封闭，线接触才是；V 形夹爪的抓取质量比平口高三成多。上下料动作中逐点求最小夹紧力的线性规划表明：惯性力能使同一姿态下所需的力增大六成，但这个动作的最大值仍在两端静止时；线性规划给出的是下限，接触力实际怎样分配取决于弹性。

| 概念 | 一句话 |
|---|---|
| 接触 | 两个物体碰在一起，只能互相压、不能互相拉 |
| 互补条件 | 间隙与法向接触力至少一个为零，两者都不能为负 |
| 赫兹接触 | 弹性曲面的接触：力与压入量的 3/2 次方成正比 |
| 等效弹性模量 | 两个物体的弹性模量和泊松比合成的一个模量 |
| 罚函数法 | 允许穿透，按穿透深度给出推力 |
| 软接触 | MuJoCo 的接触：按参考弹簧-阻尼器规定约束方向的加速度 |
| 摩擦系数 | 最大切向力与法向力之比 |
| 摩擦锥 | 以法向为轴、半顶角为 arctan μ 的圆锥，接触力必须在其内 |
| 扭转摩擦、软指接触 | 面接触时绕法向的摩擦矩；带扭转摩擦的点接触模型 |
| 恢复系数 | 碰撞后分开的相对速度与碰撞前接近的相对速度之比 |
| 有效质量 | 从碰撞点沿某一方向看，机器人相当于多大的质点 |
| 抓取矩阵 | 把各接触力换成物体上合力旋量的矩阵 |
| 内力 | 抓取矩阵零空间中的接触力，不改变合力旋量，夹紧力属于此类 |
| 形封闭 | 只靠无摩擦接触就能平衡任意外力旋量 |
| 力封闭 | 计入摩擦后能平衡任意外力旋量 |
| 对径抓取 | 两个接触的连线位于两个摩擦锥内的两指抓取 |
| 抓取质量 | 各接触法向力之和为 1 时，最不利方向上能平衡的外力旋量大小 |
