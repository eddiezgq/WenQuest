title: 本章小结
---

本章的主线可以用一句话概括：**不确定的量用分布描述，分布随运算传播、随测量更新**。

我们从测力传感器跳动的读数出发。单个读数不可预测，但大量读数的分布是确定的：它由概率密度描述，中心用期望、分散程度用方差和标准差衡量。许多独立小扰动之和近似服从高斯分布，这是中心极限定理告诉我们的，也是传感器噪声多半呈钟形的原因。独立随机变量的方差相加，所以 n 个读数的平均值，标准差缩小为 $1/\sqrt n$；样本方差要除以 n − 1 才是无偏的。均匀分布的标准差是区间宽度的 $1/\sqrt{12}$，它给出了编码器、模数转换器量化误差的大小。

几个量一起考虑时，方差推广为协方差矩阵，它对称、半正定，特征向量给出误差的主方向，特征值的平方根给出各方向的标准差，画出来就是不确定性椭圆。线性变换下协方差矩阵按 $A\Sigma A^{\mathsf T}$ 传播；非线性函数在均值处线性化，用雅可比矩阵代替 A。机械臂末端的误差椭圆随形态而变，接近奇异位形时退化为垂直于手臂的线段。线性化的结果要用蒙特卡洛模拟检验，误差大时分布会弯曲，均值也会偏移。

得到测量以后，贝叶斯公式告诉我们怎样修改认识：后验正比于似然乘以先验。先验很小时，即使传感器很准，报警也未必可信。运动使分布变平，由全概率公式计算；测量使分布变尖，由贝叶斯公式计算；二者交替，就是贝叶斯滤波。高斯先验与高斯测量相乘仍是高斯分布，均值按方差的倒数加权，方差的倒数相加。

最大似然原则给出了构造估计量的统一方法。高斯噪声下，它就是加权最小二乘，权重是噪声协方差矩阵的逆，估计的协方差矩阵是 $(A^{\mathsf T}WA)^{-1}$；即使噪声不是高斯分布，高斯-马尔可夫定理也保证它在线性无偏估计中方差最小。平方和对野值敏感，此时应改用中位数、胡伯估计等稳健方法。

最后，把“协方差传播”用于预测，把“高斯贝叶斯更新”用于测量，就得到一维卡尔曼滤波。它在线性高斯模型下是精确的贝叶斯计算，也是加权最小二乘的递推算法；增益在模型不变时收敛到只取决于噪声之比的稳态值。多维、非线性的推广留待第 46 章。

| 概念 | 一句话 |
|---|---|
| 随机变量 | 随试验结果而变的数；单次不可预测，分布是确定的 |
| 概率密度 | 单位长度上的概率；曲线下的面积是概率 |
| 方差与标准差 | 偏离均值的平方的期望；标准差与读数同单位 |
| 高斯分布 | 由均值和方差完全确定的钟形分布；许多独立小扰动之和近似服从它 |
| 协方差矩阵 | 对角元是方差，非对角元是两两的协方差；特征向量是误差的主方向 |
| 不确定性椭圆 | 马氏距离相等的点；二维 1 倍椭圆只含约 39% 的概率 |
| 蒙特卡洛方法 | 用大量随机试验直接模拟，用来检验线性化的结果 |
| 先验、似然、后验 | 测量前的认识、数据对各假设的支持、测量后的认识；后验正比于似然乘以先验 |
| 条件独立 | 扣除共同的真实状态后，误差互不相干；逐次更新的前提 |
| 最大似然估计 | 使已经看到的数据最可能出现的参数值 |
| 加权最小二乘 | 高斯噪声下的最大似然估计；权重为噪声协方差矩阵的逆 |
| 稳健估计 | 对野值不敏感的估计，如中位数、截尾平均、胡伯估计 |
| 卡尔曼增益 | 新息被采纳的比例；预测越不准、测量越准，增益越大 |
| 新息 | 测量值与预测值之差，测量中“出乎预料”的部分 |
