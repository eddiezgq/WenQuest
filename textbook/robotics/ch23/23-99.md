title: 本章小结
---

本章的主线可以用一句话概括：**刚体的惯性由十个数描述——质量、质心、惯量张量；把它们排成 6×6 的空间惯量 𝒢，牛顿定律就成为 ℱ = 𝒢𝒱̇ − [ad_𝒱]ᵀ𝒢𝒱，在惯性系中即“空间动量的变化率等于力旋量”。**

23.1 节从质点系出发。质心是按质量加权的平均位置，组合体的质心由各部分的质心加权得到。刚体绕定点转动时，由 **v** = **ω** × **r** 得到角动量 L = Iω，其中的 3×3 矩阵 I 就是惯量张量：对角元素是转动惯量，非对角元素是惯性积的相反数。它对称、半正定，换坐标系时按 $RIR^{\mathsf T}$ 变化，有三根互相垂直的主轴；三个主惯量满足三角不等式，对称性往往不必计算就能指出主轴。书中 UR5e 模型的惯量是把各连杆当作半径 0.06 m 的均匀圆柱算出的估算值（来自 ROS-Industrial 的 URDF）。毛坯在卡盘里夹偏 1°，主轴不再是惯量主轴，以 1200 r/min 转动时轴承要承受 {{ex23_1.M_dyn:.1f}} N·m 的旋转力矩，这就是动不平衡。

23.2 节的平行轴定理把对质心的惯量换到任一点：$I_O = I_c + m(|p|^2I_3 - pp^{\mathsf T})$，对一根轴就是 $I_A = I_C + md^2$。从模型文件到连杆坐标系，先用 $R_{ic}$ 转方向，再平移。UR5e 大臂对关节 2 轴的转动惯量 {{ex23_2.J2:.3f}} kg·m²，主要来自 $md^2$；组合体的惯量是各部分换到同一点后相加。复摆的周期只取决于回转半径和悬挂点，d = k 时最短，悬挂点与振动中心可以互换。

23.3 节由质点的牛顿定律和强形式的第三定律推出质心运动定理 $m\ddot x_c = F$ 与角动量定理 $\dot L_c = M_c$；外力只以力旋量的形式出现，所以合力与合力矩相同的力系对刚体是等效的。在固定于刚体的质心坐标系中，转动方程是欧拉动力学方程 $m_b = I_c\dot\omega_b + \omega_b\times I_c\omega_b$（$m_b$ 是外力矩），陀螺项 ω × Iω 是坐标系跟着刚体转的代价。把它与平动方程合起来，得到旋量形式的牛顿-欧拉方程；空间惯量换坐标系按 $[\mathrm{Ad}]^{\mathsf T}\mathcal G[\mathrm{Ad}]$ 变化，方程在刚体上任一坐标系中形式不变。UR5e 加速转动时，法兰对负载的力旋量多出切向、法向的惯性力和绕竖直轴的力矩；高速转子被扳动时产生垂直于两根轴的陀螺力矩 $I_3\omega\Omega$，被重力扳动时就进动。

23.4 节的空间动量 𝒫 = 𝒢𝒱 是对某点的角动量与动量的合称，在惯性系中 $\dot{\mathcal P} = \mathcal F$。外力旋量为零时动量和角动量守恒，内力（包括关节力矩）不改变它们，却可以做功：花样滑冰收臂时转速变为 {{ex23_4.ratio_I:.2f}} 倍，动能的增加来自肌肉的功。动能 $K = \frac12\mathcal V^{\mathsf T}\mathcal G\mathcal V$ 等于质心平动与绕质心转动的动能之和，其变化率等于外力旋量的功率。自由刚体有两个守恒量：动能和 |L|，由它们证明了网球拍定理——绕最大、最小惯量轴的转动稳定，绕中间轴的转动不稳定，扰动以 λ 的速率增长；工具箱每隔 {{ex23_4.dt_flip:.2f}} s 翻转一次，与雅可比的精确解一致。潘索的作图把这一切画成球面与能量椭球的交线。

23.5 节从书中 UR5e 模型的 `<inertial>` 读出七个连杆的惯性参数（模型的连杆质量沿用上一代 UR5 的数值，与 UR5e 的官方值不同），换到连杆坐标系得到 $\mathcal G_i$，再沿运动链换到基座坐标系，算出整臂的质心、对关节 1 轴的转动惯量（零位 {{ex23_5.Izz0:.2f}} kg·m²，折起后不到它的三分之一）和关节 2 的重力矩。全部结果与 MuJoCo 的计算一致，包括由 $\sum J_i^{\mathsf T}\mathcal G_iJ_i$ 拼出的整个质量矩阵。这些就是第 24、25 章动力学计算的输入。

| 概念 | 一句话 |
|---|---|
| 质心 | 各质点位置按质量的加权平均；质心的运动只由外力决定 |
| 角动量 | 各质点位置与动量的叉积之和；外力矩改变它，内力不改变它 |
| 惯量张量 | 把角速度变成角动量的线性算子；参考点不同，张量不同 |
| 转动惯量、惯性积 | 惯量张量的对角元素与非对角元素（后者差一个负号） |
| 惯量主轴、主惯量 | 使惯量张量成为对角矩阵的三根轴与对角元素；只有沿主轴转，L 才与 ω 同向 |
| 回转半径 | 转动惯量相同、全部质量集中所在的半径 $\sqrt{I/m}$ |
| 静不平衡、动不平衡 | 质心偏离转轴；质心在转轴上而转轴不是主轴 |
| 平行轴定理 | 对任一点的惯量 = 对质心的惯量 + 质心处质点的惯量 |
| 复摆、振动中心 | 绕水平轴摆动的刚体；周期与之相同的单摆摆长所对应的点 |
| 质心运动定理、角动量定理 | 质点系的 $m\ddot x_c = F$ 与 $\dot L = M$ |
| 欧拉动力学方程 | 在固定于刚体的主轴坐标系中写的转动方程，含陀螺项 |
| 空间惯量 | 质量、质心、惯量张量合成的 6×6 对称正定矩阵 𝒢 |
| 牛顿-欧拉方程 | ℱ = 𝒢𝒱̇ − [ad_𝒱]ᵀ𝒢𝒱，在刚体上任一坐标系中形式相同 |
| 陀螺力矩、进动、章动 | 扳动转子的轴所需的力矩 Ω × L；转轴在力矩作用下的转动；伴随进动的点头 |
| 空间动量 | 对某点的角动量与动量合成的六维矢量，像力旋量一样变换 |
| 柯尼希定理 | 动能 = 质心平动的动能 + 绕质心转动的动能 |
| 永久转动 | 自由刚体的匀速转动，只能绕主轴 |
| 网球拍定理 | 绕最大、最小惯量轴的转动稳定，绕中间轴的不稳定 |
| 惯量椭球、不变平面 | 潘索作图中固定在刚体上的椭球，与它相切、垂直于 L 的固定平面 |
| 本体极迹、空间极迹 | 切点在椭球上、在平面上画出的曲线 |
| 惯性参数 | 每个连杆的十个数：m、mr、对连杆坐标系原点的惯量张量的六个元素（动力学方程对它们是线性的） |
