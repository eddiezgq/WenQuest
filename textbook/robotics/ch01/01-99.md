title: 本章小结
---

本章的主线可以用一句话概括：**机器人是依据自己的感知自主地运动或作业的、可编程的驱动机构**。其余的内容，都是围绕这句话展开的。

1.1 节从国际标准 ISO 8373 的定义出发，看到机器人与一般自动化设备的根本区别不在机构是否复杂，而在于自主性：决策是否依赖于它自己的测量。感知-决策-执行回路把这一点表达得很清楚，开环的机器按时间表动作，闭环的机器看着环境动作。停车距离的算例说明，感知能力必须与运动能力匹配：车开得越快，就要看得越远。

1.2 节的历史回顾表明，今天机器人身上的思想各有来历：从希罗的绳索、雅卡尔的卡片到可改写的程序，从浮子水钟、瓦特的调速器到反馈控制，从德沃尔的专利、第一台 Unimate 到精确可靠的工业机器人，从 Shakey、包容式结构到今天的具身智能。具身智能没有改变回路的结构，改变的是决策规则的来源：从人编写，变为从数据中学习。IFR 的数字显示，全球工业机器人的年安装量十年翻了一番，相当于每年增长约 7%。

1.3 节按用途把机器人分为工业、服务和医疗三类，按结构与移动方式分为串联、并联的固定基座操作臂，以及轮式、足式、仿人、空中、水下等移动机器人。不同结构的工作空间形状不同，选型要看任务。

1.4 节把机器人拆成七个部分：机构、驱动、电气、传感、控制、软件和智能，能量流与信息流在它们之间形成一个完整的回路。自由度是贯穿全书的基本概念：平面刚体有 3 个，空间刚体有 6 个，基座固定的开链机构的自由度等于各关节自由度之和。执行器少于自由度的机器人是欠驱动的，轮式小车、四足机器人、仿人机器人和四旋翼都是如此。

1.5 节用数字工厂的数据算了几笔账：一根输出轴在车间里要搬运七次，十分钟搬运时间中七分钟花在装卸上；滚齿机是瓶颈，两台 AGV 够用；UR5e 能搬轴，搬不动齿轮毛坯。家里的扫地机器人则说明了地图与规划的价值：随机清扫要覆盖 95% 的地面，所用时间是按行清扫的两倍半。

1.6 节给出了全书的路线图，介绍了五台贯穿机器人。它们的参数全部来自问渠零件库，并在以后各章中保持一致。

| 概念 | 一句话 |
|---|---|
| 机器人 | 经过编程、带有驱动的机构，具有一定程度的自主性，用于移动、操作或定位（ISO 8373:2021） |
| 自主性 | 依据当前状态和感知、不经人的干预完成任务的能力 |
| 开环与闭环 | 指令只依赖时间，还是依赖测量 |
| 工业、服务、医疗机器人 | 按用途的三类；适用的标准和统计口径不同 |
| 串联与并联 | 从基座到末端只有一条路，还是几条支链同时相连 |
| 协作机器人 | 为与人在共享空间中直接配合而设计；是否安全要看整个应用 |
| 自由度 | 确定位置所需的最少独立变量数 |
| 欠驱动 | 执行器少于自由度 |
| 示教再现 | 人带着走一遍，机器人记录后自动重复 |
| 额定负载 | 末端能搬运的最大质量，含夹爪，与重心位置有关 |
| 重复定位精度 | 同一指令反复执行时末端位置的分散范围，不等于绝对定位精度 |
