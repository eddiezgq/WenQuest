The main thread of this chapter can be summed up in one sentence: **a matrix is a linear transformation, and to study a matrix is to study what this transformation turns into what.** Everything else answers this question from a different angle.

We started from the velocity relation of the planar 2R arm and saw that the end-effector velocity is a linear combination of the columns of the Jacobian matrix, and that matrix multiplication is two transformations carried out one after the other. The determinant is the factor by which a transformation scales areas; when it is zero, the transformation flattens the plane, the matrix is not invertible, and the robot arm is in a singular configuration. The trace is the sum of the diagonal entries and satisfies tr(AB) = tr(BA). From this property and det(AB) = det A det B it follows that, although the matrices $P^{-1}AP$ of the same transformation in different frames all differ, the trace, the determinant and the eigenvalues do not change; they are properties of the transformation itself, and Chapter 4 uses exactly this to find the angle of rotation from the trace.

Eigenvectors are the directions that a transformation only stretches and does not turn. The eigenvalues of a symmetric matrix (stiffness, inertia, covariance) are all real and its eigenvectors are mutually orthogonal; in the frame they form, the matrix becomes diagonal: this is the spectral theorem. A non-symmetric matrix may have only complex eigenvalues, or too few eigenvectors. The singular value decomposition holds for every matrix: every linear transformation is "turn, stretch along mutually perpendicular directions, then turn again", taking the unit circle to an ellipse. The semi-axes of the ellipse are the singular values, and they give the 2-norm, the rank and the condition number of the matrix, and the manipulability of a robot arm.

When there are more equations than unknowns and the data carry errors, the method of least squares takes the solution with the smallest sum of squared residuals; geometrically it projects the right-hand-side vector orthogonally onto the range, and algebraically it is the normal equations. When there are fewer equations than unknowns, the pseudoinverse gives the solution of smallest length. Both are expressed in a unified way by the singular value decomposition. The null space and the range answer when a system has solutions and how many; the rank–nullity theorem says that the dimension of the input space is conserved between "the part squashed to zero" and "the part carried one-to-one". For a redundant robot arm, the null space is the self-motion that leaves the end-effector still, and null-space projection lets the arm do something else while carrying out its end-effector task. Finally, the Gram–Schmidt process tidies a set of directions into mutually orthogonal unit vectors, and its matrix form is the QR decomposition; it keeps the first direction and pushes the error onto the later directions, something to bear in mind both when teaching a frame and when correcting an orientation matrix.

| Concept | In one sentence |
|---|---|
| Linear combination | Several vectors, each multiplied by a number, then added; Ax is a linear combination of the columns of A |
| Linear transformation | A mapping that preserves linear combinations; column j of its matrix is the image of basis vector j |
| Determinant | The signed factor by which areas (volumes) are enlarged; if it is zero, the matrix is not invertible |
| Trace | The sum of the diagonal entries; equals the sum of the eigenvalues and does not change with the frame |
| Similar matrices | Matrices of the same linear transformation in different bases |
| Eigenvector | A direction that the transformation only stretches and does not turn |
| Positive definite matrix | $x^{\mathsf T}Ax > 0$ for every non-zero x; for a symmetric matrix, equivalent to all eigenvalues being positive |
| Singular value | The length of a semi-axis of the image of the unit circle (an ellipse) |
| Condition number | The ratio of the largest to the smallest singular value; the factor by which errors are amplified |
| Manipulability | The product of the semi-axes of the manipulability ellipse; zero at a singular configuration |
| Least-squares solution | The solution with the smallest sum of squared residuals; the residual is perpendicular to the range |
| Pseudoinverse | Reverses each singular-value channel, leaving zero channels at zero |
| Null space | The inputs the matrix squashes to zero; the self-motion directions of a redundant robot arm |
| Range | All the outputs the matrix can produce; all the velocities the end-effector can reach |
| Orthogonal matrix | Orthonormal columns, inverse equal to transpose, preserves lengths and angles |
| Gram–Schmidt process | Subtract the projections one by one, then normalize; the first direction is kept exactly |
