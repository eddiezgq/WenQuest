title: 本章小结
---

本章的主线可以用一句话概括：**矩阵是一个线性变换，研究矩阵就是研究这个变换把什么变成了什么。** 其余的内容，都是从不同的角度回答这个问题。

我们从平面 2R 臂的速度关系出发，看到末端速度是雅可比矩阵各列的线性组合，矩阵乘法就是两个变换接连进行。行列式衡量变换把面积放大多少倍，它为零时变换把平面压扁，矩阵不可逆，机械臂处于奇异位形。迹是对角元之和，满足 tr(AB) = tr(BA)。由这条性质和 det(AB) = det A det B 可知，同一个变换在不同坐标系中的矩阵 $P^{-1}AP$ 虽然各不相同，迹、行列式和特征值却都不变；它们是变换本身的属性，第 4 章正是据此由迹求出转角。

特征向量是变换只伸缩、不转向的方向。对称矩阵（刚度、惯量、协方差）的特征值都是实数，特征向量两两正交，在由它们组成的坐标系中矩阵成为对角矩阵，这是谱定理。不对称的矩阵则可能只有复特征值，或者特征向量不够。奇异值分解对任何矩阵都成立：任何线性变换都是“转动、沿互相垂直的方向伸缩、再转动”，把单位圆变成椭圆。椭圆的半轴就是奇异值，它们给出了矩阵的 2-范数、秩、条件数，以及机械臂的可操作度。

方程比未知数多又带误差时，最小二乘法取残差平方和最小的解，几何上是把右端向量正交投影到值域上，代数上是正规方程。方程比未知数少时，伪逆给出长度最小的解。两者都由奇异值分解统一地表达。零空间和值域回答了方程什么时候有解、有多少解；秩-零化度定理说明输入空间的维数在“压成零的部分”和“一一对应的部分”之间守恒。对冗余机械臂，零空间就是末端不动的自运动，零空间投影让手臂在完成末端任务的同时做别的事。最后，格拉姆-施密特法把一组方向整理成两两正交的单位向量，矩阵形式是 QR 分解；它保留第一个方向、把误差推给后面的方向，这一点在示教坐标系和修正姿态矩阵时都要心中有数。

| 概念 | 一句话 |
|---|---|
| 线性组合 | 若干向量各乘一个数再相加；Ax 是 A 的各列的线性组合 |
| 线性变换 | 保持线性组合的映射；它的矩阵的第 j 列是第 j 个基向量的像 |
| 行列式 | 面积（体积）的放大倍数，带符号；为零则不可逆 |
| 迹 | 对角元之和；等于特征值之和，换坐标系不变 |
| 相似矩阵 | 同一个线性变换在不同基下的矩阵 |
| 特征向量 | 变换只伸缩、不转向的方向 |
| 正定矩阵 | 对一切非零 x 有 $x^{\mathsf T}Ax > 0$；对称时等价于特征值全正 |
| 奇异值 | 单位圆的像（椭圆）的半轴长 |
| 条件数 | 最大与最小奇异值之比；误差放大的倍数 |
| 可操作度 | 可操作度椭圆各半轴之积；奇异位形处为零 |
| 最小二乘解 | 残差平方和最小的解；残差垂直于值域 |
| 伪逆 | 把每个奇异值通道反过来，零通道仍为零 |
| 零空间 | 被矩阵压成零的输入；冗余机械臂的自运动方向 |
| 值域 | 矩阵能产生的全部输出；末端能达到的全部速度 |
| 正交矩阵 | 各列标准正交，逆等于转置，保持长度与夹角 |
| 格拉姆-施密特法 | 逐个减去投影再归一化；第一个方向完全保留 |
