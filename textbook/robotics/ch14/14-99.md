title: 本章小结
---

逆运动学是由末端位姿求关节变量。它与正运动学的根本区别，在于答案不唯一：目标在工作空间之外时无解，在之内时往往有好几组解，同一个位姿可以由形态完全不同的手臂姿势达到。所以逆解的任务是求出全部的解，再按约束挑选。一般几何的六轴臂至多有 16 组解，要解一个 16 次多项式；工业机械臂则通过特殊的几何结构，把逆解化为几个简单的步骤，每一步都能写成公式。

本章的方法可以用一句话概括：利用转动的不变量消去关节。绕一根轴转动时，轴上的点不动，到轴上一点的距离不变，沿轴方向的分量不变。把方程作用在末端几根轴的公共点上，末端的关节就消失了；取到首端几根轴的公共点的距离，首端的关节就不起作用了；几根轴互相平行时，沿它们方向的分量与这几个关节都无关。剩下的问题就是三个帕登-卡汉子问题：绕一根轴把点转到目标，绕两根相交的轴把点转到目标，绕一根轴转动使点到另一点的距离为给定值。

平面 2R 臂是最小的例子：末端到基座的距离给出肘部转角，有正负两个值，即肘上与肘下；再把末端转到目标给出肩部转角。皮珀准则说明，六轴臂中只要有三根相邻的轴交于一点或互相平行，逆解就可以化为不高于四次的方程；常见的工业机械臂还有更多的特殊结构，可以直接拆成子问题。球形手腕的三根腕部轴交于腕心，前三个关节定位置、后三个关节定姿态；UR5e 的关节 2、3、4 互相平行，逆解分为 θ₁、(θ₅, θ₆)、(θ₃, θ₂, θ₄) 三步，每步两个分支，至多 8 组解。SCARA 是平面 2R 加升降和转角，有左手、右手两种构型；Delta 的每条支链是一次子问题 3。

求出全部的解以后，选择同样重要：离当前关节角最近，在一段连续的运动中保持同一支，不超限位，不发生碰撞。两支解只在奇异位形处相遇，UR5e 的肩部、肘部、手腕三种奇异正好对应逆解中的三个“二选一”。手臂接近奇异位形时，关节角对目标位置极其敏感，这是逆解问题本身的性质，第 16 章将从雅可比矩阵出发系统地讨论。

| 概念 | 一句话 |
|---|---|
| 逆运动学 | 由末端位姿求全部关节变量 |
| 多解 | 同一末端位姿对应几组关节变量（几种构型） |
| 肘上/肘下 | 肘点在肩—腕（或基座—末端）连线上方或下方的两种构型 |
| 手腕翻转 | 腕部关节换到另一组解，末端姿态不变 |
| 解析解 | 全部的解可以用有限次代数运算和三角函数写出 |
| 帕登-卡汉子问题 | 由转动构成的三个基本几何问题，旋量法求解析逆解的工具 |
| 皮珀准则 | 三根相邻的关节轴交于一点或互相平行，则有解析逆解 |
| 球形手腕、腕心 | 腕部三根轴交于一点；这一点只由前三个关节决定 |
| 右手构型、左手构型 | SCARA 俯视时肘部在基座—目标连线右侧或左侧的两种构型 |
