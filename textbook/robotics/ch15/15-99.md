title: 本章小结
---

数值逆运动学的思路只有一句话：从一个初值出发，看末端离目标差多少，按“关节转一点、末端动多少”的关系修正关节角，反复进行，直到误差足够小。本章的工作，是把这句话在位姿的李群 SE(3) 上说准确，并回答由此产生的几个问题：怎样修正，收敛多快，奇异时怎么办，有关节限位和多个目标时怎么办，初值怎样选。

“差多少”用误差旋量度量：$[\mathcal V_b] = \log(T^{-1}T_d)$ 是从当前末端坐标系走到目标所需的螺旋运动，在末端坐标系中表示，与基座放在哪里无关。“关节转一点、末端动多少”由物体雅可比给出：它的第 i 列是关节 i 此刻的旋量轴在此刻的末端坐标系中的表示，由指数积公式直接求出。于是牛顿-拉夫森法就是解 $J_b\Delta\theta = \mathcal V_b$。物体雅可比并不是误差旋量的精确导数，但两者之差与误差成正比，所以迭代在解附近仍然二次收敛。UR5e 的数值解与第 14 章的解析解在双精度意义下完全一致；对标定后不再有解析解的手臂，以名义解析解为初值，两三步就得到精确解。

牛顿法在奇异附近给出过大的步子。雅可比转置法把误差当作一根拉着末端的弹簧，用 $J^{\mathsf T}$ 把弹簧力换成关节力矩，误差只减不增，每一步都有界，代价是线性收敛，速度由条件数的平方决定。阻尼最小二乘在两者之间折中：沿每个奇异方向，牛顿法的增益是 1/σ，雅可比转置法是 ασ，阻尼最小二乘是 σ/(σ² + λ²)，大奇异值方向与牛顿法相同，小奇异值方向近乎放弃，步长不超过 ‖e‖/(2λ)。实时控制中用可变阻尼，只在奇异附近加阻尼；离线求解用按增益比自动调整阻尼的 LM 法。

关节限位把逆解限制在关节空间的一个盒子里。每步截断会让迭代卡在不是驻点的地方；每步解一个有界最小二乘，则每一步都是下降方向，停下来的地方一定是误差在盒子上的驻点。冗余臂可以在零空间里做附加的事，例如让关节远离限位，但这只是引导，不是保证。多个目标冲突时，加权让每个目标都差一点；任务优先级先满足主任务，次任务只在主任务的零空间里改进，做不到时停在算法奇异上，需要阻尼。

数值解给出哪一组解由初值决定。远离解时牛顿法乱跳，吸引域支离破碎；限步长使结果整齐得多；延拓法让目标一点一点移过去，只要路径不碰奇异位形，就留在出发时的那一支上。实时控制用上一周期的解作初值，一两次迭代就够；离线求解失败时换初值重试，m 次中至少成功一次的概率约为 $1 - (1 - p)^m$。目标不可达时，任何初值都不会成功，要及早判断并报告最近可达的姿态。

| 概念 | 一句话 |
|---|---|
| 数值解 | 从初值出发迭代求得的逆解，一次一组，哪一组取决于初值 |
| 误差旋量 | 当前末端位姿到目标位姿的螺旋运动，在末端坐标系中表示；为零当且仅当到达 |
| 物体雅可比 | 各关节此刻的旋量轴在此刻的末端坐标系中的表示，排成 6×n 矩阵 |
| 空间雅可比 | 同样的旋量轴在基座坐标系中的表示，$J_s = [\mathrm{Ad}_T]J_b$ |
| 牛顿-拉夫森法 | 每步解 $J_b\Delta\theta = \mathcal V_b$，解附近二次收敛 |
| 雅可比转置法 | 每步沿 $J^{\mathsf T}e$ 走，相当于虚拟弹簧拉手臂；误差不增，线性收敛 |
| 李雅普诺夫函数 | 非负、只在目标处为零、沿运动不增的量，用来证明稳定或收敛 |
| 闭环逆运动学 | 每个控制周期把末端误差乘以增益，经雅可比的转置或（阻尼）逆变成关节速度 |
| 分解运动速率控制 | 用雅可比的逆把末端速度指令分解为各关节速度 |
| 阻尼最小二乘 | 在“消除误差”与“步子小”之间折中，步长有与形态无关的上界 |
| 可变阻尼 | 只在接近奇异时加阻尼，远离奇异时与精确求逆相同 |
| 关节限位 | 每个关节允许的取值范围；全部限位构成关节空间中的一个盒子 |
| 有界最小二乘 | 未知数各有上下限的最小二乘，每步守住限位的工具 |
| 梯度投影法 | 把附加目标的梯度投影到零空间，不影响末端的同时改进它 |
| 加权最小范数 | 用随限位而变的权重，让接近限位的关节少动 |
| 任务优先级 | 先满足主任务，次任务只在主任务的零空间里改进 |
| 算法奇异 | 各任务的雅可比都满秩，叠在一起却降秩：任务之间冲突 |
| 吸引域 | 收敛到某一组解的全部初值 |
| 延拓法 | 让目标从起点逐段移到终点，每段以上一段的解为初值 |
| 热启动 | 用上一次（上一控制周期）的解作初值 |
| 随机重启 | 失败后换随机初值重试 |
