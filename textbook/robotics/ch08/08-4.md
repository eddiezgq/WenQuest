### 8.4.1 问题的提出：局部最优够不够

8.1 节的逆运动学目标函数有两个极小点、三个鞍点和一个极大点，从不同的初值出发，迭代会走到不同的地方。对逆运动学，这还不算严重：两个极小点都是逆解，选哪一个取决于需要。在另一些问题中，局部最优可能非常糟糕。

设想数字工厂车间里的一台 AGV，要从车间左下角绕过一排货架，开到右上角的工位。若把路径上的航点作为决策变量，把“路径短而平顺”作为目标函数，把“不碰货架”作为约束，用 8.1 至 8.3 节的方法求解，结果可能取决于初值：从货架一侧出发的迭代，停在这一侧的某条路径上；从另一侧出发，停在另一侧。更糟的是，算法停下来时，我们无从知道还有没有更好的路径。

有一类问题没有这个烦恼：它们的每个局部极小点都是全局极小点，而且有可靠、高效的算法，能在给定精度内算出最优值，并给出精度的证明。这就是凸优化问题。它的理论在 20 世纪 50 年代以后逐步成熟，1994 年涅斯捷罗夫（Yu. Nesterov）和涅米罗夫斯基（A. Nemirovskii）证明了一大类凸问题可以用内点法在多项式时间内求解。今天，凸优化已经是机器人运动规划、控制、估计中的基本工具。博伊德（S. Boyd）和范登伯格（L. Vandenberghe）在他们的教材中说，应用凸优化的难点和技巧不在求解，而在把问题认出来、写成凸的形式。本节先给出凸集、凸函数的定义和基本性质，证明凸问题局部最优即全局最优，再介绍对偶和障碍函数法，最后用两个例子说明怎样把避障写成凸问题。

### 8.4.2 凸集与凸函数

**定义 8.4.1（凸集）** 集合 $C \subseteq \mathbb R^n$ 称为**凸集**，若对任意 $x, y \in C$ 和任意 $s \in [0, 1]$，

$$
s\,x + (1 - s)\,y \in C . \tag{8.4.1}
$$

当 s 从 0 变到 1，$sx + (1-s)y$ 从 y 走到 x，画出连接两点的线段。所以凸集就是“任意两点之间的线段都在集合内”的集合（图 8.4.1 (a)）。实心的圆、椭圆、正方形、三角形都是凸集；圆环、L 形、月牙形不是。图 8.4.1 (b) 是车间中绕过货架的可通行区域，起点和终点的连线穿过了货架，所以它不是凸集。

::: 图 8.4.1
src: fig8_4_1
说明: (a) 凸集：任意两点的连线都在集合内；(b) 非凸集：绕过货架的可通行区域，连线穿过货架；(c) 凸函数：弦在图像上方；(d) 非凸函数：平面 2R 臂逆运动学目标函数沿两组逆解 A、B 连线的取值，弦（f = 0）在图像下方
:::

机器人中最常见的凸集由线性不等式给出。对非零向量 a 和数 b，集合 $\{x: a^{\mathsf T}x = b\}$ 称为**超平面**（二维时是直线，三维时是平面），$\{x : a^{\mathsf T}x \le b\}$ 称为**半空间**，a 是它的外法向。半空间是凸集：若 $a^{\mathsf T}x \le b$、$a^{\mathsf T}y \le b$，则 $a^{\mathsf T}(sx + (1-s)y) = s\,a^{\mathsf T}x + (1-s)\,a^{\mathsf T}y \le sb + (1-s)b = b$。有限个半空间的交集 $\{x: Ax \le b\}$ 称为**多面体**，平面上的凸多边形、空间中的长方体和棱柱都是多面体。

**定理 8.4.1** 任意多个凸集的交集是凸集。因此多面体是凸集。

*证明*　设 x、y 属于每个凸集 $C_\alpha$，则对每个 α，线段 $sx + (1-s)y$ 都在 $C_\alpha$ 中，因而在它们的交集中。　∎

**定义 8.4.2（凸函数）** 设 $f: C \to \mathbb R$，C 是凸集。若对任意 $x, y \in C$ 和 $s \in [0, 1]$，

$$
f\big(s\,x + (1-s)\,y\big) \le s\,f(x) + (1-s)\,f(y) , \tag{8.4.2}
$$

称 f 为**凸函数**；若 $x \ne y$、0 < s < 1 时不等式严格成立，称 f 为**严格凸函数**。

式 (8.4.2) 的右边是连接 (x, f(x)) 和 (y, f(y)) 的弦上的点，左边是函数图像上同一位置的点，所以凸函数就是“弦总在图像上方”的函数（图 8.4.1 (c)）。式 (8.4.2) 称为**詹森不等式**，丹麦数学家詹森（J. L. W. V. Jensen）在 1906 年系统研究了满足它的函数。

**算例 8.4.1** 平面 2R 臂逆运动学的目标函数 $f(\theta) = \tfrac12\|p(\theta) - p_d\|^2$ 不是凸函数。取两组逆解 $\theta_A$、$\theta_B$，$f(\theta_A) = f(\theta_B) = 0$；它们的中点处，程序 8.4.1 算得 $f = {{ex8_4.f_mid:.4f}}$ m²，大于两端的平均值 0，詹森不等式不成立（图 8.4.1 (d)）。这也说明它的“谷底”不止一处。

直接用定义判断凸性往往不方便。对可微函数，有下面两个等价的条件。

**定理 8.4.2（一阶条件）** 设 f 在开凸集 C 上可微。f 是凸函数，当且仅当对任意 $x, y \in C$，

$$
f(y) \ge f(x) + \nabla f(x)^{\mathsf T}(y - x) . \tag{8.4.3}
$$

*证明*　设 f 是凸函数。由式 (8.4.2)，对 0 < s ≤ 1，$f(x + s(y - x)) \le f(x) + s\,[f(y) - f(x)]$，即 $\frac{f(x + s(y-x)) - f(x)}{s} \le f(y) - f(x)$；令 $s \to 0$，左边趋于方向导数 $\nabla f(x)^{\mathsf T}(y - x)$（定理 8.1.1），得式 (8.4.3)。反之，设式 (8.4.3) 成立，记 $z = sx + (1-s)y$。对 x 和 z、y 和 z 分别用式 (8.4.3)：$f(x) \ge f(z) + \nabla f(z)^{\mathsf T}(x - z)$，$f(y) \ge f(z) + \nabla f(z)^{\mathsf T}(y - z)$。第一式乘 s、第二式乘 1 − s 相加，梯度项为 $\nabla f(z)^{\mathsf T}(sx + (1-s)y - z) = 0$，得 $sf(x) + (1-s)f(y) \ge f(z)$。　∎

式 (8.4.3) 的几何意义是：凸函数的图像总在它的每一条切线（切平面）上方。由此立刻看出：若 $\nabla f(x^*) = 0$，则对一切 y 有 $f(y) \ge f(x^*)$。也就是说，可微凸函数的驻点一定是全局极小点。8.1 节中“驻点可能是鞍点”的麻烦，对凸函数不存在。

**定理 8.4.3（二阶条件）** 设 f 在开凸集 C 上二阶偏导数连续。f 是凸函数，当且仅当对一切 $x \in C$，黑塞矩阵 $\nabla^2 f(x)$ 半正定。

*证明*　设黑塞矩阵处处半正定。由定理 8.1.4 证明中的拉格朗日余项形式，$f(y) = f(x) + \nabla f(x)^{\mathsf T}(y-x) + \tfrac12(y-x)^{\mathsf T}\nabla^2 f(\xi)(y-x)$，ξ 在 x、y 之间的线段上（在 C 内），最后一项非负，于是式 (8.4.3) 成立，f 是凸函数。反之，若某点 x 处存在 d 使 $d^{\mathsf T}\nabla^2 f(x)d < 0$，由式 (8.1.8)，s 足够小时 $f(x + sd) < f(x) + s\nabla f(x)^{\mathsf T}d$，与式 (8.4.3) 矛盾。　∎

由定理 8.4.3，二次函数 $\tfrac12x^{\mathsf T}Qx + c^{\mathsf T}x$ 是凸函数当且仅当 Q 半正定；最小二乘的目标函数 $\tfrac12\|Ax - b\|^2$ 的黑塞矩阵是 $A^{\mathsf T}A$，总是凸函数（程序 8.4.1 对一个随机的 A 抽查了 1000 次詹森不等式）。由定义还可以直接验证：任何范数 ‖x‖ 是凸函数（由三角不等式），凸函数的非负加权和是凸函数，若干凸函数逐点取最大值仍是凸函数。这些规则让我们可以像搭积木一样构造并识别凸函数。

### 8.4.3 凸优化问题：局部最优就是全局最优

**定义 8.4.3（凸优化问题）** 形如

$$
\min_x\ f(x) \qquad \text{s.t.}\quad g_i(x) \le 0\ \ (i = 1, \ldots, m), \qquad Ex = d \tag{8.4.4}
$$

的问题，若 f 和各个 $g_i$ 都是凸函数，称为**凸优化**问题。

等式约束只能是线性的，这一点很重要：$h(x) = 0$ 等价于 $h \le 0$ 且 $-h \le 0$，要求 h 和 −h 都是凸函数，只有线性函数满足。凸问题的可行集是凸集：每个 $\{x: g_i(x) \le 0\}$ 是凸集（若 $g_i(x) \le 0$、$g_i(y) \le 0$，由式 (8.4.2)，$g_i(sx + (1-s)y) \le 0$），线性方程的解集是凸集，由定理 8.4.1，它们的交集是凸集。8.3 节的凸二次规划是凸问题；目标函数和约束都是线性的问题称为线性规划，也是凸问题。

**定理 8.4.4** 凸优化问题的任一局部极小点都是全局极小点。若 f 是严格凸函数，全局极小点至多有一个。

*证明*　设 $x^*$ 是局部极小点，但存在可行点 y 使 $f(y) < f(x^*)$。对 0 < s ≤ 1，$z_s = sy + (1-s)x^*$ 可行（可行集是凸集），且由式 (8.4.2)，$f(z_s) \le sf(y) + (1-s)f(x^*) < f(x^*)$。s 足够小时 $z_s$ 离 $x^*$ 任意近，与局部极小矛盾。若 f 严格凸而 $x_1 \ne x_2$ 都是全局极小点，函数值都是 $p^*$，则中点可行且 $f(\tfrac12x_1 + \tfrac12x_2) < p^*$，矛盾。　∎

**定理 8.4.5（KKT 条件的充分性）** 设问题 (8.4.4) 是凸问题，f、$g_i$ 可微。若可行点 $x^*$ 与乘子 λ、$\mu \ge 0$ 满足 KKT 条件 (8.3.4)，则 $x^*$ 是全局极小点。

*证明*　对任一可行点 x，由定理 8.4.2 和驻点条件，

$$
f(x) \ge f(x^*) + \nabla f(x^*)^{\mathsf T}(x - x^*) = f(x^*) - \sum_i\mu_i\nabla g_i(x^*)^{\mathsf T}(x - x^*) - \lambda^{\mathsf T}E(x - x^*) .
$$

E(x − x*) = 0；再对凸函数 $g_i$ 用式 (8.4.3)，$\nabla g_i(x^*)^{\mathsf T}(x - x^*) \le g_i(x) - g_i(x^*)$，乘以 $\mu_i \ge 0$ 后不等号方向不变。由互补松弛 $\mu_i g_i(x^*) = 0$，得 $f(x) \ge f(x^*) - \sum_i\mu_i g_i(x) \ge f(x^*)$，最后一步用了 $\mu_i \ge 0$、$g_i(x) \le 0$。　∎

定理 8.3.1 的充分性部分，就是这个定理在二次规划上的特例。注意这个定理只说“满足 KKT 条件就是最优”，不需要任何约束规范。反过来，凸问题的最优点不一定有 KKT 乘子：8.3.2 节的例子 $\min x_1$ s.t. $x_1^2 + x_2^2 \le 0$ 就是一个凸问题。8.4.5 节将说明，再加上斯莱特条件，KKT 条件对凸问题就既必要又充分。

### 8.4.4 分离超平面与法卡斯引理

凸集最有用的几何性质，是可以用一个超平面把它和外面的点隔开。

**定理 8.4.6（分离超平面定理）** 设 C 是非空闭凸集，点 y ∉ C。则存在非零向量 a 和数 b，使

$$
a^{\mathsf T}x \le b < a^{\mathsf T}y \qquad \text{对一切}\ x \in C . \tag{8.4.5}
$$

*证明*　设 $x_0$ 是 C 中离 y 最近的点（C 是闭集，最近点存在，这是分析学中的标准结论）。令 $a = y - x_0 \ne 0$，$b = a^{\mathsf T}x_0$。任取 x ∈ C，对 0 < t ≤ 1，$z = x_0 + t(x - x_0) \in C$，所以 $\|y - z\|^2 \ge \|y - x_0\|^2$。展开，

$$
\|a - t(x - x_0)\|^2 - \|a\|^2 = -2t\,a^{\mathsf T}(x - x_0) + t^2\|x - x_0\|^2 \ge 0 .
$$

两边除以 t 再令 t → 0，得 $a^{\mathsf T}(x - x_0) \le 0$，即 $a^{\mathsf T}x \le b$。又 $a^{\mathsf T}y - b = a^{\mathsf T}(y - x_0) = \|a\|^2 > 0$。　∎

证明里的构造很直观：从 y 向 C 作“垂线”，垂足是 $x_0$，过 $x_0$ 作垂直于 $y - x_0$ 的超平面，C 全在一侧，y 在另一侧。同样的道理可以推广到两个不相交的闭凸集：只要其中一个有界，它们之间就存在严格分离的超平面（对两集合中距离最近的一对点作中垂面即可）。8.4.6 节的算例会用到它。现在用定理 8.4.6 补上 8.3 节欠下的证明。

*引理 8.3.1（法卡斯引理）的证明*　记 $K = \{\sum_j\lambda_je_j + \sum_i\mu_ia_i : \lambda_j \in \mathbb R,\ \mu_i \ge 0\}$。K 是凸集，且对正数的乘法封闭（是一个锥）；由有限个向量生成的锥是闭集（证明见 Boyd 与 Vandenberghe 的书或 Rockafellar 的《凸分析》）。要证的是 $-g \in K$。若不然，由定理 8.4.6，存在 d 和 b 使 $d^{\mathsf T}k \le b < -d^{\mathsf T}g$ 对一切 k ∈ K 成立。因 0 ∈ K，b ≥ 0，所以 $g^{\mathsf T}d < 0$。又若某个 k ∈ K 使 $d^{\mathsf T}k > 0$，把 k 放大足够多倍（仍在 K 中）就会超过 b，所以对一切 k ∈ K 有 $d^{\mathsf T}k \le 0$。取 $k = a_i$ 得 $a_i^{\mathsf T}d \le 0$；取 $k = \pm e_j$ 得 $e_j^{\mathsf T}d = 0$。这样的 d 满足引理的前提，却使 $g^{\mathsf T}d < 0$，矛盾。　∎

### 8.4.5 对偶

对问题 (8.4.4)，写出拉格朗日函数 $L(x, \lambda, \mu) = f(x) + \sum_i\mu_ig_i(x) + \lambda^{\mathsf T}(Ex - d)$。

**定义 8.4.4（拉格朗日对偶函数）** 对 μ ≥ 0，

$$
q(\lambda, \mu) = \inf_x\ L(x, \lambda, \mu) \tag{8.4.6}
$$

称为**拉格朗日对偶函数**，inf 表示下确界（对所有 x 取最小值；最小值不一定取得时取下确界）。

**定理 8.4.7（弱对偶性）** 对任意 μ ≥ 0、任意 λ 和任意可行点 x，

$$
q(\lambda, \mu) \le f(x) . \tag{8.4.7}
$$

因此 $q(\lambda, \mu) \le p^*$，$p^*$ 是问题 (8.4.4) 的最优值。

*证明*　x 可行，$g_i(x) \le 0$、Ex = d，又 $\mu_i \ge 0$，所以 $L(x, \lambda, \mu) = f(x) + \sum_i\mu_ig_i(x) \le f(x)$；而 q 是 L 对 x 的下确界，$q \le L(x, \lambda, \mu)$。　∎

弱对偶性对任何问题都成立，不需要凸性。它的用处在于给出最优值的下界：手里有一个可行点 x 和一组乘子 (λ, μ)，就知道 $f(x) - p^* \le f(x) - q(\lambda, \mu)$，右边称为**对偶间隙**。对偶间隙小，就证明了 x 离最优不远，而这不需要知道 $p^*$ 本身。求最好的下界，$\max_{\mu\ge0, \lambda} q(\lambda, \mu)$，称为**对偶问题**，原来的问题相应地称为原问题。式 (8.4.7) 称为**弱对偶性**；若两者的最优值相等，称**强对偶性**成立。对凸问题，若存在一个严格可行点（所有 $g_i(x) < 0$ 且 Ex = d），强对偶性一定成立，而且最优值有限时对偶问题的最优解 $(\lambda^*, \mu^*)$ 存在，它们正是原问题最优点处的 KKT 乘子。这个条件称为**斯莱特条件**，由斯莱特（M. Slater）在 1950 年给出（证明见 Boyd 与 Vandenberghe 的《Convex Optimization》中关于强对偶的论述）。它是凸问题中最常用的约束规范：线性约束之外，只要能找到一个严格满足全部不等式约束的点，KKT 条件就是最优的充分必要条件。上面的反例 $x_1^2 + x_2^2 \le 0$ 没有严格可行点，所以不满足斯莱特条件。

### 8.4.6 障碍函数法

凸问题怎样求解？对线性不等式约束 $a_i^{\mathsf T}x \le b_i$，一个自然的想法是把约束“化进”目标函数：在可行域的边界上筑一道“墙”，使迭代点永远不会越过它。取对数障碍

$$
\phi(x) = -\sum_{i=1}^{m}\log\big(b_i - a_i^{\mathsf T}x\big) ,
$$

它在可行域内部有定义，点趋于任一边界时 φ → +∞。用它近似原问题：

$$
\min_x\ t\,f(x) + \phi(x) , \tag{8.4.8}
$$

t > 0 是一个参数。t 越大，目标函数的分量越重要，障碍的影响越小，式 (8.4.8) 的解 $x^*(t)$ 越接近原问题的解。$t\,f + \phi$ 是凸函数（−log 是凸函数，凸函数之和仍是凸函数），没有约束，可以用 8.1 节的牛顿法求解；线搜索时只要保证新点仍在可行域内部即可。随 t 变化，$x^*(t)$ 画出一条曲线，称为**中心路径**。

**定理 8.4.8** 设问题只有线性不等式约束（可另有线性等式约束），f 是可微凸函数，$x^*(t)$ 是式 (8.4.8) 的解。则

$$
f(x^*(t)) - p^* \le \frac{m}{t} , \tag{8.4.9}
$$

其中 m 是不等式约束的个数。

*证明*　$x^*(t)$ 满足式 (8.4.8) 的驻点条件：$t\nabla f(x^*(t)) + \sum_i a_i/(b_i - a_i^{\mathsf T}x^*(t)) = 0$。令

$$
\mu_i = \frac{1}{t\,\big(b_i - a_i^{\mathsf T}x^*(t)\big)} > 0 , \tag{8.4.10}
$$

驻点条件成为 $\nabla f(x^*(t)) + \sum_i\mu_ia_i = 0$。这说明 $x^*(t)$ 是凸函数 $L(x, \mu) = f(x) + \sum_i\mu_i(a_i^{\mathsf T}x - b_i)$ 的驻点，也就是它的全局极小点（定理 8.4.2 之后的说明）。于是 $q(\mu) = L(x^*(t), \mu) = f(x^*(t)) - \sum_i\mu_i(b_i - a_i^{\mathsf T}x^*(t)) = f(x^*(t)) - m/t$。由弱对偶性 $q(\mu) \le p^*$，得式 (8.4.9)。有线性等式约束时，在 L 中再加一项 $\lambda^{\mathsf T}(Ex - d)$，论证相同。　∎

这个证明顺便给出了对偶间隙的上界 m/t，以及一组近似的乘子 (8.4.10)。由此得到障碍函数法：从一个严格可行点和不大的 t 出发，用牛顿法求出 $x^*(t)$（称为定心），然后把 t 放大若干倍（如 10 倍），以上一个中心为初值再定心，直到 m/t 小于要求的精度。用对数函数作障碍的想法由弗里施（R. Frisch）在 1955 年提出；菲亚科（A. V. Fiacco）和麦考密克（G. P. McCormick）在 1968 年的书中系统发展了这种“序列无约束最小化”方法；1984 年卡马卡（N. Karmarkar）提出了线性规划的多项式时间内点算法，引发了内点法的研究热潮；涅斯捷罗夫与涅米罗夫斯基的自和谐函数理论则证明了障碍函数法对一大类凸问题的多项式复杂度。这类在可行域内部前进的方法统称**内点法**，本节介绍的是其中最简单的**障碍函数法**。

**算例 8.4.2** 夹爪与障碍物之间的最短距离。俯视图中，夹爪的投影是一个 12 cm × 6 cm、转过 25° 的矩形，障碍物是一个三角形，都是凸多边形，分别写成 $A_1u \le b_1$、$A_2w \le b_2$（每条边一个不等式，外法向为单位向量）。两者之间的最短距离是

$$
\min_{u, w}\ \tfrac12\|u - w\|^2 \qquad \text{s.t.}\quad A_1u \le b_1,\quad A_2w \le b_2 , \tag{8.4.11}
$$

一个 4 个变量、7 个不等式约束的凸二次规划。从两个多边形的形心（严格可行）出发，程序 8.4.1 的障碍函数法经过 {{ex8_4.outer_d}} 次定心、共 {{ex8_4.steps_d}} 个牛顿步，得到最近的两点 $u^* = {{ex8_4.u}}$ m（在夹爪的一条边上）和 $w^* = {{ex8_4.w}}$ m（障碍物的一个顶点），最短距离 {{ex8_4.dist_mm:.3f}} mm，对偶间隙的上界 $m/t = {{ex8_4.gap_d:sci0}}$。作为独立核对，程序枚举所有“顶点到边”的距离，取最小值，与它相差不到 $10^{-8}$ m。

由式 (8.4.10) 得到的乘子中，只有三个不为零：夹爪那条边的乘子 {{ex8_4.mu1:.4f}}，障碍物顶点处两条边的乘子 {{ex8_4.mu4:.4f}} 和 {{ex8_4.mu6:.4f}}。驻点条件给出 $w^* - u^* = A_1^{\mathsf T}\mu_1$：两点的连线沿夹爪那条边的外法向 $n = {{ex8_4.n}}$，恰是 $(\cos 25°, \sin 25°)$。过两点连线的中点、垂直于 n 的直线就是一条分离直线：程序验证了夹爪的所有顶点都在它的一侧，最近的顶点离直线 {{ex8_4.gap_G:.4f}} m；障碍物的所有顶点都在另一侧，最近的离直线 {{ex8_4.gap_O:.4f}} m，两者之和就是最短距离。这正是定理 8.4.6 所说的分离。图 8.4.2 画出了这条直线。

碰撞检测是运动规划中最耗时的计算（第 53 章）。把机器人和障碍物都近似为凸体，两两求距离，距离大于零就没有碰撞，乘子还告诉我们距离对位置的导数，可供优化算法使用。吉尔伯特（E. G. Gilbert）、约翰逊（D. W. Johnson）和基尔蒂（S. S. Keerthi）在 1988 年提出的 GJK 算法，专门利用凸体的几何结构快速求这个距离，是今天各种物理引擎和运动规划库的标准组件。

**算例 8.4.3** AGV 在凸走廊中的路径。图 8.4.3 中，车间的可通行区域是 L 形的，不是凸集。把它拆成两个凸区域：下方的走廊 $R_1$（上边是倾斜的货架边缘）和右侧的走廊 $R_2$。货架已按 AGV 的半径向外“膨胀”，所以只需把 AGV 当作一个点。路径由起点 $x_0$、终点 $x_{10}$ 和 9 个航点 $x_1, \ldots, x_9$ 连成；规定 $x_1, \ldots, x_5$ 在 $R_1$ 中，$x_5, \ldots, x_9$ 在 $R_2$ 中（$x_5$ 在两者的交集里）。问题是

$$
\min\ \sum_{k=0}^{9}\|x_{k+1} - x_k\|^2 \qquad \text{s.t.}\quad x_1, \ldots, x_5 \in R_1,\quad x_5, \ldots, x_9 \in R_2 , \tag{8.4.12}
$$

目标函数让航点均匀分布、路径短而直，是凸二次函数；约束是线性不等式，共 {{ex8_4.mc}} 个，变量 {{ex8_4.nvar}} 个。

这个建模的要点在于约束保证了整条路径不碰货架，而不只是航点不碰。相邻两个航点在同一个凸区域里，由凸集的定义 (8.4.1)，连接它们的线段整个在这个区域里；$x_5$ 同时属于两个区域，把两段接起来。程序 8.4.1 在每段线段上取 50 个点抽查，全部在相应的区域内。

用障碍函数法求解，{{ex8_4.outer_c}} 次定心、共 {{ex8_4.steps_c}} 个牛顿步。最优路径是两段直线：从起点直奔两个区域交界的拐角 $x_5 = {{ex8_4.corner}}$ m，再直奔终点，总长 {{ex8_4.length:.4f}} m。scipy 的 SLSQP 方法给出的解与它相差 ${{ex8_4.sc_err:sci0}}$ m。中心路径清楚地显示了障碍函数的作用：拐角航点 $x_5$ 在 t = 1 时位于 ${{ex8_4.cp1}}$ m，远离所有边界；t = 10 时到 ${{ex8_4.cp10}}$，t = 100 时到 ${{ex8_4.cp100}}$，t = 1000 时到 ${{ex8_4.cp1000}}$，一步步逼近拐角。

实际的运动规划中，难点在于两件事：怎样在障碍物之间找出足够大的凸区域，以及每个航点该属于哪个区域。前者有专门的算法，如戴茨（R. Deits）与特德雷克（R. Tedrake）的 IRIS 方法（2015）；后者是一个组合问题，常用混合整数规划或先用采样规划（第 53 章）找出一条粗路径。另一种思路是不预先划分区域，而在当前路径附近把避障约束线性化，反复求解凸问题，称为序列凸优化，舒尔曼（J. Schulman）等人 2014 年的 TrajOpt 就是这样规划机械臂运动的。

### 8.4.7 生活中的例子

在一个光滑的碗里放一颗小球，无论从哪里放，它都滚到同一个最低点。碗的形状是凸的：任意两点之间，碗底总在连线下方，球没有地方被卡住。在鸡蛋托盘上放一颗小球，它会落进最近的那个凹坑，从不同位置放，落点不同：托盘的形状不是凸的，每个凹坑都是一个局部最低点。

凸性带来的好处，在日常的决策中也看得到。把一笔钱分给几项开支，若每项开支的“不满意程度”都随投入的减少而加速增加（这正是凸函数），那么只要逐步把钱从“边际不满意”低的项目挪到高的项目，最后一定达到最好的分配，不会卡在某个“看似不错”的方案上。8.3.6 节的资产组合问题就是这样一个凸问题。

凸问题有全局最优的保证，但机器人中大量的问题本质上是非凸的，例如逆运动学和标定。下一节回到非凸问题，讨论其中最常见的一类：目标函数是残差平方和的非线性最小二乘。

**工程师笔记**

- 拿到一个优化问题，先问它是不是凸的。目标函数和不等式约束是凸函数、等式约束是线性的，就可以放心使用成熟的凸优化求解器（如 OSQP、ECOS、MOSEK，或 Python 的 CVXPY 建模工具），并相信算出的就是全局最优。
- 非凸问题常可以“凸化”：把非凸的可通行区域拆成若干凸区域；把机器人和障碍物用凸包、球或胶囊体近似；在当前解附近把非凸约束线性化，反复求解凸问题。
- 障碍函数法需要严格可行的起点。若没有现成的，可以先解一个辅助问题，例如 $\min s$ s.t. $a_i^{\mathsf T}x - b_i \le s$，s < 0 时就找到了严格可行点。
- 对偶间隙是停机的可靠依据。求解器报告的对偶间隙小于要求的精度，就证明了解的质量，不必与别的方法对比。
- 避障时要给障碍物留余量：按机器人的尺寸、定位误差和控制误差把障碍物膨胀，否则最优路径会恰好擦着障碍物的边角通过，如算例 8.4.3 的拐角。
