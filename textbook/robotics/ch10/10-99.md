title: 本章小结
---

本章的主线可以用一句话概括：**运动学是在选定的参考系中研究位置、速度和加速度；矢量本身与坐标系无关，坐标系只决定沿哪些方向读出分量，而参考系决定运动本身。**

我们首先区分了参考系和坐标系。参考系是约定为静止的物体，坐标系是给点编号的规则。同一参考系中换坐标系，速度和加速度这两支箭头不变，只是读数不同；换一个有相对运动的参考系，箭头本身就变了。AGV 上看静止的零件在绕圈，就是后一种情形。

在固定的直角坐标中，速度和加速度的分量就是坐标的一阶、二阶导数，这是因为坐标轴不动。由加速度和初始条件积分可以求出运动，由采样位置作差商可以估计速度和加速度。曲线坐标中的局部基随点的位置而转动，求导时多出基矢量本身的变化率。柱面坐标的局部基以 $\dot\varphi$ 绕 z 轴转动，由此得到径向、横向分量，其中横向的 $2\dot\rho\dot\varphi$ 一项在 SCARA 边转边伸时不可忽视；球面坐标的局部基就是两轴云台上相机的坐标系，它以 $\dot\varphi\hat{\boldsymbol z} + \dot\theta\boldsymbol e_\varphi$ 转动，在极点附近，方位角的变化率趋于无穷，这就是云台的锁孔问题，与第 4 章的万向节锁同属坐标的奇异。自然坐标以轨迹本身为参照，速度只有切向分量，加速度分为改变速率的切向部分和改变方向的法向部分，后者等于曲率乘以速率的平方。四种坐标分解的是同一支箭头；求曲线坐标公式的统一方法是：写出局部基的角速度，基矢量的导数等于角速度叉乘基矢量。

参考系本身转动时，矢量在定系中的导数等于它在动系中的相对导数加上 $\boldsymbol\Omega\times\boldsymbol q$。由此得到速度合成定理和加速度合成定理：绝对加速度等于牵连加速度、相对加速度与科氏加速度 $2\boldsymbol\Omega\times\boldsymbol v_{\mathrm{rel}}$ 之和。系数 2 的两半，一半来自相对速度随动系转动，一半来自牵连点的更换。转台上直线匀速行驶的 AGV，加速度计读出的横向加速度正是科氏加速度；地球自转对车间机器人的影响则只有重力加速度的百万分之几。

最后，刚体上任意两点的距离不变，三个不共线的点就确定了整个刚体，计数 3 + 2 + 1 = 6 给出了刚体的六个自由度。刚体上各点的速度由一点的速度和角速度共六个数确定，加速度公式与牵连加速度相同。从点到刚体，下一步是由关节连接的多个刚体，即第 11 章的机构。

| 概念 | 一句话 |
|---|---|
| 参考系 | 约定为静止、用来描述运动的物体；运动依赖于参考系 |
| 坐标系 | 给点编号的规则；同一参考系中换坐标系只换读数 |
| 运动方程与轨迹 | 位置随时间的函数；它画出的曲线 |
| 局部基 | 曲线坐标在一点处沿各坐标线的单位矢量，随点的位置而转动 |
| 径向、横向分量 | 沿 $\boldsymbol e_\rho$、$\boldsymbol e_\varphi$ 的分量；横向加速度含 $2\dot\rho\dot\varphi$ |
| 锁孔问题 | 方位-俯仰结构在极点方向附近，方位角速度趋于无穷 |
| 切向、法向加速度 | 前者改变速率，后者改变方向，等于 $\kappa v^2$ |
| 曲率 | 单位弧长上切线方向的转角；圆的曲率是半径的倒数 |
| 绝对、相对、牵连运动 | 相对定系、相对动系、动系本身的运动；牵连点是动系上与动点重合的点 |
| 科氏加速度 | $2\boldsymbol\Omega\times\boldsymbol v_{\mathrm{rel}}$，垂直于相对速度，只改变相对运动的方向 |
| 惯性力 | 在非惯性参考系中写牛顿定律时须补上的离心力、科氏力等 |
| 刚体的六个自由度 | 三个不共线点：3 + 2 + 1 = 6；或位置 3 加姿态 3 |
