title: 本章小结
---

本章的主线可以用一句话概括：**一个坐标系相对另一个坐标系的位置和姿态，写成一个 4×4 的齐次变换矩阵；坐标系之间的一切换算，都是这种矩阵的连乘与求逆，次序由下标相消规则决定。**

我们从原点不同的两个坐标系出发。位置矢量依赖于原点，所以点的坐标换算除了转动，还要加上两个原点之间的平移：$p_a = R_{ab}\,p_b + p_{ab}$。这是一个仿射变换，而不是线性变换；速度、力、方向这类自由矢量则只按旋转矩阵变换。描述一个坐标系相对另一个坐标系所需的全部信息，就是姿态 $R_{ab}$ 和原点位置 $p_{ab}$，二者合称位姿，共有 6 个独立参数。

给点添上第四个分量 1、给方向添上 0，仿射变换就成了四维中的线性变换。齐次变换矩阵 $T_{ab}$ 的前三列是 {b} 的三根轴，第四列是 {b} 的原点，读一个矩阵就是读出一个坐标系。全体齐次变换矩阵构成特殊欧几里得群 SE(3)，它恰好刻画了保持距离和右手关系的刚体变换。同一个矩阵有三种用法：描述位姿，换算坐标，以及作为位移算子移动物体。

复合与求逆服从下标相消规则：$T_{ab}T_{bc} = T_{ac}$，$T_{ab}^{-1} = T_{ba}$。求逆公式 $T^{-1} = (R^{\mathsf T},\ -R^{\mathsf T}p)$ 中的 $R^{\mathsf T}$ 不可遗漏，它把反向的箭头换到另一组坐标轴上去读。左乘的位移相对固定坐标系，右乘的位移相对物体自身；与 SO(3) 不同，SE(3) 中的左乘转动绕固定坐标系的原点进行，会把工具甩到远处。

一个工作站的坐标系组织成坐标系树：每个坐标系只记录相对父坐标系的位姿，任意两个坐标系之间的位姿沿树中唯一的路径相乘，向上的一步乘逆。机器人模型文件本身就是一条坐标系链，沿链相乘就是正运动学。树中不存储回路，回路作为约束用于检查和标定。

最后，相机-机械臂-工件的抓取问题归结为一个闭合方程：经过机器人的路径与经过相机的路径必须在抓取点相遇。用下标相消规则即可解出法兰的目标位姿。误差分析表明，角度误差会被距离放大，小角度误差 δ 造成的位置偏差约为 δ 乘以杠杆长度；缩短坐标链、直接标定关键的位姿，是提高精度的根本办法。

| 概念 | 一句话 |
|---|---|
| 坐标系 | 一个原点加三根两两垂直、构成右手系的单位轴 |
| 位姿 | 一个坐标系相对另一个坐标系的姿态和原点位置，6 个独立参数 |
| 仿射变换 | 线性变换再加一个常数平移；点的坐标换算属于此类 |
| 齐次坐标 | 点末位补 1，方向末位补 0 |
| 齐次变换矩阵 | 前三列是轴，第四列是原点 |
| SE(3) | 全体齐次变换矩阵构成的群，即全体刚体变换 |
| 刚体变换 | 保持距离和右手关系的映射 |
| 下标相消规则 | 相邻的相同下标相消，剩下首尾下标就是乘积的含义 |
| 坐标系树 | 每个坐标系只记录相对父坐标系的位姿；任意两者之间路径唯一 |
| 最近公共祖先 | 两条向上的链最先相遇的坐标系 |
| 闭合方程 | 两条路径到达同一坐标系，位姿必须相等 |
