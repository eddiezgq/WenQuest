title: 本章小结
---

本章在写运动学方程之前，回答了“机器人能怎样动”这个问题。贯穿全章的是一个看法：**运动由约束决定。** 关节是约束，回路是约束，车轮不侧滑也是约束；自由度、构型空间、工作空间，都是约束的结果。

关节的约束用旋量描述最为干净。一个关节允许的运动旋量组成 $\mathbb R^6$ 的一个 f 维子空间，f 就是关节的自由度；理想关节的约束力不做功，所以约束力旋量与每个允许的运动旋量都互易，组成 6 − f 维的子空间。转动、移动、螺旋三种单自由度低副都是一根旋量轴，只是节距不同。工程上，前者告诉我们电机要驱动哪个方向，后者告诉我们轴承要承受哪些载荷。

把关节连成机构，自由度可以先放开、再约束地数出来，这就是格吕布勒公式 $M = m(N - 1 - J) + \sum f_i$。它假定各关节的约束彼此独立，所以给出的是自由度的下界。被动自由度、平行或相交的轴造成的过约束（平面机构、本内特机构）、以及共线一类的奇异位置，都会使实际自由度更大。真正可靠的办法是写出速度闭环方程，求系数矩阵的秩。

机器人的全部构型组成构型空间，它的维数是自由度，它的形状比维数包含更多的信息。转动关节的变量在圆周上，两个转动关节的构型空间是环面而不是平面，所以关节插值要考虑绕回；SO(3) 与 $\mathbb R^3$ 不同胚，所以任何三参数的姿态表示都有奇异。在构型空间中，机器人缩成一个点，障碍物变成禁区，运动规划成了给一个点找路。描述任务用的是任务空间，比较构型空间与任务空间的维数，可以判断机器人对一项任务是否够用、是否冗余。

工作空间是正运动学的像。可达工作空间说明末端能到哪里，灵巧工作空间说明在哪里末端可以取任意姿态，后者小得多，而且随工具加长而缩小。平面机械臂的工作空间有解析表达式；空间机械臂一般用程序计算，UR5e 用解析逆解逐点判断，SCARA 由关节限位直接算出。工作空间的边界由奇异位形组成。

闭链使关节变量之间出现闭环方程。闭环方程是完整约束，它把构型空间削成低维的曲线或曲面：四杆机构的构型空间是环面上的闭曲线，同一个输入对应几种装配模式，格拉斯霍夫条件判断曲柄能否整周转动。并联机构的逆运动学是每条支链各自求解，正运动学却要联立求解并且多解，正好与串联机械臂相反。另一类约束只能写成速度之间的关系，即普法夫约束；不可积的普法夫约束是非完整约束，它不减少构型空间的维数，只限制每一时刻的运动方向。差速 AGV 的车头方向由两轮转角决定，位置却不由两轮转角决定，必须由轮速的全部历史积分得到。

第 12 章将用本章的关节旋量写出开链机械臂的正运动学。

| 概念 | 一句话 |
|---|---|
| 运动副（关节） | 两个构件之间允许一定相对运动的可动连接；面接触为低副，点、线接触为高副 |
| 关节的自由度与约束数 | 允许的运动旋量子空间的维数 f；约束力旋量子空间的维数 c = 6 − f |
| 约束力旋量 | 理想关节施加的、与一切允许运动互易的力旋量，决定轴承的载荷 |
| 被动自由度 | 不影响机构其余部分的自由度，如两端为球关节的杆绕自身轴线的转动 |
| 过约束机构 | 因特殊几何条件，部分约束自动重复，实际自由度大于格吕布勒公式的值 |
| 构型空间 | 机器人全部可能构型组成的空间，维数等于自由度 |
| 任务空间 | 描述任务所用的末端位置和（或）姿态的空间 |
| 构型空间障碍物 | 与障碍物发生碰撞的构型在构型空间中占据的区域 |
| 可达 / 灵巧工作空间 | 末端以至少一种 / 任意姿态能够到达的位置 |
| 闭环方程 | 绕回路一周回到原处的条件，是闭链关节变量之间的完整约束 |
| 装配模式 | 闭链在同一组输入下的不同构型；不经过两解合一的位置不能互相转换 |
| 极限位置 | 闭链的输入到达转动范围的端点、两种装配模式相接的位置 |
| 完整约束 | 能写成构型变量的方程 g(q) = 0 的约束，降低构型空间的维数 |
| 普法夫约束 | 速度的线性约束 A(q)q̇ = 0 |
| 非完整约束 | 不可积的普法夫约束，只限制每一时刻的运动方向，不降低构型空间的维数 |
