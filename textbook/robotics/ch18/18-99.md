title: 本章小结
---

并联机构把动平台用几条支链同时连到机座上。与串联臂相比，它的长处与短处都来自这个结构。工作空间是各支链工作空间的交，而串联臂是各段运动的和，所以同样的杆长，并联机构能到达的范围小得多；杆长相同的五杆只有 2R 臂约一半的可用面积，Delta 的工作空间不到 UR5e 的三十分之一。逆解按支链分别求，常有公式；正解要把各支链联立起来，多解是常态。速度关系写成 A ẋ = B θ̇ 的隐式形式，A 可逆时 J = A⁻¹B。在条件良好的区域里，五杆的误差放大和柔度普遍比 2R 臂小，刚度更均匀；并联机器人的“快”则主要来自电机集中在机座上、运动部分轻，而不是来自速度传递比。

旋量理论把并联机构的运动和受力放在同一个框架里。每条支链的关节旋量轴张成它的运动旋量系，与之互易的力旋量组成约束力旋量系，这是支链不经过任何关节做功就能对平台施加的力；平台能有的运动，就是与全部约束力旋量都互易的运动旋量。Delta 的每条支链只有一个约束力旋量：垂直于平行四边形平面的力偶 t × u，三个力偶线性无关，平台便只能平移；平台受到的扭矩全部由平行四边形的一拉一压承担，电机感觉不到。锁住电机后支链多出的那个力旋量是驱动力旋量：Delta 是沿杆的力，Stewart 平台的每条腿是沿腿轴线的力，腿是二力杆。由驱动力旋量和约束力旋量，速度关系统一地写成 A𝒱 = Bθ̇、C𝒱 = 0，静力关系写成 ℱ = Aᵀf + Cᵀμ、τ = Bf。

并联机构的奇异分为三类。B 奇异是逆运动学奇异，与串联臂的奇异相同，支链伸直或折叠，平台失去某个方向的运动，通常在工作空间的边界上。G = (A; C) 奇异是正运动学奇异：电机全部锁死，平台仍能一阶地运动，某些力旋量无法平衡，支链力和电机力矩按 1/σ_min 增长，正解的两个装配模式在这里合一；五杆在两根从动杆共线时、Stewart 平台在绕竖直轴转过 ±90° 时都处于这种位形。C 降秩是约束奇异，平台的运动性质改变；Delta 在三根杆都竖直时发生，那里也同时是正运动学奇异，但都在关节限位以外。关节限位和行程限制在设计中起着把机构挡在奇异之外的作用。

Stewart 平台的逆解一步算出六条腿长，腿速由 l̇ = A𝒱_s 直接给出（A 以六条腿的单位力旋量为行）；正解在 SE(3) 上用牛顿法：每一步解 AΔ𝒱 = l − l(T)，再把 e^{[Δ𝒱]} 左乘到当前位姿上。在正运动学奇异以外，迭代二次收敛；在控制周期中用上一周期的位姿作初值，两次迭代就够了。同样的腿长对应多个装配模式，平面型平台的解还成对地关于机架平面对称（本章的平台对一组腿长有 8 个实数解，由同伦法核对没有遗漏）；从远处的初值出发，牛顿法很可能收敛到不能实际装出的那些解，所以上电时要从已知的位姿开始跟踪。

Delta 的速度关系由“二力杆只沿自身方向推拉平台”直接得到。电机转速各自受限时，平台能达到的速度构成一个平行六面体，沿某个方向的最大速度为 ω_max/‖J⁻¹d‖∞，各方向都能保证的速度为 ω_max 除以 J⁻¹ 各行长度的最大值。保证速度在工作空间中部偏下最大，靠近静平台和下边界时迅速减小。按标准的 25/305/25 mm 拾放循环计算，只计转速限制时，节拍下限随放置位置相差近一半：传送带放在哪里、多高，直接决定产能。下一章转向轮式移动机器人。

| 概念 | 一句话 |
|---|---|
| 并联机构 | 末端通过至少两条独立的运动链与机架相连的闭链机构 |
| 静平台、动平台、支链 | 固定的部分、末端所在的刚体、连接两者的运动链 |
| 主动关节、被动关节 | 装电机、由控制器驱动的关节；随机构被动运动的关节 |
| 完全并联机构 | n 个自由度、n 条支链、每条支链一个主动关节 |
| 工作模式 | 同一平台位姿下逆解的不同组合；与装配模式相对 |
| 闵可夫斯基和 | 两个点集的元素两两相加所得的集合；串联臂的工作空间 |
| 混联机构 | 一部分并联、一部分串联的机构 |
| 运动旋量系 | 支链允许平台具有的全部运动旋量组成的子空间 |
| 约束力旋量系 | 与支链运动旋量系互易的全部力旋量，即支链能施加而不做功的力 |
| 驱动力旋量 | 与支链被动关节都互易、与主动关节不互易的力旋量 |
| 二力杆 | 两端铰接、只沿两铰点连线受拉或受压的杆 |
| 逆运动学奇异 | B 奇异：电机能动而平台不动，平台失去运动方向 |
| 正运动学奇异 | G 奇异：电机锁死而平台能动，某些力无法平衡 |
| 约束奇异 | 约束力旋量线性相关，平台的运动性质改变 |
| 线几何 | 研究直线集合的几何与代数；Stewart 平台的奇异即腿线线性相关 |
| 拾放 | 从一处取起物体、放到另一处的动作；用标准循环衡量速度 |
