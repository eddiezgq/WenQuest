title: 本章小结
---

本章讲的是正运动学的另一种标准写法：DH 参数法。它的出发点是一个几何事实：两根关节轴之间的相对位置，由它们的公垂线完全确定，只需要两个数，即公垂线的长度和两轴的夹角；关节的状态再用沿轴的距离和绕轴的转角两个数描述。于是只要在每个连杆上按规则放好坐标系，相邻两个坐标系之间的变换就只含四个参数，整条手臂就是这些变换的连乘。

规则有两种。标准 DH 把 {i} 放在连杆 i 的远端（轴 i+1 上），变换次序是先 z 后 x；Craig 的改进 DH 把 {i} 放在近端（轴 i 上），先 x 后 z。两者用的是同一组几何量，只是在参数表中错开一行，整条链的乘积只差一个固定变换 $X_n$。拿错约定，算出的就不是这台机器人；拿到一张表，首先要弄清它的约定。

为一台具体的机器人建系，按固定步骤进行，并对相交轴、平行轴、重合轴、移动关节以及基座和末端作补充约定。这些约定留下的自由不影响正运动学（定理 13.2.1），却使同一台机器人可以有许多张不同的参数表。厂商手册通常选择使关节偏置为零的写法，因此会出现负的连杆长度，UR5e 的官方参数表就是如此。用它计算的末端与第 12 章零件库模型相差一毫米左右，差别全部来自长度参数，并可以逐项精确地写出（定理 13.3.1）。

DH 参数与指数积可以精确地互相换算。由 DH 到指数积只需一个公式：零位时，标准 DH 的 {i−1}（改进 DH 的 {i}）的 z 轴就是关节 i 的旋量轴。由指数积到 DH，则要把每个旋量轴还原为直线，再按建系步骤求公垂线。本章用 UR5e（标准 DH）和 Panda（Franka 公布的 Craig 表）在两个方向上做了验证，与零件库三维模型的差别只有舍入误差。

DH 的主要局限在于相邻轴接近平行时：一根轴在两轴所在的平面内偏转 ε，公垂线就退化为远处的交点，d 约为 −a/ε，在 ε = 0 处由 −∞ 跳到 +∞。真实机器人的出厂标定数据中出现几百米的 d，原因就在这里。标定时应改用哈亚蒂参数或基于指数积的方法。DH 适合交流，指数积适合计算和标定，这是本书的分工。

| 概念 | 一句话 |
|---|---|
| 公垂线 | 与两条直线都垂直并相交的线段；不平行时唯一，长度是两线的最短距离 |
| DH 参数 | 连杆长度 a、连杆扭角 α（属于连杆），连杆偏距 d、关节角 θ（属于关节） |
| 标准 DH | {i} 在轴 i+1 上，$z_i$ 沿下一个关节的轴；变换先 z 后 x |
| 改进 DH | Craig 约定：{i} 在轴 i 上，$z_i$ 沿本关节的轴；变换先 x 后 z，表的第 i 行是 $a_{i-1}$、$\alpha_{i-1}$、$d_i$、$\theta_i$ |
| 连杆坐标系 | 按规则固定在各连杆上的坐标系；位置由轴线决定，不必在关节实物中心 |
| 关节偏置 | 控制器关节变量与 DH 关节角（或偏距）之间的常数差 |
| 名义参数 | 设计图纸上的参数；同一型号通用，与每台机器人的标定参数有零点几毫米的出入 |
| 厂商手册形式 | 优先使关节偏置为零，因此允许负的连杆长度 |
| 哈亚蒂参数 | 用绕 y 的转角 β 代替 d，描述名义上平行的两根轴，参数随几何连续变化 |

两种坐标系记号的对照（详见表 13.1.1）：Craig 的 ${}^{A}P$、${}^{A}_{B}R$、${}^{A}_{B}T$、${}^{i-1}_{\ \ i}T$ 分别对应本书的 $p_a$、$R_{ab}$、$T_{ab}$、$T_{i-1,i}$；Craig 的规则是相邻的上标与下标相消，本书的规则是相邻的两个下标相消。
