title: 本章小结
---

本章的主线可以用一句话概括：**关节力矩对惯性参数和摩擦参数是线性的，$\tau = Y(\theta, \dot\theta, \ddot\theta)\pi$；让机器人按一条专门设计的轨迹运动，记录角度和力矩，用最小二乘就能求出由运动唯一确定的那些参数组合（基参数），再用没参加辨识的动作检验。**

26.1 节从辨识和应用的角度重看运动方程的三条性质。由 $\dot M = C + C^{\mathsf T}$，广义动量 $p = M\dot\theta$ 的变化率不含 $\ddot\theta$，广义动量观测器的残差 r 是外力矩的一阶滤波，不需要角加速度就能检测碰撞：书中的例子中 TCP 受 {{ex26_1.F_EXT:.0f}} N 的外力，残差 {{ex26_1.t_det_ms:.0f}} ms 内超过阈值；但观测器的模型若不含负载，残差平时就有 {{ex26_1.r_pre_nom:.1f}} N·m。单个连杆的十个惯性参数满足 $\mathcal G_i\dot{\mathcal V}_i - [\mathrm{ad}_{\mathcal V_i}]^{\mathsf T}\mathcal G_i\mathcal V_i = \Psi\pi_i$，由此用递推算出回归矩阵，给出定理 24.3.4 的构造性证明。UR5e 连同转子和摩擦共 {{ex26_1.n_par}} 个参数，带列主元的 QR 分解表明只有 {{ex26_1.rank}} 个基参数可辨识：{{ex26_1.n_zero}} 个参数对力矩毫无影响，{{ex26_1.n_dep}} 个只能以组合的形式出现。辨识出的参数还应使每个连杆的伪惯量矩阵正定，否则就不对应任何真实的物体。

26.2 节说明，生产中的上下料动作数据再多也是秩亏的（条件数 ${{ex26_2.cond_m:sci1}}$），必须专门设计激励轨迹。用有限项傅里叶级数（周期 10 s，五个谐波）参数化，在转角、速度、加速度和离地高度的限制下优化条件数，从 {{ex26_2.cond_start:.0f}} 降到 {{ex26_2.cond_opt:.0f}}。同样的噪声下，优化轨迹的参数误差为 {{ex26_2.err_opt:.1f}}%，幅度小的随机轨迹为 {{ex26_2.err_rand:.0f}}%。

26.3 节在 MuJoCo 中让带 3.8 kg 负载和关节摩擦的“真实”UR5e 跑两个周期的激励轨迹，零相位滤波求导、降采样后得到 {{ex26_3.n_rows}} 个方程，用 QR 分解求出 {{ex26_3.n_base}} 个基参数，相对误差 {{ex26_3.err_rel:.1f}}%。用上下料动作检验，关节 2 的力矩预测误差（均方根）由名义模型的 {{ex26_3.rms_nom2:.1f}} N·m 降到 {{ex26_3.rms_id2:.2f}} N·m。手臂已知时只辨识负载，质量误差 {{ex26_3.err_m:.2f}}%，质心偏差 {{ex26_3.err_c_mm:.2f}} mm。摩擦参数的偏差远超标准差，说明标准差只反映随机误差。运动学标定与动力学辨识是同一类问题，前者非线性、要用外部仪器，后者线性、只用机器人自己的传感器。

26.4 节讲摩擦。上下料动作中，关节 6 的力矩几乎全是摩擦，关节 1 的摩擦也占四成。库仑加黏性模型 $\tau_f = f_c\,\mathrm{sign}\,\dot\theta + f_v\dot\theta$ 的参数是线性的，可以排进回归矩阵，也可以用恒速试验单独测出；低速处的斯特里贝克效应和预滑动、滞后要用非线性或动态模型。26.3 节摩擦参数的偏差来自速度换向处：滤过的力矩是斜坡，模型的 sign θ̇ 是跳变；去掉每个关节低速的方程后，基参数误差由 {{ex26_4.e_all:.2f}}% 降到 {{ex26_4.e_k:.2f}}%。摩擦随温度、负载、磨损变化，惯性参数辨识一次即可，摩擦参数要在工作中更新。

| 概念 | 一句话 |
|---|---|
| 参数辨识 | 由机器人的运动和电机力矩反推模型参数 |
| 广义动量观测器 | 由广义动量和电机力矩估计外力矩的一阶观测器，不需要角加速度 |
| 惯性参数 | 每个连杆的质量、质量乘质心（静矩）、关于原点的惯量，共十个 |
| 回归矩阵 | 力矩对参数的系数矩阵，只依赖运动和几何 |
| 基参数 | 使回归矩阵各列线性无关的最少的参数组合，由运动唯一确定 |
| 带列主元的 QR 分解 | 每一步选范数最大的列做分解，用来判断秩和挑出独立列 |
| 伪惯量矩阵 | 4×4 的 $\int\bar r\bar r^{\mathsf T}\mathrm dm$，参数合乎物理当且仅当它正定 |
| 激励轨迹 | 专为辨识设计、使回归矩阵良态的运动 |
| 条件数 | 最大与最小奇异值之比，决定噪声在参数中被放大多少 |
| 摩擦模型 | 摩擦力矩与速度（及状态）的关系 |
| 库仑摩擦、黏性摩擦 | 大小不变、方向与运动相反的摩擦；与速度成正比的摩擦 |
| 静摩擦、斯特里贝克效应 | 启动时要克服的最大摩擦；低速时摩擦随速度增大而下降 |
| 动态摩擦模型 | 带内部状态、描述预滑动和滞后的摩擦模型（达尔、LuGre） |

### 在问渠软件里试一试

- 数字工厂实验 28（机器人厂）：一台 WQ-CR5 在负载跑合台上的实测关节力矩，减去零件库模型的刚体逆动力学，用 26.4 节的模型 $f_c\tanh(\dot\theta/0.01) + f_v\dot\theta$ 对每个关节做最小二乘，辨识出库仑摩擦和黏性摩擦，再写回模型看仿真与实测的差还剩多少。数据可以下载，自己算一遍。
- 数字工厂实验 25（机器人厂）：关节测试台记录每台关节的空载摩擦力矩和背隙，控制图上能看到摩擦的散布——26.4.5 节说的“摩擦会变”，在出厂检验里就是这张图。
- 数字工厂实验 26（机器人厂）：运动学标定，与本章的动力学参数辨识是同一套最小二乘和可辨识性的问题。
