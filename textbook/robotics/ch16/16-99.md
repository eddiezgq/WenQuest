title: 本章小结
---

速度运动学的出发点是一个朴素的事实：一个关节转动时，它以外的手臂绕这根轴作刚体转动；几个关节同时转动时，末端的运动旋量就是各关节此刻的旋量轴乘以各自的转速再相加。把这些旋量轴排成矩阵的列，就得到雅可比矩阵。由空间形式的指数积公式求导，第 i 列是被关节 1 到 i − 1 搬到此刻位置的第 i 根轴，在 {s} 中表示，这是空间雅可比；在此刻的末端坐标系中表示，就是第 15 章的物体雅可比。两者只差一个伴随矩阵，秩和行列式相同，奇异值一般不同。把线速度的参考点取在法兰盘中心，得到最直观的几何雅可比。雅可比矩阵随形态而变，它对时间的导数可以用李括号逐列写出：末端匀速运动时，关节一般并不匀速。

工程上常用欧拉角或旋转矢量描述姿态，它们的导数不是角速度。对这样的坐标求偏导得到解析雅可比，它与几何雅可比之间差一个只依赖于姿态坐标的矩阵。这个矩阵不可逆时出现表示奇异，例如 ZYX 欧拉角在俯仰 ±90° 处的万向节锁；机器人本身此时毫无问题。控制和计算应当用几何雅可比，欧拉角只用于显示和人工输入。

雅可比矩阵降秩的形态是运动学奇异。用奇异值分解可以一次看清它的四个侧面：失去的运动方向，使末端不动的自运动，完全由结构承受的力旋量，以及奇异附近与最小奇异值成反比的关节速度。工作空间的边界一定由奇异位形构成。UR5e 的雅可比行列式分解为三个因子之积，分别对应肘部、手腕和肩部奇异，恰好是第 14 章逆解中的三个“二选一”；接近奇异时，最小奇异值与相应的因子成正比。

单位关节速度对应的末端速度构成可操作度椭球，半轴是奇异值乘以左奇异矢量。线速度与角速度单位不同，要分开求；工具姿态必须保持不变时，线速度椭球由雅可比矩阵之逆的后三列给出，它在奇异处退化，而不要求姿态的椭球可能并不退化。可操作度、最小半轴和条件数分别回答“总体多快”“最慢多慢”“是否均衡”，最优的形态往往不同。

静力关系 τ = Jᵀ F 由功率平衡得到：关节 i 的力矩就是末端力旋量对关节 i 此刻的轴的力矩。单位关节力矩能平衡的末端力构成力椭球，它与速度椭球主轴相同、半轴互为倒数：动得慢的方向最能扛力，沿主轴“省力费距离”严格成立。反过来由关节力矩估计末端的力要解方程，误差按最小奇异值的倒数放大；七轴臂多出的一维读数可以用来发现手以外的接触。关节的弹性使末端在力的作用下让开，柔度矩阵为 JK⁻¹Jᵀ。

最后，各种灵巧性指标都来自雅可比矩阵的奇异值。比较不同的设计要用无量纲的局部条件指标及其在工作空间上的平均，即全局条件指标；含有转动时要先选定特征长度。平面 2R 臂只有在大臂是小臂的 √2 倍时才能各向同性；这个长度比还使它在每一个肘角上都最均衡，因而全局条件指标最大。把局部指标画成灵巧性地图，就可以为 UR5e 的托盘找到最合适的位置。下一章讨论冗余机器人，雅可比矩阵的零空间和本章的各种指标将成为主角。

| 概念 | 一句话 |
|---|---|
| 速度运动学 | 关节速度与末端速度之间的关系 |
| 雅可比矩阵 | 把关节速度变成末端速度、只依赖于形态的矩阵 |
| 空间雅可比 | 各关节此刻的旋量轴在 {s} 中的表示，配空间运动旋量 |
| 物体雅可比 | 各关节此刻的旋量轴在 {b} 中的表示，配物体运动旋量 |
| 几何雅可比 | 角速度在 {s} 中、线速度取末端原点的实际速度 |
| 解析雅可比 | 末端位姿坐标（位置与欧拉角等）对关节变量的偏导数 |
| 点动 | 按住按键，机器人沿指定方向持续移动或转动 |
| 表示奇异 | 姿态坐标的缺陷：机器人能动，所选的三个数跟不上 |
| 运动学奇异 | 雅可比矩阵降秩：末端失去运动方向，机器人本身的性质 |
| 边界奇异、内部奇异 | 末端在工作空间边界上或内部的奇异位形 |
| 肘部、手腕、肩部奇异 | UR5e 的三类奇异：sin θ₃ = 0、sin θ₅ = 0、r = 0 |
| 可操作度椭球 | 单位关节速度能产生的全部末端速度 |
| 线速度椭球、角速度椭球 | 把可操作度椭球按线速度和角速度分开求 |
| 速度传递比 | 单位关节速度沿某方向能产生的最大末端速度 |
| 静力学 | 研究力作用下的平衡；机械臂中即 τ = Jᵀ F |
| 力椭球 | 单位关节力矩能平衡的全部末端力 |
| 力传递比 | 单位关节力矩沿某方向能平衡的最大末端力 |
| 运动静力对偶 | 速度与力的椭球主轴相同、半轴互为倒数 |
| 柔度矩阵 | 关节弹性引起的末端变形与末端力之比 |
| 灵巧性指标 | 衡量运动和施力能力的数，由奇异值算出 |
| 局部条件指标 | 条件数的倒数，0 为奇异，1 为各向同性 |
| 各向同性位形 | 速度椭球是球的形态 |
| 特征长度 | 使含转动和平移的雅可比无量纲化的长度尺度 |
| 全局条件指标 | 局部条件指标在工作空间上的平均 |
