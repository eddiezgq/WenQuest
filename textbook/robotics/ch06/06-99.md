title: 本章小结
---

本章的主线可以用一句话概括：**刚体的运动是螺旋，运动和力都是旋量**。

我们从沙勒定理出发。任何刚体位移，不论经过怎样复杂的路径，都等价于绕某一根轴转过一个角度、同时沿这根轴平移一段距离。轴、转角和节距是位移本身的几何属性，与坐标系无关。平面上，这根轴退化为一个极点。

接着研究速度。旋转矩阵的导数总可以写成 $\dot R = [\omega_s]R = R[\omega_b]$，同一个角速度在空间和物体坐标系中有两套分量；全体反对称矩阵 so(3) 是 SO(3) 在单位元处的切空间，即它的李代数。把同样的推导用于齐次变换，$\dot T T^{-1}$ 和 $T^{-1}\dot T$ 给出空间和物体运动旋量 (ω, v)，它们属于 se(3)。莫齐定理说明，刚体在任一瞬间都绕一根瞬时螺旋轴做螺旋运动；任何运动旋量都可以写成旋量轴乘以转速。位姿是李群 SE(3) 中的矩阵，只能相乘；运动旋量是李代数中的矢量，可以相加。

指数映射把两者连接起来：以恒定运动旋量运动，位姿按 $e^{[\mathcal S]\theta}$ 变化，它有含 G(θ) 的闭式，几何上就是沿旋量轴拧过 θ。对数映射反过来由位移求旋量，并以代数的方式重新证明了沙勒定理。换坐标系时，运动旋量按伴随矩阵变换，轴随之搬动，节距和转角不变。

力旋量 (m, f) 与运动旋量配对，两者的点积是功率。由功率不变立即得到力旋量的变换规律（伴随矩阵的转置）和关节静力矩 τ = SᵀF。力系与运动一样有一根中心轴和一个节距；两个旋量的互易积为零时，一个力旋量对一个运动不做功，转动关节就不能被与其轴共面的力驱动。这些是鲍尔旋量理论的核心。最后，李括号刻画了运动不可交换的程度：两个运动交替进行的净效果，到二阶就是它们的李括号。

| 概念 | 一句话 |
|---|---|
| 螺旋运动 | 绕一根轴转动、同时沿这根轴平移；节距 = 每转 1 rad 前进的距离 |
| 沙勒定理 | 任何刚体位移都是一个螺旋运动 |
| 极点 | 平面位移中唯一的不动点，位移等于绕它转一次 |
| 空间角速度与物体角速度 | 同一个角速度矢量在 {s}、{b} 中的分量 |
| 李群与李代数 | 李群是光滑的矩阵群（SO(3)、SE(3)）；李代数是它在单位元处的切空间（so(3)、se(3)），带有李括号 |
| 运动旋量 | 刚体速度的六维描述 (ω, v)，v 是此刻位于原点的那一点的速度 |
| 瞬时螺旋轴 | 速度与 ω 平行的点组成的直线（莫齐定理） |
| 旋量轴 | 一根带节距的直线，写成六维矢量；运动旋量 = 旋量轴 × 转速 |
| 指数坐标 Sθ | 以恒定运动旋量 Sθ 运动 1 s 到达的位移 |
| 伴随矩阵 | 把运动旋量从一个坐标系换到另一个的 6×6 矩阵；它的转置变换力旋量 |
| 力旋量 | 力系的六维描述 (m, f)，力矩在前 |
| 中心轴 | 力系等价于沿它的力加绕它的力偶的那根直线（潘索） |
| 互易旋量 | 互易积为零的两个旋量：相应的力旋量对运动旋量不做功 |
| 李括号 | 两个运动交替进行的净效果的方向；so(3) 中就是叉积 |

### 历史注记

| 年份 | 人物 | 贡献 |
|---|---|---|
| 1763 | 莫齐 | 证明刚体的瞬时运动是绕一根轴的螺旋运动（瞬时螺旋轴） |
| 1775 | 欧拉 | 证明有一点不动的刚体运动是绕一根轴的转动（第 4 章） |
| 1803、1806 | 潘索 | 引入力偶，证明力系可化为一个力加一个力偶；中心轴 |
| 1830 | 沙勒 | 指出任何有限的刚体位移都是螺旋运动（1840 年罗德里格斯给出解析证明） |
| 1865 | 普吕克 | 用六个坐标描述空间直线 |
| 1873 | 克利福德 | 双四元数：旋量的代数表示 |
| 1870 年代 | 李 | 研究连续变换群，发现其结构由单位元附近的“无穷小变换”决定 |
| 1876、1900 | 鲍尔 | 《旋量理论》及《旋量理论专论》，系统建立运动旋量、力旋量、互易旋量的理论 |
| 1897–1906 | 坎贝尔、贝克、豪斯多夫 | 两个指数之积的指数由李括号级数给出 |
| 1903 | 施图迪 | 用对偶数发展旋量的代数 |
| 1930 年代 | 外尔 | 提出“李代数”这一名称 |
| 1938、1939 | 拉舍夫斯基、周炜良 | 由李括号判断非完整系统的可达性 |
| 1984 | 布罗克特 | 把旋量与李群用于机械臂，提出指数积公式（第 12 章） |
| 1994、2017 | 默里、李泽湘、萨斯特里；林奇、帕克 | 以旋量和李群为主线的机器人学教材 |
