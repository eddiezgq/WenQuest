title: 本章小结
---

本章的主线可以用一句话概括：**选关节角作广义坐标，写出动能 $\frac12\dot\theta^{\mathsf T}M(\theta)\dot\theta$ 和势能 U(θ)，按拉格朗日方程求导，就得到 $M\ddot\theta + C\dot\theta + g = \tau$；约束力不出现，电机的功率全部变成机械能的变化。**

24.1 节从约束讲起。完整约束把位置之间的关系写成等式，广义坐标是描述位形的最少的独立变量。约束力在虚位移上不做功的约束称为理想约束，光滑关节、刚体内部、不可伸长的绳都是。由牛顿定律和达朗贝尔原理，借助两个恒等式，得到拉格朗日方程 $\frac{\mathrm d}{\mathrm dt}\partial L/\partial\dot q - \partial L/\partial q = Q^{\mathrm{nc}}$，L = K − U；力旋量对应的广义力是 $J^{\mathsf T}\mathcal F$，关节力矩就是关节角的广义力。秋千的方程里没有绳的拉力，60° 摆幅的周期比小摆角公式长 {{ex24_1.ratio60_pct:.1f}}%，最低点拉力是体重的两倍，可由牛顿定律、拉格朗日乘子或 MuJoCo 的约束力求出。桁架吊运的两个方程是耦合的：加速时间取摆动周期的整数倍，吊重到匀速时就不摆了。

24.2 节完整推导了平面两连杆臂。质量矩阵只依赖肘角，非对角元素是两个关节的惯性耦合；速度项中 $h\dot\varphi_1^2$ 是离心项，$-2h\dot\varphi_1\dot\varphi_2$ 是科氏项；重力项只依赖姿态。UR5e 的关节 2、3 在关节 1 和手腕不动时精确地是这样一台两连杆臂，等效参数由模型文件算出，与 MuJoCo 的质量矩阵、偏置力和逆动力学逐项一致。装着毛坯把它平着送向卡盘（1 s），关节 2 的力矩峰值 {{ex24_2.pk_tot1:.1f}} N·m，以重力为主；力矩上限允许的最短用时 {{ex24_2.T_min:.2f}} s，但这个动作先受速度上限的限制。

24.3 节推广到 n 个关节。$M(\theta) = \sum J_i^{\mathsf T}\mathcal G_iJ_i$，速度项由克里斯托费尔符号 $\Gamma_{ijk} = \frac12(\partial_kM_{ij} + \partial_jM_{ik} - \partial_iM_{jk})$ 给出。M 对称正定、与 $\theta_1$ 无关，全转动关节时特征值有正的上下界；$\dot M - 2C$ 反对称；方程对惯性参数是线性的。UR5e 关节 1 推动的惯量随姿态变化 {{ex24_3.d_ratio1:.0f}} 倍；腕部关节的惯量几乎全是电机转子的等效惯量 $N^2J_m$，它还把质量矩阵的条件数从 {{ex24_3.cond_max:.0f}} 降到 {{ex24_3.cond_arm_max:.0f}}。

24.4 节证明了功率平衡 $\dot E = \dot\theta^{\mathsf T}\tau$。送料动作中电机的总功等于势能的增量 {{ex24_4.W:.2f}} J，但肩关节做了 {{ex24_4.W_neg1:.1f}} J 的负功、肘关节做了 {{ex24_4.W_j2:.1f}} J 的正功。自由下落时机械能应当守恒：显式欧拉法的能量误差持续累积，半隐式欧拉法（MuJoCo 的 Euler）增长得慢得多，但在质量矩阵随姿态变化时并非严格的辛方法，终究会漂移；RK4 的误差随步长按四次方缩小。四种故意写错的方程都使能量偏差增大九个数量级以上；能量检验查得出程序不自洽，查不出自洽的参数错误。双摆的初值相差 10⁻⁹ rad，{{ex24_4.t_div:.1f}} s 后轨迹就分道扬镳，能量却始终守恒。

| 概念 | 一句话 |
|---|---|
| 完整约束、非完整约束 | 能写成位置之间的等式的约束；只能写成速度关系的约束 |
| 自由度、广义坐标 | 位形可以独立变化的个数；描述位形所需的最少的独立变量 |
| 虚位移 | 冻结时间、满足此刻约束的任意微小位置变化 |
| 理想约束 | 约束力在任何虚位移上的总虚功为零 |
| 主动力、广义力 | 约束力以外的力；主动力在只改变一个广义坐标的虚位移上的虚功除以该坐标的变化 |
| 达朗贝尔原理 | 主动力与惯性力 −mr̈ 在任何虚位移上的总虚功为零 |
| 拉格朗日函数、拉格朗日方程 | L = K − U；由 L 求导得到的 n 个二阶运动方程 |
| 拉格朗日乘子 | 保留多余坐标时为每个约束配的未知数，乘以约束梯度就是约束力 |
| 质量矩阵 | 动能 ½θ̇ᵀMθ̇ 中的对称正定矩阵；对角元素是各关节推动的惯量，非对角元素是耦合 |
| 离心项、科氏项 | 速度项中与 θ̇_j² 成正比的项；与 θ̇_jθ̇_k（j ≠ k）成正比的项 |
| 逆动力学、正动力学 | 由运动求力矩；由力矩求运动 |
| 克里斯托费尔符号 | 由 M 的偏导数组成的 Γ_ijk，给出速度项；由它组成的曲率张量刻画构型空间的“弯曲” |
| 等效惯量、负载惯量比 | 转子惯量乘减速比的平方；关节推动的连杆惯量与之的比值 |
| 线性参数化 | 运动方程对惯性参数是线性的：τ = Yπ |
| 功率平衡 | 电机的功率等于机械能的变化率；速度项与惯性项合起来就是动能的变化率 |
| 辛积分 | 保持哈密顿系统相空间几何结构（辛形式）的数值方法，长时间仿真中能量误差有界 |
| 混沌 | 确定性系统中初值的微小差别随时间指数放大 |
