title: 本章小结
---

本章的主线是：**机器人的运动由微分方程描述，计算机一步一步地求它的近似解；每一种近似都有误差，而误差的大小和性质都可以分析、可以测量。**

我们从变化率出发定义了导数，并用带余项的泰勒公式说明了“沿切线近似”的误差与步长的平方成正比，这一事实贯穿全章。物理定律把变化率与量本身联系起来，就是微分方程。电机的一阶模型有解析解，时间常数刻画了它的快慢；连杆是二阶方程，取角度和角速度为状态，就化为一阶的状态方程，一般的机械臂也是如此。相平面把运动画成轨线，平衡点处的线性化和雅可比矩阵的特征值判断稳定性，无摩擦时能量守恒，轨线就是能量的等值线。

数值积分的出发点是欧拉法。它的局部截断误差与 h² 成正比，全局误差与 h 成正比，是一阶方法；方法的阶可以用“步长减半、看误差缩小几倍”的办法实测。步长太大时会出现与精度无关的另一种失败：数值不稳定，对欧拉法而言条件是 h ≤ 2/|λ|。龙格-库塔法在一步内取几个斜率加权平均，经典 RK4 是四阶的。长时间仿真守恒系统时，更重要的是不让能量漂移：欧拉法放大相空间面积，能量持续增长；辛方法保持面积，能量误差有界。姿态不是普通的向量，由陀螺仪读数积分时要用指数映射在 SO(3) 上推进，这样的李群积分永远得到旋转矩阵，马格努斯展开给出四阶的版本。

非线性方程用牛顿法解：在当前点线性化、解线性方程、迭代。它在根附近二次收敛，但依赖初值，在雅可比矩阵奇异处寸步难行，目标无解时会乱跳；线搜索和阻尼最小二乘是两种最常用的补救。数值微分是数值积分的反面：截断误差随 h 减小，读数误差（舍入、量化、噪声）被 1/h 放大，最佳跨度在两者平衡处；编码器测速就是这个问题。最后，当系统中快慢模态相差悬殊时，方程是刚性的，显式方法的步长被最快的模态卡住，隐式方法每步解一个方程，换来任意步长下的稳定。

这些方法将在后面各章反复使用：第 8 章的优化与高斯-牛顿法，第 15 章的数值逆运动学，第 23～29 章的动力学仿真，第 42～46 章的控制器离散化与状态估计。

| 概念 | 一句话 |
|---|---|
| 状态 | 知道它和以后的输入，就能唯一确定以后的运动 |
| 相平面 | 以状态的两个分量为坐标的平面，运动是其中的轨线 |
| 平衡点 | f(x) = 0 的状态；线性化矩阵的特征值判断它是否稳定 |
| 局部截断误差与全局误差 | 走一步产生的偏差；累积并传播后的总偏差 |
| 方法的阶 | 全局误差 ∝ $h^p$；步长减半，误差缩小 $2^p$ 倍 |
| 数值稳定性 | 放大因子的模不超过 1，误差不会被一步步放大 |
| 辛方法 | 保持相空间面积的方法，能量误差有界、不漂移 |
| 李群积分 | 用指数映射在李群上推进，数值解始终在李群上 |
| 二次收敛 | 误差与上一步误差的平方成正比，有效位数每步约加倍 |
| 吸引域 | 迭代收敛到某个解的初值的集合 |
| 刚性方程 | 快慢模态相差悬殊，显式方法的步长被快模态卡住 |
| A-稳定 | 稳定区域包含整个左半平面，任何步长都稳定 |
