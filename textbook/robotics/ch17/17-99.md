title: 本章小结
---

冗余总是相对于任务而言的。一项任务用 m 个数描述，关节有 n 个，n > m 时多出 r = n − m 个自由度：七轴的 Panda 对位姿任务冗余一度，六轴的 UR5e 对绕工具轴对称的焊接任务也冗余一度。固定任务的值，所有能完成它的关节角组成逆解集；在任务雅可比满秩的地方，它是一个 n − m 维的光滑曲面，切空间就是雅可比矩阵的零空间，手臂在其中的运动称为自运动。冗余度为 1、关节都是转动关节时，自运动流形由若干条互不相交的闭曲线组成：平面 3R 臂只管位置时，目标离基座的距离跨过 |l₁ ± l₂ ± l₃| 这几个临界值，闭曲线的条数就改变。用某个量（工具朝向、焊枪绕轴线的转角、某个关节角）作冗余参数时，参数沿流形取极值的地方，必定是把这个参数固定以后所得机构的奇异位形：焊枪绕轴线转到头时，UR5e 的肘部伸直；Panda 的 θ₃ 取极值时，锁住关节 3 的六轴臂奇异。

冗余度为 1 时，零空间方向可以用广义叉积写出：零空间矢量的各分量是删去一列后的子式，它与雅可比矩阵的各行正交，长度等于可操作度，随形态连续变化而不会变号。沿它积分并每步用牛顿法校正，就能沿自运动流形一直走下去而不偏离。Panda 的手固定在 ready 姿态时，自运动闭曲线只有一段在关节限位以内，两端都是关节 2 到下限；同一个位姿还有几条互不相连的闭曲线。手动起来时，最小范数解不含零空间分量，这是一个普法夫约束；它一般不可积，所以末端走一条闭合的路径，关节回不到原处。加一个把关节拉回参考形态的零空间项，或者用扩展雅可比把关节角完全确定下来，运动才可重复。

多出来的自由度用来完成次要任务。梯度投影把一个性能函数的梯度投影到零空间里：末端不动时，手臂沿自运动流形单调地改进这个函数，停在拉格朗日条件 ∇H = Jᵀλ 成立的地方，即函数在流形上的驻点。避开关节限位、提高可操作度都可以这样做；可操作度的梯度由雅可比矩阵的李括号解析地算出，而且与选用哪一种雅可比无关。避障则把手臂到障碍物的距离当作一维的次任务，在主任务的零空间里求它的阻尼最小二乘解。这些都是局部的方法：只能找到最近的驻点，障碍物来得太快时，零空间里的修正需要超过上限的关节速度。

Panda 在协作工位上的搬运说明了全局与局部的分工。从离 ready 最近的形态出发，最小范数解和锁住关节 3 的六轴做法都让肘部迎着工人的手过去；局部的优先级控制能保住距离，却要求两倍于上限的关节速度。沿目标点的自运动闭曲线先挑选一个起始形态（θ₃ 在这条闭曲线上恰好是整体参数），再用同样的局部控制，四条要求就全部满足。规划决定从哪里出发，控制应付途中的变化，两者缺一不可。下一章讨论另一类机构：并联机构。

| 概念 | 一句话 |
|---|---|
| 冗余、冗余度 | 关节数多于任务所需的自由度；多出的个数 r = n − m |
| 冗余机器人 | 对某项任务冗余的机器人 |
| 任务雅可比 | 把关节速度映射为任务速度的矩阵 |
| 自运动 | 任务不变、关节在动的运动 |
| 自运动流形 | 完成同一任务值的全部关节角，一般是 n − m 维的光滑曲面 |
| 零空间投影 | 把关节速度投影到雅可比矩阵的零空间里，不影响末端 |
| 广义叉积 | m×(m + 1) 矩阵各行的“叉积”，张成零空间，长度等于可操作度 |
| 柯西-比内公式 | 矩形矩阵乘积的行列式等于对应子式乘积之和 |
| 预测-校正法 | 先沿切向走一步，再用牛顿法拉回流形 |
| 冗余度分解 | 在完成主任务的全部关节运动中按准则选出一个 |
| 主任务、次要任务 | 必须保证的任务；在主任务的零空间里尽量满足的要求 |
| 扩展雅可比 | 把“性能函数在流形上取驻点”作为附加方程，使关节角唯一确定 |
| 避障 | 把手臂到障碍物的距离作为次要任务，让手臂让开 |
| 臂角 | “球—转—球”七轴臂的肘点绕肩腕连线转过的角，常用作冗余参数 |
