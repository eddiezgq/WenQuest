title: 本章小结
---

本章沿着一条测量链，从应变片走到控制器里的一个读数，再走到工厂里的合格判定。每个环节都在回答同一个问题：这个数有多可信。

**读数要带不确定度。** 误差分为系统误差和随机误差。真值未知，误差无法精确知道，所以用不确定度表达测量结果的可信程度：A 类用统计方法，B 类用其他信息，各分量按平方和合成，再乘包含因子 k = 2 得到扩展不确定度。合成时最大的一两项决定结果。

**电桥把微小的电阻变化变成电压。** 应变片的电阻只变化万分之几，惠斯通电桥把它变成毫伏级的电压差，全桥的输出是单臂电桥的 4 倍，并且是严格线性的，还能补偿温度。仪表放大器只放大两个输入之差，抑制共模电压，增益由一个电阻 $R_g$ 设定。增益要按满量程和模数转换器的输入范围选取。

**采样要满足采样定理。** 模数转换器的分辨率由位数和参考电压决定，理想信噪比约为 6.02N + 1.76 dB。采样频率必须高于信号最高频率的两倍，否则高频成分会混叠成低频，混叠一旦发生就无法用数字方法去除，只能在采样之前用抗混叠滤波器防止。

**滤得越干净，反应越慢。** 滑动平均对 $f_s/N$ 的整数倍频率完全消除，适合对付频率固定的干扰；一阶低通只需一行代码，衰减平稳。两者都以延迟为代价，控制用的读数不能随意加大滤波。

**标定修正系统误差。** 用标准量逐级加载、卸载、重复，最小二乘拟合出零点和灵敏度，读数按拟合直线反算。线性度、迟滞、重复性描述拟合直线以外的偏差，前两项是系统性的，重复性是随机的。

**判定要留保护带，过程要用控制图盯住。** 测得值落在公差限附近时真值可能已经超差，接收区应从两端各收窄 U。控制图由过程自己的数据定出控制限，用判异规则发现趋势和偏移，在出现废品之前报警；$C_p$ 与 $P_{pk}$ 的差别告诉我们问题在分散还是在漂移。

| 概念 | 一句话 |
|---|---|
| 系统误差与随机误差 | 前者重复测量时保持不变或按规律变化，可以修正；后者无规律，只能用多次测量减小 |
| 测量不确定度 | 表示被测量的值可能分散范围的参数，用标准差度量 |
| 共模抑制 | 仪表放大器只放大两输入之差，对两输入共同的电压几乎不响应 |
| 奈奎斯特频率 | 采样频率的一半，高于它的成分采样后会混叠 |
| 混叠 | 高频信号采样后表现为低频信号，采样后无法区分 |
| 标定 | 用已知的标准量确定测量链实际的输入–输出关系 |
| 迟滞 | 同一个输入，加载和卸载时输出不同 |
| 保护带 | 为保证判为合格的零件真值也合格，从公差两端各收窄的一段 |
| 控制限 | 由过程自己的数据算出的、稳定时组均值的波动范围，不同于公差限 |
