title: 本章小结
---

本章的主线可以用一句话概括：**车身、机身不固定的机器人，质心怎样走、身体怎样转，只取决于外界给它的力——车轮和脚的摩擦与压力、旋翼与空气的力；运动是否可行，就看这些力能不能在摩擦锥、单边接触和执行器能力的限制之内凑出来。**

28.1 节讲轮式车。轮胎靠一点点滑动传递力，纵向用滑移率、侧向用侧偏角描述，小的时候力与它们成正比，大了以后饱和于摩擦力；纵向力和侧向力共用一个摩擦圆。加速、制动、转弯时载荷在车轮之间转移：后轮驱动的 AGV 加速时后轮变重、制动时变轻；转弯时外侧变重、内侧变轻，内侧车轮的法向力降到零就侧翻。静态稳定系数 $w/(2h)$ 小于摩擦系数的车先翻后滑：满载的牵引式 AGV 在干地面上过 R = 3 m 的弯道，{{ex28_1.v_tip:.2f}} m/s 时侧翻，MuJoCo 中验证了载荷转移公式和侧翻、侧滑的极限。动力学自行车模型给出不足转向度 $K_u$：轿车车速越高，同样的弯要打越多的方向；AGV 低速过弯时侧偏只使转弯半径差 0.3%，但后轴的侧滑让里程计每过一个 90° 的弯偏 {{ex28_1.drift90_cm:.0f}} cm。

28.2 节讲双足步行。由质心动力学，地面力的合力在地面上的作用点——零力矩点——由质心加速度和角动量变化率决定，它就是压力中心，必须在支撑多边形内；G1 在 MuJoCo 中前后摆动时，两种算法的零力矩点相差不到 1 μm。保持质心高度、忽略角动量，得到线性倒立摆 $\ddot x = \omega_0^2(x - x_Z)$：质心偏离零力矩点就指数发散，G1 的时间常数 {{ex28_2.Tc_ms:.0f}} ms。捕获点 $\xi = x + \dot x/\omega_0$ 决定能否停住：在脚掌内就站得住，G1 向前能承受 {{ex28_2.v_front:.2f}} m/s、向后只有 {{ex28_2.v_back:.2f}} m/s 的推速；在脚掌外就要迈步到捕获点。由脚印给出的零力矩点计划，质心轨迹是有界解 (28.2.8)，它依赖将来的零力矩点，所以步行规划必须预见。

28.3 节讲四旋翼。动量理论给出推力与诱导速度、功率的关系，X2 悬停的理想功率约 {{ex28_3.P_id4:.0f}} W；桨叶的升力使推力和反扭矩都与转速的平方成正比。欧拉方程 $m_b = I_b\dot\omega_b + \omega_b \times I_b\omega_b$ 把第 21 章平坦映射给出的角加速度变成力矩，再由推力分配矩阵变成四个推力，MuJoCo 中逐位核对。X2 的后旋翼低于前旋翼，惯量张量有惯量积，横滚会带出一点偏航；偏航只靠反扭矩，角加速度比横滚、俯仰小一个数量级。空气阻力使平飞时机身必须前倾，10 m/s 约 {{ex28_3.th10:.0f}}°，逆风悬停也一样；旋翼的陀螺力矩在相邻旋翼反转时大部分抵消。

28.4 节讲浮动基座的一般形式。运动方程的前 6 行没有关节力矩，就是整台机器人的牛顿-欧拉方程，改写到质心上即质心动力学：质心只能靠外力加速，腾空时走抛物线；对质心的角动量只能靠外力矩改变，腾空时守恒，但角动量为零是不可积的约束，Go2 的腿按方框摆一圈，机身能净转过一个角度。各只脚的力要凑出质心动力学需要的力旋量，这和抓取是同一个问题，解不唯一，MuJoCo 中站立的 Go2 带着一组侧向把脚往里拉的内力。足端离地 0.3 m 跳下，冲击力是体重的八九倍，腿越硬力越大，小腿电机接近饱和；式 (28.4.6) 给的是平均力，峰值约为它的 1.5 倍。

| 概念 | 一句话 |
|---|---|
| 滑移率 | 轮子转出的线速度比车速快（或慢）了多少，与车速之比 |
| 侧偏角 | 轮心速度方向与轮平面的夹角 |
| 侧偏刚度 | 侧偏角小时侧向力与侧偏角之比 |
| 摩擦圆 | 轮胎的纵向力和侧向力的合力不超过 μ 乘法向力 |
| 载荷转移 | 加速、制动、转弯时法向力在车轮之间重新分配 |
| 静态稳定系数 | 轮距的一半与质心高度之比，小于摩擦系数则先翻后滑 |
| 动力学自行车模型 | 前后各一个有侧偏的车轮，描述车身侧向和横摆运动的模型 |
| 不足转向、过度转向 | 车速越高需要的转向角越大、越小 |
| 特征车速、临界车速 | 不足转向车横摆增益最大的车速；过度转向车失稳的车速 |
| 零力矩点 | 地面力合起来对它的水平力矩为零的点，即压力中心 |
| 线性倒立摆 | 质心保持高度不变的倒立摆，水平运动是线性的 |
| 轨道能量 | 线性倒立摆的守恒量，决定质心能否越过支点 |
| 捕获点 | 把零力矩点放在这里，机器人就能停住 |
| 动量理论 | 把旋翼看作加速空气的作动盘，推力等于动量的变化率 |
| 诱导速度 | 空气穿过旋翼盘面时被加速到的速度 |
| 悬停效率 | 旋翼的理想功率与实际功率之比 |
| 浮动基座 | 不固定在地上、位置和姿态都是未知量的机身 |
| 选择矩阵 | 把关节力矩放到运动方程中有电机的那些行上 |
| 质心动量、质心动量矩阵 | 整机的动量和对质心的角动量；它们与广义速度之间的矩阵 |
| 质心动力学 | 质心动量的变化率等于外力旋量 |
