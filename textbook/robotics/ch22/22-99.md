title: 本章小结
---

本章的主线可以用一句话概括：**轨迹 = 路径 × 时间规律；路径决定走哪里，时间规律决定走多快、多稳。**

22.1 节把这句话写成了公式：θ(t) = θ(s(t))，速度、加速度由式 (22.1.2) 拆成只与几何有关的 θ′、θ″ 和只与时间有关的 $\dot s$、$\ddot s$。点到点运动取关节空间的直线，问题化为设计一个标量时间标度。三次多项式起止速度为零，但加速度跳变；五次多项式起止加速度也为零，速度曲线呈钟形，与人手臂的运动相似。按各关节的速度、加速度、加加速度限值，由式 (22.1.11) 可求出最短时间；关节空间的直线并不让 TCP 走直线。

22.2 节证明，只限速度和加速度时，梯形速度曲线最快，多个关节按最吃紧的一个同步。但“最快”有代价：加速度的跳变会激起夹爪和轴的振动，运动结束后还要等它衰减。七段 S 形曲线恰好是梯形曲线的滑动平均，窗宽 $t_j$ 取振动周期时，残余振动几乎完全抵消。这是全章反复用到的工具：先求最快的，再滤波。

22.3 节让轨迹不停顿地经过路径点。三次样条在路径点处速度、加速度都连续，未知数满足对角占优的三对角方程组，解存在唯一；抛物线过渡不经过路径点，只在附近拐过去。各段时长按比例整体缩放，就能用二分法满足关节限值。

22.4 节转到笛卡尔空间。送料时 TCP 必须走直线，关节运动由逆解或雅可比求出；过三点的圆由式 (22.4.6) 确定；一般的曲线要按弧长重新参数化，才能匀速。沿曲线运动有法向加速度 $\kappa v^2$；路径经过奇异附近时，关节对路径的导数很大，只能放慢脚步。

22.5 节讨论位姿的插值。解耦插值让所选的参考点走直线、姿态走测地线，结果与参考点的选取有关；旋量插值让物体绕固定的螺旋轴运动，与基座和物体坐标系的选取都无关。多个姿态之间，用 $\omega_b = A(r)^{\mathsf T}\dot r$ 构造的姿态样条使角速度连续。

22.6 节在路径给定后求最快的时间规律。以 x = $\dot\sigma^2$、u = $\ddot\sigma$ 为变量，速度、加速度限值都是线性的；可控集是区间，从终点往回求出“刹得住”的上界，再从起点往前每步取最大的加速度，就得到时间最优的轨迹，直线路径上它就是梯形曲线。时间最优的转移比样条缩放快约两成，但加速度是 bang-bang 的，振动造成的等待把省下的时间又赔了进去；把它滤波、限值打一个折扣，上下料工位的半个循环从每点停下的 {{ex22_6.cyc_stop:.2f}} s 缩短到 {{ex22_6.cyc_fir:.2f}} s。

| 概念 | 一句话 |
|---|---|
| 路径 | 只有几何形状、不含时间的曲线 θ(s) |
| 轨迹 | 路径加上时间规律：每一时刻在哪里 |
| 时间标度 | 单调的 s(t)，从 0 到 1，决定沿路径走的快慢 |
| 点到点运动 | 只规定起点和终点、各关节同步起止的运动 |
| 最小加加速度轨迹 | 使加加速度平方积分最小的轨迹，点到点时就是五次多项式 |
| 梯形速度曲线 | 加速、匀速、减速三段，速度和加速度有界时最快 |
| S 形速度曲线 | 加加速度有界的七段曲线，即梯形曲线的滑动平均 |
| 残余振动 | 运动结束后，弹性部件仍在继续的振动 |
| 三次样条 | 经过路径点、处处二阶导数连续的分段三次多项式 |
| 抛物线过渡 | 在路径点附近用匀加速的一段连接两条直线段 |
| 直线插补、圆弧插补 | 让末端沿直线、圆弧运动，在每个控制周期算出关节角 |
| 弧长参数化 | 改用走过的弧长作路径参数，使匀速运动成为可能 |
| 解耦插值 | 参考点走直线、姿态走测地线 |
| 旋量插值 | 绕固定的螺旋轴运动，与坐标系的选取无关 |
| 相平面 | 以路径参数和它的速度为坐标的平面 |
| 速度上限曲线 | 相平面上满足全部限值的最大速度 |
| 可控集 | 从某一点出发还能在终点停下的速度范围 |
| 时间最优路径参数化 | 沿给定路径、在限值内用时最短的时间规律 |
