title: 本章小结
---

本章的主线可以用一句话概括：**四旋翼的四个推力互相平行，所以位置只能通过姿态来改变。**

21.1 节从结构上看到了这一点。四个推力沿 $z_b$，反扭矩也沿 $z_b$，六维的力旋量中旋翼只能产生沿 $z_b$ 的力和三个力矩，力旋量矩阵有两行恒为零。对 X 形布局、对角旋翼同向转的四旋翼，推力分配矩阵的四行两两正交，总推力、横滚、俯仰、偏航四个通道互不干扰；偏航力矩只能靠很小的反扭矩系数产生，是最弱的通道。每个旋翼的推力都有上下限，平均推力离两端越近，力矩能力越小。

21.2 节把结构上的事实变成运动上的关系。由质心的运动方程，推力加速度 $\ddot p + \mathfrak g\hat z$ 必须沿 $z_b$：加速度决定了总推力和 $z_b$ 的方向，偏航角决定了剩下的那个转动。再求一次导数，加加速度决定了物体角速度的前两个分量。位置经过两次积分接姿态，姿态经过两次积分接力矩，水平位置离力矩隔着四次积分。加速度计在飞行中只能读到沿 $z_b$ 的比力，感觉不到倾斜。

21.3 节给欠驱动一个精确的说法：输入矩阵的秩小于自由度数。四旋翼的秩为 4，缺的是 $x_b$、$y_b$ 两个方向的推力加速度，这是对加速度的二阶非完整约束。它不妨碍四旋翼到达任何位置和姿态，但使它只能水平地悬停，并且每次平移都要先转身；横移算例中，转身的时间使用时比全驱动的极限多 18%。把旋翼倾斜可以得到全驱动的飞行器，代价是悬停效率。

21.4 节说明，四旋翼虽然欠驱动，却是微分平坦的：位置和偏航角是平坦输出，姿态、推力、角速度、角加速度都由它们的导数经代数运算得到，不需要积分微分方程。轨迹规划因此归结为画一条足够光滑的曲线。最小 snap 样条每段是 7 次多项式，与悬停状态光滑衔接；配合时间分配的优化和时间缩放，就能在限制之内为巡检任务生成最快的轨迹。第 28 章将补上从角加速度到力矩、从推力到转速的动力学，第 49 章将用平坦性给出的前馈和 SO(3) 上的反馈让四旋翼跟踪这样的轨迹。

| 概念 | 一句话 |
|---|---|
| 推力分配矩阵 | 把四个推力换成总推力和三个力矩的 4×4 矩阵，由几何和反扭矩系数决定 |
| 反扭矩 | 旋翼转动时机身受到的反向力矩，与推力成正比，对角旋翼同向转使它们相互抵消 |
| 推力加速度 | $\ddot p + \mathfrak g\hat z$，推力单独产生的加速度，必须沿 $z_b$ |
| 协调转弯 | 机头沿飞行方向、推力的倾斜恰在机身左右方向上的转弯 |
| 欠驱动 | 输入矩阵的秩小于自由度数 |
| 二阶非完整约束 | 不能积分成速度或位置约束的加速度约束 |
| 串级控制 | 外层由位置误差求想要的加速度和姿态，内层用力矩跟踪姿态 |
| 微分平坦 | 状态和输入都是某组输出（平坦输出）及其导数的函数 |
| 最小 snap 轨迹 | 使位置四阶导数平方积分最小的过航点轨迹，每段 7 次多项式 |
