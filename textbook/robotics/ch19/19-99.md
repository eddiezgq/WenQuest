title: 本章小结
---

本章的主线是：**车轮只能沿车轮平面滚动、不能侧滑，这给车体加上了速度的约束；约束限制的是每一时刻能往哪里动，而不是最终能到哪里。**

每一个标准轮给出两个条件：纯滚动条件告诉我们车轮该转多快，不侧滑条件才是加给车体的约束。把一辆车所有标准轮的不侧滑条件排在一起，得到约束矩阵，3 减去它的秩就是可移动度。几何上，所有标准轮的轴线必须交于一点，这一点就是瞬心；交不到一点，就必有车轮侧滑。脚轮和瑞典轮不加约束，前者不能驱动，后者能。允许的运动写成无漂移系统 $\dot q = G(q)u$，各输入方向是构型空间上的矢量场；它们的李括号给出交替运动的净效果，反复的李括号张成全空间时，由周-拉舍夫斯基定理，车可以到达任何位姿。李括号的秩比维数少几，就藏着几个完整约束。

差速驱动的车靠两轮的速度差转向，两轮转速与车速、角速度之间是一个可逆的线性关系，瞬心在两轮的轴线上滑动；两轮匀速时车走圆弧，位姿的变化就是 SE(2) 中的指数，可以精确积分。沿真实路线行驶，要在轮速和加速度的限制下规划车速，再由曲率求出两轮转速；拐角处的减速使实际时间比按路程除以车速的估计长不少。全向轮和麦克纳姆轮的辊子“让开”了侧向，车可以任意横移和原地转；四轮底盘多一个轮子，就多一个相容条件，可以用来发现打滑，装错辊子则会使某个方向失控。阿克曼转向让两前轮转过不同的角度，使四条轴线交于后轴延长线上一点；车的角速度由车速和转向角共同决定，所以不能原地转，转弯半径有下限，横移是第二层李括号，侧方停车要靠两段反向的圆弧。

里程计把每个周期的轮转角增量换成位姿增量逐步累加。圆弧精确更新就是 SE(2) 上的李群积分，没有离散化误差。剩下的误差有两类：轮径差、轮距误差等系统误差，可以用直行、原地转和正方形双向测试标定；随机误差则不可避免，航向误差按距离的平方根增长，又被行驶距离放大成横向误差，横向标准差按距离的 3/2 次方增长。所以里程计只能在短距离内可靠，需要地面标志、激光雷达或视觉定期校正，这是第 46、47 章的内容。

| 概念 | 一句话 |
|---|---|
| 纯滚动 | 车轮与地面的接触点相对地面速度为零：既不打滑，也不侧滑 |
| 标准轮、脚轮、瑞典轮 | 标准轮加一个约束；脚轮因偏距而不加约束但不能驱动；瑞典轮靠辊子不加约束且能驱动 |
| 可移动度 | 此刻能动的独立方向数，等于 3 减去约束矩阵的秩 |
| 瞬心定理 | 标准轮都不侧滑，当且仅当它们的轴线交于一点（瞬心） |
| 无漂移系统 | 输入为零时状态不变的系统，轮式车的运动学模型都是 |
| 李括号 | 两个运动交替进行、再分别撤销的净效果的方向 |
| 可控性 | 能从任一构型到达任一构型；无漂移系统由李代数秩条件判断 |
| 相容条件 | 冗余车轮的转速之间必须满足的关系，违反说明有轮子打滑 |
| 阿克曼转向 | 内侧前轮比外侧转得多，使四条轮轴线交于一点 |
| 航位推算 | 由速度和航向逐步累加推算位置，误差随距离累积 |
| 系统误差、随机误差 | 前者方向一致可以标定；后者不可预测，方差随距离增长 |
