### 11.4.1 拉的平均应力有害

同样的应力幅，平均应力是拉的，寿命短；是压的，寿命长。拉应力把微裂纹撑开，压应力把它压合。σ₋₁ 是 σm = 0 时测的，σm ≠ 0 时要换算：在 σm–σa 坐标里，把“寿命相同”的点连起来，叫**极限应力线图**（海格图，图 11.4.1）。它在纵轴上的截距是 σ₋₁，在横轴上的截距是抗拉强度 R_m（静载断裂）。几种常用的近似：

$$\text{古德曼：}\ \frac{\sigma_\mathrm a}{\sigma_{-1}} + \frac{\sigma_\mathrm m}{R_\mathrm m} = 1\qquad \text{格伯：}\ \frac{\sigma_\mathrm a}{\sigma_{-1}} + \left(\frac{\sigma_\mathrm m}{R_\mathrm m}\right)^2 = 1\qquad \text{索德伯格：}\ \frac{\sigma_\mathrm a}{\sigma_{-1}} + \frac{\sigma_\mathrm m}{\sigma_\mathrm s} = 1 \tag{11.4.1}$$

把它们反过来用，就是**平均应力修正**：把一个 (σa, σm) 的循环换成寿命相同的对称循环的应力幅 σa,eq，例如古德曼 σa,eq = σa/(1 − σm/R_m)，再查 S–N 曲线。另一种常用的是史密斯–沃森–托珀（SWT）参数 σa,eq = √(σmax·σa)，它不用 R_m，对受拉平均应力大的情形（以及铝合金）常与试验符合得更好。

- **古德曼线**偏保守，最常用；数字工厂的疲劳程序、第 33 章的 DIN 743 方法都用它的思路。
- **格伯抛物线**通过试验点的中间，偏危险一点，塑性好的钢常用。
- 索德伯格线以屈服强度为截距，最保守，同时保证不屈服；现在用得少，一般另外校核屈服（图中的点线 σa + σm = σs）。
- 平均应力是压的：古德曼、格伯在 σm < 0 一侧不可靠。保守的做法是压的平均应力不计好处（σa,eq = σa）；数字工厂的程序取 |σm|，把压的平均应力也当作有害，更保守一些。

（括号里是等效应力幅比 σa 大的百分数。）

(1) 是 WQ-CR5 跑一个标准节拍时，大臂根部内角最大主应力平均值最大的那个点（θ = {{ex11_3.th1:.0f}}°；看平均应力的影响，所以选平均应力最大的点，它与 11.5、11.6 节按损伤找出的最危险点 θ ≈ 120° 相邻）：重力使它一直受拉，雨流计数得到的最大一个循环平均应力是应力幅的 {{ex11_3.ratio1:.1f}} 倍，R = {{ex11_3.r1:.2f}}。(2) 是 RJ-201 输出轴（第 33 章）的花键段在谐波减速器启停允许峰值转矩 {{ex11_3.T_rep:.0f}} N·m 下起停：τ = {{ex11_3.tau:.1f}} MPa，当量应力 √3τ = {{ex11_3.smax2:.1f}} MPa，0 → 峰值 → 0。(3) 是第 17 章螺栓的预告：预紧使平均应力很大。

可以看到：平均应力只是 R_m 的几个百分点时（(1)、(2)），三种基于 R_m 的修正几乎一样，只有 SWT 明显大——SWT 在 R = 0 时总是给出 √2 倍，它对“0 → 峰值 → 0”的循环更严厉。平均应力达到强度的一半时（(3)），几种方法差一两倍，选哪一种就很要紧了：按平均应力不变、应力幅放大的倍数算，古德曼给出的安全系数 {{ex11_3.Sm_goodman3:.2f}}、格伯 {{ex11_3.Sm_gerber3:.2f}}、SWT {{ex11_3.Sm_swt3:.2f}}、索德伯格 {{ex11_3.Sm_soderberg3:.2f}}。不过格伯和 SWT 允许的最大应力已经超过屈服强度，这里实际由屈服线 σa + σm = σs 控制——这正是另外校核屈服的原因。

注意 (1) 和 (2) 的绝对值：大臂根部内角的应力幅只有 6 MPa 左右，RJ-201 花键段的当量应力只有二十几兆帕，与疲劳极限相比都非常小——这两个零件的尺寸是由刚度定的（第 9 章、第 33 章），疲劳不是问题。不过 (2) 用的是花键小径处的名义应力，没有计入齿根的应力集中；(1) 的应力已经是有限元在圆角上的局部值。

**工程师笔记**

- 残余应力就是平均应力。焊缝附近的残余拉应力可达屈服强度，所以焊接结构的疲劳强度几乎与外载的平均应力无关，只看应力变程（IIW 的推荐和欧洲规范 3（钢）、9（铝）都这样处理，11.9 节）；喷丸、滚压留下的残余压应力则大大提高疲劳强度。
- 螺栓的预紧力造成很大的平均应力，但外载在螺栓里引起的应力幅很小（第 17 章），所以螺栓的疲劳校核主要看应力幅，标准直接给出允许的应力幅。
- 平均应力修正的选择对低平均应力几乎无所谓，对高平均应力差别很大。有试验数据时，按试验选；没有时用古德曼，并另外校核屈服。
