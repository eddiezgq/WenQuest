### 11.9.1 FKM 准则

前面各节的系数，工程上要有一套统一的规则来取，才能在设计、评审、认证之间说得清楚。德国机械制造联合会的研究机构（FKM）编制的**FKM 准则**（《机械零件的计算强度评定》）是机械行业最常用的一套，覆盖钢、铸铁、铝合金，静强度和疲劳强度都有。第 33 章用的 DIN 743 是专门针对轴的标准，与 FKM 思路相同。

FKM 有两条路：**名义应力法**（按梁、板公式算名义应力，缺口用 Kf）和**局部应力法**（直接用有限元在缺口处的局部应力）。后者正适合有限元为主的设计。局部应力法的主要步骤：

1. **材料**：由抗拉强度的设计值求光滑试样的拉压疲劳强度 σ_W,zd = f_W·R_m（钢 f_W = 0.45，变形铝合金 0.30）。
2. **构件**：设计系数 K_WK 汇总了缺口支撑、表面粗糙度、表面处理：K_WK = (1/n_σ)·[1 + (1/K̃_f)(1/K_R − 1)]·1/(K_V K_S)。**支撑系数** n_σ 由缺口处的相对应力梯度 G 算出——应力梯度越陡，高应力区越小，材料越能支撑，这正是 11.3 节 Kt 与 Kf 之差的来源。
3. **平均应力**：平均应力敏感系数 M_σ = a_M·10⁻³·R_m + b_M，按应力比 R 所在的区间求平均应力系数 K_AK（R 在 0 与 0.5 之间时 K_AK = (1 + M_σ/3)/(1 + M_σ)/(1 + (M_σ/3)·σm/σa)）。
4. **循环次数与变幅**：系数 K_BK 由要求的循环次数、载荷谱和 S–N 曲线算出（相当于 11.6 节的迈因纳累积）。铝合金没有疲劳极限，过了拐点 N_D 曲线仍继续下降。
5. **安全系数和利用度**：安全系数 j_D 按失效后果和是否定期检查取（后果严重、不定期检查时 1.5）；**利用度** a = σa / (K_BK·K_AK·σ_WK / j_D) ≤ 1 即通过。

### 11.9.2 算例：WQ-CR5 大臂根部内角

**算例 11.9.1** 应力取 11.6 节临界平面上的最大一个循环：σa = {{ex11_8.sa:.2f}} MPa、σm = {{ex11_8.sm:.2f}} MPa、R = {{ex11_8.R:.2f}}（程序 11.9.1）。

| 步骤 | 取值 | 说明 |
|---|---|---|
| ① R_m 设计值 | {{ex11_8.Rm_min:.0f}} MPa | 6061-T6 挤压管的最低值（ASTM B221）；材料库的 310 MPa 是典型值 |
| σ_W,zd = 0.30 R_m | {{ex11_8.s_wzd:.1f}} MPa | 拉压、高存活率的设计值；材料库的 σ₋₁ = {{ex11_8.s1_lib:.1f}} MPa 是旋转弯曲、50% 存活率的典型值，两者基准不同，不能直接比 |
| ② G ≈ 2/r | {{ex11_8.G:.1f}} mm⁻¹ | r = 2 mm 圆角 |
| 支撑系数 n_σ | {{ex11_8.n_s:.2f}} | 变形铝合金 a_G = 0.05、b_G = 850 MPa |
| 粗糙度 K_R | {{ex11_8.K_R:.3f}} | R_z = {{ex11_8.Rz:.1f}} μm；R_m 取设计值 260 MPa，所以与 11.3 节（取 310 MPa）略有不同 |
| 表面处理 K_S | {{ex11_8.K_S:.1f}} | 阳极氧化，本书取值（11.3 节） |
| 设计系数 K_WK | {{ex11_8.K_WK:.3f}} | 支撑作用大于表面的削弱 |
| σ_WK = σ_W,zd / K_WK | {{ex11_8.s_wk:.1f}} MPa | 构件（局部）疲劳强度 |
| ③ M_σ | {{ex11_8.M_s:.2f}} | a_M = 1.0、b_M = −0.04 |
| K_AK（区间 {{ex11_8.region}}） | {{ex11_8.K_AK:.3f}} | 平均应力使允许的应力幅降低 |
| ④ K_BK | {{ex11_8.K_BK:.3f}} | 每个节拍只有一个大循环（11.6 节），按等幅计；拐点 N_D = 10⁶ 以后斜率 15（本书按 FKM 对铝合金的做法取，以规范原文为准），5 年 ${{ex11_8.N_life:sci1}}$ 次 |
| ⑤ j_D | {{ex11_8.j_D:.1f}} | 与人共处、后果严重，不定期检查 |
| 利用度 a | {{ex11_8.util:.3f}} | ≤ 1，通过 |

利用度只有 {{ex11_8.util:.2f}}，也就是说，在 FKM 要求的安全系数之下，载荷还能放大 {{ex11_8.lam_fkm:.1f}} 倍；不计安全系数是 {{ex11_8.lam_fkm1:.1f}} 倍，与 11.6 节按数字工厂程序（临界平面应力）算出的 {{ex11_8.lam_mach:.1f}} 倍同一量级（图 11.9.1）。两者接近有一部分是巧合：FKM 的支撑系数 n_σ 正好抵消了阳极氧化的削弱，而 11.6 节的算法两样都没算；两者都说明这个零件的疲劳余量很大，但不是彼此独立的印证。

### 11.9.3 对照：如果法兰是焊上去的

**算例 11.9.2** 为了省材料、省加工，把整体机加工的大臂改成铝管两端焊法兰（角焊缝，焊趾在管上）。焊接结构的疲劳按 IIW 的推荐用名义应力法：每种接头形式有一个 **FAT 等级**——2 × 10⁶ 次时允许的应力变程（MPa），S–N 斜率 m = 3，1 × 10⁷ 次以后为水平线（等幅载荷）。焊缝的残余拉应力已经接近屈服，所以只看应力变程，与平均应力无关（11.4 节）。铝合金的管–板角焊缝本书取 FAT {{ex11_8.FAT:.0f}}（按 IIW 的分类取值）；IIW 2016 版在 1 × 10⁷ 次以后改为斜率 m = 22 继续下降，5 年的次数下允许的应力变程 {{ex11_8.ds_L:.1f}} MPa；材料分项系数按安全寿命设计、后果严重取 γ_M = {{ex11_8.gam:.2f}}。变幅载荷本应做迈因纳累积（IIW 取 D = 0.5），本例每个节拍只有一个大循环，按等幅计。

根部截面的名义应力按梁理论算（弯曲 + 轴力；扭转切应力很小，没有计；焊根的失效也没有查，IIW 要求两项都查），一个节拍里圆周上变程最大的一点（θ = {{ex11_8.th_weld:.0f}}°）Δσ = {{ex11_8.dsn:.2f}} MPa，利用度 {{ex11_8.util_weld:.2f}}，载荷还能放大 {{ex11_8.lam_weld:.1f}} 倍（不计 γ_M 是 {{ex11_8.lam_weld1:.1f}} 倍）——不到整体机加工的一半。另外，6061-T6 焊后热影响区的屈服强度约降一半（第 10 章 10.6 节），静强度的余量也小了很多。焊接方案在标准动作下仍然可以用，但快速版、更重的负载或尖锐的碰撞会很快把这点余量吃掉；评审时应要求焊趾打磨或改为整体机加工（任务单 TS-11-1）。

**工程师笔记**

- FKM、DIN 743、IIW、欧洲规范 3 和 9……各有适用范围。一个零件用哪一套，要在设计任务书里写明；客户、认证机构往往指定。书里用的是简化流程，正式评定要按规范全文（变幅载荷、多轴、温度、各种表面处理都有详细规定）。
- 焊接结构的疲劳主要由接头形式决定，与母材强度几乎无关：高强度钢焊接件的 FAT 等级与普通钢一样。焊接结构减重，换高强度材料没有用，要改接头（对接代替角接、把焊缝移出高应力区、焊趾打磨或锤击）。
- 局部应力法要求网格在缺口处收敛（第 10 章 10.4 节）；用网页上整体粗网格的结果直接做 FKM 评定，局部应力偏低，结论偏危险。
