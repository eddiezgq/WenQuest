### 11.10.1 数字工厂的“疲劳寿命”背后

数字工厂“仿真与分析”的“疲劳寿命”页面，背后是 factory/digital/cae/fatigue.py，核心计算交给开源的疲劳库 pyLife（博世公司开发，Apache 许可）：雨流计数用它的四点法，S–N 曲线和损伤用它的 WoehlerCurve。网页上的每个输入对应程序里的一个参数：

| 网页上的输入 | 程序里 | 本章 |
|---|---|---|
| 有限元结果（计算工况） | vm_ref：各表面点的冯·米塞斯应力 | 11.5 节 |
| 计算工况的载荷、载荷谱 | ref_load、series：一个标量序列，应力 = vm_ref × 载荷 / ref_load | 11.5、11.6 节 |
| 材料 | 材料库的 σ₋₁、N_D、k、R_m | 11.2 节 |
| 表面状态 | β：抛光 1.0 … 锻造毛坯 0.55（网页默认磨削 0.92；本章取精车 0.85） | 11.3 节 |
| 尺寸系数 | ε，默认 0.85 | 11.3 节 |
| 附加缺口系数 | Kf，默认 1（有限元已含应力集中） | 11.3 节 |
| 海巴赫修正 | 开（斜率 2k − 1）/ 关（原始迈因纳） | 11.2、11.6 节 |

程序的主干只有十几行（略去了统计和报告）：

```python
cyc = rainflow(series)                               # 重复块的雨流计数：[(幅值, 平均值)]
SD = mat["sigma_1"] * beta * size_factor / kf        # 修正后的疲劳极限
scale = vm / abs(ref_load)                           # 每单位载荷的应力
wc = pd.Series({"SD": SD, "ND": ND, "k_1": k, "k_2": 2 * k - 1}).woehler
for a, m in cyc:
    sa, sm = scale * a, scale * abs(m)
    sa_eq = sa / (1 - sm / Rm)                       # 古德曼，取 |σm|
    D += 1 / wc.cycles(sa_eq)                        # 迈因纳累积
```

### 11.10.2 一步一步重做

**算例 11.10.1** 用网页上的做法算 WQ-CR5 大臂：有限元取示例零件的预设工况（静止伸直，J3 处反力矩 {{ex11_9.M0:.1f}} N·m），载荷谱取一个标准节拍里 J3 反力矩的大小（{{ex11_9.n_series}} 个采样点）。程序 11.10.1 逐步重做：

1. **闭合的块**：载荷谱看作不断重复的块，从 |载荷| 最大处切开、首尾相接（图 11.10.1a），这样雨流计数时每个循环都能闭合。
2. **雨流计数**：pyLife 的四点法对一段记录会留下没闭合的“残余”。程序把块接一遍计数得到 {{ex11_9.n_one}} 个循环、接两遍得到 {{ex11_9.n_two}} 个，相减就是稳态下每块的 {{ex11_9.n_cyc}} 个循环，其中幅值大于 0.001 N·m 的 {{ex11_9.n_amp}} 个（图 11.10.1b）。
3. **疲劳极限**：S_D = σ₋₁ × β × ε / Kf = {{ex11_9.SD:.1f}} MPa（精车 β = {{ex11_9.beta:.2f}}）。
4. **最危险点**：全部表面点里损伤最大的在根部内角 θ = {{ex11_9.th:.0f}}°，计算工况下的冯·米塞斯应力 {{ex11_9.vm:.2f}} MPa，每 N·m 载荷 {{ex11_9.scale:.4f}} MPa。最大的一个循环：载荷幅 {{ex11_9.a1:.2f}}、平均 {{ex11_9.m1:.2f}} N·m → σa = {{ex11_9.sa1:.2f}}、σm = {{ex11_9.sm1:.2f}} MPa → 古德曼 σa,eq = {{ex11_9.saeq1:.2f}} MPa → 安全系数 {{ex11_9.S_fat:.1f}}。
5. **迈因纳累积**：逐个循环查 N 再相加，与 fatigue.compute 的结果{{ex11_9.same_txt}}。

这个安全系数与 11.5 节 (a) 相同——它就是数字工厂现在的做法。11.5 节已经说明，对 WQ-CR5 这种弯矩方向在转的零件，它比临界平面法偏危险。

### 11.10.3 它的假设和局限

读数字工厂（以及大多数商用软件的简化疲劳模块）的结果时，要记住这些假设：

- **比例加载**：只有一个计算工况和一个标量载荷谱，各点应力同比例变化。多个载荷不同步、方向在转时偏危险（11.5 节）。
- **|冯·米塞斯| 当量应力**：没有正负，应力反号的循环会被算成脉动循环（11.5 节）；平均应力取 |σm|，压的平均应力也当作有害（偏保守）。
- **只看表面点、线弹性**：不考虑局部屈服（低周疲劳用 11.7 节的方法），不考虑缺口支撑（偏保守，FKM 的 n_σ）。
- **系数要用户自己给**：β 按钢的典型值，铝合金、阳极氧化、可靠度、腐蚀都要用户通过 Kf 补上。

这些不是缺点，而是一个教学平台要先讲清楚的边界。书里的程序（_ch11.py）补上了多分量叠加和临界平面；第 11 章的施工记录里已经请数字工厂增加带符号的当量应力和多分量载荷历程。

**工程师笔记**

- pyLife 是开源的，可以直接在自己的计算书里调用（数字工厂、本书的程序都这样做）。它还有本书没用到的功能：概率 S–N 曲线、FKM 的非线性方法、多轴的临界平面——需要时查它的文档。
- 用任何疲劳软件，先用一个能手算的情形核对（例如等幅对称循环，fatigue.hand_check），再算真实的零件。
- 报告里要写清所有输入：载荷谱的来源、材料参数、表面、尺寸、Kf、是否海巴赫、平均应力修正方法。只给一个“寿命 xx 小时”，别人无法复核。
