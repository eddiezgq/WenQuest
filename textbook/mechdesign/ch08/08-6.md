### 8.6.1 任意方向上的应力

在一点取一个小单元体，各个面上的应力合起来叫这一点的**应力状态**。零件表面没有外载荷的一点，垂直于表面的应力为零，叫**平面应力**状态，只剩 σx、σy、τxy 三个分量。把单元体转过角度 θ，新的 x′ 面上的应力是

$$\sigma_{x'} = \frac{\sigma_x + \sigma_y}{2} + \frac{\sigma_x - \sigma_y}{2}\cos 2\theta + \tau_{xy}\sin 2\theta,\qquad
\tau_{x'y'} = -\frac{\sigma_x - \sigma_y}{2}\sin 2\theta + \tau_{xy}\cos 2\theta \tag{8.6.1}$$

### 8.6.2 主应力与莫尔圆

转到某个角度，切应力为零，正应力达到最大和最小——这两个面叫**主平面**，上面的正应力叫**主应力**：

$$\sigma_{1,2} = \frac{\sigma_x + \sigma_y}{2} \pm \sqrt{\left(\frac{\sigma_x - \sigma_y}{2}\right)^2 + \tau_{xy}^2},\qquad \tan 2\theta_p = \frac{2\tau_{xy}}{\sigma_x - \sigma_y} \tag{8.6.2}$$

符号约定：正应力拉为正；τxy 在 x 面上沿 +y 方向为正；θ 从 x 轴逆时针量。tan 2θ_p 在 0–180° 内有两个根，相差 90°，分别对应 σ₁ 和 σ₂；取 2θ_p = atan2(2τxy, σx − σy)，得到的就是 σ₁ 的方向（程序 8.6.1 这样算）。莫尔圆上本书把 τ 向下画为正，这样圆上的转向与单元体的转向一致。

再转 45°，切应力最大，等于两个主应力之差的一半。三个主应力按代数值排为 σ₁ ≥ σ₂ ≥ σ₃（平面应力时有一个为零），**最大切应力** τ_max = (σ₁ − σ₃)/2。

把式 (8.6.1) 的两式平方相加，消去 θ，得到一个圆：以 ((σx + σy)/2, 0) 为圆心、以 √(((σx − σy)/2)² + τxy²) 为半径——这就是**莫尔圆**。单元体转 θ，圆上的点转 2θ；圆与 σ 轴的两个交点是主应力，半径是最大切应力（动画 8.6.1）。

### 8.6.3 应变花

一个应变片只能测一个方向的正应变。主方向事先不知道时，在同一点沿三个方向贴三片——**应变花**。最常用的直角应变花，三片分别在 0°、45°、90°：

$$\varepsilon_x = \varepsilon_0,\quad \varepsilon_y = \varepsilon_{90},\quad \gamma_{xy} = 2\varepsilon_{45} - \varepsilon_0 - \varepsilon_{90} \tag{8.6.3}$$

应变也有自己的莫尔圆（把 τ 换成 γ/2），由它求主应变 ε₁、ε₂ 和主方向，再用广义胡克定律（8.1 节）换成主应力。

**算例 8.6.2** 第 33 章用数字工厂的“运动与动力分析”算出了 UR5e 肩关节一个节拍里的力矩和大臂传来的力。取力矩最大的时刻（节拍开始后 {{ex8_6.t_i:.3f}} s）：转矩 {{ex8_6.T_i:.1f}} N·m，大臂的力（合力）{{ex8_6.F_i:.0f}} N，到外侧轴承中心 {{ex8_6.arm:.0f}} mm，在那里产生弯矩 {{ex8_6.M_b:.2f}} N·m；两个轴承之间弯矩线性减小，这里把它当作贴片处弯矩的上限。假设 RJ-201 的 Ø50/Ø30 段表面能贴片（见 8.1 节），贴一个直角应变花（0° 沿轴线），按这个状态算出三片的读数（取到 0.1 µε，当作“测得”的）：ε₀ = {{ex8_6.r0:.1f}} µε，ε₄₅ = {{ex8_6.r45:.1f}} µε，ε₉₀ = {{ex8_6.r90:.1f}} µε。由式 (8.6.3) 反求：主应变 {{ex8_6.e1:.1f}}、{{ex8_6.e2:.1f}} µε，主应力 {{ex8_6.p1:.2f}}、{{ex8_6.p2:.2f}} MPa，σ₁ 与轴线成 {{ex8_6.th2:.1f}}°；与直接由载荷算出的 {{ex8_6.q1:.2f}}、{{ex8_6.q2:.2f}} MPa、{{ex8_6.th_true:.1f}}° 相比，差别来自读数的取整。这个点几乎是纯剪切（图 8.6.1b），弯曲正应力只有 {{ex8_6.sx:.2f}} MPa。

由式 (8.1.3) 和应变的坐标变换，±45° 两个方向的应变是 ε±45 = (εx + εy)/2 ± γxy/2。两片相减，(εx + εy)/2 这一项——弯曲（以及均匀的温度变化，8.10 节）带来的部分——正好抵消，只剩 γxy。这就是 8.1 节的力矩传感器要用 ±45° 全桥的原因：本例 ε₊₄₅ − ε₋₄₅ = {{ex8_6.bridge:.1f}} µε，正好等于扭转引起的切应变 γ = {{ex8_6.gam:.1f}} µε，弯矩一点也没进来。

**工程师笔记**

- 零件表面一般是平面应力，但内部（如赫兹接触的表面下，8.9 节；过盈配合的轮毂，8.7 节）是三向应力。三向应力时，最大切应力由最大和最小两个主应力决定，莫尔圆变成三个圆。
- 应变花要贴在同一点，箔栅越小越好；三片的方向角度贴偏 1°–2°，就会使主方向算错几度，重要测量要标定。
- 判断“这点危险不危险”，看的是主应力和当量应力，不是哪一个分量。
