### 8.7.1 拉梅公式

壁厚与直径相比不很小的圆筒（**厚壁圆筒**）受内压 p_i、外压 p_o 时，径向应力 σr 和周向应力 σθ 沿壁厚变化。拉梅（G. Lamé）在 1852 年的《弹性理论讲义》中给出了解：内半径 a、外半径 b，半径 r 处

$$\sigma_r = A - \frac{B}{r^2},\qquad \sigma_\theta = A + \frac{B}{r^2},\qquad A = \frac{p_i a^2 - p_o b^2}{b^2 - a^2},\quad B = \frac{(p_i - p_o)a^2b^2}{b^2 - a^2} \tag{8.7.1}$$

只受内压时，内壁的周向拉应力最大：σθ,max = p_i (b² + a²)/(b² − a²)，总是大于内压本身。液压缸、高压管、轮毂，都按它计算。

### 8.7.2 过盈配合

轴的直径比孔略大，压装或热装以后，配合面上产生压力 p——**过盈压力**。对轴来说它是外压，对轮毂来说是内压。p 由“两者在配合面上的径向位移之差等于过盈量的一半”求出：

$$p = \frac{\delta}{d\left[\dfrac{1}{E_h}\left(\dfrac{D^2 + d^2}{D^2 - d^2} + \nu_h\right) + \dfrac{1}{E_s}\left(\dfrac{d^2 + d_i^2}{d^2 - d_i^2} - \nu_s\right)\right]} \tag{8.7.2}$$

δ 是直径上的过盈量，d 是配合直径，D 是轮毂外径，d_i 是空心轴的内径（实心轴为 0），下标 h、s 分别表示轮毂和轴。实心轴受外压时，整个截面 σr = σθ = −p；轮毂内壁的周向拉应力最大。

过盈量由轴和孔的极限偏差决定，是一个范围。还有一点常被忽略：配合面的微观凸峰在压装时被压平，实际有效的过盈比按尺寸算的小。DIN 7190-1:2017 的做法是减去 0.4(Rz轴 + Rz孔)（旧版取 0.8，许多手册还在沿用）。

**工程师笔记**

- 过盈配合的计算总要做两头：最小有效过盈下能不能传转矩（不打滑），最大过盈下轮毂会不会屈服、轴承内圈会不会胀裂。
- 压装会刮伤配合面，使有效过盈变小、可传转矩降低；热装和冷装更好，但要控制温度。
- 轮毂越薄（D/d 越小），同样过盈下的接触压力越小、轮毂应力越大；D/d 小于约 1.4 的薄轮毂，不宜用大过盈。
