# 《机械设计》符号约定（v0.1，2026-10-02，待 Eddie 审阅）

全书统一使用本约定。正文、计算书、程序、插图、动画、实验、工程任务单都以它为准。新增符号先登记在这里，再在正文中使用。

## 一、总原则

1. **国内通行写法为主，注明英文教材写法**。机械设计的计算公式与国家标准紧密相连（GB/T 3480、GB/T 6391 等），符号以国内教材和国家标准为主；一个符号第一次出现时，用一句话注明 Shigley、Norton 等英文教材的写法，第八节列出全部对照。英文版改用英文教材写法，并在第一次出现时注明中文版写法。
2. **一个符号只表示一种东西**。确有冲突时（如 $S$ 在国内教材里是安全系数，在 Shigley 中是强度），以本约定为准，并在该节开头说明。
3. **单位**：国际单位制。设计计算的习惯单位是：力 N 或 kN，长度 mm，应力 MPa（= N/mm²），转矩与弯矩 N·m（代入以 mm 为单位的应力公式时换成 N·mm，并在算式里写明），转速 r/min，功率 kW，寿命 h 或 r（转数）。每个算式写明各量所用单位。
4. **计算书写法**：已知 → 求 → 计算（公式、代入、结果、单位、出处）→ 结论（与许用值比较）。查表得到的系数写出处：标准号 + 表号或图号，例如“$K_\mathrm A$ = 1.25（GB/T 3480.6 表 A.1）”。
5. **程序与书一致**：程序中的变量名与书中符号对应，例如 `sigma_a`、`K_sigma`、`S_ca`；标准表的引用写成 `std.table("GB/T 1096", "表1")` 的形式（见 `textbook/mechdesign/std/`）。

## 二、字体与排版

| 对象 | 写法 | 例 |
|---|---|---|
| 物理量 | 斜体 | $F$, $T$, $d$, $\sigma$ |
| 矢量（少用） | 粗斜体 | $\boldsymbol F$, $\boldsymbol M$ |
| 说明性下标（文字缩写） | 正体 | $\sigma_\mathrm{H}$（齿面接触）、$\sigma_\mathrm{F}$（齿根弯曲）、$K_\mathrm{A}$（使用系数）、$F_\mathrm{r}$（径向）、$F_\mathrm{a}$（轴向）、$\sigma_\mathrm{ca}$（计算应力） |
| 变量下标 | 斜体 | $F_i$, $d_x$ |
| 数字下标 | 正体 | $\sigma_{-1}$, $d_1$, $z_2$ |
| 函数与算符 | 正体 | $\sin$, $\ln$, $\max$ |
| 牌号、代号 | 正体，不加数学环境 | 45 钢、40Cr、6208、M12×1.75、H7/k6 |

## 九、图样与工程文件

- 图样按 GB/T 4457～4460、GB/T 14689 等制图标准；英文版图样按 ISO 128 系列，第一角投影（中国、欧洲通用），第 3 章说明第三角投影（美国）的区别。
- 物料编码与数字工厂一致：零件号如 SH-301（输出轴），零件库编号如 `A-BRG-TR`（圆锥滚子轴承）。图号、版本号、更改单号的写法见第 3.10 节和第 44 章。
- 计算书、分析报告、任务单的文件名：`<零件号>_<文件类别>_<版本>`，如 `SH-301_计算书_B.docx`。
