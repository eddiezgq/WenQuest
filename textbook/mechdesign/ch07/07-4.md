### 7.4.1 从时间历程到循环

疲劳损伤取决于载荷循环的大小和次数（第 11 章）。可实际记录下来的载荷是一条不规则的曲线（图 7.2.1c），哪里算一个循环？不同的“数法”会得到不同的结果。工程上通用的方法是**雨流计数**（rainflow counting），由日本的松石（M. Matsuishi）和远藤（T. Endo）在 1968 年提出，ASTM E1049 把它写成了标准的算法。它的思路是：把时间历程竖起来，想象雨水从屋檐（峰、谷）往下流，流到哪里停下，就对应一个闭合的应力–应变滞回环，也就是材料“感受到”的一个循环。

计算时用 ASTM E1049 的三点法：

1. 只保留**转折点**（峰和谷），去掉中间的点；
2. 按顺序把转折点压入一个栈。每压入一个，看栈顶的三个点 A、B、C：X = |C − B| 是最新的一段，Y = |B − A| 是前一段；
3. 若 X < Y，继续读下一个点；若 X ≥ Y：Y 段包含记录的起点时，记 Y 为**半循环**并去掉起点；否则记 Y 为一个**全循环**（范围 Y，平均值 (A + B)/2），从栈中去掉 A、B，回到第 2 步再比较；
4. 记录读完后，栈里剩下的每一段各记为半循环。

每个循环有范围（峰谷差，幅值是它的一半）和平均值两个量。

**算例 7.4.1** 程序 7.4.1 先用 ASTM E1049 标准里的例子（−2, 1, −3, 5, −1, 3, −4, 4, −2）核对自己写的雨流计数，结果与标准的表{{ex7_4.astm_ok}}。再处理跑合试验台的转矩记录（图 7.4.1a）：三次起停记出相当于 {{ex7_4.n_big:.0f}} 个大循环（峰值一次比一次高，没有闭合，实际是 6 个半循环），范围 {{ex7_4.big_range_lo:.0f}}–{{ex7_4.big_range_hi:.0f}} N·m（从零到起动峰值再回到零，略大于峰值是因为停机后的读数有小的负值），正好是三次起停；运行中的波动记出 {{ex7_4.n_small:.1f}} 个小循环，每秒约 {{ex7_4.small_per_s:.1f}} 个，95% 的幅值不超过 {{ex7_4.a95:.0f}} N·m。

数字孪生的客户现场没有把这样的原始记录发回工厂——每台减速器每天十几个小时、每秒十个点，数据太多。现场的采集器（边缘端）在本地做好雨流计数，只上报结果，而且做了简化：每次起停记成一个 0 → 峰值 → 0 的大循环，运行中的波动记成幅值 {{ex7_4.twin_ripple}} N·m（额定的 8%）、每秒半个的小循环。与试验台记录的逐点计数比：大循环的处理一致；小循环的次数少了（噪声产生的小循环没有计），幅值也略小。7.3 节已经看到，小循环对扭转疲劳几乎没有贡献，这个简化对结论影响不大；但如果零件对小循环敏感（比如 m 小的失效形式，或小循环的幅值接近疲劳极限），就要上报更完整的计数。

### 7.4.2 载荷谱与外推

把雨流计数的结果按幅值分档、从大到小累计次数，画成“幅值–累积次数”曲线，就是**载荷谱**（累积频次图，图 7.4.1b）。横坐标用对数，一眼可以看出：大载荷次数少，小载荷次数多；最大的几个循环决定了曲线的头，大量的小循环拖出长长的尾巴。

设计寿命往往比能测到的数据长得多。最简单的**外推**是按时间比例放大次数：

**算例 7.4.2** 矿山皮带机一年运行 {{ex7_4.run_h:.0f}} h，设计寿命 {{ex7_4.life_h:.0f}} 运行小时相当于 {{ex7_4.years:.1f}} 年，各档次数乘 {{ex7_4.scale:.2f}}。外推后约有 {{ex7_4.n_starts:.0f}} 次起停、总共约 {{ex7_4.n_total_m:.0f}} 万个循环，最大幅值 {{ex7_4.a_max:.0f}} N·m（卡料时的峰值的一半）。

按比例外推有一个缺陷：最大值不会变大。实际上测得越久，遇到的最大载荷越大——一年里没有遇到的严重卡料，五年里可能遇到。严格的外推要用统计方法（如按极值分布外推载荷谱的头部），这超出了本书的范围；设计时至少要在外推谱上加一个“极端载荷”，由客户的过载保护（安全联轴器、电机的过流保护）的动作值确定。

### 7.4.3 当量载荷

一个载荷谱有几十档，强度计算时用一个**当量载荷**代替：它作用同样多次（或参考次数 N_ref）造成的损伤，与整个谱造成的相同。按线性累积损伤（Miner 法则，第 11 章）和斜率为 m 的 S-N 曲线，

$$S_{eq} = \left(\frac{\sum n_i S_i^{\,m}}{N_{ref}}\right)^{1/m} \tag{7.4.1}$$

nᵢ 是幅值为 Sᵢ 的循环次数。式 (7.3.2) 是它的特例（N_ref 取总转数）。

对 WQR-105 输出轴的扭转，取 m = {{ex7_4.m_sh:.0f}}，N_ref 取寿命期内的起停次数，矿山皮带机的当量幅值是 {{ex7_4.a_eq:.0f}} N·m（图 7.4.1b 中的虚线），相当于每次起停的峰值 {{ex7_4.peak_eq:.0f}} N·m。运行中几千万个小循环只占损伤的 {{ex7_4.damage_share_run:.4f}}%。所以，输出轴扭转疲劳的设计载荷可以写成：“{{ex7_4.n_starts:.0f}} 次 0 → {{ex7_4.peak_eq:.0f}} N·m → 0 的脉动循环”，再加上前面说的极端载荷做静强度校核。这正是第 11 章疲劳校核要用的输入。

### 7.4.4 从运行记录到设计载荷的步骤

1. 确定要测（或要取）的量：转矩、力、应变，采样频率要能抓住冲击的峰值；
2. 取有代表性的工况，记录足够长的时间（至少覆盖一个完整的生产周期：开机、满载、空载、停机）；
3. 雨流计数，得到各档幅值（和平均值）的次数；
4. 外推到设计寿命，补上极端载荷；
5. 按失效形式选指数 m 和参考次数，求当量载荷；静强度用最大值；
6. 写进载荷说明书，并在产品投入使用后用现场数据核对（数字孪生）。

**工程师笔记**

- 雨流计数只看转折点的顺序，不看时间——两段记录拼在一起和分开数，结果略有不同（拼接处会多出或少掉一个大循环）。长记录要整段数；对重复的载荷块，ASTM E1049 给出了从最大峰（或谷）处重排记录再计数的简化方法。
- 雨流计数丢掉了频率和先后顺序。对有腐蚀、高温（蠕变）或顺序效应明显的材料，只看载荷谱是不够的。
- 采样太慢会削掉冲击峰值：试验台的 10 Hz 记录对起动冲击（上升约 1 s）够用，对齿轮啮合的冲击（毫秒级）就不够了。
