### 3.8.1 问题的提出

输送线有轻载、中载、重载三种，滚筒分别用 6205、6207、6209 轴承，每种都要一个轴承座。在 CAD 里可以建一个参数化模型，再用“设计表”生成三个规格。还有另一种办法：把设计规则和建模步骤写成一个程序，输入轴承型号，程序算出全部尺寸、生成三维模型、导出 STEP 文件——这就是代码建模。

### 3.8.2 为什么要用代码建模

用代码建模（build123d、CadQuery、OpenSCAD 等）和在 CAD 界面里点鼠标建模，得到的都是同样的实体模型。代码的好处是：

- **规则写得明明白白**：壁厚、中心高、螺栓规格怎样从轴承型号推出来，全在程序里，任何人都能读、能检查；
- **能比较、能追溯**：程序是文本，可以用 Git 管理，两个版本差在哪里一目了然；
- **能批量生成**：一个循环就生成整个产品系列，再自动出图、算质量、导出 STEP；
- **能接进自动化流程**：数字工厂的在线设计台（SH-301）、零件库的标准件模型、本书的插图，都是用 build123d 程序生成的。

代价是：形状复杂、需要反复凭眼睛调整的零件（如外观曲面），用代码不如用交互式 CAD 方便。工程中两者常常配合：主体和系列化的零件用代码，外观件用 CAD。

### 3.8.3 参数化轴承座

**算例 3.8.1** 程序 3.8.1 分两步：`params(轴承型号)` 按设计规则算出全部尺寸，`model(参数)` 按特征的顺序生成实体。设计规则是：

- 轴承尺寸 d、D、B 从本书的标准表（GB/T 276）读取；
- 壁厚 = 0.12D + 3（取整），圆弧半径 Ro = D/2 + 壁厚；
- 中心高 H 取不小于 Ro + 2 的 R20 优先数（第 2.6 节）——同一系列的中心高落在优先数上，机架的横梁好配；
- 座宽 = 轴承宽 + 14（端盖止口 4 + 挡肩 10），底板宽比座宽大 12；
- 地脚螺栓：D ≤ 52 用 M8，D ≤ 72 用 M10，再大用 M12；孔距 = 2(Ro + 孔径 + 2)，底板长 = 孔距 + 3 倍孔径。

build123d 的写法很像“说话”：`Box(L, Wb, tb)` 是一个长方体，`Pos(x, y, z) *` 把它移到某处，`+` 是并、`−` 是差，`Cylinder(r, h)` 是圆柱。整个程序去掉注释和空行只有 {{ex3_8.n_lines}} 行。三个规格（图 3.8.1）：

- 6205：中心高 {{ex3_8.H5}} mm，底板长 {{ex3_8.L5:.0f}} mm，{{ex3_8.bolt5}} 地脚螺栓，质量约 {{ex3_8.m5:.2f}} kg；
- 6207：中心高 {{ex3_8.H7}} mm，底板长 {{ex3_8.L7:.0f}} mm，质量约 {{ex3_8.m7:.2f}} kg；
- 6209：中心高 {{ex3_8.H9}} mm，底板长 {{ex3_8.L9:.0f}} mm，{{ex3_8.bolt9}} 地脚螺栓，质量约 {{ex3_8.m9:.2f}} kg。

质量按灰铸铁 HT200（7.2 g/cm³）计算。程序同时把每个规格导出为 STEP 文件——6207 的模型有 {{ex3_8.faces7}} 个面，STEP 文件约 {{ex3_8.step7:.0f}} kB。STEP（ISO 10303）是各种 CAD、CAE、CAM 软件之间交换三维模型的标准格式：数字工厂的“仿真与分析”、数控编程和设计发布读的都是它。

### 3.8.4 与数字工厂的关系

数字工厂的“设计与工艺”页有一个在线设计台：SH-301 的各段直径和长度、圆角、键槽都是参数，学生改参数，服务器用 build123d 重新生成模型和图纸，再提交设计发布（第 33.9 节）。零件库里一千多个规格的三维模型也是这样生成的：每一族零件一个生成程序，规格表里的每一行生成一个模型。FreeCAD 也可以运行同样的 Python 代码——问渠的 FreeCAD 宏就是用代码建 SH-301 的。

---

**工程师笔记**

- 设计规则里的系数（如壁厚 0.12D + 3）要有出处：来自标准、手册、公司的经验，还是计算；没有出处的规则要做试验或分析验证。
- 程序生成的模型也要检查：程序里写错一个符号，整个系列都会错。用断言（`assert`）核对关键数值，是最便宜的检查。
- 代码模型交给别人时，交 STEP（结果）也交程序（意图）。
