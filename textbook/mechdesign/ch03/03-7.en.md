### 3.7.1 The problem

The load on the conveyor has increased, and the roller bearings are to be changed from 6207 to 6209. If the pillow block was "drawn" in CAD, with every line length a fixed number, it has to be drawn again. If it was made by **parametric modeling**, changing the bearing outer diameter from 72 to 85 is enough, and the model grows by itself. But is the grown model still right? That depends on whether the "design intent" was built into the model.

### 3.7.2 Sketches and constraints

Parametric modeling starts from a **sketch**, a rough outline drawn on a plane, to which **constraints** are then added to "pin it down". Constraints are of two kinds:

- **Geometric constraints**: horizontal, vertical, parallel, perpendicular, tangent, concentric, symmetric, coincident and so on, which fix the relations between elements;
- **Dimensional constraints**: lengths, radii, angles and so on, which fix sizes. A constraint may be written as an expression referring to other dimensions or parameters.

Every point of a sketch has two coordinates and every circle a radius as well; these are the unknowns. Each constraint is an equation. The number of unknowns minus the number of independent equations is the number of degrees of freedom left in the sketch. If it is greater than zero, the sketch is **under-constrained** (it can still be dragged); if it is zero, it is **fully constrained**; if there are surplus equations, it is **over-constrained** (redundant or contradictory, and CAD reports an error or a warning).

**Example 3.7.1** The sketch of the front outline of the pillow block (Figure 3.7.1a): 9 points (A, B, C and K of the base, D and G of the upright, the arc end points E and F, and the center O) plus the bearing bore radius make {{ex3_7.nv}} unknowns. First {{ex3_7.n_geo}} geometric constraints are added: the bottom edge horizontal, the other edges horizontal or vertical, the arc tangent to the vertical lines at E and F (end points level with the center), left-right symmetry, the midpoint of the bottom edge at the origin, and the top faces of the base on both sides at the same height. This leaves {{ex3_7.dof_free}} degrees of freedom. Then 5 dimensions are added: bearing bore diameter = D, center height H, base length L, base thickness tb, and arc radius = bearing bore radius + wall thickness. The degrees of freedom become {{ex3_7.dof_full}}, and the sketch is fully constrained. Program 3.7.1 solves for the outline that satisfies all the constraints by Newton's method, starting from the "hand-drawn" position (from the dashed outline to the continuous one), and counts the degrees of freedom from the rank of the Jacobian matrix of the constraint equations. If one more dimension, "distance between the two vertical edges = 2Ro", is added, the rank does not increase and there are {{ex3_7.red_over}} redundant constraints: the new dimension repeats the existing constraints, and CAD warns that the sketch is "over-constrained".

### 3.7.3 Design intent

Two sketches may both be fully constrained and yet be dimensioned in very different ways. Figure 3.7.1b changes the bearing outer diameter from {{ex3_7.D7}} to {{ex3_7.D9}} (6209):

- With the arc radius constrained as "bearing bore radius + wall thickness" (the wall thickness growing with the outer diameter by rule), the arc grows with the bore, the wall is {{ex3_7.wall9:.0f}} mm thick, and the model remains sound.
- With the arc radius written directly as {{ex3_7.Ro7:.0f}} mm, the model is still generated, without any error message, but the wall is only {{ex3_7.wall_bad:.1f}} mm thick. This is thinner than the usual minimum wall thickness of gray-iron sand castings: it is hard to cast and not stiff enough.

This is **design intent**: the relations between dimensions, "which follows which", that represent the designer's thinking. The wall thickness of the pillow block should vary with the bearing, so it must be constrained by an expression. The base length is set by the anchor-bolt holes, and the holes in turn by the arc and the bolts. Only when these dependencies are written into the model does the model "understand" the design. A model with the wrong design intent is perfectly correct with its original parameters, goes wrong as soon as a parameter is changed, and often gives no error message, which makes the problem the hardest of all to find.

### 3.7.4 Features and the feature tree

A three-dimensional model is built up from **features** added one after another. Extrusion, revolution, sweep and loft are basic features that "add" or "remove" material; holes, fillets, chamfers, ribs and patterns are features named for their engineering meaning. CAD lists the features in the order of their creation as a feature tree. Later features refer to the geometry of earlier ones (a fillet, for example, is attached to a particular edge), so when an earlier feature is changed, the later ones are recomputed.

The modeling order should follow the logic of design and machining: first the main body, then the main holes, then the details (fillets, chamfers). For the pillow block the order is base → upright and arc → stepped bore → anchor-bolt holes → base recess → oil hole (Program 3.8.1). Fillets and chamfers come last; otherwise, when an earlier feature changes, a fillet attached to an edge may fail to find its edge.

**Engineer's notes**

- Before modeling, be clear about which dimensions are inputs (such as the bearing designation), which are calculated by rules, and which are independent; write these relations into constraints and expressions.
- Sketches must always be fully constrained: an under-constrained sketch may "drift" when something elsewhere changes, without any error message.
- When you take over someone else's model, first change a few key parameters and see whether the model changes according to the design intent. This is the quickest way to check design intent.
