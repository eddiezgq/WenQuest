### 20.4.1 问题的提出

第 5、9、10 章多次用到关节阶跃响应的公式

$$
q(t) = 1 - e^{-\zeta\omega_nt}\Bigl(\cos\omega_dt + \frac{\zeta}{\sqrt{1 - \zeta^2}}\sin\omega_dt\Bigr),\qquad \omega_d = \omega_n\sqrt{1 - \zeta^2} ,
$$

却一直没有说它从哪里来。20.7 节将说明，PD 控制下的关节角满足

$$
\ddot q + 2\zeta\omega_n\dot q + \omega_n^2q = \omega_n^2q_{\text{ref}} , \tag{20.4.1}
$$

$q_{\text{ref}}$ 是目标角度。右边不为零，这是一个非齐次方程。

另一个问题：机械臂快速移动一段距离后停下，末端会抖。20.3 节说，这是上臂在减速器扭转刚度上的振动。振动的大小与运动的快慢有什么关系？能不能让它停下时不抖？

由定理 20.2.5，非齐次方程的通解 = 一个特解 + 齐次方程的通解。齐次方程的通解 20.3 节已经会求了，本节求特解。

### 20.4.2 待定系数法

当常系数方程的右边是多项式、指数函数、正弦余弦或它们的乘积时，求导不会产生新的类型的函数，所以可以猜一个“同类型、系数待定”的特解，代入后比较系数。这叫作**待定系数法**。

| 右边 $f(x)$ | 设特解为 |
|---|---|
| $P_m(x)e^{\lambda x}$（$P_m$ 为 $m$ 次多项式） | $x^sQ_m(x)e^{\lambda x}$ |
| $e^{\alpha x}\bigl(P(x)\cos\beta x + R(x)\sin\beta x\bigr)$ | $x^se^{\alpha x}\bigl(Q_1(x)\cos\beta x + Q_2(x)\sin\beta x\bigr)$ |

表中 $Q$ 是与 $P$、$R$ 中次数较高者同次的待定多项式；$s$ 是 $\lambda$（或 $\alpha + i\beta$）作为特征根的重数，不是特征根时 $s = 0$。乘 $x^s$ 的原因是：若猜的函数本身就是齐次方程的解，代入后左边为零，不可能等于右边。

**算例 20.4.1** 求 $y'' - 3y' + 2y = 4x$ 的通解。

*解*　$\lambda = 0$ 不是特征根（特征根为 1、2），设 $y_p = Ax + B$，代入：$-3A + 2(Ax + B) = 4x$，$A = 2$，$B = 3$。通解 $y = 2x + 3 + c_1e^x + c_2e^{2x}$。　∎

**算例 20.4.2** 推导本节开头的阶跃响应公式：(20.4.1) 中 $q_{\text{ref}} = 1$，$0 < \zeta < 1$，$q(0) = 0$，$\dot q(0) = 0$。

*解*　右边是常数 $\omega_n^2$，0 不是特征根，设 $q_p = A$，得 $A = 1$。通解

$$
q = 1 + e^{-\zeta\omega_nt}(c_1\cos\omega_dt + c_2\sin\omega_dt) .
$$

由 $q(0) = 0$ 得 $c_1 = -1$；$\dot q(0) = -\zeta\omega_nc_1 + \omega_dc_2 = 0$，得 $c_2 = -\frac{\zeta\omega_n}{\omega_d} = -\frac{\zeta}{\sqrt{1 - \zeta^2}}$。这就是开头的公式。取第 5 章的 $\zeta = 0.6$、$\omega_n = 10$ rad/s，$q(0.3) = {{ex20_4.st_q03:.6f}}$，数值解 {{ex20_4.st_q03_num:.6f}}。　∎

特解 $q_p = 1$ 是“稳态”，齐次部分是“暂态”，与一阶系统（19.4 节）的结构相同。

**算例 20.4.3（共振）** 解 $y'' + 4y = \sin 2t$，$y(0) = y'(0) = 0$。

*解*　$\pm 2i$ 是特征根（$s = 1$），设 $y_p = t(A\cos 2t + B\sin 2t)$。代入得 $-4A\sin 2t + 4B\cos 2t = \sin 2t$，$A = -\frac14$，$B = 0$。再由初值，

$$
y = \frac18\sin 2t - \frac t4\cos 2t .
$$

数值解在 $t = 10$ 处得 {{ex20_4.rs_num:.6f}}，公式给出 {{ex20_4.rs_formula:.6f}}。振幅随 $t$ 线性增长，没有上限：外力的频率恰好等于无阻尼系统的固有频率，每个周期都把能量送进去。这就是**共振**，20.6 节详细讨论。　∎

### 20.4.3 常数变易法

右边不是上述类型（例如 $\tan x$、$\frac1x$、实测的外力曲线）时，待定系数法不适用。19.4 节的常数变易法可以推广到二阶。

**定理 20.4.1（常数变易法）** 设 $y_1$、$y_2$ 是 $y'' + py' + qy = 0$ 的基本解组，$W$ 是它们的朗斯基行列式，$f$ 连续。则

$$
y_p = -y_1\int\frac{y_2f}{W}\,dx + y_2\int\frac{y_1f}{W}\,dx \tag{20.4.2}
$$

是 $y'' + py' + qy = f$ 的一个特解。

*证明*　设 $y = u_1y_1 + u_2y_2$，$u_1$、$u_2$ 是待定的函数。两个函数只需满足一个方程，可以再加一个条件，选它使导数的形式简单：

$$
u_1'y_1 + u_2'y_2 = 0 .
$$

于是 $y' = u_1y_1' + u_2y_2'$，$y'' = u_1y_1'' + u_2y_2'' + u_1'y_1' + u_2'y_2'$。代入方程，含 $u_1$、$u_2$ 的项因 $y_1$、$y_2$ 是齐次方程的解而消去，剩下

$$
u_1'y_1' + u_2'y_2' = f .
$$

这两式是关于 $u_1'$、$u_2'$ 的线性方程组，系数行列式为 $W\ne 0$，由克拉默法则 $u_1' = -\frac{y_2f}{W}$，$u_2' = \frac{y_1f}{W}$，积分即得 (20.4.2)。　∎

**算例 20.4.4** 求 $y'' + y = \tan x$（$-\frac\pi2 < x < \frac\pi2$）的一个特解。

*解*　$y_1 = \cos x$，$y_2 = \sin x$，$W = 1$。由 (20.4.2)，

$$
u_1 = -\int\sin x\tan x\,dx = -\int(\sec x - \cos x)\,dx = \sin x - \ln(\sec x + \tan x),\qquad u_2 = \int\cos x\tan x\,dx = -\cos x ,
$$

所以 $y_p = u_1\cos x + u_2\sin x = -\cos x\,\ln(\sec x + \tan x)$。　∎

**振动方程的杜阿梅尔积分。** 对 $\ddot x + 2\zeta\omega_n\dot x + \omega_n^2x = f(t)$（$0\le\zeta < 1$），取 $y_1 = e^{-\zeta\omega_nt}\cos\omega_dt$、$y_2 = e^{-\zeta\omega_nt}\sin\omega_dt$，$W = \omega_de^{-2\zeta\omega_nt}$。用 (20.4.2) 取从 0 到 $t$ 的定积分，合并后得到零初值的解（习题 20.4.5）：

$$
x(t) = \frac{1}{\omega_d}\int_0^te^{-\zeta\omega_n(t - s)}\sin\omega_d(t - s)\,f(s)\,ds . \tag{20.4.3}
$$

与一阶系统的 (19.4.5) 一样，$t$ 时刻的响应是过去各时刻外力的加权和，权重 $\frac1{\omega_d}e^{-\zeta\omega_nu}\sin\omega_du$ 是一个衰减的正弦：过去的外力在系统里“回荡”。它就是系统在 $t = 0$ 时受到一个单位冲量后的响应，叫作冲激响应。

### 20.4.4 让机械臂停下时不抖

**算例 20.4.5** 电机按“先以角加速度 $\alpha_0$ 加速 $T$ 秒，再以 $-\alpha_0$ 减速 $T$ 秒”的规律驱动肩关节，然后停住。上臂相对于电机侧的扭转角 $\varphi$ 满足

$$
\ddot\varphi + 2\zeta\omega_n\dot\varphi + \omega_n^2\varphi = -\alpha(t) ,
$$

（这里假设电机侧严格按指令运动，即理想的伺服，并且不计重力。电机侧加速时，上臂因惯性“落后”，相当于受到 $-J\alpha$ 的惯性力矩。）$\omega_n$、$\zeta$ 同算例 20.3.2，固有周期 $T_n = \frac{2\pi}{\omega_n}\approx {{ex20_4.rv_Tn_ms:.1f}}$ ms，$\alpha_0 = {{ex20_4.rv_a0:g}}$ rad/s²。停下后残余振动有多大？

*解*　由 (20.4.3) 算出 $t = 2T$ 时的 $\varphi$ 和 $\dot\varphi$，此后是自由振动，振幅为 $\sqrt{\varphi^2 + \bigl((\dot\varphi + \zeta\omega_n\varphi)/\omega_d\bigr)^2}$。表 20.4.1 列出几种加速时间下的结果，并用数值解核对。　∎

结果很惊人：加速时间恰为固有周期的整数倍时，残余振动几乎为零；是半个周期的奇数倍时最大，可达数百微弧度。不计阻尼时可以算出残余振幅为 $\frac{4\alpha_0}{\omega_n^2}\sin^2\frac{\omega_nT}{2}$（习题 20.4.7），最大约 {{ex20_4.rv_max_urad:.0f}} μrad。原因可以从 (20.4.3) 看出（取 $\zeta = 0$）：恒定的加速度使扭转角在 $-\frac{\alpha_0}{\omega_n^2}$ 附近振荡，加速段恰好持续整数个周期时，它在结束的瞬间正好回到起点、速度为零，减速段同理，于是什么也没留下。

这就是工程中“输入整形”的思想：知道了结构的固有频率，就把运动指令安排得让它自己把振动“抵消”掉，而不是硬等振动衰减。阻尼比越小，这种办法的收益越大；它的弱点是依赖固有频率的准确值，所以表中阻尼使整数倍处的残余振动不完全为零，固有频率估得不准时效果也会变差。

### 20.4.5 历史注记

待定系数法实际上是欧拉在 18 世纪 40—50 年代处理常系数方程时就用过的办法。常数变易法由拉格朗日在 1774—1775 年对一般的高阶线性方程给出（19.4 节说过，一阶的情形更早）。法国数学家杜阿梅尔在 1833 年研究热传导时提出了用“过去各时刻的输入叠加”表示响应的原理，(20.4.3) 是它在振动中的形式。用指令“抵消”振动的想法最早见于史密斯 1957 年的“半周期延迟”（posicast）控制，辛格和西林在 1990 年把它发展为今天机器人和起重机中常用的“输入整形”方法。

### 20.4.6 生活中的例子

端着一杯满满的咖啡走路，常常走着走着就洒了。研究表明，咖啡在杯中晃动的固有频率与人走路的步频相近，每一步都在“推”它一下，晃动越来越大（2012 年的一项物理研究专门测量了这件事）。起步和停下时动作平缓、走得慢一些、眼睛盯着杯子，都能减少洒出。这与机械臂“按固有周期安排加速时间”是同一个道理。

**工程师笔记**

- 右边是多项式、指数、正弦的组合时用待定系数法；猜的函数若与齐次解重复，乘以 $x$（或 $x^2$）。
- 杜阿梅尔积分 (20.4.3) 把任意外力下的响应写成一个积分，适合对实测的力、加速度数据做数值计算。
- 运动指令会激起结构的振动。加速、减速的时间安排成固有周期的整数倍，可以大大减小残余振动；固有频率要先测准。
