### 20.3.1 问题的提出

20.1 节说，机械臂末端的变形主要来自减速器的扭转。减速器像一根扭簧：上臂偏离平衡位置 $\theta$，就受到恢复力矩 $-k\theta$；材料和润滑的内摩擦产生与角速度成正比的阻尼力矩 $-c\dot\theta$。电机一侧被制动器锁住时，上臂绕肩轴（转动惯量 $J$）的运动满足

$$
J\ddot\theta + c\dot\theta + k\theta = 0 . \tag{20.3.1}
$$

上臂被碰了一下，会怎样振动？振动多快衰减？

这是一个常系数的齐次线性方程。由 20.2 节，只要找到两个线性无关的解。对常系数方程，这可以完全用代数做到。

### 20.3.2 特征方程

考虑

$$
y'' + ay' + by = 0\qquad(a, b\text{ 为实常数}) . \tag{20.3.2}
$$

指数函数求导后仍是自身的倍数，猜 $y = e^{rx}$：$y' = re^{rx}$，$y'' = r^2e^{rx}$，代入得 $(r^2 + ar + b)e^{rx} = 0$。所以 $e^{rx}$ 是解，当且仅当 $r$ 是

$$
r^2 + ar + b = 0 \tag{20.3.3}
$$

的根。(20.3.3) 叫作 (20.3.2) 的**特征方程**，它的根叫作**特征根**。微分方程的问题变成了二次方程的问题。

**定理 20.3.1** 设判别式 $\Delta = a^2 - 4b$。(20.3.2) 的基本解组为：

1. $\Delta > 0$，两个不等实根 $r_1$、$r_2$：$e^{r_1x}$、$e^{r_2x}$；
2. $\Delta = 0$，重根 $r = -\frac a2$：$e^{rx}$、$xe^{rx}$；
3. $\Delta < 0$，共轭复根 $\alpha\pm i\beta$（$\alpha = -\frac a2$，$\beta = \frac12\sqrt{4b - a^2}$）：$e^{\alpha x}\cos\beta x$、$e^{\alpha x}\sin\beta x$。

*证明*　由 20.2 节，只需验证每组都是解，并且朗斯基行列式不为零。

1. 两个都是解；$W = (r_2 - r_1)e^{(r_1 + r_2)x}\ne 0$。

2. 只需验证 $xe^{rx}$ 是解。$(xe^{rx})' = (1 + rx)e^{rx}$，$(xe^{rx})'' = (2r + r^2x)e^{rx}$，代入左边得

$$
\bigl[(r^2 + ar + b)\,x + (2r + a)\bigr]e^{rx} = 0 ,
$$

因为 $r$ 是特征根，又 $2r + a = 0$。$W = e^{2rx}\ne 0$。

3. 设 $u = e^{\alpha x}\cos\beta x$，则 $u' = e^{\alpha x}(\alpha\cos\beta x - \beta\sin\beta x)$，$u'' = e^{\alpha x}\bigl[(\alpha^2 - \beta^2)\cos\beta x - 2\alpha\beta\sin\beta x\bigr]$。代入左边，$\cos\beta x$ 的系数为 $\alpha^2 - \beta^2 + a\alpha + b$，$\sin\beta x$ 的系数为 $-2\alpha\beta - a\beta$。由 $\alpha = -\frac a2$、$\beta^2 = b - \frac{a^2}{4}$，两者都是 0。$e^{\alpha x}\sin\beta x$ 同理。$W = \beta e^{2\alpha x}\ne 0$。　∎

第 3 种情形的来历：形式上 $e^{(\alpha + i\beta)x}$ 是解，而第 24 章的欧拉公式 $e^{i\theta} = \cos\theta + i\sin\theta$ 说 $e^{(\alpha + i\beta)x} = e^{\alpha x}(\cos\beta x + i\sin\beta x)$，它的实部和虚部各是一个实的解。这里我们绕过了复指数，直接验证。

**算例 20.3.1** 解 (1) $y'' - 3y' + 2y = 0$；(2) $y'' + 2y' + y = 0$，$y(0) = 1$，$y'(0) = 0$；(3) $y'' + 2y' + 5y = 0$。

*解*　(1) $r^2 - 3r + 2 = 0$，$r = 1, 2$，$y = c_1e^x + c_2e^{2x}$。(2) $r = -1$（重根），$y = (c_1 + c_2x)e^{-x}$，由初值 $c_1 = 1$，$c_2 = 1$，$y = (1 + x)e^{-x}$。程序 20.3.1 用数值解核对 $y(3) = 4e^{-3}\approx {{ex20_3.rep_formula:.6f}}$，得 {{ex20_3.rep_num:.6f}}。(3) $r = -1\pm 2i$，$y = e^{-x}(c_1\cos 2x + c_2\sin 2x)$。　∎

### 20.3.3 振动的三种情形

振动问题习惯写成

$$
\ddot x + 2\zeta\omega_n\dot x + \omega_n^2x = 0 ,\qquad \omega_n = \sqrt{\frac kJ},\quad \zeta = \frac{c}{2\sqrt{kJ}} , \tag{20.3.4}
$$

(20.3.1) 两边除以 $J$ 即得。$\omega_n$ 叫作**固有频率**（单位 rad/s），$\zeta$ 叫作**阻尼比**。特征根是 $-\zeta\omega_n\pm\omega_n\sqrt{\zeta^2 - 1}$，按定理 20.3.1 分三种情形（表 20.3.1，图 20.3.1）：

- $\zeta > 1$，**过阻尼**：两个负实根，$x = c_1e^{r_1t} + c_2e^{r_2t}$，不振荡，慢慢回到平衡位置；
- $\zeta = 1$，**临界阻尼**：重根 $-\omega_n$，$x = (c_1 + c_2t)e^{-\omega_nt}$，在不振荡的情形中回得最快（习题 20.3.5）；
- $0 < \zeta < 1$，**欠阻尼**：$x = e^{-\zeta\omega_nt}(c_1\cos\omega_dt + c_2\sin\omega_dt)$，$\omega_d = \omega_n\sqrt{1 - \zeta^2}$，振幅按 $e^{-\zeta\omega_nt}$ 衰减的振荡。

$\zeta = 0$ 时无阻尼，$x = c_1\cos\omega_nt + c_2\sin\omega_nt = A\cos(\omega_nt - \varphi)$，叫作**简谐振动**，周期 $\frac{2\pi}{\omega_n}$ 与振幅无关。小摆幅的单摆 $\ddot\theta + \frac gl\theta = 0$ 就是 $\omega_n = \sqrt{g/l}$ 的简谐振动，20.1 节的 $T_0 = 2\pi\sqrt{l/g}$ 由此而来。

**算例 20.3.2** 上臂绕肩轴的转动惯量 $J = {{ex20_3.fx_J:g}}$ kg·m²（17.4 节），设减速器的扭转刚度 $k = {{ex20_3.fx_k:sci0}}$ N·m/rad、阻尼比 $\zeta = {{ex20_3.fx_z:g}}$（都是假设的典型值，实际要由实验测定）。电机侧锁住时，上臂的肘端被碰了一下，获得 0.05 m/s 的速度。求振动的频率、衰减快慢和最大振幅。

*解*　$\omega_n = \sqrt{k/J}\approx {{ex20_3.fx_wn:.1f}}$ rad/s，即 {{ex20_3.fx_f:.1f}} Hz；阻尼系数 $c = 2\zeta\sqrt{kJ}\approx {{ex20_3.fx_c:.2f}}$ N·m·s/rad。$\zeta$ 很小，$\omega_d\approx\omega_n$。初值 $\theta(0) = 0$，$\dot\theta(0) = \frac{0.05}{0.425}$ rad/s，由此 $c_1 = 0$，$c_2 = \frac{\dot\theta(0)}{\omega_d}$：

$$
\theta(t) = \frac{\dot\theta(0)}{\omega_d}e^{-\zeta\omega_nt}\sin\omega_dt .
$$

振幅不超过 $\frac{\dot\theta(0)}{\omega_d}\approx {{ex20_3.fx_amp_urad:.0f}}$ μrad，第一个峰约 {{ex20_3.fx_pk_urad:.0f}} μrad，肘端位移约 {{ex20_3.fx_pk_tip_um:.0f}} μm。振幅的衰减时间常数 $\frac{1}{\zeta\omega_n}\approx {{ex20_3.fx_tau:.2f}}$ s，衰减到 5% 要 $\frac{\ln 20}{\zeta\omega_n}\approx {{ex20_3.fx_t5:.2f}}$ s，其间振动约 {{ex20_3.fx_n5:.0f}} 次。　∎

几十赫兹、持续近一秒的振动，正是机械臂快速停止后末端“抖”的来源。控制器要么避免在这个频率附近激励它（20.6 节），要么主动增加阻尼。

### 20.3.4 高阶常系数方程

$n$ 阶方程 $y^{(n)} + a_{n - 1}y^{(n - 1)} + \dots + a_0y = 0$ 同样代入 $e^{rx}$，得到 $n$ 次特征方程。每个 $m$ 重实根 $r$ 给出 $m$ 个解 $e^{rx}$、$xe^{rx}$、…、$x^{m - 1}e^{rx}$；每对 $m$ 重共轭复根 $\alpha\pm i\beta$ 给出 $2m$ 个解 $x^ke^{\alpha x}\cos\beta x$、$x^ke^{\alpha x}\sin\beta x$（$0\le k < m$）。合起来恰有 $n$ 个，它们线性无关，组成基本解组（证明从略）。例如 $y'''' - y = 0$ 的特征根为 $\pm 1$、$\pm i$，通解 $y = c_1e^x + c_2e^{-x} + c_3\cos x + c_4\sin x$。

**特征根决定稳定性。** 所有解都趋于 0，当且仅当所有特征根的实部都是负的：实部为负的根给出衰减的解，实部为正的根给出增长的解，实部为零的根给出不衰减的振荡（或多项式增长）。这是第 21 章稳定性理论的出发点，也是控制工程判断系统稳定的基本方法。

### 20.3.5 历史注记

欧拉在 1739—1743 年间研究常系数线性方程，提出了用 $e^{rx}$ 代入、化为代数方程的方法，并处理了重根和复根的情形。他在研究弦振动、摆的小振动时用到了这些结果。“固有频率”“阻尼比”这些名称来自 19 世纪的声学和 20 世纪的振动工程；瑞利在 1877 年的《声学理论》中系统地讨论了有阻尼的振动。

### 20.3.6 生活中的例子

汽车的减振器（避震器）就是一个阻尼器。新车的减振器把阻尼比调在 0.2—0.4 之间：车压过减速带后，车身上下晃一两下就停了。减振器漏油、失效后阻尼变小，车身会上下晃好几次，乘坐很不舒服，转弯时也容易失控。按一下车头再松手，看车身晃几下，就是检查减振器的老办法。

**工程师笔记**

- 常系数线性方程的解完全由特征根决定：实部给出衰减（或增长）的快慢，虚部给出振荡的频率。
- 二阶系统先算 $\omega_n = \sqrt{k/J}$ 和 $\zeta = \frac{c}{2\sqrt{kJ}}$，就知道响应的样子。机械结构的阻尼比通常只有百分之几，振动要几十个周期才停下来。
- 刚度越大、惯量越小，固有频率越高。提高固有频率是让机械臂“不抖”的根本办法；固有频率还限制了控制器能做到多快（20.7 节）。
