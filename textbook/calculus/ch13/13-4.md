### 13.4.1 问题的提出

求导有一张基本导数表（7.4 至 7.6 节），配合四则运算法则和链式法则，任何初等函数都能求导。求积分是求导的逆运算，把导数表倒过来读，就得到一张基本积分表。它是一切积分计算的出发点，就像乘法口诀之于除法。本节列出这张表，并用它计算一些工程中常见的积分。

### 13.4.2 积分表

表 13.4.1 的每一行都由一条求导公式倒过来得到，求导即可验证（程序 13.4.1 用 SymPy 对 {{ex13_4.n_table}} 条公式逐一验算，{{ex13_4.n_ok}} 条全部通过）。

说明: 基本积分表（C 为积分常数）
:::

| 被积函数 | 不定积分 | 对应的导数公式 |
|---|---|---|
| $x^\mu$（$\mu\ne -1$） | $\dfrac{x^{\mu+1}}{\mu + 1} + C$ | $(x^{\mu+1})' = (\mu + 1)x^\mu$ |
| $\dfrac1x$ | $\ln\lvert x\rvert + C$ | 式 (7.4.10) |
| $e^x$ | $e^x + C$ | $(e^x)' = e^x$ |
| $a^x$（$a > 0$，$a\ne 1$） | $\dfrac{a^x}{\ln a} + C$ | $(a^x)' = a^x\ln a$ |
| $\sin x$ | $-\cos x + C$ | $(\cos x)' = -\sin x$ |
| $\cos x$ | $\sin x + C$ | $(\sin x)' = \cos x$ |
| $\sec^2x = \dfrac{1}{\cos^2x}$ | $\tan x + C$ | $(\tan x)' = \sec^2x$ |
| $\csc^2x = \dfrac{1}{\sin^2x}$ | $-\cot x + C$ | $(\cot x)' = -\csc^2x$ |
| $\dfrac{1}{1 + x^2}$ | $\arctan x + C$ | 式 (7.6.3) |
| $\dfrac{1}{\sqrt{1 - x^2}}$ | $\arcsin x + C$ | 式 (7.6.3) |
| $\sinh x$ | $\cosh x + C$ | 式 (7.4.11) |
| $\cosh x$ | $\sinh x + C$ | 式 (7.4.11) |

几点说明：

- 幂函数一行排除了 $\mu = -1$：那时 $\frac{x^{\mu+1}}{\mu + 1}$ 没有意义。$\frac1x$ 的原函数是对数，这是对数函数在微积分中地位重要的原因之一。$\ln\lvert x\rvert$ 中的绝对值使公式在 $x < 0$ 上也成立（式 (7.4.10) 的用处正在这里），但在包含 0 的区间上不能用（算例 13.2.4）。
- 在每个公式成立的区间上，常数 $C$ 都可以取不同的值（13.3.2 节）。
- 表中没有 $\tan x$、$\ln x$、$\arctan x$ 等函数本身的积分，它们要用换元法（13.5 节）或分部积分（第 14 章）求出。

由线性性质，表中函数的线性组合都能直接积分。

**算例 13.4.1** 计算 $\int_1^4\Bigl(\sqrt x + \frac1x\Bigr)\,dx$ 与 $\int_0^{\pi/4}\sec^2x\,dx$、$\int_0^{1/2}\frac{dx}{\sqrt{1 - x^2}}$。

*解*　
$$
\int_1^4\Bigl(x^{1/2} + \frac1x\Bigr)\,dx = \Bigl[\frac23x^{3/2} + \ln x\Bigr]_1^4 = \frac23(8 - 1) + \ln 4\approx {{ex13_4.e1x:.4f}} ,
$$

$\int_0^{\pi/4}\sec^2x\,dx = \tan\frac\pi4 - \tan 0 = 1$，$\int_0^{1/2}\frac{dx}{\sqrt{1 - x^2}} = \arcsin\frac12 = \frac\pi6$。程序 13.4.1 用中点和算得 {{ex13_4.e1:.4f}}、{{ex13_4.sec2:.4f}}、{{ex13_4.asin_half:.4f}}，与公式一致。　∎

### 13.4.3 先变形，再查表

被积函数不在表中时，常常可以先用代数或三角恒等式变形。

**算例 13.4.2** 求 $\int\sin^2x\,dx$，并求 $\sin^2x$ 在一个周期 $[0, 2\pi]$ 上的平均值。

*解*　由倍角公式 $\sin^2x = \frac{1 - \cos 2x}{2}$。$\cos 2x$ 的原函数是 $\frac12\sin 2x$（求导验算：$\bigl(\frac12\sin 2x\bigr)' = \cos 2x$），所以

$$
\int\sin^2x\,dx = \frac x2 - \frac{\sin 2x}{4} + C .
$$

在 $[0, 2\pi]$ 上积分得 $\pi$，平均值为 $\frac{\pi}{2\pi} = \frac12$（程序 13.4.1 的数值结果为 {{ex13_4.sin2_mean:.4f}}）。这就严格证明了 12.5.5 节的结论：正弦量的均方根是峰值的 $\frac{1}{\sqrt2}$。　∎

**算例 13.4.3（五次多项式运动的均方根加速度）** 算例 12.5.2 用中点和求了关节五次多项式运动的均方根角加速度。现在求出准确的公式。

*解*　关节角 $\theta(t) = \theta_0 + \Delta\cdot s\bigl(\frac tT\bigr)$，$s(u) = 10u^3 - 15u^4 + 6u^5$（7.8 节），$s''(u) = 60u - 180u^2 + 120u^3$，角加速度 $\alpha(t) = \frac{\Delta}{T^2}s''\bigl(\frac tT\bigr)$。先算多项式的积分：

$$
\int_0^1s''(u)^2\,du = \int_0^1\bigl(3600u^2 - 21600u^3 + 46800u^4 - 43200u^5 + 14400u^6\bigr)\,du = 1200 - 5400 + 9360 - 7200 + \frac{14400}{7} = \frac{120}{7} .
$$

于是（下一节的换元 $u = \frac tT$）$\frac1T\int_0^T\alpha^2\,dt = \frac{\Delta^2}{T^4}\int_0^1s''(u)^2\,du$，

$$
\alpha_{\text{rms}} = \frac{\Delta}{T^2}\sqrt{\frac{120}{7}}\approx 4.14\,\frac{\Delta}{T^2} .
$$

$\Delta = \frac\pi2$，$T = 2$ s 时，$\alpha_{\text{rms}} = \frac{\pi}{8}\sqrt{\frac{120}{7}}$，与算例 12.5.2 的数值结果一致。准确公式的好处是一目了然：均方根加速度与转角成正比，与时间的*平方*成反比。　∎

### 13.4.4 历史注记

积分表几乎与微积分一样古老。莱布尼茨和约翰·伯努利在 17 世纪末已经整理出常用的积分公式；欧拉在 1768—1770 年的三卷本《积分学原理》中系统地编纂了当时已知的积分方法和结果。19、20 世纪出现了大部头的积分表，最著名的是雷日克 1943 年出版的俄文积分表，1951 年起与格拉德什泰因合著，即《积分、级数和乘积表》，经多次增订，收录的公式上万条。今天的符号计算软件在很大程度上取代了查表，但工程师和物理学家手边仍常备一本积分表，而书末的那几行基本公式则是人人要熟记的。

### 13.4.5 生活中的例子

家用电器铭牌上的“220 V、50 Hz”，220 V 是交流电压的均方根（有效值）。为什么选均方根而不选峰值或平均值？因为电热水壶、电饭煲的发热功率与电压的平方成正比，均方根相同的交流电与直流电发热相同。算例 13.4.2 算出正弦的均方根是峰值的 $\frac{1}{\sqrt2}$，所以 220 V 交流电的峰值约 311 V；电器的绝缘要按峰值设计，功率要按有效值计算。

**工程师笔记**

- 基本积分表要熟记，就像乘法口诀。复杂的积分最后都要化成表中的形式，化不过去的，再交给软件或数值方法。
- 积分结果的验算永远是求导。对定积分，还可以用中点和或 `scipy.integrate.quad` 粗算一下数量级，防止丢掉常数因子或符号。
- 多项式的积分永远是多项式，三角多项式的积分永远是三角多项式。机器人轨迹大多由这两类函数拼成，所以轨迹的位移、能量、均方根加速度一般都有准确的公式，不必数值计算。
