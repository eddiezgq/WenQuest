本章的主线可以用一句话概括：*连续就是极限等于函数值；闭区间上的连续函数不会“跳过”任何值，也不会“逃到”无穷远去*。

$f$ 在 $a$ 点连续，要求 $f$ 在 $a$ 点有定义、极限存在、两者相等。用 $\varepsilon$–$\delta$ 说，就是输入的误差足够小，输出的误差就小于任意给定的允许值；用数列说，就是连续函数与极限运算可以交换次序。不满足这些要求的点是间断点：左右极限都存在的是第一类（可去、跳跃），否则是第二类（无穷、振荡）。可去间断补上一个值就连续了（$\operatorname{sinc}$）；航向读数的 $2\pi$ 跳变可以用解卷绕接回去，前提是采样足够快；库仑摩擦的跳变是真实的物理，在仿真中要专门处理。

连续函数经过四则运算、复合、取反函数仍然连续。由此，初等函数在定义区间内连续，求极限可以直接代入，外层函数连续时极限号可以移进去；幂指函数 $u^v$ 写成 $e^{v\ln u}$ 处理。

闭区间上的连续函数有界，取到最大值和最小值，取到介于两端值之间的一切值。有界性定理和零点定理可以用二分法加闭区间套证明，这个证明本身就是二分法：每一步区间减半，$k$ 步后误差不超过 $(b - a)/2^{k+1}$，步数可以事先算出。二分法只要求连续和变号，可靠但慢；不变号、多个根、间断时会失效。

一致连续要求一个 $\delta$ 对区间上所有点都管用。满足利普希茨条件的函数一致连续，$\delta = \varepsilon/K$；闭区间上的连续函数一致连续（康托尔定理），但可能不满足利普希茨条件，如 $\sqrt x$ 在 0 附近、肘关节角在伸直位置附近，那里 $\delta$ 与 $\varepsilon^2$ 成正比。

### 历史注记

| 年份 | 人物 | 贡献 |

“连续”是最早被直觉接受、又最晚被说清楚的概念之一。从欧拉“由一个公式给出”，到波尔查诺和柯西“小的改变产生小的改变”，再到魏尔斯特拉斯的 $\varepsilon$–$\delta$，人们花了一百多年。魏尔斯特拉斯构造的处处连续而处处不可导的函数，更说明“连续”与“光滑”是两回事，图像不断开并不意味着可以画出切线。

### 部分习题答案与提示

5.1.1 （1）不连续，$f(2)$ 无定义；（2）连续；（3）连续；（4）$x = 1$ 处不连续（右连续而不左连续），$x = 1.5$ 处连续。

5.1.3 （1）$\lvert x^2 - a^2\rvert = \lvert x + a\rvert\lvert x - a\rvert$，限定 $\lvert x - a\rvert < 1$ 后 $\lvert x + a\rvert < 2\lvert a\rvert + 1$，取 $\delta = \min\{1, \varepsilon/(2\lvert a\rvert + 1)\}$。（2）限定 $\lvert x - a\rvert < \lvert a\rvert/2$，则 $\lvert x\rvert > \lvert a\rvert/2$，$\bigl\lvert\frac1x - \frac1a\bigr\rvert < \frac{2\lvert x - a\rvert}{a^2}$，取 $\delta = \min\{\lvert a\rvert/2, a^2\varepsilon/2\}$。两个 $\delta$ 都依赖于 $a$。

5.1.4 （1）$k = 3$；（2）$k = e^2$；（3）$k = 1$。

5.1.5 取 $\varepsilon = \tfrac12f(a)$。$f(a)\ge 0$ 时结论不成立：$f(x) = -x^2$ 在 0 点。

5.1.6 $\bigl\lvert\lvert f(x)\rvert - \lvert f(a)\rvert\bigr\rvert\le\lvert f(x) - f(a)\rvert$。反之不然：$f(x) = 1$（$x\ge 0$），$f(x) = -1$（$x < 0$），$\lvert f\rvert\equiv 1$ 连续。

5.1.7 5 ms 时约为 {{ans5.e517_5:.0f}} rad/s，1 ms 时约为 {{ans5.e517_1:.0f}} rad/s。周期越短，尖峰越大：跳变量 $2\pi$ 不变，除以越来越小的 $T$。问题不在采样，而在读数本身不连续。

5.1.9 对无理数 $x_0$ 和 $\varepsilon > 0$，$x_0$ 附近分母 $q\le 1/\varepsilon$ 的有理数只有有限个，取 $\delta$ 小于 $x_0$ 到它们的最小距离，则 $\lvert x - x_0\rvert < \delta$ 时 $R(x) < \varepsilon$。对有理数 $x_0 = p/q$，$R(x_0) = 1/q$，而趋于 $x_0$ 的无理数列上 $R = 0$。


5.1.10 左极限为 $a$，右极限为 $2 + 1 = 3$，所以 $a = b = 3$。

5.2.1 （1）$x = 0$ 跳跃（左极限 $-1$，右极限 $1$）；$x = 1$ 可去，补充 $f(1) = \tfrac12$；$x = -1$ 无穷。（2）$x = 0$ 可去，补充 $f(0) = 1$；$x = k\pi + \tfrac\pi2$ 无穷。（3）$x = 0$ 无穷；$x = 1$ 跳跃（左极限 0，右极限 1）。（4）$x = 0$ 振荡。

5.2.2 $\lvert x\rvert < 1$ 时 $f(x) = x$，$\lvert x\rvert > 1$ 时 $f(x) = -x$，$f(\pm 1) = 0$。$x = \pm 1$ 都是跳跃间断点。

5.2.4 $\Delta = \operatorname{atan2}(\sin d, \cos d)$，$d = \theta_{\text{目标}} - \theta_{\text{当前}}$。$d = -6.0$ rad，折回后约为 {{ans5.e524:.4f}} rad，应逆时针转约 $16^\circ$；直接相减会让车顺时针转将近一圈。

5.2.5 （1）计数器在转角每增加 16 圈（$65536/4096$）时从 65535 跳回 0，是跳跃间断点；计数本身是转角的取整，每个计数边界也是跳跃间断点（跳跃量 1）。（2）相邻两次读数之差超过 32768 时补上 $\mp 65536$。（3）一个控制周期内的计数变化不超过 32768；按题设每周期最多变化约 {{ans5.e525_counts:.1f}} 个计数，远小于此。

5.2.7 由定理 5.2.1，若 $f$ 在 $a$ 点间断，则 $f(a^-) < f(a^+)$（设 $f$ 递增），区间 $(f(a^-), f(a^+))$ 中除 $f(a)$ 外的值都取不到，与 $f(I)$ 是区间矛盾。
