### 5.3.1 问题的提出

两节连杆手臂的末端位置由两个关节角决定（正运动学，2.4 节）：

$$
p_x = l_1\cos\theta_1 + l_2\cos(\theta_1 + \theta_2),\qquad p_y = l_1\sin\theta_1 + l_2\sin(\theta_1 + \theta_2) .
$$

### 5.3.2 连续函数的四则运算与复合

由极限的运算法则（定理 4.2.1）立即得到：

**定理 5.3.1（四则运算）** 若 $f$、$g$ 都在 $a$ 点连续，则 $f\pm g$、$fg$ 在 $a$ 点连续；若还有 $g(a)\ne 0$，则 $\dfrac fg$ 在 $a$ 点连续。

由复合函数的极限（定理 4.2.3，外层函数连续的情形）得到：

**定理 5.3.2（复合）** 若 $g$ 在 $a$ 点连续，$f$ 在 $g(a)$ 点连续，则 $f\circ g$ 在 $a$ 点连续。更一般地，若 $\lim_{x\to a}g(x) = b$，$f$ 在 $b$ 点连续，则

$$
\lim_{x\to a}f(g(x)) = f\Bigl(\lim_{x\to a}g(x)\Bigr) . \tag{5.3.1}
$$

(5.3.1) 说的是：*外层函数连续时，极限号可以移到里面去。*第 4 章计算 $\lim\sqrt{\frac{\sin x}{x}}$、$\lim e^{\cos x}$，以及 4.5 节由 $(1 + u)^{1/u}\to e$ 推出 $\frac{\ln(1 + u)}{u}\to 1$，用的都是这一条；当时说“要用到连续性，第 5 章”，现在只差证明 $\ln$、$\exp$ 等函数本身连续了。

多项式是常数和 $x$ 经过有限次加法和乘法得到的，所以处处连续；有理函数在分母不为零处连续。由算例 5.1.1、习题 5.1.2 和定理 5.3.1，$\sin x$、$\cos x$ 处处连续，$\tan x = \frac{\sin x}{\cos x}$、$\cot x$ 在定义域内连续。5.3.1 节的正运动学是由 $\sin$、$\cos$ 经过加法、数乘、复合得到的，所以是关节角的连续函数（对两个变量的连续性，第 30 章有严格的定义，这里取其直观含义）。

### 5.3.3 反函数的连续性

**定理 5.3.3（反函数的连续性）** 设 $f$ 在区间 $I$ 上严格单调递增（或递减）且连续，则它的值域 $J = f(I)$ 也是区间，反函数 $f^{-1}$ 在 $J$ 上严格单调递增（或递减）且连续。

*证明*　设 $f$ 严格递增（递减的情形对 $-f$ 讨论）。由 5.4 节的推论 5.4.2（介值定理的推论），$J = f(I)$ 是区间。$f^{-1}$ 严格递增：若 $y_1 < y_2$ 而 $f^{-1}(y_1)\ge f^{-1}(y_2)$，两边作用 $f$ 得 $y_1\ge y_2$，矛盾。

下证 $f^{-1}$ 在 $J$ 的每一点 $y_0 = f(x_0)$ 连续。先设 $x_0$ 是 $I$ 的内点。任给 $\varepsilon > 0$（不妨设 $[x_0 - \varepsilon, x_0 + \varepsilon]\subset I$），取

$$
\delta = \min\{y_0 - f(x_0 - \varepsilon),\ f(x_0 + \varepsilon) - y_0\} > 0 .
$$

当 $\lvert y - y_0\rvert < \delta$ 且 $y\in J$ 时，$f(x_0 - \varepsilon) < y < f(x_0 + \varepsilon)$，由 $f^{-1}$ 递增，$x_0 - \varepsilon < f^{-1}(y) < x_0 + \varepsilon$。若 $x_0$ 是 $I$ 的端点（比如左端点），只取右侧：$\delta = f(x_0 + \varepsilon) - y_0$，证明相同，得到 $f^{-1}$ 在 $y_0$ 处单侧连续。　∎

这个 $\delta$ 有清楚的几何意义：把 $x$ 轴上的 $\varepsilon$ 邻域通过 $f$ 映到 $y$ 轴上，取 $y_0$ 两侧较近的那一段。另一种证法见习题 5.2.7：$f^{-1}$ 是区间 $J$ 上的单调函数，值域是区间 $I$，因而没有跳跃。

由定理 5.3.3：$\arcsin x$ 在 $[-1, 1]$ 上连续，$\arccos x$ 在 $[-1, 1]$ 上连续，$\arctan x$ 在 $\mathbb R$ 上连续；$\sqrt[n]x$ 在其定义域上连续。

### 5.3.4 指数函数与对数函数的连续性

2.4 节对实数指数 $a^x$ 只作了直观的介绍。对有理数 $x = p/q$，$a^x = \sqrt[q]{a^p}$ 有明确的意义；对无理数 $x$，$a^x$ 定义为 $a^{r_n}$ 的极限，$r_n$ 是任一列趋于 $x$ 的有理数。这个极限存在且与 $r_n$ 的取法无关，要用到实数的完备性（柯西收敛准则，6.4 节）；有理指数幂的运算法则和单调性（$a > 1$ 时 $a^x$ 严格递增）由此保持到全体实数。下面的证明承认这些结论。

**定理 5.3.4** 设 $a > 0$，$a\ne 1$。指数函数 $a^x$ 在 $\mathbb R$ 上连续，对数函数 $\log_a x$ 在 $(0, +\infty)$ 上连续。

*证明*　设 $a > 1$（$0 < a < 1$ 时用 $a^x = 1/(1/a)^x$）。先证 $a^x$ 在 0 点连续。由习题 3.5.2，$\sqrt[n]a = a^{1/n}\to 1$。任给 $\varepsilon > 0$，取 $N$ 使 $a^{1/N} < 1 + \varepsilon$，令 $\delta = \frac1N$。当 $0 < x < \delta$ 时，由单调性 $1 < a^x < a^{1/N} < 1 + \varepsilon$；当 $-\delta < x < 0$ 时，$1 > a^x = \frac{1}{a^{-x}} > \frac{1}{1 + \varepsilon} > 1 - \varepsilon$。所以 $\lim_{x\to 0}a^x = 1 = a^0$。

再证在任一点 $x_0$ 连续：$a^x - a^{x_0} = a^{x_0}(a^{x - x_0} - 1)$，$x\to x_0$ 时 $x - x_0\to 0$，括号趋于 0。

$\log_a x$ 是 $a^x$ 的反函数，$a^x$ 在 $\mathbb R$ 上严格单调且连续，由刚才证明的结论和定理 5.3.3，$\log_a x$ 在 $a^x$ 的值域 $(0, +\infty)$ 上连续。　∎

程序 5.3.1 给出了证明中的数：$2^{1/10}\approx {{ex5_3.r2_10:.4f}}$，$2^{1/1000}\approx {{ex5_3.r2_1000:.6f}}$；要使 $0 < x < \delta$ 时 $2^x - 1 < 10^{-3}$，取 $\delta = \frac{1}{1000}$ 就够了。

幂函数 $x^\mu = e^{\mu\ln x}$（$x > 0$）是 $e^u$ 与 $\mu\ln x$ 的复合，由定理 5.3.2，在 $(0, +\infty)$ 上连续。$\mu > 0$ 时它在 0 点右连续：$0 < x < \varepsilon^{1/\mu}$ 时 $0 < x^\mu < \varepsilon$。$\mu$ 为整数时 $x^\mu$ 是多项式或有理函数；$\mu = p/q$（$q$ 为奇数）时 $x^\mu = (\sqrt[q]x)^p$，在负半轴上也连续。

### 5.3.5 初等函数的连续性

至此，所有的基本初等函数（常数、幂函数、指数函数、对数函数、三角函数、反三角函数）在各自的定义域内都连续。初等函数是由基本初等函数经过有限次四则运算和复合得到的，由定理 5.3.1、5.3.2：

**定理 5.3.5** 初等函数在其定义区间内连续。

“定义区间”指包含在定义域内的区间。之所以不说“定义域”，是因为有的初等函数的定义域是孤立的点，例如 $\sqrt{\cos x - 1}$ 只在 $x = 2k\pi$ 处有定义，在这些孤立点上谈不上极限。

定理 5.3.5 是计算极限最常用的依据：*初等函数在定义区间内的点处求极限，直接代入。*

**算例 5.3.1** 求（1）$\lim_{x\to 0}\dfrac{\ln(1 + x^2)}{\cos x}$；（2）$\lim_{x\to\pi/2}\arcsin\dfrac{\sin x}{2}$。

*解*　两个函数都是初等函数，$x = 0$、$x = \tfrac\pi2$ 都在定义区间内，直接代入：（1）$\dfrac{\ln 1}{\cos 0} = 0$；（2）$\arcsin\tfrac12 = \tfrac\pi6$。　∎

### 5.3.6 幂指函数的极限

形如 $u(x)^{v(x)}$（$u > 0$）的函数叫作幂指函数。写成 $u^v = e^{v\ln u}$，由复合函数的连续性：

**定理 5.3.6** 若 $\lim u(x) = A > 0$，$\lim v(x) = B$，则 $\lim u(x)^{v(x)} = A^B$。

*证明*　$v\ln u\to B\ln A$（$\ln$ 在 $A$ 处连续，再用乘积的极限），$e^t$ 在 $B\ln A$ 处连续，所以 $e^{v\ln u}\to e^{B\ln A} = A^B$。　∎

若 $A = 1$、$B = \infty$（$1^\infty$ 型），$A = 0$、$B = 0$（$0^0$ 型），或 $A = +\infty$、$B = 0$（$\infty^0$ 型），定理不适用，要先求 $\lim v\ln u$，这就是 4.5.3 节的做法。

**算例 5.3.2** 求 $\lim_{x\to 0}(1 + 2x)^{1/\sin x}$。

*解*　$1^\infty$ 型。$\dfrac{\ln(1 + 2x)}{\sin x} = \dfrac{\ln(1 + 2x)}{2x}\cdot\dfrac{x}{\sin x}\cdot 2\to 1\cdot 1\cdot 2 = 2$（4.5 节的重要极限），由 $e^t$ 的连续性，原式 $= e^2$。　∎

### 5.3.7 生活中的例子

用手机拍照测量一张桌子的长度：照片上量出像素数，乘以比例尺（由已知尺寸的参照物求出）。最终结果是“像素数 × 参照物实际长度 ÷ 参照物像素数”，由几个测量值经过乘除得到。只要分母（参照物的像素数）不为零，结果就是各测量值的连续函数：每个测量都足够准，结果就足够准。若参照物离得很远，只占几个像素，分母接近零，商的连续性虽然还在，但输入的微小误差会被放大很多倍。“连续”保证了误差能够控制，“控制到什么程度”则要看函数变化得多快，这是第 7、8 章导数和微分的话题。

**工程师笔记**

- 由连续的部件（加减乘除、开方、三角函数、指数对数）搭起来的公式，在分母不为零、根号下非负、对数的自变量为正的地方都是连续的。程序出错，多半出在这些“例外”的地方。
- 外层函数连续时极限号可以移进去：$\lim e^{g} = e^{\lim g}$，$\lim\ln g = \ln\lim g$。这也是数值算法里“先算内层的极限，再套外层”的依据。
- 反三角函数、反函数在定义域的端点处虽然连续，却可能变化得极快：$\arccos x$ 在 $x = 1$ 附近就是这样（4.3 节的灵敏度，5.6 节）。
