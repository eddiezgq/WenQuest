### 5.4.1 问题的提出

UR5e 的上臂长 $l_1$、前臂长 $l_2$（$l_1 + l_2 = {{ex5_4.r_max:.0f}}$ mm，$\lvert l_1 - l_2\rvert = {{ex5_4.r_min:.0f}}$ mm）。肘关节角为 $\theta_2$ 时，腕心到肩的距离是

$$
r(\theta_2) = \sqrt{l_1^2 + l_2^2 + 2l_1l_2\cos\theta_2},\qquad 0\le\theta_2\le\pi .
$$

$\theta_2 = 0$（伸直）时 $r = l_1 + l_2$，$\theta_2 = \pi$（完全折回）时 $r = \lvert l_1 - l_2\rvert$。问：介于两者之间的每一个距离，比如 600 mm，是否都能达到？

直觉告诉我们能：$\theta_2$ 从 0 连续地转到 $\pi$，$r$ 从 {{ex5_4.r_max:.0f}} mm 连续地减小到 {{ex5_4.r_min:.0f}} mm，中间不会“跳过”任何一个值（图 5.4.2 左）。再让肩关节 $\theta_1$ 转一圈，就得到手臂在这个平面内的工作空间：内半径 {{ex5_4.r_min:.0f}} mm、外半径 {{ex5_4.r_max:.0f}} mm 的圆环。

“不会跳过任何一个值”正是本节的介值定理。它和最值定理一起，是闭区间上连续函数最重要的性质。它们看似显然，却依赖实数的完备性：在有理数范围内，它们都不成立。

### 5.4.2 有界性定理与最值定理

**定义 5.4.1（最大值、最小值）** 设 $f$ 在集合 $I$ 上有定义。若有 $x_0\in I$，使对一切 $x\in I$ 都有 $f(x)\le f(x_0)$，称 $f(x_0)$ 为 $f$ 在 $I$ 上的**最大值**；类似地定义**最小值**。

**定理 5.4.1（有界性定理）** 闭区间 $[a, b]$ 上的连续函数在 $[a, b]$ 上有界。

*证明*　用二分法和闭区间套性质（2.1.2 节）。设 $f$ 在 $[a, b]$ 上无界。把 $[a, b]$ 二等分，$f$ 至少在其中一半上无界，记这一半为 $[a_1, b_1]$；再二等分，又有一半上 $f$ 无界，记为 $[a_2, b_2]$……得到一列闭区间，一个套一个，长度 $(b - a)/2^n\to 0$，$f$ 在每一个上都无界。由闭区间套性质，有唯一的点 $c$ 属于所有区间，$c\in[a, b]$。$f$ 在 $c$ 点连续（若 $c$ 是端点，则单侧连续），取 $\varepsilon = 1$，有 $\delta > 0$，使 $[a, b]$ 中满足 $\lvert x - c\rvert < \delta$ 的 $x$ 都有 $\lvert f(x)\rvert < \lvert f(c)\rvert + 1$。而 $n$ 足够大时 $[a_n, b_n]$ 整个落在 $(c - \delta, c + \delta)$ 内，$f$ 在它上面有界，矛盾。　∎

**定理 5.4.2（最值定理）** 闭区间 $[a, b]$ 上的连续函数在 $[a, b]$ 上一定取到最大值和最小值。

定理 5.4.1 说 $f$ 的值有上界，最值定理进一步说这些值中有一个最大的。“有上界”到“有最大值”之间隔着一步：上确界是否存在、是否被取到。这要用到确界原理，证明放在 6.6 节。

两个定理的条件缺一不可（区间不闭的情形见图 5.4.1 中）：

- 区间不闭：$f(x) = \dfrac1x$ 在 $(0, 1]$ 上连续，却无界；$f(x) = x$ 在 $(0, 1)$ 上有界，却没有最大值和最小值（2.1 节）。
- 函数不连续：$f(x) = x - \lfloor x\rfloor$ 在 $[0, 1]$ 上的值无限接近 1，却取不到 1。

### 5.4.3 零点定理与介值定理

**定理 5.4.3（零点定理）** 设 $f$ 在 $[a, b]$ 上连续，且 $f(a)$ 与 $f(b)$ 异号（$f(a)f(b) < 0$），则至少有一点 $\xi\in(a, b)$，使 $f(\xi) = 0$。

*证明*　不妨设 $f(a) < 0 < f(b)$。取中点 $m = \tfrac12(a + b)$：若 $f(m) = 0$，证毕；若 $f(m) < 0$，取 $[a_1, b_1] = [m, b]$；若 $f(m) > 0$，取 $[a_1, b_1] = [a, m]$。总之 $f(a_1) < 0 < f(b_1)$。对 $[a_1, b_1]$ 重复这一步……若某一步中点恰为零点，证毕；否则得到一列闭区间 $[a_n, b_n]$，一个套一个，长度 $(b - a)/2^n\to 0$，且

$$
f(a_n) < 0 < f(b_n) . \tag{5.4.1}
$$

由闭区间套性质，有唯一的点 $\xi$ 属于所有区间，且 $a_n\to\xi$，$b_n\to\xi$（$\lvert a_n - \xi\rvert\le b_n - a_n\to 0$）。由 $f$ 的连续性（定理 5.1.2，$\xi$ 为端点时用单侧的情形），$f(a_n)\to f(\xi)$，$f(b_n)\to f(\xi)$。对 (5.4.1) 取极限（推论 3.4.1），$f(\xi)\le 0\le f(\xi)$，所以 $f(\xi) = 0$。又 $f(a)\ne 0$，$f(b)\ne 0$，故 $\xi\in(a, b)$。　∎

这个证明本身就是一个求根的算法，即 5.5 节的二分法。

**定理 5.4.4（介值定理）** 设 $f$ 在 $[a, b]$ 上连续，$f(a)\ne f(b)$，$C$ 是介于 $f(a)$ 与 $f(b)$ 之间的任一数，则至少有一点 $\xi\in(a, b)$，使 $f(\xi) = C$。

*证明*　对 $g(x) = f(x) - C$ 用零点定理：$g(a)$、$g(b)$ 异号。　∎

**推论 5.4.1** 闭区间 $[a, b]$ 上的连续函数的值域是闭区间 $[m, M]$，$m$、$M$ 分别是它的最小值和最大值。

*证明*　由最值定理，$m = f(x_1)$，$M = f(x_2)$。对 $x_1$、$x_2$ 之间的闭区间用介值定理，$[m, M]$ 中每个数都是 $f$ 的值；而 $f$ 的值都在 $[m, M]$ 中。　∎

**推论 5.4.2** 区间上的连续函数把区间映成区间：若 $f$ 在区间 $I$ 上连续，则 $f(I)$ 是区间。

*证明*　一个数集 $J$ 是区间，当且仅当 $J$ 中任意两数之间的数都属于 $J$。设 $y_1 = f(x_1)$、$y_2 = f(x_2)$ 属于 $f(I)$，$y_1 < C < y_2$，对 $x_1$、$x_2$ 之间的闭区间用介值定理，$C\in f(I)$。　∎

介值定理的条件也不能少：函数有跳跃时，两端异号也可以没有零点（图 5.4.1 右）。

回到 5.4.1 节：$r(\theta_2)$ 是初等函数，在 $[0, \pi]$ 上连续，$r(0) = l_1 + l_2 > 600\text{ mm} > r(\pi) = \lvert l_1 - l_2\rvert$，由介值定理，有 $\theta_2\in(0, \pi)$ 使 $r(\theta_2) = 600$ mm。程序 5.4.1 用二分法求得 $\theta_2\approx {{ex5_4.t2_bis:.4f}}^\circ$，与余弦定理给出的 ${{ex5_4.t2_exact:.4f}}^\circ$ 一致。介值定理不告诉我们根在哪里，但它保证了根*存在*，这就是二分法能找到它的前提。逆运动学（由末端位置求关节角）的“解存在吗？”这个问题，在最简单的情形下就是这样回答的。

### 5.4.4 连续的一一对应函数是严格单调的

第 2 章（2.5 节）指出，一一对应的函数不一定单调，但区间上*连续*的一一对应函数一定单调。现在可以证明它。

**定理 5.4.5** 设 $f$ 在区间 $I$ 上连续，且是一一对应的（$x_1\ne x_2$ 时 $f(x_1)\ne f(x_2)$），则 $f$ 在 $I$ 上严格单调。

*证明*　先证：对 $I$ 中任意 $x_1 < x_2 < x_3$，$f(x_2)$ 介于 $f(x_1)$ 与 $f(x_3)$ 之间。否则，比如 $f(x_2)$ 大于 $f(x_1)$ 和 $f(x_3)$，取 $C$ 满足 $\max\{f(x_1), f(x_3)\} < C < f(x_2)$。由介值定理，$(x_1, x_2)$ 和 $(x_2, x_3)$ 中各有一点使 $f = C$，与一一对应矛盾。$f(x_2)$ 小于两者的情形同理。

再证严格单调。取定 $I$ 中两点 $p < q$，不妨设 $f(p) < f(q)$，下证 $f$ 严格递增。任取 $I$ 中 $x < y$，把 $p, q, x, y$ 从小到大排列（相同的只算一次），记排好的点为 $z_1 < z_2 < \cdots < z_k$。对每相邻的三点 $z_{i-1} < z_i < z_{i+1}$ 用上面的结论，$f(z_i)$ 居中，所以 $f(z_i) - f(z_{i-1})$ 与 $f(z_{i+1}) - f(z_i)$ 同号；逐段传递，所有相邻差 $f(z_{i+1}) - f(z_i)$ 同号，即 $f$ 在这些点上严格单调。由 $f(p) < f(q)$，这个方向是递增，所以 $f(x) < f(y)$。　∎

由定理 5.4.5 和定理 5.3.3：区间上连续的一一对应函数，反函数也连续。

### 5.4.5 介值定理的应用

**不动点。** 设 $g$ 在 $[a, b]$ 上连续，且 $g([a, b])\subset[a, b]$。则存在 $x^*\in[a, b]$ 使 $g(x^*) = x^*$。只要对 $f(x) = g(x) - x$ 用零点定理：$f(a) = g(a) - a\ge 0$，$f(b) = g(b) - b\le 0$。这是布劳威尔不动点定理在一维的情形。例如 $\cos x$ 把 $[0, 1]$ 映到 $[\cos 1, 1]\subset[0, 1]$，所以方程 $\cos x = x$ 在 $[0, 1]$ 中有根；程序 5.4.1 求得 $x^*\approx {{ex5_4.fix:.6f}}$。在计算器上（弧度模式）反复按 cos 键，最后停在的正是这个数。

**四足机器人站稳。** 四足机器人（或一张四条腿的方桌）放在不平的地面上，常常只有三只脚着地，第四只脚悬空，一推就晃。有一个令人意外的结论：只要地面起伏不太剧烈，把机身绕中心转一个不超过 $90^\circ$ 的角，总能让四只脚同时着地。

设四只脚的落点在外接圆半径为 $\rho$ 的正方形四角，机身转过 $\varphi$ 角时，四个落点处的地面高度依次为 $z_1, z_2, z_3, z_4$。让 1、2、3 号脚着地，三点确定一个平面；正方形中 4 号脚的平面位置等于“1 号 + 3 号 − 2 号”，所以平面在 4 号脚处的高度是 $z_1 + z_3 - z_2$，4 号脚离地的高度就是

$$
D(\varphi) = z_1 + z_3 - z_2 - z_4 .
$$

（$D < 0$ 时 4 号脚会“陷进”地面，实际上是 2、4 号着地，1、3 号中有一只悬空；总之 $D\ne 0$ 时机身在两条对角线之间摇晃。）机身转过 $90^\circ$，四只脚的位置轮换一格，$z_1\to z_2\to z_3\to z_4\to z_1$，于是 $D(\varphi + 90^\circ) = -D(\varphi)$。若 $D(0)\ne 0$，则 $D(0)$ 与 $D(90^\circ)$ 异号；$D$ 随 $\varphi$ 连续变化（地面高度是位置的连续函数），由零点定理，有 $\varphi^*\in(0, 90^\circ)$ 使 $D(\varphi^*) = 0$，四脚同时着地。

程序 5.4.1 在一个起伏约几厘米的地面上（$\rho = 0.35$ m）计算：$D(0)\approx {{ex5_4.D0_mm:.2f}}$ mm，$D(90^\circ)\approx {{ex5_4.D90_mm:.2f}}$ mm，二分法求得 $\varphi^*\approx {{ex5_4.phi_star:.2f}}^\circ$（图 5.4.2 右）。这个论证假设了地面起伏相对于腿长很小，转动时脚只在水平方向移动；严格的讨论见习题 5.4.8 的参考文献。

### 5.4.6 历史注记

介值定理曾被认为“显然”而无须证明，直到 1817 年波尔查诺发表《纯粹分析的证明》，才第一次给出了不依赖几何直观的证明。他指出：说一条连续曲线从直线一侧走到另一侧必然穿过直线，是借用了几何的直观，而几何本身的连续性恰恰需要分析来奠基。波尔查诺的证明要用到“有上界的集合有最小上界”，这一点在当时还没有严格的实数理论作为依据，直到 1872 年戴德金和康托尔构造了实数（第 6 章）。最值定理由魏尔斯特拉斯在 19 世纪 60 年代的讲课中证明。在有理数范围内，这些定理都不成立：$f(x) = x^2 - 2$ 在有理数集上“连续”，$f(1) < 0 < f(2)$，却没有有理数零点。

### 5.4.7 生活中的例子

早上 6 点，一位登山者从山脚出发，沿一条小路上山，傍晚到达山顶，在山顶过夜。第二天早上 6 点，他沿同一条路下山，傍晚回到山脚。两天中走走停停，速度忽快忽慢。问：路上是否有一个地点，他两天经过这里的钟点恰好相同？答案是一定有。设想两天的行程同时进行：一个人上山，另一个人下山，两人在同一条路上相向而行，必在某处相遇。用函数说：设 $u(t)$、$d(t)$ 分别是两天中 $t$ 时刻离山脚的路程，到达后视为停在原地，$f(t) = u(t) - d(t)$ 在早上 6 点为负，在两天中较晚的那个到达时刻为正，由零点定理，某个时刻 $f = 0$。

再如：任何时刻，地球赤道上总有两个对径点（相差 $180^\circ$ 经度）的气温相同。设 $T(\varphi)$ 是经度 $\varphi$ 处的气温，$g(\varphi) = T(\varphi) - T(\varphi + 180^\circ)$，则 $g(\varphi + 180^\circ) = -g(\varphi)$，与四足机器人的论证如出一辙。

**工程师笔记**

- 介值定理保证“解存在”，但不告诉解在哪里、有几个。工程中先用它（或画图）确认解存在、找到一个有根的区间，再用二分法等算法去求。
- 闭区间、连续，两个条件少一个，最大值就可能取不到。优化问题（第 11、33 章）求最大最小值之前，先检查变量的范围是否闭、目标函数是否连续；变量范围是开区间时，最优解可能“跑到边界上去”而取不到。
- 逆运动学的可达性、四足机器人的落脚、控制器参数的存在性，很多“存在一个……使得……”的工程问题，都是介值定理的应用。
