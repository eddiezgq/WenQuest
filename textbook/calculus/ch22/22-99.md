title: 本章小结
---

本章的主线是：*数值解的误差 = 每步新产生的误差 + 旧误差的传播；方法的好坏既看阶数，也看稳定性和长期行为*。

$p$ 阶方法的局部截断误差为 $O(h^{p+1})$，整体误差为 $O(h^p)$；误差在传播中每步最多放大 $1 + hL$ 倍，由此证明了欧拉法的误差估计。步长并非越小越好，舍入误差随步数积累。龙格–库塔法在一步之内取几处斜率加权平均，经典 RK4 每步四次求值、四阶精度，是光滑问题的默认选择；自己写的 RK4 与 MuJoCo 的 RK4 逐位相同。嵌入式方法用两个不同阶的结果之差估计误差，据此自动调整步长，把计算花在变化快的地方。刚性方程的显式解法受最快模态的稳定性限制，隐式欧拉法等 A-稳定方法配合牛顿迭代可以大步前进，电机的电–机–热模型就是典型例子。保守系统的长时间仿真看重结构：显式欧拉法每步把相平面面积放大 $1 + h^2\omega^2$ 倍，能量越来越大；辛方法保持面积，能量误差长期有界，MuJoCo 默认的半隐式欧拉法就是辛欧拉法。最后，皮卡迭代证明了：右边连续且关于未知函数满足利普希茨条件时，初值问题的解局部存在、唯一，并连续依赖于初值（格朗沃尔不等式）；线性方程组的解在整个区间上存在。

### 部分习题答案与提示

22.1.1 $y_{10} = 1.1^{10}\approx {{ans22.e2211_y:.4f}}$，误差约 {{ans22.e2211_err:.4f}}，误差界 $\frac{e\cdot 0.1}{2}(e - 1)\approx {{ans22.e2211_bound:.4f}}$。

22.1.2 由中值定理 $\lvert y_{n+1} - z_{n+1}\rvert\le(1 + hL)\lvert y_n - z_n\rvert$，再用 $1 + hL\le e^{hL}$。

22.1.3 $e_{n+1} = \bigl(1 + h\frac{\partial f}{\partial y}\bigr)e_n + \tau_{n+1}$，而 $0\le 1 + h\frac{\partial f}{\partial y}\le 1 - h\mu$，所以 $\lvert e_{n+1}\rvert\le(1 - h\mu)\lvert e_n\rvert + \frac{Mh^2}{2}$。由引理 22.1.1 证明中的几何级数求和，$\lvert e_n\rvert\le\frac{Mh^2}{2}\cdot\frac{1 - (1 - h\mu)^n}{h\mu}\le\frac{Mh}{2\mu}$。算例 22.1.1 中 $\mu = 1$，这个界为 $1.5h$，比定理 19.6.1 的 $\frac{3h}{2}(e^2 - 1)$ 紧得多，只比实际误差（约 $0.41h$）大三四倍。

22.1.4 $y'' = 0$ 时 $\tau = 0$；$y_n = 2x_n$，与准确解相同。

22.1.6 单精度在 100 附近的相邻两数相差 $2^{-17}\approx 7.6\times 10^{-6}$ m。若速度为 1 m/s，每 1 ms 增加 1 mm，舍入误差可达增量的 0.4%（而且可能总朝一个方向）；离原点越远越糟。所以长时间运行的里程计应使用双精度或定点数，或者分段积分后再累加。

22.2.1 休恩法误差约 {{ans22.e2221_heun:.2e}}，RK4 约 {{ans22.e2221_rk4:.2e}}。

22.2.3 展开 $k_2 = f + h(cf_x + af_yf) + O(h^2)$，与 $y + hf + \frac{h^2}{2}(f_x + f_yf)$ 比较 $h$、$h^2$ 的系数。

22.2.6 不再是四阶。跨过换向时刻的那一步中 $f$ 有跳跃，这一步 $\omega$ 的局部误差为 $O(h)$（$\theta$ 为 $O(h^2)$）。这样的步只有有限个，整体误差为 $O(h)$；而且误差大小取决于换向时刻落在步内的位置，步长减半时误差不规则地变化，大致只缩小一半。应在换向时刻分段积分（22.3.4 节的事件检测）。

22.3.1 $k_1 = 0$，$k_2 = f(0.5, 1) = -1$，$\mathrm{err} = 0.25 > 10^{-3}$，拒绝；$0.9\sqrt{0.004}\approx 0.057 < 0.2$，按限幅取 $h = 0.5\times 0.2 = 0.1$。

22.3.2 $0.9\times 4^{-1/2} = 0.45$ 倍；$0.9\times 4^{-1/5}\approx 0.68$ 倍。

22.3.3 叫作局部外推。(22.3.1) 估计的是低阶结果的误差，所接受的高阶结果的误差一般更小，所以控制是偏保守的。

22.3.4 步数大致与 $\mathrm{tol}^{-1/2}$ 成正比，因为误差估计 $\propto h^2$。

22.4.1 $y_n = \frac{y_0}{(1 + h\lambda)^n}$，$0 < \frac{1}{1 + h\lambda} < 1$。

22.4.2 $R(z) = \frac{1 + z/2}{1 - z/2}$；$\operatorname{Re}z < 0$ 时 $z$ 到 $-2$ 比到 $2$ 近，$\lvert R\rvert < 1$。$h\lambda\to -\infty$ 时 $R\to -1$：很快的模态不被衰减，而是每步变号地振荡，所以对很刚性的问题梯形法会出现“振铃”，隐式欧拉法则把它们迅速压下去。

22.4.3 第一次迭代 $z_1 = {{ans22.e2243_z1:g}}$，第二次 $z_2\approx {{ans22.e2243_z2:.4f}}$，已接近方程的根 {{ans22.e2243_z:.4f}}；与准确解 $\frac{1}{\sqrt 2}\approx {{ans22.e2243_exact:.4f}}$ 的差来自大步长的截断误差，而不是牛顿法。

22.4.4 $h < \frac{2}{\lvert\lambda_{\max}\rvert}\approx {{ans22.e2244_h_ms:.2f}}$ ms，1 小时至少约 ${{ans22.e2244_steps:sci1}}$ 步。

22.4.5 非常数的多项式在负实轴上 $\lvert R(-x)\rvert\to\infty$（$x\to +\infty$）。

22.4.6 接触弹簧通常带阻尼，特征值 $-\zeta\omega\pm i\omega\sqrt{1 - \zeta^2}$（$\omega = \sqrt{k/m}$）的模很大，而我们关心的运动很慢，所以是刚性的。显式方法要求 $h\omega$ 不超出稳定区域（RK4 约 $h < 2.8\sqrt{m/k}$；无阻尼时显式欧拉对任何步长都不稳定）。物理引擎把接触当作约束求解（而不是硬弹簧），或者用软约束加隐式阻尼。

22.5.1 矩阵为 $\begin{pmatrix}1 & -h\\ h\omega^2 & 1\end{pmatrix}^{-1}$，行列式 $\frac{1}{1 + h^2\omega^2}$，与 (22.5.1) 同样的计算得 $E$ 每步乘以 $\frac{1}{1 + h^2\omega^2}$。单摆的摆幅越来越小，像有阻尼一样。

22.5.3 $h\omega < 2$；约 $h < {{ex22_5.ho_hcrit:.2f}}$ s。

22.5.5 辛欧拉法与 $h$ 成正比，蛙跳法与 $h^2$ 成正比。

22.5.6 有阻尼时能量本来就减小，耗散的物理效应比数值方法的差别大，两者的区别不再本质；但显式欧拉法在大阻尼时可能发散（刚性），MuJoCo 中有较大关节阻尼时宜用 `implicitfast`。

22.6.1 $y_n = \sum_{k=0}^n\frac{x^{2k}}{k!}$，是 $e^{x^2}$ 的泰勒多项式。

22.6.2 $M = 1 + b^2$，$\frac{b}{1 + b^2}\le\frac12$（$b = 1$ 时取等号），所以最大为 $\frac12$；实际的解 $\tan x$ 在 $\lvert x\rvert < \frac\pi2$ 上存在。

22.6.3 $\lvert\sin y - \sin z\rvert = \lvert\cos\eta\rvert\lvert y - z\rvert\le\lvert y - z\rvert$。单摆的 $\boldsymbol f = \bigl(\omega, -\frac gl\sin\theta\bigr)$ 在整个平面上满足利普希茨条件，由定理 22.6.2，解在任意区间上存在。

22.6.4 $\frac{\sqrt{\lvert y\rvert}}{\lvert y\rvert} = \frac{1}{\sqrt{\lvert y\rvert}}\to\infty$。$y\equiv 0$ 与“$x < 0$ 时 $y = 0$，$x\ge 0$ 时 $y = \frac{x^2}{4}$”都是解。

22.6.5 $u = \lvert y - z\rvert\le\int(Lu + \varepsilon)$，对 $u + \frac\varepsilon L$ 用格朗沃尔不等式。模型误差 $\varepsilon$ 的影响也按 $e^{L\lvert x - x_0\rvert}$ 放大。

22.6.6 $y_n$ 的前 $n + 1$ 项与 $\frac1{1 - x} = 1 + x + x^2 + \cdots$ 相同（例如 $y_2 = 1 + x + x^2 + \frac{x^3}{3}$）；$x > 1$ 时 $y_n(x)$ 随 $n$ 增大趋于无穷，不收敛。这与幂级数的收敛半径有关（第 24 章）。
