### 14.3.1 问题的提出

清洁机器人和一些 AGV 背着一个卧式圆柱形水箱（或电解液、冷却液箱）。箱里装一个液位传感器，测出液面高度 $h$。控制器要据此报告“还剩多少水”。问题是：圆柱横放时，液位和水量不成正比，液位降到一半时水量正好剩一半，液位降到四分之一时水量却只有约五分之一。怎样由液位算出水量？

把水按水平方向切成薄片：高度 $y$ 处（以圆心为原点）薄片的宽度是 $2\sqrt{r^2 - y^2}$，长度是箱长 $L$，厚 $dy$。于是

$$
V(h) = L\int_{-r}^{h - r}2\sqrt{r^2 - y^2}\,dy .
$$

被积函数里有根式 $\sqrt{r^2 - y^2}$，前面的方法都对付不了它。13.5 节求单位圆面积时用过一个办法：令 $y = r\sin\theta$，根号就消失了。本节把这个办法系统化。

### 14.3.2 三种代换

根式 $\sqrt{a^2 - x^2}$、$\sqrt{a^2 + x^2}$、$\sqrt{x^2 - a^2}$（$a > 0$）分别对应三个恒等式：

| 根式 | 代换 | 用到的恒等式 | 化简结果 |
|---|---|---|---|
| $\sqrt{a^2 - x^2}$ | $x = a\sin\theta$，$-\frac\pi2\le\theta\le\frac\pi2$ | $1 - \sin^2\theta = \cos^2\theta$ | $a\cos\theta$ |
| $\sqrt{a^2 + x^2}$ | $x = a\tan\theta$，$-\frac\pi2 < \theta < \frac\pi2$ | $1 + \tan^2\theta = \sec^2\theta$ | $a\sec\theta$ |
| $\sqrt{x^2 - a^2}$ | $x = a\sec\theta$，$0\le\theta < \frac\pi2$（$x\ge a$） | $\sec^2\theta - 1 = \tan^2\theta$ | $a\tan\theta$ |

$\theta$ 的范围这样取，是为了让代换单调（可以反解出 $\theta$），并且开方后的 $\cos\theta$、$\sec\theta$、$\tan\theta$ 都不是负数，根号可以直接去掉。几何上，三种代换都是把 $x$、$a$ 和根式看作一个直角三角形的三条边（例如 $x = a\sin\theta$ 时，斜边 $a$、对边 $x$、邻边 $\sqrt{a^2 - x^2}$）。

**算例 14.3.1** 求 $\int\sqrt{a^2 - x^2}\,dx$。

*解*　令 $x = a\sin\theta$，$dx = a\cos\theta\,d\theta$：

$$
\int a\cos\theta\cdot a\cos\theta\,d\theta = a^2\int\frac{1 + \cos 2\theta}{2}\,d\theta = \frac{a^2}{2}\Bigl(\theta + \sin\theta\cos\theta\Bigr) + C .
$$

换回 $x$：$\theta = \arcsin\frac xa$，$\sin\theta = \frac xa$，$\cos\theta = \frac{\sqrt{a^2 - x^2}}{a}$，所以

$$
\int\sqrt{a^2 - x^2}\,dx = \frac{a^2}{2}\arcsin\frac xa + \frac x2\sqrt{a^2 - x^2} + C . \tag{14.3.1}
$$

两项各有几何意义：$\frac x2\sqrt{a^2 - x^2}$ 是一个三角形的面积，$\frac{a^2}{2}\arcsin\frac xa$ 是一个扇形的面积（习题 14.3.4）。　∎

**算例 14.3.2** 求 $\int\frac{dx}{\sqrt{x^2 + a^2}}$。

*解*　令 $x = a\tan\theta$，$dx = a\sec^2\theta\,d\theta$，$\sqrt{x^2 + a^2} = a\sec\theta$：

$$
\int\frac{a\sec^2\theta}{a\sec\theta}\,d\theta = \int\sec\theta\,d\theta = \ln\lvert\sec\theta + \tan\theta\rvert + C_1 = \ln\Bigl(\frac{\sqrt{x^2 + a^2}}{a} + \frac xa\Bigr) + C_1 ,
$$

（用了 (14.2.5)。）把 $-\ln a$ 并入常数，得

$$
\int\frac{dx}{\sqrt{x^2 + a^2}} = \ln\bigl(x + \sqrt{x^2 + a^2}\bigr) + C = \operatorname{arsinh}\frac xa + C' . \tag{14.3.2}
$$

最后一步用了 2.6 节的 $\operatorname{arsinh}x = \ln\bigl(x + \sqrt{x^2 + 1}\bigr)$：2.6 节预告的“$\int\frac{dx}{\sqrt{x^2 + 1}}$ 的答案就是 $\operatorname{arsinh}x$”至此兑现。程序 14.3.1 用中点和算得 $\int_0^2\frac{dx}{\sqrt{x^2 + 1}}\approx {{ex14_3.asinh_num:.6f}}$，$\operatorname{arsinh}2\approx {{ex14_3.asinh2:.6f}}$。也可以直接用双曲代换 $x = a\sinh u$（$\cosh^2u - \sinh^2u = 1$），一步得到 $\int du = u$（习题 14.3.5）。　∎

**算例 14.3.3** 求 $\int\frac{\sqrt{x^2 - 1}}{x}\,dx$（$x > 1$）。

*解*　令 $x = \sec\theta$，$dx = \sec\theta\tan\theta\,d\theta$，$\sqrt{x^2 - 1} = \tan\theta$：

$$
\int\frac{\tan\theta}{\sec\theta}\sec\theta\tan\theta\,d\theta = \int\tan^2\theta\,d\theta = \int(\sec^2\theta - 1)\,d\theta = \tan\theta - \theta + C = \sqrt{x^2 - 1} - \operatorname{arcsec}x + C .
$$

（$\operatorname{arcsec}x = \arccos\frac1x$。）　∎

### 14.3.3 卧式水箱的液位与水量

回到 14.3.1 节。对 $\int 2\sqrt{r^2 - y^2}\,dy$ 用 (14.3.1)，代入上下限 $y = -r$ 与 $y = h - r$，整理得

$$
V(h) = L\Bigl[r^2\arccos\frac{r - h}{r} - (r - h)\sqrt{2rh - h^2}\Bigr],\qquad 0\le h\le 2r . \tag{14.3.3}
$$

方括号里是液面以下那个弓形的面积：$h\le r$ 时是扇形减去三角形（图 14.3.1 左），$h > r$ 时是扇形加三角形，公式靠 $r - h$ 变号自动成立。取 $r = 0.15$ m，$L = 0.6$ m，满箱 {{ex14_3.full_L:.1f}} L。表 14.3.1 是程序 14.3.1 用公式和用数值积分算出的结果。

### 14.3.4 配方后再代换

根式里是一般的二次式 $\sqrt{ax^2 + bx + c}$ 时，先配方化成上面三种形式之一，再代换。

**算例 14.3.4** 求 $\int\frac{x}{\sqrt{x^2 + 2x + 5}}\,dx$。

*解*　$x^2 + 2x + 5 = (x + 1)^2 + 4$。令 $u = x + 1$：

$$
\int\frac{u - 1}{\sqrt{u^2 + 4}}\,du = \sqrt{u^2 + 4} - \operatorname{arsinh}\frac u2 + C = \sqrt{x^2 + 2x + 5} - \operatorname{arsinh}\frac{x + 1}{2} + C .
$$

第一项用换元 $w = u^2 + 4$，第二项用 (14.3.2)。　∎

### 14.3.5 历史注记

三角代换的思想与三角学同样古老：用一个角来参数化圆上的点。17 世纪，求圆和双曲线的面积、弧长是微积分的核心问题，牛顿、莱布尼茨和他们的追随者在这些问题中大量使用了这样的代换；欧拉在 1768 年的《积分学原理》中把它们作为标准方法整理出来。卧式罐的容积公式在 19 世纪石油、酒类的储运中被广泛使用，各国的计量规程至今仍规定用 (14.3.3) 一类的公式编制罐容表。

### 14.3.6 生活中的例子

加油站的地下油罐是卧式圆柱，工作人员用量油尺插进罐里，看油浸到哪一格，再查一张表得出还剩多少升，这张表就是 (14.3.3) 算出来的罐容表。汽车的油量表也有类似的问题：油箱形状不规则，浮子的位置与油量不成正比。若指针直接按液位走，在“半箱”附近每升油对应的指针位移最小，指针走得慢；接近空箱时每升油对应的液位变化大，指针掉得快。所以厂家要用一条非线性的曲线去修正，否则司机会觉得油量“后半箱掉得特别快”。

**工程师笔记**

- 罐容表：液位—体积关系由几何形状决定，横放的圆柱、球形罐、带封头的罐都有公式（封头部分也用三角代换），复杂形状则用 CAD 模型数值计算。控制器里存一张表或一个拟合多项式即可。
- 液位传感器在箱底和箱顶附近灵敏度高（液位变化大、水量变化小），在中间灵敏度低。若要求水量的精度一致，中间段的液位测量要更准。
- 三角代换后，根式开方要按 $\theta$ 的范围判断符号。$\sqrt{\cos^2\theta} = \lvert\cos\theta\rvert$，在 $-\frac\pi2\le\theta\le\frac\pi2$ 上才等于 $\cos\theta$。
