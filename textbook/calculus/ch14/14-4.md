### 14.4.1 问题的提出

一架 1.5 kg 的四旋翼无人机以 10 m/s 平飞，突然停止水平推进（例如失去信号后的保护动作：保持高度，推力只用来平衡重力），靠阻力减速滑行。阻力有两部分：与速度成正比的线性阻力 $c_1v$（主要来自旋转的旋翼，低速时为主），与速度平方成正比的二次阻力 $c_2v^2$（机身的空气阻力，高速时为主）。由牛顿第二定律

$$
m\frac{dv}{dt} = -(c_1v + c_2v^2) .
$$

减到 1 m/s 要多久，这期间滑出多远？把变量分开（第 19 章将系统地讲这种“分离变量”的方法），时间是

$$
t = \int_{v_1}^{v_0}\frac{m\,dv}{c_1v + c_2v^2} .
$$

被积函数是两个多项式之比，叫作**有理函数**。本节说明：有理函数的积分*一定*能用初等函数表示出来，方法是把它拆成几个简单分式之和。

### 14.4.2 部分分式分解

有理函数 $\frac{P(x)}{Q(x)}$ 中，若分子的次数不低于分母（假分式），先做多项式除法，化成“多项式 + 真分式”。多项式容易积分，下面只讨论真分式。

代数学告诉我们（这里不证明）：实系数多项式 $Q(x)$ 总能分解成一次因式 $(x - a)$ 与没有实根的二次因式 $(x^2 + px + q)$（$p^2 < 4q$）的乘积，可能有重复。相应地，真分式可以唯一地写成下列*部分分式*之和：

- 每个一次因式 $(x - a)^k$ 对应 $\dfrac{A_1}{x - a} + \dfrac{A_2}{(x - a)^2} + \dots + \dfrac{A_k}{(x - a)^k}$；
- 每个二次因式 $(x^2 + px + q)^k$ 对应 $\dfrac{B_1x + C_1}{x^2 + px + q} + \dots + \dfrac{B_kx + C_k}{(x^2 + px + q)^k}$。

系数可以用“通分后比较系数”求出，一次因式的系数更快的方法是“遮盖法”：要求 $\frac{1}{(x - a)}$ 的系数 $A$，把原式乘以 $(x - a)$，再令 $x = a$。

**算例 14.4.1** 求 $\int\frac{dx}{x^2 - 1}$。

*解*　$x^2 - 1 = (x - 1)(x + 1)$，设 $\frac{1}{x^2 - 1} = \frac{A}{x - 1} + \frac{B}{x + 1}$。遮盖法：乘以 $(x - 1)$ 后令 $x = 1$，得 $A = \frac12$；乘以 $(x + 1)$ 后令 $x = -1$，得 $B = -\frac12$。于是

$$
\int\frac{dx}{x^2 - 1} = \frac12\ln\lvert x - 1\rvert - \frac12\ln\lvert x + 1\rvert + C = \frac12\ln\Bigl\lvert\frac{x - 1}{x + 1}\Bigr\rvert + C .
$$

求导即可验算。
与 $\int\frac{dx}{x^2 + 1} = \arctan x + C$ 比较：分母只差一个符号，答案一个是对数，一个是反正切。区别在于分母有没有实根。　∎

**算例 14.4.2（重根）** 求 $\int\frac{x + 3}{x(x - 1)^2}\,dx$。

*解*　设 $\frac{x + 3}{x(x - 1)^2} = \frac Ax + \frac{B}{x - 1} + \frac{C}{(x - 1)^2}$。遮盖法：$x = 0$ 得 $A = 3$；乘以 $(x - 1)^2$ 后令 $x = 1$ 得 $C = 4$。再比较 $x^2$ 的系数：通分后分子 $A(x - 1)^2 + Bx(x - 1) + Cx$ 中 $x^2$ 的系数 $A + B$ 应等于 0，所以 $B = -3$。于是

$$
\int\Bigl(\frac3x - \frac{3}{x - 1} + \frac{4}{(x - 1)^2}\Bigr)dx = 3\ln\Bigl\lvert\frac{x}{x - 1}\Bigr\rvert - \frac{4}{x - 1} + C .
$$

　∎

**算例 14.4.3（二次因式）** 求 $\int\frac{dx}{x^3 + 1}$。

*解*　$x^3 + 1 = (x + 1)(x^2 - x + 1)$，后者判别式为负。设 $\frac{1}{x^3 + 1} = \frac{A}{x + 1} + \frac{Bx + C}{x^2 - x + 1}$。$x = -1$ 遮盖得 $A = \frac13$；比较 $x^2$ 项系数 $A + B = 0$，$B = -\frac13$；比较常数项 $A + C = 1$，$C = \frac23$。第二项拆成“分子是分母导数的倍数”加“常数除以配方后的二次式”：

$$
\frac{-\frac13x + \frac23}{x^2 - x + 1} = -\frac16\cdot\frac{2x - 1}{x^2 - x + 1} + \frac12\cdot\frac{1}{(x - \frac12)^2 + \frac34} .
$$

前者积分为 $-\frac16\ln(x^2 - x + 1)$，后者用算例 13.5.1（4）为 $\frac12\cdot\frac{2}{\sqrt3}\arctan\frac{2x - 1}{\sqrt3}$。合起来

$$
\int\frac{dx}{x^3 + 1} = \frac13\ln\lvert x + 1\rvert - \frac16\ln(x^2 - x + 1) + \frac{1}{\sqrt3}\arctan\frac{2x - 1}{\sqrt3} + C .
$$

14.6 节将看到，计算机代数系统给出的答案与此相同。　∎

由分解的四种形式可以看出：*有理函数的原函数只含有理函数、对数和反正切*三种成分。$\frac{1}{(x - a)^k}$ 积分为幂或对数；$\frac{Bx + C}{(x^2 + px + q)^k}$ 配方后积分为对数、反正切，以及 $k\ge 2$ 时由递推公式得到的有理函数（习题 14.4.6）。所以有理函数总能积出来，难的只是分母的因式分解（五次及五次以上的多项式没有一般的求根公式，那时只能数值求根）。

### 14.4.3 无人机的滑行

回到 14.4.1 节。$\frac{m}{c_1v + c_2v^2} = \frac{m}{v(c_1 + c_2v)} = \frac{m}{c_1}\Bigl(\frac1v - \frac{c_2}{c_1 + c_2v}\Bigr)$，所以从 $v_0$ 减到 $v_1$ 的时间

$$
t = \frac{m}{c_1}\ln\frac{v_0(c_1 + c_2v_1)}{v_1(c_1 + c_2v_0)} . \tag{14.4.1}
$$

滑行距离：$dx = v\,dt = \frac{mv\,dv}{-(c_1v + c_2v^2)}$，约去 $v$ 后更简单，

$$
x = \int_{v_1}^{v_0}\frac{m\,dv}{c_1 + c_2v} = \frac{m}{c_2}\ln\frac{c_1 + c_2v_0}{c_1 + c_2v_1} . \tag{14.4.2}
$$

取 $m = 1.5$ kg，$c_1 = 0.3$ N·s/m，$c_2 = 0.05$ N·s²/m²，$v_0 = 10$ m/s，$v_1 = 1$ m/s：$t\approx {{ex14_4.t_f:.2f}}$ s，$x\approx {{ex14_4.x_f:.1f}}$ m。程序 14.4.1 用小步长直接积分运动方程，得 {{ex14_4.t_num:.2f}} s 和 {{ex14_4.x_num:.1f}} m，与公式一致。表 14.4.1 是减到各个速度所需的时间与距离。

### 14.4.4 历史注记

有理函数的积分问题在 17 世纪末由莱布尼茨和约翰·伯努利解决。他们认识到关键是分母的因式分解，而当时还不清楚实系数多项式是否总能分解成一次和二次因式；莱布尼茨甚至一度以为 $x^4 + a^4$ 不能这样分解。这个问题直到“代数基本定理”（每个复系数多项式都有复根）被证明才彻底解决：达朗贝尔、欧拉、拉格朗日都尝试过，高斯在 1799 年的博士论文中给出了第一个被普遍接受的证明。所以“有理函数总能积出来”这个微积分的结论，依赖于代数学中一个很深的定理。

### 14.4.5 生活中的例子

传染病、新产品、谣言的传播常用“逻辑斯谛模型”描述：$\frac{dN}{dt} = rN\bigl(1 - \frac NK\bigr)$，$N$ 是已经感染（或购买、听说）的人数，$K$ 是总人数。分离变量后要求 $\int\frac{dN}{N(1 - N/K)}$，用部分分式拆成 $\frac1N + \frac{1}{K - N}$，积出来正是那条著名的 S 形曲线：开始缓慢、中间迅猛、最后饱和。手机、电动汽车的普及率曲线都接近这个形状。第 19 章将详细讨论它。

**工程师笔记**

- 运动方程 $m\dot v = -F(v)$ 中阻力是速度的多项式时，减速时间 $\int\frac{m\,dv}{F(v)}$ 与距离 $\int\frac{mv\,dv}{F(v)}$ 都是有理函数的积分，可以得到准确公式。它们常用来估计制动距离、失控后的影响范围。
- 部分分式在控制工程中天天用到：传递函数的拉普拉斯反变换，就是把有理函数拆成部分分式，每一项对应一个指数或衰减振荡（第 44 章）。
- 分母有接近相等的根时，部分分式的系数会很大且符号相反，数值计算容易严重相消（4.7 节）。这时宜改用其他形式或直接数值积分。
