### 4.4.1 问题的提出

一台数控机床加工一根轴，图纸要求直径误差不超过 $\varepsilon$。直径取决于刀具的位置 $x$：$d = f(x)$，名义位置 $a$ 对应名义直径 $L = f(a)$。车间要回答的问题是：刀具的定位误差必须控制在多大范围 $\delta$ 之内，才能保证直径误差不超过 $\varepsilon$？客户要求越严（$\varepsilon$ 越小），定位就要越准（$\delta$ 越小）。如果无论客户提出多严的要求，车间总能找到相应的定位精度，就说直径“随刀具位置连续地、可控地变化”。

这正是函数极限的准确含义：“$f(x)$ 无限接近 $L$”就是无论要求多近（$\varepsilon$），只要 $x$ 足够接近 $a$（$\delta$），都能做到。它与 3.3 节数列的 $\varepsilon$–$N$ 定义是同一个想法，只是把“从第 $N$ 项起”换成了“在 $a$ 的 $\delta$ 去心邻域内”。

### 4.4.2 定义

**定义 4.4.1（函数极限）** 设函数 $f$ 在 $a$ 的某个去心邻域内有定义，$L$ 是实数。如果对于任意给定的 $\varepsilon > 0$，总存在 $\delta > 0$，使得当 $0 < \lvert x - a\rvert < \delta$ 时，

$$
\lvert f(x) - L\rvert < \varepsilon , \tag{4.4.1}
$$

就称 $L$ 为 $f(x)$ 当 $x\to a$ 时的极限，记作 $\lim\limits_{x\to a}f(x) = L$。

用量词写出来：

$$
\lim_{x\to a}f(x) = L\iff\forall\varepsilon > 0,\ \exists\delta > 0,\ \forall x:\ 0 < \lvert x - a\rvert < \delta\Rightarrow\lvert f(x) - L\rvert < \varepsilon .
$$

几何上：在 $y = L$ 上下画出宽为 $2\varepsilon$ 的水平带，总能在 $x = a$ 左右找到宽为 $2\delta$ 的竖直带，使函数图像在竖直带内的部分（$x = a$ 那一点除外）全部落在水平带内（图 4.4.1）。$\varepsilon$ 越窄，$\delta$ 一般也要越窄。

“$0 < \lvert x - a\rvert$”这个条件把 $x = a$ 排除在外，它体现了 4.1.2 节的第一点：极限与 $f$ 在 $a$ 点的值无关。

这个定义可以看作一个两人游戏。对手先出一个 $\varepsilon$（他想要的精度），你应答一个 $\delta$（你保证的范围）；你赢，当且仅当在 $\delta$ 范围内所有的 $x$ 都满足精度要求。$\lim f = L$ 的意思是：无论对手出什么 $\varepsilon$，你都有必胜的应答。

### 4.4.3 用定义证明极限

与 3.3 节一样，先倒着分析，从 $\lvert f(x) - L\rvert < \varepsilon$ 出发，看 $\lvert x - a\rvert$ 多小时它成立，由此确定 $\delta$；再正着写证明。

**算例 4.4.1** 证明 $\lim_{x\to 2}(3x + 1) = 7$。

*证明*　$\lvert(3x + 1) - 7\rvert = 3\lvert x - 2\rvert$。任给 $\varepsilon > 0$，取 $\delta = \varepsilon/3$，当 $0 < \lvert x - 2\rvert < \delta$ 时，$\lvert(3x + 1) - 7\rvert < 3\delta = \varepsilon$。　∎

**算例 4.4.2** 证明 $\lim_{x\to 2}x^2 = 4$。

*分析*　$\lvert x^2 - 4\rvert = \lvert x - 2\rvert\,\lvert x + 2\rvert$。因子 $\lvert x - 2\rvert$ 可以控制，因子 $\lvert x + 2\rvert$ 要先给一个上界。先限定 $\lvert x - 2\rvert < 1$，这时 $1 < x < 3$，$\lvert x + 2\rvert < 5$（习题 2.1.5 已经做过）。于是只要再让 $\lvert x - 2\rvert < \varepsilon/5$。

*证明*　任给 $\varepsilon > 0$，取 $\delta = \min\{1, \varepsilon/5\}$。当 $0 < \lvert x - 2\rvert < \delta$ 时，$\lvert x + 2\rvert < 5$，所以 $\lvert x^2 - 4\rvert < 5\cdot\dfrac\varepsilon5 = \varepsilon$。　∎

“先限定一个范围，给其余因子找上界”是 $\varepsilon$–$\delta$ 证明中最常用的技巧，$\delta = \min\{1, \cdots\}$ 这种写法也随处可见。程序 4.4.1 在 $\delta$ 邻域内取了二十万个点核对（表 4.4.1）：误差的最大值都小于 $\varepsilon$，而且留有余地；实际能用的最大 $\delta$ 比证明给出的稍大一些。

**算例 4.4.3** 设 $a > 0$，证明 $\lim_{x\to a}\sqrt x = \sqrt a$。

*证明*　有理化：$\lvert\sqrt x - \sqrt a\rvert = \dfrac{\lvert x - a\rvert}{\sqrt x + \sqrt a}\le\dfrac{\lvert x - a\rvert}{\sqrt a}$。任给 $\varepsilon > 0$，取 $\delta = \min\{a, \sqrt a\,\varepsilon\}$（$\delta\le a$ 保证 $x > 0$，$\sqrt x$ 有定义），则 $0 < \lvert x - a\rvert < \delta$ 时 $\lvert\sqrt x - \sqrt a\rvert < \varepsilon$。　∎

### 4.4.4 其他几种极限的定义

单侧极限、无穷远处的极限、无穷大，都按同样的思路给出定义，只是把“$0 < \lvert x - a\rvert < \delta$”或“$\lvert f(x) - L\rvert < \varepsilon$”换成相应的条件：

| 极限 | 定义：对任意……，存在……，当……时，有…… |
|---|---|
| $\lim_{x\to a^+}f(x) = L$ | $\varepsilon > 0$；$\delta > 0$；$a < x < a + \delta$；$\lvert f(x) - L\rvert < \varepsilon$ |
| $\lim_{x\to a^-}f(x) = L$ | $\varepsilon > 0$；$\delta > 0$；$a - \delta < x < a$；$\lvert f(x) - L\rvert < \varepsilon$ |
| $\lim_{x\to+\infty}f(x) = L$ | $\varepsilon > 0$；$X > 0$；$x > X$；$\lvert f(x) - L\rvert < \varepsilon$ |
| $\lim_{x\to-\infty}f(x) = L$ | $\varepsilon > 0$；$X > 0$；$x < -X$；$\lvert f(x) - L\rvert < \varepsilon$ |
| $\lim_{x\to\infty}f(x) = L$ | $\varepsilon > 0$；$X > 0$；$\lvert x\rvert > X$；$\lvert f(x) - L\rvert < \varepsilon$ |
| $\lim_{x\to a}f(x) = +\infty$ | $M > 0$；$\delta > 0$；$0 < \lvert x - a\rvert < \delta$；$f(x) > M$ |
| $\lim_{x\to a}f(x) = -\infty$ | $M > 0$；$\delta > 0$；$0 < \lvert x - a\rvert < \delta$；$f(x) < -M$ |
| $\lim_{x\to a}f(x) = \infty$ | $M > 0$；$\delta > 0$；$0 < \lvert x - a\rvert < \delta$；$\lvert f(x)\rvert > M$ |
| $\lim_{x\to+\infty}f(x) = +\infty$ | $M > 0$；$X > 0$；$x > X$；$f(x) > M$ |

$\lim_{x\to+\infty}f(x) = L$ 与数列极限的定义几乎相同，只是 $x$ 取一切大于 $X$ 的实数，而不只是整数。

### 4.4.5 函数极限与数列极限：海涅定理

函数极限与数列极限之间有一座桥。

**定理 4.4.1（海涅定理）** $\lim_{x\to a}f(x) = L$ 的充分必要条件是：对*每一个*满足 $x_n\to a$、$x_n\ne a$ 的数列 $\{x_n\}$，都有 $f(x_n)\to L$。

*证明*　必要性：设 $\lim_{x\to a}f(x) = L$，$x_n\to a$，$x_n\ne a$。任给 $\varepsilon > 0$，有 $\delta > 0$ 使 $0 < \lvert x - a\rvert < \delta$ 时 $\lvert f(x) - L\rvert < \varepsilon$；对这个 $\delta$，又有 $N$ 使 $n > N$ 时 $0 < \lvert x_n - a\rvert < \delta$，于是 $\lvert f(x_n) - L\rvert < \varepsilon$。

充分性用反证法：设 $f(x)$ 不以 $L$ 为极限，则存在 $\varepsilon_0 > 0$，使对任意 $\delta > 0$ 都有某个 $x$ 满足 $0 < \lvert x - a\rvert < \delta$ 而 $\lvert f(x) - L\rvert\ge\varepsilon_0$。依次取 $\delta = 1, \tfrac12, \tfrac13, \dots$，得到一列 $x_n$，$0 < \lvert x_n - a\rvert < \tfrac1n$，$\lvert f(x_n) - L\rvert\ge\varepsilon_0$。这列 $x_n\to a$，而 $f(x_n)$ 不趋于 $L$，与条件矛盾。　∎

海涅定理有两个用处。其一，第 3 章关于数列极限的结论（唯一性、四则运算、夹逼准则）可以通过它直接搬到函数极限上来，定理 4.2.1、4.2.2 由此得证（习题 4.4.6、4.4.10）。其二，它是证明极限*不存在*的利器：只要找到两列趋于 $a$ 的点，函数值趋于不同的数，极限就不存在。

**算例 4.4.4** 证明 $\lim_{x\to 0}\sin\dfrac1x$ 不存在。

*证明*　取 $x_n = \dfrac{1}{2n\pi + \pi/2}$，$y_n = \dfrac{1}{2n\pi - \pi/2}$，两列都趋于 0 且不为 0。$\sin\dfrac{1}{x_n} = 1$，$\sin\dfrac1{y_n} = -1$（程序 4.4.1 核对了前五项；$x_5$ 约为 {{ex4_4.x5:.4f}}）。两列函数值趋于不同的数，由海涅定理，极限不存在。　∎

最后补上 4.2 节复合函数极限（定理 4.2.3）的证明。任给 $\varepsilon > 0$，由 $\lim_{u\to b}f(u) = A$，有 $\eta > 0$ 使 $0 < \lvert u - b\rvert < \eta$ 时 $\lvert f(u) - A\rvert < \varepsilon$；对这个 $\eta$，由 $\lim_{x\to a}g(x) = b$，有 $\delta_1 > 0$ 使 $0 < \lvert x - a\rvert < \delta_1$ 时 $\lvert g(x) - b\rvert < \eta$；又由条件，有 $\delta_2 > 0$ 使 $0 < \lvert x - a\rvert < \delta_2$ 时 $g(x)\ne b$。取 $\delta = \min\{\delta_1, \delta_2\}$，则 $0 < \lvert x - a\rvert < \delta$ 时 $0 < \lvert g(x) - b\rvert < \eta$，于是 $\lvert f(g(x)) - A\rvert < \varepsilon$。若 $f$ 在 $b$ 处连续，$g(x) = b$ 时 $\lvert f(g(x)) - A\rvert = 0 < \varepsilon$ 也成立，条件 $g(x)\ne b$ 就用不着了。　∎

### 4.4.6 函数极限的局部性质

数列极限的性质，对函数极限都有对应的版本，只是“从某项起”换成了“在 $a$ 的某个去心邻域内”。

**定理 4.4.2（局部性质）** 设 $\lim_{x\to a}f(x) = L$。

1. （唯一性）极限 $L$ 唯一。
2. （局部有界性）存在 $\delta > 0$ 和 $M$，使 $0 < \lvert x - a\rvert < \delta$ 时 $\lvert f(x)\rvert\le M$。
3. （局部保号性）若 $L > 0$，则存在 $\delta > 0$，使 $0 < \lvert x - a\rvert < \delta$ 时 $f(x) > \tfrac L2 > 0$。
4. （保不等式）若 $\lim_{x\to a}g(x) = M$，且在 $a$ 的某个去心邻域内 $f(x)\le g(x)$，则 $L\le M$。

证明与定理 3.4.1–3.4.3 和推论 3.4.1 相同，只需把 $N$ 换成 $\delta$（习题 4.4.4）。注意第 4 条即使把 $f\le g$ 换成 $f < g$，结论也只能是 $L\le M$：$x^2 < 2x^2$（$x\ne 0$），两边在 0 处的极限却都是 0。注意“局部”二字：$\tfrac1x$ 在 $x\to 1$ 时有极限 1，在 1 附近有界，但在整个定义域上无界。

### 4.4.7 历史注记：从“无限接近”到 $\varepsilon$–$\delta$

“$\varepsilon$–$\delta$”的思想萌芽于柯西 1821 年的《分析教程》和 1823 年的《无穷小计算教程概论》。柯西在证明中已经使用了“给定一个任意小的数 $\varepsilon$，就能找到一个数 $\delta$”这样的论证，但他的定义仍用文字表述，“变量无限接近”之类的说法仍不够明确，以致有些定理（如连续函数列的极限）出了差错。魏尔斯特拉斯在 19 世纪 60 年代于柏林大学的讲课中，把极限、连续、一致收敛都用不等式和量词写成今天的形式，他的学生把这些讲义传播开来。海涅 1872 年的《函数论基础》系统地整理了这些内容，定理 4.4.1 因此以他命名。从 1821 年到 1870 年代，数学家用了半个世纪，才把“无限接近”说清楚。

### 4.4.8 生活中的例子

烤面包的配方写着“盐用面粉重量的 2%”。烘焙师希望盐的误差不超过 0.5 g，称面粉的秤要多准？这就是一个 $\varepsilon$–$\delta$ 问题：盐量 $= 0.02\times$ 面粉量，允许的盐量误差 $\varepsilon = 0.5$ g 是要求，面粉的称量误差 $\delta$ 是应答，取 $\delta = \varepsilon/0.02 = 25$ g 就够了。要求越严，秤就要越准；只要结果随输入“连续”地变化，无论要求多严，总有足够准的秤能满足它。工厂里的公差设计、实验室的仪器选型，都在反复回答“为了 $\varepsilon$，需要多小的 $\delta$”。

**工程师笔记**

- 工程中的“灵敏度”就是 $\delta$ 与 $\varepsilon$ 之比的倒数：输出误差 $\varepsilon$ 约等于灵敏度乘以输入误差 $\delta$。灵敏度大的地方（如 4.3.1 节接近伸直的手臂），要保证同样的输出精度，输入就要控制得更准。第 8 章用导数把这件事说得更精确：$\varepsilon\approx\lvert f'(a)\rvert\,\delta$。
