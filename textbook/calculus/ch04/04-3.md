越接近伸直，灵敏度越大，而且没有上限：$r\to R^-$ 时灵敏度趋于 $+\infty$。这意味着：若要腕心以恒定的速度沿径向外伸到伸直位置，肘关节的转速就要趋于无穷大，任何电机都做不到。机器人学中把这种位置叫作奇异位形，规划轨迹时要绕开它（第 7、46 章）。

这里出现了两种新的极限：$r$ 只能从*一侧*（$r < R$）趋于 $R$；函数值趋于*无穷大*。本节讨论单侧极限、无穷大的极限，以及 $x\to\pm\infty$ 时的极限，并用它们描述函数图像的渐近线。

### 4.3.2 单侧极限

**定义 4.3.1（单侧极限，直观说法）** 若 $x$ 从 $a$ 的左侧（$x < a$）无限接近 $a$ 时，$f(x)$ 无限接近 $L$，称 $L$ 为 $f$ 在 $a$ 处的**左极限**，记作 $\lim_{x\to a^-}f(x) = L$；若 $x$ 从右侧（$x > a$）趋近，称为**右极限**，记作 $\lim_{x\to a^+}f(x) = L$。左极限和右极限统称**单侧极限**。

（国内教材也把左、右极限写作 $f(a^-)$、$f(a^+)$ 或 $f(a - 0)$、$f(a + 0)$。）

**定理 4.3.1** $\lim_{x\to a}f(x) = L$ 当且仅当 $\lim_{x\to a^-}f(x) = \lim_{x\to a^+}f(x) = L$。

（证明在 4.4 节给出定义后是直接的，见习题 4.4.5。）

这条定理常用来判断极限不存在：左、右极限不相等，极限就不存在。

- 符号函数（2.7 节）：$\lim_{x\to 0^-}\operatorname{sgn}x = -1$，$\lim_{x\to 0^+}\operatorname{sgn}x = 1$，所以 $\lim_{x\to 0}\operatorname{sgn}x$ 不存在。
- 取整函数：在整数 $n$ 处，$\lim_{x\to n^-}\lfloor x\rfloor = n - 1$，$\lim_{x\to n^+}\lfloor x\rfloor = n$。
- $2^{1/x}$：$x\to 0^+$ 时 $1/x\to+\infty$，$2^{1/x}\to+\infty$（$x = 0.1$ 时已是 {{ex4_3.p_plus:.0f}}）；$x\to 0^-$ 时 $1/x\to-\infty$，$2^{1/x}\to 0$（$x = -0.01$ 时约为 ${{ex4_3.p_minus2:sci1}}$）。

单侧极限在工程中很常见。电路中开关闭合的瞬间，电感电流、电容电压在“闭合前一瞬间”（$t\to 0^-$）与“闭合后一瞬间”（$t\to 0^+$）的值，是分析电路暂态的出发点。7.2 节的左导数、右导数也是单侧极限。

### 4.3.3 无穷大的极限与铅直渐近线

若 $x\to a$ 时 $\lvert f(x)\rvert$ 无限增大，记作 $\lim_{x\to a}f(x) = \infty$；若 $f(x)$ 取正值无限增大，记作 $+\infty$。与 3.7 节一样，这只是说明了极限不存在的*方式*，$\infty$ 不是一个数。例如

$$
\lim_{x\to 0}\frac{1}{x^2} = +\infty,\qquad \lim_{x\to 0^+}\frac1x = +\infty,\qquad \lim_{x\to 0^-}\frac1x = -\infty,\qquad \lim_{x\to\frac\pi2^-}\tan x = +\infty .
$$

**定义 4.3.2（铅直渐近线）** 若 $\lim_{x\to a^-}f(x)$ 或 $\lim_{x\to a^+}f(x)$ 为 $\pm\infty$，称直线 $x = a$ 为 $y = f(x)$ 的**铅直渐近线**。

有理函数的铅直渐近线通常出现在分母为零（而分子不为零）的地方；$\tan x$ 在 $x = \tfrac\pi2 + k\pi$ 处、$\ln x$ 在 $x = 0$ 处都有铅直渐近线。4.3.1 节的灵敏度作为 $r$ 的函数，在 $r = R$ 处有铅直渐近线（图 4.3.1 右）。程序 4.3.1 还发现，它近似等于 $\dfrac{C}{\sqrt{R - r}}$，由表中数据估计 $C\approx {{ex4_3.C:.3f}}$，与理论值 $\sqrt{R/(2l_1l_2)}\approx {{ex4_3.C_pred:.3f}}$ 吻合（理论值的推导要用第 7 章的导数和 4.6 节的等价无穷小）。离伸直的距离缩小到百分之一，灵敏度增大到十倍。

### 4.3.4 无穷远处的极限与水平渐近线

若 $x\to+\infty$ 时 $f(x)$ 无限接近 $L$，记作 $\lim_{x\to+\infty}f(x) = L$；$x\to-\infty$ 同理。若 $x\to+\infty$ 和 $x\to-\infty$ 时极限都是 $L$，就记作 $\lim_{x\to\infty}f(x) = L$，这里 $x\to\infty$ 指 $\lvert x\rvert\to+\infty$。例如

$$
\lim_{x\to\pm\infty}\frac1x = 0,\qquad \lim_{x\to+\infty}e^{-x} = 0,\qquad \lim_{x\to+\infty}\arctan x = \frac\pi2,\qquad \lim_{x\to-\infty}\arctan x = -\frac\pi2 .
$$

**定义 4.3.3（水平渐近线）** 若 $\lim_{x\to+\infty}f(x) = L$ 或 $\lim_{x\to-\infty}f(x) = L$，称直线 $y = L$ 为 $y = f(x)$ 的**水平渐近线**。

电机起动后的转速 $\omega(t) = \omega_\infty(1 - e^{-t/\tau})$（3.6 节）以 $\omega = \omega_\infty$ 为水平渐近线：转速永远达不到但无限接近稳态值。$\tanh x$ 以 $y = \pm 1$ 为水平渐近线，这是 2.6 节“饱和”的数学描述。

求有理函数在无穷远处的极限，与算例 3.4.1 相同：分子分母同除以 $x$ 的最高次幂。

**算例 4.3.1** 求 $\lim_{x\to\infty}\dfrac{3x^2 - x + 2}{2x^2 + 5}$ 和 $\lim_{x\to-\infty}\dfrac{\sqrt{x^2 + 1}}{x}$。

*解*　第一个：同除以 $x^2$，得 $\dfrac{3 - 1/x + 2/x^2}{2 + 5/x^2}\to\dfrac32$。第二个要小心符号：$x < 0$ 时 $\sqrt{x^2} = \lvert x\rvert = -x$，所以

$$
\frac{\sqrt{x^2 + 1}}{x} = \frac{\lvert x\rvert\sqrt{1 + 1/x^2}}{x} = -\sqrt{1 + \frac1{x^2}}\to -1 .
$$

（$x\to+\infty$ 时极限是 $+1$，两条水平渐近线 $y = \pm 1$。）把 $\sqrt{x^2}$ 当作 $x$ 是这类题目最常见的错误（2.1 节）。

### 4.3.5 斜渐近线

有些函数在无穷远处不趋于常数，而是越来越贴近一条斜线。

**定义 4.3.4（斜渐近线）** 若 $\lim_{x\to+\infty}[f(x) - (kx + b)] = 0$（或 $x\to-\infty$），$k\ne 0$，称直线 $y = kx + b$ 为 $y = f(x)$ 的**斜渐近线**。

由定义，$k$ 和 $b$ 可以这样求：

$$
k = \lim_{x\to+\infty}\frac{f(x)}{x},\qquad b = \lim_{x\to+\infty}[f(x) - kx] . \tag{4.3.1}
$$

（前一式：$\frac{f(x)}{x} = \frac{f(x) - kx - b}{x} + k + \frac bx\to k$。）$x\to-\infty$ 方向的斜渐近线要另算，两个方向的结果可能不同（习题 4.3.3）。水平、铅直、斜三种直线统称**渐近线**。

**算例 4.3.2** 求 $f(x) = \dfrac{x^2 + 1}{x - 1}$ 的渐近线。

*解*　$x\to 1$ 时分母趋于 0、分子趋于 2，所以 $x = 1$ 是铅直渐近线。由 (4.3.1)，$k = \lim\dfrac{x^2 + 1}{x(x - 1)} = 1$，$b = \lim\Bigl(\dfrac{x^2 + 1}{x - 1} - x\Bigr) = \lim\dfrac{x + 1}{x - 1} = 1$，斜渐近线是 $y = x + 1$。实际上用多项式除法，$f(x) = x + 1 + \dfrac{2}{x - 1}$，余项 $\dfrac{2}{x - 1}$ 在无穷远处趋于 0。程序 4.3.1：$x = 100$ 时 $f(x)$ 与 $x + 1$ 相差约 {{ex4_3.gap100:.4f}}，$x = 10^4$ 时相差约 ${{ex4_3.f1e4:sci1}}$（图 4.3.1 左）。

### 4.3.6 生活中的例子

一杯热水放在桌上，水温随时间下降，越来越接近室温，却永远（在模型中）不会低于室温：室温是水温曲线的水平渐近线。从坡顶推下一辆小车，车速越来越快，但因空气阻力，速度有一个上限，叫作终端速度，跳伞运动员在开伞前下落的速度也趋于这样一个终端速度（约每小时 200 千米）：它又是一条水平渐近线。渐近线描述的是“长期的趋势”，日常说的“越来越接近，但永远达不到”，就是它。

**工程师笔记**

- 程序中遇到铅直渐近线附近的计算要格外小心。两节连杆的逆运动学在伸直位置附近，`acos` 的参数接近 1，微小的数值误差就会造成肘关节角的显著变化；工程上的做法是给工作空间留出余量，或者在奇异位形附近改用阻尼最小二乘等方法（第 46 章）。
- 画图时，程序会把渐近线两侧的点连起来，画出一条假的竖线（例如 $\tan x$）。2.4 节的插图把 $\lvert\cos x\rvert$ 很小处的点设为 `nan` 来断开曲线，就是这个原因。
