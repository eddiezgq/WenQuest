# 《微积分》符号约定（v0.1，2026-10-02，待 Eddie 审阅）

全书统一使用本约定。写作、程序、插图、动画、实验都以它为准。新增符号先登记在这里，再在正文中使用。

## 一、总原则

1. **国际通行写法为主，注明国内写法**：正文用 Stewart、Apostol、Spivak、Courant 等国际教材通行的记号；一个记号第一次出现时，用一句话注明国内教材（同济《高等数学》、华东师大《数学分析》）的写法，便于读者对照和应试。第八节列出全部对照。
2. **一个符号只表示一种东西**。确有冲突时（如 $e$ 既表示自然对数的底又可能表示误差），在该节开头说明；误差一律写成 $E$ 或 $\varepsilon$，不写 $e$。
3. **先说含义，再用符号**：每个新符号第一次出现时，用一句话说明它表示什么、单位是什么。
4. **程序与书一致**：程序中的变量名尽量与书中符号对应，例如 `t`、`theta`、`omega`、`h`（步长）、`dfdx`。

## 二、字体与排版

| 对象 | 写法（LaTeX） | 例 |
|---|---|---|
| 数（标量）、变量 | 斜体 | $x$, $t$, $a$, $\theta$ |
| 函数名（自定义） | 斜体单字母 | $f$, $g$, $F$ |
| 标准函数 | 正体 | $\sin$, $\cos$, $\tan$, $\ln$, $\exp$, $\arcsin$, $\sinh$ |
| 微分记号中的 d | 正体 `\mathrm{d}`，正文简写为 `d` 也可，但同一节内统一 | $\dfrac{\mathrm dy}{\mathrm dx}$ 或 $\dfrac{dy}{dx}$ |
| 偏导数 | `\partial` | $\dfrac{\partial f}{\partial x}$ |
| 向量 | 粗斜体 `\boldsymbol{r}` | $\boldsymbol r(t)$, $\boldsymbol v$, $\boldsymbol F$ |
| 矩阵 | 斜体大写 | $J$, $H$ |
| 数集 | 黑板粗体 | $\mathbb N$, $\mathbb Z$, $\mathbb Q$, $\mathbb R$, $\mathbb C$ |
| 常数 e、i、π | 正体或斜体均可，全书取斜体 $e$、$i$、$\pi$ | $e^{i\theta}$ |
| 单位 | 正体，与数之间空一格 | $2\ \mathrm{rad/s}$, $0.425\ \mathrm{m}$ |

**微分记号的 d**：全书正文统一写成斜体 $d$（如 $dy/dx$、$\int f(x)\,dx$），与国内外大多数教材相同；积分号与 $dx$ 之间加细空格 `\,`。

## 三、数、集合与区间

| 记号 | 含义 | 说明 |
|---|---|---|
| $\mathbb N$ | 自然数 $\{0, 1, 2, \dots\}$ | 与国家标准 GB 3102.11 一致，含 0；需要从 1 开始时写 $\mathbb N^+$ 或 $n\ge 1$ |
| $(a, b)$、$[a, b]$、$[a, b)$ | 开区间、闭区间、半开区间 | 点的坐标也写 $(a, b)$，由上下文区分；有歧义时写“区间 $(a,b)$”“点 $(a,b)$” |
| $(a, +\infty)$、$(-\infty, b]$ | 无穷区间 | 写 $+\infty$，不写 $\infty$ 表示正无穷 |
| $U(x_0, \delta)$ | $x_0$ 的 $\delta$ 邻域 $(x_0-\delta, x_0+\delta)$ | 国内写法相同 |
| $\mathring U(x_0, \delta)$ | 去心邻域 | 同济写法相同 |
| $\lvert x\rvert$ | 绝对值 | |
| $\max$、$\min$、$\sup$、$\inf$ | 最大、最小、上确界、下确界 | |
| $\forall$、$\exists$ | 任意、存在 | 只在定义和证明中使用，正文叙述用文字 |
| $\Rightarrow$、$\Leftrightarrow$ | 推出、等价 | |
| $:=$ | 定义为 | 只在第一次定义时用 |

## 四、极限与无穷小

| 记号 | 含义 |
|---|---|
| $\lim_{x\to a} f(x) = L$ | 函数极限 |
| $\lim_{x\to a^-}$、$\lim_{x\to a^+}$ | 左极限、右极限（国内也写 $f(a^-)$、$f(a-0)$） |
| $\lim_{n\to\infty} a_n$ | 数列极限（$n\to\infty$ 默认指 $n\to+\infty$） |
| $f(x)\to L\ (x\to a)$ | 极限的另一种写法 |
| $o(g)$ | 比 $g$ 高阶的无穷小：$f/g\to 0$ |
| $O(g)$ | 与 $g$ 同阶或更高阶：$\lvert f/g\rvert$ 有界 |
| $f\sim g$ | 等价无穷小：$f/g\to 1$ |
| $\varepsilon$、$\delta$、$N$ | 极限定义中的正数和下标；$\varepsilon$ 用 `\varepsilon` |

## 五、导数与微分

| 记号 | 含义 | 何时用 |
|---|---|---|
| $f'(x)$ | 拉格朗日记号 | 函数已有名字时的默认写法 |
| $\dfrac{dy}{dx}$、$\dfrac{df}{dx}$、$\dfrac{d}{dx}f(x)$ | 莱布尼茨记号 | 讲链式法则、变量替换、相关变化率时 |
| $\left.\dfrac{dy}{dx}\right\rvert_{x=a}$ | 在 $x=a$ 处的导数值 | 国内也写 $y'\rvert_{x=a}$ |
| $f''$、$f'''$、$f^{(n)}$ | 二阶、三阶、$n$ 阶导数 | 四阶起写 $f^{(4)}$ |
| $\dfrac{d^2y}{dx^2}$、$\dfrac{d^ny}{dx^n}$ | 高阶导数的莱布尼茨写法 | |
| $\dot x$、$\ddot x$、$\dddot x$ | 对**时间** $t$ 的一、二、三阶导数（牛顿记号） | 只用于时间导数：速度、加速度、加加速度；对其他变量求导不用点 |
| $f'_-(a)$、$f'_+(a)$ | 左导数、右导数 | 国内同 |
| $Df$ | 导数算子 | 只在讲算子性质时用 |
| $dy$、$dx$ | 微分 | 第 8 章 |
| $\Delta x$、$\Delta y$ | 增量 | $\Delta y = f(x+\Delta x) - f(x)$ |
| $h$ | 差商与数值微分中的步长 | $\dfrac{f(x+h)-f(x)}{h}$ |
| $D_h^+f$、$D_h^-f$、$D_h^0f$ | 前向、后向、中心差商 | 第 7、8 章；$D_h^0 f(x) = \dfrac{f(x+h)-f(x-h)}{2h}$ |

**运动量的符号**（与《机器人学》《大学物理》一致）：位置 $x$（直线）或 $\boldsymbol r$（向量），速度 $v = \dot x$，加速度 $a = \ddot x$，加加速度 $j = \dddot x$；关节角 $\theta$、角速度 $\omega = \dot\theta$、角加速度 $\alpha = \ddot\theta$；转速用 r/min 时注明换算 $1\ \mathrm{r/min} = 2\pi/60\ \mathrm{rad/s}$。

## 六、积分

| 记号 | 含义 |
|---|---|
| $\int_a^b f(x)\,dx$ | 定积分 |
| $\int f(x)\,dx = F(x) + C$ | 不定积分，$C$ 为任意常数 |
| $\big[F(x)\big]_a^b$、$F(x)\big\rvert_a^b$ | $F(b) - F(a)$ |
| $\sum_{i=1}^n$ | 求和 |
| $\Delta x_i$、$x_i^*$ | 第 $i$ 个小区间的长度、其中的取样点 |
| $\iint_D$、$\iiint_\Omega$ | 二重、三重积分 |
| $\int_C f\,ds$、$\int_C \boldsymbol F\cdot d\boldsymbol r$ | 对弧长的曲线积分、对坐标的曲线积分（国内称第一型、第二型；正文第一次出现时注明） |
| $\oint_C$ | 沿闭曲线的积分 |
| $\iint_S f\,dS$、$\iint_S \boldsymbol F\cdot d\boldsymbol S$ | 对面积的曲面积分、通量（第一型、第二型） |

## 七、多元与向量分析

| 记号 | 含义 | 国内写法 |
|---|---|---|
| $f_x$、$\dfrac{\partial f}{\partial x}$ | 偏导数 | $f_x'$、$z_x$ |
| $f_{xy}$、$\dfrac{\partial^2 f}{\partial y\,\partial x}$ | 混合偏导数：先对 $x$ 再对 $y$ | 同济 $f_{xy}$ 也是先 $x$ 后 $y$ |
| $\nabla f$ | 梯度（列向量） | $\operatorname{grad} f$ |
| $D_{\boldsymbol u} f$ | 沿单位向量 $\boldsymbol u$ 的方向导数 | $\dfrac{\partial f}{\partial \boldsymbol l}$ |
| $\nabla\cdot\boldsymbol F$ | 散度 | $\operatorname{div}\boldsymbol F$ |
| $\nabla\times\boldsymbol F$ | 旋度 | $\operatorname{rot}\boldsymbol F$ 或 $\operatorname{curl}\boldsymbol F$ |
| $\nabla^2 f$、$\Delta f$ | 拉普拉斯算子 | 同 |
| $J$、$\dfrac{\partial(x, y)}{\partial(u, v)}$ | 雅可比矩阵、雅可比行列式 | 同 |
| $H$、$\nabla^2 f$ | 黑塞矩阵（在不与拉普拉斯算子混淆时） | 同 |
| $\boldsymbol T$、$\boldsymbol N$、$\boldsymbol B$ | 单位切向量、主法向量、副法向量 | $\boldsymbol\tau$、$\boldsymbol n$、$\boldsymbol\beta$ |
| $\kappa$、$\tau$ | 曲率、挠率 | $K$ |
| $\boldsymbol i$、$\boldsymbol j$、$\boldsymbol k$ | 坐标轴单位向量 | 同 |
| $\boldsymbol a\cdot\boldsymbol b$、$\boldsymbol a\times\boldsymbol b$ | 点积、叉积 | $\boldsymbol a\cdot\boldsymbol b$、$\boldsymbol a\times\boldsymbol b$（同济），也写 $[\boldsymbol a\ \boldsymbol b\ \boldsymbol c]$ 表示混合积 |

向量在 $\mathbb R^n$ 中一律是**列向量**，与《线性代数》一致；行内写成 $(a, b, c)^{\mathsf T}$，在不涉及矩阵运算时也可写成 $(a, b, c)$，并在该节说明。

## 八、与国内教材写法的对照

| 内容 | 本书 | 同济《高等数学》等国内写法 |
|---|---|---|
| 正切、余切 | $\tan x$、$\cot x$ | $\tan x$、$\cot x$（旧书 $\operatorname{tg}x$、$\operatorname{ctg}x$） |
| 正割、余割 | $\sec x$、$\csc x$ | 同 |
| 反三角函数 | $\arcsin x$、$\arccos x$、$\arctan x$（第一次出现时注明英文教材写作 $\sin^{-1}x$，它**不是** $1/\sin x$） | 同本书 |
| 自然对数 | $\ln x$ | 同；常用对数 $\lg x$；$\log_a x$ |
| 指数 | $e^x$，指数复杂时写 $\exp(\cdot)$ | 同 |
| 双曲函数 | $\sinh x$、$\cosh x$、$\tanh x$ | $\operatorname{sh}x$、$\operatorname{ch}x$、$\operatorname{th}x$ |
| 在一点的导数 | $f'(x_0)$、$\left.\dfrac{dy}{dx}\right\rvert_{x=x_0}$ | 同，也写 $y'\rvert_{x=x_0}$ |
| 无穷小阶 | $o(\cdot)$、$O(\cdot)$、$\sim$ | 同 |
| 第一型、第二型曲线积分 | 对弧长的、对坐标的曲线积分 | 第一型（对弧长）、第二型（对坐标）曲线积分 |
| 梯度、散度、旋度 | $\nabla f$、$\nabla\cdot\boldsymbol F$、$\nabla\times\boldsymbol F$ | $\operatorname{grad}f$、$\operatorname{div}\boldsymbol F$、$\operatorname{rot}\boldsymbol F$ |
| 方向导数 | $D_{\boldsymbol u}f$ | $\dfrac{\partial f}{\partial l}$ |
| 曲率 | $\kappa$ | $K$ |
| 去心邻域 | $\mathring U(x_0,\delta)$ | 同 |
| 自然数 | $\mathbb N$ 含 0 | 同（国家标准）；部分国外教材从 1 开始 |

## 九、数值与单位

1. **单位制**：国际单位制。角度在公式中一律用弧度；给数据时可用度，换算写明，程序内部一律用弧度。
2. **有效数字**：书中计算得到的数由程序给出，默认 5 位有效数字；题目给定的数据可以手写。
3. **步长与误差**：数值方法的步长写 $h$；误差写 $E(h)$；收敛阶写成 $E(h) = O(h^p)$。
4. **浮点数**：双精度浮点数的机器精度写 $\varepsilon_{\text{mach}} \approx 2.2\times 10^{-16}$（由程序给出）。
5. **时间序列数据**：采样周期写 $T_s$，第 $k$ 个采样时刻 $t_k = kT_s$，采样值 $\theta_k$。
