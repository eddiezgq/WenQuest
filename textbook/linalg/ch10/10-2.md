### 10.2.1 问题的提出

8.5 节说：行空间与零空间的维数之和是 $n$，列空间与左零空间的维数之和是 $m$。8.4 节还验证了一个例子：行空间的基与零空间的基两两点积为零。这是巧合吗？8.3 节的三连杆臂中，最小范数的关节速度为什么恰好不含自运动成分？本节证明：四个子空间两两配对，不仅维数互补，而且互相垂直，互为正交补。这是线性代数基本定理的第二部分，也是最小二乘的理论基础。

### 10.2.2 定理

**定理 10.2.1（线性代数基本定理，第二部分）** 设 $A$ 是 $m\times n$ 矩阵，则

$$
N(A) = C(A^{\mathsf T})^\perp,\qquad N(A^{\mathsf T}) = C(A)^\perp . \tag{10.2.1}
$$

即在 $\mathbb R^n$ 中，零空间与行空间互为正交补；在 $\mathbb R^m$ 中，左零空间与列空间互为正交补。

*证明*　$A\boldsymbol x = \boldsymbol 0$ 逐行写开，就是 $A$ 的每一行与 $\boldsymbol x$ 的点积为零：

$$
A\boldsymbol x = \begin{pmatrix}\text{第 1 行}\cdot\boldsymbol x\\ \vdots\\ \text{第 } m \text{ 行}\cdot\boldsymbol x\end{pmatrix} = \boldsymbol 0 .
$$

所以 $\boldsymbol x\in N(A)$ 当且仅当 $\boldsymbol x$ 与每一行正交，当且仅当 $\boldsymbol x$ 与各行的一切线性组合（行空间）正交。这正是 $N(A) = C(A^{\mathsf T})^\perp$。对 $A^{\mathsf T}$ 用同样的论证，得 $N(A^{\mathsf T}) = C(A)^\perp$。　∎

证明只有一行，却与第一部分（定理 8.5.1）合起来给出完整的图景。由定理 10.1.1，

$$
\mathbb R^n = C(A^{\mathsf T})\oplus N(A),\qquad \mathbb R^m = C(A)\oplus N(A^{\mathsf T}), \tag{10.2.2}
$$

两个直和的两部分都互相垂直，维数分别是 $r + (n - r)$ 与 $r + (m - r)$。图 10.2.1 是 8.5 节全景图的“正交版”：两对子空间各自垂直。

### 10.2.3 三个推论

**推论 10.2.1（相容条件）** $A\boldsymbol x = \boldsymbol b$ 有解当且仅当 $\boldsymbol b$ 与左零空间中的每个向量正交。

这是 8.4 节用消元证明过的结论，现在它只是 $C(A) = N(A^{\mathsf T})^\perp$（定理 10.1.1 的第 3 条）。对 8.1 节的 $A$，左零空间由 $\boldsymbol y = (1, 1, -1)^{\mathsf T}$ 张成：$\boldsymbol y\cdot(1, 3, 4) = {{ex10_2.yb:.0f}}$，有解；$\boldsymbol y\cdot(1, 3, 5) = {{ex10_2.yb2:.0f}}$，无解。

**推论 10.2.2（正交分解）** 每个 $\boldsymbol x\in\mathbb R^n$ 唯一地写成 $\boldsymbol x = \boldsymbol x_r + \boldsymbol x_n$，$\boldsymbol x_r\in C(A^{\mathsf T})$，$\boldsymbol x_n\in N(A)$，且 $A\boldsymbol x = A\boldsymbol x_r$，$\lVert\boldsymbol x\rVert^2 = \lVert\boldsymbol x_r\rVert^2 + \lVert\boldsymbol x_n\rVert^2$。

取 $\boldsymbol x = {{ex10_2.x}}$，程序 10.2.1 算得 $\boldsymbol x_r = {{ex10_2.xr}}$，$\boldsymbol x_n = {{ex10_2.xn}}$，两者点积为 {{ex10_2.dot:.0f}}；$A\boldsymbol x = A\boldsymbol x_r = {{ex10_2.Ax}}$；$\lVert\boldsymbol x\rVert^2 = {{ex10_2.nx:.0f}} = {{ex10_2.nr_f}} + {{ex10_2.nn_f}}$。8.5 节说“$A$ 把零空间压成零”，现在可以补上：被压掉的那一部分与保留下来的那一部分互相垂直。

**定理 10.2.2（最小范数解）** 设 $A\boldsymbol x = \boldsymbol b$ 有解。则它恰有一个解 $\boldsymbol x^+$ 在行空间中，而且 $\boldsymbol x^+$ 是所有解中长度最小的。

*证明*　任取一个解 $\boldsymbol x$，正交分解 $\boldsymbol x = \boldsymbol x_r + \boldsymbol x_n$，则 $A\boldsymbol x_r = A\boldsymbol x = \boldsymbol b$，$\boldsymbol x_r$ 是行空间中的解。若行空间中有两个解，它们的差既在行空间中（子空间）又在零空间中（$A$ 作用为零），只能是零向量。全部解是 $\boldsymbol x^+ + N(A)$（定理 8.3.1），对其中任一个 $\boldsymbol x^+ + \boldsymbol z$（$\boldsymbol z\in N(A)$），$\boldsymbol x^+\perp\boldsymbol z$，由勾股定理 $\lVert\boldsymbol x^+ + \boldsymbol z\rVert^2 = \lVert\boldsymbol x^+\rVert^2 + \lVert\boldsymbol z\rVert^2\ge\lVert\boldsymbol x^+\rVert^2$，等号仅当 $\boldsymbol z = \boldsymbol 0$。　∎

对 $\boldsymbol b = (1, 3, 4)^{\mathsf T}$，8.3 节的特解 $(1, 0, 1, 0)^{\mathsf T}$ 长度为 {{ex10_2.np_:.4f}}；把它投影到行空间，得最小范数解 $\boldsymbol x^+ = {{ex10_2.xmin_from_p}}$，长度只有 {{ex10_2.nmin:.4f}}。它与 `np.linalg.pinv(A) @ b` 算出的结果相同：伪逆 $A^+$ 给出的正是最小范数解（第 18 章）。

### 10.2.4 应用：冗余机械臂的最小范数关节速度

8.3 节的三连杆平面臂，雅可比矩阵 $J$ 是 $2\times3$ 的，零空间（自运动方向）是一维的。要求末端以 0.1 m/s 沿 $x$ 方向运动，8.3 节给出的特解 $\dot{\boldsymbol\theta}_p = {{ex10_2.qp}}$ rad/s 就是最小范数解：它与自运动方向 $\boldsymbol n$ 的点积约为 ${{ex10_2.qn}}$（舍入误差），确实在行空间里。加上半个单位的自运动（按最大分量归一的 $\boldsymbol n$ 乘以 0.5），末端速度不变，关节速度的长度却从 {{ex10_2.nqp:.4f}} 增大到 {{ex10_2.nq2:.4f}} rad/s。“末端任务用最小范数解完成，剩下的自由度在零空间里另作他用”，这就是冗余控制的基本格式 $\dot{\boldsymbol\theta} = J^+\boldsymbol\xi + (I - J^+J)\boldsymbol z$ 的含义（10.3 节、第 32 章）：两项分别在行空间和零空间中，互相垂直，互不干扰。

### 10.2.5 生活中的例子

一台只能显示黑白的老电视接收彩色信号：信号中“亮度”的部分被显示出来，“色彩”的部分被丢掉（零空间）。两部分在信号空间中是互相独立的方向。显示出来的画面只取决于亮度部分；而在所有能产生同一画面的信号中，“没有色彩”的那一个最“省”，这就是最小范数解。

**工程师笔记**

- 欠定方程组（未知数多于方程）求解时，`np.linalg.lstsq` 和 `pinv` 默认返回最小范数解。若需要别的解（例如让某个关节尽量不动），要显式地加上零空间分量或改用加权的范数。
- 判断 $\boldsymbol b$ 是否在列空间中，最可靠的数值办法是求它在左零空间上的分量（即最小二乘的残差，10.4 节），看它相对于 $\lVert\boldsymbol b\rVert$ 是否足够小。
- 最小范数解对单位敏感：关节中有转动也有移动时，“长度”把 rad/s 和 m/s 混在一起，结果依赖于单位的选择。实际中常用加权范数（第 32 章）。
