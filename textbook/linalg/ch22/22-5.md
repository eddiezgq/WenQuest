### 22.5.1 问题的提出

AGV 上装的嵌入式计算板有一块小 GPU，单精度（float32）算得很快，双精度（float64）却慢得多：许多 GPU 的双精度速度只有单精度的 1/2 到 1/64；深度学习用的张量核心主要为低精度设计，用半精度（float16、bfloat16）甚至更低的精度相乘、单精度累加，速度又快一个数量级（4.7 节）。另一方面，第 20 章说过，单精度只有约 7 位有效数字，半精度只有约 3 位。机器人的定位、标定、模型预测控制要解线性方程组，能不能用低精度的速度，得到双精度的精度？

答案是：在一定条件下可以。关键在于把计算分成两部分：*运算量大的部分（分解，$O(n^3)$）用低精度做，运算量小但决定精度的部分（残差，$O(n^2)$）用高精度做*。本节讨论这种混合精度方法，以及低精度计算中最容易出错的累加。

### 22.5.2 累加的精度

矩阵乘法和分解的核心是内积 $\sum_ix_iy_i$。用低精度逐个累加时，部分和越来越大，加上去的每一项相对越来越小，最后被“吃掉”（20.4 节的单精度时钟就是这样停走的）。

**算例 22.5.1** 程序 22.5.1 取 10000 对 $[0, 1)$ 内的随机数，计算 $\sum x_iy_i$（真值约 {{ex22_5.dot_exact:.0f}}）。把输入存成半精度本身带来 ${{ex22_5.dot_in}}$ 的相对误差，这是不可避免的。在此之上：

- 半精度相乘、半精度累加：得 {{ex22_5.dot16:.0f}}，相对误差 {{ex22_5.dot_rel16:.0%}}。部分和超过 1024 后，相邻两个半精度数相差 1：小于 0.5 的乘积（占大多数）加上去被舍掉，大于 0.5 的才让和加 1，和越涨越慢，最后只到 {{ex22_5.dot16:.0f}}。
- 半精度输入、单精度累加：得 {{ex22_5.dot16_32:.2f}}，相对误差 ${{ex22_5.dot_rel32}}$（与半精度输入的精确内积相比）。

这就是张量核心“半精度乘、单精度加”的设计理由：乘积本身只有 3 位有效数字没关系，累加不能用 3 位。

### 22.5.3 混合精度迭代改进

设要解 $A\boldsymbol x = \boldsymbol b$。迭代改进的算法是：

1. 用低精度（例如单精度）做 LU 分解 $A\approx\hat L\hat U$，解出初值 $\boldsymbol x_0$；
2. 对 $k = 0, 1, 2, \dots$：用高精度（双精度）计算残差 $\boldsymbol r_k = \boldsymbol b - A\boldsymbol x_k$；用低精度的分解解修正方程 $\hat L\hat U\boldsymbol d_k = \boldsymbol r_k$；更新 $\boldsymbol x_{k+1} = \boldsymbol x_k + \boldsymbol d_k$（双精度）。

为什么会收敛？修正方程的解 $\boldsymbol d_k$ 有低精度的相对误差，约为 $\kappa(A)u_{\mathrm f}$（$u_{\mathrm f}$ 为分解所用精度的单位舍入）。所以每一步把误差缩小为原来的约 $c\,\kappa(A)u_{\mathrm f}$ 倍：

**定理 22.5.1**（迭代改进的收敛，大意） 记 $u_{\mathrm f}$ 为分解所用精度的单位舍入，$u_{\mathrm r}$ 为计算残差所用精度的单位舍入，$u$ 为存放解所用的工作精度（本节中 $u_{\mathrm r} = u$ 为双精度）。设分解的后向误差满足 $(A + \delta A) = \hat L\hat U$，$\lVert A^{-1}\delta A\rVert\le\theta < 1/2$（大致相当于 $c(n)\kappa(A)u_{\mathrm f} < 1/2$）。则误差 $\boldsymbol e_k = \boldsymbol x_k - \boldsymbol x$ 满足

$$
\lVert\boldsymbol e_{k+1}\rVert\lesssim\frac{\theta}{1 - \theta}\lVert\boldsymbol e_k\rVert + (\text{残差计算的舍入误差}), \tag{22.5.1}
$$

误差线性地减小，直到被残差计算的精度所限：残差用工作精度计算（$u_{\mathrm r} = u$）时，最终误差约为 $\kappa(A)u$，与直接用工作精度求解相同；残差用更高的精度计算（$u_{\mathrm r}\ll u$）时，最终误差可达 $u$。

*推导*　$\boldsymbol r_k = \boldsymbol b - A\boldsymbol x_k = -A\boldsymbol e_k$（不计舍入），$\boldsymbol d_k = (A + \delta A)^{-1}\boldsymbol r_k = -(I + A^{-1}\delta A)^{-1}\boldsymbol e_k$，所以 $\boldsymbol e_{k+1} = \boldsymbol e_k + \boldsymbol d_k = [I - (I + A^{-1}\delta A)^{-1}]\boldsymbol e_k = (I + A^{-1}\delta A)^{-1}A^{-1}\delta A\,\boldsymbol e_k$。由诺伊曼级数的界 (21.1.4)，$\lVert(I + A^{-1}\delta A)^{-1}\rVert\le1/(1 - \theta)$，即得第一项。　∎

### 22.5.4 生活中的例子

木工做家具，先用电锯快速锯出大致的形状（快但粗糙），再用刨子、砂纸一点点修到尺寸（慢但精细，可工作量小）。混合精度迭代改进就是这个办法：低精度分解是电锯，高精度残差是卡尺，修正方程是刨子。木料本身若是歪的（条件数太大），电锯锯出的形状离目标太远，刨子也修不回来。

**工程师笔记**

- 嵌入式和 GPU 上解方程组：先估计条件数。$\kappa < 10^5$ 左右时，单精度分解加一两步双精度改进是“又快又准”的选择；条件数未知时，用改进后的残差判断是否收敛，不收敛就退回双精度。
- 残差 $\boldsymbol b - A\boldsymbol x_k$ 必须用比分解更高的精度计算，并且用原始的 $A$（不是低精度的副本），否则改进不会带来任何精度。
- 训练神经网络用的混合精度（半精度存储和乘法、单精度累加和主权重、“损失缩放”防止梯度下溢），与这里的思想相同：把精度用在最需要的地方（第 38 章）。
