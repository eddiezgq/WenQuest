### 4.3.1 问题的提出

数的乘法有几条大家熟悉的规律：$ab = ba$；$(ab)c = a(bc)$；$a(b + c) = ab + ac$；$ab = 0$ 则 $a = 0$ 或 $b = 0$；$a\ne0$ 时由 $ab = ac$ 可以约去 $a$。矩阵乘法保留了其中哪些？

这不是纯粹的形式问题。一幅图像先转 30° 再沿水平方向剪切（图像处理中校正倾斜常用这两种变换），与先剪切、再旋转，结果一样吗？一条由三个矩阵组成的计算链，先乘哪两个，结果一样吗？耗时一样吗？本节逐条回答。

### 4.3.2 单位矩阵与零矩阵

先介绍两个特殊矩阵。主对角线（左上到右下）上的元素都是 1、其余元素都是 0 的 $n$ 阶方阵称为 $n$ 阶**单位矩阵**，记为 $I_n$ 或 $I$；它的各列就是标准基向量 $\boldsymbol e_1, \dots, \boldsymbol e_n$。所有元素都是 0 的矩阵称为**零矩阵**，记为 $O$。由定理 4.1.2，$I$ 对应恒等变换（什么也不做），所以对任意 $m\times n$ 矩阵 $A$，

$$
I_mA = A = AI_n,\qquad OA = O,\quad AO = O , \tag{4.3.1}
$$

这里各个 $I$、$O$ 的大小要使乘法有定义。$I$ 在矩阵乘法中扮演数 1 的角色，$O$ 扮演数 0 的角色。

### 4.3.3 成立的运算律

**定理 4.3.1（运算律）** 设下列各式中的矩阵大小使运算有定义，$c$ 是实数，则

$$
\begin{aligned}
&(AB)C = A(BC) &&\text{（结合律）},\\
&A(B + C) = AB + AC,\quad (A + B)C = AC + BC &&\text{（分配律）},\\
&c(AB) = (cA)B = A(cB) .
\end{aligned} \tag{4.3.2}
$$

*证明*　用 4.2.2 节“乘法就是复合”的观点。对任意向量 $\boldsymbol x$，反复用命题 4.2.1 的 $(AB)\boldsymbol x = A(B\boldsymbol x)$：

$$
\bigl((AB)C\bigr)\boldsymbol x = (AB)(C\boldsymbol x) = A\bigl(B(C\boldsymbol x)\bigr),\qquad \bigl(A(BC)\bigr)\boldsymbol x = A\bigl((BC)\boldsymbol x\bigr) = A\bigl(B(C\boldsymbol x)\bigr).
$$

两个矩阵对一切 $\boldsymbol x$ 给出相同的结果，由定理 4.1.2 的唯一性部分，它们相等。这就是结合律：两种算法都是“先做 $C$，再做 $B$，最后做 $A$”。分配律：$A(B + C)\boldsymbol x = A(B\boldsymbol x + C\boldsymbol x) = AB\boldsymbol x + AC\boldsymbol x$，第二步用了定理 4.1.1；另一条分配律和数乘的规律同样由逐元素的计算得到。　∎

结合律的证明几乎不用计算，这正是从“复合”定义乘法的好处。若从 (4.2.3) 的求和式出发，证明要交换两重求和的次序，读者可以作为练习（习题 4.3.2）。程序 4.3.1 用 $2\times3$、$3\times4$、$4\times5$ 的随机矩阵验证了结合律（{{ex4_3.assoc}}）。

由于结合律，连乘 $ABC$ 不必加括号，**矩阵的幂** $A^k = AA\cdots A$（$k$ 个 $A$，$A$ 为方阵）也有确定的意义，并约定 $A^0 = I$。幂满足 $A^jA^k = A^{j+k}$、$(A^j)^k = A^{jk}$。转 30° 的矩阵 $R$ 自乘 12 次，转了 360°：$R^{12} = {{ex4_3.R12}}$。剪切矩阵 $S = {{ex4_3.S}}$ 的 5 次幂是 $S^5 = {{ex4_3.S5}}$，剪切量逐次累加。

### 4.3.4 括号不改变结果，但改变运算量

结合律保证 $(AB)\boldsymbol x = A(B\boldsymbol x)$，但两种算法的运算量差别巨大。设 $A$、$B$ 都是 $1000\times1000$ 矩阵。按 (4.2.5)，先算 $AB$ 要 $10^9$ 次乘法，再乘 $\boldsymbol x$ 又要 $10^6$ 次；先算 $B\boldsymbol x$ 只要 $10^6$ 次，再乘 $A$ 又是 $10^6$ 次，共 $2\times10^6$ 次。后者快了约 500 倍。

一般地，计算一串矩阵的乘积时，加括号的方式决定了运算量。$A_1A_2\cdots A_k$ 的最佳加括号方式可以用动态规划求出，这是算法课的经典例子“矩阵链乘法”。实际工作中只需记住一条：*乘向量时从右往左算*。神经网络的反向传播之所以快，原因之一正是它始终让向量先参与乘法，从不先把一长串雅可比矩阵乘在一起。

### 4.3.5 乘法一般不可交换

**交换律**对矩阵乘法不成立。首先，$AB$ 有定义时 $BA$ 未必有定义；即使两者都有定义，大小也可能不同（$2\times3$ 乘 $3\times2$ 是 $2\times2$，反过来是 $3\times3$）。即使 $A$、$B$ 是同阶方阵，一般也有 $AB\ne BA$。

**算例 4.3.1** 设 $R$ 是转 30° 的矩阵，$S$ 是上面的剪切矩阵。

$$
RS = {{ex4_3.RS}},\qquad SR = {{ex4_3.SR}} .
$$

两者不同。$RS\boldsymbol x = R(S\boldsymbol x)$ 是先剪切、再旋转；$SR\boldsymbol x$ 是先旋转、再剪切。图 4.3.1 和动画 4.3.1 把两种次序作用在同一面小旗上，结果明显不同：先剪切再旋转，被拉斜的小旗整体转了 30°，形状与剪切后一样；先旋转再剪切，转过来的小旗又沿水平方向被拉斜，形状变了。两个乘积矩阵的列（图中红、绿箭头）也不同。

日常生活中“次序要紧”的例子很多：先穿袜子再穿鞋，与先穿鞋再穿袜子，结果不同。三维空间中绕两根不同的轴旋转，次序不同结果也不同，第 31 章的旋转表示要专门处理这一点。可交换只是例外：任何方阵都与 $cI$ 可交换；两个对角矩阵可以交换（{{ex4_3.diagcomm}}）；同一个矩阵的幂彼此可以交换，$A^jA^k = A^kA^j$。平面上绕原点的两个旋转也可以交换，因为它们只是把转角相加。

不可交换带来一个代数上的后果：$(A + B)^2 = A^2 + AB + BA + B^2$，一般不等于 $A^2 + 2AB + B^2$。中学里的展开公式，凡是用到交换律的，对矩阵都要重新检查。

### 4.3.6 零因子与消去律

数的乘法中，$ab = 0$ 意味着 $a$、$b$ 中至少有一个是 0。矩阵不然。

**算例 4.3.2** 设 $P = {{ex4_3.P}}$，$Q = {{ex4_3.Q}}$。两者都不是零矩阵，但

$$
PQ = {{ex4_3.PQ}},\qquad QP = {{ex4_3.QP}} .
$$

原因可以用列图看清楚：$PQ$ 的每一列是 $P$ 的两列的组合，而 $P$ 的两列共线（第 2 列是第 1 列的 2 倍），$Q$ 的每一列恰好给出“2 倍第 1 列减去 1 倍第 2 列”这样的组合，于是抵消为零。几何上，$P$ 把整个平面压到一条直线上，$Q$ 的输出恰好落在被 $P$ 压成零的方向上。

同样的原因使消去律失效。取 $B = I$、$C = I + Q = {{ex4_3.Cm}}$，则 $PC = P + PQ = P = PB$，但 $B\ne C$（程序验证：{{ex4_3.cancel}}）。所以由 $AB = AC$ *不能*约去 $A$ 而得到 $B = C$。第 5 章将看到，若 $A$ 可逆，消去就是合法的：两边左乘 $A^{-1}$ 即可。对方阵而言，可逆性正是“能不能约去”的判据。

### 4.3.7 生活中的例子

洗衣服的“洗”和“烘”是两个操作，次序不能交换：先烘再洗，衣服是湿的。但“给左手戴手套”和“给右手戴手套”可以交换。矩阵乘法与此相同：一般不可交换，可交换的是彼此“不干扰”的操作。两个对角矩阵分别缩放各个坐标，互不干扰，所以可以交换。

**工程师笔记**

- 代码中矩阵连乘的次序就是变换的次序，从右往左读：`R @ S @ x` 是先 $S$ 后 $R$。写注释时用“先……再……”说清楚，比只写公式可靠。
- 计算 $A_1A_2\cdots A_k\boldsymbol x$ 时，从右往左逐个乘向量，不要先把矩阵乘起来，除非这个矩阵链要重复使用很多次（4.2 节的 AGV 例子）。
- 两个矩阵是否可交换，用 `np.allclose(A @ B, B @ A)` 检查，不要凭直觉。两个“差不多可交换”的变换，交换次序后的微小差别在长时间迭代中会积累起来。
