title: 本章小结
---

本章的主线是一句话：**矩阵乘法就是线性变换的复合**。由此出发，乘法的定义、四种算法、运算律以及“不可交换”，都顺理成章。

矩阵乘向量 $A\boldsymbol x$ 是用 $\boldsymbol x$ 的分量对 $A$ 的各列做线性组合，也可以逐行与 $\boldsymbol x$ 做点积。它是线性的；反过来，每个从 $\mathbb R^n$ 到 $\mathbb R^m$ 的线性变换都是一个 $m\times n$ 矩阵，矩阵的第 $j$ 列就是 $\boldsymbol e_j$ 的像。旋转、反射、投影、相机的成像，都可以这样写出矩阵。

两个变换先后作用，复合的矩阵就是乘积：$AB$ 的第 $j$ 列是 $A\boldsymbol b_j$，使 $(AB)\boldsymbol x = A(B\boldsymbol x)$。乘积有四种算法：行乘列得到一个元素，列的组合得到一列，行的组合得到一行，列乘行之和得到整个矩阵。$(m\times n)(n\times p)$ 的乘积需要 $mnp$ 次乘法。

乘法满足结合律和分配律，单位矩阵 $I$ 相当于 1，零矩阵 $O$ 相当于 0。但一般 $AB\ne BA$；$AB = O$ 不意味着 $A = O$ 或 $B = O$；$AB = AC$ 也不能约去 $A$。括号不改变乘积，却能改变运算量：乘向量时从右往左算。

分块矩阵可以把子块当作数来乘，只是不能交换子块的次序。齐次坐标把旋转和平移装进一个分块矩阵，机器人的坐标变换链 $T_{WB} = T_{WA}T_{AB}$ 就是分块矩阵的连乘。

转置把行变成列，$(AB)^{\mathsf T} = B^{\mathsf T}A^{\mathsf T}$，点积写成 $\boldsymbol x^{\mathsf T}\boldsymbol y$，并有 $(A\boldsymbol x)\cdot\boldsymbol y = \boldsymbol x\cdot A^{\mathsf T}\boldsymbol y$；在机器人中，速度用 $J$ 传递，力用 $J^{\mathsf T}$ 传递。$A^{\mathsf T}A$ 总是对称的，叉积矩阵是反对称的，任何方阵都可唯一地分解为对称部分与反对称部分之和。

对角矩阵逐个分量缩放，三角矩阵之积仍是三角矩阵，置换矩阵重排行或列且 $P^{\mathsf T}P = I$，稀疏矩阵只存非零元。最后，矩阵乘法的速度主要取决于内存的使用：调整循环次序、分块、调用 BLAS、使用 GPU；施特拉森算法用 7 次块乘法代替 8 次，使乘法次数降到约 $n^{2.81}$，但实际中受限于数值稳定性和额外开销。

### 历史注记

| 年份 | 人物或文献 | 贡献 |

| 1812 | 比奈、柯西 | 行列式乘积公式，隐含了矩阵乘法的规则 |
| 1844 | 格拉斯曼 | 《线性扩张论》，向量空间与线性变换的思想 |
| 1850 | 西尔维斯特 | 首次使用“矩阵”（matrix）一词，意为“产生行列式的母体” |

| 1878–1879 | 弗罗贝尼乌斯 | 系统地发展矩阵理论，引入秩、正交矩阵等概念 |

| 1979 | 劳森等 | BLAS 一级标准；1988、1990 年扩充为二级、三级 |
| 1990 | 科珀史密斯、威诺格拉德 | 矩阵乘法指数降到约 2.38 |
| 2022 | AlphaTensor | 用强化学习搜索小矩阵的乘法公式 |

凯莱的定义正是从复合出发的：他把线性替换 $x' = ax + by$、$y' = cx + dy$ 简记为一个数表，两次替换接连进行，得到的新数表就是两个数表的乘积，乘法的规则由此而来。在凯莱之后很长一段时间里，矩阵主要被看作行列式的附属物；直到 20 世纪，量子力学（海森伯 1925 年的矩阵力学）和数值计算的发展，才使矩阵成为数学和工程的主角。
