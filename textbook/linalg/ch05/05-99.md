title: 本章小结
---

本章的主线是一句话：**消元就是分解，$A = LU$**。第 3 章一步步做的消元，记录下来就是 $A = LU$；有了它，解方程组、判断可逆、求逆、求行列式都只是后续的简单步骤。

逆矩阵是“撤销”一个变换的矩阵：$AA^{-1} = A^{-1}A = I$。方阵可逆，当且仅当它有 $n$ 个主元，当且仅当 $A\boldsymbol x = \boldsymbol 0$ 只有零解，当且仅当 $A\boldsymbol x = \boldsymbol b$ 对每个右端都有唯一解。对方阵，$AB = I$ 就足以推出 $BA = I$。奇异矩阵把某个方向压成了零，信息丢失，所以无法撤销。乘积的逆要反转次序，$(AB)^{-1} = B^{-1}A^{-1}$。

每一次初等行变换都是左乘一个初等矩阵，初等矩阵都可逆。高斯–若尔当法对 $(A\mid I)$ 做行变换，得到 $(I\mid A^{-1})$；可逆矩阵就是初等矩阵的乘积。

消元的乘数排成单位下三角矩阵 $L$，消元的结果是上三角矩阵 $U$，$A = LU$；乘数在 $L$ 中各就各位，互不干扰。解方程组分为前代 $L\boldsymbol c = \boldsymbol b$ 和回代 $U\boldsymbol x = \boldsymbol c$。分解约需 $\tfrac13n^3$ 次乘法，每个右端只需约 $n^2$ 次，所以“分解一次、多次求解”。需要交换行时写成 $PA = LU$；部分选主元使每个乘数不超过 1，避免小主元把舍入误差放大成灾难。

对称矩阵的分解只需算一半：$A = LDL^{\mathsf T}$，$D$ 由主元组成；主元全为正时得到乔列斯基分解 $A = CC^{\mathsf T}$。三对角和带状矩阵的分解保持带状，追赶法只需约 $8n$ 次运算，关节轨迹的三次样条、杆的热传导都由它求解。最后，解方程组时不要先求逆：求逆慢约 3 倍，对接近奇异的矩阵不准，而且稀疏矩阵的逆通常是稠密的。$A^{-1}\boldsymbol b$ 是记号，求解才是算法。

把消元看成矩阵分解，是 20 世纪三四十年代数值分析诞生时的关键一步。图灵在 1948 年的论文中写道，高斯消元可以看成把矩阵分解为一个下三角矩阵与一个上三角矩阵的乘积。这个观点把一个“手算的步骤”变成了一个可以分析、可以复用的数学对象，此后的 $QR$、奇异值分解等算法都沿着这条路发展。
