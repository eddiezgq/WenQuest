### 5.1.1 问题的提出

4.2 节的 AGV 控制器由车体速度 $(v, \omega)$ 算出两个轮子的角速度：$\boldsymbol w = W\boldsymbol x$，$W = {{ex5_1.W}}$（即 4.2 节的矩阵 $A$，这里记作 $W$，以免与本章的一般矩阵 $A$ 混淆）。里程计要做相反的事：编码器测出两个轮子的角速度，求车体走了多快、转了多快。4.4 节已经写出了这个反方向的矩阵 $K = {{ex5_1.K}}$。两者相乘，$KW = {{ex5_1.KW}}$：先由车体速度算轮速、再由轮速算回车体速度，回到了出发点。$K$ 就是 $W$ 的逆。

同样，相机把三维点变成像素（4.1.6 节），视觉定位要从像素反推光线的方向；电路的节点矩阵把电压变成注入电流，求解电路要由电流反推电压。什么样的矩阵有“逆”？逆怎样求？本节回答第一个问题。

### 5.1.2 定义

**定义 5.1.1（逆矩阵）** 设 $A$ 是 $n$ 阶方阵。若存在 $n$ 阶方阵 $B$ 使

$$
AB = I\quad\text{且}\quad BA = I , \tag{5.1.1}
$$

则称 $A$ **可逆**，$B$ 称为 $A$ 的**逆矩阵**，记为 $A^{-1}$。不可逆的方阵称为**奇异矩阵**，可逆矩阵也称为**非奇异矩阵**。

只有方阵才谈得上逆矩阵。按第 4 章的观点，$A^{-1}$ 是“撤销 $A$”的变换：先做 $A$ 再做 $A^{-1}$，或者反过来，都等于什么也没做。

**定理 5.1.1** 可逆矩阵的逆矩阵是唯一的。

*证明*　设 $B$、$C$ 都满足 (5.1.1)。由结合律，$B = BI = B(AC) = (BA)C = IC = C$。　∎

若 $A$ 可逆，方程组 $A\boldsymbol x = \boldsymbol b$ 两边左乘 $A^{-1}$，得 $\boldsymbol x = A^{-1}\boldsymbol b$；反过来，这个 $\boldsymbol x$ 确实满足 $A\boldsymbol x = AA^{-1}\boldsymbol b = \boldsymbol b$。所以**可逆矩阵对每个右端都有唯一解** $\boldsymbol x = A^{-1}\boldsymbol b$。5.7 节将说明，这个公式适合推导，不适合计算。

### 5.1.3 二阶矩阵的逆

对 2 阶方阵，逆矩阵有现成的公式：

$$
\begin{pmatrix} a & b\\ c & d\end{pmatrix}^{-1} = \frac{1}{ad - bc}\begin{pmatrix} d & -b\\ -c & a\end{pmatrix},\qquad ad - bc\ne 0 . \tag{5.1.2}
$$

主对角线上的两个元素对调，副对角线上的两个元素变号，再除以 $ad - bc$。直接相乘即可验证。$ad - bc = 0$ 时矩阵不可逆（习题 5.1.3）。数 $ad - bc$ 是第 6 章行列式的第一个例子。

**算例 5.1.1** $A = {{ex5_1.A}}$，$ad - bc = 6 - 5 = 1$，$A^{-1} = {{ex5_1.Ai}}$。程序 5.1.1 验证了 $AA^{-1} = A^{-1}A = I$（{{ex5_1.I1}}）。方程组 $2x_1 + x_2 = 1$，$5x_1 + 3x_2 = 2$ 的解是 $A^{-1}(1, 2)^{\mathsf T} = {{ex5_1.x}}$。

用 (5.1.2) 求 AGV 矩阵 $K$ 的逆：$ad - bc = \frac r2\cdot\frac rb + \frac r2\cdot\frac rb = \frac{r^2}{b}$，得 $K^{-1} = {{ex5_1.Kinv}}$，正是 $W$。

### 5.1.4 可逆的条件

什么样的方阵可逆？第 3 章已经做好了准备。

**定理 5.1.2（可逆的条件）** 对 $n$ 阶方阵 $A$，下列条件等价：

1. $A$ 可逆；
2. 对每个 $\boldsymbol b\in\mathbb R^n$，$A\boldsymbol x = \boldsymbol b$ 有唯一解；
3. $A\boldsymbol x = \boldsymbol 0$ 只有零解；
4. 消元后 $A$ 有 $n$ 个主元。

*证明*　由推论 3.5.3，2 与 4 等价；由 3.6 节，3 与 4 等价（齐次方程组只有零解当且仅当没有自由变量）。只需证明 1 与 2、3、4 的关系。

1 ⇒ 3：若 $A\boldsymbol x = \boldsymbol 0$，则 $\boldsymbol x = A^{-1}A\boldsymbol x = A^{-1}\boldsymbol 0 = \boldsymbol 0$。

2、3 ⇒ 1：由条件 2，对每个 $j$ 可解出 $A\boldsymbol x_j = \boldsymbol e_j$。令 $X = (\boldsymbol x_1\ \cdots\ \boldsymbol x_n)$，按定义 4.2.1，$AX = (\boldsymbol e_1\ \cdots\ \boldsymbol e_n) = I$。还要证 $XA = I$。由于 $A(XA - I) = (AX)A - A = A - A = O$，矩阵 $XA - I$ 的每一列都是 $A\boldsymbol x = \boldsymbol 0$ 的解，由条件 3 都是零向量，所以 $XA = I$。　∎

证明的后半给出了求逆的方法：$A^{-1}$ 的第 $j$ 列是方程组 $A\boldsymbol x = \boldsymbol e_j$ 的解。5.2 节把这 $n$ 个方程组放在一起消元。证明还顺带说明了一件事：

**推论 5.1.1** 设 $A$、$B$ 是 $n$ 阶方阵。若 $AB = I$，则 $BA = I$，即 $B = A^{-1}$。

*证明*　若 $B\boldsymbol x = \boldsymbol 0$，则 $\boldsymbol x = (AB)\boldsymbol x = A(B\boldsymbol x) = \boldsymbol 0$，所以 $B$ 满足定理 5.1.2 的条件 3，$B$ 可逆。于是 $A = A(BB^{-1}) = (AB)B^{-1} = B^{-1}$，从而 $BA = BB^{-1} = I$。　∎

对方阵，验证一边就够了。这个结论对非方阵不成立：$(1\ \ 0)\begin{pmatrix}1\\0\end{pmatrix} = (1)$ 是 1 阶单位矩阵，反过来的乘积 $\begin{pmatrix}1\\0\end{pmatrix}(1\ \ 0) = \begin{pmatrix}1&0\\0&0\end{pmatrix}$ 却不是 $I$。

### 5.1.5 奇异矩阵：信息丢失了

4.3 节的 $P = {{ex5_1.P}}$ 不可逆：它的第 2 列是第 1 列的 2 倍，$P(2, -1)^{\mathsf T} = {{ex5_1.Pnull}}$，违反了定理 5.1.2 的条件 3。几何上，$P$ 把整个平面压到一条直线上（图 5.1.1 右和动画 5.1.1 换用了奇异矩阵 $S = \begin{pmatrix}1 & 0.5\\ 0.6 & 0.3\end{pmatrix}$，两列同样共线，以便与其他各幅画在同一尺度上）：$(2, -1)^{\mathsf T}$ 方向上的差别被压成了零，压扁之后无从知道原来在哪里，所以没有什么变换能把它“撤销”。动画 5.1.1 对比了这两种情形。

“可逆”与“不丢信息”是一回事。机器人中最常见的奇异矩阵出现在奇异位形：两连杆臂的肘关节伸直时，雅可比矩阵奇异，末端沿手臂方向的速度无论关节怎样转都产生不出来（第 6、18 章）。

### 5.1.6 逆矩阵的运算规则

**定理 5.1.3** 设 $A$、$B$ 是同阶可逆矩阵，$c\ne0$，则 $A^{-1}$、$AB$、$A^{\mathsf T}$、$cA$ 都可逆，且

$$
(A^{-1})^{-1} = A,\qquad (AB)^{-1} = B^{-1}A^{-1},\qquad (A^{\mathsf T})^{-1} = (A^{-1})^{\mathsf T},\qquad (cA)^{-1} = \tfrac1c A^{-1} . \tag{5.1.3}
$$

*证明*　由推论 5.1.1，只需验证一边。$(AB)(B^{-1}A^{-1}) = A(BB^{-1})A^{-1} = AA^{-1} = I$。由定理 4.5.1，$A^{\mathsf T}(A^{-1})^{\mathsf T} = (A^{-1}A)^{\mathsf T} = I^{\mathsf T} = I$。其余两条同样直接验证。　∎

乘积的逆与乘积的转置一样，要**反转次序**：先做 $B$ 再做 $A$，撤销时要先撤销 $A$、再撤销 $B$。取 $B = {{ex5_1.B}}$，$(AB)^{-1} = {{ex5_1.ABi}} = B^{-1}A^{-1}$，而 $A^{-1}B^{-1} = {{ex5_1.AiBi}}$，两者不同。

*相机的逆*。4.1.6 节的内参矩阵（这里记作 $K_c$，以免与上面 AGV 的 $K$ 混淆）可逆，$K_c^{-1} = \begin{pmatrix} 1/f & 0 & -c_u/f\\ 0 & 1/f & -c_v/f\\ 0 & 0 & 1\end{pmatrix}$。像素 $(370, 215)$ 对应的光线方向是 $K_c^{-1}(370, 215, 1)^{\mathsf T} = {{ex5_1.ray}}$。单凭一幅图像只能知道点在这条光线上；若由深度相机测得深度 $Z = 1.6$ m，乘以 $Z$ 就回到了三维点 ${{ex5_1.P3}}$ m。投影本身（三维到二维）丢掉了深度，是不可逆的；可逆的只是 $K_c$ 这一步。

### 5.1.7 生活中的例子

彩色电视的信号不直接传送红、绿、蓝三个分量 $(R, G, B)$，而是传送亮度 $Y$ 和两个色差信号，三者都是 $R$、$G$、$B$ 的线性组合，写成一个 3 阶矩阵。黑白电视只用 $Y$，彩色电视再用这个矩阵的逆把三个信号还原成 $R$、$G$、$B$ 去驱动屏幕。今天的视频压缩仍然沿用这种做法。矩阵必须可逆，颜色才能原样还原。

**工程师笔记**

- 判断矩阵是否可逆，不要看“行列式是不是零”，那在浮点运算中靠不住（第 6、20 章）。要看条件数，`np.linalg.cond(A)`；条件数接近 $10^{16}$ 时，在双精度下应视为奇异。
- 机器人的雅可比矩阵在奇异位形附近“几乎奇异”，直接求逆会得到巨大的关节速度。实际控制器用阻尼最小二乘（第 18、32 章）代替求逆。
- 相机内参矩阵的逆可以直接按上面的公式写出，不必调用求逆程序；这也是“结构已知就别用通用求逆”的一个例子。
