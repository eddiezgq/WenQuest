### 3.6.1 问题的提出

3.5.4 节的三连杆臂有一个有趣的问题：能不能让三个关节都转动，而末端一动不动？这就是要求 $J\dot{\boldsymbol\theta} = \boldsymbol 0$ 的非零解。右端为零的方程组看似特殊，其实它掌握着一般方程组解的结构：3.4 节通解 (3.4.3) 中“自由变量乘以向量”的那几项，正是右端换成零之后方程组的解。本节研究这类方程组。

**定义 3.6.1（齐次方程组）** 右端全为零的线性方程组 $A\boldsymbol x = \boldsymbol 0$ 称为**齐次方程组**；$\boldsymbol b\ne\boldsymbol 0$ 时，$A\boldsymbol x = \boldsymbol b$ 称为**非齐次方程组**，$A\boldsymbol x = \boldsymbol 0$ 称为它对应的齐次方程组（导出组）。

### 3.6.2 齐次方程组总有解

$\boldsymbol x = \boldsymbol 0$ 显然满足 $A\boldsymbol x = \boldsymbol 0$，称为**平凡解**（零解）；其他的解称为**非平凡解**（非零解）。所以齐次方程组总是相容的，三种情形中只剩两种：只有零解，或者有无穷多解。用增广矩阵消元时，最后一列始终是零，可以不写，只对系数矩阵做行变换。

1.5 节的命题 1.5.1 已经证明，两个变量的齐次方程的解对加法和数乘封闭。同样的论证对任意的齐次方程组成立：

**定理 3.6.1** 若 $\boldsymbol u$、$\boldsymbol w$ 都是 $A\boldsymbol x = \boldsymbol 0$ 的解，$c$、$d$ 是实数，则 $c\boldsymbol u + d\boldsymbol w$ 也是 $A\boldsymbol x = \boldsymbol 0$ 的解。

*证明*　$A\boldsymbol x$ 的第 $i$ 个分量是 $A$ 的第 $i$ 行 $\boldsymbol r_i$ 与 $\boldsymbol x$ 的点积。由点积的线性（定理 2.3.1），$\boldsymbol r_i\cdot(c\boldsymbol u + d\boldsymbol w) = c\,\boldsymbol r_i\cdot\boldsymbol u + d\,\boldsymbol r_i\cdot\boldsymbol w = 0$，对每个 $i$ 成立。　∎

于是齐次方程组的解集是一个“对线性组合封闭”的集合，第 7 章称之为子空间，第 8 章称之为矩阵的**零空间**，记作 $N(A)$。3.4.4 节中每个自由变量取 1、其余取 0 得到的那几个解，国内教材称为**基础解系**，第 7、8 章将说明它们正是零空间的一组基。

**定理 3.6.2** 若齐次方程组的未知数个数 $n$ 多于方程个数 $m$，则它有非平凡解。

*证明*　主元个数不超过 $m < n$，至少有一个自由变量。令这个自由变量为 1、其余自由变量为 0，按 3.4.4 节解出主变量，得到一个非零解（它的那个自由变量分量为 1）。　∎

这个定理看似简单，却是第 7 章“维数”概念的基石：$\mathbb R^m$ 中多于 $m$ 个向量必定线性相关，证明的关键一步正是它。

对方阵，由推论 3.5.3 和定理 3.6.2 的论证可知：$n\times n$ 齐次方程组只有零解，当且仅当 $A$ 有 $n$ 个主元，当且仅当 $A\boldsymbol x = \boldsymbol b$ 对每个 $\boldsymbol b$ 都有唯一解。“齐次方程组只有零解”是检验方阵可逆最常用的办法之一。

### 3.6.3 非齐次方程组解的结构

**定理 3.6.3** 设 $\boldsymbol x_p$ 是 $A\boldsymbol x = \boldsymbol b$ 的一个解。则 $A\boldsymbol x = \boldsymbol b$ 的全部解是

$$
\boldsymbol x = \boldsymbol x_p + \boldsymbol x_h , \tag{3.6.1}
$$

其中 $\boldsymbol x_h$ 取遍对应齐次方程组 $A\boldsymbol x = \boldsymbol 0$ 的全部解。

*证明*　若 $A\boldsymbol x_h = \boldsymbol 0$，则 $A(\boldsymbol x_p + \boldsymbol x_h) = \boldsymbol b + \boldsymbol 0 = \boldsymbol b$，所以 $\boldsymbol x_p + \boldsymbol x_h$ 是解（这里用到了 $A(\boldsymbol u + \boldsymbol w) = A\boldsymbol u + A\boldsymbol w$，它由逐行的点积的线性得到）。反之，若 $\boldsymbol x$ 是 $A\boldsymbol x = \boldsymbol b$ 的任一解，令 $\boldsymbol x_h = \boldsymbol x - \boldsymbol x_p$，则 $A\boldsymbol x_h = \boldsymbol b - \boldsymbol b = \boldsymbol 0$，即 $\boldsymbol x = \boldsymbol x_p + \boldsymbol x_h$ 正是所说的形式。　∎

这就是 3.4 节通解 (3.4.3) 的结构：第一个向量是特解，后面两项合起来是齐次方程组的全部解。程序 3.6.1 验证：特解加上齐次解的任意组合（例如 $7\boldsymbol s_1 - 3\boldsymbol s_2$）仍是原方程组的解；原方程组任意两个解之差是齐次方程组的解。

几何上，齐次方程组的解集是过原点的直线、平面或更高维的“平面”；非齐次方程组的解集是把它平移 $\boldsymbol x_p$ 得到的、平行的直线或平面。1.1 节说仿射映射是“线性加平移”，这里的解集结构是同样的道理。第 2 章“直线 $\boldsymbol x = \boldsymbol p + t\boldsymbol d$”中的 $\boldsymbol p$ 和 $t\boldsymbol d$，正是一个特解和过原点的直线。

推论：方程组 $A\boldsymbol x = \boldsymbol b$ 若有解，解唯一当且仅当对应的齐次方程组只有零解。解的“个数”由 $A$ 决定，与 $\boldsymbol b$ 无关；$\boldsymbol b$ 只决定“有没有解”。

### 3.6.4 机器人：末端不动的自运动

回到三连杆臂。$J\dot{\boldsymbol\theta} = \boldsymbol 0$ 是两个方程、三个未知数的齐次方程组，由定理 3.6.2 一定有非零解。由 3.5.4 节的简化行阶梯形，把右端换成零，就得到

$$
\dot{\boldsymbol\theta} = \dot\theta_3\begin{pmatrix} {{ex3_5.nv}}\end{pmatrix}.
$$

沿这个方向转动三个关节，末端（在线性近似下）一动不动，只是臂身的姿态在变，称为**自运动**。3.5.4 节的两个解之差 $\dot{\boldsymbol\theta}_b - \dot{\boldsymbol\theta}_a$ 正是这样一个自运动（$\dot\theta_3 = 0.5$）。七轴的 Franka Panda 机械臂执行六维的末端任务时，同样有一维的自运动，第 18 章的实验 18.6 将让读者亲手体验它。

### 3.6.5 生活中的例子

一个天平两端各放几个砝码保持平衡，相当于一个齐次方程：左边的质量减去右边的质量等于零。“什么都不放”当然平衡（平凡解）；在已经平衡的天平两边各加一个同样的砝码，仍然平衡（齐次解可以相加）。称东西时，“物体加某些砝码 = 另一些砝码”是非齐次方程；找到一种放法（特解）之后，在两边同时加减任何“自己平衡的砝码组合”（齐次解），仍是一种可行的放法。

**工程师笔记**

- 结构分析中，刚度方程 $K\boldsymbol u = \boldsymbol f$ 的齐次方程组若有非零解，说明结构可以在不受力的情况下发生位移，是“机构”而不是“结构”，约束不够。有限元程序遇到这种情况会报“刚度矩阵奇异”，通常是忘了加支座约束（第 40 章）。
- 齐次方程组的非零解只确定到一个倍数：化学方程式配平（3.7 节）通常取最小的正整数解；特征向量（第 13 章）通常取单位长度。
- 数值计算中，求齐次方程组的非零解不用消元，而用第 18 章的奇异值分解：最小奇异值对应的右奇异向量就是“最接近”非零解的单位向量。
