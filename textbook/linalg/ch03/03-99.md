title: 本章小结
---

本章的主线可以用一句话概括：**消元把方程组化为阶梯形，主元决定一切**。有没有解、有几个解、解是什么样子，都写在行阶梯形里。

线性方程组 $A\boldsymbol x = \boldsymbol b$ 有两种看法。行图：每个方程是一个超平面（二维中是直线，三维中是平面），解是它们的公共点。列图：$\boldsymbol b$ 是否为 $A$ 的各列的线性组合，组合系数就是解。两种看法说的是同一件事，列图与维数无关，是后面各章的出发点。

高斯消元法用每个方程的主元消去下方方程中的同一个未知数，化成上三角形后回代。它就是《九章算术》的方程术。主元为零时与下方的行交换；整列都找不到主元时跳到下一列。用增广矩阵 $(A\mid\boldsymbol b)$ 记录这一过程，所用的只有三种初等行变换：交换、数乘（非零数）、倍加。三种变换都可以撤销，所以不改变解集。

消元的终点是行阶梯形；再把主元化为 1、消去主元上方的元素，得到简化行阶梯形，它对每个矩阵是唯一的。主元所在的列对应主变量，其余是自由变量。由简化行阶梯形可以直接读出全部解：自由变量任意取值，主变量随之确定，通解写成“特解加上自由变量乘以若干向量”。

解的情形只有三种：增广矩阵的最后一列是主元列时无解；否则，没有自由变量时解唯一，有自由变量时有无穷多解。方程少于未知数时不可能有唯一解；$n\times n$ 方程组对每个右端都有唯一解，当且仅当有 $n$ 个主元。

齐次方程组 $A\boldsymbol x = \boldsymbol 0$ 总有零解，解集对线性组合封闭；未知数多于方程时一定有非零解。非齐次方程组的全部解等于一个特解加上齐次方程组的全部解，解的“个数”由 $A$ 决定，$\boldsymbol b$ 只决定有没有解。冗余机械臂的无穷多组关节速度、末端不动的自运动，都是这一结构的体现。

守恒和平衡定律在许多领域给出线性方程组：电路的节点电压、桁架的杆力、化学方程式的配平、路网的流量、部门之间的投入产出。最后，消元约需 $n^3/3$ 次乘法和同样多次加法，回代只需约 $n^2/2$ 次；$n$ 扩大 10 倍，运算量扩大 1000 倍，大规模问题必须利用稀疏性。

3.2.2 第一个主元为 0，交换第 1、2 个方程；解为 $(3, 1, 2)$。

3.2.3 消元后第二个方程变为 $0 = c - 6$。$c = 6$ 时有无穷多解 $(3 - 2t, t)$，否则无解。

3.2.7 设三个模块的力为 $f_1, f_2, f_3$：$f_1 + f_2 + f_3 = 600$，$f_1 - f_2 = 50$，$f_3 = (f_1 + f_2)/2$，解得 $f_1 = 225$，$f_2 = 175$，$f_3 = 200$（N）。

3.3.4 $R_1\leftarrow R_1 + R_2$，$R_2\leftarrow R_2 - R_1$，$R_1\leftarrow R_1 + R_2$，$R_2\leftarrow -R_2$。

3.4.2 简化行阶梯形的非零行为 $(1, -1, 0, -3\mid -1)$、$(0, 0, 1, 2\mid 2)$；主元列 1、3，自由变量 $x_2$、$x_4$；$\boldsymbol x = (-1, 0, 2, 0)^{\mathsf T} + x_2(1, 1, 0, 0)^{\mathsf T} + x_4(3, 0, -2, 1)^{\mathsf T}$。
