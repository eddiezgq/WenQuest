### 3.3.1 问题的提出

3.2 节消元时，每一步都把整个方程组抄一遍。可是真正变化的只有系数和右端，$x$、$y$、$z$、加号和等号一直原样照抄。《九章算术》的算板上只摆数，不写未知数，道理正在于此。只记数，既省事，又便于交给计算机。

还有一个问题需要回答：消元为什么是对的？每一步都把方程组换成了另一个方程组，凭什么说新方程组的解就是原方程组的解，而且一个不多、一个不少？本节把这两件事讲清楚。

### 3.3.2 增广矩阵

**定义 3.3.1（增广矩阵）** 把方程组 $A\boldsymbol x = \boldsymbol b$ 的系数矩阵 $A$ 和右端 $\boldsymbol b$ 并排写在一起，得到的 $m\times(n + 1)$ 矩阵称为方程组的**增广矩阵**，记作 $(A\mid\boldsymbol b)$。

例如方程组

$$
\begin{aligned}
x + 2y - z &= 2,\\
2x + 5y + z &= 9,\\
-x + y + 4z &= 7
\end{aligned} \tag{3.3.1}
$$

的增广矩阵是

$$
(A\mid\boldsymbol b) = {{ex3_3.M}} .
$$

竖线只是提醒最后一列是右端，计算时与其他列一样处理。增广矩阵的每一行代表一个方程，前 $n$ 列分别对应 $n$ 个未知数。国内教材常记作 $\overline A$ 或 $\widetilde A$。

### 3.3.3 三种初等行变换

消元中对方程做的操作，在增广矩阵上就是对行的操作。一共只需要三种。

**定义 3.3.2（初等行变换）** 对矩阵的行做下列三种变换，称为**初等行变换**：

1. **交换**：交换两行，记作 $R_i\leftrightarrow R_j$；
2. **数乘**：用一个非零数 $c$ 乘某一行，记作 $R_i\leftarrow cR_i$（$c\ne0$）；
3. **倍加**：把某一行的 $c$ 倍加到另一行上，记作 $R_i\leftarrow R_i + cR_j$（$i\ne j$）。

若矩阵 $B$ 可以由矩阵 $A$ 经过有限次初等行变换得到，就称 $A$ 与 $B$ **行等价**。

高斯消元只用到第 1、3 种（遇到零主元时交换，其余全是倍加），第 2 种在 3.4 节化简行阶梯形时把主元化为 1。对方程组 (3.3.1)，依次做 $R_2\leftarrow R_2 - 2R_1$、$R_3\leftarrow R_3 + R_1$、$R_3\leftarrow R_3 - 3R_2$：

$$
{{ex3_3.M}}\ \to\ {{ex3_3.A1}}\ \to\ {{ex3_3.A2}}\ \to\ {{ex3_3.A3}} .
$$

最后的增广矩阵代表上三角方程组 $x + 2y - z = 2$，$y + 3z = 5$，$-6z = -6$。回代得 $z = {{ex3_3.z}}$，$y = {{ex3_3.y}}$，$x = {{ex3_3.x}}$。

三种变换都可以撤销，而且撤销它们的也是同一类初等行变换：交换两次就复原了；$R_i\leftarrow cR_i$ 用 $R_i\leftarrow\frac1cR_i$ 撤销（这就是要求 $c\ne0$ 的原因）；$R_i\leftarrow R_i + cR_j$ 用 $R_i\leftarrow R_i - cR_j$ 撤销（这要求 $i\ne j$，否则 $R_i\leftarrow R_i + cR_i$ 实际上是数乘 $1 + c$，当 $c = -1$ 时把一行变成零，无法撤销）。

### 3.3.4 行变换不改变解

**定理 3.3.1** 若增广矩阵 $(A\mid\boldsymbol b)$ 与 $(B\mid\boldsymbol d)$ 行等价，则方程组 $A\boldsymbol x = \boldsymbol b$ 与 $B\boldsymbol x = \boldsymbol d$ 的解集相同。

*证明*　只需证明做一次初等行变换不改变解集，然后对变换的次数用数学归纳法（1.5 节）。

设一次变换把方程组 S 变成方程组 S′。先证 S 的每个解都是 S′ 的解。交换两个方程只改变方程的次序，解当然不变。数乘：若 $\boldsymbol x$ 满足第 $i$ 个方程 $\boldsymbol r_i\cdot\boldsymbol x = b_i$（$\boldsymbol r_i$ 表示 $A$ 的第 $i$ 行），则它也满足 $c\,\boldsymbol r_i\cdot\boldsymbol x = cb_i$。倍加：若 $\boldsymbol x$ 满足第 $i$、$j$ 两个方程，则 $(\boldsymbol r_i + c\boldsymbol r_j)\cdot\boldsymbol x = b_i + cb_j$，即满足新的第 $i$ 个方程；其余方程没有变。

再证 S′ 的每个解都是 S 的解。由于 S 可以由 S′ 经过一次初等行变换（撤销的那一次）得到，把上一段的论证用于这次变换即可。两个方向合起来，S 与 S′ 的解集相同。　∎

证明的第二部分正是要求三种变换都“可以撤销”的原因。如果允许用 0 乘一行，那一行就变成了 $0 = 0$，原来的约束丢失了，解集可能变大。初学者常犯的另一个错误是同时做两个依赖于彼此的倍加，例如同时做 $R_1\leftarrow R_1 - R_2$ 和 $R_2\leftarrow R_2 - R_1$（都用变换前的行）。这一对变换合起来把两行变成了互为相反数的两行，丢失了一个方程。每次做一个变换，就不会出这种问题。

注意定理 3.3.1 只说**行**变换。对列做变换（例如交换两列）相当于交换未知数的名字，或者把未知数换成它们的组合，解会随之改变，必须记录下来再换回去。

### 3.3.5 生活中的例子

会计对账时，把一张收支表的几行相加、相减，或者统一换算单位（元换成万元），表达的财务事实不变：这相当于倍加和数乘。但如果把“收入”和“支出”两列互换，账就全乱了：这相当于列变换，改变了每个数的含义。同样，调换几行的次序不影响账目，调换列的次序就必须同时改表头。

**工程师笔记**

- 在程序中做行变换时，对行切片原地赋值，如 `M[i] = M[i] - l * M[k]`。在 NumPy 中，`M[i]` 是视图，若写成 `r = M[i]; r -= l * M[k]` 也会修改原矩阵；需要保留原矩阵时先 `M = M.copy()`。
- 交换两行在 NumPy 中写成 `M[[i, j]] = M[[j, i]]`。写成 `M[i], M[j] = M[j], M[i]` 是错的：右边是视图，第一次赋值后第二个视图的内容已经变了。
- 用整数初始化的 NumPy 数组（如 `np.array([[2, 1], [4, 3]])`）元素类型是整数，做 `M[i] = M[i] - l * M[k]` 时小数部分会被截掉。消元前先 `M = M.astype(float)`。
- 记录每一次行变换（类型、行号、倍数），既便于检查，也是第 5 章构造 LU 分解和置换矩阵的依据。
