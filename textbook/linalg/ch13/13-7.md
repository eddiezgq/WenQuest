### 13.7.1 问题的提出

13.5 节的采样控制器在 $K_p = 100$、$K_d = 20$ 时有二重特征值 0.5（临界阻尼），在 $K_p = 400$、$K_d = 40$ 时有二重特征值 0（无差拍）。无差拍的 $A$ 两个特征值都是 0，$A$ 本身却不是零矩阵，可见它不能对角化（能对角化的话 $A = X0X^{-1} = 0$）。这时 (13.5.2) 不再适用，$A^k$ 是什么样子？关节还稳定吗？本节说明特征值重复时可能出现的问题，以及哪些性质在换基（相似变换）后保持不变。

### 13.7.2 两种重数

**定义 13.7.1** 设 $\lambda$ 是 $A$ 的特征值。$\lambda$ 作为特征多项式的根的重数称为它的**代数重数**；特征空间 $E_\lambda = N(A - \lambda I)$ 的维数称为它的**几何重数**。

几何重数就是属于 $\lambda$ 的线性无关的特征向量的最大个数，等于 $n - \operatorname{rank}(A - \lambda I)$。

**定理 13.7.1** 对每个特征值，$1\le$ 几何重数 $\le$ 代数重数。

*证明*　设几何重数为 $g$，取 $E_\lambda$ 的一组基 $\boldsymbol x_1, \dots, \boldsymbol x_g$，扩充为 $\mathbb C^n$ 的一组基，以它们为列组成可逆矩阵 $M$。前 $g$ 列满足 $A\boldsymbol x_j = \lambda\boldsymbol x_j$，所以 $M^{-1}AM = \begin{pmatrix}\lambda I_g & *\\ 0 & D\end{pmatrix}$。它的特征多项式是 $(\lambda - \mu)^g\det(D - \mu I)$（这里 $\mu$ 是变量），而相似矩阵的特征多项式相同（定理 13.7.3，它的证明不依赖本定理），所以 $\lambda$ 至少是 $g$ 重根。　∎

**定理 13.7.2** $A$ 可以（在复数范围内）对角化，当且仅当对每个特征值，几何重数等于代数重数。

*证明*　代数重数之和是 $n$。若每个特征值的几何重数等于代数重数，把各特征空间的基合在一起共 $n$ 个向量，它们线性无关（定理 13.4.2 的推广，习题 13.7.4），由定理 13.4.1 可对角化。反过来，若可对角化，$X$ 的 $n$ 列中属于 $\lambda$ 的恰有“代数重数”个（$A$ 与 $\Lambda$ 相似，由定理 13.7.3 特征多项式相同，$\lambda$ 在 $\Lambda$ 对角线上出现的次数就是代数重数），它们都在 $E_\lambda$ 中且线性无关，所以几何重数不小于代数重数，再由定理 13.7.1 两者相等。　∎

某个特征值的几何重数小于代数重数时，矩阵称为**亏损矩阵**：特征向量不够用。

**算例 13.7.1**

- 单位矩阵 $I_2$：特征值 1，代数重数 2，$N(I - I)$ 是整个平面，几何重数 2，可对角化（本身就是对角的）。
- 剪切 $S = \begin{pmatrix}1 & 1\\ 0 & 1\end{pmatrix}$：特征值 1，代数重数 2，$\operatorname{rank}(S - I) = 1$，几何重数 1，亏损。
- 13.2 节的 $B$：特征值 3 的代数重数 2，几何重数 {{ex13_7.geoB3}}，亏损；特征值 2 的两种重数都是 1。

特征值互不相同时，每个代数重数都是 1，几何重数只能也是 1，所以一定可以对角化（推论 13.4.1）。麻烦只出在重特征值上。

### 13.7.3 相似矩阵

9.6 节说，若 $B = M^{-1}AM$（$M$ 可逆），称 $A$ 与 $B$ **相似**：它们是同一个线性映射在两组不同基下的矩阵。对角化就是找一个与 $A$ 相似的对角矩阵。

**定理 13.7.3** 相似矩阵有相同的特征多项式，因而有相同的特征值（包括代数重数）、迹和行列式；它们的秩、每个特征值的几何重数也相同。若 $A\boldsymbol x = \lambda\boldsymbol x$，则 $B(M^{-1}\boldsymbol x) = \lambda(M^{-1}\boldsymbol x)$。

*证明*　$\det(B - \lambda I) = \det(M^{-1}AM - \lambda M^{-1}M) = \det(M^{-1})\det(A - \lambda I)\det M = \det(A - \lambda I)$。迹和行列式由定理 13.3.1 得到。$B - \lambda I = M^{-1}(A - \lambda I)M$，乘可逆矩阵不改变秩（定理 8.6.2），所以 $\operatorname{rank}B = \operatorname{rank}A$，$\operatorname{rank}(B - \lambda I) = \operatorname{rank}(A - \lambda I)$，几何重数相同。最后，$BM^{-1}\boldsymbol x = M^{-1}A\boldsymbol x = \lambda M^{-1}\boldsymbol x$。　∎

**算例 13.7.2** 取算例 13.2.1 的 $A$ 和 $M = {{ex13_7.M}}$，$B = M^{-1}AM = {{ex13_7.Bs}}$。$B$ 的元素与 $A$ 完全不同，但特征多项式的系数仍是 {{ex13_7.polyBs}}，即 $\lambda^2 - \lambda - 2$，迹为 {{ex13_7.trBs:.0f}}，行列式为 {{ex13_7.detBs:.0f}}。$A$ 属于 2 的特征向量 $(5, 2)^{\mathsf T}$ 变为 $M^{-1}(5, 2)^{\mathsf T} = {{ex13_7.vB}}$，$B{{ex13_7.vB}} = {{ex13_7.BvB}}$，确实是 2 倍。

反过来不成立：特征多项式相同的矩阵不一定相似。$I$ 与 $S$ 的特征多项式都是 $(\lambda - 1)^2$（系数 {{ex13_7.polyS}}），但与 $I$ 相似的矩阵只有 $M^{-1}IM = I$ 自己，$S$ 不是。两者的几何重数不同，这就是区别。判断两个矩阵是否相似的完整答案是若尔当标准形（第 17 章）。

| 相似变换下不变 | 相似变换下会变 |
|---|---|
| 特征多项式、特征值（及代数重数） | 特征向量（变为 $M^{-1}\boldsymbol x$） |
| 迹、行列式、秩 | 矩阵的元素 |
| 每个特征值的几何重数 | 对称性（相似变换一般不保持对称） |
| 能否对角化 | 列空间、零空间（变为 $M^{-1}$ 作用后的空间） |

### 13.7.4 应用：临界阻尼与无差拍

*临界阻尼*　$K_p = 100$、$K_d = 20$ 时，

$$
A = {{ex13_7.Ab}},
$$

迹为 1，行列式为 0.25，由 (13.3.2) 特征值为二重的 0.5；$\operatorname{rank}(A - 0.5I) = {{ex13_7.rankAb}}$，几何重数为 1，$A$ 是亏损矩阵。特征向量只有 $\boldsymbol v_1 = {{ex13_7.v1}}$ 一个方向（$A\boldsymbol v_1 = {{ex13_7.Ab_v1}}$）。再解 $(A - 0.5I)\boldsymbol v_2 = \boldsymbol v_1$ 得到第二个向量，例如 $\boldsymbol v_2 = (2, 0)^{\mathsf T}$（验证：$(A - 0.5I)\boldsymbol v_2 = (1, -10)^{\mathsf T} = \boldsymbol v_1$，于是 $\boldsymbol x_0 = (1, 0)^{\mathsf T} = \tfrac12\boldsymbol v_2$）；以 $\boldsymbol v_1$、$\boldsymbol v_2$ 为列组成 $X$，程序 13.7.1 算得

$$
X^{-1}AX = J = \begin{pmatrix}0.5 & 1\\ 0 & 0.5\end{pmatrix}
$$

（误差 ${{ex13_7.Jchk}}$）。这不是对角矩阵，是最接近对角的形式，称为若尔当块（第 17 章）。它的幂是

$$
J^k = \begin{pmatrix}\lambda^k & k\lambda^{k-1}\\ 0 & \lambda^k\end{pmatrix},\qquad \lambda = 0.5, \tag{13.7.1}
$$

比 $\Lambda^k$ 多了一项 $k\lambda^{k-1}$（习题 13.7.2）。从 $\theta_0 = 1$、$\omega_0 = 0$ 出发，可以算出 $\theta_k = (1 + k)\,0.5^k$（习题 13.7.6，程序给出 $\theta_3 = {{ex13_7.theta3}}$），比单纯的 $0.5^k$ 衰减得慢（图 13.7.1）。不过 $k\lambda^k\to0$（$\lvert\lambda\rvert < 1$ 时指数衰减胜过线性增长），所以关节仍然稳定。本例验证了 13.5.2 节“谱半径小于 1 则 $A^k\to0$”对亏损矩阵同样成立，一般的证明见 21.1 节。

*无差拍*　$K_p = 400$、$K_d = 40$ 时，$A = {{ex13_7.Ac}}$，$A^2 = {{ex13_7.Ac2}}$。特征值是二重的 0，$\operatorname{rank}A = {{ex13_7.rankAc}}$，几何重数 1。由 $A^2 = 0$，任何初始状态两步后都变为零：$\boldsymbol x_2 = A^2\boldsymbol x_0 = \boldsymbol 0$。这叫无差拍控制，是离散系统特有的现象（连续系统只能无限趋近零）。这里的无差拍是对模型 (13.5.4) 而言；对零阶保持的精确模型，同样这组增益的特征值是 {{ex13_5.zoh_c}}，并不是无差拍，那里的无差拍增益是 $K_p = 1/T^2 = 400$、$K_d = 1.5/T = 30$（第 35 章）。代价是第一步的控制力矩很大（$u_0 = -K_p\theta_0 = -400$），实际电机的力矩有上限，所以很少这样调（实验 13.5 的思考题）。

### 13.7.5 生活中的例子

两条车道在前方合并成一条。合并之前，车可以沿两个不同的方向行驶；合并处，两个方向挤成了一个。重特征值的亏损情形也是这样：两个特征值“撞”在一起时，两个特征方向往往也挤成了一个，于是凑不出足够的特征向量。一般的矩阵稍微扰动一下，两个特征值就会分开，特征方向也恢复为两个，所以亏损矩阵是“例外”，但在工程设计中（例如有意把两个极点放在一起的临界阻尼），这种例外恰恰会被刻意选中。

---

**工程师笔记**

- 重特征值对扰动非常敏感。$\begin{pmatrix}1 & 1\\ \varepsilon & 1\end{pmatrix}$ 的特征值是 $1\pm\sqrt\varepsilon$：$\varepsilon = 10^{-10}$ 时特征值变化了 $10^{-5}$，放大了十万倍（21.4 节）。所以数值计算几乎从不“恰好”得到重特征值，也不用若尔当形做计算，而用舒尔分解（17.7 节）。
- 对亏损矩阵，`numpy.linalg.eig` 仍会返回 $n$ 个“特征向量”，但其中几个几乎平行，$X$ 的条件数极大（程序 13.4.1 中剪切矩阵的 $\det X$ 只有 $10^{-16}$ 量级）。用它做 $X\Lambda^kX^{-1}$ 会得到错误的结果。
- 临界阻尼是机器人关节常用的整定目标：在不超调的响应中回零最快（固定比例增益时）。设计时要注意 $k\lambda^k$ 项带来的速度峰值（本例中第一步的角速度就到了 $-5$），它决定了需要的最大力矩。
