# 《线性代数》符号约定（v0.1，2026-10-02，待 Eddie 审阅）

全书统一使用本约定。写作、程序、插图、动画、实验都以它为准。新增符号先登记在这里，再在正文中使用。

## 一、总原则

1. **国际通行写法为主，注明国内写法**：正文用 Strang、Axler、Golub–Van Loan 等国际教材通行的记号；一个记号第一次出现时，用一句话注明国内教材（同济《线性代数》、北大《高等代数》）的写法，便于读者对照和应试。第六节列出全部对照。
2. **一个符号只表示一种东西**。确有冲突时（如 $\sigma$ 既表示奇异值又表示应力），在该节开头说明。
3. **列向量为默认**：$\mathbb R^n$ 中的向量一律是列向量；行向量写成转置 $\boldsymbol x^{\mathsf T}$。矩阵乘向量写成 $A\boldsymbol x$（左乘）。
4. **程序与书一致**：程序中的变量名尽量与书中符号对应，例如 `A`、`x`、`U, s, Vt = np.linalg.svd(A)`（注意 NumPy 返回的是 $V^{\mathsf T}$ 和奇异值的一维数组，第 18 章专门说明）。

## 二、字体与排版

| 对象 | 写法（LaTeX） | 例 |
|---|---|---|
| 数（标量） | 斜体小写 | $a$, $c$, $\lambda$, $\sigma_1$ |
| 向量 | 粗斜体小写 `\boldsymbol{x}` | $\boldsymbol x$, $\boldsymbol v_1$, $\boldsymbol 0$ |
| 向量的第 $i$ 个分量 | 斜体加下标 | $x_i$ |
| 矩阵 | 斜体大写 | $A$, $Q$, $\Sigma$ |
| 矩阵的元素 | 小写加双下标，或 $(A)_{ij}$ | $a_{ij}$ |
| 矩阵的第 $j$ 列 | 粗斜体小写加下标 | $\boldsymbol a_j$ |
| 向量组、基 | 花体大写 | $\mathcal B = \{\boldsymbol v_1, \dots, \boldsymbol v_n\}$ |
| 向量空间、子空间 | 斜体大写 | $V$, $W$, $U$ |
| 数集、数域 | 黑板粗体 | $\mathbb R$, $\mathbb C$, $\mathbb Q$, $\mathbb F$ |
| 线性映射 | 斜体大写 | $T$, $S$ |
| 函数与算子名 | 正体 | $\det$, $\operatorname{tr}$, $\operatorname{rank}$, $\operatorname{span}$, $\ker$, $\operatorname{im}$, $\dim$ |

向量用粗体，即使在【进阶】章节讲抽象向量空间时也不改（多项式、函数作为向量时写 $\boldsymbol p$、$\boldsymbol f$；在不致混淆的函数空间例题中，可按习惯写 $p(x)$，并在该节开头说明）。

## 五、特征值与奇异值

| 符号 | 含义 | 首次出现 |
|---|---|---|
| $\lambda$, $\lambda_i$ | 特征值 | 13.1 |
| $p(\lambda) = \det(A - \lambda I)$ | 特征多项式（国内多写 $\lvert\lambda I - A\rvert$，两者相差因子 $(-1)^n$，根相同） | 13.2 |
| $\rho(A)$ | 谱半径 | 21.1 |
| $R(\boldsymbol x) = \dfrac{\boldsymbol x^{\mathsf T}A\boldsymbol x}{\boldsymbol x^{\mathsf T}\boldsymbol x}$ | 瑞利商 | 14.4 |
| $\sigma_1\ge\sigma_2\ge\cdots\ge\sigma_r>0$ | 非零奇异值，**按从大到小**排列；$r = \operatorname{rank}A$ | 18.1 |
| $\boldsymbol u_i$, $\boldsymbol v_i$ | 左、右奇异向量：$A\boldsymbol v_i = \sigma_i\boldsymbol u_i$ | 18.1 |
| $\Sigma$ | $m\times n$ 的奇异值矩阵（完整 SVD）；紧凑 SVD 中为 $r\times r$ 对角阵，写 $\Sigma_r$ | 18.2 |
| $A_k = \sum_{i=1}^k \sigma_i\boldsymbol u_i\boldsymbol v_i^{\mathsf T}$ | 秩 $k$ 截断 | 18.4 |
| $\kappa(A) = \sigma_1/\sigma_n$ | 条件数（2-范数） | 18.2, 20.3 |
| $\lVert A\rVert_2$, $\lVert A\rVert_F$, $\lVert A\rVert_*$ | 谱范数、弗罗贝尼乌斯范数、核范数 | 18.4, 20.2 |

## 六、与国内教材写法的对照

| 本书 | 国内常见写法 | 说明 |
|---|---|---|
| $\boldsymbol x$（粗斜体） | $\boldsymbol\alpha$, $\boldsymbol\beta$（希腊字母表示向量组） | 本书讲向量组时也用 $\boldsymbol v_1,\dots,\boldsymbol v_k$ |
| $A^{\mathsf T}$ | $A^{\mathsf T}$ 或 $A'$ | |
| $\det A$ | $\lvert A\rvert$、$D$ | 本书在第 6 章同时使用两种写法，之后统一用 $\det A$ |
| $\operatorname{rank} A$ | $R(A)$、$r(A)$、$\operatorname{r}(A)$ | 本书 $R$ 另有用处（上三角因子、旋转矩阵），故不用 $R(A)$ 表示秩 |
| $C(A)$ | $R(A)$（值域）、$\operatorname{Im}A$ | |
| $N(A)$ | $N(A)$、$\operatorname{Ker}A$、$\ker A$ | |
| $A^{*}$ | 伴随矩阵 | 本书伴随矩阵写 $\operatorname{adj}A$，$A^{*}$ 留给伴随算子 |
| $\det(A - \lambda I)$ | $\lvert\lambda E - A\rvert$ | 国内单位矩阵常写 $E$ |
| $I$ | $E$ | |
| $\mathbb F$ | $P$、$K$（数域） | |
| $\langle\boldsymbol u,\boldsymbol v\rangle$ | $(\boldsymbol\alpha,\boldsymbol\beta)$、$[\boldsymbol x,\boldsymbol y]$ | |

## 七、数值与程序

1. **书中的小数**一律由程序给出（第 7 轮规则），默认 5 位有效数字；矩阵用 `bookout.tex(M, digits)` 排成 LaTeX，默认小数点后 4 位。
2. **浮点结果里的“零”**：程序给出的极小数（如 $3\times10^{-16}$）在正文中写成“在舍入误差范围内为零”，并给出它的量级，不写成 0。
3. **奇异值、特征值的排序**：奇异值从大到小；实对称矩阵的特征值从小到大写 $\lambda_1\le\cdots\le\lambda_n$（瑞利商、极小极大原理用这个顺序），其他场合在用到时说明。
4. **特征向量、奇异向量的符号**：不唯一，程序给出的结果与手算可能差一个符号（复数时差一个模为 1 的因子）。程序统一规定“第一个绝对值最大的分量为正”（绝对值相差不到 $10^{-9}$ 的算作一样大，取靠前的一个），正文在第一次遇到时说明。
5. **随机数**：程序用 `np.random.default_rng(种子)`，种子写在程序开头，保证每次构建的数相同。
