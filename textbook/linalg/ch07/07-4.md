### 7.4.1 问题的提出

两连杆臂的两个关节各自转动时，末端分别沿 $J$ 的两列方向运动（6.8 节）。两个关节同时转，末端的速度是这两列的线性组合。所有可能的末端速度构成一个集合：它是整个平面，还是只有一条直线？3.1 节的列图问的是同一个问题：$\boldsymbol b$ 能不能由 $A$ 的各列组合出来。本节给这个集合起一个名字：张成的子空间。

### 7.4.2 定义

**定义 7.4.1（张成）** 向量 $\boldsymbol v_1, \dots, \boldsymbol v_k\in V$ 的全部线性组合构成的集合

$$
\operatorname{span}\{\boldsymbol v_1, \dots, \boldsymbol v_k\} = \{c_1\boldsymbol v_1 + \cdots + c_k\boldsymbol v_k : c_1, \dots, c_k\in\mathbb F\} \tag{7.4.1}
$$

称为由它们**张成**的子空间。若 $\operatorname{span}\{\boldsymbol v_1, \dots, \boldsymbol v_k\} = W$，称 $\boldsymbol v_1, \dots, \boldsymbol v_k$ 张成 $W$，也称它们是 $W$ 的一组**生成元**。

**定理 7.4.1** $\operatorname{span}\{\boldsymbol v_1, \dots, \boldsymbol v_k\}$ 是 $V$ 的子空间，而且是包含 $\boldsymbol v_1, \dots, \boldsymbol v_k$ 的最小的子空间：任何包含这些向量的子空间都包含它。

*证明*　两个线性组合之和、线性组合的倍数仍是线性组合，所以它是子空间。任何包含 $\boldsymbol v_1, \dots, \boldsymbol v_k$ 的子空间对线性组合封闭，必然包含它们的全部线性组合。　∎

几何上：$\mathbb R^3$ 中一个非零向量张成一条过原点的直线；两个不共线的向量张成一个过原点的平面；三个不共面的向量张成整个 $\mathbb R^3$。

### 7.4.3 b 在不在张成的空间里

**定理 7.4.2** $\boldsymbol b\in\operatorname{span}\{\boldsymbol a_1, \dots, \boldsymbol a_n\}$ 当且仅当方程组 $A\boldsymbol x = \boldsymbol b$ 有解，其中 $A = (\boldsymbol a_1\ \cdots\ \boldsymbol a_n)$。

这只是 3.1 节列图的重述。第 8 章把 $A$ 的各列张成的子空间称为 $A$ 的列空间。

**算例 7.4.1** $\boldsymbol a_1 = (1, 0, 1)^{\mathsf T}$，$\boldsymbol a_2 = (0, 1, 1)^{\mathsf T}$，$\boldsymbol a_3 = (1, 1, 2)^{\mathsf T}$，即 $A = {{ex7_4.A}}$。$\boldsymbol a_3 = \boldsymbol a_1 + \boldsymbol a_2$，三个向量只张成一个平面（$A$ 的秩为 {{ex7_4.rank}}）。这个平面的法向量是 $\boldsymbol n = \boldsymbol a_1\times\boldsymbol a_2 = {{ex7_4.n}}$，平面方程为 $-x - y + z = 0$。$\boldsymbol b = {{ex7_4.b_in}}$ 满足 $\boldsymbol n\cdot\boldsymbol b = {{ex7_4.nb:.0f}}$，在平面内，$A\boldsymbol x = \boldsymbol b$ 有解（程序算得残差约为零）；$\boldsymbol b' = {{ex7_4.b_out}}$ 满足 $\boldsymbol n\cdot\boldsymbol b' = {{ex7_4.nb2:.0f}}$，不在平面内，方程组无解，最接近的组合也有 {{ex7_4.resid_out:.3f}} 的距离（第 10 章的最小二乘）。

回到两连杆臂（UR5e 尺寸，$\theta_1 = 30^\circ$）：$\theta_2 = 60^\circ$ 时，$J$ 的两列张成整个平面（秩 {{ex7_4.rJ}}），末端可以沿任何方向运动；手臂伸直时，两列平行，只张成一条直线（秩 {{ex7_4.rJ0}}），这正是 6.8 节的奇异位形。

### 7.4.4 函数与多项式的张成

$\operatorname{span}\{1, t, t^2, t^3\} = \mathcal P_3$。$\operatorname{span}\{\cos t, \sin t\}$ 是 $y'' + y = 0$ 的解空间（第 16 章）。三角多项式 $\operatorname{span}\{1, \cos t, \sin t, \cos2t, \sin2t, \dots, \cos Nt, \sin Nt\}$ 是傅里叶分析的出发点：周期信号可以用它们的线性组合逼近，$N$ 越大越接近（第 36 章）。

### 7.4.5 生活中的例子

调色盘上只有红、黄、蓝三种颜料（以一定比例混合，暂且把混合看作线性），能调出的颜色就是这三种颜色“张成”的范围。若只有红和黄，就调不出蓝色系的颜色：蓝色不在红、黄张成的空间里。不过颜料的用量不能为负，实际能调出的只是这几种颜色的非负组合（称为色域），它是张成空间中的一个“锥”。印刷用青、品红、黄、黑四色，屏幕用红、绿、蓝三色，选择的原则是让色域尽量大。

**工程师笔记**

- 用数值方法判断 $\boldsymbol b$ 是否在张成的空间里，不能要求残差严格为零，要与 $\|\boldsymbol b\|$ 和测量误差比较。
- 判断一组向量能否张成 $\mathbb R^m$，看它们排成的矩阵的秩是否为 $m$：`np.linalg.matrix_rank(A) == m`。秩的数值计算用奇异值（第 18 章）。
- 传感器标定中，用几组已知的激励张成整个输入空间，才能唯一地确定线性模型的系数。若激励只张成一个子空间（例如所有试验都只沿一个方向加力），有些系数就辨识不出来。
