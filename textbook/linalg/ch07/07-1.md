### 7.1.1 问题的提出

机器人的关节轨迹是时间的函数 $\theta(t)$。两条轨迹可以相加（叠加一个修正量），可以乘以一个数（整体放大）；第 5 章用三次样条生成的轨迹，节点相同的任意两条样条，线性组合仍是同样节点上的三次样条。这和 $\mathbb R^n$ 中的向量何其相似！可是轨迹不是 $n$ 个数排成的一列，它有无穷多个“分量”（每个时刻一个）。

第 2—6 章的结论，有多少只依赖于“能相加、能数乘、满足运算律”，而与“是 $n$ 个数”无关？如果把这些运算规律单独提出来作为出发点，前面的结论就可以一次性地推广到多项式、函数、信号等一切满足这些规律的对象上。这就是向量空间的思想：不问向量“是什么”，只问它们“怎样运算”。

### 7.1.2 数域

数乘中的“数”从哪里取？到目前为止都是实数。但在信号处理和量子力学中要用复数，在编码和密码中要用只有 0 和 1 的“数”。我们只要求这些数能做加、减、乘、除四则运算。

**定义 7.1.1（数域）** 设 $\mathbb F$ 是一个包含 0 和 1 的数集。若 $\mathbb F$ 中任意两个数的和、差、积以及商（除数不为零）仍在 $\mathbb F$ 中，则称 $\mathbb F$ 为一个**数域**。

有理数集 $\mathbb Q$、实数集 $\mathbb R$、复数集 $\mathbb C$ 都是数域。整数集 $\mathbb Z$ 不是：$2$ 的倒数 ${{ex7_1.q_inv}}$ 不是整数。本书大多数情况下取 $\mathbb F = \mathbb R$，涉及特征值和傅里叶分析时取 $\mathbb C$。

更一般地，一个集合连同加法、乘法两种运算，若满足交换律、结合律、分配律，含有 0 和 1，每个元素有负元、每个非零元素有逆元，就称为一个**域**，它的元素不必是通常的数。数域是由数组成的域。最小的域是只有 0 和 1 两个元素的二元域 $\mathrm{GF}(2)$，规定 $1 + 1 = 0$（模 2 加法）。它的加法是 $0 + 0 = 0$，$0 + 1 = 1 + 0 = 1$，$1 + 1 = 0$。在 $\mathrm{GF}(2)^4$ 中，$(1, 0, 1, 1)^{\mathsf T} + (1, 1, 0, 1)^{\mathsf T} = {{ex7_1.gf2_sum}}$，而任何向量加上自己都是零向量：$\boldsymbol u + \boldsymbol u = {{ex7_1.gf2_self}}$。计算机中的奇偶校验、纠错码、二维码都在这个域上做线性代数：数据位 $(1, 0, 1, 1)$ 的奇偶校验位就是各位在 $\mathrm{GF}(2)$ 中的和 {{ex7_1.parity}}（第 28 章）。

### 7.1.3 向量空间的公理

**定义 7.1.2（向量空间）** 设 $V$ 是一个非空集合，$\mathbb F$ 是一个域（本书多数情况下是数域 $\mathbb R$ 或 $\mathbb C$）。在 $V$ 上定义了加法（任意 $\boldsymbol u, \boldsymbol v\in V$ 对应 $\boldsymbol u + \boldsymbol v\in V$）和数乘（任意 $c\in\mathbb F$、$\boldsymbol v\in V$ 对应 $c\boldsymbol v\in V$）。若对任意 $\boldsymbol u, \boldsymbol v, \boldsymbol w\in V$ 和 $c, d\in\mathbb F$，下列八条成立，则称 $V$ 为数域 $\mathbb F$ 上的**向量空间**（也称**线性空间**），$V$ 中的元素称为向量：

$$
\begin{aligned}
&(1)\ \boldsymbol u + \boldsymbol v = \boldsymbol v + \boldsymbol u; &&(2)\ (\boldsymbol u + \boldsymbol v) + \boldsymbol w = \boldsymbol u + (\boldsymbol v + \boldsymbol w);\\
&(3)\ \text{存在零向量 }\boldsymbol 0\text{，使 }\boldsymbol v + \boldsymbol 0 = \boldsymbol v; &&(4)\ \text{对每个 }\boldsymbol v\text{ 存在 }-\boldsymbol v\text{，使 }\boldsymbol v + (-\boldsymbol v) = \boldsymbol 0;\\
&(5)\ 1\boldsymbol v = \boldsymbol v; &&(6)\ c(d\boldsymbol v) = (cd)\boldsymbol v;\\
&(7)\ c(\boldsymbol u + \boldsymbol v) = c\boldsymbol u + c\boldsymbol v; &&(8)\ (c + d)\boldsymbol v = c\boldsymbol v + d\boldsymbol v .
\end{aligned} \tag{7.1.1}
$$

这八条正是 2.2 节对 $\mathbb R^n$ 列出的运算律，现在把它们当作定义。定义中已要求加法和数乘的结果仍在 $V$ 中，称为对加法和数乘**封闭**。本章的定义和定理只用到域中的四则运算，所以对 $\mathrm{GF}(2)$ 这样的有限域同样成立。检查一个集合是不是向量空间时，最常出问题的就是封闭性。

在 $\mathbb C$ 上，$\mathbb C^2$ 中 $\mathrm i\cdot(1, \mathrm i)^{\mathsf T} = {{ex7_1.cz}}^{\mathsf T}$，数乘可以用复数。$\mathbb C^n$ 既是 $\mathbb C$ 上的向量空间，也可以看成 $\mathbb R$ 上的向量空间（只允许实数数乘），两者的维数不同（习题 7.6.6）。

### 7.1.4 由公理推出的性质

**定理 7.1.1** 在任一向量空间中：

1. 零向量是唯一的；每个向量的负向量是唯一的；
2. $0\boldsymbol v = \boldsymbol 0$，$c\boldsymbol 0 = \boldsymbol 0$；
3. $(-1)\boldsymbol v = -\boldsymbol v$；
4. 若 $c\boldsymbol v = \boldsymbol 0$，则 $c = 0$ 或 $\boldsymbol v = \boldsymbol 0$。

*证明*　1：若 $\boldsymbol 0$、$\boldsymbol 0'$ 都是零向量，则 $\boldsymbol 0 = \boldsymbol 0 + \boldsymbol 0' = \boldsymbol 0'$（先用 $\boldsymbol 0'$ 是零向量，再用交换律和 $\boldsymbol 0$ 是零向量）。若 $\boldsymbol v'$、$\boldsymbol v''$ 都是 $\boldsymbol v$ 的负向量，则 $\boldsymbol v'' = \boldsymbol v'' + \boldsymbol 0 = \boldsymbol v'' + (\boldsymbol v + \boldsymbol v') = (\boldsymbol v'' + \boldsymbol v) + \boldsymbol v' = \boldsymbol 0 + \boldsymbol v' = \boldsymbol v'$（用了结合律和交换律）。2：$0\boldsymbol v = (0 + 0)\boldsymbol v = 0\boldsymbol v + 0\boldsymbol v$，两边加上 $-(0\boldsymbol v)$，用结合律和公理 (3)、(4) 得 $\boldsymbol 0 = 0\boldsymbol v$；$c\boldsymbol 0 = \boldsymbol 0$ 同理。3：$\boldsymbol v + (-1)\boldsymbol v = (1 + (-1))\boldsymbol v = 0\boldsymbol v = \boldsymbol 0$，由负向量的唯一性。4：若 $c\ne0$，则 $\boldsymbol v = 1\boldsymbol v = (c^{-1}c)\boldsymbol v = c^{-1}(c\boldsymbol v) = c^{-1}\boldsymbol 0 = \boldsymbol 0$。这里用到了 $c^{-1}\in\mathbb F$，即数域对除法封闭。　∎

这些性质在 $\mathbb R^n$ 中显而易见，证明却只用了八条公理，所以在任何向量空间中都成立。这正是公理方法的力量：证明一次，处处适用。

### 7.1.5 不是向量空间的例子

- *第一象限* $\{(x, y): x\ge0, y\ge0\}$：对加法封闭，但对数乘不封闭，$(-1)(1, 2)^{\mathsf T} = {{ex7_1.neg}}$ 跑出了第一象限。
- *第一个分量为 1 的向量* $\{\boldsymbol x\in\mathbb R^3: x_1 = 1\}$：$(1, 2, 3)^{\mathsf T} + (1, -1, 0)^{\mathsf T} = {{ex7_1.sum1}}$，第一个分量变成了 2，对加法不封闭；也不含零向量。
- *整数分量的向量* $\mathbb Z^n$：对加法封闭，但用实数（例如 $\tfrac12$）数乘后不再是整数向量。它在 $\mathbb Z$ 上满足八条运算律，但 $\mathbb Z$ 不是数域；这样的结构称为“模”，是另一门课程的内容。

### 7.1.6 生活中的例子

调酒师的配方是一个“向量”：各种基酒、果汁、糖浆的用量。两份配方可以混在一起（相加），一份配方可以按比例放大（数乘），混合与放大满足通常的运算规律。但“用量不能为负”使所有配方只构成一个“锥”，而不是向量空间：减去一份配方在厨房里做不到。数学上允许负数，换来的是一套干净、完整的理论；第 29 章再回来处理“必须非负”的约束。

**工程师笔记**

- 程序中的“向量”只是数组，向量空间的抽象在代码里体现为“只用加法和数乘写成的算法”。例如梯度下降、卡尔曼滤波的预测步，对多项式系数、离散信号、矩阵都适用，只要它们能加、能乘以数。
- 有限域上的线性代数（如 $\mathrm{GF}(2)$）不能用 NumPy 的浮点运算直接做，要用整数运算再取模，或者用专门的库（如 `galois`）。
- 判断一个“量”能否放进向量空间，先问两件事：两个这样的量相加有没有意义、乘以 $-1$ 有没有意义。概率分布、旋转矩阵都不能随意相加，它们不构成向量空间（旋转在第 31 章用李群处理）。
