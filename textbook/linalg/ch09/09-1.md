### 9.1.1 问题的提出

AGV 在车体坐标系中的速度是 $(0.4, 0.1)$ m/s，航向角 30°，它在车间（世界）坐标系中的速度是多少？多项式 $2 - x + 3x^2$ 的导数是什么？把一个向量投影到一条直线上，结果是什么？这三个问题看上去毫不相干，却有一个共同点：输入加倍，输出也加倍；两个输入相加，输出也相加。具有这种性质的映射称为线性映射。第 1 章已经见过它（1.1.2 节），本节在一般的向量空间上给出定义。

### 9.1.2 定义

**定义 9.1.1（线性映射）** 设 $V$、$W$ 是同一个数域 $\mathbb F$ 上的向量空间。映射 $T: V\to W$ 称为**线性映射**，如果对任意 $\boldsymbol u, \boldsymbol v\in V$ 和 $c\in\mathbb F$，

$$
T(\boldsymbol u + \boldsymbol v) = T(\boldsymbol u) + T(\boldsymbol v),\qquad T(c\boldsymbol v) = cT(\boldsymbol v) . \tag{9.1.1}
$$

两条合起来等价于：对任意 $a, b\in\mathbb F$，$T(a\boldsymbol u + b\boldsymbol v) = aT(\boldsymbol u) + bT(\boldsymbol v)$，即 $T$ 把线性组合映成同样系数的线性组合。$V = W$ 时，$T$ 也称为 $V$ 上的*线性变换*（线性算子）。第 4 章把 $\mathbb R^n\to\mathbb R^m$ 的线性映射也叫线性变换；从本章起，“线性变换”专指 $V\to V$ 的情形。

由定义立刻得到：$T(\boldsymbol 0) = T(0\cdot\boldsymbol 0) = 0\cdot T(\boldsymbol 0) = \boldsymbol 0$，线性映射总把零向量映成零向量；$T(-\boldsymbol v) = -T(\boldsymbol v)$；更一般地，$T(c_1\boldsymbol v_1 + \dots + c_k\boldsymbol v_k) = c_1T(\boldsymbol v_1) + \dots + c_kT(\boldsymbol v_k)$。

最常见的线性映射是矩阵乘法：$m\times n$ 矩阵 $A$ 给出 $T(\boldsymbol x) = A\boldsymbol x$，$\mathbb R^n\to\mathbb R^m$，由式 (4.1.4)，它是线性的。反过来，定理 4.1.2 说明 $\mathbb R^n\to\mathbb R^m$ 的线性映射都是矩阵乘法；9.3 节把它推广到一般的有限维空间：选定基后，线性映射都是矩阵乘法。

**定理 9.1.1** 线性映射由它在一组基上的值唯一确定。确切地说，设 $\boldsymbol v_1, \dots, \boldsymbol v_n$ 是 $V$ 的基，$\boldsymbol w_1, \dots, \boldsymbol w_n$ 是 $W$ 中任意 $n$ 个向量，则存在唯一的线性映射 $T: V\to W$，使 $T(\boldsymbol v_j) = \boldsymbol w_j$（$j = 1, \dots, n$）。

*证明*　每个 $\boldsymbol v\in V$ 可唯一地写成 $\boldsymbol v = c_1\boldsymbol v_1 + \dots + c_n\boldsymbol v_n$（定理 7.7.1）。若 $T$ 线性且 $T(\boldsymbol v_j) = \boldsymbol w_j$，则必有 $T(\boldsymbol v) = c_1\boldsymbol w_1 + \dots + c_n\boldsymbol w_n$，所以 $T$ 唯一。反过来，用这个式子定义 $T$：系数 $c_j$ 由 $\boldsymbol v$ 唯一确定，所以 $T$ 有定义；$a\boldsymbol u + b\boldsymbol v$ 的系数是 $\boldsymbol u$、$\boldsymbol v$ 的系数的同样组合，所以 $T(a\boldsymbol u + b\boldsymbol v) = aT(\boldsymbol u) + bT(\boldsymbol v)$。　∎

### 9.1.3 例子

**算例 9.1.1（求导与积分）** 设 $\mathcal P_n$ 是次数不超过 $n$ 的实系数多项式构成的空间（7.2 节；本章多项式的变量写作 $x$）。求导 $D: \mathcal P_3\to \mathcal P_3$，$D(p) = p'$，是线性映射：$(ap + bq)' = ap' + bq'$。取 $p = {{ex9_1.p}}$，$q = {{ex9_1.q}}$，程序 9.1.1 算得 $D(3p - 2q) = {{ex9_1.Dcomb}}$，而 $3D(p) - 2D(q) = {{ex9_1.combD}}$，两者相同。从 0 积分 $I: \mathcal P_3\to \mathcal P_4$，$I(p)(x) = \int_0^x p(t)\,\mathrm dt$，也是线性映射，例如 $I(p) = {{ex9_1.Ip}}$。求导与积分是微积分的两个基本运算，它们都是线性的，这就是线性代数在微分方程中大有用武之地的原因（第 16 章）。

**算例 9.1.2（旋转、投影、反射）** 平面上绕原点逆时针转 30°、向与 $x$ 轴成 30° 的直线投影、关于这条直线反射，矩阵分别是

$$
R = {{ex9_1.Rot}},\quad P = {{ex9_1.Proj}},\quad H = {{ex9_1.Refl}} . \tag{9.1.2}
$$

一般地，转角为 $\theta$ 的旋转矩阵是 $\begin{pmatrix}\cos\theta & -\sin\theta\\ \sin\theta & \cos\theta\end{pmatrix}$；向单位向量 $\boldsymbol u$ 方向的直线投影是 $P = \boldsymbol u\boldsymbol u^{\mathsf T}$（第 10 章），关于这条直线反射是 $H = 2\boldsymbol u\boldsymbol u^{\mathsf T} - I$：先投影得到直线上的点，再越过直线走同样远。图 9.1.1 画出了它们和一个剪切 $\begin{pmatrix}1 & 0.8\\ 0 & 1\end{pmatrix}$ 对网格的作用：旋转、反射、剪切都可逆，网格线变换后仍是等距的平行直线，原点不动；投影不可逆，它把整个网格压到 30° 的直线上（平行直线映成直线或点，习题 9.1.5）。程序 9.1.1 用随机的向量和系数检验了三个映射的线性，误差不超过 ${{ex9_1.lin_err}}$（舍入误差）。

**算例 9.1.3（车体坐标到世界坐标）** AGV 的航向角为 $\theta$ 时，车体坐标系中的速度 $\boldsymbol v_b$ 与世界坐标系中的速度 $\boldsymbol v_w$ 的关系是 $\boldsymbol v_w = R(\theta)\boldsymbol v_b$，这是一个旋转。$\theta = 30°$、$\boldsymbol v_b = {{ex9_1.vb}}$ m/s 时，$\boldsymbol v_w = {{ex9_1.vw}}$ m/s。注意这里变换的是速度（向量），不是位置：位置还要加上车体原点的坐标，那不再是线性映射。

**算例 9.1.4（不是线性映射的例子）** 平移 $T(\boldsymbol x) = \boldsymbol x + \boldsymbol s$（$\boldsymbol s\ne\boldsymbol 0$）不是线性映射：$T(\boldsymbol 0) = \boldsymbol s\ne\boldsymbol 0$。取 $\boldsymbol s = (1, 0.5)^{\mathsf T}$，$\boldsymbol x = (1, 2)^{\mathsf T}$，$\boldsymbol y = (-0.5, 1)^{\mathsf T}$，$T(\boldsymbol x + \boldsymbol y) = {{ex9_1.trsum}}$，而 $T(\boldsymbol x) + T(\boldsymbol y) = {{ex9_1.sumtr}}$。$f(x) = x^2$、$\|\boldsymbol x\|$、$\sin x$ 也都不是线性的。平移在机器人和图形学中无处不在；第 30、31 章用*齐次坐标*把平移也写成矩阵乘法，代价是把空间升高一维。

### 9.1.4 线性化：非线性世界里的线性映射

现实中的大多数映射是非线性的：机械臂的关节角到末端位置、相机的三维点到像素、电机的电压到转速。但在一点附近，光滑的非线性映射可以用线性映射来近似：$f(\boldsymbol x + \Delta\boldsymbol x)\approx f(\boldsymbol x) + J\Delta\boldsymbol x$，$J$ 是雅可比矩阵（第 1 章、第 32 章）。小位移之间的关系是线性映射，这正是线性代数能够处理非线性系统的原因。机械臂的雅可比矩阵把关节速度映成末端速度，第 8 章研究了它的四个子空间，9.7 节将看到它的对偶 $J^{\mathsf T}$ 把末端的力映成关节力矩。

### 9.1.5 生活中的例子

把一份菜谱的用量加倍，总热量也加倍；两道菜放在一起，热量相加：“用量 → 热量”是线性映射。可是“用量 → 好吃程度”就不是：盐放两倍，菜不会好吃两倍。判断一个关系是否线性，就是问这两件事：加倍是否加倍，相加是否相加。

**工程师笔记**

- 检验一段程序实现的映射是否线性，最简单的办法是像程序 9.1.1 那样随机抽样：对随机的 $\boldsymbol u$、$\boldsymbol v$、$a$、$b$ 比较 $T(a\boldsymbol u + b\boldsymbol v)$ 与 $aT(\boldsymbol u) + bT(\boldsymbol v)$。传感器的标定、滤波器的实现都可以这样做“线性度测试”。
- 线性映射可以不写成矩阵直接实现。例如求导在系数向量上只是“移位并乘以次数”，计算量与 $n$ 成正比；而把它写成 $n\times n$ 矩阵再相乘，计算量与 $n^2$ 成正比。大规模计算（第 25 章的迭代法）中，常常只提供“计算 $A\boldsymbol x$ 的函数”，而不存矩阵本身。
- 坐标系之间的变换要分清是变换向量（速度、力、位移：只转动）还是变换点（位置：转动加平移）。混淆二者是机器人程序中常见的错误。

**习题**

9.1.1 （概念）判断下列映射是否线性：(1) $T(x, y) = (x + y, x - y)$；(2) $T(x, y) = (x + 1, y)$；(3) $T(x, y) = (xy, x)$；(4) $T: \mathcal P_2\to\mathbb R$，$T(p) = p(1)$；(5) $T: \mathcal P_2\to\mathbb R$，$T(p) = p(0)p(1)$；(6) $T: \mathbb R^{2\times2}\to \mathbb R^{2\times2}$，$T(A) = A^{\mathsf T}$。

9.1.2 （证明）证明：$T$ 是线性映射当且仅当 $T(a\boldsymbol u + b\boldsymbol v) = aT(\boldsymbol u) + bT(\boldsymbol v)$ 对任意 $\boldsymbol u$、$\boldsymbol v$、$a$、$b$ 成立。

9.1.3 （计算）线性映射 $T: \mathbb R^2\to\mathbb R^3$ 满足 $T(1, 1) = (1, 0, 2)$，$T(1, -1) = (3, 2, 0)$。求 $T(5, 1)$ 和 $T$ 的矩阵。

9.1.4 （计算）写出关于直线 $y = x$ 的反射矩阵、向直线 $y = 2x$ 的投影矩阵，验证 $H^2 = I$、$P^2 = P$。

9.1.5 （证明）证明：线性映射把过原点的直线映成过原点的直线或原点，把平行直线映成平行直线或点。

9.1.6 （证明）$T: \mathbb R\to\mathbb R$ 满足 $T(x + y) = T(x) + T(y)$ 对一切实数成立，且 $T$ 连续。证明 $T(x) = cx$。（提示：先对整数、有理数证明。）

9.1.7 （编程）仿照程序 9.1.1，写一个函数 `is_linear(T, n, trials)`，对 $\mathbb R^n$ 上的映射做随机线性检验；用它检验 $\boldsymbol x\mapsto A\boldsymbol x$、$\boldsymbol x\mapsto A\boldsymbol x + \boldsymbol b$、$\boldsymbol x\mapsto\|\boldsymbol x\|\boldsymbol x$。

9.1.8 （机器人）AGV 的位姿为 $(x, y, \theta)$。说明“车体坐标系中的点 → 世界坐标系中的点”不是线性映射，而“车体坐标系中的速度 → 世界坐标系中的速度”是线性映射。
