title: 本章小结
---

本章的主线是一句话：**一个矩阵带着四个子空间，它们的维数由秩一个数决定**。

$m\times n$ 矩阵 $A$ 的列空间 $C(A)$ 是 $\mathbb R^m$ 中各列张成的子空间，$A\boldsymbol x = \boldsymbol b$ 有解当且仅当 $\boldsymbol b\in C(A)$；零空间 $N(A)$ 是 $\mathbb R^n$ 中 $A\boldsymbol x = \boldsymbol 0$ 的全部解。消元后，$A$ 的主元列是列空间的基，每个自由变量对应一个特殊解，它们是零空间的基。秩 $r$ 是主元的个数，它既是列空间的维数，也是行空间的维数：独立的列与独立的行一样多。秩为 $r$ 的矩阵可以写成 $A = CR_r$，即 $r$ 个秩一矩阵之和。

$A\boldsymbol x = \boldsymbol b$ 的完整解是一个特解加上零空间；相容条件来自 $R$ 的零行，也就是左零空间：$\boldsymbol y^{\mathsf T}A = \boldsymbol 0^{\mathsf T}$ 的 $\boldsymbol y$ 记录了方程之间的关系，有解时必有 $\boldsymbol y^{\mathsf T}\boldsymbol b = 0$。按 $r$ 与 $m$、$n$ 的关系，解的情形分为四种：可逆、列满秩、行满秩、秩亏。

四个子空间的维数是 $r$、$n - r$、$r$、$m - r$：$\mathbb R^n$ 被分成行空间与零空间，$\mathbb R^m$ 被分成列空间与左零空间。$A$ 在行空间与列空间之间一一对应，把零空间压成零，永远到不了左零空间的方向。由此得到秩的不等式：$\operatorname{rank}(AB)\le\min(\operatorname{rank}A, \operatorname{rank}B)$，西尔维斯特不等式，$\operatorname{rank}(A + B)\le\operatorname{rank}A + \operatorname{rank}B$，以及 $\operatorname{rank}(A^{\mathsf T}A) = \operatorname{rank}A$。

图的关联矩阵中，零空间是“电位可以整体差一个常数”，左零空间是回路，电流定律与电压定律就是四个子空间的关系，独立回路数为 $m - n + 1$。冗余机械臂的雅可比矩阵中，零空间是末端不动的自运动。

### 历史注记

| 年份 | 人物或文献 | 贡献 |
|---|---|---|
| 1845—1847 | 基尔霍夫 | 电路的电流定律与电压定律；用图的生成树分析电路方程组的解（1847） |
| 1884 | 西尔维斯特 | 提出“零化度”（nullity）一词与“零化度定律”，即乘积的秩的不等式 |
| 1879 | 弗罗贝尼乌斯 | 提出矩阵的秩（Rang）的概念，用不为零的子式的最高阶数定义它 |
| 1936 | 埃卡特、杨 | 用奇异值分解求最佳的低秩近似（第 18 章） |
| 1993 | 斯特朗 | 《线性代数基本定理》一文，提出“四个基本子空间”的全景图 |

“四个子空间”的提法在线性代数中由来已久，但把它们画成一幅全景图、作为整门课程的组织线索，是斯特朗在 20 世纪 70 年代以后的教材和 1993 年的文章中推广开来的。本书沿用这一组织方式。

### 部分习题答案与提示

8.1.1 简化行阶梯形的非零行为 $(1, 3, 0, -1)$、$(0, 0, 1, 1)$；列空间的基为第 1、3 列；零空间的基为 $(-3, 1, 0, 0)^{\mathsf T}$、$(1, 0, -1, 1)^{\mathsf T}$。

8.1.2 至少 2 维；至多 3 维。

8.1.4 例如各列为 $(1, -1, 0)^{\mathsf T}$、$(0, 1, -1)^{\mathsf T}$、$(1, 0, -1)^{\mathsf T}$。

8.2.1 1；2；2。

8.2.2 $C = \begin{pmatrix}1 & 0\\ 2 & 1\\ 1 & 1\end{pmatrix}$，$R_r = \begin{pmatrix}1 & 3 & 0 & 2\\ 0 & 0 & 1 & 1\end{pmatrix}$。

8.2.4 最大为 4；行满秩；对每个 $\boldsymbol b$ 都有解，但不唯一（零空间 2 维）。

8.3.1 $\boldsymbol x = (2, 0, 1, 0)^{\mathsf T} + c_1(-2, 1, 0, 0)^{\mathsf T} + c_2(-1, 0, -1, 1)^{\mathsf T}$。

8.3.2 $b_3 = 7$；$\boldsymbol x = (2, 0, 1, 0)^{\mathsf T} + c_1\boldsymbol s_1 + c_2\boldsymbol s_2$。

8.3.3 秩 3：无解或唯一解；秩 2：无解或无穷多解。

8.3.6 可以。$\dot{\boldsymbol\theta} = \dot{\boldsymbol\theta}_p + t\boldsymbol n$，取 $t$ 使第一个分量为零，得 $\dot{\boldsymbol\theta}\approx(0, -0.3718, 0.4714)^{\mathsf T}$ rad/s。

8.4.1 行空间的基 $(1, 0, -1)$、$(0, 1, 2)$；左零空间的基 $(2, -1, 0)^{\mathsf T}$。

8.4.2 $5b_1 - 2b_2 + b_3 = 0$。

8.5.1 3、4、3、1。

8.5.2 $3\times3$ 不行：两者维数之和为 3，不能都是 1。$2\times2$ 可以，如 $\begin{pmatrix}0 & 1\\ 0 & 0\end{pmatrix}$ 的列空间与零空间都是 $x$ 轴。

8.5.4 例如 $\begin{pmatrix}1 & 0 & -1\\ 0 & 1 & -1\\ 1 & 1 & -2\end{pmatrix}$。

8.5.6 一般位形：6、1、6、0；秩为 5 时：5、2、5、1。

8.6.1 $AB$（$5\times5$）的秩不超过 3，不可逆；$BA$（$3\times3$）可能可逆。

8.6.4 例如 $A = I$，$B = -I$：$\operatorname{rank}(A + B) = 0$。

8.6.7 $G$ 可逆时 $\operatorname{rank}(JG) = \operatorname{rank}J$（定理 8.6.2）。$G$ 有一列为零时，$\operatorname{rank}G = n - 1$，由定理 8.6.1 与 8.6.3，$\operatorname{rank}J - 1\le\operatorname{rank}(JG)\le\operatorname{rank}J$：六轴臂一般降为 5；七轴臂可能仍为 6。

8.7.1 秩 2；零空间由 $(1, 1, 1)$ 张成，左零空间由 $(1, 1, 1)$（绕回路一圈）张成，行空间与列空间都是二维的。

8.7.2 4 个独立回路，秩为 5。

8.7.4 左零空间只有零向量；没有回路，支路电流由节点电流唯一确定。

8.7.6 奇异值约为 2.147、1.384、0.660、0.383、0.092、0，秩为 5（腕部奇异）。零空间由 $(0, 0, 0.203, -1, 0, 0.797)^{\mathsf T}$ 张成：关节 3、4、6 按这个比例转动，末端不动。左零空间由 $(0.432, 0, -0.236, 0, 1, 0)^{\mathsf T}$ 张成（按 $(\boldsymbol\omega, \boldsymbol v)$ 排列）：末端速度在这个方向上的分量，无论关节怎样转都产生不了。
