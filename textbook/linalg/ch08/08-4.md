### 8.4.1 问题的提出

8.3 节的相容条件 $b_3 = b_1 + b_2$ 从哪里来？它来自“第 3 个方程是前两个方程之和”，这是方程（行）之间的关系，而列空间和零空间说的是列之间的关系。转置矩阵 $A^{\mathsf T}$ 的列就是 $A$ 的行，它也有列空间和零空间。这两个子空间补全了全景图。

### 8.4.2 定义

**定义 8.4.1** $A^{\mathsf T}$ 的列空间称为 $A$ 的**行空间**，记作 $C(A^{\mathsf T})$，它是 $A$ 的各行张成的 $\mathbb R^n$ 的子空间。$A^{\mathsf T}$ 的零空间称为 $A$ 的**左零空间**，记作 $N(A^{\mathsf T})$：

$$
N(A^{\mathsf T}) = \{\boldsymbol y\in\mathbb R^m : A^{\mathsf T}\boldsymbol y = \boldsymbol 0\} = \{\boldsymbol y : \boldsymbol y^{\mathsf T}A = \boldsymbol 0^{\mathsf T}\} . \tag{8.4.1}
$$

“左”的意思是 $\boldsymbol y^{\mathsf T}$ 乘在 $A$ 的左边。

### 8.4.3 两组基

**定理 8.4.1** 设 $A$ 的简化行阶梯形为 $R$，秩为 $r$。

1. $R$ 的 $r$ 个非零行构成 $C(A^{\mathsf T})$ 的一组基；
2. $N(A^{\mathsf T})$ 的维数为 $m - r$。设 $EA = R$（$E$ 是行变换的乘积，可逆），则 $E$ 的最后 $m - r$ 行构成 $N(A^{\mathsf T})$ 的一组基。

*证明*　1：定理 8.2.1 的证明已表明行变换不改变行空间，所以可以直接用 $R$ 的非零行，不必回到 $A$。2：$A^{\mathsf T}$ 是 $n\times m$ 矩阵，秩也是 $r$（定理 8.2.1），由定理 8.1.2 零空间维数为 $m - r$。$EA = R$ 的最后 $m - r$ 行全为零，即 $E$ 的这些行 $\boldsymbol y^{\mathsf T}$ 满足 $\boldsymbol y^{\mathsf T}A = \boldsymbol 0^{\mathsf T}$；$E$ 可逆，它的行线性无关，所以这 $m - r$ 行是 $N(A^{\mathsf T})$ 的基。　∎

对 (8.1.1)：行空间的基是 $(1, 2, 0, 1)$ 与 $(0, 0, 1, 1)$，是 $\mathbb R^4$ 中的二维子空间。左零空间是一维的，由 $\boldsymbol y = {{ex8_4.y}}$ 张成：$A^{\mathsf T}\boldsymbol y = {{ex8_4.yA}}$，即 $\boldsymbol y^{\mathsf T}A = \boldsymbol 0^{\mathsf T}$，它说的正是“第 1 行 + 第 2 行 − 第 3 行 = 0”。

### 8.4.4 左零空间与相容条件

若 $A\boldsymbol x = \boldsymbol b$ 有解，则对左零空间中的每个 $\boldsymbol y$，

$$
\boldsymbol y^{\mathsf T}\boldsymbol b = \boldsymbol y^{\mathsf T}A\boldsymbol x = \boldsymbol 0^{\mathsf T}\boldsymbol x = 0 . \tag{8.4.2}
$$

反过来也成立：$\boldsymbol b\in C(A)$ 当且仅当 $\boldsymbol b$ 与左零空间中的每个向量都正交。理由：设 $EA = R$，对增广矩阵消元得 $E(A\mid\boldsymbol b) = (R\mid E\boldsymbol b)$，$R$ 的最后 $m - r$ 个零行右端的数，正是 $E$ 的最后 $m - r$ 行（左零空间的基 $\boldsymbol y_i$）与 $\boldsymbol b$ 的乘积 $\boldsymbol y_i^{\mathsf T}\boldsymbol b$。它们全为零时没有矛盾方程，由定理 3.5.1 方程组有解。对 (8.1.1)，$\boldsymbol y^{\mathsf T}\boldsymbol b = b_1 + b_2 - b_3$，这就是相容条件 (8.3.1)。$\boldsymbol b = (1, 3, 4)^{\mathsf T}$ 时为 {{ex8_4.yb4:.0f}}，有解；$\boldsymbol b' = (1, 3, 5)^{\mathsf T}$ 时为 {{ex8_4.yb5:.0f}}，无解。

左零空间的意义可以这样理解：方程组的每个方程是一个“测量”，左零空间中的向量是测量之间的“冗余关系”。数据若满足这些关系，测量是自洽的；若不满足，至少有一个测量有误差。测量系统的“一致性检验”和故障诊断中的“残差生成”正是利用这一点。

### 8.4.5 一个预告：垂直关系

行空间的基 $(1, 2, 0, 1)$、$(0, 0, 1, 1)$ 与零空间的基 $\boldsymbol s_1 = (-2, 1, 0, 0)$、$\boldsymbol s_2 = (-1, 0, -1, 1)$ 两两的点积依次为 {{ex8_4.dots}}：全部为零。这不是巧合：$A\boldsymbol x = \boldsymbol 0$ 说的就是 $\boldsymbol x$ 与 $A$ 的每一行的点积为零，所以零空间中的每个向量都与行空间垂直。同样，左零空间与列空间垂直。第 10 章把这个关系写成基本定理的第二部分。

### 8.4.6 生活中的例子

三个人各自量一块长方形木板：甲量长，乙量宽，丙量长与宽之和。三个数之间应满足“丙 = 甲 + 乙”，这就是左零空间中的关系 $(1, 1, -1)$。若量出来“甲 + 乙 − 丙”不为零，就知道至少有一个人量错了，差值的大小还提示了误差有多大。

**工程师笔记**

- `scipy.linalg.null_space(A.T)` 求左零空间的基。测量系统中，把左零空间的基向量乘以测量值，得到的“残差”在无故障时为零（或在噪声水平内），这是解析冗余故障诊断的基本方法。
- 行空间的基用 $R$ 的非零行，列空间的基用 $A$ 的主元列：一个用变换后的矩阵，一个用变换前的矩阵，初学者常常混淆。
- 第 10 章的最小二乘中，残差 $\boldsymbol b - A\hat{\boldsymbol x}$ 恰好落在左零空间里；残差的大小就是“测量不自洽的程度”。
