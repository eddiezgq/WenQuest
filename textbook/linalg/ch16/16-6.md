### 16.6.1 问题的提出

前几节的系统都是“放手不管”的：给定初值，让它自己演化。控制工程要做的是加上输入，让系统按我们的意愿运动：关节转到指定角度、倒立摆立住、四足机器人落地不颤。现代控制理论用统一的“状态空间”形式描述这类问题，它的核心正是本章的矩阵指数和特征值。本节以一个关节伺服为例，预告第 34、35 章的内容：反馈怎样移动特征值，数字控制器的采样周期为什么不能太长。

### 16.6.2 状态空间模型

线性系统的状态空间模型为

$$
\dot{\boldsymbol x} = A\boldsymbol x + B\boldsymbol u,\qquad \boldsymbol y = C\boldsymbol x, \tag{16.6.1}
$$

$\boldsymbol x$ 是状态（$n$ 维），$\boldsymbol u$ 是输入（电机力矩、电压），$\boldsymbol y$ 是测量（编码器读数）。这里沿用控制理论的习惯记号：$C$ 是输出矩阵，与 16.4 节的阻尼矩阵无关；下文的反馈增益 $K$ 也与刚度矩阵无关。由 (16.2.5)，

$$
\boldsymbol x(t) = e^{At}\boldsymbol x_0 + \int_0^te^{A(t-s)}B\boldsymbol u(s)\,\mathrm ds . \tag{16.6.2}
$$

**算例 16.6.1** 关节伺服：转动惯量 $J = 0.01$ kg·m²，黏性摩擦 $b = 0.1$ N·m·s/rad，电机力矩 $u$：$J\ddot\theta = -b\dot\theta + u$。取 $\boldsymbol x = (\theta, \omega)$，

$$
A = {{ex16_6.A}},\qquad B = {{ex16_6.B}},\qquad C = \begin{pmatrix}1 & 0\end{pmatrix} .
$$

开环特征值为 0 和 $-b/J = -10$ s⁻¹。特征值 0 对应“转到哪里停在哪里”：不加控制，关节不会自己回到指定角度。

### 16.6.3 状态反馈移动特征值

用全部状态做反馈：$u = -K\boldsymbol x = -(k_p\theta + k_d\omega)$（这就是 PD 控制）。闭环系统为

$$
\dot{\boldsymbol x} = (A - BK)\boldsymbol x . \tag{16.6.3}
$$

$A - BK$ 的特征值由我们选择的 $K$ 决定。本例的特征多项式为 $s^2 + \frac{b + k_d}Js + \frac{k_p}J$。希望闭环特征值在 $-20\pm20\mathrm i$（阻尼比 $\zeta = {{ex16_6.zeta:.3f}}$，衰减时间约 $4/20 = 0.2$ s），即特征多项式为 $s^2 + 40s + 800$，对比系数得

$$
k_p = 800J = {{ex16_6.kp:.0f}}\ \text{N·m/rad},\qquad k_d = 40J - b = {{ex16_6.kd:.1f}}\ \text{N·m·s/rad},
$$

程序 16.6.1 验证 $A - BK = {{ex16_6.Acl}}$ 的特征值确实是 $-20\pm20\mathrm i$。这种方法称为极点配置。一般的问题是：给定 $A$、$B$，能否通过选 $K$ 把 $A - BK$ 的特征值放到任意位置？答案是“当且仅当 $(B, AB, \dots, A^{n-1}B)$ 满秩”，称为能控性（35.2 节、35.3 节）；如何“最优地”选 $K$，是线性二次型调节器（35.5 节）。实际中只能测到 $\boldsymbol y = C\boldsymbol x$（编码器只测 $\theta$），$\omega$ 要由观测器或卡尔曼滤波估计（第 34 章、35.2 节的能观性）。

### 16.6.4 数字控制：零阶保持离散化

控制器每隔 $T$ 秒采样一次状态，算出 $\boldsymbol u_k = -K\boldsymbol x_k$，在下一个采样之前保持不变（零阶保持）。$\boldsymbol u$ 在 $[kT, (k+1)T)$ 内是常数，由 (16.6.2)，

$$
\boldsymbol x_{k+1} = A_d\boldsymbol x_k + B_d\boldsymbol u_k,\qquad A_d = e^{AT},\quad B_d = \int_0^Te^{As}\,\mathrm ds\,B . \tag{16.6.4}
$$

这是精确的，没有近似。$A_d$、$B_d$ 可以一次算出：

$$
\exp\left(\begin{pmatrix}A & B\\ O & O\end{pmatrix}T\right) = \begin{pmatrix}A_d & B_d\\ O & I\end{pmatrix} \tag{16.6.5}
$$

（习题 16.6.3）。$T = 5$ ms 时，程序 16.6.1 求得 $A_d = {{ex16_6.Ad}}$，$B_d = {{ex16_6.Bd}}$。数字控制的闭环是 $\boldsymbol x_{k+1} = (A_d - B_dK)\boldsymbol x_k$，稳定的条件是 $A_d - B_dK$ 的特征值的模都小于 1（13.5 节）。

用同样的 $K$，闭环特征值的最大模为：$T = 5$ ms 时 {{ex16_6.rho5:.3f}}（连续极点映射过来是 $e^{-20T} = {{ex16_6.map5:.3f}}$，几乎一样），20 ms 时 {{ex16_6.rho20:.3f}}，40 ms 时 {{ex16_6.rho40:.3f}}。采样周期再变长，特征值离开单位圆，$T$ 超过约 {{ex16_6.Tcrit_ms:.0f}} ms 时系统失稳（图 16.6.1 (b)）。从 0 转到 1 rad 的阶跃指令，连续控制的超调为 {{ex16_6.over_c:.1f}}%，$T = 5$ ms 的数字控制为 {{ex16_6.over_d:.1f}}%，两条曲线最大相差 {{ex16_6.dev_max:.3f}} rad（图 16.6.1 (a)）。经验上，采样频率至少要是闭环带宽的 10～20 倍，数字控制器才与按连续系统设计的效果接近。

### 16.6.5 本章方法在控制中的位置

| 本章 | 控制理论中的对应 | 位置 |
|---|---|---|
| $e^{At}$、(16.6.2) | 状态转移矩阵、响应公式 | 35.1 节 |
| 特征值实部 < 0 | 稳定性；李雅普诺夫方程 $A^{\mathsf T}P + PA = -Q$（$P$ 正定，第 15 章） | 35.4 节 |
| $A - BK$ 的特征值 | 极点配置、能控性 | 35.2、35.3 节 |
| 二次型 $\boldsymbol x^{\mathsf T}Q\boldsymbol x + \boldsymbol u^{\mathsf T}R\boldsymbol u$ 的最小化 | 线性二次型调节器、里卡蒂方程 | 35.5 节 |
| 协方差的传播 $P\leftarrow A_dPA_d^{\mathsf T} + Q$ | 卡尔曼滤波 | 34.2 节 |
| (16.6.4) | 离散时间系统 | 35.1 节 |

**工程师笔记**

- 工业伺服驱动器的电流环常在 10～20 kHz 采样，速度环 2～5 kHz，位置环 1 kHz 左右：内环快、外环慢，每一层的采样频率都远高于它的带宽。
- 零阶保持相当于在控制回路里引入约 $T/2$ 的延迟。采样周期接近失稳边界之前，相位裕度就已经很差，响应会明显振荡（图 16.6.1 (a) 的 40 ms 曲线）。
