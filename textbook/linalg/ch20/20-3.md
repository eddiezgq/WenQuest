### 20.3.1 问题的提出

3.1 节的铸造车间用三种回炉料配 100 kg 铜合金，解一个 3 阶方程组 $M\boldsymbol x = \boldsymbol b$，$M$ 的三列是三种料的成分（铜、锌、锡的质量分数）。回炉料的成分是化验出来的，化验有误差。设每个质量分数都有约 0.3 个百分点的误差，算出的配料量会差多少？

程序 20.3.1 做了这样的试验：按真实成分取一组配料量 $\boldsymbol x = {{ex20_3.xt}}$ kg 算出目标 $\boldsymbol b$，再给成分矩阵加上标准差 0.003 的随机误差，用“化验值”解方程，重复 2000 次。

- 用 3.1 节原来的三种料 A、B、C：配料量的标准差为 ${{ex20_3.sd0}}$ kg，相对误差的中位数约 {{ex20_3.rel0:.1%}}。
- 把料 C 换成另一批料 C′，成分 $(0.70, 0.24, 0.06)$：标准差变为 ${{ex20_3.sd1}}$ kg，相对误差的中位数约 {{ex20_3.rel1:.0%}}，有 {{ex20_3.neg1:.1f}}% 的情形算出了负的用量（图 20.3.1）。

同样大小的化验误差，后一组料的配料量几乎不可信。原因是 C′ 几乎就是 A、B 各一半的混合物 $(0.70, 0.25, 0.05)$：三个列向量几乎共面（3.1 节工程师笔记的预言），$M$ 接近奇异。本节用一个数量化“接近奇异”的程度：条件数。

### 20.3.2 右端的误差

先看最简单的情形：$A$ 精确，右端 $\boldsymbol b$ 有误差 $\delta\boldsymbol b$。设 $A$ 可逆，$A\boldsymbol x = \boldsymbol b$，$A(\boldsymbol x + \delta\boldsymbol x) = \boldsymbol b + \delta\boldsymbol b$，则 $\delta\boldsymbol x = A^{-1}\delta\boldsymbol b$。由相容性 (20.2.3)，$\lVert\delta\boldsymbol x\rVert\le\lVert A^{-1}\rVert\lVert\delta\boldsymbol b\rVert$，又 $\lVert\boldsymbol b\rVert\le\lVert A\rVert\lVert\boldsymbol x\rVert$。两式相乘：

**定理 20.3.1** 设 $A$ 可逆，$\boldsymbol b\ne\boldsymbol 0$，则

$$
\frac{\lVert\delta\boldsymbol x\rVert}{\lVert\boldsymbol x\rVert}\le\kappa(A)\frac{\lVert\delta\boldsymbol b\rVert}{\lVert\boldsymbol b\rVert},\qquad \kappa(A) = \lVert A\rVert\,\lVert A^{-1}\rVert . \tag{20.3.1}
$$

**定义 20.3.1（条件数）** 可逆矩阵 $A$ 的**条件数**为 $\kappa(A) = \lVert A\rVert\lVert A^{-1}\rVert$。用 $p$-范数时记 $\kappa_p(A)$。

由 $1 = \lVert I\rVert = \lVert AA^{-1}\rVert\le\lVert A\rVert\lVert A^{-1}\rVert$，$\kappa(A)\ge1$。$\kappa(cA) = \kappa(A)$：条件数不随整体缩放而变，它度量的是*相对*误差的放大倍数。用 2-范数时，$\lVert A\rVert_2 = \sigma_1$，$\lVert A^{-1}\rVert_2 = 1/\sigma_n$（$A^{-1}$ 的奇异值是 $1/\sigma_i$），所以

$$
\kappa_2(A) = \frac{\sigma_1}{\sigma_n} . \tag{20.3.2}
$$

几何上：$A$ 把单位球变成椭球，$\kappa_2$ 是椭球最长轴与最短轴之比，即椭球“扁”的程度。

界 (20.3.1) 是可以达到的。由 SVD，$\boldsymbol b$ 沿 $\boldsymbol u_1$（$\boldsymbol x$ 沿 $\boldsymbol v_1$，被放大最多，所以 $\lVert\boldsymbol x\rVert$ 相对 $\lVert\boldsymbol b\rVert$ 最小）、$\delta\boldsymbol b$ 沿 $\boldsymbol u_n$（被 $A^{-1}$ 放大 $1/\sigma_n$ 倍）时，两个不等号同时取等。对料 C′ 的矩阵

$$
M' = {{ex20_3.M1}},
$$

奇异值为 ${{ex20_3.s1}}$，$\kappa_2(M') = {{ex20_3.k1:.1f}}$，而原来的 $\kappa_2(M) = {{ex20_3.k0:.1f}}$（1-范数的条件数分别为 {{ex20_3.k1_1:.0f}} 和 {{ex20_3.k0_1:.1f}}，量级相同）。程序取 $\boldsymbol b = M'\boldsymbol x$（$\boldsymbol x = {{ex20_3.xt}}$），$\delta\boldsymbol b$ 沿 $\boldsymbol u_3$、大小 0.1 kg，得 $\delta\boldsymbol x = {{ex20_3.dx}}$ kg，相对误差被放大了 {{ex20_3.amp:.1f}} 倍，几乎就是 $\kappa_2$；把 $\boldsymbol b$ 也换成沿 $\boldsymbol u_1$ 的方向，放大倍数恰为 {{ex20_3.amp_w:.1f}}。注意 $\delta\boldsymbol x$ 的三个分量 $(−, −, +)$：多用 C′、少用 A 和 B，几乎不改变总成分，正是“C′ ≈ A、B 对半混合”的方向。

### 20.3.3 矩阵的误差

成分本身有误差，扰动的是矩阵。

**定理 20.3.2** 设 $A$ 可逆，$\boldsymbol b\ne\boldsymbol 0$，$(A + \delta A)(\boldsymbol x + \delta\boldsymbol x) = \boldsymbol b + \delta\boldsymbol b$，且 $\kappa(A)\dfrac{\lVert\delta A\rVert}{\lVert A\rVert} < 1$，则 $A + \delta A$ 可逆，且

$$
\frac{\lVert\delta\boldsymbol x\rVert}{\lVert\boldsymbol x\rVert}\le\frac{\kappa(A)}{1 - \kappa(A)\lVert\delta A\rVert/\lVert A\rVert}\left(\frac{\lVert\delta A\rVert}{\lVert A\rVert} + \frac{\lVert\delta\boldsymbol b\rVert}{\lVert\boldsymbol b\rVert}\right). \tag{20.3.3}
$$

*证明*　$A + \delta A = A(I + A^{-1}\delta A)$，$\lVert A^{-1}\delta A\rVert\le\lVert A^{-1}\rVert\lVert\delta A\rVert = \kappa\lVert\delta A\rVert/\lVert A\rVert < 1$，由习题 20.2.5，$I + A^{-1}\delta A$ 可逆。展开并消去 $A\boldsymbol x = \boldsymbol b$：$(A + \delta A)\delta\boldsymbol x = \delta\boldsymbol b - \delta A\,\boldsymbol x$，所以 $\delta\boldsymbol x = (I + A^{-1}\delta A)^{-1}A^{-1}(\delta\boldsymbol b - \delta A\,\boldsymbol x)$。取范数，用习题 20.2.5 的界和 $\lVert\boldsymbol b\rVert\le\lVert A\rVert\lVert\boldsymbol x\rVert$ 即得。　∎

扰动很小时，(20.3.3) 的分母接近 1：*解的相对误差至多约为条件数乘数据的相对误差*。配料的例子中，2000 次试验的 $\lVert\delta A\rVert_2/\lVert A\rVert_2$ 中位数为 {{ex20_3.dA_rel:.2%}}，乘以 $\kappa_2$ 得 {{ex20_3.kdA:.2f}}，已经接近定理的前提 $\kappa\lVert\delta A\rVert/\lVert A\rVert < 1$ 的边界：(20.3.3) 的分母接近 0，给出的相对误差界约为 {{ex20_3.bound:.1f}}，几乎不起约束作用。实际相对误差的中位数为 {{ex20_3.rel1:.0%}}，还有 {{ex20_3.neg1:.1f}}% 的情形算出了负的用量：误差已经大到与解本身相当。

一条实用的经验：*数据有 $d$ 位有效数字，条件数为 $10^k$，解大约只有 $d - k$ 位可信*。化验结果大约 2～3 位有效数字，$\kappa\approx150$ 吃掉两位多，所剩无几。

### 20.3.4 条件数是到奇异矩阵的距离

条件数大，矩阵就“接近奇异”。这句话可以精确化：

**定理 20.3.3** 设 $A$ 是 $n$ 阶可逆矩阵，则

$$
\min\left\{\frac{\lVert\delta A\rVert_2}{\lVert A\rVert_2} : A + \delta A\ \text{奇异}\right\} = \frac{1}{\kappa_2(A)} . \tag{20.3.4}
$$

*证明*　$A + \delta A$ 奇异即秩不超过 $n - 1$。由埃卡特–杨定理（定理 18.4.1），秩不超过 $n - 1$ 的矩阵到 $A$ 的谱范数距离至少为 $\sigma_n$，在 $\delta A = -\sigma_n\boldsymbol u_n\boldsymbol v_n^{\mathsf T}$ 时取到。除以 $\lVert A\rVert_2 = \sigma_1$。　∎

程序 20.3.1 按证明中的 $\delta A$ 构造了离 $M'$ 最近的奇异矩阵（秩为 {{ex20_3.rankMs}}）：

$$
{{ex20_3.Ms}},
$$

主要是锡的那一行变了千分之几，相对距离 {{ex20_3.dist:.5f}}，恰为 $1/\kappa_2 = {{ex20_3.inv_k:.5f}}$。化验误差的大小（{{ex20_3.dA_rel:.2%}}）与这个距离相当：在化验精度之内，$M'$ 与奇异矩阵几乎分不开。

### 20.3.5 条件数的几条性质

- **正交矩阵最好**：$\kappa_2(Q) = 1$，用正交变换解方程或做变换，不放大相对误差（11.1 节）。
- **形成 $A^{\mathsf T}A$ 使条件数平方**：$A^{\mathsf T}A$ 的奇异值是 $\sigma_i^2$，所以 $\kappa_2(A^{\mathsf T}A) = \kappa_2(A)^2$。程序验证 $\kappa_2(M'^{\mathsf T}M') = {{ex20_3.kAtA:.0f}}$，$\kappa_2(M')^2 = {{ex20_3.k1sq:.0f}}$。这就是 10.4 节说正规方程会“丢掉一半有效数字”、19.3 节说主成分分析要用 SVD 的原因。
- **条件数与单位有关**：若料 C′ 的用量改用吨计，$M'$ 的第三列乘 1000，问题本身没有变，$\kappa_2$ 却从 {{ex20_3.k1:.0f}} 变为 {{ex20_3.kt:.0f}}。把各列缩放到等长后又回到 {{ex20_3.kbal:.0f}}。报告条件数时要说明变量的单位；解病态方程之前，先把各列（各变量）缩放到相近的量级，称为平衡。
- **行列式小不等于病态**：$\det(0.1I_{10}) = 10^{-10}$，但 $\kappa(0.1I) = 1$。判断病态看条件数，不看行列式。

**工程师笔记**

- `numpy.linalg.cond(A)` 用 SVD 算 $\kappa_2$，代价与解方程组相当或更高。大型问题用 LAPACK 的条件数估计（`scipy.linalg.lapack.dgecon` 等），只需 $O(n^2)$ 次运算，给出 1-范数条件数的可靠估计。
- 病态的根源往往在问题的提法：配料时三种料“几乎共面”，测量时传感器几乎平行，定位时路标几乎与车共线（实验 20.3），拟合时基函数几乎线性相关（20.6 节）。最好的补救是改变提法：换一种料、调整传感器的布置、选别的路标、换一组正交的基函数。
- 条件数只说明*最坏情况*。实际误差是否达到这个程度，要看误差的方向（20.3.2 节）。蒙特卡罗试验是检查实际影响的好办法。
