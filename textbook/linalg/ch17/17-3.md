### 17.3.1 问题的提出

16.1 节用特征向量把 $\boldsymbol u' = A\boldsymbol u$ 拆成互不相干的模态，前提是特征向量够用。不够用时，能不能退一步：按特征值把空间分成几块，每块内部也许纠缠在一起，但块与块之间互不干扰？这样，一个大系统的分析就分解成若干个“只有一个特征值”的小系统，每个小系统再用 17.1 节的若尔当链处理。本节说明这总是可以做到的，分出来的块就是根子空间。

### 17.3.2 根子空间

**定义 17.3.1** 设 $\lambda_i$ 是 $A$ 的特征值，代数重数为 $m_i$。称

$$
G_{\lambda_i} = N\left((A - \lambda_iI)^{m_i}\right) \tag{17.3.1}
$$

为属于 $\lambda_i$ 的**根子空间**（也叫广义特征空间）。它由属于 $\lambda_i$ 的全部广义特征向量和零向量组成，包含特征空间 $E_{\lambda_i} = N(A - \lambda_iI)$。

**定理 17.3.1（根子空间分解）** 设 $A$ 的特征多项式为 $p(\lambda) = (\lambda - \lambda_1)^{m_1}\cdots(\lambda - \lambda_s)^{m_s}$（$\lambda_i$ 互不相同）。则

1. 每个 $G_{\lambda_i}$ 都是 $A$ 的不变子空间，$\dim G_{\lambda_i} = m_i$；
2. $\mathbb C^n = G_{\lambda_1}\oplus G_{\lambda_2}\oplus\dots\oplus G_{\lambda_s}$；
3. 投影到 $G_{\lambda_i}$（沿其余各根子空间）的矩阵 $P_i$ 是 $A$ 的多项式。

*证明*　令 $q_i(\lambda) = p(\lambda)/(\lambda - \lambda_i)^{m_i}$。$q_1, \dots, q_s$ 没有公共根，由多项式的贝祖等式，存在多项式 $a_i$ 使 $\sum_ia_iq_i = 1$。令 $P_i = a_i(A)q_i(A)$，则

- $\sum_iP_i = I$；
- $i\ne j$ 时 $q_iq_j$ 含有完整的 $p$ 作为因子，由凯莱–哈密顿定理 $P_iP_j = O$，于是 $P_i = P_i\sum_jP_j = P_i^2$，$P_i$ 是投影；
- $(A - \lambda_iI)^{m_i}P_i = a_i(A)p(A) = O$，所以 $C(P_i)\subseteq G_{\lambda_i}$；反过来，若 $\boldsymbol v\in G_{\lambda_i}$，$j\ne i$ 时 $q_j$ 含因子 $(\lambda - \lambda_i)^{m_i}$，$P_j\boldsymbol v = \boldsymbol 0$，于是 $\boldsymbol v = \sum P_j\boldsymbol v = P_i\boldsymbol v\in C(P_i)$。

所以 $G_{\lambda_i} = C(P_i)$，$\mathbb C^n = \sum C(P_i)$，且由 $P_iP_j = O$ 知这个和是直和。$P_i$ 是 $A$ 的多项式，与 $A$ 交换，$G_{\lambda_i}$ 不变。最后，$A$ 限制在 $G_{\lambda_i}$ 上只有特征值 $\lambda_i$（若 $A\boldsymbol v = \mu\boldsymbol v$，$\boldsymbol v\in G_{\lambda_i}$，则 $(\mu - \lambda_i)^{m_i}\boldsymbol v = \boldsymbol 0$），在这些子空间的基下 $A$ 是分块对角的，特征多项式是各块特征多项式之积，所以第 $i$ 块的阶数就是 $m_i$。　∎

现在可以补上定理 17.2.2 (3) 的另一半：若最小多项式 $m = \prod(\lambda - \lambda_i)$ 没有重根，对 $m$ 做同样的论证，得到 $\mathbb C^n = \bigoplus N(A - \lambda_iI)$，即全空间是各特征空间的直和，$A$ 可对角化。

### 17.3.3 算例

**算例 17.3.1** $A = {{ex17_3.A}}$，特征多项式 ${{ex17_3.char}}$。程序 17.3.1 求得：

- 属于 1：特征空间 $E_1$ 只有 {{ex17_3.dimE1}} 维（由 ${{ex17_3.E1}}^{\mathsf T}$ 张成），根子空间 $G_1 = N((A - I)^2)$ 有 {{ex17_3.dimG1}} 维，基为 ${{ex17_3.G1}}$（转置）；
- 属于 $-1$：$E_{-1} = G_{-1}$，{{ex17_3.dimGm}} 维，基为 ${{ex17_3.Gm}}$（转置）。

四个基向量线性无关，$\mathbb C^4 = G_1\oplus G_{-1}$。$E_{-1} = G_{-1}$ 说明最小多项式是 $(\lambda - 1)^2(\lambda + 1)$，$(A - I)^2(A + I) = O$；用它代替特征多项式做定理 17.3.1 的论证更简单（取 $q_1 = \lambda + 1$、$q_2 = (\lambda - 1)^2$）。贝祖等式为 $\tfrac14(\lambda - 1)^2 + \tfrac{3 - \lambda}4(\lambda + 1) = 1$，于是

$$
P_1 = \tfrac14(3I - A)(A + I) = {{ex17_3.P1}},\qquad P_{-1} = \tfrac14(A - I)^2 = {{ex17_3.Pm}} .
$$

程序验证 $P_1 + P_{-1} = I$，$P_1^2 = P_1$，$P_1P_{-1} = O$。

### 17.3.4 $A = D + N$：可对角化部分与幂零部分

由根子空间分解，令

$$
D = \lambda_1P_1 + \dots + \lambda_sP_s,\qquad N = A - D . \tag{17.3.2}
$$

$D$ 在每个 $G_{\lambda_i}$ 上就是数乘 $\lambda_i$，可对角化；$N$ 在 $G_{\lambda_i}$ 上是 $A - \lambda_iI$，幂零；$D$、$N$ 都是 $A$ 的多项式，彼此交换。这称为若尔当–谢瓦莱分解，它是唯一的（习题 17.3.5）。算例 17.3.1 中

$$
D = {{ex17_3.D}},\qquad N = {{ex17_3.N}},
$$

$N^2 = O$，$DN = ND$（程序验证）。因为 $D$、$N$ 交换，由定理 16.2.1，

$$
e^{At} = e^{Dt}e^{Nt} = \Big(\sum_ie^{\lambda_it}P_i\Big)\Big(I + Nt + \dots + \frac{N^{k-1}t^{k-1}}{(k-1)!}\Big) . \tag{17.3.3}
$$

其中 $k$ 是 $N$ 的幂零指数（$N^k = O$）。这就是 $t^je^{\lambda t}$ 项的来源：$e^{\lambda_it}$ 来自可对角化部分，$t$ 的多项式来自幂零部分。程序 17.3.1 用 (17.3.3) 算出 $e^{At}$，与 SymPy 的精确矩阵指数一致。

(17.3.3) 也推广了 16.1 节的模态叠加：$\boldsymbol u(t) = \sum_ie^{\lambda_it}\big(I + Nt + \dots\big)P_i\boldsymbol u_0$。初始状态先投影到各根子空间（$P_i\boldsymbol u_0$），各自按 $e^{\lambda_it}$ 乘一个 $t$ 的多项式演化，互不干扰。

**工程师笔记**

- 根子空间分解在控制中称为“模态分解”：大系统的状态空间按特征值分组，快、慢模态分开设计（奇异摄动方法），不稳定模态单独处理。数值上不用贝祖等式，而是先求舒尔形，再解西尔维斯特方程消去舒尔形的非对角块（17.7.4 节）。
- (17.3.3) 说明：只要所有 $\operatorname{Re}\lambda_i < 0$，不论幂零部分多大，$e^{At}\to O$（定理 16.3.1）；但幂零部分会让瞬态先放大再衰减，放大倍数可能很大。
