title: 本章提要
---

线性代数研究的对象，说起来很简单：向量、矩阵，以及满足“比例”与“叠加”两条规则的映射。可正是这两条朴素的规则，让它成为现代科学与工程中用得最广的数学。机械臂每个控制周期要算的坐标变换，相机拍下的每一张图像，搜索引擎给网页的排序，神经网络里的每一层运算，归根结底都是线性代数的计算。原因之一是线性问题能够彻底解决；原因之二是大量非线性问题在局部可以用线性问题很好地近似。

本章是全书的导论，不要求任何线性代数的预备知识。它回答四个问题：“线性”究竟是什么意思（1.1 节）；同一个矩阵为什么可以看成方程组、几何变换和数据表三样东西（1.2 节）；线性代数为什么无处不在（1.3 节）；它是怎样一步步发展起来的（1.4 节）。随后两节准备全书要用的两样工具：阅读和书写证明的方法（1.5 节），以及用 Python 和 NumPy 做计算的方法（1.6 节）。最后一节给出全书的路线图、几种开课方式的章节选择，以及贯穿全书的几台机器人和几组数据（1.7 节）。

本章只用到高中数学：函数、方程组、平面直角坐标系和三角函数。书中第一次出现的记号和名词，都会先用日常的话说清楚它是什么，再给出定义；更系统的处理留给第 2 章及以后各章。

学完本章，读者应能：

1. 用比例和叠加两条性质判断一个映射是否线性，并说明 $y = ax + b$（$b\ne 0$）为什么不是线性映射；
2. 对一个 2×2 线性方程组，分别画出它的行图和列图，并把系数矩阵看作平面上的几何变换；
3. 举出机器人、图像、网页排序和神经网络中各一个用到矩阵运算的例子；
4. 叙述《九章算术》方程术的要点，并说出线性代数发展史上的几个节点；
5. 区分命题与它的逆命题、逆否命题，读懂并写出简单的直接证明、反证法和数学归纳法证明；
6. 写出并运行一个用 NumPy 数组做向量和矩阵运算、解线性方程组的 Python 程序；
7. 根据自己的课程或兴趣，按 1.7 节的路线表选出要读的章节。
