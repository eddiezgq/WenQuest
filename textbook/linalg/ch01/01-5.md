### 1.5.1 问题的提出

工程师常问：既然程序能算出结果，为什么还要证明？看一个著名的例子。欧拉注意到，式子 $n^2 + n + 41$ 在 $n = 0, 1, 2, \dots$ 时给出 41、43、47、53、61……全是质数。逐个检验，直到 $n = 39$ 都是质数。是否可以断言它对一切 $n$ 都给出质数？不行：程序 1.5.1 发现，$n = {{ex1_5.euler_n}}$ 时它等于 {{ex1_5.euler_v}} $= {{ex1_5.euler_sqrt}}^2$，不是质数。四十个例子都对，仍然不能保证第四十一个也对。

工程上的“例子都对”同样不可靠。一个控制算法在一百次仿真中都稳定，不等于它在所有工况下都稳定；一个矩阵公式对随机生成的一千个矩阵都成立，可能恰恰在某种特殊结构的矩阵上失效。证明的作用，就是给出一个对一切情形都成立的保证，并且说清楚这个保证在什么条件下成立。本书的定理都附有证明，学会读证明，是用好本书的前提；而写出简单的证明，是检验自己是否真正理解的最好办法。本节介绍读写证明所需的最基本的知识。

### 1.5.2 命题与它的几种变形

数学中能判断真假的陈述称为**命题**。最常见的命题形如“若 $P$，则 $Q$”，记作 $P\Rightarrow Q$。$P$ 称为条件，$Q$ 称为结论。例如：

> 命题甲：若 $f$ 是线性映射，则 $f(0) = 0$。

这是 1.1 节的命题 1.1.1，它是真的。由一个命题可以构造出三个相关的命题：

**逆命题**（$Q\Rightarrow P$）：若 $f(0) = 0$，则 $f$ 是线性映射。它是假的，$f(x) = x^2$ 满足 $f(0) = 0$，但不是线性映射。

**否命题**（非 $P\Rightarrow$ 非 $Q$）：若 $f$ 不是线性映射，则 $f(0)\ne 0$。它也是假的，反例仍是 $f(x) = x^2$。

**逆否命题**（非 $Q\Rightarrow$ 非 $P$）：若 $f(0)\ne 0$，则 $f$ 不是线性映射。它是真的。

一个命题与它的逆否命题总是同真同假，所以证明逆否命题等于证明了原命题。1.1 节用命题 1.1.1 判断 $y = 2x + 1$ 不是线性映射，用的正是逆否命题。逆命题则与原命题没有必然联系：原命题真，逆命题可能真也可能假。混淆命题与它的逆命题，是推理中最常见的错误之一。

若 $P\Rightarrow Q$ 为真，称 $P$ 是 $Q$ 的**充分条件**，$Q$ 是 $P$ 的**必要条件**。若 $P\Rightarrow Q$ 与 $Q\Rightarrow P$ 都为真，称 $P$ 与 $Q$ 互为**充要条件**，写作“$P$ 当且仅当 $Q$”，记作 $P\Leftrightarrow Q$。证明一个“当且仅当”的命题，要分别证明两个方向，定理 1.1.1 的证明就是这样分成“当”与“仅当”两部分的。

许多命题含有“对一切”或“存在”这样的词。“对一切实数 $x$、$y$，$f(x + y) = f(x) + f(y)$”的否定，不是“对一切 $x$、$y$ 都不成立”，而是“存在实数 $x$、$y$，使 $f(x + y)\ne f(x) + f(y)$”。这一区别直接决定了下面两种证明方法的分工：要证明一个“对一切”的命题，必须给出一般的论证；要否定它，只需一个反例。

### 1.5.3 反例

1.5.1 节的欧拉例子说明，“对一切”的命题不能靠举例证明；反过来，一个反例就足以否定它。看一个线性代数中的例子：

> 命题乙：对一切 2×2 矩阵 $A$、$B$，$AB = BA$。

矩阵的乘法在第 4 章定义，这里只需要知道它可以由程序计算。程序 1.5.1 随机生成整数元素的矩阵，第 {{ex1_5.trial}} 次就找到了反例：$A = {{ex1_5.A}}$，$B = {{ex1_5.B}}$，此时 $AB = {{ex1_5.AB}}$，而 $BA = {{ex1_5.BA}}$。命题乙是假的：矩阵乘法一般不能交换次序。这一事实在后面反复出现，1.3.2 节的转动推广到三维后就不能交换次序：先绕 $x$ 轴转再绕 $z$ 轴转，与先绕 $z$ 轴转再绕 $x$ 轴转，结果不同。

找反例时，先试最简单的情形：零、一、对角矩阵、只有一个非零元的矩阵。程序的随机试验是寻找反例的好帮手，但要记住它只能否定命题，不能证明命题。

### 1.5.4 直接证明

直接证明从条件出发，经过一步步正确的推理，得到结论。看一个与第 3、8 章密切相关的例子。

**命题 1.5.1** 设 $\boldsymbol u = (u_1, u_2)^{\mathsf T}$ 和 $\boldsymbol w = (w_1, w_2)^{\mathsf T}$ 都是方程 $a_1x_1 + a_2x_2 = 0$ 的解，$c$ 是任意实数。则 $\boldsymbol u + \boldsymbol w$ 和 $c\boldsymbol u$ 也都是这个方程的解。

*证明*　由条件，$a_1u_1 + a_2u_2 = 0$，$a_1w_1 + a_2w_2 = 0$。$\boldsymbol u + \boldsymbol w$ 的两个分量是 $u_1 + w_1$ 和 $u_2 + w_2$，代入方程左边：

$$
a_1(u_1 + w_1) + a_2(u_2 + w_2) = (a_1u_1 + a_2u_2) + (a_1w_1 + a_2w_2) = 0 + 0 = 0 .
$$

所以 $\boldsymbol u + \boldsymbol w$ 是解。同理，$a_1(cu_1) + a_2(cu_2) = c(a_1u_1 + a_2u_2) = c\cdot 0 = 0$，$c\boldsymbol u$ 也是解。　∎

这个命题说：右边为零的线性方程，它的解对加法和数乘“封闭”。第 7 章把这样的集合称为子空间。注意证明中每一步都有依据：分配律、结合律、条件中的两个等式。写证明时，每一步的依据应当清楚到读者无需猜测。

### 1.5.5 反证法

反证法先假设结论不成立，从这个假设推出矛盾（与条件矛盾，或与已知的事实矛盾），从而断定结论成立。最经典的例子是：

**命题 1.5.2** $\sqrt 2$ 不是有理数。

*证明*　假设 $\sqrt 2$ 是有理数，则可写成 $\sqrt 2 = p/q$，$p$、$q$ 是正整数，并且这个分数已经约到最简，$p$ 与 $q$ 没有公因数。两边平方得 $p^2 = 2q^2$，所以 $p^2$ 是偶数。奇数的平方是奇数，所以 $p$ 也是偶数，设 $p = 2k$。代回得 $4k^2 = 2q^2$，即 $q^2 = 2k^2$，同理 $q$ 也是偶数。于是 $p$、$q$ 有公因数 2，与“已经约到最简”矛盾。所以假设不成立，$\sqrt 2$ 不是有理数。　∎

反证法在线性代数中用得很多，尤其是证明某个东西“唯一”或“不存在”的时候。例如第 7 章证明“基中向量的个数是唯一确定的”，就是假设两组基的向量个数不同，推出矛盾。使用反证法时，要清楚地写出“假设……”，并指明矛盾在哪里。

### 1.5.6 数学归纳法

要证明一个对一切正整数 $n$ 成立的命题 $P(n)$，数学归纳法分两步：

1. **奠基**：证明 $P(1)$ 成立；
2. **归纳**：假设 $P(k)$ 成立（归纳假设），证明 $P(k + 1)$ 也成立。

两步都完成后，$P(1)$ 成立，于是 $P(2)$ 成立，于是 $P(3)$ 成立……如同推倒一排多米诺骨牌，对一切 $n$ 都成立。

**命题 1.5.3** 平面上的剪切变换 $S$ 把点 $(x, y)$ 映为 $(x + y, y)$。则对一切正整数 $n$，连续做 $n$ 次剪切，把 $(x, y)$ 映为 $(x + ny, y)$。

*证明*　奠基：$n = 1$ 时，结论就是 $S$ 的定义。

归纳：假设连续做 $k$ 次剪切把 $(x, y)$ 映为 $(x + ky, y)$。再做一次剪切，按 $S$ 的定义，第一个坐标加上第二个坐标，得 $((x + ky) + y,\ y) = (x + (k + 1)y,\ y)$。这正是 $n = k + 1$ 时的结论。由数学归纳法，命题对一切正整数 $n$ 成立。　∎

用矩阵的语言（第 4 章），命题 1.5.3 就是 $\begin{pmatrix}1&1\\0&1\end{pmatrix}^n = \begin{pmatrix}1&n\\0&1\end{pmatrix}$。程序 1.5.1 对 $n = 1, \dots, {{ex1_5.ind_n}}$ 逐个验证了这个等式。这样的验证有助于发现错误，但正如 1.5.1 节所说，它不能代替证明：一百个例子都对，不能保证第一百零一个也对；是归纳法保证了它对一切 $n$ 都对。

### 1.5.7 怎样读一个证明

本书的定理大多按“定理—证明的思路—证明”的格式写出。读证明时，可以按下面的顺序：

先读懂定理在说什么。弄清每个记号的含义，最好举一个具体的小例子，看看定理对它说了什么。然后读“证明的思路”，把握主线：证明大致分几步，关键的想法是什么。再逐行读证明，每读一步问自己：这一步的依据是什么？用到了哪个条件、哪个定义、哪个前面的结论？如果某一步看不懂，在旁边用具体的数验证一下，往往就明白了。最后合上书，试着自己把证明的主线复述出来。

本书用“定义”给出概念的准确含义，用“定理”表述重要的结论，用“引理”表述为证明定理而准备的辅助结论，用“推论”表述由定理直接得到的结论，用“命题”表述规模较小的结论。证明结束处标记“∎”。

### 1.5.8 生活中的例子

侦探排除嫌疑人，常用的就是反证法：“假设是他作案，那么九点钟他应该在现场；可是九点钟他在千里之外的会议上发言，有几十人作证。矛盾。所以不是他。”法律上的“不在场证明”正是一个反证法的论证。而“这家店我吃过三次都很好吃，所以它的菜一定都好吃”则犯了 1.5.1 节所说的错误：有限的例子不能证明“一切”。

**工程师笔记**

- 读工程文献中的结论时，留意它的条件。“该算法收敛”通常附带“若矩阵正定”“若步长足够小”之类的条件，条件不满足时结论可能完全失效。很多现场故障，源于把定理用在了它的条件之外。
- 程序测试与数学证明互补：证明保证一般情形，测试抓住实现中的笔误。对一个公式，先在几个手算得出的简单例子上测试，再用随机数据测试“恒等式两边相等”，是很有效的查错办法。
- 写技术文档时，把“若……则……”和“当且仅当”用准确。设计规范中的“必须”“充分”“必要”，与数学中的含义相同，写错了会造成误解。
