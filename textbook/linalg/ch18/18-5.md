### 18.5.1 问题的提出

机械臂抓取工件之前，相机要测出工件的姿态，即工件坐标系相对机器人基座的旋转矩阵 $R$。由于标定误差、图像噪声和计算中的舍入，测得的矩阵 $R_{\mathrm{m}}$ 往往不严格满足 $R^{\mathsf T}R = I$：它的三列长度不完全是 1，也不完全两两垂直。这样的矩阵若直接用于后续计算，误差会在连乘中累积；若用于控制，机器人会被要求做一个“不可能的”带拉伸的转动。工程上需要把 $R_{\mathrm{m}}$ 修正为一个真正的旋转矩阵，而且修正量要尽可能小。

这个问题的答案来自奇异值分解的一个直接推论：任何方阵都可以写成“一个正交矩阵乘一个半正定对称矩阵”，正如任何复数都可以写成“模乘一个单位复数” $z = re^{i\varphi}$。后者称为复数的极坐标形式，前者因此称为矩阵的极分解。

### 18.5.2 极分解定理

先回忆一个事实：对称半正定矩阵 $P$ 有谱分解 $P = Q\Lambda Q^{\mathsf T}$，$\Lambda = \operatorname{diag}(\lambda_1,\dots,\lambda_n)$，$\lambda_i\ge 0$。令 $P^{1/2} = Q\Lambda^{1/2}Q^{\mathsf T}$，$\Lambda^{1/2} = \operatorname{diag}(\sqrt{\lambda_1},\dots,\sqrt{\lambda_n})$，则 $P^{1/2}$ 也是对称半正定的，且 $(P^{1/2})^2 = Q\Lambda^{1/2}Q^{\mathsf T}Q\Lambda^{1/2}Q^{\mathsf T} = P$。

**定义 18.5.1（半正定平方根）** 称上述 $P^{1/2}$ 为对称半正定矩阵 $P$ 的**半正定平方根**。

**引理 18.5.1** 对称半正定矩阵的半正定平方根是唯一的：若 $S$ 对称半正定且 $S^2 = P$，则 $S = P^{1/2}$。

*证明*　设 $S$ 对称半正定，$S^2 = P$。取 $S$ 的谱分解 $S = W M W^{\mathsf T}$，$M = \operatorname{diag}(\mu_1,\dots,\mu_n)$，$\mu_i\ge 0$。则 $P = S^2 = W M^2 W^{\mathsf T}$，即 $S$ 的特征向量 $\boldsymbol w_i$ 也是 $P$ 的特征向量，对应的特征值是 $\mu_i^2$。设 $\lambda$ 是 $P$ 的任一特征值，$E_\lambda$ 是对应的特征空间。由于 $P$ 的特征空间互相正交且合起来张成全空间，$E_\lambda$ 正是由满足 $\mu_i^2 = \lambda$（即 $\mu_i = \sqrt\lambda$，因为 $\mu_i\ge 0$）的那些 $\boldsymbol w_i$ 张成的。所以在 $E_\lambda$ 上，$S$ 的作用是乘以 $\sqrt\lambda$；而按定义，$P^{1/2}$ 在 $E_\lambda$ 上的作用也是乘以 $\sqrt\lambda$。两个矩阵在每个特征空间上作用相同，而这些特征空间合起来张成全空间，所以 $S = P^{1/2}$。　∎

**定理 18.5.1（极分解）** 任何实方阵 $A\in\mathbb R^{n\times n}$ 都可以写成

$$
A = QS, \tag{18.5.1}
$$

其中 $Q$ 是正交矩阵，$S$ 是对称半正定矩阵。$S = (A^{\mathsf T}A)^{1/2}$ 是唯一的；若 $A$ 可逆，则 $S$ 正定，$Q = AS^{-1}$ 也唯一。

*证明*　存在性：取 $A$ 的奇异值分解 $A = U\Sigma V^{\mathsf T}$（方阵时 $\Sigma$ 是 $n\times n$ 对角矩阵）。在中间插入 $V^{\mathsf T}V = I$：

$$
A = U\Sigma V^{\mathsf T} = (UV^{\mathsf T})(V\Sigma V^{\mathsf T}). \tag{18.5.2}
$$

令 $Q = UV^{\mathsf T}$，它是两个正交矩阵的乘积，仍是正交矩阵；令 $S = V\Sigma V^{\mathsf T}$，它对称，特征值 $\sigma_i\ge 0$，是半正定的。

唯一性：若 $A = QS$，$Q$ 正交、$S$ 对称半正定，则 $A^{\mathsf T}A = SQ^{\mathsf T}QS = S^2$，由引理 18.5.1，$S = (A^{\mathsf T}A)^{1/2}$，与 $Q$ 的选取无关。若 $A$ 可逆，则 $S^2 = A^{\mathsf T}A$ 正定（引理 18.2.1），$S$ 的特征值都为正，$S$ 可逆，$Q = AS^{-1}$ 随之唯一确定。　∎

在式 (18.5.2) 中换一种方式插入 $U^{\mathsf T}U = I$，得到另一种极分解 $A = (U\Sigma U^{\mathsf T})(UV^{\mathsf T}) = S'Q$，即先转动、后伸缩。两种写法中的正交因子 $Q = UV^{\mathsf T}$ 是同一个。

**几何意义。** $A\boldsymbol x = Q(S\boldsymbol x)$：先由 $S$ 沿互相垂直的 $n$ 根轴 $\boldsymbol v_1,\dots,\boldsymbol v_n$ 分别伸缩 $\sigma_1,\dots,\sigma_n$ 倍（$S\boldsymbol v_i = \sigma_i\boldsymbol v_i$），再由 $Q$ 整体转动（或反射）。与 18.2.3 节“转—伸缩—转”相比，极分解把第一次转动和伸缩合并成了“沿某些方向的纯伸缩” $S$。连续介质力学中，物体一小块的变形由一个 3×3 矩阵 $F$（变形梯度）描述。它的极分解 $F = R_FS_F$ 把变形分成纯伸缩 $S_F$（力学书中常记作 $U$，称为右伸长张量，与本章的左奇异矩阵无关）和刚体转动 $R_F$：材料的应变只取决于 $S_F$，转动本身不使材料产生应变。

**算例 18.5.1** 求 $A = \begin{pmatrix}3&0\\4&5\end{pmatrix}$ 的极分解。由 18.1 节，$\sigma_1 = \sqrt{45} = 3\sqrt 5$，$\sigma_2 = \sqrt 5$，$\boldsymbol v_1 = (1, 1)^{\mathsf T}/\sqrt 2$，$\boldsymbol v_2 = (1, -1)^{\mathsf T}/\sqrt 2$。于是

$$
S = \sigma_1\boldsymbol v_1\boldsymbol v_1^{\mathsf T} + \sigma_2\boldsymbol v_2\boldsymbol v_2^{\mathsf T}
= \frac{3\sqrt 5}{2}\begin{pmatrix}1&1\\1&1\end{pmatrix} + \frac{\sqrt 5}{2}\begin{pmatrix}1&-1\\-1&1\end{pmatrix}
= \sqrt 5\begin{pmatrix}2&1\\1&2\end{pmatrix},
$$

$$
Q = AS^{-1} = \begin{pmatrix}3&0\\4&5\end{pmatrix}\cdot\frac{1}{3\sqrt 5}\begin{pmatrix}2&-1\\-1&2\end{pmatrix} = \frac{1}{\sqrt 5}\begin{pmatrix}2&-1\\1&2\end{pmatrix}.
$$

$Q$ 的行列式为 1，是转过 $\arctan(1/2)\approx {{ex18_5.qdeg:.2f}}^\circ$ 的旋转矩阵。程序 18.5.1 给出 $Q = {{ex18_5.Q}}$，$S = {{ex18_5.S}}$，与手算相同。所以 $A$ 的作用是：先沿 $\boldsymbol v_1$ 方向伸长 $3\sqrt 5$ 倍、沿 $\boldsymbol v_2$ 方向伸长 $\sqrt 5$ 倍，再整体逆时针转约 26.6°（图 18.5.1）。

### 18.5.3 最近的正交矩阵

回到 18.5.1 节的问题。下面的定理说明，极分解中的正交因子正是离 $A$ 最近的正交矩阵。

**定理 18.5.2** 设 $A\in\mathbb R^{n\times n}$，$A = U\Sigma V^{\mathsf T}$。在全体 $n\times n$ 正交矩阵中，$Q = UV^{\mathsf T}$ 使 $\lVert A - Q\rVert_F$ 最小。

*证明*　对正交矩阵 $Q$，$\lVert Q\rVert_F^2 = n$（各列都是单位向量）。利用 $\lVert X\rVert_F^2 = \operatorname{tr}(X^{\mathsf T}X)$（迹见 13.3 节）展开：

$$
\lVert A - Q\rVert_F^2 = \lVert A\rVert_F^2 + n - 2\operatorname{tr}(Q^{\mathsf T}A).
$$

前两项与 $Q$ 无关，所以问题化为使 $\operatorname{tr}(Q^{\mathsf T}A)$ 最大。代入 $A = U\Sigma V^{\mathsf T}$，利用迹的性质 $\operatorname{tr}(XY) = \operatorname{tr}(YX)$：

$$
\operatorname{tr}(Q^{\mathsf T}U\Sigma V^{\mathsf T}) = \operatorname{tr}(V^{\mathsf T}Q^{\mathsf T}U\,\Sigma) = \operatorname{tr}(Z\Sigma) = \sum_{i=1}^n z_{ii}\sigma_i ,
$$

其中 $Z = V^{\mathsf T}Q^{\mathsf T}U$ 是三个正交矩阵的乘积，也是正交矩阵，它的每一列都是单位向量，所以 $\lvert z_{ii}\rvert\le 1$。于是 $\operatorname{tr}(Q^{\mathsf T}A)\le\sigma_1 + \cdots + \sigma_n$，等号在 $Z = I$ 时成立，即 $V^{\mathsf T}Q^{\mathsf T}U = I$，$Q = UV^{\mathsf T}$。　∎

需要注意，$UV^{\mathsf T}$ 是最近的**正交**矩阵，它的行列式可能是 −1（含一次反射）。旋转矩阵还要求行列式为 +1。若 $\det(UV^{\mathsf T}) = -1$，最近的旋转矩阵是

$$
R = U\operatorname{diag}(1, \dots, 1, -1)\,V^{\mathsf T}, \tag{18.5.3}
$$

即把最小奇异值对应的那一项变号；这一结论的证明在第 31 章求最佳旋转时给出。当测量误差不大时，$R_{\mathrm m}$ 接近一个旋转矩阵，$\det(UV^{\mathsf T}) = +1$，不会出现这种情形。

**算例 18.5.2** 相机测得某工件的姿态矩阵为（保留三位小数）

$$
R_{\mathrm m} = {{ex18_5.Rm}}.
$$

它的三个奇异值为 {{ex18_5.sm}}，都接近而不等于 1，这正说明它不是正交矩阵：若是，奇异值应全为 1（习题 18.2.1）。偏离程度可以用 $\lVert R_{\mathrm m}^{\mathsf T}R_{\mathrm m} - I\rVert_F = {{ex18_5.orth_m:.4f}}$ 衡量。由定理 18.5.2，修正后的矩阵为

$$
R = UV^{\mathsf T} = {{ex18_5.Rq}},
$$

它的 $\lVert R^{\mathsf T}R - I\rVert_F$ 只有 $ {{ex18_5.orth_q:sci1}} $（舍入误差），$\det R = {{ex18_5.detq:.4f}}$，是真正的旋转矩阵；修正量 $\lVert R_{\mathrm m} - R\rVert_F = {{ex18_5.dist_mq:.4f}}$。本例的测量数据是在已知的真实姿态上加噪声模拟的，修正后的 $R$ 与真实姿态之间的相对转角为 {{ex18_5.err_true:.2f}}°（即 $R_1^{\mathsf T}R_2$ 的转角 $\arccos\frac{\operatorname{tr}(R_1^{\mathsf T}R_2) - 1}{2}$）。

一种常见的“偷懒”做法是只把每一列除以它的长度。这样得到的各列长度为 1，但仍不两两垂直：本例中 $\lVert R^{\mathsf T}R - I\rVert_F$ 仍有 {{ex18_5.naive_orth:.4f}}，与修正前相差无几。

### 18.5.4 生活中的例子

揉过的一块面团放在案板上，与原来相比它被压扁、拉长，还整体转了个方向。极分解告诉我们，无论揉面的过程多么复杂，只要最终的变形是均匀的，它都等价于两步：先沿三个互相垂直的方向分别拉伸或压缩，再整体转动。判断面团“被揉了多少”，只需要看第一步的伸缩量 $S$；第二步的转动 $Q$ 只是换了个摆放方向，面团本身并没有因此改变。

下一节讨论奇异值分解在求解线性方程组方面的推论：当方程组无解或有无穷多解时，怎样选出“最好”的那个解。

**工程师笔记**

- 正交化在机器人软件中随处可见：姿态矩阵经过成千上万次乘法后，舍入误差会使它逐渐偏离正交矩阵，控制器通常每隔若干步用 SVD（或等价的方法）修正一次。三维情形下也可以改用单位四元数表示姿态（第 31 章），只需把四元数归一化，计算量更小。
- 格拉姆–施密特法也能把矩阵正交化，但结果依赖于列的顺序：第一列只被单位化，误差全部被推到后面的列上。用极分解（SVD）修正，所有列被“公平地”对待，而且在弗罗贝尼乌斯范数下修正量最小。
- 用式 (18.5.3) 修正旋转矩阵时，若发现 $\det(UV^{\mathsf T}) = -1$，往往说明输入数据有严重问题（例如坐标系的左右手搞反了），应先查原因，而不是一修了之。
