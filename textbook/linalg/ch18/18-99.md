title: 本章小结
---

本章的主线可以用一句话概括：**任何矩阵都把单位球变成椭球**。椭球各半轴的长度是奇异值，半轴方向是左奇异向量，它们的原像方向是右奇异向量。其余的内容，都是从不同角度表达、计算和使用这句话。

我们从一个 2×2 矩阵出发，用介值定理证明了平面上总有一对互相垂直的方向，变换后仍然互相垂直；这对方向的像就是椭圆的两根半轴。推广到任意 $m\times n$ 矩阵时，介值定理不再适用，代之以对称矩阵 $A^{\mathsf T}A$ 的谱定理：它的标准正交特征向量经 $A$ 变换后仍然两两正交，由此得到奇异值分解 $A = U\Sigma V^{\mathsf T}$。几何上，它把任何线性变换分解为“转—伸缩—转”。奇异值唯一确定，奇异向量在符号上有自由，本书约定每个右奇异向量中第一个绝对值最大的分量为正。

奇异值分解一次给出了四个基本子空间的标准正交基：前 $r$ 个右奇异向量张成行空间，其余的张成零空间；前 $r$ 个左奇异向量张成列空间，其余的张成左零空间。$A$ 在行空间与列空间之间只是沿 $r$ 根正交轴伸缩。在计算中，秩要按阈值判断；阈值的依据是奇异值对扰动的稳定性 $\lvert\sigma_i(A + E) - \sigma_i(A)\rvert\le\lVert E\rVert_2$，对测量数据取误差矩阵最大奇异值的估计。小奇异值对应的右奇异向量揭示了数据中近似成立的线性关系。

奇异值分解有三个重要推论。埃卡特–杨定理说，截断的前 $k$ 项是秩不超过 $k$ 的矩阵中离 $A$ 最近的，谱范数误差为 $\sigma_{k+1}$，弗罗贝尼乌斯范数误差为其后各奇异值的平方和的平方根；这是数据压缩和降维的理论基础。极分解 $A = QS$ 把方阵分为正交矩阵与对称半正定矩阵之积，其中 $Q = UV^{\mathsf T}$ 是离 $A$ 最近的正交矩阵，用于修正带误差的旋转矩阵。伪逆 $A^+ = V\Sigma^+U^{\mathsf T}$ 给出最小二乘解中长度最小的一个，统一处理了无解与无穷多解两种情形，在冗余机械臂中给出最小范数关节速度，零空间则留给次要任务。

在应用中，截断奇异值分解能以少量存储近似一张图像，误差由被丢掉的奇异值精确给出，但它只保证整体误差最小。机械臂雅可比矩阵的奇异值刻画了末端在各方向上的运动能力：最小奇异值趋于零就是奇异位形，可操作度与条件数是两个常用的综合指标；混合单位的雅可比矩阵，奇异值的大小与长度单位有关，判断奇异性却不受影响。

| 左奇异向量 | 椭球的半轴方向 |

### 历史注记

| 年份 | 人物 | 贡献 |
|---|---|---|
| 1873 | 贝尔特拉米 | 在研究双线性型时得到方阵的奇异值分解 |
| 1874 | 若尔当 | 独立得到同一结果，给出更完整的论述 |
| 1889 | 西尔维斯特 | 再次独立发现，并给出由 $A^{\mathsf T}A$ 求奇异值的方法 |
| 1907 | 施密特 | 积分方程的奇异函数展开与最佳逼近定理 |
| 1936 | 埃卡特、杨 | 把奇异值分解推广到长方阵，证明低秩逼近定理 |
| 1955 | 彭罗斯 | 用四个条件刻画广义逆（摩尔在 1920 年已有定义） |
| 1965 | 戈卢布、卡汉 | 稳定的双对角化方法，为数值计算奠定基础 |
| 1970 | 戈卢布、赖因施 | 在双对角矩阵上迭代求奇异值的实用算法 |
| 1985 | 吉川恒夫 | 提出机械臂的可操作度 |

奇异值分解的历史在斯图尔特（G. W. Stewart）1993 年的综述中有详细的介绍。“奇异值”一名据说来自积分方程理论：使某个积分算子“奇异”的参数值。

### 部分习题答案与提示

18.1.1 $\sigma_1 = 3$，$\sigma_2 = 2$。可取 $\boldsymbol v_1 = \boldsymbol e_2$，$\boldsymbol u_1 = -\boldsymbol e_2$；$\boldsymbol v_2 = \boldsymbol e_1$，$\boldsymbol u_2 = \boldsymbol e_1$。负号放在 $\boldsymbol u_1$ 与 $\boldsymbol v_1$ 之一上，奇异值本身总是非负的。

18.1.2 $\lVert A\boldsymbol x\rVert^2 = \frac32 + \sin 2\varphi - \frac12\cos 2\varphi$，最大值 $\frac32 + \frac{\sqrt 5}{2}$，最小值 $\frac32 - \frac{\sqrt 5}{2}$，故 $\sigma_{1,2} = (\sqrt 5\pm 1)/2$，乘积为 1。

18.1.6 $J = \begin{pmatrix}-l_1/2 - l_2\sqrt 3/2 & -l_2\sqrt 3/2\\ l_1\sqrt 3/2 - l_2/2 & -l_2/2\end{pmatrix}$；两根半轴约为 0.650 m/s 和 0.256 m/s（见 18.7.2 节的表），比 60° 时更“圆”。

18.2.2 $\sigma_1 = 2$，$\boldsymbol u_1 = (1, 1, 0)^{\mathsf T}/\sqrt 2$，$\boldsymbol v_1 = (1, 1)^{\mathsf T}/\sqrt 2$；$A = 2\boldsymbol u_1\boldsymbol v_1^{\mathsf T}$。完整形式中 $\boldsymbol u_2$、$\boldsymbol u_3$ 可取 $(1, -1, 0)^{\mathsf T}/\sqrt 2$ 与 $(0, 0, 1)^{\mathsf T}$，$\boldsymbol v_2 = (1, -1)^{\mathsf T}/\sqrt 2$。

18.2.3 $\sigma_1 = 2\sqrt 2$，$\sigma_2 = \sqrt 2$。按本书的符号约定，$\boldsymbol v_2 = (1, -1)^{\mathsf T}/\sqrt 2$，$U = \operatorname{diag}(1, -1)$，$U$、$V$ 都含反射；把 $\boldsymbol u_2$、$\boldsymbol v_2$ 同时变号，得 $A = I\cdot\operatorname{diag}(2\sqrt 2, \sqrt 2)\cdot R(-45^\circ)$，即 $\alpha = 0$，$\beta = 45^\circ$。

18.4.1 $\lVert A\rVert_2 = 10$，$\lVert A\rVert_F = \sqrt{12601}/10$；秩 2 逼近的误差为 1（谱范数）和 $\sqrt{1.01}$（弗罗贝尼乌斯范数）。

18.4.2 $A_1 = \frac{3}{2}\begin{pmatrix}1&1\\3&3\end{pmatrix}$，$A - A_1 = \frac12\begin{pmatrix}3&-3\\-1&1\end{pmatrix}$，其谱范数为 $\sqrt 5$。

18.5.2 $Q = \frac{1}{\sqrt 5}\begin{pmatrix}2&1\\-1&2\end{pmatrix}$，转过 $-\arctan\frac12$；$S = \frac{1}{\sqrt 5}\begin{pmatrix}2&1\\1&3\end{pmatrix}$。剪切等于沿两个正交方向的伸缩再接一次转动。

18.6.1 (1) $\operatorname{diag}(1/2, 0, 1/5)$；(2) $O_{2\times 3}$；(3) $\boldsymbol a^{\mathsf T}/\lVert\boldsymbol a\rVert^2$。

18.6.2 $A^+ = \frac14\begin{pmatrix}1&1&0\\1&1&0\end{pmatrix}$，$\boldsymbol x^+ = (1, 1)^{\mathsf T}$，残差 $A\boldsymbol x^+ - \boldsymbol b = (1, -1, -2)^{\mathsf T}$，长度 $\sqrt 6$。

18.7.2 $\sigma_{1,2}^2 = \frac12\bigl(s\pm\sqrt{s^2 - 4l_1^2l_2^2\sin^2\theta_2}\bigr)$，$s = l_1^2 + 2l_2^2 + 2l_1l_2\cos\theta_2$；肩关节的转动只是把整个机构绕原点转动，不改变雅可比矩阵的奇异值（习题 18.2.4）。

18.7.3 对 UR5e，$\cos\theta_2\approx -0.683$，$\theta_2\approx 133^\circ$；因 $l_1\ne\sqrt 2\,l_2$，速度椭圆不能成为圆。
