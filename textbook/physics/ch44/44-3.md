### 44.3.1 问题的提出

机器人控制器里的处理器多用鳍式场效应晶体管（FinFET）：电流在一片竖立的硅“鳍”中流动，栅极从三面包住它。先进工艺中鳍的宽度只有 6 nm 左右，约三四十个原子层。电子在鳍的宽度方向上被两侧的氧化层挡住，就像一个粒子被关在一个很窄的盒子里。在这样的盒子里，电子的能量还能取任意值吗？这对晶体管有什么影响？

### 44.3.2 求解

最简单的模型是**无限深势阱**：粒子在 0 < x < L 内不受力，势能为零；在区间外势能为无穷大，粒子不可能到达。

区间外 ψ = 0。波函数要连续，所以在两壁处

$$
\psi(0) = \psi(L) = 0 .
$$

（势能在壁上有无穷大的跳变，波函数的导数在这里可以不连续，44.4 节会看到这是有限深势阱的极限。）区间内 V = 0，式 (44.2.3) 化为

$$
\frac{\mathrm d^2\psi}{\mathrm dx^2} = -k^2\psi , \qquad k = \frac{\sqrt{2mE}}{\hbar} .
$$

这正是简谐振动的方程（18.1 节），通解为 ψ = A sin kx + B cos kx。由 ψ(0) = 0 得 B = 0；由 ψ(L) = 0 得 sin kL = 0，即 kL = nπ。n = 0 给出处处为零的 ψ，不代表粒子；n 取负整数只改变 ψ 的符号，不是新的状态。所以 n = 1, 2, 3, …，对应的能量为

$$
E_n = \frac{n^2\pi^2\hbar^2}{2mL^2} , \qquad n = 1, 2, 3, \cdots . \tag{44.3.1}
$$

由归一化条件 $\int_0^L A^2\sin^2(n\pi x/L)\,\mathrm dx = A^2L/2 = 1$，得

$$
\psi_n(x) = \sqrt{\frac{2}{L}}\,\sin\frac{n\pi x}{L} , \qquad 0 < x < L . \tag{44.3.2}
$$

n 称为**量子数**。能量只能取式 (44.3.1) 中的一系列分立值，称为**能级**，这就是能量的量子化。它来自边界条件：只有在壁上恰好为零的波，才能“装进”盒子。

### 44.3.3 驻波与能级

kL = nπ 等价于 L = nλ/2：盒子的宽度恰好是半波长的整数倍。这与两端固定的弦上的驻波条件完全相同（21.3 节）。弦只能以一系列固有频率振动；盒中的粒子只能处于一系列能级，能级就是驻波。第 n 个状态在盒内有 n − 1 个节点（ψ = 0 的点），节点越多，波长越短，动量越大，能量越高（图 44.3.1）。

能级有三个值得注意的特点。

第一，最低能量 E₁ 不为零，称为**零点能**。经典粒子可以静止在盒中，能量为零；量子粒子不行。这是不确定关系（43.7 节）的要求：粒子被限制在宽 L 的区域内，Δx ~ L，动量就有 Δp ≳ ħ/(2L) 的不确定度，平均动能不可能为零。

第二，能级与 L² 成反比：盒子越小，能级越高、间隔越大。这是纳米结构中量子效应显著的原因。

第三，能级间隔随 n 增大：$E_{n+1} - E_n = (2n + 1)E_1$。但相对间隔 $(E_{n+1} - E_n)/E_n \approx 2/n$ 随 n 增大而趋于零，能级越来越“密”，量子结果趋于经典结果。这称为**对应原理**（玻尔，1920）。

**估一估** 一个 1 g 的小球在 1 cm 的盒子里以 1 cm/s 来回运动，它的量子数 n 大约是多少？由 E_n = mv²/2 得 n = Lmv/(πħ)。数量级上，Lmv ~ 10⁻⁷ J·s，ħ ~ 10⁻³⁴ J·s，所以 n 在 10²⁶～10²⁷ 之间。程序 44.3.1 给出 n ≈ ${{ex44_3.n_ball:sci1}}$。相邻能级的相对间隔约 2/n，任何仪器都分辨不出来，宏观物体的能量看起来是连续的。

**算例 44.3.1** 电子被限制在宽 1 nm 的无限深势阱中。求最低三个能级，以及电子从 n = 2 跃迁到 n = 1 时放出的光子的波长。

由式 (44.3.1)，E₁ = π² × 0.0381 eV·nm²/(1 nm)² ≈ {{ex44_3.E1:.3f}} eV，E₂ = 4E₁ ≈ {{ex44_3.E2:.3f}} eV，E₃ = 9E₁ ≈ {{ex44_3.E3:.2f}} eV。跃迁放出的光子能量为 E₂ − E₁ ≈ {{ex44_3.dE21:.3f}} eV，波长 λ = hc/(E₂ − E₁) ≈ {{ex44_3.lam21:.0f}} nm，在近红外。程序 44.3.1 还用 44.2.4 节的数值解法求了这三个能级，与解析值的相对差别小于 10⁻⁴。

**算例 44.3.2** FinFET 的硅鳍宽 W = {{ex44_3.W:.0f}} nm。把鳍看成无限深势阱，求电子在宽度方向上的最低两个能级，与室温下的热能 $k_\mathrm BT$ 比较。

半导体中的电子用有效质量代替 mₑ（44.2 节工程师笔记）。硅的导带有几组能谷，有效质量随方向不同；鳍的侧壁为 (110) 面时，最低的一组能谷在宽度方向上的有效质量约 {{ex44_3.mr:.3f}}$m_\mathrm e$，组合常数变为 0.0381/0.315 eV·nm²。由式 (44.3.1)，E₁ ≈ {{ex44_3.F1_meV:.0f}} meV，E₂ ≈ {{ex44_3.F2_meV:.0f}} meV。室温下 $k_\mathrm BT$ ≈ {{ex44_3.kT_meV:.1f}} meV，两个能级之差是它的 {{ex44_3.ratio:.1f}} 倍。按玻尔兹曼因子（23.5 节），这组能谷中处在第二能级的电子只有第一能级的约 {{ex44_3.boltz_pct:.0f}}%：电子在宽度方向上基本被“冻结”在最低能级，只能沿鳍的长度和高度方向运动。（另一组能谷的有效质量较小，最低能级还要高约 20 meV，器件仿真时要一并计入。）

这对晶体管有直接的影响。电子的最低能量比体硅中高出约 E₁ ≈ 33 meV，要让它们导电，栅极就要多加一点电压，阈值电压随之升高；鳍宽稍有起伏，阈值电压就跟着变化。图 44.3.2 画出了 E₁、E₂ 随鳍宽的变化：鳍宽超过 10 nm 以后，量子化能量降到 $k_\mathrm BT$ 附近，效应才不明显。芯片设计用的器件仿真软件必须计入这一修正。

**生活中的例子** 量子点电视（QLED）的红、绿、蓝光来自几纳米大小的半导体晶体颗粒。颗粒越小，电子的量子化能量越高，发出的光越偏蓝；同一种材料做成不同大小的颗粒，就能发出不同颜色的光。把颗粒看成三维的“盒子”，式 (44.3.1) 就能说明这个趋势，但要定量算准，还要计入电子与空穴的吸引和颗粒表面的影响。

**工程师笔记**

- 无限深势阱高估了能级：真实的势垒是有限高的，波函数会渗进壁里，等效宽度变大，能级变低（44.4 节）。它适合估算数量级和趋势。
- 判断一个结构里量子效应是否重要，就看量子化能量与 $k_\mathrm BT$（室温约 26 meV）之比。远大于 1 时，电子只占据最低的一两个能级，必须用量子力学；远小于 1 时，能级密得像连续的，经典的或半经典的模型就够了。
