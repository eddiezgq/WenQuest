id: "3.0"
title: 本章提要
---

第 2 章的控制电路里，逻辑由触点和线圈组成；从本章开始，逻辑搬进了 PLC，现场的按钮、传感器接到 PLC 的输入端子上，接触器线圈、电磁阀、指示灯接到它的输出端子上。PLC 的程序再好，信号进不来、命令出不去也是白搭；而现场调试时最常见的问题，恰恰出在这些端子上：传感器的灯亮了 PLC 却收不到，输出点烧了，模拟量跳个不停，计数少了。它们几乎都能从硬件的工作原理上找到原因。

本章讲 PLC 的硬件。3.1 节说明一台 PLC 由哪几部分组成，背板总线做什么。3.2 节比较一体式、模块式和分布式 I/O 三种结构。3.3 节是数字量输入：输入电路怎样把 24 V 变成 0 和 1，电流从输入端子流进还是流出、为什么两大厂家对同一种接法的叫法正好相反，两线制与三线制传感器怎样接，输入滤波怎样挡住触点的抖动。3.4 节是数字量输出：继电器、晶体管、晶闸管三种输出各适合什么负载，断开线圈时的电压尖峰从哪里来、怎样吸收，吸收电路又怎样拖慢了电磁阀的关闭。3.5 节是模拟量：4–20 mA 回路、标定、分辨率与断线检测，热电阻和热电偶。3.6 节介绍高速计数、脉冲输出等特殊模块，并用程序说明普通输入为什么数不了快脉冲。3.7 节为上料输送线选一台 PLC，列出 I/O 分配表，写一份选型计算书。3.8 节是现场故障案例：换了一个传感器，传感器亮了，PLC 却没收到。

读者在实验 3.3 里用电路仿真把传感器、电磁阀和液位计接到 PLC 上，量电压、看电流：接错的传感器为什么没有电流，线圈断开时触点上的几百伏从哪里来，电缆断了 PLC 怎样发现。工程任务单 TS-3-1 是第一篇篇首项目的第二个里程碑：为上料输送线选 PLC，交选型计算书、I/O 分配表和 PLC 接线图。

学完本章，读者应能：

1. 说出 PLC 的各组成部分及其作用，比较一体式、模块式和分布式 I/O；
2. 画出 PNP、NPN 传感器与两种数字量输入的接线，按电流方向判断接法对错，说明厂家对“源型”“漏型”叫法的差别；
3. 说明输入滤波的作用和代价，估算它带来的延时；
4. 为不同负载选择继电器、晶体管或晶闸管输出，说明感性负载吸收电路的作用和对释放时间的影响；
5. 说明 4–20 mA 回路的接法、标定和断线检测，计算模拟量输入的分辨率；
6. 说明普通数字量输入能数的脉冲频率上限，知道什么时候要用高速计数器；
7. 为一台设备完成 PLC 选型：I/O 点数与余量、电源容量、响应时间，列出 I/O 分配表。
