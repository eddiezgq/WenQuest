### 1.3.1 PLC 的组成

先给 PLC 下一个定义。

**定义 1.3.1（可编程控制器）** **可编程控制器**是为工业环境设计的数字式电子控制设备。它用可编程的存储器存放用户程序，通过数字量或模拟量的输入输出，实现逻辑、顺序、定时、计数和运算等控制功能，控制各种机器和生产过程。

这个定义（意思取自 IEC 61131-1 和 GB/T 15969.1）里有两个要点。一是“为工业环境设计”：PLC 要在电气柜里连续工作十几年，经受电源波动、电磁干扰、振动、灰尘和较宽的环境温度（常见的是 0–55 °C，以产品手册为准），它的输入输出电路、电源和外壳都为此专门设计，这是它和普通计算机最大的不同。二是“可编程”：同一台 PLC，装上不同的程序，可以控制输送线、压装机、电梯或者灌装机。

从硬件看，一台 PLC 由电源、CPU 与存储器、输入模块、输出模块和通信接口组成（图 1.3.1 左）。小型 PLC 把这些做成一个整体，大中型 PLC 做成一块块模块，按需要插在机架或导轨上。输入模块接按钮、限位开关、光电开关这些输入设备，把现场的 24 V 信号变成 CPU 能读的 0 和 1；输出模块接接触器线圈、电磁阀、指示灯这些执行元件，把 CPU 写的 0 和 1 变成能驱动它们的电压或电流。模拟量模块处理温度、压力、流量这些连续变化的信号（第 16 章）。通信接口连编程电脑、触摸屏和其他控制设备。第 3 章详细讲这些硬件。

### 1.3.2 扫描周期

PLC 执行程序的方式和一般的计算机程序不一样。它不是从头到尾执行一遍就结束，而是周而复始地重复同样的三步（图 1.3.1 右）：

1. **读输入**：把所有输入端子的状态一次读进来，存在一块叫**输入映像**的存储区里；
2. **执行程序**：从程序的第一行执行到最后一行，执行中用到的输入都从输入映像里取，算出的输出都写进**输出映像**；
3. **写输出**：把输出映像一次写到所有输出端子上。

三步走完，叫一个**扫描周期**，然后马上开始下一个。一个扫描周期通常是几毫秒到几十毫秒。

为什么要这样做，而不是在程序里需要哪个输入就去读哪个？因为这样做，在一次执行程序的过程中，所有输入都是“同一时刻”的值，程序的结果不会因为某个输入恰好在执行到一半时变了而自相矛盾；所有输出也在同一时刻更新，不会出现执行到一半、一部分输出已经变了另一部分还没变的情况。代价是反应会慢一点：一个输入变化以后，要等到下一次读输入时才被读进来，再执行一遍程序，才写到输出，所以从输入变化到输出变化大约要一到两个扫描周期，再加上输入电路的滤波（几毫秒）和输出器件本身的动作时间。对于按钮、限位开关、接触器这样以几十毫秒计的器件，这点延迟无关紧要；对于高速计数、精确定位，就要用专门的方法（第 4、20 章）。

扫描周期是理解 PLC 程序的钥匙。初学者遇到的许多“怪事”——检测“按钮刚按下的那一刻”（上升沿）为什么只在一个周期里有效，同一个输出在程序里写两次为什么只有后一次起作用，用循环语句在程序里“等”一个输入为什么会让 PLC 停机——都要从扫描周期去理解。第 4 章专门讲它。

### 1.3.3 PLC 不是什么

PLC 不是唯一能做控制的设备。工厂里还有好几类控制设备，它们和 PLC 各有分工，又常常连在一起工作。表 1.3.1 做了一个比较。

::: 表 1.3.1
说明: PLC 与相邻的几类控制设备
:::

| 设备 | 擅长什么 | 典型场合 | 与 PLC 的关系 |
|---|---|---|---|
| 继电器、接触器 | 通断大电流；不依赖软件的硬接线逻辑 | 电机主回路，急停回路 | PLC 的输出驱动接触器；急停回路仍用硬接线（第 33 章） |
| 单片机 | 成本低、体积小，批量生产 | 洗衣机、空调、仪表里的控制板 | 一种产品生产成千上万台用单片机；一台设备只做几台用 PLC |
| 工控机 | 计算能力强，图形界面，大量数据 | 操作站、视觉检测、数据采集 | 常做 PLC 的上位机；软 PLC 运行在工控机上（第 42 章） |
| 分布式控制系统 | 成百上千个模拟量回路，冗余，全厂统一组态 | 化工、电力、制药等流程工业 | 流程工业的主力；离散制造以 PLC 为主，两者的界线正在模糊 |
| 运动控制器 | 多轴同步、插补、凸轮 | 包装机、印刷机、数控设备 | 许多 PLC 自带运动控制功能（第 21、22 章） |
| 机器人控制器 | 机器人的运动学、轨迹规划 | 焊接、搬运、装配机器人 | PLC 管整个工作站，告诉机器人什么时候做什么（第 23 章） |

从表中可以看出，PLC 的位置是“机器和产线的控制核心”：它不追求最强的计算能力，也不追求最低的成本，而追求在工业现场长期、可靠、可维护地控制一台设备或一条产线。它的程序要让现场的电气工程师看得懂、改得动、查得出问题。本书反复强调的程序结构清楚、测试充分、故障可诊断，都是为了这个目标。
