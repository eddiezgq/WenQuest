# 《PLC 原理及实践》符号约定（v0.1，2026-10-03，待 Eddie 审阅）

全书统一使用本约定。写作、程序、插图、动画、实验、虚拟设备都以它为准。新增写法先登记在这里，再在正文中使用。

## 一、总原则

1. **英文名用美式拼写**（program、center、behavior），与另几本书一致。
2. **标准为本，厂家对照**：程序一律用 IEC 61131-3（第 3 版）语法；西门子、三菱、汇川、罗克韦尔、CODESYS 的写法只在每章末“厂家对照”和附录里出现。正文提到某家写法时，先给 IEC 写法，再说“西门子写作……”。
3. **一个名字只表示一种东西**：变量、功能块实例、I/O 点、设备代号在同一章里不重名。
4. **程序与书一致**：书中提到的变量名、功能块名与 `programs/` 里的程序完全相同；时序图、监视截图由程序运行生成。

## 二、程序的写法

| 对象 | 写法 | 例 |
|---|---|---|
| 关键字 | 大写 | `IF … THEN … END_IF`、`VAR_INPUT`、`FUNCTION_BLOCK` |
| 变量 | 驼峰式，首字母小写；布尔量用 `x` 前缀不用，直接写含义 | `motorRun`、`conveyorSpeed`、`partPresent` |
| 输入输出变量（映射到 I/O 点） | `i` / `q` 前缀 + 设备代号 + 含义 | `iB1_PartPresent`、`qM1_ConveyorFwd`、`iS0_EStopOk` |
| 常量 | 全大写，下划线分隔 | `MAX_PARTS`、`T_JAM` |
| 功能块类型 | 前缀 `FB_`；功能 `FC_`；结构体 `ST_`；枚举 `E_`；接口 `I_` | `FB_Cylinder`、`FC_Scale`、`ST_Recipe`、`E_State`、`I_Device` |
| 功能块实例 | 首字母小写，与设备代号对应 | `cylA1 : FB_Cylinder;`、`tonJam : TON;` |
| 状态枚举值 | 全大写 | `E_State.IDLE`、`E_State.RUNNING` |
| 注释 | `(* … *)`，中英文版各自用本语言 | `(* 急停未复位时禁止启动 *)` |

PLCopen 编码准则（[PLO]）是本书的编码规范；与它不同的地方（如变量前缀）以本表为准，并在第 13 章说明理由。

## 三、地址与 I/O

| 对象 | 写法 | 说明 |
|---|---|---|
| 直接地址 | `%IX0.0`、`%QX0.1`、`%IW64`、`%QD10`、`%MX10.3` | IEC 61131-3；正文首次出现时对照西门子 `I0.0`、三菱 `X0`、汇川 `%IX0.0` |
| 符号地址 | 优先使用 | 程序里一律用符号，直接地址只出现在 I/O 表 |
| I/O 表 | 列：序号、地址、符号、说明、类型、常态、接线端子、设备代号 | 每个工程任务单都附 I/O 表，格式见附录 |
| 数字量常态 | 写“常开 NO”“常闭 NC” | 安全相关输入一律用常闭、断线即安全 |

## 四、电气图

| 对象 | 标准 | 说明 |
|---|---|---|
| 图形符号 | GB/T 4728 / IEC 60617 | 国内教材常见的旧符号在附录对照 |
| 参照代号 | GB/T 5094 / IEC 81346 | 例：`-Q1` 断路器、`-K1` 接触器、`-M1` 电动机、`-S1` 按钮、`-B1` 传感器、`-Y1` 电磁阀、`-A1` PLC、`-T1` 变频器 |
| 线号 | 主电路 L1/L2/L3、U/V/W；控制电路按页码与列编号 | |
| 电源 | 控制电压 DC 24 V（L+ / M）；主电路 AC 380 V（中文版）/ 注明各地区电压（英文版） | |

## 五、梯形图、功能块图、顺序功能图

1. 梯形图按 IEC 61131-3 图形：左右母线、常开触点 `–| |–`、常闭触点 `–|/|–`、线圈 `–( )–`、置位 `–(S)–`、复位 `–(R)–`、上升沿 `–|P|–`、下降沿 `–|N|–`。
2. 一个网络（Network）只写一件事，网络编号从 1 起；正文引用写“网络 3”。
3. 顺序功能图的步编号 S0、S1……（初始步 S0 画双框），转移 T1、T2……；GRAFCET 写法只在第 12 章对照。
4. 能流、活动步在动画和监视截图里统一用绿色表示，强制值用橙色，故障用红色（色盲友好配色在插图程序里统一）。

## 六、时间与时序

| 对象 | 写法 | 例 |
|---|---|---|
| 时间常量 | IEC 写法 | `T#500ms`、`T#2s`、`T#1m30s` |
| 扫描周期 | $T_\mathrm{cyc}$ | 单位 ms |
| 输入滤波时间 | $T_\mathrm{f}$ | |
| 响应时间 | $T_\mathrm{resp}$ | 最坏值写 $T_\mathrm{resp,max}$ |
| 通信周期 | $T_\mathrm{bus}$ | |
| 时序图 | 横轴时间，信号自上而下：输入、内部变量、输出；高电平在上 | 由程序生成 |

## 七、控制与运动

| 量 | 符号 | 单位 |
|---|---|---|
| 设定值、过程值、输出 | $SP$、$PV$、$CV$（正文变量）；推导时写 $r(t)$、$y(t)$、$u(t)$ | 工程单位 / % |
| 偏差 | $e = SP - PV$ | |
| PID 参数 | 比例增益 $K_p$、积分时间 $T_i$、微分时间 $T_d$；采样周期 $T_s$ | 与《机器人学》一致 |
| 位置、速度、加速度、加加速度 | $s$、$v$、$a$、$j$ | mm、mm/s、mm/s²、mm/s³（直线）；°、°/s（旋转） |
| 电子齿轮比 | $n_\mathrm{e}$ | |
| 凸轮表 | 主轴位置 $\theta_\mathrm{m}$，从轴位置 $s(\theta_\mathrm{m})$ | 与《机械设计》凸轮一章同一套运动规律 |

## 八、安全

| 量 | 符号 | 说明 |
|---|---|---|
| 性能等级 | PL a–e；要求的等级 PL$_\mathrm{r}$ | ISO 13849-1 |
| 安全完整性等级 | SIL 1–3 | IEC 62061 |
| 平均危险失效前时间 | MTTF$_\mathrm{D}$ | 年 |
| 平均诊断覆盖率 | DC$_\mathrm{avg}$ | % |
| 每小时危险失效概率 | PFH$_\mathrm{D}$ | 1/h |
| 安全距离 | $S = K\,T + C$ | ISO 13855：$K$ 接近速度 mm/s，$T$ 总停止时间 s，$C$ 附加距离 mm |

## 九、通信

| 对象 | 写法 |
|---|---|
| 报文字节 | 十六进制，空格分隔：`01 03 00 00 00 02 C4 0B` |
| Modbus 地址 | 写协议地址（从 0 起），括号注常见的“40001”式写法 |
| 节点 | OPC UA 节点写 `ns=2;s=Line1.Conveyor.Speed` |
| MQTT 主题 | 与数字工厂一致：`wq/<工厂>/<区域>/<单元>/<类别>`，如 `wq/gearbox/machining/asm-01/status`；消息里 `source` 写 `plc/<设备>` |

## 十、单位

国际单位制；数与单位之间空一格（`24 V`、`4–20 mA`、`10 ms`）。电压写 V、电流写 A 与 mA、功率 kW、转速 r/min、频率 Hz。
