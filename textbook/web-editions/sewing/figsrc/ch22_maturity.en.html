From prototype to industrial grade: test data decide whether to move up a level

Every exit condition is a number an automated test can judge (illustrative; the full version is Table 22-7 in Section 22.8). After launch, end-of-line and field data flow back into requirements and test cases

EVTengineering validation, 2–3 units

  • ≤ 1 failure in 1000 trims
  • backtack ≤ 0.3 mm, solenoid ≤ 20°
  • HIL green 10 nights running
DVTdesign validation, 3–5 units, firmware frozen
  • EMC, ±10 % supply, 5–45 °C (Ch. 18)
  • trim 99.9 %/90 %: 2302 trims, no failure
  • 4 h run on every unit, no fault
PVTproduction validation, 20–50 units
  • EOL first-pass yield ≥ 98 %
  • no early failures after burn-in
  • test data stored by serial number
Volume productionevery unit

  • monthly review of field data
