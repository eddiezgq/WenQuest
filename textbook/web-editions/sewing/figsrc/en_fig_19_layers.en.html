From sewing machine to dashboard: data in four layers

Illustrative; data flows upwards, commands and parameters flow downwards

Application
layer

Shop-floor dashboardState, piece counts, stops
MES / piece-rate payDispatching, production reporting, labour time
Remote maintenanceFault codes, parameters, upgrades
Digital twinReal-time mirror, simulation and prediction

Platform
layer

MQTT brokerForwards by topic
Retained messages, last will
HistorianArchives every message
MetricsPiece counts, OEE, stop reasons
Interfaces / bridgesTo ERP and the hanger system

Edge
layer

Network moduleSerial port → wireless / wired network
GatewayProtocol conversion, aggregation
Buffering during network outages
Workstation terminalCard swipe, choosing stop reasons

Device
layer

Sewing-machine controllerMain-shaft start/stop, speed, stitches
Trims, thread breaks, fault codes
Card readerOperator ID card
Hanger readerCarrier ID (Chapter 12)
Work-ticket scanningOrder, operation, bundle number

Upward arrows: data (state, counts, events); downward arrows: commands (dispatching, parameters, firmware). Each layer deals only with its neighbours, so one layer can be replaced without affecting the others.
