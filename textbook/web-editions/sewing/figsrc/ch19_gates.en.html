From prototype to industrial grade: P0 → P1 → EVT → DVT → PVT → mass production

Illustrative. Every exit criterion is a pass rate of automated tests or a measured indicator; quantities are illustrative

P0 runsQuantity: 1 unitForm: bought-in head + modules
  • spindle speed, needle stop
  • event table drives solenoids
  • all SIL tests pass
Exit criteria: stop ≤ ±3°; HIL smoke tests pass
→
P1 completeQuantity: 1–2 unitsForm: modular prototype
  • all actions, network reporting
  • every requirement has a test
  • bench runs unattended
Exit criteria: ≥ 95 % cases pass; stop ≤ ±1°; trimming ≥ 99.5 % of 1000
→
EVT engineeringQuantity: 3–5 unitsForm: integrated board and box
  • modules merged into one board
  • thermal, supply, EMC pre-scan
  • 4 h at top speed
Exit criteria: all REQ cases pass; temperature rise OK (Ch. 18)
→
DVT designQuantity: 10–20 unitsForm: design frozen
  • EMC, safety, environment
  • reliability and life
  • certification samples
Exit criteria: standard tests passed; no critical failure in life test
→
PVT productionQuantity: 50–200 unitsForm: production tooling
  • line assembly, EOL test
  • burn-in (Ch. 18)
  • data back to the digital factory
Exit criteria: EOL first-pass yield ≥ 98 %; repair causes closed
→
Mass productionQuantity: —
  • EOL data → historian
  • firmware and parameter versions controlled
  • field data back to requirements
