凸轮的工艺流程：热处理以后靠磨削定形状

✓ 为该工序的主要检验项目；余量等数值为示意

下料棒料或锻坯：20CrMnTi（渗碳）/ 45、40Cr（感应淬火）✓ 材料牌号、炉号
→
车削内孔、端面、外圆，留磨量✓ 孔径、端面跳动
→
铣廓线 / 线切割数控铣（留 0.2–0.3 mm），沟槽凸轮铣槽；小批可线切割✓ 廓线余量均匀
→
热处理渗碳淬火 + 低温回火，或廓线感应淬火✓ 硬度、硬化层深、变形
↓
清洗防锈入库或装配✓ 清洁度
←
廓线测量凸轮测量仪或三坐标：每 0.5°–1° 测一点✓ 升程误差曲线、谐波
←
数控凸轮磨削C 轴转凸轮、X 轴进退砂轮；粗磨—精磨—光磨✓ 升程、表面粗糙度、烧伤
←
磨孔与端面建立凸轮磨削的基准✓ 孔径、端面垂直度
↺ 补偿回路：测得的升程误差 → 谐波分解 → 改写 C–X 磨削轨迹（反向叠加）→ 再磨一次。低阶误差改得掉，高阶（振纹）只能靠工艺消除
