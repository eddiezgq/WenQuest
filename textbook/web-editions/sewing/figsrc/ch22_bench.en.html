A universal test bench: one set of instruments, four prototypes

The test PC sends commands and reads measurements through the gateway; the bench modules measure the "true" values and compare them with what the prototype reports. Changing over means changing only the head adaptor and the wiring configuration (illustrative; module IDs are proposed IDs, planned for the library)

BENCH MODULES (PROPOSED IDs, PLANNED FOR THE LIBRARY)

Load motor and dynamometer D-TB-LOADcoupled to the spindle by jaw coupling A-CPL-JAW: applies load torque, measures torque and speed
Encoder signal emulator D-TB-ENCEMUgenerates A/B/Z (10 000 counts/rev) for HIL; can inject loss and jitter
HIL real-time simulator D-TB-HILspindle motion from the measured torque–speed curve, ≥ 1 kHz
Data acquisition + current probes D-TB-DAQcoil current, DC-link voltage, encoder and commands sampled together
Stroke sensor D-TB-STROKEsolenoid plunger travel → pull-in / release instants
Stitch camera D-TB-CAMneedle-penetration positions, backtack alignment, skips, tail length
Temperature logger D-TB-TEMPmotor, heat sink, solenoid coils, ambient
Lockstitch WQ-SC/LShead adaptor plate + spindle coupling; tests: stop, trimming, backtack, solenoids, 4 h temperature rise
Overlock WQ-SC/OLsame load motor, different adaptor; tests: stop, differential ratio, knife and wiper timing
Pattern sewer WQ-SC/PSX–Y axes with linear scales/laser displacement; tests: following error, motion while the needle is in the fabric
Scaled knitter WQ-SC/FKcarriage-position encoder emulation + selector stroke; tests: selection timing error

How the change-over works: mechanically only the "adaptor plate + coupling" is changed; electrically the same numbered connectors are used; in software each prototype has one test configuration file (wiring table, HAL drivers, test-case set). The test scripts themselves do not change.
