从原型到工业级：P0 → P1 → EVT → DVT → PVT → 量产

示意。每一级的退出条件都写成自动测试的通过率和指标；数量、比例为示意值

P0 能动数量：1 台形态：现成机头 + 模块
  • 主轴调速、停针
  • 事件表驱动电磁铁
  • SIL 全部通过
退出条件：停针 ≤ ±3°；HIL 冒烟测试通过
→
P1 功能全数量：1–2 台形态：模块化原型
  • 全部动作、联网上报
  • 需求 100% 有用例
  • 测试台自动跑
退出条件：用例通过 ≥ 95%；停针 ≤ ±1°；剪线 1000 次 ≥ 99.5%
→
EVT 工程验证数量：3–5 台形态：集成电控板、机箱
  • 模块合成一块板
  • 热、电源、初测 EMC
  • 4 h 满速运转
退出条件：全部 REQ 用例通过；温升合格（第 18 章）
→
DVT 设计验证数量：10–20 台形态：设计冻结
  • EMC、安全、环境试验
  • 可靠性与寿命
  • 认证送样
退出条件：标准试验通过；寿命试验无关键故障
→
PVT 小批验证数量：50–200 台形态：量产工装
  • 产线装配、EOL 测试
  • 老化（第 18 章）
  • 数据回流数字工厂
退出条件：EOL 一次通过率 ≥ 98%；返修原因已闭环
→
量产数量：—
  • EOL 数据 → 历史库
  • 固件与参数版本受控
  • 现场数据回到需求表
