The test pyramid: what each of the five levels tests, how fast, how costly

Test volume for one firmware version of the WQ-SC lockstitch prototype (illustrative). Lower levels are faster, cheaper and run more often; higher levels are closer to reality but slower and dearer

Note: counts and times are illustrative values for the WQ-SC/LS prototype of this chapter. A rule of thumb: each level higher at which a defect is found costs roughly ten times more to fix, so for every defect found high up, ask "can a test one level lower catch it?" (Section 22.9).
