# 写课程包的工作说明

你在把教材《缝纫机设计与制造》（八篇三十一章，中英两版）开发成问渠机器人学院的一门课：一章一讲，共 31 讲。你负责若干讲，每讲写一个文件 `course/lessons/chNN.json`（NN 两位数，如 ch03）。工作目录 `/home/claude/wenquest/textbook/web-editions/sewing/`。

## 先读
1. `course/FORMAT.md`：文件格式和硬规则（必须遵守）。
2. `GLOSSARY.md`：中英术语。
3. 你负责的每一章：中文正文 `src/zh/chNN.html`、英文正文 `src/en/chNN.html`（逐节读完，包括算例、习题和答案）；本章的虚拟实验页 `src/zh/labs/<id>.html`（看清控件、任务和判据，指导书的步骤要按实验页真实写）。
4. 篇章结构见 `book.py`。

## 这门课的取向
- 学生：工科本科高年级或研究生、问渠机器人学院学员，中英双语。
- 实际问题以**缝制车间**为主（教材每章的“引子”就是很好的素材，可以改编，但要给出具体数字，学完本讲能算出答案）；每讲另配一个**机器人联系**（同一原理在机器人上的对应：伺服、编码器、凸轮与轨迹规划、视觉检测、数字孪生……要具体，说清对应关系）和一个**生活例子**。
- PPT 每页要点精炼、讲稿口语化（像老师在讲），讲清楚本页，不是念要点。
- 测验和考试题考理解和计算，不考死记硬背的数字；数值题答案用 Python 算出（脚本放 `course/calc/chNN.py`）。
- 作业要有工程味：给条件、要结果、要说明理由。

## 完成标准
- `python3 course/tools/check.py chNN` 对你的每一讲都是 OK。
- 文件里的数字与教材一致；你自己再通读一遍中英文。
- 不要改别的文件（教材正文、实验页、工具、别人的讲）。
- 最后回复：完成了哪几讲；每讲测验与考试题里数值题的答案是怎样算的（一句话）；你对教材发现的任何错误或疑点（不要改教材，只报告）。
