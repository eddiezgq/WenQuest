20.1 引子：把一台机械平缝机头变成电控样机

设想你在一个小实验室里，桌上放着一台带剪线机构的平缝机机头（它原本配的是电控，但只买了机械部分），一台旧的离合器电机，一箱第 19 章列出的模块：WQ-SC 主控板、伺服驱动器和电机、电磁铁驱动板、几只推拉式电磁铁、脚踏、电源。任务是在两周内让它缝出第一道线、剪断、停在上针位，并且能把每一次剪线的数据发到数字工厂的看板上。

动手以前先要想清楚三件事。第一，机械上改什么：哪些件拆掉，电机怎样接到主轴上，五个电磁铁装在哪里、推哪根杆。第二，控制上怎样组织：哪些动作按转角、哪些按时间，事件表的初值从哪里来。第三，怎样知道它“好了”：什么时候算调通，什么时候算达标。很多原型做不下去，不是因为某个电路不会画，而是这三件事没有先想清楚，结果每改一个地方就要回头重来。本章按这个顺序展开：20.2 节讲系统构成和硬件，20.3 节讲固件，20.4 节讲逐步调试，20.5 节讲验收。20.6–20.7 节换成包缝机，20.8 节回头看两台原型共用了多少。

20.2.1 框图

图 20-1 把第 19 章的五层参考架构落到这台平缝机上。最下面是改装的机械：电机经梅花联轴器直接接主轴（直驱），或者装在台下用 1:1 同步带传动。往上是执行与传感：主轴伺服电机带 2500 线增量编码器，四倍频后每转 10000 个计数，分辨率 0.036°；五只推拉式电磁铁分别管剪线、拨线、倒缝、抬压脚和松线；脚踏里是霍尔传感器。驱动层有伺服驱动器、6 路电磁铁驱动板、24 V 开关电源和急停回路。实时控制层只有一块 WQ-SC 主控板。最上面是网关，把状态和每次剪线的测量值按 wq/sewing/<区域>/<单元>/measurement 这样的主题发出去。

有一处连线值得单独说：编码器接在伺服驱动器上（驱动器做矢量控制必须要它），驱动器再把 A、B、Z 三路信号 1:1 转发给主控。主控板的编码器接口定时器自己计数，转角就在主控手里，按转角触发电磁铁不必经过总线。如果改成由驱动器经 CAN FD 把角度报给主控，每帧可能有几百微秒的延迟和抖动，剪线转速 300 r/min 时 0.5 ms 就是 0.9°，看起来不多，但它是随机的，会直接加到进刀角的散布上。速度指令、状态和参数走 CAN FD 没有问题，它们对时间不那么敏感。

主轴电机　直驱是首选：电机做一个法兰装在机壳尾部，电机轴和主轴之间用梅花联轴器（A-CPL-JAW），手轮装到电机后端。联轴器能容许一点不同轴，但不能太多，弹性体在每转里反复受压会发热；安装时用百分表打电机轴和主轴的同轴度，按联轴器规格表里的允许值控制。台下带传动的方案改动小，适合不想动机壳的情况，但要用同步带（A-PUL-HTD 带轮 + C-BLT-BELT），而且传动比取 1:1，原因在 20.6 节讲包缝机时会看到：传动比不是整数，编码器的 Z 相就不再每转对准主轴的同一个角度。

五只电磁铁　剪线电磁铁装在底板下面、旋梭旁边，经连杆摆动动刀（第 14 章讲的“直接驱动”式）；拨线电磁铁装在机臂前端，拨线杆从针下扫过；倒缝电磁铁在机臂里，拉针距调节器的倒缝杠杆；抬压脚电磁铁装在底板下，推原来膝控抬压脚的那根杠杆；松线电磁铁装在机臂上，顶开夹线器的松线顶杆。带剪线机构的机头，这些安装孔和杠杆多半都是现成的；没有的，就要自己做支架，用零件库的螺钉和复位弹簧（A-SCR-SHC、A-SPR-CMP）。电磁铁的行程要和杠杆的有效行程对上，留 0.3–0.5 mm 的余量，让衔铁吸到底时杠杆已经到位，而不是杠杆先顶死、衔铁还差一点吸不到底：后一种情况下维持电流保不住衔铁，线圈会一直在强激磁和维持之间来回切换，发热和噪声都大。

两只开关　机头翻倒开关（接近开关，D-SNS-PROX）装在底板和台板之间，机头翻起来维修时断开，固件禁止启动；脚踏霍尔传感器（D-SNS-HALL）装在台下脚踏连杆上。

20.2.5 电源与安全

功率预算　24 V 电源要应付的是电磁铁的强激磁电流。每只线圈强激磁时电流最高 24/8 = 3 A。标准事件表里剪线和松线在 300° 和 310° 通电，强激磁各持续 10 ms，在 300 r/min 时两次通电只隔 5.6 ms，会重叠，峰值约 6 A；抬压脚在拨线复位以后才动作，不与它们重叠。再加主控、传感器约 0.5 A，峰值约 6.5 A、156 W，选 24 V、200 W 的电源留出余量。平均功率很小：一次剪线的电磁铁能量约 0.9 J（粗算），每分钟剪 30 次也不到 0.5 W；真正要核算的是抬压脚电磁铁，它在操作工整理布料时一直保持着，维持 1 A 就是 8 W，要看线圈的允许占空比。

急停与联锁　第 18 章引过 IEC 60204-31 的规定：用脚踏这类“松开即停”的装置启动的机器可以不设急停按钮。原型机不一样：防护罩可能还没装，固件也没有经过验证，所以本书建议原型一律加一只双触点急停按钮。一组触点硬接线，切断伺服驱动器的使能输入和电磁铁的 24 V（经安全继电器）；另一组接 DI1，让固件知道并记录。不要只靠固件去停机，固件出问题时急停也就失效了。机头翻倒开关断开时禁止启动；上电时脚踏不在中位，也禁止启动（ISO 10821 要求防止意外启动，第 18 章）。

接地与防护　机头、电机外壳、控制箱外壳都接保护地（PE），用黄绿线，单独接到接地端子上，不经过信号地；电源前装漏电保护器。编码器线和电机动力线分开走线，必须交叉时垂直交叉。带传动方案要装带罩，直驱方案的联轴器外面也要有罩，手指不能伸进转动件。

20.3 平缝机原型的固件

20.3.1 结构：状态机 + 角度中断 + HAL

图 20-3 是固件的结构，沿用第 19 章的框架。上面一行是状态机：IDLE（压脚落下等脚踏）→ RUN（脚踏调速，含起缝回针和慢起针）→ SLOW（减速到剪线转速）→ TRIM（剪线事件表生效）→ POSITION（位置环停到上针位）→ 回到 IDLE（拨线、抬压脚）；任一状态出故障都进 SAFE。下面是三层任务：10 kHz 的角度中断读编码器、扫描事件表、数回针针数；1 kHz 的控制任务跑状态机、速度曲线和位置环；后台任务处理脚踏滤波、参数、故障码、日志和网关。最底下是 HAL，每类模块一组接口。

为什么事件放在 10 kHz 的角度中断里？第 13 章说过，按转角触发的动作必须靠近硬件。10 kHz 意味着每 0.1 ms 检查一次，剪线转速 300 r/min 时主轴每 0.1 ms 转 0.18°，700 r/min 时 0.42°，这就是事件的最大触发误差，比电磁铁延迟的散布小一个数量级。要更准，可以用定时器的比较器在指定计数上直接触发，但原型阶段 10 kHz 扫描已经够了，而且代码简单、好调试。

本章用剪线周期角 ψ 表示事件表里的角度：剪线那一针（最后一针）的转角是 0–360°，下一转记为 360–720°。表里写 408°，就是下一转的 48°。书中角度的零点始终是针杆上止点（第 3、8 章），这就要求编码器的读数先被标定到这个零点上（20.4.2 节）。

    uint16_t on_x10;     /* 起始角，0.1°，剪线周期角 0..7199 */
    uint16_t off_x10;    /* 结束角；0xFFFF 表示保持到“停稳” */
    uint8_t  ch;         /* SOL_TRIM, SOL_TREL, ... */
    uint8_t  cond;       /* COND_TRIM：仅在 TRIM/POSITION 状态有效 */
} evt_t;

#define EVT_MAX 8
extern evt_t    evt_tab[EVT_MAX];
extern uint8_t  evt_n;
extern uint16_t evt_ver;             /* 参数版本号，随日志上报 */

/* angle_isr.c — 10 kHz，由定时器中断调用 */
static int32_t psi_prev;             /* 上一次的剪线周期角，0.1° */

void angle_isr(void)
{
    int32_t cnt = enc_read(&enc_spindle);        /* 累计计数（含方向与偏置标定） */
    int32_t psi = enc_to_psi_x10(cnt);            /* 0.1°，剪线开始时清零到 0..3599 */
    if (sm_state == ST_TRIM || sm_state == ST_POSITION) {
        for (uint8_t i = 0; i < evt_n; i++) {
            const evt_t *e = &evt_tab[i];
            if (psi_prev < e->on_x10 && psi >= e->on_x10)  sol_on(e->ch);
            if (e->off_x10 != 0xFFFF &&
                psi_prev < e->off_x10 && psi >= e->off_x10) sol_off(e->ch);
        }
    }
    bt_count_isr(psi_prev, psi);                  /* 回针针数计数，20.3.4 节 */
    psi_prev = psi;
}

状态机里的剪线序列在 1 kHz 控制任务中。它不直接开关电磁铁，只负责切换状态、设定转速、在停稳以后按时间排拨线和抬压脚，并且给每一步设超时：

/* sm_trim.c — 1 kHz 控制任务中的剪线序列（节选） */
case ST_SLOW:                                     /* 减速到剪线转速 */
    spindle_set_speed(P.trim_rpm);                /* 300 r/min */
    if (spindle_rpm() <= P.trim_rpm + 10 && psi_in(1700, 1800)) {
        enc_psi_zero_at(1800);                    /* 剪线那一针从 180° 起计 ψ */
        sm_enter(ST_TRIM, /*timeout ms*/ 400);
    }
    break;
case ST_TRIM:                                     /* 事件表在角度中断里执行 */
    if (psi_now() >= P.engage_x10) {              /* 3850 = 次转 25° */
        spindle_position(P.target_x10);           /* 4300 = 次转 70°，定位速度 200 r/min */
        sm_enter(ST_POSITION, 300);
    }
    break;
case ST_POSITION:
    if (spindle_stopped(5 /*ms*/, 5 /*0.1°*/, 10 /*r/min*/)) {
        evt_flush_until_stop();                   /* 关掉“保持到停稳”的行，如松线 */
        log_trim(psi_now(), sm_elapsed_ms());     /* 停针角、剪线周期时间 → measurement */
        timer_after(P.wipe_on_ms,  sol_on,  SOL_WIPE);
        timer_after(P.wipe_on_ms + P.wipe_len_ms, sol_off, SOL_WIPE);
        timer_after(P.pfl_on_ms,   sol_on,  SOL_PFL);
        sm_enter(ST_IDLE, 0);
    }
    break;
/* 任一状态超时、过流、编码器丢失或急停：sm_enter(ST_SAFE) → sol_all_off()，主轴自由停或制动 */

两个细节。第一，spindle_stopped() 的判据（误差 ≤ 0.5°、转速 < 10 r/min、持续 5 ms）就是“停稳标志”；拨线和抬压脚以它为起点，所以它判得太松，拨线杆会扫到还在微动的机针，判得太紧，剪线周期就拖长。第二，evt_flush_until_stop() 处理那些结束角设在停针角之后的行，例如松线：主轴停在 70°，永远到不了 430° 以外的结束角，必须在停稳时统一关掉。

20.3.4 自动回针：针数计数与切换角

回针的关键是在送布牙沉在针板下面时切换方向（第 14 章，114.2°–325.8°，空闲角 211.6°）。固件在每一针的 114.2° 发令，倒缝电磁铁的延迟设 18–22 ms（示意；它推连杆和弹簧，比剪线电磁铁慢），切换必须在 325.8° 以前完成，留 10° 余量，转速上限 n = 201.6 / (6t)：18 ms 时 1870 r/min，22 ms 时 1530 r/min。所以原型的回针转速取 1500 r/min，最慢的 22 ms 折合 198°，仍在 201.6° 以内。针数在角度中断里数，每过一次 114.2° 记一针：

/* bt.c — 起缝回针：先倒缝 bt_n 针，再正缝；在送布空闲角内切换 */
#define BT_SWITCH_X10  1142                       /* 114.2°：送布牙刚沉到针板下 */
static volatile uint8_t bt_left;                  /* 剩余回针针数 */

void bt_start(uint8_t n) { bt_left = n; sol_on(SOL_BT); spindle_limit(P.bt_rpm); }

void bt_count_isr(int32_t prev, int32_t now)      /* now、prev 为 0..3599 的单转角 */
{
    if (bt_left == 0) return;
    if (prev < BT_SWITCH_X10 && now >= BT_SWITCH_X10) {
        if (--bt_left == 0) { sol_off(SOL_BT); spindle_limit(P.max_rpm); }
    }
}

注意起点：踩下脚踏以前主轴停在上针位 70°，bt_start() 在启动前就给倒缝电磁铁通电，主轴静止时切换没有时序问题，所以第一针的送布已经是倒向的；此后每跨过一次 114.2° 减一针，减到零时断电，切回正向的动作正好从空闲角的起点开始。回针针迹对不齐的机械原因（间隙、布料弹性）第 14 章讲过，原型上用“回针补偿”参数在第一针和最后一针单独微调切换角，验收时用相机量（20.5 节）。

20.3.5 脚踏曲线与速度曲线

脚踏是一个 0.5–4.5 V 的模拟量。原型用分段映射：前掌踩下（2.1–4.3 V）调速，中位（1.5–2.1 V）停，后跟轻踩（0.9–1.5 V）抬压脚，后跟踩到底（< 0.9 V）剪线；每段边界留 0.1 V 的回差，免得在边界上来回跳；超出 0.3–4.7 V 当作传感器断线。调速段用平方曲线，脚尖刚踩下时转速变化慢，便于对位：

/* pedal.c — 脚踏电压 → 指令（后台任务 1 kHz，已做 8 点滑动平均） */
pedal_cmd_t pedal_map(float v)
{
    static pedal_cmd_t last = PED_NEUTRAL;
    const float h = (last == PED_RUN) ? 0.1f : 0.0f;          /* 回差 */
    if (v < 0.3f || v > 4.7f)        return fault(F_PEDAL_WIRE), PED_FAULT;
    if (v < 0.9f)                     return last = PED_TRIM;
    if (v < 1.5f)                     return last = PED_LIFT;
    if (v < 2.1f - h)                 return last = PED_NEUTRAL;
    float u = (v - 2.1f) / 2.2f; if (u > 1.0f) u = 1.0f;
    g_rpm_cmd = P.min_rpm + (P.max_rpm - P.min_rpm) * u * u;   /* 200..4000 r/min */
    return last = PED_RUN;
}

脚踏给出的只是“想要的”转速，速度曲线再加上第 14 章的几条限制：慢起针（起缝回针以后的前 3 针限 400 r/min），加减速度不超过伺服能力的 60%（约 2650 rad/s²）。按这个加速度，400→4000 r/min 要 0.14 s、5.2 转，4000→300 r/min 也是 0.15 s、5.2 转。限幅放在控制任务里，对脚踏指令做斜坡，而不是放进伺服驱动器的加减速参数里，因为剪线前的减速要按针数而不是按时间来安排。

20.4.1 上电检查

第 0、1 步不让主轴转。先确认急停真的能断：按下急停，用万用表量电磁铁驱动板的 24 V 和伺服驱动器的使能端，必须都断开。再在网页参数界面上逐路点动电磁铁，每路看三样：机构动作对不对（推的是哪根杆）、动作方向对不对（推还是拉）、电流回读的波形上有没有第 13 章讲的那个“凹口”。凹口出现，说明衔铁确实在吸合时运动了；没有凹口，可能是衔铁卡住或机构顶死。

20.4.2 编码器方向与 Z 相对位

编码器装在电机上，它的 Z 相刻线在码盘上的位置和主轴的上止点没有任何关系；电机装反方向、或驱动器转发时 A、B 对调，计数方向也可能反。所以第一件事是让固件读出的角度和书中的约定一致：正转时增大，0° 正好是针杆上止点。

方向　手轮正转（操作者看手轮，向自己方向转），看读数增大还是减小。减小就在参数里把计数方向取反。真机上这一步不能省：方向反了，伺服速度环就是正反馈，一启动就飞车，驱动器会报“超速”或“编码器异常”。

Z 相偏置：为什么不直接找上止点　最直接的想法是转手轮，用百分表找针杆的最高点，记下那时的读数。问题是曲柄滑块在上止点附近几乎不动：按第 3、8 章的针杆尺寸（r = 15.5 mm，l = 55 mm），离上止点 1.8° 时针杆只下降 0.01 mm，百分表读不出来，所以“找最高点”会有 ±1.8° 的不确定度（图 20-5 右）。

对称两点法　改在针杆运动最快的地方测。对心曲柄滑块的位移曲线关于上、下止点对称，于是：选一个百分表读数，例如针杆离上止点 12.00 mm；正转手轮，下行经过这个读数时记下编码器读数 r1，继续转，上行再经过时记下 r2。两次读数的平均就是下止点：

\[ \varphi_{BDC} = \frac{r_1 + r_2}{2}, \qquad \Delta = 180^\circ - \varphi_{BDC} \]

把偏置加上 Δ 写入参数即可（r2 若跨过了 360°，先加 360° 再平均）。在 12 mm 处针杆的速度是 0.26 mm/°，百分表 0.01 mm 的分辨率只对应 0.04°，两次读数取平均后标定不确定度在 0.05° 以内，比直接找上止点好四十多倍（图 20-5）。

算例　虚拟实验 20-1 里的那台原型，计数方向反、Z 相刻线在主轴 137.6° 处。把方向取反、偏置为 0 时，12.00 mm 处读到 r1 = 307.6°、r2 = 137.2°；r2 跨过了 360°，平均值为 (307.6 + 137.2 + 360)/2 = 402.4°，即 42.4°，Δ = 180° − 42.4° = 137.6°，写入后读数与主轴角一致。用直驱或 1:1 带传动时，这个偏置每次上电都有效；用非整数传动比时则不然，见 20.6 节。

20.4.3 速度环与位置环整定

先做惯量辨识。在转矩模式下给 1.0 N·m 的转矩，测从静止到 1000 r/min 的时间。第 13 章算例的 J = 6×10⁻⁴ kg·m²、摩擦 0.15 N·m，算得约 75 ms；实测时间长，说明惯量大了（例如换了更重的手轮），按比例修正驱动器的惯量参数。然后按第 13 章的顺序整定：先让速度环硬起来，带宽 Kv/J = 0.2 / 6×10⁻⁴ ≈ 333 rad/s；位置环增益取带宽的四分之一到二分之一，标准的 200 s⁻¹ 已是带宽的 0.6 倍、接近上限，不要再加。积分时间 12 ms，用来消除摩擦造成的静差。判据用第 13 章的四条：超调 ≤ 0.5°，停稳 ≤ 60 ms，静差 ≤ 0.05°，转矩饱和 ≤ 5 ms。虚拟实验 13-1 可以先在模型上练一遍。

20.4.4 电磁铁时序标定：用转角，不用时间

电磁铁的延迟最后要折算成转角，所以标定也直接在转角上做。方法是：不穿线、不放布，让主轴以剪线转速匀速转，固件在某个固定角 φc 给剪线电磁铁通电，同时以 10 kHz 记录线圈电流。电流波形上的凹口谷底就是衔铁吸到底的时刻（第 13 章），记下这一刻的主轴角 φp，吸合角 Δφ = φp − φc。在 200、300、500 r/min 各做 20 次，Δφ 对转速作图应是一条过原点的直线，斜率就是 6t。这样得到的 t 已经包含了驱动板、线缆和实际的机构负载，比用示波器在台架上单独测电磁铁更接近真实。

释放的标定类似，用断电后电流降到零、再加上衔铁回程的机械时间；后者没有电信号，可以在动刀上贴一小片反光纸，用光电传感器看它回到原位的那一刻。标定时还要做一次“冷、热”对比：连续剪线 10 分钟让线圈热起来，再测一次，看吸合角变化多少。算例的模型给出 8 Ω 到 9.5 Ω 时，24 V 下吸合从 6.9 ms 变到 8.0 ms，300 r/min 时差 2°，这就是事件表要留余量的原因之一。

20.6 包缝机原型：差在哪里

有了平缝机原型，包缝机原型 WQ-SC/OL 的大部分东西可以直接搬过来：同一块主控、同一个伺服驱动器、同一块电磁铁驱动板、同一个电源和网关。变的是四件事：转速更高，所以主轴的传动和惯量要重算；不需要剪线电磁铁，改成链线切刀和吸风；要用布边光电传感器实现“布到即起、布走即停”；差动送布可以选做电子的。图 20-7 是它的构成和状态机。

20.6.2 不用剪线电磁铁：链线切刀与吸风

包缝机没有梭芯，缝完一段后机针和弯针仍带着线继续成圈，在布后面形成一条链线（第 9 章）。所以它不需要平缝机那样在一转之内精确完成的剪线：只要布走以后再多缝几针，让链线长到 30–40 mm，停车以后用一把气缸驱动的切刀把链线切断，同时打开吸风把线头吸走。这件事对时间不敏感，电磁阀十几毫秒、气缸几十毫秒的响应（第 13 章）完全够用，算例取切刀阀通电 60 ms、吸风 300 ms。气阀线圈也是 24 V 电感负载，接在同一块电磁铁驱动板上，只是不用强激磁。

20.6.3 布边光电传感器：布到即起、布走即停

光电传感器装在针前 ds = 25 mm 处，布遮住它就“布到”，离开它就“布走”。要算的是距离和针数。7000 r/min、针距 3 mm 时布速 350 mm/s，传感器 1 ms 的响应对应 0.35 mm，可以忽略；但如果去抖用 20 ms，就是 7 mm，到了 3000 r/min 又变成 3 mm。所以去抖不按时间按针数：连续 2 针都看到布才算布到，对应 6 mm，与转速无关。这和剪线事件按转角而不按时间是同一个道理。

布走以后，还要缝 N1 = ds/s = 25/3 ≈ 9 针布尾才走到针下，再缝 N2 = Lc/s = 40/3 ≈ 14 针链线，一共 23 针后停车。问题在于高速时停不下来：按表 20-7 的 1:1.25 方案，从 7000 r/min 以 60% 能力减速到停要转 15.8 转，也就是 15.8 针。如果等 23 针缝完才开始减速，链线会多出将近 16 针、约 47 mm。固件要“提前减速”：剩余针数 ≤ Nb 时开始减速，Nb 随转速平方变化，

\[ N_b = \frac{\omega_s^2}{2\,\alpha_s}\cdot\frac{1}{2\pi}, \qquad \alpha_s = i\,\alpha_m \]

7000 r/min 时 Nb = 15.8，要在布走以后第 7.2 针就开始减速，这时布尾还没到针下；4000 r/min 时 Nb = 5.2，在第 17.8 针开始（图 20-8）。

状态机就是图 20-7 下方那一行：WAIT → RUN → TAIL → STOP → CUT → WAIT。核心代码如下，针数在角度中断里数（每过一次上针位记一针），减速的判断放在 1 kHz 任务里：

/* ol_sm.c — 包缝机原型：布到即起、布走即停、延时切链（1 kHz，节选） */
case OL_WAIT:
    if (pe_cover_stitches() >= 2 || pedal_run())  { spindle_set_speed(P.run_rpm); sm_enter(OL_RUN, 0); }
    break;
case OL_RUN:
    if (pe_clear_stitches() >= 1) {                /* 布离开传感器 */
        tail_left = P.n1 + P.n2;                   /* 9 + 14 = 23 针 */
        sm_enter(OL_TAIL, 0);
    }
    break;
case OL_TAIL: {                                     /* tail_left 在角度中断里每针减 1 */
    float nb = brake_revs(spindle_rpm());           /* ω²/(2α)/(2π)，α 取能力的 60% */
    if (pe_cover_stitches() >= 2) { sm_enter(OL_RUN, 0); break; }   /* 下一片布接上来 */

    break; }
case OL_STOP:
    if (spindle_stopped(5, 10, 10)) {
        valve_pulse(VLV_CUT, 60);                   /* 切链 60 ms */
        valve_pulse(VLV_SUCK, 300);                 /* 吸风 300 ms */
        log_chain(tail_left_at_stop(), sm_elapsed_ms());
        sm_enter(OL_WAIT, 0);
    }
    break;

TAIL 状态里有一行容易漏掉：如果下一片布紧接着来了（流水作业里很常见），要回到 RUN 继续缝，而不是停车切链。这时链线把两片布连在一起，由后道工序剪开。

20.6.4 电子差动送布（可选）

第 9 章讲过，差动比由差动摆杆上滑块的位置决定，D ≈ ld/lm。电子化最简单的做法是用一台闭环步进电机经丝杠（C-SCN-LEAD）推这个滑块。算例取 lm = 20 mm，D 从 0.7 到 2.0，滑块行程 26 mm；丝杠导程 1 mm、电机 200 步 × 8 细分，每微步 0.000625 mm，分辨率远远够用。以 10 mm/s 走完全程要 2.6 s，所以它是“按缝段切换”的，不是逐针调整：滑块在送布机构里每针受力，调整放在停车或低速时做。闭环步进的意义在于防止失步（第 13 章）：差动比悄悄变了，布边就从平整变成波浪，操作工一时还看不出来。

20.7 包缝机原型的调试与验收

调试步骤和表 20-4 一样，只是第 2 步换成“带传动下的方向与偏置”：先在电机侧标定方向，再用上针位传感器的边沿作主轴的参考，偏置的求法仍用对称两点法（包缝机的针杆斜 20°，百分表沿针杆方向架设即可，对称性不变）。第 4 步换成“传感器与气阀的标定”：用一条已知长度的布条以低速通过，记下传感器边沿对应的针数，核对 N1；切刀阀用电流回读看换向时刻，再用高速摄像或手动慢转看切刀到位。

20.9 模型的边界

本章的原型是“原理样机”，从 P0（能动）走到 P1（功能全），离工业产品还有一段明确的距离。

电磁兼容　原型的控制箱是敞开的，线缆是临时走的，没有做传导和辐射发射试验，也没有做静电、快速瞬变、浪涌的抗扰度试验（第 18 章）。车间里一台高频熨烫机就可能让编码器多计几个数，原型对此没有防护。这是进入 DVT（设计验证）阶段的主要工作之一。

寿命　推拉式电磁铁、联轴器弹性体、同步带、气缸密封件都有寿命。工业平缝机一天剪几千次线，一年就是上百万次，原型的 4 h 连续运转只能发现早期故障，不能说明寿命；需要加速寿命试验和磨损数据。

成本　原型用的是通用模块：一块能跑四种机器的主控板、一块 6 路的电磁铁驱动板，对一台平缝机来说都是“富余”的。工业产品会把主控、伺服驱动和电磁铁驱动合成一块板，元件数和成本都低得多，第 18 章的电控箱就是这样。原型的价值在于快速验证原理和参数，量产设计要另做。

安全认证　原型加了急停和联锁，但没有经过 ISO 10821、IEC 60204-31 的符合性评估，不能作为产品交给操作工使用。

模型本身　本章的数由一个简化模型算出：伺服是连续时间模型，电流环简化为一阶滞后，没有编码器量化和速度测量延迟；电磁铁模型没有考虑铁芯饱和、涡流和温度对弹簧的影响；剪断窗口 45°–65°、拨线和抬压脚的时间、包缝机的惯量、链线长度都是示意值；软件在环的随机扰动只包括电压、线圈温度、转速、摩擦和负载，没有包括机构的磨损和间隙。算出来的“1000/1000”说明的是：在这些假设下事件表的余量够了；整机测试台上的数才是验收的依据。

现场要点

  • 一步一步上电：先 24 V，再手转，再伺服，最后穿线；每一步有判据，过了再走下一步。
  • 编码器先查方向，再标偏置；偏置用对称两点法，不要在上止点附近“找最高点”。
  • 电磁铁的延迟在转角上标定，冷态、热态各测一次；事件表的余量要装得下电压和温度引起的变化。
  • 剪线转速一改，事件表就要改；先让电磁铁更快、更一致，再提高剪线转速。
  • 包缝机用带传动时，传动比选得让每主轴转的计数是整数，并加一个主轴上针位传感器。
  • 去抖、回针、链线长度都按针数而不是按时间算，这样它们才和转速无关。
  • 每条测试结果都带上固件版本号和事件表版本号。

第 20 章 习题

  1. 剪线转速 400 r/min，剪线电磁铁吸合延迟在 6.2–9.4 ms 之间，动刀要在 300°–330° 之间进刀。求吸合折合的转角范围、散布和使进刀范围居中的通电角。
    参考答案每毫秒 2.4°，吸合折合 14.9°–22.6°，散布 7.7°；平均提前 18.7°，通电角约 315° − 18.7° ≈ 296°，进刀 311°–319°。
  2. 平台指标要求电磁铁吸合折合转角 ≤ 20°。按最慢的 9.4 ms 算，剪线转速最高是多少？若提高强激磁电压使最慢吸合变为 6.0 ms 呢？
    参考答案20 /(6 × 0.0094) ≈ 355 r/min；20 /(6 × 0.006) ≈ 556 r/min。
  3. 标定编码器时，计数方向已改对、偏置为 0，在针杆离上止点 12.00 mm 处下行读到 307.6°、上行读到 137.2°。求应写入的偏置。为什么不直接在上止点附近找针杆最高点？
    参考答案上行读数跨过了 360°，平均 (307.6 + 137.2 + 360)/2 = 402.4°，即 42.4°；偏置 = 180° − 42.4° = 137.6°。上止点附近针杆几乎不动，离上止点 1.8° 时只下降 0.01 mm，百分表读不出，有 ±1.8° 的不确定度；12 mm 处 0.01 mm 只对应 0.04°。
  4. 包缝机原型用同步带，电机编码器每转 10000 计数。传动比（主轴/电机）分别为 1.25 和 1.4 时，每主轴转多少计数？哪一个会带来问题，为什么？
    参考答案8000；7142.857…。后者不是整数，Z 相每转落在主轴的不同角度上，不能用来校正主轴角，舍入误差会累积；应选整数计数的传动比，并加主轴上针位传感器。
  5. 包缝机原型 1:1.25 传动，7000 r/min 时减速到停需 15.8 转，减速转数与转速平方成正比。缝纫转速 5000 r/min、针距 3 mm、传感器在针前 25 mm、链线 40 mm，布走以后第几针开始减速？如果到第 23 针才开始减速，链线多出多长？
    参考答案Nb = 15.8 × (5000/7000)² ≈ 8.1 针，23 − 8.1 ≈ 第 14.9 针开始减速；不提前则多出约 8 针、约 24 mm。
  6. 布边传感器去抖用 20 ms，缝纫转速 6000 r/min、针距 2.5 mm 时，去抖期间布走了多远？换成“连续 2 针”去抖呢？哪一种更好，为什么？
  7. （讨论）20.5 节里，标定残差 0.7° 时剪线全部成功，停针却全部超差。结合 20.4.2 节和表 20-6，说明为什么验收要把“停针误差”和“剪线成功率”分成两条需求，而不是只看“剪线成功”。再想一想：如果要把这台原型推进到 EVT，你会先补哪三项测试？
