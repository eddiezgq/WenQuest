模型（示意，与本书 model20.py 相同）：名义间隙 0.07 mm；各环误差按正态分布，公差 = ±3σ；不调整时间隙 = 0.07 + 各环误差之和。装配时对着装上的那根针把间隙调到 0.07 mm（调整误差 ±0.01 mm），机壳孔位、针夹孔、梭尖尺寸和机针两环都被吸收，只剩针杆游隙和旋梭轴径向游隙；换针时机针两环变成新针的值。加工成本 = Σ 系数 × 0.03 / 公差 × 2（公差减半，成本加倍），装配调整每台 3 元。

模型（示意，与本书 model20.py 相同）：机臂看成单自由度系统，模态刚度 1×10⁸ N/m × (固有频率/190 Hz)²；激振力为一阶（平衡后残余，5000 r/min 时 300 N）和二阶（120 N），都与转速平方成正比、与往复质量成正比；响应 X = F/k × 1/√((1−r²)² + (2ζr)²)，r = 激振频率/固有频率；振动速度有效值 = 2πfX/√2；噪声按 5000 r/min 时 83.5 dB(A)（第 8 章说明书数据），按振动速度每加倍增加 6 dB 估算。判据：工作转速范围（到当前转速为止）内振动 ≤ 8 mm/s，当前转速噪声 ≤ 86 dB(A)（示意）。
