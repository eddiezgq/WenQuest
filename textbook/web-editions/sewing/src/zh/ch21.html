21.1 引子：两台“数控”缝制设备的原型

一所高校的实验室按第 20 章做出了平缝机原型，接着想做两件更难的事：一台能缝口袋盖的花样机，一台能织一小块提花样片的横机。有人提议买二手整机来改，算下来不划算：二手花样机的控制箱是封闭的，改不动；横机更贵，而且几百枚针的整机对教学来说太大。最后决定都自己搭，机械能用零件库就用零件库，电控全部用 WQ-SC 平台的模块。

动手之前，指导老师让学生先回答两个问题。第一，花样机原型的 X–Y 平台要多大的电机？第 15 章说 3 mm 针距、1.5 mm 布厚时离布窗口 203.4°，那么转速、加速度、电机转矩之间是什么关系？第二，缩比横机用自制的选针器，响应慢、离散大，机头最多能跑多快？控制周期 1 ms 的 MCU 够不够，是否非上 FPGA 不可？

这两个问题都不能靠试出来。电机买小了，花样机只能在 500 r/min 下缝；选针器做慢了，横机只能慢慢爬。正确的做法是先做时序预算：从窗口出发，一步步算到加速度、转矩、提前量和抖动，定下零件，再动手。本章的两台原型就是这样设计出来的。

21.2 花样机原型的机械与电气构成

21.3 花样机原型的运动控制固件

21.3.1 从窗口到电机转矩：一条算到底的链

第 15 章已经算出：布加下模板厚 1.5 mm 时，针在 101.7° 入布、258.3° 出布，几何窗口 W = 203.4°。原型在两端各留 10°，给伺服的整定和延迟误差，实用窗口 Wu = 183.4°，从 268.3° 开始，到下一转的 91.7° 结束（图 21-2a）。

算例　求 3 mm 针距、主轴 1600 r/min 时 X 轴电机的峰值转矩。

第 1 步，求允许时间。转过 183.4° 用时

\[ \Delta t = \frac{W_u}{6n} = \frac{183.4}{6\times1600} = 19.1\ \text{ms} \]

第 2 步，求所需加速度。原型固件用 S 形（七段式）加减速：每半程里加速度按 1/8 时间斜升、1/4 恒定、1/8 斜降，加速度连续，不激起平台振动。对这种规律数值积分，得峰值加速度系数 C = 5.33、峰值速度系数 2.0（等加速等减速为 4 和 2，第 15 章）：

\[ a = C\,\frac{s}{\Delta t^2} = 5.33\times\frac{0.003}{0.0191^2} = 43.9\ \text{m/s}^2, \qquad v_{pk} = 2.0\,\frac{s}{\Delta t} = 0.314\ \text{m/s} \]

vpk 对应电机 0.314/0.010 × 60 ≈ 1885 r/min，低于额定 3000 r/min。

第 3 步，求转矩。丝杠传动把直线加速度换成电机角加速度 α = 2πa/Ph，负载惯量折算为 m(Ph/2π)²。四项依次为电机转子 0.30、两只带轮 0.01、丝杠 0.25、滑座 0.10（单位 10⁻⁴ kg·m²）：

\[ J = J_m + 2J_p + \frac{\pi\rho L d^4}{32} + m\left(\frac{P_h}{2\pi}\right)^2 \approx 0.668\times10^{-4}\ \text{kg}\cdot\text{m}^2 \]
\[ T = J\,\frac{2\pi a}{P_h} + \frac{\mu m g P_h}{2\pi\eta} = 0.668\times10^{-4}\times\frac{2\pi\times43.9}{0.010} + 0.004 \approx 1.84\ \text{N}\cdot\text{m} \]

Y 轴运动质量 12 kg，同样算得 2.27 N·m，都低于峰值 3.8 N·m。丝杠方案的特点在这里看得很清楚：摩擦项只有 0.004 N·m，转矩几乎全花在加速电机自己的转子和丝杠上，负载质量只占一小部分。

第 4 步，用发热定设计加速度。和第 15 章一样，真正卡住的是均方根转矩。S 形规律在移动段内的 rms 形状系数为 0.816，最坏情况每针都用满窗口，移动段占 183.4/360：

\[ T_{rms} = T_{pk}\times0.816\times\sqrt{183.4/360} = 0.58\,T_{pk} \le 1.27\ \text{N}\cdot\text{m} \;\Rightarrow\; T_{pk} \le 2.2\ \text{N}\cdot\text{m} \]

反算得 X 轴可持续的加速度约 52 m/s²，Y 轴约 42 m/s²。原型取设计值 X 50 m/s²、Y 40 m/s²（rms 分别为 1.22、1.21 N·m）；短时的峰值能力（X 72、Y 59 m/s²）留作余量，不进规划。

第 5 步，反过来给每种针距定转速上限：Δt = √(C·s/a)，ncap = Wu/(6Δt)，再与机头限速 2500 r/min 取小。结果见表 21-5 和图 21-2b。

21.3.2 固件结构

固件沿用第 19 章的框架：时间基准是主轴转角，剪线、拨线、中压脚按事件表触发，状态机多了 CLAMP（压框）、JUMP（空走）和 HOME（回原点）三个状态。新写的是三块：花样文件解析、前瞻限速、窗口内插补（图 21-3）。X、Y 两个位置轴，不论用伺服还是闭环步进，都挂在 HAL 的 stepper_* 接口下，换电机只改驱动文件。

原型用一种自定的示意格式 .wqp，按第 15 章“命令 + ΔX + ΔY、整数增量”的思路，把每条记录压成 3 个字节：

表 21-6　.wqp 花样文件格式（本书示意格式）
部分字节内容
文件头16"WQP1"、版本、单位（1 = 0.1 mm）、记录数（u16）、最高转速/10（u16）、起针点 X、Y（int16）、CRC-16
记录3cmd（u8）、dx（int8）、dy（int8）；dx、dy 以 0.1 mm 为单位，范围 ±12.7 mm，正好是第 15 章说的最大针距

解析时做三件事：校验 CRC；把增量累加成绝对坐标，检查是否超出 300 × 200 mm 行程；把记录放进针队列。用整数累加，几千针以后也没有舍入误差。

typedef struct { int8_t dx, dy; uint8_t cmd, flags; uint16_t n; } stitch_t;

int wqp_parse(const uint8_t *buf, int len, stitch_t *q, int qmax)
{
    if (len < 16 || memcmp(buf, "WQP1", 4) != 0) return -E_FORMAT;
    if (crc16(buf, 14) != rd_u16(buf + 14))    return -E_CRC;
    int nrec = rd_u16(buf + 6);
    int32_t x = (int16_t)rd_u16(buf + 10), y = (int16_t)rd_u16(buf + 12);  /* 0.1 mm */
    const uint8_t *r = buf + 16;
    int k = 0;
    for (int i = 0; i < nrec && k < qmax; i++, r += 3) {
        uint8_t cmd = r[0]; int8_t dx = (int8_t)r[1], dy = (int8_t)r[2];
        if (cmd == CMD_END) break;
        if (cmd == CMD_SEW || cmd == CMD_JUMP) {
            x += dx; y += dy;
            if (x < 0 || x > 3000 || y < 0 || y > 2000) return -E_TRAVEL;   /* 300 × 200 mm */
        }
        q[k++] = (stitch_t){ dx, dy, cmd, 0, 0 };
    }
    return k;   /* 针队列长度，交给 plan_speed() */
}

21.3.4 前瞻限速：主轴自动降速

表 21-5 给出每针自身的上限，但主轴不能一针就从 2092 跳到 1080 r/min。第 15 章的前瞻算法（反向一遍、正向一遍）在原型里写成下面的函数，在后台任务里对整段花样算一次。每轴分别算，取较慢的一轴；起针和剪线前各 2 针限速 400 r/min；每针允许的转速变化 Δn = 300 r/min。

#define WU     183.4f           /* 实用窗口，度 */
#define C_S    5.333f           /* S 形峰值加速度系数 */
#define A_X    50.0f            /* m/s²，按发热定 */
#define A_Y    40.0f
#define N_HEAD 2500
#define N_SLOW 400
#define DN     300

static float t_axis(float s_mm, float a)            /* 走 s 所需时间，s */
{ return s_mm <= 0.f ? 0.f : sqrtf(C_S * s_mm * 1e-3f / a); }

void plan_speed(stitch_t *s, int N)
{
    for (int i = 0; i < N; i++) {
        float t = fmaxf(t_axis(fabsf(s[i].dx) * 0.1f, A_X),
                        t_axis(fabsf(s[i].dy) * 0.1f, A_Y));
        float cap = (t > 0.f) ? WU / (6.f * t) : N_HEAD;
        s[i].n = (uint16_t)fminf(cap, N_HEAD);
        if (s[i].flags & (F_START2 | F_TRIM2)) s[i].n = MIN(s[i].n, N_SLOW);
    }
    for (int i = N - 2; i >= 0; i--)                     /* 反向：为后面的慢针提前减速 */
        s[i].n = MIN(s[i].n, s[i + 1].n + DN);
    uint16_t prev = N_SLOW;                               /* 正向：加速也不能太猛 */
    for (int i = 0; i < N; i++) { s[i].n = MIN(s[i].n, prev + DN); prev = s[i].n; }
}

算例　一串沿 X 的 2 mm 针中间夹一针沿 Y 的 6 mm 针（第 5 针）。每针上限为 2092、2092、2092、2092、1080、2092……，前瞻后的转速为 2092、1980、1680、1380、1080、1380、1680、1980 r/min：控制器提前 4 针开始降速，到长针时刚好降到 1080 r/min。

21.3.5 窗口内的单针插补

插补中断每 1 ms 执行一次。它不看时间，只看主轴转角：先用预测角 φp = φ + ω·Td 补偿从发命令到电机跟上的总延迟（Td = 1.5 ms，含 CAN FD 传输和驱动器内的一个插补周期；1600 r/min 时相当于 14.4°），再算 τ，查 S 形表得 f(τ)。窗口以外命令保持不变，这就是“针在布中模板不动”的软件保证。

#define PHS10  2683            /* 窗口起点 268.3°（0.1° 单位）*/
#define WU10   1834            /* 窗口宽 183.4° */
#define TD_US  1500            /* 总延迟 */
static int32_t x0_um, y0_um;   /* 本针起点 */
static stitch_t cur; static uint8_t moving;

void xy_tick_1ms(void)                         /* 1 kHz，最高优先级之一 */
{
    int32_t phi = spindle_angle_d10();         /* 0..3599 */
    int32_t w   = spindle_speed_d10_per_ms();  /* 0.1°/ms */
    int32_t d   = phi + w * TD_US / 1000 - PHS10;
    d %= 3600; if (d < 0) d += 3600;           /* 离窗口起点多少（0.1°）*/
    int32_t x = x0_um, y = y0_um;

    if (d <= WU10) {                           /* 在实用窗口内 */
        if (!moving) { if (!queue_peek(&cur)) goto out; moving = 1; }
        uint32_t f = scurve_q15((uint32_t)d * 32768u / WU10);   /* f(τ)，0..32768 */
        x = x0_um + (int32_t)cur.dx * 100 * (int32_t)f / 32768;
        y = y0_um + (int32_t)cur.dy * 100 * (int32_t)f / 32768;
    } else if (moving) {                        /* 窗口结束：落到终点，弹出这一针 */
        x0_um += cur.dx * 100; y0_um += cur.dy * 100;
        x = x0_um; y = y0_um; queue_pop(); moving = 0;
        spindle_set_speed(queue_next_speed()); /* 下一针的计划转速 */
    }
out:
    stepper_set_pos(AX_X, x); stepper_set_pos(AX_Y, y);
    stepper_sync();                             /* CAN FD 同步帧：两轴同时生效 */
    trace_log(phi, x, y);                       /* 调试与验收记录（21.4 节） */
}

这段代码有三个地方值得留意。一是 S 形表用 Q15 定点数存 1025 个点，查表加线性插值，中断里没有浮点除法。二是主轴转速命令在每针结束时下发，转速变化落在离布窗口里，不影响针在布中的那一段。三是只要窗口外命令不变，即使上位的规划算错了，模板也不会在针在布中时被命令移动；剩下的风险只来自伺服跟不上，这要靠 21.4 节的测试去查。

空走　JUMP 记录不在窗口里走。状态机先执行剪线（第 20 章的事件表），主轴停在上针位，中压脚抬起，然后 X、Y 按梯形速度曲线走到下一段起点：此时不受离布窗口限制，取每轴的短时能力（X 约 70 m/s²、速度 0.5 m/s，对应电机 3000 r/min）。一次 100 mm 的空走约需 0.2 s 加上剪线和起针的时间，所以花样分段越少，周期越短（第 15 章）。空走结束后中压脚放下，以 400 r/min 起针，再交还给前瞻算出的转速。

现场要点

  • φ 必须来自主控直接接的主轴编码器，不能从总线上的驱动器读，否则多出一个总线周期的延迟。
  • Td 不要估，要测：低速时按 21.4 节的办法记录命令与实际位置，两者的相位差就是 Td。
  • 先用 300–500 r/min 和“单步”功能试缝新花样，再按前瞻结果提速。

21.4 花样机原型的调试与验收

调试按“由静到动、由单轴到同步”的顺序进行，每一步都有判据，结果按第 22 章的格式写成测试报告，并发到 wq/sewing/proto/ps01/measurement 主题。

第 1 步：回原点　每轴先慢速碰原点开关，再反向找电机编码器的 Z 相，以 Z 相为准。开关本身的重复性只有零点几毫米，Z 相是 1 μm 级。判据：连续回原点 20 次，重复性 ≤ 0.01 mm。

第 2 步：反向间隙与螺距误差补偿　丝杠螺母有预紧时间隙很小，但 1:1 带轮和支承轴承还会带进一点。用千分表或激光测距，在全行程上每 25 mm 一个点、正反两个方向各测一遍（做法参照 ISO 230-2 的双向定位测量）。正反向读数之差的平均值是反向间隙，写进参数表，换向时补；同一方向的误差曲线写成补偿表，固件在 stepper_set_pos() 里按位置线性插值叠加。判据（示意）：补偿后全行程定位误差 ≤ 0.02 mm，反向间隙残差 ≤ 0.005 mm。

第 3 步：坐标标定　模板里夹一张纸，主轴 300 r/min，在 200 × 200 mm 范围内按 50 mm 间距刺 5 × 5 个针孔，用相机或钢尺量孔的位置。整体平移就是针位相对平台原点的偏移；两个方向的比例误差修正每毫米计数；用两条对角线 d1、d2 求 X、Y 的垂直度偏差 δ ≈ (d1² − d2²)/(4ab)（a、b 为矩形边长），超过 0.1 mm/200 mm 就要调整 Y 导轨。

第 4 步：同步验证　这是花样机原型最关键的一项。以 1600 r/min 连续缝 3 mm 针距，插补中断里的 trace_log() 每 1 ms 记录 φ 与 X、Y 的命令值，伺服驱动器的跟踪功能同时以更高的频率记录电机编码器的实际值，统一按主轴角对齐。然后做两项统计：跟随误差（命令 − 实际）的最大值；每一针在 φ1–φ2（针在布中）期间实际位置的最大变化量。

图 21-4 是一次调试的对比。初调时位置环约 40 Hz、加速度前馈只开了一半、没做延迟补偿，跟随误差达 0.22 mm，模板在针入布后还在“滑”，针在布中位移 0.18 mm，这样缝出来针孔会被拉大。把位置环提到约 100 Hz（丝杠刚度允许，21.2.1 节）、加速度前馈加到 95%、按预测角查表后，跟随误差降到 0.006 mm，针在布中位移 0.002 mm，即 2 个编码器计数。

21.5 缩比横机原型的构成

工业横机有几百枚针、两到三个系统、两块针床。教学原型把它缩到最小而原理不丢：单系统、单针床、60 枚针、E5（针距 5.08 mm）。粗针距有两个好处：针槽、三角、选针片都大，用普通铣床和激光切割就能做；选针时间宽，自制的选针器也来得及。60 针 × 5.08 mm = 304.8 mm，一张 A4 纸宽，正好放在实验台上。P0 先只做编织和不编织（一个选针点 S1），P1 再加第二个选针点 S2 做集圈，双针床和摇床留到以后。

机头由一台 200 W 伺服经 5M 同步带驱动，带轮 A-PUL-HTD 5M-20-15 一转走 100 mm，电机编码器 10000 计数/转，机头位置分辨率 0.01 mm。机头 2.5 kg，加速度 10 m/s²（与第 17 章相同）时，所需推力约为 2.5 × 10 + 摩擦 2.5 N + 针踵过三角的阻力 15 N ≈ 42.5 N，电机峰值转矩约 0.69 N·m，匀速时约 0.28 N·m；2 m/s 对应 1200 r/min，200 W 伺服都在能力之内（示意值）。机头位置可以只用电机编码器，也可以在导轨旁贴一条磁栅尺直接测；后者把带的弹性排除在外，加速时带伸长约 0.03 mm（按第 15 章的带刚度估算），对 E5 原型可以忽略，换细针距时再考虑。

选针器是这台原型的核心，也最值得自己做。它由 8 个小电磁铁叠成 8 段，选针片的针踵按 8 种高度循环排列：第 i 枚针由第 k = i mod 8 段负责。这样同一段相邻两次动作隔 8 个针距，机头 0.6 m/s 时是 67.7 ms，远大于一次吸合加释放的 3 ms。自制电磁选针器的响应时间按 1.5 ms、离散 ±0.3 ms 估（示意，比第 17 章的工业选针器慢一倍多）；压电选针器响应快一个数量级、离散也小，但需要 100 V 以上的驱动，原型 P0 不用。

哪些件自制、哪些用库，原则是：决定精度和寿命、又有标准规格的，用零件库；决定这台机器“是横机”的，自己做。导轨、带轮、轴承、丝杠、蜗杆属于前一类，直接按库里的规格选；针床、三角座、选针片、纱嘴属于后一类，库里不会有，也不该有，它们的图纸就是这台原型最重要的设计成果。自制件做完要测三个尺寸：针槽槽距的累积误差（60 槽累计不超过 0.1 mm）、三角座与针床面的间隙、选针片针踵的 8 种高度。

21.6 横机原型的固件

21.6.1 以机头位置为时间基准

第 19 章的固件框架在横机上只改一处：时间基准从“主轴转角”换成“机头位置”。第 i 枚针在位置 xi = c + (i + ½)p 处应当被选中（c 是换向余量，即选针点从起步处到第 0 枚针的距离）。选针器从接到命令到衔铁动作要 Tr，所以命令要提前：

\[ x_{cmd} = x_i - v\left(T_r + \tfrac{1}{2}T_q\right) \]

这里比第 17 章多了一项 Tq/2，Tq 是“触发量化”：MCU 每个控制周期 Tc 才查一次机头位置，过了命令点也要等到下一个周期才发出，平均晚半个周期；FPGA 每个编码器计数都比较一次，Tq 只是走过一个计数（0.01 mm）的时间。

21.6.2 选针时序预算

衔铁实际动作的位置离理想位置有多远？把三个来源放在一起（图 21-6a）：

\[ |e|_{max} = v\left(\tfrac{1}{2}T_q + J\right) + |e_{lead}| \]

其中 J 是选针器响应时间的离散（随线圈温度、电源电压变），elead 是提前量本身算错的部分（固定提前量在加速区就会算错，第 17 章图 17-4）。判据两条：|e| ≤ 0.25p 选针片还能被正确推入（或让开），超过就错选；验收要求 ≤ 0.1p，留 2.5 倍余量。

算例　E5，机头最高 0.6 m/s，加速度 10 m/s²，换向余量 40 mm，MCU 控制周期 1 ms，按实时速度算提前量。

如果不补偿，滞后就是整整 0.24p，接近错选的边界。0.6 m/s 已在验收线以内，最多能跑多快？令 v(Tc/2 + J) = 0.1p，得

\[ v_{max} = \frac{0.1p}{T_c/2 + J} = \frac{0.508\ \text{mm}}{0.5 + 0.3\ \text{ms}} \approx 0.635\ \text{m/s} \]

这时一行 0.895 s、约 4020 行/h。把控制周期缩到 0.5 ms 和 0.25 ms，上限分别升到 0.91 和 1.16 m/s。改用 FPGA 逐计数比较后，量化只剩半个计数（0.005 mm），上限由选针器自己的离散决定：

\[ v_{max} \approx \frac{0.1p - 0.005}{J} = \frac{0.503}{0.3} \approx 1.68\ \text{m/s} \]

按完整模型（考虑加速段内速度的变化）算得 1.66 m/s，一行 0.546 s、约 6590 行/h。速度提高到 2.6 倍，产量只提高 64%，因为加减速时间 v/a 和换向停顿不随速度缩短——这和第 17 章 17.8 节的结论相同。图 21-6b 还说明两件事：一是 MCU 1 ms 方案到 1.59 m/s 就会开始错选，不只是“验收不过”；二是对 E7（p = 3.63 mm），同样的选针器和 FPGA 只能跑 1.16 m/s，MCU 1 ms 只有 0.45 m/s。

结论很明确：E5 原型 P0 用 MCU、1 ms 控制周期跑 0.6 m/s 足够；要提速或换细针距，先上 FPGA，再改进选针器的离散。单纯把选针器做快（减小 Tr）对上限没有帮助，因为 Tr 已被提前量补偿，限制速度的是它的离散 J。

设计要点

  • 先算“离散”，再算“延迟”：延迟能补偿，离散不能。选针器的线圈要用强激磁加恒流维持（第 13 章），让电流上升时间不随电源电压和温度变，这比单纯把它做快更有效。
  • 提前量用实时速度，并把量化的半个周期一起补上；固定提前量只在全速段对，原型上没有理由用它。
  • 多段选针器的段数按“同段间隔 n段·p/v ≥ 2Tr，并留 2 倍以上余量”定；E5 原型 8 段绰绰有余，留给以后换细针距。
  • 速度上去以后，换向余量、制动距离和限位开关的位置要一起重算。

21.6.3 从花型行到选针位图

主控按“行”工作（第 17 章 17.5 节）。每到换向区，它把下一行的意匠数据（K、T、·）拆成两个选针点的位，按 k = i mod 8 分段，再按机头走向把每枚针的目标位置排成表，写进机头板的“空闲”缓冲（图 21-7）。目标位置以编码器计数表示：targeti = (c + (i + ½)p)/0.01 mm，第 0 枚针是 4254，第 1 枚是 4762……提前量不写进表，由机头板在比较时按实时速度减去。

typedef struct { int32_t target[60]; uint8_t s1[60], s2[60]; int n; int8_t dir; } row_t;

void build_row(const char *design, int8_t dir, row_t *r)    /* design: 60 个 'K' / 'T' / '.' */
{
    r->n = 60; r->dir = dir;
    for (int k = 0; k < 60; k++) {
        int i = (dir > 0) ? k : 59 - k;                         /* 按经过的先后排序 */
        int32_t x_um = C_UM + (2 * i + 1) * P_UM / 2;           /* c + (i + 1/2) p */
        r->target[k] = (dir > 0) ? x_um / 10 : (STROKE_UM - x_um) / 10;  /* 0.01 mm 计数 */
        r->s1[k] = (design[i] != '.');                          /* 编织或集圈：S1 选 */
        r->s2[k] = (design[i] == 'K');                          /* 只有编织：S2 选 */
    }
}

21.6.4 逐针触发（MCU 版）

P0 用机头板上的 MCU 做逐针触发。它在 1 ms 的控制周期里（或者用定时器比较中断，周期更短）执行下面的函数；段号就是 k & 7，因为相邻的针按顺序轮流落在 8 段上。

#define TR_US 1500            /* 选针器响应时间，标定得到（21.7 节）*/
#define TC_US 1000            /* 控制周期 */
static row_t *row; static int k;

void sel_tick(void)
{
    int32_t pos = carriage_pos();                 /* 本方向的行程坐标，0.01 mm 计数 */
    int32_t v   = carriage_speed();               /* 计数/ms，用最近 1 ms 的增量 */
    int32_t lead = v * (TR_US + TC_US / 2) / 1000;
    while (k < row->n && pos + lead >= row->target[k]) {
        if (row->s1[k]) sol_pulse(SEL_S1_BASE + (k & 7), BOOST_US, HOLD_US);
        k++;                                      /* 一个周期里可能连发几枚针 */
    }
    if (k > 0 && pos < row->target[k - 1] - 2 * P_CNT)
        fault(F_SEL_SEQ);                         /* 位置倒退：编码器异常，停机 */
}

改用 FPGA 时，比较器和脉冲发生器的写法与第 17 章 17.5.2 节完全相同，MCU 只负责把 target、s1、s2 写进双缓冲 RAM；第 17 章的虚拟实验 17-3 可以直接拿来练这段 Verilog。

21.6.5 行程两端：换向、度目与纱嘴

21.7 横机原型的调试与验收

选针时序标定　Tr 不能只信计算或电磁铁样本，要在整机上标。方法是“两速扫描”：固件按一个初值（如 1.2 ms）算提前量，再加一个偏置 δ；机头分别以 0.3 m/s 和 0.9 m/s 织一种“选、不选”交替的测试行，每个 δ 织 30 行，统计选针正确率（用探针或相机检查每枚针是否被推起）。正确率达到 100% 的那段 δ 是通过带，取它的中点。中点随速度移动，斜率就是 Tr 的误差（图 21-8）。

这个方法同时给出另一个有用的数：通过带的宽度。低速时带宽约 2 mm，高速时只剩 1.2 mm，宽度缩小的速率就反映了离散 J。标定好以后，Tr 写进参数表并带版本号上报；线圈换了、电源电压改了，都要重标。

度目零点　每个度目步进先回零位开关，再以“刚好不成圈”的深度作为机械零点，用塞尺量弯纱三角相对针床口的高度，写进参数表。一般左、右两个三角要分别标定，否则来回两行的线圈长度不一样，织物会出现横条。

牵拉张力　用张力摆杆的霍尔角度做闭环：设定值按组织给出（示意：平针 3 N），步进每行补走一段，使摆杆角度回到设定区间。起头几行织物够不到罗拉，先用重锤挂住。

现场要点

  • 织物上某一纵行总出错，先查是哪一段：错的针号 mod 8 都相同，就是那一段的线圈或衔铁有问题，不是时序问题。
  • 错针集中在织物两侧，多半是加速区：用了固定提前量，或换向余量太短。
  • 高速时错针随机分布，是离散 J 太大：查电源电压和线圈温度，或者降速、上 FPGA。
  • 机头板的连接器和拖链电缆是最常见的故障点（第 17 章），P0 就要选带锁扣的连接器。

21.9 模型的边界

本章的算例都建立在简化模型上，用到真实原型时要注意以下几点。

  • 花样机的伺服模型：图 21-4 用的是二阶跟随加前馈的理想模型，没有考虑丝杠的轴向弹性、导轨摩擦的非线性和带轮的齿隙，也没有考虑横梁的扭转（Y 轴单电机驱动时，横梁两端可能不同步）。实际的跟随误差和整定时间必须在样机上测。
  • 布料与模板：窗口按“针尖高于布加下模板”算，没有计入布料被针带起的高度，也没有计入中压脚抬起的时刻。厚料、弹性料要另外留余量（第 15 章）。
  • 转矩和发热：rms 转矩按“每针都用满窗口”的最坏情况估算，偏保守；电机的转矩–转速曲线、驱动器的电流限制、环境温度都没有计入。
  • 选针模型：把选针器当作“延迟 Tr、离散 ±J、均匀分布”的理想开关，没有考虑衔铁回弹、相邻段之间的磁耦合、过压电源在连续动作时的电压跌落。±0.25p 的允许窗口是示意值，实际值取决于选针片针踵和三角的几何形状，要在样机上用两速扫描测出来。
  • 机头位置：模型认为电机编码器读数就是机头位置；同步带在加速时伸长约 0.03 mm，E5 原型可以忽略，换 E12 以上的细针距时，应该改用直线编码器或者在模型里加上这一项。
  • 产量：行时间只算了单系统、单针床、固定的 0.1 s 换向停顿，不包括摇床、翻针和纱嘴换色的额外趟数，不能直接拿来估计工业横机的产量（第 17 章 17.8 节）。

第 21 章 习题

  1. 花样机原型，布加下模板厚 3 mm（第 15 章：几何窗口 192.6°），两端仍各留 10°。沿 Y 方向缝 4 mm 针距（a = 40 m/s²，S 形，C = 5.33），主轴最高能到多少？
    参考答案实用窗口 172.6°；Δt = √(5.33 × 0.004/40) = 23.1 ms；n = 172.6/(6 × 0.0231) ≈ 1250 r/min。
  2. 若想让 12 kg 的 Y 轴也用 50 m/s² 的设计加速度，400 W 电机还行吗？给出两种改法。
    参考答案峰值转矩 0.820 × 10⁻⁴ × 2π × 50/0.01 ≈ 2.58 N·m，低于峰值 3.8 N·m；但最坏 rms = 2.58 × 0.816 × √(183.4/360) ≈ 1.51 N·m > 1.27 N·m，连续缝会过热。改法：换额定转矩更大的电机；或减轻 Y 轴运动质量（如压框改铝型材、X 电机移到横梁外固定，改为 H 型带传动）；也可以在固件里加 I²t 热模型，只在短时间内允许 50 m/s²。
  3. 花样机原型主轴 2500 r/min 时，若忘了按 φ + ω·Td 查表（Td = 1.5 ms），模板动作会滞后多少度？两端各 10° 的余量够不够？
  4. 横机原型 E5、MCU 控制周期改为 0.5 ms，其余按 21.6 节算例，验收允许的最高机头速度约为多少？与 FPGA 方案相比还差多少？
    参考答案解析 0.508/(0.25 + 0.3) ≈ 0.92 m/s，完整模型约 0.91 m/s；FPGA 约 1.66 m/s。
  5. 如果把 8 段选针器换成单段（每枚针都由同一个电磁铁选），E5、FPGA、Tr = 1.5 ms 时，机头速度受哪条限制？换 E7 呢？
    参考答案单段要求 p/v ≥ 2Tr：E5 时 v ≤ 5.08/3 ≈ 1.69 m/s，与时序上限 1.66 m/s 很接近，几乎没有余量；E7 时 v ≤ 3.63/3 ≈ 1.21 m/s，时序上限 1.16 m/s。两者都卡得很紧，所以要用多段。
  6. 横机原型急停的制动加速度为 20 m/s²。机头 1.66 m/s 时制动距离是多少？限位开关应当装在哪里？
  7. 用两速扫描标定选针器：初值 Tr = 1.2 ms，0.3 m/s 和 0.9 m/s 时通过带中点分别为 0.09 mm 和 0.26 mm。Tr 应改为多少？为什么用两种速度而不是一种？
    参考答案斜率 (0.26 − 0.09)/(0.9 − 0.3) ≈ 0.28 ms，Tr ≈ 1.48 ms。只用一种速度时，中点偏移里混着选针点的几何偏移（与速度无关）和 Tr 误差（与速度成正比），两种速度才能把两者分开：斜率是 Tr 误差，截距是几何偏移。
  8. （讨论）用虚拟实验 21-1 完成三个任务，再结合表 21-13，说明“原型先用 MCU，量产再上 FPGA”和“原型一开始就上 FPGA”各有什么利弊。
