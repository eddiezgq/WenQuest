Output vs WIP limit (current rule; dashed line = current limit)

Model: a T-shirt with 6 operations (join shoulders 30 s, set collar 45 s, set sleeves 60 s, close side seams 50 s, hem sleeves 35 s, hem bottom 40 s); 10 operators, each skilled in 1–2 operations, efficiency 0.8–1.1; one hanger is launched every 5 s, and launching stops when the number of hangers on the line reaches the limit; a hanger takes 15 s from the main rail to a station, and if all stations are full it goes round the main rail once more (60 s) to be reassigned. “Fixed stations” sends work only to operators whose main operation it is; “Shortest queue” sends it to the operator with the fewest hangers queued; “Earliest finish” sends it to the operator estimated (from efficiency) to finish soonest. Times, skills and efficiencies are illustrative; results are the mean of 3 simulation runs.

Hand-off position for each garment (solid) and the theoretical balance position (dashed)

Bucket-brigade rule: when the last operator finishes a garment, they walk back and take over the garment from the operator before them; that operator in turn walks back and takes over from the one before; the first operator returns to the start and begins a new garment. An operator who catches up with the one ahead can only follow and wait (no overtaking). Walking-back time is neglected. Speed is work content completed per unit time (illustrative values). With “fixed segments” each operator always does 1/3, and output is set by the slowest operator.
