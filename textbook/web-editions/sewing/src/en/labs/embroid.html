Speed limit vs stitch length (current head count and drive force; dot: current setting)

Model (illustrative): the needle is out of the fabric for a 204° window (taken from Chapter 15); the frame completes one stitch along a cycloidal motion law, peak acceleration a = 2π s /T², T = 204° /(6n); equivalent Y-axis mass = 10 + 4 × number of heads kg (6 kg for a single head), friction 50 N, available acceleration = (drive force − 50 N) / mass; machine maximum 1100 r/min; a DST record holds at most 12.1 mm per coordinate direction (here the stitch is taken to lie along one direction). Number of heads vs machine efficiency (expected value; current break rate and handling time)

Model (illustrative): each head breaks λ times per 10,000 stitches, independently; a break on any head stops the whole machine; each break costs the set handling time (walk over, rethread, confirm) plus back-up and repair (back up b stitches at a repair speed of 600 r/min, counted twice for there and back); detection delay d stitches: after a break the machine sews d more stitches without thread before it stops, so if the back-up b is less than d, d − b stitches are left missing. 6 colour changes of 6 s each.
