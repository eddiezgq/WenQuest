Model (same as the book’s model21.py): operations and standard minute values are worked-example values (min/piece, allowances included). Several adjacent operations form a group shared by k operators, k = ⌈group work content ÷ takt time⌉; the operations in a group can be split among operators by piece count, and load per operator = group work content ÷ k. A group has at most 4 operators, 4 operations and 2 machine types (manual work not counted); automatic grouping uses dynamic programming to cut the sequence ordered by positional weight, and after switching to special machines the original equipment’s order is kept. Actual cycle time = largest load per operator, output = 60 ÷ cycle time; balance efficiency = total work content ÷ (operators × cycle time). Machines of each type = sum over groups of ⌈work content on that type ÷ cycle time⌉ (not more than the group’s operators). Output is a theoretical value from standard minutes; in practice multiply by the workshop efficiency.

Machine time for one seam: from first stitch to trim and full stop (soft start 3 stitches at 400 r/min, trim at 300 r/min, acceleration/deceleration as in Chapter 14)

Model (same as the book’s model21.py): one operator tends n automatic machines (programmable pattern sewers, template machines, etc.); each machine needs a min of loading/unloading and w min of walking per cycle, and sews automatically for t min. Cycle time C = max(n(a+w), a+t); operator utilisation = n(a+w)/C, machine utilisation = (a+t)/C; cost per piece = (labour + n × machine rate) × C ÷ n. Wage 0.5 yuan/min and machine rate 0.08 yuan/min per machine are worked-example values. The speed profile of one seam is the same as Chapter 14’s model14.py.
