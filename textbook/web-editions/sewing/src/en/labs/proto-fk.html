Model: the carriage runs a trapezoidal (triangular on short strokes) speed profile over D = 2c + 60p + Lk (Lk = 80 mm cam span), with a 0.1 s dwell at each reversal (stitch cams, carriers). Needle i must be selected at xi = c + (i + ½)p. The controller "should" issue the command when the carriage reaches xi − lead, but actually issues it at the next control tick (MCU) or the next encoder count (FPGA, 0.01 mm); the armature then acts after the selector response Tr ± J. Error = carriage position when the armature acts − xi. Real-time lead = v(Tr + quantisation/2). |error| ≤ 0.1p passes acceptance; > 0.25p is a mis-selection. Successive actions of one selector step, nsteps·p/v apart, need ≥ 2Tr (pull + release), otherwise they count as mis-selections for the worst-case pattern.
