Thread used per 1 cm of seam (cm / cm)

Model: each needle thread per stitch = stitch length + 2 × fabric thickness + 2 × 0.5 mm (loop); looper thread per stitch = number of needles × (2 × stitch length + 1 mm) + stitch length + 2 × needle gauge; cover thread per stitch = 2 × needle gauge + number of needles × 0.6 mm. The grey vertical line is the value from a thread maker’s consumption guide (7 sti/cm). This is an illustrative geometric model and differs from the published data by less than ±12%; real consumption also varies with thread tension, thread elasticity and fabric, so sew a test seam and measure before a large order.
