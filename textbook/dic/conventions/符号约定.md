# 《数字集成电路设计》符号约定（草案 v0.1，2026-10-05）

全书统一使用本约定，写作、程序、插图、动画、实验都以它为准。新增符号先登记在这里，再在正文中使用。

## 一、总原则

1. 物理量的名称、符号和单位符合 GB 3100～3102；电压用国标写法 U 的地方，本书按集成电路领域的通行写法用 V（VDD、VGS、Vout），首次出现处说明。
2. 单位用 SI：长度在版图和器件尺寸中用 μm，时间用 ns、ps，电容用 fF、pF，电流用 μA、mA。
3. 工艺：SKY130，1.8 V 器件 sky130_fd_pr__nfet_01v8 / pfet_01v8，最小沟道长度 L = 0.15 μm，最小宽度 0.42 μm。
4. 模型参数取自 `conventions/mos.py`（按 SKY130 tt、27 °C 校准），程序与浏览器实验共用，正文的数字由程序给出。
5. 与问渠其他教材一致：同一个中文术语的英文名相同。

## 二、器件与电路

| 符号 | 含义 | 单位 |
|---|---|---|
| VDD | 电源电压 | V |
| VGS、VDS | 栅源电压、漏源电压（NMOS） | V |
| VSG、VSD | 源栅电压、源漏电压（PMOS，取正值） | V |
| VTn、VTp | NMOS、PMOS 阈值电压的大小（本书模型中两者相等，记作 VT） | V |
| ID | 漏极电流 | A |
| k′n、k′p | 工艺跨导参数 μCox | μA/V² |
| r | k′n / k′p，两管饱和电流相等时的尺寸比 | — |
| β | 尺寸比 Wp / Wn（1.3 节推导中使用） | — |
| W、L | 沟道宽度、长度（Wn、Wp 分别为 NMOS、PMOS 的宽度） | μm |
| Ron | 线性区导通电阻（VDS → 0） | Ω |
| Req | 开关过程的等效电阻（取 ¾VDD / IDSAT） | Ω |
| Cg、Cd | 每微米栅宽的栅电容、漏极电容 | fF/μm |
| γ | 自载比 Cd / Cg | — |
| CL | 负载电容 | F |
| Vin、Vout | 反相器输入、输出电压 | V |
| VM | 开关阈值（Vout = Vin 的点） | V |
| VIL、VIH | 传输特性斜率为 −1 的两点对应的输入电压 | V |
| VOL、VOH | 输出低电平、高电平。1.1 节作设计指标（如 VOL ≤ 0.2 V）；1.2 节定义噪声容限时专指 VIH、VIL 处的输出（最坏输出） | V |
| NML、NMH | 低电平、高电平噪声容限 | V |
| tPHL、tPLH | 输出由高到低、由低到高的传播延时（50 % 点之间） | s |
| tp | 平均传播延时 (tPHL + tPLH)/2 | s |
| f | 每级扇出（下一级输入电容与本级输入电容之比） | — |
| F | 总扇出 CL / C1 | — |
| N | 反相器链的级数；功耗计算中为门的个数 | — |
| α | 翻转率：每个时钟周期一个门的输出由 0 变 1 的概率 | — |
| f（时钟） | 时钟频率；与扇出 f 同字母，按上下文区分，时钟频率处写明“时钟” | Hz |

## 三、写法

- 下标为说明性文字时用正体：VDD、tPHL、IDSAT、Req。
- 晶体管尺寸写成 W/L = 0.42/0.15，或“Wn = 0.42 μm”。
- 数值的写法与另几本书相同：小数点用“.”，多于四位每三位空半格。
