title: 本章小结
---

静态 CMOS 门由 NMOS 下拉网络和对偶的 PMOS 上拉网络组成：开关串联为“与”、并联为“或”，上拉网络把串联换成并联、并联换成串联。任何输入组合下恰好一个网络导通，所以静态 CMOS 门保留了反相器满摆幅、几乎无静态功耗的优点；它天生输出某个函数的非，一级门只能实现反相的函数，与或非、或与非这样的复合门可以一级完成较复杂的逻辑，比分立实现管子少、级数少。

门的尺寸按最坏情况定：n 个管子串联要各加宽 n 倍，并联的每个管子都要单独够强。以两管等强的参考反相器为标准，n 输入与非门的 NMOS 各取 n·Wmin、PMOS 各取 r·Wmin，或非门的 NMOS 各取 Wmin、PMOS 各取 n·r·Wmin。这样定出的门，每个输入的电容与参考反相器之比就是逻辑努力 g：与非门 (n + r)/(1 + r)，或非门 (1 + nr)/(1 + r)。或非门加宽的是本来就弱的 PMOS，所以 CMOS 设计偏爱与非门。

以 τ = 0.69RCinv 为单位，一级门的延时 d = gh + p。一条路径的路径努力 F = GBH，各级努力相等时延时最小，D = NF^{1/N} + ΣP；级数按 ln F / ln 4 估计，再比较相邻整数；尺寸从输出往回逐级求出。最优点附近延时变化平缓，参数有一二成误差也不改变结论。

有比逻辑（伪 NMOS）用一个常通的 PMOS 代替上拉网络，管子少、输入轻，但输出低电平由两管强弱之比决定，输出为低时有静态电流，适合平时几乎不动作的宽或门。传输管把晶体管当作通路上的开关，NMOS 传 1 只能传到 VDD − VT（体效应使它更低），传输门把 NMOS、PMOS 并联，两种电平都能传满。动态逻辑借助时钟预充、求值，没有静态电流，逻辑努力小；多米诺逻辑在动态门后接反相器，保证下一级的输入只从 0 变 1；宽的动态门受寄生延时拖累，要分组；电荷分享会使预充的节点掉电，要用保持管或内部节点预充来防止。

手算模型与 SKY130 仿真相比，或非门的逻辑努力很接近，与非门因为串联 NMOS 的速度饱和较轻，手算偏大约一成；误差更大的是寄生延时，靠近输出的输入只有手算的一半左右，译码器的延时差别主要由它造成，但选出的结构和尺寸不变；同一个门靠近电源轨的输入寄生延时明显更大，关键信号应接在靠近输出的输入上；有比逻辑的电平直接受模型误差影响，必须用仿真核对。

### 部分习题答案与提示

2.1.1 各 6 个管子。三输入与非门：三个 NMOS 串联、三个 PMOS 并联；三输入或非门相反。

2.1.3 A = B = 1、C = 0 时：下拉网络因 C 截止而断开，上拉网络中 A、B 的 PMOS 也截止，输出悬空，靠电容保持上一次的值，并且容易被耦合和漏电改变。这不再是静态门，输出可能停在中间电平，后级反相器还会有静态电流。

2.1.4 不能。三个低有效信号表示时 EN = ESTOP_N·(LIM_N + DIR_N)，它随每个输入的增大而增大（不反相），而一级静态 CMOS 门的输出只会随输入增大而减小。至少两级，例如或与非门 ¬((LIM_N + DIR_N)·ESTOP_N) 再接一个反相器。

2.2.1 四输入与非门 g ≈ {{ex2_ans.a221_nand4:.2f}}；四输入或非门 g ≈ {{ex2_ans.a221_nor4:.2f}}，PMOS 各宽约 {{ex2_ans.a221_nor4_wp:.1f}} μm。

2.2.2 下降最坏时两个最小 NMOS 串联，电阻约为参考反相器下拉的 2 倍，延时约 2 倍（自载电容略有不同）；上升最坏时只有一个 PMOS 导通，与参考反相器相同；A、B 都为 0 时两个 PMOS 并联，上升最快。

2.2.3 A 输入约 {{ex2_2.g_aoi_a:.2f}}，B（或 C）输入为 {{ex2_2.g_aoi_bc:.1f}}。A 的 NMOS 单独一路只需 Wmin，B、C 的 NMOS 串联要各取 2Wmin；两者的 PMOS 都在两个串联管的通路上，都取 2r·Wmin。

2.3.1 D = Σfi + P，约束 Πfi = F。由算术—几何平均不等式 Σfi ≥ N(Πfi)^{1/N} = NF^{1/N}，等号在各 fi 相等时成立。

2.3.2 与非门 f = 4g ≈ {{ex2_ans.a232_nand_f:.2f}}，d ≈ {{ex2_ans.a232_nand_d:.1f}}τ；或非门 f ≈ {{ex2_ans.a232_nor_f:.2f}}，d ≈ {{ex2_ans.a232_nor_d:.1f}}τ。

2.3.3 F 加倍到约 {{ex2_ans.a233_F:.0f}}，ln F / ln 4 接近 4。3 级 {{ex2_ans.a233_D3:.1f}}τ、4 级 {{ex2_ans.a233_D4:.1f}}τ，最快变为 {{ex2_ans.a233_best:.0f}} 级，最小延时比原来增加约 {{ex2_ans.a233_inc_ps:.0f}} ps。负载加倍，延时只增加约一成，这正是多级缓冲的好处。

2.3.4 与非门尺寸取最优值的一半或两倍时，前一级的努力乘 2、本级除以 2（或相反），总延时增加约 {{ex2_ans.a234_half:.0f}} %；只偏离 20 % 时，增加约 {{ex2_ans.a234_20:.0f}} %。一增一减的两项之和 x + 1/x 在 x = 1 处取极小，附近变化是二阶的，所以小偏差几乎不影响延时，大偏差才明显。

2.3.5 F = CL/Cinv ≈ {{ex2_ans.a235_F:.0f}}，每级 g = 1、p = γ，D(N) = NF^{1/N} + Nγ，最快 {{ex2_ans.a235_N:.0f}} 级，D ≈ {{ex2_ans.a235_D:.1f}}τ ≈ {{ex2_ans.a235_ps:.0f}} ps，与第 1 章算例 1.4.2 完全一致：逻辑努力就是第 1 章方法的推广。

2.4.1 PMOS 加宽一倍，静态电流约加倍，输出低电平升高（与非线性有关，约加倍），上升延时约减半。

2.4.2 约 {{ex2_ans.a242_mw:.2f}} mW（50 × 2 % × 静态功耗）。

2.4.4 仿真的弱 1 约 {{ex2_ans.a244_v1:.2f}} V；对称反相器的开关阈值约 0.9 V，VIH ≈ {{ex2_ans.a244_vih:.2f}} V，不会误判，但高电平噪声容限只剩约 {{ex2_ans.a244_nmh:.2f}} V，而且反相器里有静态电流。

2.4.5 传 0 时输出端是 NMOS 的源极，VGS = VDD − 0 始终大于阈值，管子一直导通，直到输出放到 0。

2.5.1 动态门本身是反相的（输出“或非”），接反相器后成为非反相的“或”；多米诺电路里每一级都是非反相的，只能实现单调递增的函数。异或要用双轨多米诺（同时算出原码和反码），或改用静态门。

2.5.2 输入来自前一级多米诺（预充期间一定为 0）时可以省掉底管。省掉后输入管只需 Wmin，g ≈ {{ex2_ans.a252_g:.2f}}。

2.5.3 不会：内部节点也在 VDD，A 导通时两边电位相同，没有电荷转移。在 A、B 之间的节点接一个由 CLK 控制的小 PMOS 到 VDD 即可。

2.5.4 动态或 + 反相器约 {{ex2_ans.a254_dyn:.1f}}τ，静态或非 + 反相器约 {{ex2_ans.a254_static:.1f}}τ。

2.5.5 保持管太强，求值时下拉网络要先“打赢”它才能把 X 放掉，下降变慢，甚至放不下去；这与伪 NMOS 的负载管一样，是一个有比的设计，强弱之比要按最坏情况核对。

### 历史注记

1963 年万拉斯提出 CMOS 时，就给出了互补结构的或非门。用串并联开关网络描述逻辑的思想更早：1938 年，香农在硕士论文中证明了继电器开关电路可以用布尔代数分析和综合，串联对应“与”、并联对应“或”。20 世纪 70 年代 NMOS 工艺占主流时，有比电路是标准做法，负载用耗尽型 NMOS；CMOS 里模仿这种结构、用常通 PMOS 作负载的门因此叫伪 NMOS。CMOS 普及后，无比的静态门成为主流，有比电路只在特殊场合使用。动态逻辑在 MOS 电路早期就已使用；1982 年克兰贝克等人提出多米诺逻辑，解决了动态门级联的问题，此后长期用于高性能处理器。逻辑努力方法由萨瑟兰和斯普劳尔在 20 世纪 80 年代末提出，1999 年与哈里斯合著的《逻辑努力：设计快速 CMOS 电路》使它成为手算门级延时的通用方法。
