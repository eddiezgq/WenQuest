### 2.5.1 问题的提出

2.4 节用伪 NMOS 做了十六路故障信号的“或”，检测很快，但有故障时有静态电流，输出低电平也随工艺波动。能不能既保留“每路输入只接一个 NMOS”的轻负载，又没有静态电流？办法是利用时钟：先在一个时钟相位里把输出节点充到高电平，再在另一个相位里只用下拉网络判断要不要把它放掉。

### 2.5.2 动态门

图 2.5.1 左半部分是一个动态门。时钟 CLK = 0 时，预充 PMOS 导通，底部的 NMOS（**底管**）截止，节点 X 被充到 VDD，这叫**预充**；CLK = 1 时，预充管截止，底管导通，如果下拉网络导通（任何一路输入为 1），X 就被放到 0，否则 X 靠自己的电容保持高电平，这叫**求值**。这样的门叫**动态门**：输出在求值期间靠电容上的电荷“记住”高电平，而不是靠一条导通的上拉通路。

src: fig2_5_1
说明: 带底管和保持管的多米诺或门：动态节点 X 在 CLK = 0 时预充、CLK = 1 时求值；后接的反相器输出 Y，并经保持管把 X 维持在高电平
:::

动态门没有静态电流：预充时下拉网络被底管切断，求值时预充管截止。每路输入只接一个 NMOS，按 2.2 节的等效反相器方法，输入管和底管串联、各取 2Wmin，逻辑努力只有 2Wmin·Cg / Cinv ≈ {{ex2_5.g_dyn:.2f}}，不到参考反相器的六成，与输入数无关。静态 CMOS 四输入或非门的逻辑努力是 {{ex2_5.g_nor4:.1f}}。

代价同样有好几条。第一，要时钟，每个周期都给 X 预充一次。第二，输入在求值期间只能从 0 变 1，不能从 1 变 0：X 一旦被放掉，就充不回来了，所以动态门的输出不能直接接到下一个动态门的输入（X 在求值开始时是 1，会错误地放掉下一级）。在 X 后面接一个反相器，输出 Y 在预充时为 0、求值时只会从 0 变 1，正好满足下一级的要求。这样“动态门 + 反相器”串起来的电路叫**多米诺逻辑**，信号像一排推倒的骨牌一样，一级接一级地向前传。第三，节点 X 是悬空的高电平，容易受干扰和漏电影响；在 X 和反相器输出之间加一个小 PMOS，Y 为 0 时它把 X 拉住，这个管子叫**保持管**。

**算例 2.5.1** 十六路故障信号的“或”：每路信号最多呈现 1 个参考反相器的输入电容，输出驱动 4 个参考反相器（H = 4）。比较四种做法的延时：静态两级（四输入或非 + 四输入与非）、伪 NMOS 十六输入或非 + 反相器、多米诺十六输入或、两个八输入动态门加一个二输入与非门。

宽的动态门受寄生延时拖累，这是动态逻辑设计的常识：动态节点上并联的管子一般不超过八个左右，再多就分组，用静态门合并。

### 2.5.3 电荷分享

动态门还有一个静态门没有的毛病。设故障条件是“过流且已使能”，动态门的下拉网络是 A、B 两个 NMOS 与底管串联。预充时 X 充到 VDD，A、B 之间的内部节点却可能是 0（上一个周期放掉了）。求值时如果 A = 1、B = 0，下拉网络不通，X 本应保持高电平；但 A 导通把 X 和内部节点连在一起，X 上的电荷要分一部分给内部节点的电容，电压随之下降，这叫**电荷分享**。

**算例 2.5.2** 上述动态与门的输入管和底管各取 3Wmin，X 接一个高偏斜反相器（PMOS 加宽一倍）。求电荷分享后 X 的电压，它离反相器的开关阈值还有多远？

X 上的电容包括预充管、保持管和 A 管的漏极，以及反相器的输入，约 {{ex2_5.Cx_ff:.1f}} fF；内部节点是 A 的源极和 B 的漏极，约 {{ex2_5.Cint_ff:.1f}} fF。电荷守恒，X 降到 VDD·Cx/(Cx + Cint) ≈ {{ex2_5.v_after:.2f}} V，掉了 {{ex2_5.dv:.2f}} V。高偏斜反相器的开关阈值约 {{ex2_5.vm_hi:.2f}} V，只剩 {{ex2_5.margin:.2f}} V 余量，再加上噪声和漏电就可能误翻转。解决办法有三种：加大保持管，让它在分享后把 X 拉回去；在预充时把内部节点也充高（加一个小预充管）；或者调整输入的顺序，把求值期间常为 1、或最早到达的输入放在靠近底管的位置，让它导通时连通的是已经放过电的下部节点，而不是去分 X 的电荷。

### 2.5.4 模型在哪里失效

这一节的延时都是用手算模型的 g、p 估算的。动态门的速度对几件模型没有考虑的事很敏感：保持管在求值时与下拉网络“打架”，使下降变慢；时钟边沿与输入到达时间的配合（输入必须在求值开始前稳定）；以及漏电，SKY130 的 1.8 V 器件漏电很小，X 能保持很久，但先进工艺中漏电大，保持管必不可少，时钟也不能停得太久。动态电路的设计需要更细的仿真和专门的时序检查，在今天的标准单元设计流程中，它主要用于存储器的读出电路和少数对速度极敏感的模块（第 7 章）。

### 2.5.5 生活中的例子

一个水塔，每天早上先把水灌满（预充），白天任何一户打开龙头，水就流走（求值）；如果没人用水，塔里的水一直满着。水塔不需要一直开着水泵，但只能“放水”不能中途“补水”；水塔有点漏，就要加一个小补水管（保持管）。
