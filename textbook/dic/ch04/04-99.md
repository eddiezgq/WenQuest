title: 本章小结
---

导线的电阻由方块电阻和长宽比决定，R = R□·L/W；电容由面积电容和边缘电容组成，细导线以边缘电容为主，与相邻同层导线之间还有随间距减小而迅速增大的耦合电容。SKY130 的各层导线电容相差不大，电阻却相差上千倍：li1 只用于单元内部，met1、met2 细而密，met3～met5 厚而疏，长线、时钟和电源应走上层。导线的 R 和 C 都与长度成正比，RC 与长度的平方成正比。

导线是分布式 RC 网络，信号沿线扩散，远端的 50 % 延时约 0.38RwCw，集总模型的 0.69RC 高估将近一倍。树状连线上每个节点的 Elmore 延时 ΣRikCk 是 50 % 延时的上界，乘 0.69 是常用的估计，对以集总电容为主的节点较准，对长支线的末端偏小。驱动器加导线加负载的延时可用 0.69Rd(Cself + Cw + CL) + 0.38RwCw + 0.69RwCL 估算，驱动器只能减小第一项。

长线分段插中继器后，延时从与长度的平方成正比变为与长度成正比；最优段长和中继器尺寸只取决于工艺和金属层，最优点附近延时变化平缓，实际常取小一些的中继器以节省面积和功耗。换到电阻小得多的上层厚金属，往往比插中继器更有效。

相邻导线之间的耦合电容造成串扰：悬空的受害线跳动 VDD·Cc/(Cc + Cg)，有驱动的受害线噪声随驱动加强、干扰线边沿放慢而减小；加大间距、加强驱动、插屏蔽线是三种基本措施。耦合电容还使延时随邻线动作而变，有效电容在 Cg 与 Cg + 2Cc 之间。

信号上升时间小于导线往返传播时间时，要按传输线处理。芯片外的电路板走线常常如此，末端开路、源端阻抗很低时会反复反射振荡，源端串联一个使总电阻等于特性阻抗的电阻即可消除；芯片上只有边沿足够快、且总电阻小于约 2Z0 的宽厚导线才需要考虑电感。

### 部分习题答案与提示

4.1.1 R ≈ {{ex4_ans.a411_R:.0f}} Ω，C ≈ {{ex4_ans.a411_C:.1f}} fF。

4.1.2 R ∝ L/W，C ∝ L，所以 RC ∝ L²；线宽加倍，R 减半，C 中只有面积电容部分增加，对细导线所占比例很小，所以 RC 约减半。

4.1.3 两侧最小间距的邻线时约 {{ex4_ans.a413_x1:.1f}} 倍；间距加到 3 倍时约 {{ex4_ans.a413_x3:.1f}} 倍。

4.1.4 met5 的方块电阻约为 met1 的四分之一，最小线宽又是 met1 的约 11 倍，单位长度电阻小约 50 倍；两者单位长度的电容相近，所以 RC 也小约 50 倍。

4.2.1 末端：每段电容 c·dx 乘上它到电源的电阻 r·x，积分 ∫rcx dx（0 到 L）= rcL²/2 = RwCw/2。中点：前一半的电容积分得 rc(L/2)²/2，后一半的电容都乘 r·L/2，共 rcL²/4，合计 3RwCw/8。

4.2.2 驱动项约 {{ex4_ans.a422_drv:.0f}} ps，导线项约 {{ex4_ans.a422_wire:.0f}} ps，共约 {{ex4_ans.a422_tot:.0f}} ps。驱动项最大：最小反相器驱动 2 mm 导线，问题首先是驱动太弱。

4.2.3 驱动 20 倍时约 {{ex4_ans.a423_20:.0f}} μm；加到 40 倍时约 {{ex4_ans.a423_40:.0f}} μm。驱动加大，驱动项减小，导线项不变，两者相等的线长变短。

4.2.4 两条支线等长，Elmore 延时相同，偏斜为 0；每个计数器的 Elmore 延时约 {{ex4_ans.a424_el:.0f}} ps。

4.2.5 约 {{ex4_ans.a425_rise:.2f}}RC，集总 RC 为 2.2RC。

4.3.1 总延时 t(k, s) = k[0.69(R0/s)(γsC0 + cL/k + sC0) + 0.38rc(L/k)² + 0.69r(L/k)sC0]。对 s 求导：−0.69R0cL/(ks²)·k + 0.69rLC0 = 0，得 s = √(R0c/(rC0))。对 k 求导：0.69R0C0(1 + γ) − 0.38rcL²/k² = 0，得式 (4.3.1)。

4.3.2 kopt 与 L 成正比，L/kopt 只含 r、c、R0、C0、γ。met1 最优段长约 {{ex4_ans.a432_met1_mm:.2f}} mm，met3 约 {{ex4_ans.a432_met3_mm:.1f}} mm。

4.3.4 中继器（3 个 26 倍，只计输入电容）约 {{ex4_ans.a434_rep_uw:.0f}} μW，导线电容约 {{ex4_ans.a434_wire_uw:.0f}} μW，中继器的功耗是导线本身的一半以上；计入中继器自身的漏极电容还要更多。

4.4.1 约 {{ex4_ans.a441:.2f}} V。负载电容增加，分压比略降，但 Cc 仍占大头。

4.4.2 约 {{ex4_ans.a442:.2f}} V，低于噪声容限。边沿越慢，受害线的驱动器越来得及泄放电荷。

4.4.3 约 {{ex4_ans.a443_s:.2f}} μm，即最小间距的约 2.7 倍。

4.4.4 相邻的 B0、B1 与 A1 反向翻转时 A1 最慢（米勒系数 2），同向翻转时最快（系数 0）。

4.4.5 屏蔽线悬空时，它只是把干扰线和受害线串联成两个耦合电容，耦合依然存在；接地（或接电源这样交流上的地）后，电场终止在一个电位不变的导体上，耦合才被截断。

4.5.1 约 {{ex4_ans.a451_cm_ns:.1f}} cm/ns；2 cm 走线的往返时间约 {{ex4_ans.a451_2td_ps:.0f}} ps，与 200 ps 的边沿相当，处在临界附近，应当检查反射，必要时端接。

4.5.2 约 {{ex4_ans.a452_v:.2f}} V（输出电阻与 50 Ω 分压），输出为高时静态功耗约 {{ex4_ans.a452_p_mw:.0f}} mW，比源端串联端接大得多。

4.5.3 入射波只有一半幅度，要等末端的反射波回来才升到 VDD；走线中途的器件会先看到一段停在 VDD/2 附近的台阶，可能误判。源端串联端接只适合点对点连接。

4.5.4 met1 电阻约 {{ex4_ans.a454_met1_R:.0f}} Ω、met3 约 {{ex4_ans.a454_met3_R:.0f}} Ω，都远大于 2Z0（约 {{ex4_ans.a454_met1_2Z:.0f}} Ω），不需考虑电感；met5 约 {{ex4_ans.a454_met5_R:.0f}} Ω，小于 2Z0，边沿很快时要考虑。

### 历史注记

1948 年，埃尔莫尔在研究宽带放大器时提出用冲激响应的一阶矩估计延时，这就是 Elmore 延时。1983 年，鲁宾斯坦、彭菲尔德和霍罗威茨给出了 RC 树上波形的上下界，使它成为集成电路连线延时分析的基础；1997 年，古普塔、图图亚努和皮莱吉证明了 Elmore 延时是 RC 树上 50 % 延时的上界。20 世纪 80 年代，巴科格卢等人系统研究了芯片上长线的中继器插入，得出了最优段数和尺寸的闭式解。20 世纪 90 年代后期，工艺进入深亚微米，导线延时超过门延时，铜互连（IBM 于 1997 年宣布、次年量产）和低介电常数介质相继引入，以降低导线的电阻和电容。SKY130 仍使用铝互连和五层金属，属于成熟工艺，但本章的方法同样适用于先进工艺。
