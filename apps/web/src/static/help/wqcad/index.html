00课程怎么学

写给从没用过 FreeCAD 的人：从界面和鼠标讲起，一课一课做出 WQ-LS 平缝机的零件，最后装成挑线机构、出工程图。

这套课程

问渠 CAD 是在开源的 FreeCAD 1.1.4 上改出来的：界面、菜单、操作都和 FreeCAD 一样，另外带 27 处内核修正和问渠的 AI 工作台。所以这套课大部分是在教 FreeCAD——学会了，用官方 FreeCAD 也一样。

  • 8 个模块、21 课 + 附录：入门、草图、零件建模、曲线与曲面、装配、工程图、进阶、AI。约 25–30 小时。
  • 一条主线：每课做 WQ-LS 平缝机上的一个真零件，尺寸取自 WQ-LS 设计，做出来能和真设计对上；每课附答案模型。
  • 每课的样子：学完能做什么 → 讲解 → 录屏（真软件操作，黄圈标出点哪里）→ 跟着做 → 自己做 → 3 道小测。
  • 两种用法：按顺序学；或者左上角搜索，按功能查——它也是问渠 CAD 的帮助。

录屏是怎么录的

录屏都是真软件在操作：云端电脑上装的 FreeCAD 1.1.4、问渠 CAD 的品牌和同一版 AI 工作台，中文界面；鼠标点哪里、键盘输什么，软件就真的执行（画草图、加约束、凸台都是软件自己算的）。和你电脑上的问渠 CAD 只差 27 个内核补丁——补丁不改界面；“检查几何”“展开面”两处结果不同，这两处不录屏，用书里的验收数据讲。

录屏暂时没有配音，看字幕（视频右下角可以开关）。讲解配音以后补上。

01第 1 课 认识界面

学完能做：认出界面上每一块是干什么的；用鼠标转、移、缩放模型；切换标准视图；点选零件看属性；知道单位和导航方式在哪里改。约 1 小时。

学完能做什么

  • 说出菜单、工具栏、工作台、模型树、属性、三维视图、导航立方体、报告视图、状态栏各管什么。
  • 用 CAD 导航方式：中键拖 = 平移，中键 + 左键拖 = 旋转，滚轮 = 缩放。
  • 前 / 上 / 右 / 轴测视图来回切；转乱了一键“适应全部”。
  • 点选一个零件，在属性里看它的数据。

本课用的文件：WQ-LS 平缝机整机（110 个零件，按八个部件分组）。

界面上的每一块

FreeCAD 的窗口分九块。点下面的图，看每一块是干什么的。

“工作台”是 FreeCAD 最特别的地方：同一个窗口，换一个工作台，工具栏就换一套——画草图用“草图”，做零件用“零件设计”，装配用“装配”，出图用“工程图”。问渠 CAD 多一个 “AI Parts” 工作台（第 21 课讲）。

首选项：单位、语言、导航方式

菜单“编辑 → 首选项”。最常改的三样：

  • 单位：“常规 → 语言和数字格式 → 默认单位系统”。机械设计用“标准（mm、kg、s）”。
  • 语言：同一栏。改了要重启软件。
  • 导航方式：“显示 → 导航栏 → 3D 导航”。习惯了别的软件可以换，本课程一律按“CAD”讲。

跟着做

  1. 打开问渠 CAD，开始页点“打开文件”，打开课程附带的 WQ-LS.FCStd。
  2. 按 0（轴测），再点“适应全部”。
  3. 中键拖：把整机移到画面左边；中键 + 左键拖：转到能看见手轮的一面；滚轮：放大到看清针杆。
  4. 按 1、2、3，分别从前、上、右看；再点导航立方体的一个角回到轴测。
  5. 在模型树里展开“主轴与挑线”，点 crank（曲柄）：三维里它变绿，左下属性里显示它的名字和位置。
  6. 点空白处取消选择。

自己做

  1. 在三维视图里直接点手轮，看模型树里哪一项被选中了。
  2. 把“机壳”组隐藏（选中它按空格），看清里面的机构；再按空格显示回来。
  3. 打开首选项，确认单位是“标准（mm、kg、s）”，然后按“取消”。

小测

CAD 导航方式下，怎样旋转视图？

中键拖是平移；中键 + 左键一起按住拖才是旋转。左键单独是选择。

换到“草图”工作台以后，最先变的是什么？

工作台只换工具：工具栏、菜单换成这个工作台的命令；文件、单位、模型都不变。

视图转乱了、模型跑出画面，最快怎么找回来？

“适应全部”把所有可见对象缩放到画面中间；按 0 再回到轴测方向。

02第 3 课 草图入门

学完能做：新建零件和草图；画直线、多段线、圆、圆弧、构造线；画的时候直接键入尺寸；把草图凸台成零件。做出 WQ-LS 的压脚杆套环，画出针夹的轮廓。约 1.5 小时。

学完能做什么

  • 新建“参数实体”（Body），在 XY 平面上开一张草图。
  • 用圆、多段线、圆弧、直线工具画轮廓；画圆时直接键入直径。
  • 把线切换成构造线（只帮忙定位，不成形）。
  • 关闭草图，用“凸台”把它拉成实体。

本课做两样东西：压脚杆套环（外径 16、内孔 8、厚 3 mm，和 WQ-LS 设计里的一样），以及针夹的轮廓（下一课加约束、定尺寸）。

草图是什么

FreeCAD 做零件的基本路子：先在一个平面上画二维草图，再把草图变成三维（凸台、挖槽、旋转……）。草图里的每条线有两种东西：

  • 几何：线、圆、圆弧——形状；
  • 约束：重合、水平、竖直、直径、距离——把形状“钉住”。

草图编辑时右边“草图编辑”一栏随时告诉你还差多少：“约束不足：n 个自由度”“完全约束”（全绿）或“过约束 / 冗余约束”（红字）。下面这个小实验模拟画圆的两下：先点圆心，再拖出半径或键入直径——看约束和自由度怎么变。

录屏：压脚杆套环

开始页 → 参数实体 → 新建草图 → XY 平面 → 圆工具：点原点，键入 16 回车；工具还开着，再点原点，键入 8 回车 → 右边显示“完全约束” → 关闭草图 → 凸台，长度 3。

录完软件算出的体积是 452.4 mm³，和 WQ-LS 真零件一样。

录屏：针夹的轮廓

针夹夹在针杆下端：上面一段圆弧（半径 5.5），下面一个方耳朵（宽 7，伸到中心下方 7），中间是套针杆的孔（直径 8）。这一课只把形状画出来，尺寸先不管准不准：

  1. 多段线：右上 → 右下 → 左下 → 左上，点四下；右键结束，Esc 退出。软件自动给竖线加“竖直”、给横线加“水平”、给连着的点加“重合”。
  2. 圆弧（圆心、起点、终点）：先点原点，再点右上角的端点，绕过上面，点左上角的端点。
  3. 圆：圆心在原点，键入直径 8。
  4. 直线：从下往上画一条竖线，再点“切换构造线”：它变成蓝色虚线——中心线，只用来定位。

画完右边写着“约束不足：6 个自由度”——形状对了，大小还能被拖动。下一课把它定死。

跟着做

  1. 照第一段录屏做出压脚杆套环，保存为 压脚杆套环.FCStd。
  2. 新建一个参数实体，在 XY 平面画针夹轮廓（多段线 + 圆弧 + 圆 + 一条构造中心线），保存为 针夹草图.FCStd，下一课用。

自己做

  1. 用“矩形”工具画一个 20 × 10 的长方形，凸台 5 mm。看右边自由度：矩形工具自动加了几个约束？
  2. 把套环的内孔改成 8.2（双击草图进入编辑，双击“8 mm”那个尺寸改数），看凸台跟着变。

小测

画圆时点完圆心，直接键入 16 回车，会发生什么？

FreeCAD 1.1 的屏上输入：画圆时键入的是直径，回车后圆画好，同时加上直径约束（约束列表里多一条“16 mm”）。

构造线有什么用？

构造线（蓝色虚线）只在草图里帮忙定位，凸台时不算轮廓。

草图画完，右边写“约束不足：6 个自由度”，意思是？

自由度 = 还能独立变化的量（位置、大小）。能凸台，但零件尺寸不可靠；加约束把它变成 0（完全约束）。

03第 4 课 约束

学完能做：看懂自由度；加几何约束（重合、点在线上、对称）和尺寸约束（半径、水平距离、距离）；把草图做到“完全约束”；碰到“冗余 / 过约束”知道怎么查。做出 WQ-LS 的针夹。约 1.5 小时。

学完能做什么

  • 读懂草图编辑栏：约束不足 n 个自由度 / 完全约束 / 冗余约束 / 过约束。
  • 先选对象、再点约束按钮，加几何约束；加尺寸约束并键入数值。
  • 知道“冗余”是什么、怎么在约束列表里找到并删掉。
  • 把上一课的针夹轮廓定死，凸台 8 mm 成针夹。

自由度：图形还能怎么动

一个点在平面里有 2 个自由度（x、y），一条线 4 个，一个圆 3 个（圆心 2 + 半径 1），一段圆弧 5 个。每个约束吃掉 1 个或 2 个。全部吃完 = 完全约束：草图变绿，尺寸可靠。

下面是针夹轮廓。把约束一个个勾上，看自由度怎么减少、没定住的部分怎么还在动：

几何约束

规矩：先选，再点。在草图里点一下就加进选择（不用按 Ctrl）；点端点选的是点，点线中间选的是线。

约束 选什么 作用
重合 / 点在线上 两个点；或一个点 + 一条线 点重合；或点落在线上
水平 / 竖直 一条线（或两个点） 线水平 / 竖直
平行 / 垂直 / 相切 两条线（或线 + 圆弧） 方向关系
相等 两条线或两个圆 一样长 / 一样大
对称 两个点 + 一条线（或一个点） 关于线（点）对称
锁定 一个点 位置钉死

录屏里有个常见的坑：下边线已经有“水平”，再加“左右两个下角关于 Y 轴对称”——对称已经包含了“两点一样高”，于是软件报 冗余约束（红字）。办法：撤销，在约束列表里选中那条“水平”，按 Delete，再加对称。

尺寸约束

约束 选什么 键入
半径 / 直径 圆或圆弧 半径 / 直径
水平距离 / 竖直距离 一条线，或两个点 x / y 方向的距离
距离 两个点；点 + 线（垂直距离）；一条线（长度） 距离
角度 两条线 角度

针夹还剩 3 个自由度：圆弧半径、耳朵宽、耳朵伸多长。加三个尺寸：圆弧半径 5.5、下边线水平距离 7、原点到下边线的距离 7 → 完全约束 → 关闭草图，凸台 8。

软件算出的针夹体积 464.4 mm³；WQ-LS 真零件是 436.2 mm³——差的是两个小孔（穿线孔、夹紧螺钉孔），第 6 课“孔”加上。

过约束、冗余怎么查

  1. 红字“冗余约束”或“过约束”后面列着是哪几条（点它，三维里相关的约束变红）。
  2. 约束列表里选中多余的那条，按 Delete；或者把它改成“参考”尺寸（只显示、不约束）。
  3. 拿不准就 Ctrl+Z 撤销刚加的那条——过约束几乎总是最后加的那条引起的。

跟着做

  1. 打开上一课的 针夹草图.FCStd，双击草图进入编辑，读右边的自由度。
  2. 中心线：下端点 + 下边线 → 点在线上；上端点 + 圆弧 → 点在线上。
  3. 删掉下边线的“水平”，加左右下角关于 Y 轴对称。
  4. 圆弧半径 5.5；下边线水平距离 7；原点 + 下边线距离 7 → 完全约束。
  5. 关闭草图，凸台 8 mm，保存。

自己做

  1. 给下边线再加一个“水平距离 7”，看软件怎么说；然后用约束列表删掉它。
  2. 把半径 5.5 改成 6，凸台跟着变；改回来。
  3. 回到第 3 课的矩形：用“对称”让它关于原点居中，再加两个尺寸，做到完全约束。

小测

一段圆弧有几个自由度？

圆心 2 个 + 半径 1 个 + 起始角、终止角各 1 个 = 5 个。

下边线已有“水平”，再选左右两个下角和 Y 轴加“对称”，软件报“冗余约束”。为什么？

关于竖轴对称 = x 相反、y 相等；y 相等就是水平。两个约束说了同一件事，所以冗余。

草图变成全绿、写着“完全约束”，说明什么？

完全约束 = 0 个自由度。尺寸照样能改（双击尺寸改数），改了以后仍然完全约束。

04附录 A 安装问渠 CAD

Windows 10 / 11（64 位）一个安装包，装完就能用。测试版需要一年测试授权码（注册用户免费领）。

下载和授权

官网“软件下载”页（美国 wenquestrobotics.com/download，国内 wenquestech.online/download）：登录后点“领取一年测试授权”，复制授权码；下载问渠 CAD 安装包（约 1 GB）。

安装

  1. 双击安装包。Windows 可能提示“已保护你的电脑 / 未知发布者”（测试版没买代码签名证书）：点更多信息 → 仍要运行。
  2. 选语言 → 同意许可 → 选安装位置（默认即可）→ 安装，约 3–5 分钟。
  3. 桌面上双击“问渠 CAD”。首次打开 AI Parts 等问渠工作台时，粘贴授权码。
  4. 首次启动会出“欢迎”页：语言选“简体中文”，单位选“标准（mm、kg、s）”，导航方式选“CAD”（本课程都按 CAD 讲）。

排错

  • 双击没反应：可能是 Windows 的“智能应用控制”拦下了（Windows 安全中心 → 应用和浏览器控制）。公司电脑请找管理员。
  • 杀毒软件报毒：测试版没有代码签名，个别杀毒软件会误报；从官网下的安装包可以核对页面上的 SHA-256 校验码。
  • 界面是英文：编辑 → 首选项 → 常规 → 语言，选“简体中文”，重启。
