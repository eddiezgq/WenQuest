00How to use this course

Written for people who have never used FreeCAD. It starts with the window and the mouse, and lesson by lesson you build real parts of the WQ-LS lockstitch sewing machine — ending with an assembled take-up mechanism and its drawings.

This course

WenQuest CAD is built on the open-source FreeCAD 1.1.4: the window, menus and workflow are the same as FreeCAD, plus 27 kernel fixes and the WenQuest AI workbench. So most of this course teaches FreeCAD — what you learn works in standard FreeCAD too.

  • 8 modules, 21 lessons + appendix: Getting started, Sketching, Part modelling, Curves and surfaces, Assembly, Drawings, Advanced, AI. About 25–30 hours.
  • One running project: each lesson makes a real part of the WQ-LS lockstitch machine, with dimensions taken from the WQ-LS design, so your result can be checked against the real one; every lesson comes with an answer model.
  • Each lesson: what you will be able to do → explanation → screen recording (the real software, a yellow ring shows each click) → follow along → on your own → 3 quiz questions.
  • Two ways to use it: work through it in order, or search (top left) by feature — it is also the help for WenQuest CAD.

How the recordings are made

Every recording is the real software at work: FreeCAD 1.1.4 on a cloud computer with the WenQuest CAD branding and the same AI workbench, English interface. Where the mouse clicks and what is typed, the software really does — sketches, constraints and pads are all computed by FreeCAD itself. The only difference from WenQuest CAD on your computer is the 27 kernel fixes, which do not change the interface; “Check geometry” and “Unfold face” give different results, so those are not recorded and are taught with the book's verified data instead.

The recordings have English subtitles (toggle them at the bottom right of the video). Narration will be added later.

01Lesson 1 The FreeCAD window

You will be able to name every part of the window, rotate, pan and zoom a model with the mouse, switch standard views, select a part and read its properties, and find where units and navigation style are set. About 1 hour.

What you will be able to do

  • Say what the menu bar, toolbars, workbench selector, model tree, properties, 3D view, navigation cube, report view and status bar are for.
  • Use CAD navigation: middle-drag = pan, middle + left drag = rotate, wheel = zoom.
  • Switch between front / top / right / isometric views, and bring a lost model back with “Fit all”.
  • Select a part and read its data in the properties.

File used: the complete WQ-LS lockstitch machine (110 parts in eight groups).

The “workbench” is FreeCAD's special feature: the same window, but each workbench brings its own toolbars — Sketcher for sketches, Part Design for parts, Assembly for assemblies, TechDraw for drawings. WenQuest CAD adds an “AI Parts” workbench (lesson 21).

  4. Press 1, 2, 3 to look from the front, top and right; click a corner of the navigation cube to go back to isometric.
  5. In the model tree expand “Upper shaft & take-up” and click crank: it turns green in the 3D view and its name and placement appear in the properties.
  6. Click empty space to deselect.

On your own

  1. Click the handwheel in the 3D view and see which tree item is selected.
  2. Hide the “Housing” group (select it and press Space) to see the mechanism inside; press Space again to show it.
  3. Open Preferences, check that the unit system is “Standard (mm, kg, s)”, then click Cancel.

Quiz

With CAD navigation, how do you rotate the view?

Middle-drag pans; middle + left together rotates. The left button alone selects.

What changes first when you switch to the Sketcher workbench?

A workbench only changes the tools: toolbars and menus switch to its commands. The file, units and model stay the same.

The view is a mess and the model is off screen. Fastest way back?

“Fit all” zooms all visible objects into the middle of the view; press 0 to go back to the isometric direction.

02Lesson 2 Files and data

You will be able to create, save, undo and redo; read how objects depend on each other in the model tree, so that changing an earlier object updates the later ones; export a part as STEP for someone else and import it back to check. About 1 hour.

What you will be able to do

  • Create an empty document and add primitives with the Part workbench; undo, redo; name the file when you first save it.
  • Know that an .FCStd file stores “objects + how they were made”, not just shapes.
  • Read parent/child relations in the model tree: what depends on what; change an object and everything after it is recomputed.
  • Export STEP (for other CAD), STL (3D printing), DXF (2D drawings); import a STEP someone gives you.

New, save, undo

To… Menu Shortcut

Save / Save as File → Save / Save As Ctrl+S / Ctrl+Shift+S
Undo / Redo Edit → Undo / Redo; curved arrows on the toolbar Ctrl+Z / Ctrl+Y

FreeCAD's own file is .FCStd (really a zip holding each object's parameters and shape). Saving also leaves an .FCBak backup in the same folder; if a file is damaged, rename the backup to .FCStd and open it.

Dependencies: change the earlier, the later follows

FreeCAD is parametric: every object remembers how it was made. “Cut” remembers “cube minus cylinder”, so in the model tree the cube and cylinder move under “Cut” (they are used up by the cut and hidden by default). Change the cylinder's radius or position and the cut recomputes itself. Click the objects below to see what changing each one affects:

FreeCAD's result in the recording: a 10 × 10 × 10 block with a through hole of radius 3, volume 717.26 mm³ (= 1000 − π × 3² × 10).

On your own

  1. In “practice”, change the cylinder height to 5: is the hole still through? Why?
  2. Delete “Cut” (select it, press Delete): what happens to the cube and cylinder? Undo.
  3. Export the needle bar as STL and open it in your computer's 3D viewer.

Quiz

Which format is best for sending a part to a colleague who uses SolidWorks?

STEP is the exact solid format every CAD reads; FCStd is FreeCAD-only, STL is approximate triangles, DXF is 2D lines.

After the cut, the cube and cylinder move under “Cut” and disappear from the 3D view. Were they deleted?

That is a dependency: the cut remembers “cube minus cylinder”. Select the cube and press Space to show it again.

You import a STEP file from someone else. Can you change the original hole diameter in the properties?

STEP is the result, without the modelling history. You can add features on top, or ask for the original file.

03Lesson 3 Sketching basics

You will be able to create a part and a sketch; draw lines, polylines, circles, arcs and construction lines; type dimensions while drawing; and pad a sketch into a solid. You make the WQ-LS presser-bar collar and draw the needle-clamp outline. About 1.5 hours.

What you will be able to do

  • Create a “Parametric Body” and open a sketch on the XY plane.
  • Draw outlines with the circle, polyline, arc and line tools; type the diameter while drawing a circle.
  • Toggle a line to construction geometry (for positioning only, not part of the shape).
  • Close the sketch and turn it into a solid with “Pad”.

Two things are made in this lesson: the presser-bar collar (OD 16, bore 8, 3 mm thick, exactly as in the WQ-LS design) and the needle-clamp outline (constraints and exact sizes come in the next lesson).

What a sketch is

The basic FreeCAD way to make a part: first draw a 2D sketch on a plane, then turn the sketch into 3D (pad, pocket, revolve…). A sketch holds two kinds of things:

  • Geometry: lines, circles, arcs — the shape;
  • Constraints: coincident, horizontal, vertical, diameter, distance — what pins the shape down.

While you edit a sketch, the “Sketch edit” panel always tells you how far you are: “Under-constrained: n degrees of freedom”, “Fully constrained” (all green) or “Over-constrained / redundant constraints” (red text). This small experiment imitates the two clicks of the circle tool: first the centre, then drag out the radius or type a diameter — watch how the constraints and degrees of freedom change.

Recording: the presser-bar collar

Start page → Parametric Body → Create sketch → XY plane → Circle tool: click the origin, type 16, Enter; with the tool still active, click the origin again, type 8, Enter → the panel shows “Fully constrained” → close the sketch → Pad, length 3.

The volume FreeCAD computes in the recording is 452.4 mm³ — the same as the real WQ-LS part.

Recording: the needle-clamp outline

The needle clamp sits at the bottom of the needle bar: an arc on top (radius 5.5), a square tab below (width 7, reaching 7 below the centre), and a bore in the middle for the needle bar (diameter 8). In this lesson we only draw the shape; exact sizes come later:

  1. Polyline: top right → bottom right → bottom left → top left, four clicks; right-click to finish, Esc to leave. FreeCAD adds “Vertical” to the vertical lines, “Horizontal” to the horizontal one and “Coincident” where lines meet.
  2. Arc (centre, start, end): click the origin, then the top-right end point, go round over the top, click the top-left end point.
  3. Circle: centre at the origin, type diameter 8.
  4. Line: draw a vertical line from bottom to top, then click “Toggle construction geometry”: it turns into a blue dashed centre line, used only for positioning.

When you finish, the panel says “Under-constrained: 6 degrees of freedom” — the shape is right, but it can still be dragged. The next lesson pins it down.

Quiz

Drawing a circle, you click the centre and type 16, Enter. What happens?

FreeCAD 1.1's on-view parameters: for a circle you type the diameter; Enter draws it and adds a diameter constraint (“16 mm” appears in the constraint list).

What are construction lines for?

Construction geometry (blue dashed) only helps inside the sketch; Pad ignores it.

The panel says “Under-constrained: 6 degrees of freedom”. What does that mean?

Degrees of freedom = quantities (positions, sizes) that can still change on their own. You can pad, but the part's sizes are not reliable; constrain it down to 0 (fully constrained).

04Lesson 4 Constraints

You will be able to read degrees of freedom; add geometric constraints (coincident, point on object, symmetric) and dimensional constraints (radius, horizontal distance, distance); bring a sketch to “Fully constrained”; and find the cause of “redundant / over-constrained”. You make the WQ-LS needle clamp. About 1.5 hours.

What you will be able to do

  • Read the Sketch edit panel: under-constrained n degrees of freedom / fully constrained / redundant / over-constrained.
  • Select first, then click a constraint button to add a geometric constraint; add a dimensional constraint and type its value.
  • Know what “redundant” means and how to find and delete the extra constraint in the constraint list.
  • Fully constrain last lesson's needle-clamp outline and pad it 8 mm into the needle clamp.

Degrees of freedom: how the shape can still move

A point in the plane has 2 degrees of freedom (x, y), a line 4, a circle 3 (centre 2 + radius 1), an arc 5. Each constraint removes 1 or 2. When none are left the sketch is fully constrained: it turns green and its sizes are reliable.

Below is the needle-clamp outline. Tick the constraints one by one and watch the degrees of freedom drop and the unfixed parts keep moving:

Geometric constraints

The rule: select first, then click. In a sketch, a click adds to the selection (no Ctrl needed); click an end point to pick the point, the middle of a line to pick the line.

Constraint Select Effect
Coincident / point on object Two points; or a point + a line Points meet; or the point lies on the line
Horizontal / vertical A line (or two points) Line horizontal / vertical
Parallel / perpendicular / tangent Two lines (or line + arc) Direction relation
Equal Two lines or two circles Same length / same size
Symmetric Two points + a line (or a point) Mirror about the line (point)
Lock A point Position fixed

The recording shows a common trap: the bottom edge already has “Horizontal”; adding “the two lower corners are symmetric about the Y axis” already implies “the two points are at the same height”, so FreeCAD reports a redundant constraint (red text). The fix: undo, select that “Horizontal” in the constraint list, press Delete, and add the symmetry again.

Dimensional constraints

Constraint Select Type
Radius / diameter Circle or arc Radius / diameter
Horizontal / vertical distance A line, or two points Distance in x / y
Distance Two points; point + line (perpendicular distance); a line (length) Distance
Angle Two lines Angle

The needle clamp has 3 degrees of freedom left: arc radius, tab width and how far the tab reaches. Add three dimensions: arc radius 5.5, horizontal distance 7 on the bottom edge, distance 7 from the origin to the bottom edge → fully constrained → close the sketch and pad 8.

FreeCAD computes 464.4 mm³ for this needle clamp; the real WQ-LS part is 436.2 mm³ — the difference is two small holes (thread hole and clamp-screw hole), added in lesson 6 “Holes”.

Finding over-constrained and redundant constraints

  1. The red “Redundant constraints” or “Over-constrained” text lists which ones (click it and the related constraints turn red in the 3D view).
  2. Select the extra one in the constraint list and press Delete; or make it a “reference” dimension (shown, not enforced).
  3. When unsure, Ctrl+Z the constraint you just added — over-constraining is almost always caused by the last one.

Follow along

  1. Open NeedleClampSketch.FCStd from the last lesson, double-click the sketch and read the degrees of freedom.
  2. Centre line: lower end point + bottom edge → point on object; upper end point + arc → point on object.
  3. Delete the bottom edge's “Horizontal” and make the two lower corners symmetric about the Y axis.
  4. Arc radius 5.5; horizontal distance 7 on the bottom edge; distance 7 from the origin to the bottom edge → fully constrained.
  5. Close the sketch, pad 8 mm, save.

On your own

  1. Add a second “horizontal distance 7” to the bottom edge, see what FreeCAD says, then delete it from the constraint list.
  2. Change radius 5.5 to 6 and watch the pad follow; change it back.
  3. Go back to the rectangle from lesson 3: centre it on the origin with “Symmetric”, add two dimensions and make it fully constrained.

Quiz

How many degrees of freedom does an arc have?

Centre 2 + radius 1 + start angle 1 + end angle 1 = 5.

The bottom edge is already Horizontal. You add Symmetric to the two lower corners about the Y axis and get “Redundant constraints”. Why?

Symmetric about a vertical axis = opposite x, equal y; equal y is exactly horizontal. Two constraints say the same thing, so one is redundant.

The whole sketch is green and says “Fully constrained”. That means?

Fully constrained = 0 degrees of freedom. You can still change dimensions (double-click and type), and it stays fully constrained.

05Lesson 5 Sketch techniques

You will be able to save half the drawing with a mirror; tidy intersecting circles and lines into one closed outline with Trim; drive dimensions with expressions and a spreadsheet so that changing one number updates the whole part. You make the plate outline of the WQ-LS crank. About 1.5 hours.

What you will be able to do

  • Tangent constraints: line to circle, line to arc; answer “Yes” to the “Sketcher constraint substitution” question.
  • Mirror (the Symmetry tool): draw one side, generate the other.
  • Trim: click away unwanted pieces one by one; know that Trim cuts at the nearest intersections.
  • Expressions: type = in a dimension to refer to other values; spreadsheets: one sheet controls a set of dimensions.

This lesson makes the crank plate outline: a circle of diameter 33 on the main shaft, a circle of diameter 22 for the crank pin, 15.5 apart, joined by two tangent lines into one loop and padded 10 mm. (The real WQ-LS crank also has a sector-shaped counterweight and two bores; a later lesson adds them.)

Mirror and trim

Two circles and two tangent lines cross at several points. Trim removes the piece you click between the nearest intersections on either side — so the large circle needs three clicks on top (first the middle, then the two small pieces up to the tangent points) and the small circle one click at the bottom. Try it here first:

Two details in the recording: - The second Tangent pops up “Sketcher constraint substitution”: FreeCAD offers to replace “point on circle + tangent” with a single “endpoint tangency”. Choose Yes. - The mirrored line is geometry only, without constraints; after the trims join its ends to the arcs, add two tangents just as on the right.

Expressions and spreadsheets

Type = first in a dimension box and it becomes an expression: arithmetic (=33/2) or a reference to another object's value (=Spreadsheet.B1). Keep a set of key dimensions in a spreadsheet: change a number in the sheet and every dimension and part that refers to it updates — that is how part families are made and how calculation results are carried into the model.

In the recording the plate volume is 10710.93 mm³ with a centre distance of 15.5; with 18 in the sheet it becomes 11360.1 mm³ after recompute.

Write Meaning
=Spreadsheet.B1 The value in cell B1
=Spreadsheet.e By name, after giving B1 the alias e (right-click the cell → Properties → Alias)
=Sketch.Constraints.D / 2 Half of the sketch dimension named D
=Pad.Length + 2 The pad length plus 2

Follow along

  1. New Parametric Body, sketch on XY: a circle of diameter 33 centred on the origin and one of diameter 22 on the Y axis.
  2. On the right draw a line with its ends on the two circles and add two tangents (answer Yes).
  3. Select the line, click Symmetry, then click the Y axis: the left side appears.
  4. Trim: three pieces on top of the large circle, one at the bottom of the small one. Add two tangents to the left line.
  5. Spreadsheet B1 = 15.5; in the sketch add a vertical distance from the origin to the small circle's centre: =Spreadsheet.B1; pad 10.
  6. Change B1 to 18, recompute, watch the crank; change it back to 15.5.

On your own

  1. Give B1 the alias e and change the expression to =Spreadsheet.e.
  2. Put the two diameters in B2 and B3 and make the diameter constraints read them too.
  3. Mirror again with “Create symmetric constraints” ticked: what does FreeCAD report after trimming, and how do you deal with it? (Redundant constraints, lesson 4.)

Quiz

You click a circle with the Trim tool. Which part is removed?

Trim looks for the nearest intersections or tangent points with other geometry, which is why it sometimes takes several clicks.

A dimension says =Spreadsheet.B1, and you change B1 from 15.5 to 18. What happens?

The expression links the dimension to the sheet; after recompute everything that refers to it updates.

Adding a tangent pops up “Sketcher constraint substitution”, offering an endpoint tangency instead. Usually you choose?

The line's end is already on the circle; adding tangency on top would repeat it. One endpoint-tangency constraint means both on the circle and tangent, without redundancy.

06Lesson 6 Pad, pocket, revolve, hole

You will be able to make prismatic parts with Pad and Pocket; turned parts such as shafts, rods and pins with Revolution and Groove; and threaded or counterbored holes with the Hole tool. You make the WQ-LS needle bar and crank pin. About 1.5 hours.

What you will be able to do

  • Tell the four basic features apart: Pad (extrude, add), Pocket (extrude, remove), Revolution (around an axis, add), Groove (around an axis, remove).
  • For a turned part, sketch only half the section, with one side on the axis.
  • Small sketches: zoom in to draw, then lock the position with Horizontal / Vertical distance.
  • Hole tool: place a point in a sketch first; choose thread type, size, depth and bottom shape in the panel.

The four basic features

Feature What it does Sketch needs Example in this lesson
Pad extrude along the normal, add material closed profile crank pin Ø10 × 25
Pocket extrude along the normal, remove material closed profile, on a face or plane of the solid (on your own)
Revolution revolve around an axis, add material closed half section, must not cross the axis needle bar Ø8 × 180
Groove revolve around an axis, remove material same oil groove on the needle bar
Hole cut a hole to a standard points or circles in a sketch M3 threaded hole in the pin end

Which one: the cross-section is the same all along (plate, pin, block) → Pad; the part is symmetric about an axis (shaft, rod, sleeve, wheel) → Revolution.

Needle bar: Revolution and Groove

The WQ-LS needle bar is 8 in diameter and 180 long, with two oil grooves 0.5 wide and 0.2 deep at 39.25 and 41.25 mm from the bottom, and a 0.5 chamfer at each end. This lesson makes the rod and the first groove:

  • After the first corner of a rectangle, just type “width, Tab, height, Enter” and the sizes become constraints; the first corner on the origin becomes coincident — fully constrained in one go.
  • The Revolution axis defaults to the vertical sketch axis; with the half section drawn against it, the result is a solid rod.
  • The groove rectangle is only 0.2 × 0.5: zoom in to over a hundred pixels per millimetre to draw it, then lock its lower-left corner with Horizontal distance 3.8 and Vertical distance 39.25.

Volumes: plain rod 9047.79 mm³; one groove 9045.34; two grooves 9042.89. After the 0.5 chamfers in lesson 7 it is 9036.86 — the same as the real needle bar in the machine, 9036.86 mm³.

On your own

  1. With Pocket, cut a slot 1 wide and 1.5 deep across the other end of the crank pin (not on the real part — practice): sketch on the end face, a rectangle across it, Pocket 1.5.
  2. Change the hole type to Clearance and see the diameter; then add a counterbore and see which parameters appear.
  3. Can both needle-bar grooves be drawn in one sketch and cut with a single Groove? Try it.

Quiz

The quickest way to model a stepped shaft?

A shaft is symmetric about its axis: draw the half section with all the steps and revolve once.

What happens if the half section of a Revolution crosses the axis?

Crossing the axis makes the revolved shape pass through itself, which is an error. Keep one side on the axis, or the whole section on one side of it.

Hole type “Tap drill (to be threaded)”, size M3 — what diameter is cut?

A tap drill is cut at the tap-drill size (2.5 for M3); 3.4 is the clearance hole. The thread itself isn't modelled; the size is stored in the properties.

07Lesson 7 Chamfer, fillet, draft, thickness

You will be able to chamfer and fillet edges; make cups, boxes and covers with Thickness; and know when to use draft and thicken. With its chamfers the needle bar becomes identical to the real part in the machine; then you make the WQ-LS bobbin case. About 1 hour.

What you will be able to do

  • Dress-up features (chamfer, fillet, draft, thickness) come after the shape is built: pick edges or faces first, then the tool.
  • Multiple selection: hold Ctrl to add a second or third edge.
  • Thickness: the selected faces are opened; every other face keeps the same wall.
  • Know the limits: Thickness is uniform; a fillet that is too large fails.

Five dress-up features

Feature Pick Main parameters Used for
Chamfer edges size (or two distances, or distance and angle) shaft ends, hole edges: easy assembly, no sharp edges
Fillet edges radius inside and outside corners of castings and mouldings; less stress concentration
Draft faces + neutral plane angle castings and mouldings release from the mould (1°–3°)
Thickness faces to open thickness, inwards or outwards cups, boxes, covers
Thicken (Part workbench, Offset → Thicken) a surface or face thickness turning surfaces into solids (lesson 14)

Do dress-up features last: finish the shape, then chamfer and fillet. If an earlier feature changes, edge numbers may change and the dress-up reports a missing edge — double-click it and pick the edges again.

Needle bar: chamfer

The needle bar from the last lesson, with both oil grooves. Chamfer 0.5 at both ends:

The volume is now 9036.86 mm³, the same as the real needle bar in the machine STEP, 9036.86 mm³ — revolution, two grooves and two chamfers, all matching.

Bobbin case: thickness

The bobbin case is a small cup that holds the bobbin: 22.4 outside, 14 deep, 0.6 wall.

After Thickness the volume is 787.08 mm³. The real bobbin case in the machine is 1104.77 mm³ — its bottom is 1.5 thick, not 0.6. Thickness is the same everywhere; for a thin wall and a thick bottom, skip Thickness: sketch a Ø21.2 circle on the end face and Pocket 12.5 mm to cut the cavity (On your own, 1).

  2. New file: circle Ø22.4 on XY, Pad 14.

  2. Fillet both ends of the crank pin R0.5, then change to a 0.5 × 45° chamfer and compare the volumes.
  3. In Thickness, untick “Make thickness inwards” (grow outwards). What does the outside diameter become?

Quiz

Chamfering two edges at once: how do you pick the second edge?

In Part Design a plain click replaces the selection; Ctrl adds to it.

What happens to the face selected for Thickness?

The selected faces are the openings; all other faces keep the wall thickness.

A cup needs a 0.6 side wall and a 1.5 bottom. Best approach?

Thickness is uniform; when walls differ, pocket the cavity to its own size so each wall is set by a dimension.

08Lesson 8 Sweep, loft, helix

You will be able to make springs with Helix; move a section along a path with a sweep (Additive pipe) for bent wires and tubes; and join several different sections with a loft. You make the WQ-LS presser spring and check spring. About 1.5 hours.

What you will be able to do

  • Helix: a section sketch plus an axis; pitch, height (or turns), left or right hand.
  • Sweep (Additive pipe in Part Design): one sketch for the path, another for the section, with the section at the start of the path and perpendicular to it.
  • Loft: two or more sections joined in order into one solid.
  • Each has a subtractive version: subtractive helix (threads), subtractive pipe, subtractive loft.

Three features

Feature Needs Typical parts
Helix a section sketch + axis; pitch, height, turns, cone angle springs, threads, screw conveyors
Pipe (sweep) section sketch + path (sketch, edges) bent wire, piping, seals
Loft two or more sections (sketches on different planes) transition pieces, ducts, handles, blades

Where the section sits matters most: a helix section must not touch the axis; a sweep section must be at the start of the path and perpendicular to it, or the result twists or self-intersects.

Presser spring: helix

The presser spring is 15.8 outside with 1.8 wire, so the section circle sits 7 from the axis (half the mean diameter).

The result has 15 turns and 1678.82 mm³. In the machine model the presser spring is drawn as a tube (15.8 outside, 12.2 inside, 62.79 long, 4971.25 mm³): assembly and motion simulation don't need every coil, and a tube is fast. For a part drawing or a stiffness calculation, use the real helix. The pitch of 4 is a demonstration value chosen for this lesson; the machine model doesn't give one.

Helix panel Notes
Axis vertical / horizontal / normal sketch axis; here the section is on XZ and the spring grows upwards, so vertical
Mode pitch-height-angle, pitch-turns-angle, height-turns-angle, height-turns-growth
Cone angle non-zero gives a conical spring
Left handed ticked for a left-hand coil

Check spring: sweep

The check spring is a Ø0.7 wire: an R9.35 arc through 265°, then a straight leg 14.85 long.

  • Path: arc with Radius 9.35 and Angle 265°, line tangent to the arc and 14.85 long — fully constrained.
  • Section: the XZ plane passes through the start of the arc, perpendicular to it there; the centre is at (9.35, 0).
  • Pipe panel: the section is already chosen; for the path click Object, then click any part of the path in the view — the whole sketch becomes the path.

The result is 22.36 mm³. The check spring in the machine STEP is 27.37 mm³; the difference is in how the ends finish, which this lesson doesn't go into.

Loft

A loft needs two or more sections on different planes, say a circle and a rectangle 20 mm above it: select the first section sketch, click Additive loft, Add section in the panel, then click the second sketch. Sections should have the same number of vertices (a circle lofts to anything) with aligned start points, or the result twists. There is no lofted part in the WQ-LS, so this is practice only (On your own).

Follow along

  1. New body, circle on XZ: centre on the horizontal axis, horizontal distance 7, diameter 1.8. Helix: vertical sketch axis, pitch 4, height 60.
  2. New file, path on XY: arc (centre on the origin, start on the horizontal axis, radius 9.35, angle 265°), a line from its end, tangent to the arc, 14.85 long.
  3. Section on XZ: centre at horizontal distance 9.35 on the horizontal axis, diameter 0.7.
  4. Select the section sketch, Additive pipe, Object for the path and click the path. The volume should be 22.36 mm³.

On your own

  1. Switch the presser spring to height-turns-angle: height 60, 14 turns. What is the pitch now?
  2. On one end of the needle bar (lessons 6–7), cut an illustrative M8 thread with a subtractive helix: the section is a small triangle.
  3. Loft practice: a Ø20 circle on XY; a datum plane 20 above with a 16 × 10 rectangle; Additive loft. Then replace the rectangle with a circle and compare.

Quiz

The helix section circle is 7 from the axis with diameter 1.8. What is the spring's outside diameter?

Outside diameter = 2 × (7 + 0.9) = 15.8; mean 14, inside 12.2.

Where should a sweep section be?

At the start and perpendicular, the sweep is a uniform tube; placed askew it twists or self-intersects.

Why are springs often drawn as plain tubes in a machine model?

Hundreds of parts move together; helical faces are many and slow. Use the real helix for part drawings and stiffness.
