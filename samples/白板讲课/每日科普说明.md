# 每日热点科普：做法（定时任务每天照这个做）

Eddie 2026-10-15 定：每天抓热点新闻，和科普结合，做成 MinutePhysics 式的白板短片。**每天两期：一期中文、一期英文**，早上 8 点（美东）前发给 Eddie。

## 一、选题
- 中文期：当天中国网民热议的科技/科学热点（新浪科技热点小时报、澎湃、36氪等）；英文期：当天英文世界的科技/科学热点（The Verge、Ars Technica、Science/Nature 新闻、AIP FYI、The Robot Report 等）。两期不要同一个题目。
- 优先：机器人、AI、物理、工程、航天、生命科学里**能讲出一个科学道理**的新闻；问渠是机器人学院，机器人相关的加分。
- 不选：政治、战争、灾难伤亡、名人八卦、医疗建议、尚未核实的传闻。
- 事实必须有出处（至少两个来源或一个权威来源）；拿不准的数字不用，或在片中说“据报道”；推测要说成推测；思想实验要说是思想实验。

## 二、讲稿（2 分半到 3 分钟，约 22–28 段）
照《AI 为什么总“转圈圈”？》（`科普_AI为什么总转圈圈/make.py`）和《电脑里的那只果蝇，痒吗？》（`科普样片_果蝇大脑_v2/make.py`）的路子：
1. 开头一句抓人的事实或问题（新闻本身），第二句就抖一个包袱；
2. 一个**烧脑问题贯穿全片**，中间至少两次反转（“原因三，最反直觉”“再烧一点”）；
3. 用一个**贴切的比喻**把科学讲透（例：神经元 = 传纸条，攒够了才往下传；AI 宕机 ≈ 当年的电网）。比喻必须准确，不能“到处短路”式地误导；
4. 幽默：自嘲、对观众说话、一个贯穿全片的梗，结尾回扣开头；
5. 最后“友情提示”说清局限，再用一句妙语收尾。
- 中文期全中文（术语可附英文）；英文期全英文，口语、短句。
- 先写讲稿，自己核对一遍事实，再排画板。

## 三、画板
- 复用 `popkit.py`（cute_fly、stick、network、bubble、txt）和 AI 那期的 `xiaoka`（小卡，显卡角色）、spinner、pylon、house、button；需要新角色就照同样的画法加进 `popkit.py`。
- 没有手（`lesson["hand"] = False`），画得快（`lesson["pace"] = 0.5`），不写板书标题；一张画板一个点，字少、简笔画为主，一点颜色。
- 让东西动起来：`bob`（悬停）、`wiggle`（扇动、搓）、`spin`（转圈）、`signal`（小点沿线传）、`rotate`/`shift`（可带 `delay` 依次发生，做多米诺）、`pulse`（强调）。整只角色用 `"name*"` 作目标。
- 英文期的字用 `font="en"`；中文期用默认中文字体。脚本会检查缺字（`missing_chars`），缺字就换写法。
- 先用假时间（每段 7 秒）出一张全部画板的缩略图检查排版（见下），没问题再配音。

## 四、配音、出片
- 声音模型：`services/voice/fetch_models.sh <目录>` 下载（约 440 MB，GitHub）；中文用 `zm_yunjian`（sid 49），英文用 `am_michael`（sid 16），语速 1.12。英文名、数字年份在中文期里按读法替换（如 DeepSeek → Deep Seek，1965 → 一九六五）。
- 每期一个目录：`samples/白板讲课/每日科普/<日期>_<中文|英文>_<题目>/`，里面放 `make.py`（讲稿、画板、配音全在里面，`--boards-only` 只重排画板）。
- `python3 make.py <kokoro 模型目录>`，然后 `python3 tools/whiteboard/wb.py <目录> --mp4`（约课长的 4 倍时间）。
- 检查：`tools/whiteboard/snap.py <目录>` 看每张画板画完时的截图；抽几帧 MP4 看动作。

## 五、交付
- 两期的 MP4 和网页版（`白板课.html`）用 SendUserFile 发给 Eddie（push 通知），附：题目、一句话卖点、事实出处链接、哪些是推测或思想实验。
- 讲稿和脚本提交推送到 main（MP4、音频不进仓库，`.gitignore` 已忽略）。
- 做不成时（比如没有合适的热点、模型下载失败），照样在 8 点前告诉 Eddie 原因和备选题目。
