# 三维仿真视频：场景文件格式（第 37 轮）

一段视频就是一个目录，里面放一个 `scene.yaml`。场景文件里只写数据，不写程序；AI 写的、人改的都是这个文件。

```bash
python3 tools/blender/render.py video3d/<名> --draft --still 3,15   # 看几张单帧（几十秒）
python3 tools/blender/render.py video3d/<名> --draft                 # 低清小样（960×540，15 帧/秒）
# 正式片：GitHub → Actions → “3D video” → Run workflow（填场景目录；20 份并行，约 10 分钟）
```

样板：
- `video3d/机械臂抓取/scene.yaml`：程序生成的机械臂，逆运动学，透视电机；
- `video3d/缝纫机一针/scene.yaml`：已有虚拟实验的整机和运动，剖开，透视，读数和曲线；
- `video3d/旋梭钩线_整机/scene.yaml`：从整机钻到针板下看旋梭钩线，再到布里的线结，最后回整机（三维线环、线迹、两段剖开叠用）。

平台上（第 38 轮）老师在“三维视频”里出片：AI 按本文件写场景，网关先检查（`services/gateway/app/video3d.py` 的 `check`），关键画面在 blender 容器出，小样和高清租 Lambda 机器出。

## 规则

1. **只用已有模型**（Eddie 2026-10-16）：
   - `gen:` 程序生成的机构；
   - `box` / `cyl` 简单形体；
   - `weblab:` 已有虚拟实验的整机；
   - `item` 被搬运的小物件。
   - 不能凭空造形状。缺的机构先做成生成器或接入虚拟实验。
2. **运动都由程序算**：
   - 机械臂用逆运动学；
   - 整机用虚拟实验自己的机构计算，视频和学生在网页上看到的完全一致；
   - 不手调关键帧。
3. **坐标：** 米，z 向上；镜头的方位角 `az`：0 = 从 −y 方向（正前方）看，正值向右转。

## 顶层字段

| 字段 | 说明 |
| --- | --- |
| `name` | 成片文件名 |
| `title` | `{zh, en}` 默认标题 |
| `duration` | 秒 |
| `fps` | 默认 30 |
| `floor` | 默认 `true`（地面）；整机自带台板时写 `false` |
| `clip` | 镜头最近距离，默认 0.01；拍小零件时写 0.002 |
| `light` | 灯光预设，默认 `paint.sl` |

## models（只用已有模型）

| use | 参数 | 说明 |
| --- | --- | --- |
| `gen:arm6` | `params: {d1, l2, l3, tool}` | 六轴机械臂，夹爪竖直朝下的逆运动学。组：`<id>.shell` 外壳，`<id>.motors` 电机和减速器（平时不画，透视时画） |
| `gen:conveyor` | `at: [x, y]`、`length`、`width`、`height`、`speed` | 传送带，沿 x 走 |
| `box` / `cyl` | `size`（box 为长宽高；cyl 为半径、长度）、`at`、`rot`（度）、`color` | 台子、底座等 |
| `item` | `start`、`appear`、`pick`、`drop`（秒）、`arm`、`belt`、`size`、`color` | 在 start 出现 → pick 时被夹住随夹爪走 → drop 后随皮带走 |
| `weblab:<实验>` | `at`、`colors`（零件名或组名 → 颜色名）；缝纫机另有 `loop3d: true`（旋梭钩线按三维画线环，加梭尖红点和转向箭头）、`handover: 300`（旋梭转过这个角度后，收线交给布上的线迹 `gen:seam` 接着画） | 已接入：`sewing/proto-lockstitch`。组：`<id>.<零件名>`、`<id>.<零件组>`（frame、needle、takeup、hook、feed、drive）、`<id>.threads`；`loop3d` 时另有 `<id>.threads_static`（梭尖、箭头）。缝纫机零件名：face、top、rear、body、body_cut、table、stand、spool、details、oil、belt、tension、guide、feed、lower、upper、rod、takeup、presser、slide、bush、plate、needle、hook、nbar、bcase、bstop |
| `gen:seam` | `at`、`rot_z`（度）、`stitches`、`pitch`、`ply`、`thread`、`width`（米）、`tighten: [起, 止]`（秒，最后一针收紧）、`hide_last_before_tighten` | 两层布沿针孔剖开的锁式线迹，面线蓝、底线橙，捻线画法。放到缝纫机针孔：`at: [-0.017, 0, 0]`、`rot_z: -90`。组：`<id>.threads` |
| `gen:sewdesign` | `machine`（`lockstitch` 平缝机 / `overlock` 包缝机）、`params`（设计参数，同缝纫机设计软件）、`at`、`colors`（零件名或组名 → 颜色） | 第 56 轮：缝纫机设计软件里“这一台设计”的机构零件，尺寸、每个主轴转角的位置都由计算核心 `sewcore/cad.py` 的 `parts3d` 给（同网页三维、STEP）。运动写 `drive: weblab` 同样的 `angle`。组：`<id>.<零件名>`（同 STEP）、`<id>.<机构>`（needle、takeup、hook、feed、drive、frame；包缝机另有 looper、knife）。读数：`phi`；平缝机另有 `needle`（针尖高出针板 mm）、`hookdeg`。不画线环。**由设计软件“导出 → 三维讲解片”自动写，`machine`、`params` 锁定：AI 和人改场景时改不了，网关每次都按那台设计重置** |

颜色名：`body` `joint` `accent` `part` `table` `belt` `frame` `floor` `motor` `gear` `needle` `takeup` `hook` `feed` `steel` `shell` `wood` `thread` `bobbin` `dark`。

## points 与 motion

- `points`：给位置起名字，`{名: [x, y, z]}`。
- `motion` 每一项是一个驱动：
  - `drive: pick_place`，`model: <机械臂>`，`steps` 是一个列表，每一步：
    - `{t: [起, 止], at: 点}`：停在一个点；
    - `{t: [起, 止], from: 点, to: 点}`：从一点走到另一点，五次多项式平滑加减速；距离超过 0.3 m 的走拱形，`arch` 设拱高；
    - `do: grip | release`：夹紧或松开；
    - `holding: true`：这一步手里拿着东西。
  - `drive: weblab`，`model: <整机>`，`angle: [[秒, 主轴累计转角°], …]`：相邻两点之间匀速转。慢放、暂停、快放都用它表达。

## camera

关键点列表：`{t, look: [x, y, z], az, el, dist, lens}`。相邻两点之间平滑过渡；同样的值写两次就是停住。

## effects

- `{kind: xray, t: [起, 止], top: [组, …]}`：透视。别的东西都变成半透明，`top` 里的组清楚地叠在上面；前后各用 1.5 秒淡入淡出。
- `{kind: cutaway, t: [起, 止], hide: [组…], show: [组…]}`：剖开，例如去掉外盖、把机壳换成开窗机壳。几段可以叠用（整机去外盖一段、近看时再去掉更多一段）。
- `{kind: blur, t: [起, 止], n, shutter}`：运动模糊（快速运动时用）。
- `{kind: flash, t: [起, 止]}`：闪白（只在 `style: cinematic` 里用）。

## stills（可选）

关键画面取在哪几秒（1–6 个）。不写就按镜头关键点自动挑。缝纫机讲解片用它把红灯那张停在出问题的转角上。

## lang（可选）

`both`（默认：每条字中文一行、英文一行）、`zh` 或 `en`：只出一种文字。缝纫机讲解片跟设计软件的“文件语言”走。

## style

默认工程图风格（出片快）。`style: cinematic` 是写实电影风格（真实光照、深色背景、浅景深，配 `voice`、`pops`、`titles` 叠字），渲染慢得多，只在需要“震撼”时用。

## labels（中英标注）

`{t: [起, 止], zh, en}`：
- 默认显示在顶部标题栏；加 `tone: bad` 标题画成红色、`tone: warn` 黄色（第 56 轮，红黄灯项）；
- 加 `where: bottom`：显示成底部字幕条；
- 加 `phi: [起, 止]`：只在主轴转角落在这个区间时显示，用于按机构相位讲解。

## panel（右侧面板）

- `{kind: joints, arm: <机械臂>}`：6 个关节角加夹爪状态。
- `{kind: readouts, head, items: […], plot: {…}}`：
  - `items` 每一项：`{zh, en, key, fmt, unit, scale}`。`key` 取实验给出的读数，缝纫机有 `phi`（主轴转角）、`needle`（针尖高出针板，mm）、`hook`、`hookdeg`（旋梭转过的角度）、`tk`（挑线杆）、`dogX`、`dogY`（送布牙）；写了 `scale` 就画读数条。
  - `plot` 画一圈 0–360° 的曲线，带当前位置光标：`{key, zh, en, marks: [{phi, zh}]}`。

## 接入新的虚拟实验

页面的 `window.__api` 要提供两个接口，然后在 `tools/blender/weblab.py` 的 `LABS` 里登记：
- `mesh()`：返回零件网格，格式同 `WQLS_MESH`；
- `dump(a)`：返回主轴累计转角 a 时每个零件的世界矩阵（毫米，y 向上）、线的路径点和读数。
