## 第 1 课 · 认识界面（`wqcad-l01a.mp4`，剧本 `tools/video/fcrec/l01a.py`）

- `00:00` 开始页：新建、打开文件、示例。点“打开文件”，打开 WQ-LS 平缝机整机
- `00:08` 最上面是菜单：文件、编辑、视图、工具……所有命令都在这里
- `00:11` 下面是工具栏：常用命令的按钮。鼠标停在按钮上会显示它是什么
- `00:15` 工作台下拉框：零件设计、草图、装配、工程图、有限元……换工作台，工具栏跟着换
- `00:18` 左上是模型树：文件里的每个对象。WQ-LS 按部件分了八组
- `00:22` 左下是属性：选中一个对象，它的位置、颜色、尺寸都在这里
- `00:25` 中间最大的是三维视图，零件在这里看、在这里点选
- `00:29` 右上角是导航立方体：点它的面，就转到那个方向看
- `00:32` 报告视图：软件的提示、警告、出错都写在这里（视图 → 面板 → 报告视图）
- `00:37` 最下面是状态栏：鼠标指着什么、当前的导航方式、单位
- `00:41` 这就是 FreeCAD 的界面。问渠 CAD 是在它上面改的，界面一样

## 第 1 课 · 鼠标导航、标准视图、选零件（`wqcad-l01b.mp4`，剧本 `tools/video/fcrec/l01b.py`）

- `00:07` 状态栏右下角写着“CAD”：现在是 CAD 导航方式（问渠 CAD 默认）
- `00:11` CAD 导航方式：按住中键拖动 = 平移
- `00:14` 按住中键再按左键拖动 = 旋转
- `00:17` 滚轮 = 缩放：往前滚放大，往后滚缩小（以鼠标所在点为中心）
- `00:22` 转乱了不要紧：点“适应全部”，整机回到画面中间
- `00:25` 导航立方体：点“前视图”那一面，就从前面看；点角上，看轴测
- `00:28` 按 2
- `00:30` 按 3
- `00:31` 按 0
- `00:35` 左键点一个零件：它变绿，左下的属性里显示它的数据；点空白处取消

## 第 1 课 · 首选项（`wqcad-l01c.mp4`，剧本 `tools/video/fcrec/l01c.py`）

- `00:00` 菜单“编辑 → 首选项”：软件的各种设置都在这里
- `00:05` “常规”页的“语言和数字格式”：界面语言、默认单位系统（标准 mm / kg / s，或英制）、小数位数
- `00:12` “显示 → 导航栏”：导航方式（CAD、Blender、触摸板……）也可以在这里换
- `00:20` 看完按“取消”，什么都不改

## 第 3 课 · 压脚杆套环（`wqcad-l03a.mp4`，剧本 `tools/video/fcrec/l03a.py`）

- `00:00` 从开始页新建一个“参数实体”：零件设计工作台，一个实体（Body）
- `00:02` 点“新建草图”，选 XY 平面
- `00:10` 圆工具：先点圆心（原点），再键入直径 16，回车
- `00:15` 工具还开着，接着画内孔：圆心还是原点，直径 8
- `00:20` 右边显示“完全约束”（绿色）：两个圆的位置、大小都定了
- `00:22` 关闭草图，选中草图点“凸台”，长度键入 3 mm
- `00:33` 压脚杆套环：外径 16、内孔 8、厚 3——和 WQ-LS 设计里的一样

## 第 3 课 · 针夹轮廓（`wqcad-l03b.mp4`，剧本 `tools/video/fcrec/l03b.py`）

- `00:10` 针夹的轮廓：上面一段圆弧，下面一个方耳朵。先用“多段线”画三条直边
- `00:17` 右键结束多段线（工具还开着就按 Esc 退出）
- `00:18` 圆弧工具：先点圆心（原点），再点起点，绕过上面，到终点
- `00:26` 中间的孔：圆工具，圆心在原点，直径 8
- `00:31` 再画一条竖的中心线，切换成“构造线”（蓝色虚线：只帮忙定位，不成形）
- `00:39` 轮廓画好了，但尺寸是点出来的，不准——右边写着还有几个自由度。第 4 课用约束把它定死

## 第 4 课 · 自由度（`wqcad-l04a.mp4`，剧本 `tools/video/fcrec/l04a.py`）

- `00:06` 右边写着“约束不足”：还有几个自由度——形状能被拖动，尺寸没定
- `00:10` 拖一下下边线：整条边跟着走，因为它离原点多远还没定
- `00:13` 圆弧也能拖大拖小：半径也没定
- `00:16` 撤销两次（Ctrl+Z），回到原样
- `00:18` 颜色也告诉你：白色是还能动的，完全约束以后全变绿

## 第 4 课 · 几何约束与冗余（`wqcad-l04b.mp4`，剧本 `tools/video/fcrec/l04b.py`）

- `00:06` 几何约束：先选对象，再点约束按钮。中心线下端还没定——选它的下端点，再选下边线
- `00:09` 点“重合 / 点在线上”：端点落到线上
- `00:12` 上端点放到圆弧上：同样先选，再点
- `00:18` 左右对称：选左下角、右下角，再选竖轴（Y 轴），点“对称”
- `00:25` 红字“冗余约束”：对称已经让左右两点一样高，下边线原来的“水平”就重复了
- `00:29` 撤销对称（Ctrl+Z），在约束列表里选中那个“水平”，按 Delete 删掉
- `00:33` 再加对称：左下角、右下角、Y 轴，点“对称”
- `00:41` 每加一个约束，自由度就少一点。剩下的要用尺寸定

## 第 4 课 · 尺寸约束到完全约束（`wqcad-l04c.mp4`，剧本 `tools/video/fcrec/l04c.py`）

- `00:06` 还剩 3 个自由度：圆弧多大、耳朵多宽、耳朵伸多长。用尺寸约束定
- `00:09` 选圆弧，点“半径”，键入 5.5
- `00:14` 选下边线，点“水平距离”，键入 7（耳朵宽 7）
- `00:20` 选原点和下边线，点“距离”，键入 7（下边离中心 7）
- `00:26` “完全约束”，整个草图变绿：每条线在哪、多大都定了
- `00:31` 关闭草图，凸台 8 mm：针夹就出来了（尺寸和 WQ-LS 设计里的针夹一样）
