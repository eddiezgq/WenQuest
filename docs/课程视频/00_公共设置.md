# 公开课视频 · 各门课共用的设置

所有课程（线性代数、微积分、缝纫机设计与制造、大学物理……）的公开课视频都用同一套设置。

> **标准样板（2026-10-07 Eddie 定）**：《线性代数》14.2 讲（`docs/课程视频/线性代数/14-2/`：讲稿、`预览/` 里的关键画面、字幕与上传资料；成片见 Actions 运行 37696207354）。新课程的每一讲按它的结构、风格、长度和审读流程做。定于第 22 轮。2026-10-07，Eddie 要求“和其他课程共享”。新开一门课的视频时，直接照这里做，不另起一套。

## 二、仓库密钥（都已设好，各门课共用）

| 密钥 | 用途 |
|---|---|
| `VOICE_KEY` | 解开样音（也用来加密试听结果） |
| `LAMBDA_KEY` | 租 GPU 合成配音 |
| `YT_CLIENT_ID`、`YT_CLIENT_SECRET`、`YT_REFRESH_TOKEN` | YouTube 上传 |

## 三、做一讲的步骤

1. 讲稿写在 `docs/课程视频/<课>/<讲>/讲稿.yaml`，格式见 `tools/video/README.md`。网页版教材（缝纫机课）的写法也在那里。
2. 讲稿过独立 AI 审读，修改后提交。
3. 到 GitHub → Actions → “Lecture videos 公开课视频” → Run workflow，按下表填：

   | 选项 | 填法 |
   |---|---|
   | task | `render` |
   | lectures | 讲稿目录（可以填几讲，用空格分开） |
   | voice | `clone` |
   | engine | `cv2` |
   | upload | 先 `none`，Eddie 看过后再 `youtube` |

4. 运行完，`预览/` 下会自动提交这几样，不下载视频也能检查：
   - 关键画面拼图；
   - 字幕；
   - 上传资料；
   - 时长。
5. 成片在这次运行页面的 Artifacts 里下载（保留 14 天）。

## 四、注意

- 工作流按“讲稿目录 + 任务”分别排队，不同课、不同讲的运行不会互相挤掉。
- 配音按“声音 + 文字”缓存在 GPU 机器的一次运行里。改了一句讲稿，要重跑这一讲的配音（`voice=clone`）。
- 声音合成的运行日志（去掉 IP）放在 `docs/课程视频/运行日志/`，出错时先看这里。
