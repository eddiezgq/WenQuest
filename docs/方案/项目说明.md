# 问渠 WenQuest 智慧教学平台 · 项目说明

> 本文件建议作为 Claude Project 的第一份知识文件，并把下面“项目背景”一节复制到 Project 的自定义指令里。

## 项目背景（可直接用作 Project 指令）

- 项目：问渠 WenQuest，AI 原生、适应国内生态的高校智慧教学平台。口号“问渠那得清如许，为有源头活水来” / *Every answer has a source.*，简称 WenQ。
- 目标：回国向高校推介，先做一个学院试点，再推广全校，并以云服务形式对外。
- 架构：自研问渠前端（网页 + 微信小程序 + App，一套 uni-app 代码）+ 接口网关 + AI 服务层（核心，Python FastAPI）+ 教学引擎适配层 + 开源 Moodle 5.2（无界面，只做教学数据引擎）+ 模型网关 + 已备案国产大模型。所有终端经接口网关访问，不直接访问 Moodle。引擎可替换，后续可接 Canvas。
- 为何 Moodle 不选 Canvas：部署运维简单（PHP）、信创适配、国内人才多、题库成熟、自带 AI 子系统和 DeepSeek 接入；许可上 Moodle 为 GPL v3，Canvas 为 AGPL v3（只调用接口、不改代码时影响较小）。
- 合规：国内只用已备案模型（DeepSeek、通义千问等），属地网信办登记，AI 生成内容标识，等保三级，个人信息保护，数据境内存储。Claude 只用于美国演示，Anthropic 不向中国大陆提供服务；`aiprovider_claude` 不进国内部署包。
- 政策依据：《“人工智能+教育”行动计划》（教科信〔2026〕1号，2026 年 4 月）。
- AI 功能按“教、学、练、评”十个模块：智能课件工坊（含智能备课）、情景教学、课程 AI 助教、虚拟实验（含 AI 机器人仿真实验包）、个性化学习路径、智能出题与组卷、智能批改、学情分析与预警、学生过程性评价、教学评价。
- 原则：AI 做教师的助手，不替代教师；AI 引导学生思考，不代替学生完成学习；回答注明出处；评价由教师复核。
- 待办提醒：WenQuest 商标与域名检索；Docker 镜像尚未在真实服务器上构建；Claude 插件需真实 API Key 做一次端到端测试。

## 代码现状

- **已实现**：Moodle 5.2 安装与部署包；DeepSeek 自动配置；Claude 提供方插件（Messages API，Sonnet 5 / Opus 5.5 / Haiku 4.5，海外演示用）；题库样品已导入 Moodle 验证；各演示样品。
- **下一步开发**（按架构文档第二十三节）：模型网关与 `aiprovider_ailms`、接口网关、AI 服务层框架与 `local_aiservice`、课程知识库与 AI 助教、问渠前端（uni-app）、教学引擎适配层、情景教学封装为 `mod_aiscenario`、仿真实验包下一批（巡线小车、路径规划）。

## 开发环境要点

- Moodle 5.1 起代码在 `public/` 下，路由 `FallbackResource /r.php`，需 `max_input_vars ≥ 5000`。
- PHPUnit 初始化：`php public/admin/tool/phpunit/cli/init.php --disable-composer`，需要 `en_AU.UTF-8` 语言环境。
- 插件放在 `public/ai/provider/claude`。
- 部署：复制 `.env.example` 为 `.env`，填密码和 API Key，`docker compose up -d`。
