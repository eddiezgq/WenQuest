## 一、原则与对标

**1. 能实不虚、虚实结合。** 教育部对虚拟仿真实验教学的要求是：在坚持“能实不虚”的基础上建设虚拟仿真实验，探索线上线下结合。虚拟仿真主要解决几类问题：真实实验条件不具备，高危、极端环境，高成本、高消耗，操作不可逆，大型综合训练。我们的定位是：
- 每个实验室都有虚拟版。学生先在虚拟里做，熟悉流程、验证设计。
- 能配实物的配实物：机器人学院的实验室、合作学校的现有设备。
- 实物做不了、做不起、不能反复做的，以虚拟为主：芯片流片、数控撞刀、液压爆管、整条产线等。

**2. 对标三类标准。**
- 教育部《普通高等学校本科专业类教学质量国家标准》：机械类、电子信息类、计算机类、自动化类对实验和实践环节的要求。
- 中国工程教育专业认证通用标准：实践环节要能支撑毕业要求。
- 国家虚拟仿真实验教学课程共享平台“实验空间”（ilab-x.com）：申报国家级课程，需要按它的技术接口规范（2020 版）完成数据接口联通。我们的实验按这个接口预留，日后可以申报、共享。

**3. 每个实验项目的标配。**
- 实验目的、原理、实际问题（以机器人为主，保留一个生活例子）
- 实验指导书、报告模板
- 交互操作（学生自己设参数、做选择，不是看动画）
- 自动判分：`services/labcheck` 无头检查
- 中英对照
- 简介视频 3 分钟以内，引导视频 5–8 分钟，用网页版 PPT 加真页面录屏

**4. 三档运行。**

| 档 | 在哪里跑 | 用在 |
| --- | --- | --- |
| 浏览器档 | 自写网页实验、WebAssembly、Pyodide | 基础实验、验证性实验；手机也能做 |
| 容器档 | 服务器上每人一个容器 | 芯片流程、有限元、ROS 2、操作系统、网络等 |
| 本机档 | 学生电脑：问渠 CAD、问渠电子 | 设计性实验、课程设计、毕业设计 |

不默认提供 GPU。需要 GPU 的实验先做 CPU 小规模版；要开 GPU 须经 Eddie 同意。

**5. 实验类型代号。** 验 = 验证性，综 = 综合性，设 = 设计性 / 创新性。学时按 2 学时一个实验计，综合、设计类 4–8 学时。

**6. 资源状态。** ● = 已有核或已有实验，补指导书和判分即可；◐ = 有部分资源，要改造；○ = 新建。
