## 一、定位与目标

本方案给问渠增加一条“弱电—微电子”课程线：用开源工具和网页虚拟实验，让学生从晶体管一路做到芯片版图，优秀作品可以真流片。它和已有的物理课、机器人仿真实验包采用同一套做法（R2 课型、R4 虚拟实验标准、R6 建模主线、R7/R8 指导书与报告），不另起炉灶。

**面向对象**：国内高校的微电子科学与工程、集成电路设计与集成系统、电子信息工程、电子封装技术专业；美国机器人学院中想走芯片与嵌入式方向的学生。

**培养的能力**：

1. 懂原理：半导体物理、器件和工艺的物理图像，能用模型做估算。
2. 会设计：数字与模拟电路设计、硬件描述语言、版图，走通一次完整的 RTL 到 GDS 流程。
3. 会验证与测试：仿真、验证、良率和可靠性分析。
4. 懂封装：热、力、电三方面的封装问题，会用有限元和电磁仿真工具估算。

**与现有工作的关系**：机器人方向的实际问题继续沿用（例如为机器人关节驱动器设计一块电机控制芯片的数字部分、为传感器设计一个放大器）；嵌入式部分和机器人仿真实验包的巡线小车共用；封装的热与可靠性问题和数字工厂的质量模块可以衔接。

**本方案的范围**：课程体系、工具选型、虚拟实验清单、贯通项目、资源估算和施工顺序。不含教材正文；每门课的课件、动画和实验在确认后按样例章逐门做。

## 五、贯通项目：从晶体管到芯片

贯通项目是这条线的招牌：同一个机器人问题贯穿四步，学生交出一份可以提交流片的 GDS 版图。前三步放在对应课程里分散完成，第四步在第 7 学期的集成电路课程设计里集中完成。（在线主本中有“四步与流片奖励”示意图。）

**主问题（示例）**：为机器人关节设计一块电机控制芯片的数字部分——PWM 发生器加编码器计数器。规模足够小，能放进一个开源流片小块；也足够真实，和机器人实验包的电机控制直接衔接。

1. **器件**（半导体器件物理）：在 SKY130 模型上测 MOSFET 曲线，得到后面设计要用的阈值和驱动电流。
2. **单元**（数字集成电路设计）：设计反相器和一个与非门，亲手画版图并通过 DRC/LVS，理解标准单元库是怎么来的。
3. **模块**（硬件描述语言与 FPGA、集成电路验证）：用 Verilog 写 PWM 与计数器，用 cocotb 验证，有开发板的可先上 FPGA 试跑。
4. **芯片版图**（VLSI 物理设计、课程设计）：用 OpenLane 跑出 GDS，修正时序和 DRC 违例，写设计报告。

**评分**：沿用实验报告量规（原理 20、数据 25、分析 25、实际问题 20、规范 10），另加一项“流片就绪度”：时序、DRC、LVS 全部通过。AI 给评分建议，教师复核。

**流片路径**：流片就绪且评分优秀的作品，可报名 Tiny Tapeout 这类共享流片项目，每个设计占芯片上一小块，费用约数百美元。问渠每学期资助评分前几名，其余学生可自愿自费。合作工厂、班次和价格常变，见第九节。拿到芯片后，可以在机器人实验台上用它真的驱动一个电机，整条线形成闭环。

## 六、平台与服务器资源

浏览器档几乎不花钱，成本集中在容器档，尤其是 RTL 到 GDS 的后端流程。容器档延用机器人仿真进阶档的做法：每人一个容器，画面推到浏览器，按使用时长计费。下表数字是估算，待容器镜像做好后实测。

| 项目 | 浏览器档 | 容器档（交互） | 容器档（批处理） |
|---|---|---|---|
| 内容 | 自写网页实验；WebAssembly 版 ngspice、Yosys；Pyodide | Xschem、Magic、KLayout 等图形工具，经网页远程桌面使用 | OpenLane 全流程、大型仿真、DEVSIM、有限元 |
| 每人资源（估） | 学生自己的浏览器 | 1–2 vCPU、4 GB 内存 | 2–4 vCPU、8 GB，小模块一次 10–30 分钟 |
| 共享存储 | 无 | 开源 PDK 只读共享卷，每个工艺库约数十 GB（待核） | 同左 |
| 调度方式 | 不需要 | 上课时按班级预启动 | 作业排队，结果（日志、版图图片、报告）写回问渠 |
| 一个 60 人班的峰值（估） | 0 | 约 120 vCPU、240 GB | 排队后约 32–64 vCPU 即可 |
| 计费 | 包含在平台内 | 按使用时长，云服务增值项 | 同左 |

**部署**：美国学院继续用现有 DigitalOcean 环境，容器档按需开节点；国内高校按总方案第六节的三种部署模式选择，开源工具链可全部离线安装在校内。

**AI 助教的角色**：与机器人实验包一致。AI 读 DRC/LVS 报告、时序报告和仿真曲线，指出问题和方向，不替学生改设计；学生尝试 3 次后才解锁示范。

## 七、施工顺序与验收

建议先做一门样例课的第 1 章，把浏览器档和容器档各跑通一次，再铺开到其他课。样例课建议选“数字集成电路设计”：它同时用到器件、电路、版图和工艺库，也是贯通项目的第二、三步。

| 步 | 内容 | 交付物 | 验收 |
|---|---|---|---|
