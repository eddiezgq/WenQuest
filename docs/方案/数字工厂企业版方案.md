# 问渠数字工厂 · 企业版方案

2026-10-01 · Eddie 已接受方向（“企业建议我接受”）；分期细节见 `factory/digital/实施细则_第8轮_企业版第一期.md`

## 一、定位

数字工厂现有两种模式：**教学模式**（学生扮演各角色做实验 7）和**生产模式**（一家工厂的日常工作台）。企业版就是把生产模式做成企业真正能用的样子。

企业不缺 CAD，缺的是 **CAD 与 ERP、车间的打通**：设计改版后，物料、BOM、工艺、加工程序自动跟着变，车间只拿到批准过的最新版。数字工厂已经有这条链（发布 → 统一数据总线 → ERPNext 版本加一 → 工单带新 G 代码 → AI 检查在制品），企业版在这条链上补齐企业必需的环节。

## 二、分工

| 谁 | 用什么 | 做什么 |
|---|---|---|
| 设计工程师 | 桌面 CAD：FreeCAD（免费、可商用）；企业已有的 SolidWorks、中望、CAXA 等 | 画图；用“发布到问渠工厂”插件提交新版本。暂时没有插件的 CAD：在网页上传 STEP 发布 |
| 工艺、质量、主管 | 网页：三维看图、图纸、标注意见、审批 | 不装 CAD 也能看懂改了什么、提意见、批准或退回 |
| 销售、接单 | 网页参数配置器（由现在的网页设计台升级） | 标准产品按客户要求改尺寸，自动出图纸、报价、草拟订单 |
| 车间 | 车间终端 | 只拿到已批准的版本和加工程序 |

## 三、要补的功能（企业版相对现在）

1. **设计发布审批**：提交 → 审阅（看图、批注）→ 批准/退回 → 生效。只有批准后，ERPNext 的版本、BOM、工单程序才更新。全程留痕。
2. **网页看图与批注**：任何发布的版本都能在网页上转动三维、看图纸；可以在模型上点一处写意见；新旧两版对比。
3. **通用零件发布**：不再只限输出轴 SH-301，任何物料编号都能发布（STEP、图纸、加工程序可选）。
4. **CAD 接入**：FreeCAD 工作台按钮（第一期）；网页上传 STEP（任何 CAD 都能用，第一期）；SolidWorks、中望等专用插件（第二期，需要 Windows 和正版软件实测）。
5. **参数配置器**：把产品做成“参数模板”（参数、校核规则、建模、图纸、工艺），销售填参数即出三维、图纸和报价，确认后草拟 ERPNext 销售订单（沿用现有“提议—确认”）。
6. **企业账号与权限**：企业用户不是问渠学生账号；设计、审批、配置、车间分角色授权。

## 四、不做的

- 不做网页版 CAD 建模（工程师用桌面 CAD 效率最高）。
- 云端远程 FreeCAD 只作个别情况的选项，不作为企业版主线（成本高、有延迟）。

## 五、合规

AI 功能沿用数字工厂现有通道：国内部署只用已备案模型（DeepSeek），Claude 只在美国用。
