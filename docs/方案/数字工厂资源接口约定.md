# 数字工厂资源接口约定（草案 v0.1，2026-09-30）

> 用途：问渠学习平台（AI 建课、课件、动画、虚拟实验）从**问渠数字工厂**取用零件、机器人、机构、案例、图纸和生产数据。两边按本约定开发。
> 基础：数字工厂《实施细则 第 2 轮：零件与机器人库》附录 B（条目格式 v1、`index.json`、发布到 Releases 与 Spaces）和《第 3 轮：上线》（factory.wenquestrobotics.com，问渠账号登录）。**那边已有设计的地方以那边为准，本约定只写学习平台怎么用、还需要补什么。**
> 状态：草案，待 Eddie 确认；数字工厂一侧看过后如有出入，改本文件并在末尾“变更记录”写一行。

## 一、总原则

1. **一个库，两处用**：零件与机器人库只在数字工厂一侧建；学习平台不另存一套，只按**编号 + 版本**引用。
2. **课件用时复制一份**：课件里用到的模型、图纸，在生成时从库里下载一份放进这门课（连同许可与署名）。库以后更新或下架，已发布的课件不受影响；重做这一课时再取新版本。
3. **来源必注**：课件、讲义、视频片尾的“素材来源”里列出每个用到的条目：编号、名称、版本、许可、署名（直接用条目的 `source.attribution`）。
4. **只读**：学习平台只读数据，不写回数字工厂。
5. **国内部署**：接口只用 HTTPS + JSON + 静态文件，不依赖境外服务；国内部署时把 Spaces 换成国内对象存储即可。

## 二、零件与机器人库（静态发布，学习平台直接读）

### 2.1 学习平台读取的地址

| 内容 | 地址（按第 2 轮 B.7） | 学习平台怎么用 |
|---|---|---|
| 总索引 | `<库地址>/library/<版本>/index.json` | 建课时下载一次，AI 按类别、标签、参数、教学字段挑条目 |
| 最新版本指针 | `<库地址>/library/latest.json` → `{"version": "2026.10.1", "index": "..."}` | **需补（R1）**：学习平台只记住这一个地址 |
| 单个条目详情 | `<库地址>/library/<版本>/<编号>/entry.json` | **需补（R2）**：`entry.yaml` 的 JSON 版（含参数定义、教学、来源许可、机器人关节） |
| 网页三维模型 | `<库地址>/library/<版本>/<编号>/<规格>.glb` | 三维动画渲染、三维虚拟实验 |
| 缩略图 | `<库地址>/library/<版本>/<编号>/<规格>.png` | 课件插图、资料清单预览 |
| 二维工程图 | `<库地址>/library/<版本>/<编号>/<规格>.svg` | **需补（R3）**：主视图 + 侧视图 + 主尺寸标注，课件插图直接用 |
| CAD / 机器人描述 | Releases 里的条目压缩包（STEP、URDF/MJCF） | 老师下载；学习平台一般不需要 |

`<库地址>` 由数字工厂一侧定（Spaces 公开地址或自定义域名，如 `https://library.wenquestrobotics.com`），写进学习平台服务器配置 `WQ_LIBRARY_URL`。

### 2.2 学习平台用到的字段（全部已在附录 B 里，只列用途）

| 字段 | 用途 |
|---|---|
| `id`、`name.zh/en`、`category`、`tags` | 检索；课件里中英名称 |
| `kind`、`params`、`specs`/`defaults`/`ranges` | 插图标注、动画和实验里的参数（例：四杆机构杆长的可调范围直接成为实验滑块范围） |
| `teaching.principle/uses/courses/labs` | AI 选案例、写讲义时的依据；`labs` 作为动画和实验的建议 |
| `robot.type/dof/payload_kg/reach_mm/joints` | 机器人课：运动学动画、关节拖动实验 |
| `source.license/attribution` | 素材来源页、视频片尾 |
| `factory.erp_items` | 与工厂案例对上（例：6207 轴承 ↔ 减速器 WQR-105） |

### 2.3 需要库一侧补的（请数字工厂窗口评估）

| 编号 | 需求 | 原因 |
|---|---|---|
| R1 | `latest.json` 最新版本指针 | 学习平台不写死版本号 |
| R2 | 每个条目发布 `entry.json`（`entry.yaml` 原样转 JSON，另加构建时提取的关节表） | 学习平台不解析 YAML、不下载整包 |
| R3 | 每个规格一张**二维工程图 SVG**（主视图、侧视图、主尺寸标注，中英文标题栏）；机器人给一张带关节编号和坐标系的示意图 | 课件插图最常用的就是图纸和示意图 |
| R4 | 机器人的 glTF 里，**每个连杆一个节点，节点名 = URDF 连杆名**；`entry.json` 的关节表带 `parent`、`child`、`axis`（xyz）、`origin`（xyz + rpy）| 三维动画和三维实验要按关节转动各连杆 |
| R5 | 机构（C 部分）的 glTF 同样按构件分节点，并在 `entry.json` 给出运动关系（输入构件、各构件随输入角的位置可由生成器算出时，附一张采样表 `motion.csv`：输入角 → 各构件位姿） | 机构动画、实验不必各自重写运动学 |
| R6 | Spaces 允许学习平台域名跨域读取（CORS：`GET`，来源 `https://learn.wenquestrobotics.com`） | 老师在浏览器里预览模型；学生端的实验仍用课内复制的一份 |

## 三、数字工厂案例与生产数据（工作台接口，服务器对服务器）

数字工厂上线后（factory.wenquestrobotics.com），学习平台的网关用一把**只读钥匙**调用枢纽的接口，取课件需要的案例和数据。学生和老师不直接调用这些接口。

### 3.1 认证

- 请求头 `Authorization: Bearer <WQ_FACTORY_READ_KEY>`；钥匙由数字工厂服务器生成，写进两边服务器的 `.env`，只读、可随时更换。
- 同一台服务器上时走内部网络；以后分开部署走 HTTPS。

### 3.2 需要的接口（草案，路径由数字工厂一侧定）

| 接口 | 返回 | 课件里怎么用 |
|---|---|---|
| `GET /api/course/products` | 产品列表（现在只有 WQR-105）：编号、名称、简介、主图 | 选案例 |
| `GET /api/course/products/{code}` | 产品结构树（BOM，每个节点带物料编码、数量、**库条目编号**若有）、工艺路线（工序、工位、工时）、工作中心、质检方案（特性、名义值、公差、量具）、标准成本 | 讲义里的真实数据表；插图（产品结构图、工艺流程图）；习题数据 |
| `GET /api/course/designs/{item}` | 设计版本列表；每版的 STEP、零件图 SVG、G 代码、参数、发布人和时间（FreeCAD 发布宏的产物） | 零件图插图、刀路动画、设计变更案例 |
| `GET /api/course/cases` | 教学情景列表（如“实验 7”），每个情景一段说明 | 选案例 |
| `GET /api/course/data?case=&kind=&from=&to=` | 一段时间的生产数据，`kind` 为 `measurement`（测量值，含特性、名义、公差、实测、判定）、`event`（设备状态、故障、安灯）、`agv`（位置轨迹）、`order`（订单、工单、交付）、`kpi`（指标） | 控制图、瓶颈分析、交期计算等习题和实验的真实数据；AGV 轨迹动画 |
| `GET /api/course/layout` | 车间平面：设备编号、名称、位置、尺寸、所属工序；AGV 路线 | 车间平面插图；三维车间动画 |
| `GET /embed/workshop?view=&device=&speed=&t0=` | 可嵌入的只读 3D 车间页面（无需登录，只显示、不能操作；数据可取实时或回放某段时间） | 录制“车间实况”视频片段；课件里嵌入 |

要求：
1. 数据**不含个人信息**（学生姓名、账号），操作人统一写成角色（计划员、操作工……）；
2. 每次返回带 `as_of`（数据时间）和 `source`（ERPNext / 历史库 / FreeCAD），课件里注明“数据来自问渠数字工厂，截至 …”；
3. 一次最多返回 10 000 行，超过分页（`page`、`next`）。

## 四、学习平台一侧怎么用（摘要，详见《实施细则 · 第 4 轮 课件能力升级》）

1. **课程设计书**里写明这门课用的库条目（例：贯穿全课的机器人 `B-ARM-UR5E` + `B-EDU-DIFF`）和工厂案例。
2. **资料清单**多一类来源“来自数字工厂”：用到的每个条目、每份数据都列出来（编号、版本、许可），老师可以删、可以换。
3. **插图师、动画师、实验师、讲解视频**都只从课内复制的那一份取素材；生成物的审稿清单里多一项“素材来源已注明”。
