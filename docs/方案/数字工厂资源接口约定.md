# 数字工厂资源接口约定（v0.9，2026-09-30）

> 用途：问渠学习平台（AI 建课、课件、动画、虚拟实验）从**问渠数字工厂**取用零件、机器人、机构、案例、图纸和生产数据。两边按本约定开发。
> 基础：数字工厂《实施细则 第 2 轮：零件与机器人库》附录 B（条目格式 v1、`index.json`、发布到 Releases 与 Spaces）和《第 3 轮：上线》（factory.wenquestrobotics.com，问渠账号登录）。**那边已有设计的地方以那边为准，本约定只写学习平台怎么用、还需要补什么。**
> 状态：v0.9——Eddie 已确认（2026-09-30）；R1–R6 全部接受，路径和字段已定（见各节）。以后任何一侧改动，都改本文件并在末尾“变更记录”写一行。
> 数字工厂一侧的对应细则：`factory/digital/实施细则_第2轮_零件与机器人库.md` 第九节与附录 B.10–B.13（零件库）、`factory/digital/实施细则_第4轮_课程接口.md`（工作台课程接口）。

## 一、总原则

1. **一个库，两处用**：零件与机器人库只在数字工厂一侧建；学习平台不另存一套，只按**编号 + 版本**引用。
2. **课件用时复制一份**：课件里用到的模型、图纸，在生成时从库里下载一份放进这门课（连同许可与署名）。库以后更新或下架，已发布的课件不受影响；重做这一课时再取新版本。
3. **来源必注**：课件、讲义、视频片尾的“素材来源”里列出每个用到的条目：编号、名称、版本、许可、署名（直接用条目的 `source.attribution`）。
4. **只读**：学习平台只读数据，不写回数字工厂。
5. **国内部署**：接口只用 HTTPS + JSON + 静态文件，不依赖境外服务；国内部署时把 Spaces 换成国内对象存储即可。

## 二、零件与机器人库（静态发布，学习平台直接读）

### 2.1 学习平台读取的地址

| 内容 | 地址（按第 2 轮 B.7） | 学习平台怎么用 |
|---|---|---|
| 最新版本指针 | `<库地址>/library/latest.json` | 学习平台只记住这一个地址（R1） |
| 总索引 | `<库地址>/library/<版本>/index.json` | 建课时下载一次，AI 按类别、标签、参数、教学字段挑条目；每个规格一行（`items[]`） |
| 单个条目详情 | `<库地址>/library/<版本>/<编号>/entry.json` | `entry.yaml` 的 JSON 版，另有 `sizes[]`、`package`、机器人关节表、机构运动（R2） |
| 网页三维模型 | `<库地址>/library/<版本>/<编号>/<规格>.glb` | 三维动画渲染、三维虚拟实验 |
| 缩略图 | `<库地址>/library/<版本>/<编号>/<规格>.png` | 课件插图、资料清单预览（512×512） |
| 二维图 | `<库地址>/library/<版本>/<编号>/<规格>.svg` | 课件插图（R3，三种见 2.4） |
| 机构运动表 | `<库地址>/library/<版本>/<编号>/motion.csv` | 机构动画、实验（R5，只 C 部分） |
| CAD / 机器人描述 | Releases 里的条目压缩包，地址在 `entry.json` 的 `package` | 老师下载；学习平台一般不需要 |

- **`<库地址>`**：第一期为 `https://factory.wenquestrobotics.com`（由数字工厂服务器提供 `library/` 下的文件，带跨域头）；Spaces 存储桶和钥匙配好后改为 Spaces 的 CDN 公开地址。学习平台只认服务器配置 `WQ_LIBRARY_URL`，切换时只改这一项。
- **版本** `YYYY.MM.N`（如 `2026.10.1`）；已发布的版本目录不再改动。
- **规格代号**：零件族用规格表里的代号（文件名里 `/` 换成 `_`、`×` 换成 `x`）；机器人、机构、案例只有一种，规格代号固定为 `default`（如 `B-ARM-UR5E/default.glb`）。
- **单位与坐标**：glTF 用米、Y 向上；根节点 `root` 把 CAD/URDF 的 Z 向上转过来，它下面的节点坐标与 URDF、机构坐标系一致。SVG 的 `viewBox` 以毫米为单位。

`latest.json`：

```json
{"schema": 1, "version": "2026.10.1", "released": "2026-10-12T15:00:00Z",
 "index": "library/2026.10.1/index.json",
 "release_url": "https://github.com/eddiezgq/WenQuest/releases/tag/library-v2026.10.1"}
```

`index.json` 的一行（路径相对于该版本目录；`params` 只含主参数，完整参数在 `entry.json`）：

```json
{"ref": "A-BRG-DG/6207", "id": "A-BRG-DG", "size": "6207", "part": "A", "kind": "family", "category": "BRG",
 "name": {"zh": "深沟球轴承 6207", "en": "Deep groove ball bearing 6207"},
 "tags": ["滚动轴承"], "standards": ["GB/T 276-2013", "ISO 15:2017"], "params": {"d_mm": 35, "D_mm": 72, "B_mm": 17},
 "license": "Apache-2.0", "erp_items": ["BRG-6207"],
 "files": {"glb": "A-BRG-DG/6207.glb", "png": "A-BRG-DG/6207.png", "svg": "A-BRG-DG/6207.svg"},
 "entry": "A-BRG-DG/entry.json",
 "family": {"zh": "深沟球轴承", "en": "Deep groove ball bearing"}, "origin": "wenquest", "default": true}
```

`index.json` 顶层另有 `collections`（只收索引的外部库，第一期是 FreeCAD 零件库 `freecad-library.json`，CC BY 3.0，模型从原仓库下载）和 `categories`（类别代号的中英文名）。机器人行另有 `dof`。字段细节见数字工厂第 2 轮附录 B.10。第一期没有 `svg`（二维图 R3 在第二期）。

### 2.4 二维图、关节表、机构运动表的格式

**二维图 SVG**：白底黑线，右下角中英文标题栏（名称、编号/规格、标准、比例、单位、来源与许可），文字用系统字体。

| 部分 | 内容 |
|---|---|
| A 标准件 | 主视图 + 侧视图（回转件剖开显示内部），标注主尺寸，单位 mm |
| B 机器人 | 关节示意图：零位侧视，连杆画线段，关节画圆编号 J1…Jn，标基座坐标系；不画外形 |
| C 机构 | 机构运动简图：默认参数，标准符号（转动副、移动副、机架），标构件名与主要尺寸 |

**机器人**：`robot.links[]` 每项 `{"name", "node", "mass_kg"}`；`robot.joints[]` 每项（米、弧度）：

```json
{"name": "shoulder_pan_joint", "type": "revolute", "parent": "base_link", "child": "shoulder_link",
 "axis": [0, 0, 1], "origin": {"xyz": [0, 0, 0.1625], "rpy": [0, 0, 0]},
 "limit": {"lower": -6.2832, "upper": 6.2832, "velocity": 3.1416, "effort": 150}}
```

`type` 取 `revolute`、`continuous`、`prismatic`、`fixed`。glTF 节点层级 = 运动链。

**机构**：

```json
{"dof": 1,
 "members": [{"id": "ground", "name": {"zh": "机架", "en": "Ground"}, "node": "ground", "ground": true},
             {"id": "crank", "name": {"zh": "曲柄", "en": "Crank"}, "node": "crank"}],
 "input": {"member": "crank", "type": "rotation", "unit": "deg", "range": [0, 360], "step": 1},
 "motion": "motion.csv"}
```

`motion.csv`：每个输入值一行，第一列 `input`（单位同 `input.unit`），之后每个活动构件 7 列 `<id>.x_m, <id>.y_m, <id>.z_m, <id>.qx, <id>.qy, <id>.qz, <id>.qw`（相对机构坐标系；机架不列）；机构锁死、无解的输入值不出行。

## 三、数字工厂案例与生产数据（工作台接口，服务器对服务器）

数字工厂上线后（factory.wenquestrobotics.com），学习平台的网关用一把**只读钥匙**调用枢纽的接口，取课件需要的案例和数据。学生和老师不直接调用这些接口。

### 3.1 认证

- 请求头 `Authorization: Bearer <WQ_FACTORY_READ_KEY>`；钥匙由数字工厂的安装脚本生成，存在服务器 `/opt/wenquest/factory/.env`；**学习平台的部署脚本从这个文件读取**，写进学习平台的 `.env`（同一台服务器）。只读、可随时更换。
- 走公网地址 `https://factory.wenquestrobotics.com`（经 Caddy）；以后分开部署也不用改。

### 3.2 接口（v0.2 定稿，路径与字段见数字工厂《实施细则 第 4 轮 课程接口》第四节）

| 接口 | 返回（主要字段） | 课件里怎么用 |
|---|---|---|
| `GET /api/course/products` | `items[]`：`code`、`name{zh,en}`、`summary`、`image`、`specs` | 选案例 |
| `GET /api/course/products/{code}` | `bom`（树：`item_code`、`name`、`kind`＝raw/buy/make/sub/fg、`qty`、`uom`、`library_ref`、`children`）、`routings{物料: [seq, operation{zh,en}, workstation, minutes]}`、`workstations[]`（`unit`、`name`、`rate_per_hour`、`capacity`）、`quality_plans[]`（`template`、`item_code`、`characteristics[]`：`name`、`numeric`、`unit`、`min`、`max`、`gauge`）、`std_cost{物料: material, operations, total, currency}` | 讲义里的真实数据表；产品结构图、工艺流程图；习题数据 |
| `GET /api/course/designs/{item}` | `revisions[]`：`revision`、`released_at`、`author_role`、`change_note`、`params`、`files[]`（`kind`＝step/svg/gcode、`name`、`url`、`sha256`）、`gcode`（`operation`、`machine`、`est_time_s`、`lines`） | 零件图插图、刀路动画、设计变更案例 |
| `GET /api/course/cases` | `items[]`：`id`（目前只有 `lab7`）、`name`、`summary`、`mode`、`guide_url` | 选案例 |
| `GET /api/course/data?case=lab7&kind=&from=&to=&page=` | `rows[]`，`kind` 取 `measurement`、`event`、`agv`、`order`、`kpi`（每种的字段见第 4 轮 4.3）；`from`/`to` 为 ISO 时间（UTC），缺省最近 7 天 | 控制图、瓶颈分析、交期计算等习题和实验的真实数据；AGV 轨迹动画 |
| `GET /api/course/layout` | `floor`、`units[]`（`unit`、`name`、`x_m`、`y_m`、`w_m`、`d_m`、`area`、`operations`）、`aisles`、`agv_home` | 车间平面插图；三维车间动画 |
| `GET /api/course/embed-token?ttl=1800` | `token`、`expires`（回放用，30 分钟有效） | 学习平台网关申请后放进嵌入网址 |
| `GET /embed/workshop?view=overview\|device&device=&mode=live\|replay&t0=&speed=&token=` | 可嵌入的只读 3D 车间页面，无任何操作按钮；`mode=live` 不用登录，`mode=replay` 要 `token` | 录制“车间实况”视频片段；课件里嵌入 |

要求（数字工厂一侧保证）：
1. 数据**不含个人信息**：操作人只写角色（`actor_role`、`author_role`：planner、engineer、operator、quality、manager、system、sim），不返回姓名和账号编号；总线上也不再出现姓名（数字工厂第 4 轮 C5）；
2. 每次返回带 `as_of`（数据截至时间，UTC）和 `source`（`factory-data`、`erpnext`、`historian`、`freecad`），课件里注明“数据来自问渠数字工厂，截至 …”；
3. 列表一页最多 10 000 行：`page` 从 1 开始，返回 `next`（下一页页码，没有则为 `null`）；
4. 生产模式（企业真实数据）不对课程接口开放，只提供教学情景。

### 3.3 实现说明（v0.5，2026-09-30 上线；以此为准）

- **钥匙与地址**：数字工厂每次部署时没有钥匙就生成 `WQ_FACTORY_READ_KEY`；学习平台的 `deploy/update.sh` 每次部署从 `/opt/wenquest/factory/.env` 复制过来，并设 `WQ_FACTORY_URL=https://factory.<域名>`；网关容器的环境变量同名（`WQ_FACTORY_URL`、`WQ_FACTORY_READ_KEY`）。没带钥匙、钥匙错一律 401。
- **产品详情**：`source` 目前只有 `factory-data`（工厂设计数据：物料、BOM、工艺路线、工位费率、检验模板，与 ERPNext 里导入的是同一份）。`std_cost` 对每个自制零件、部件和成品都给，逐级累加（材料 = 外购件与原材料价格 × 用量；工序 = 工时 × 工位费率），单位美元/件。`workstations[]` 的 `unit` 是工位组代号（如 `cnc-l01`），另有 `units`（这组的设备单元号，如 `cnc-l01-a`、`cnc-l01-b`，与车间平面一致）和 `rate_parts`（折旧、人工、能耗）。`quality_plans[].characteristics[]`：数值项有 `min`、`max`、`unit`、`gauge`（量具）；非数值项有 `requirement`（如“无锈蚀、转动灵活无卡滞”），`gauge` 为“目测”。`quality_plans[]` 另有 `items`（用这个模板的全部物料）。
- **设计版本**：`files[].kind` 为 `step`、`svg`（零件图）、`gcode`；`url` 是完整地址，不用登录即可下载；`gcode` 另有 `cut_length_mm`；另带 `bom`（这一版的物料清单）。
- **生产数据**：`event` 里设备状态变化也是一行（`event` = `state`，`state` 为 run/idle/setup/down/fault）；`actor_role` 另有 `ai`、`user`（本地版填名字登录的人，不知道岗位）。`order` 含销售订单、工单、采购订单、物料申请，采购订单的 `customer` 是供应商；每次单据变化一行（`action`）。`kpi` 只给工作日，一次最多 62 天；`otd` 是截至当天的当月累计准时交付率，其余按当天算（算法与看板相同）。
- **车间平面**：`aisles[]` 为 `{axis: "x", y_m, width_m}`（横向主通道）和 `{axis: "y", x_m, from_y_m, to_y_m, width_m}`（左侧纵向通道）；`agv_home` 为 `{agv-01: {x_m, y_m}}`。
- **嵌入**：`embed-token` 的 `ttl` 最长 1800 秒（超过按 1800）。`/embed/workshop` 只允许学习平台、数字工厂本站和本机开发地址用 iframe 嵌入（`frame-ancestors`）；回放每次向枢纽取 10 分钟数据，凭证过期时页面提示刷新。页面自己用的 `/api/embed/config`、`/api/embed/replay` 不属于课程接口，学习平台不用调用。
- **零件库对照**：`library_ref` 按零件库 `index.json` 的 `erp_items` 对上（第一期已有：轴承 BRG-6205/6206/6207、平键 4 种、螺栓螺母、内六角螺钉等）；每天读一次。

## 四、学习平台一侧怎么用（摘要，详见《实施细则 · 第 4 轮 课件能力升级》）
