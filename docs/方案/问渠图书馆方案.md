## 一、一句话

**问渠图书馆不自己囤书，而是把世界上合法的免费书库接到一个搜索框里。** 读者在问渠里搜一次，就能同时搜到：
- 公有领域图书
- 开放获取学术专著
- 免费大学教材
- 开放论文
- 国内公益学术平台

AI 馆员回答问题时，每句话都标出处和链接（*Every answer has a source*）。在这之上，DSpace 存学校自己的作品和论文；学校有纸本馆藏时，再接开源图书馆系统 Koha 管借还。

**不接盗版书库**：Z-Library、LibGen、Anna's Archive、网盘资源一律不接、不链接。

## 二、连接的免费书库

接入分三档：

| 档 | 做法 | 适用 |
| --- | --- | --- |
| **甲：全文入库** | 书目和全文都存进问渠，AI 馆员可以读全文回答 | 公有领域、CC BY / CC BY-SA 等允许再分发的 |
| **乙：书目收割** | 定期收割书目进统一检索，全文点链接去原站看 | 许可不允许再分发，或全文太大 |
| **丙：跳转** | 只在检索结果里给入口，读者到原站注册后免费看 | 要个人注册的国内公益平台 |

非商业许可（CC BY-NC）的资源，问渠一旦收费，就只做乙或丙，不做甲。

| 书库 | 内容 | 许可 | 接口 | 档 |
| --- | --- | --- | --- | --- |
| **Project Gutenberg** | 公有领域电子书，以英文经典为主 | 美国公有领域；美国以外不担保；名称是注册商标 | 网站禁止自动访问，批量用 rsync 私有镜像；书目用官方目录文件 | 个人版甲；在线版乙（国内只对作者去世满 50 年的书做甲，收费时去掉商标页头） |
| **Open Library / Internet Archive** | 书目大全、封面；公有领域图书全文 | 书目开放；全文看各书 | 接口不能批量用；批量用每月数据包 | 乙 |
| **HathiTrust** | 大学图书馆数字化的书，公有领域部分可全文看 | 美国以外 1901–1930 年出版的书只对美国 IP 开放；谷歌扫描的书非会员逐页下载 | 书目接口 | 乙；国内站按地区过滤 |
| **OAPEN Library** | 同行评审的开放获取学术专著 | 多为 CC | OAI-PMH、REST | 甲 / 乙（看单本许可） |
| **DOAB 开放获取图书目录** | 开放获取学术图书总目录 | 多为 CC | OAI-PMH、MARCXML | 乙 |
| **OpenStax** | 大学教材：物理、微积分、化学、统计等 | 实测 129 本：CC BY 38、CC BY-NC-SA 80、未标 11 | CMS 接口 | 个人版甲；在线版只有 CC BY 的做甲，其余乙 |
| **LibreTexts** | 大学教材，含工程、物理、化学 | 多为 CC | 网页 | 乙 / 甲（看单本） |
| **Open Textbook Library** | 开放教材目录 | 多为 CC | 网页目录 | 乙 |
| **arXiv** | 预印本论文（物理、数学、计算机、电子） | 元数据 CC0；全文各篇许可不同 | OAI-PMH（批量首选） | 乙；产品上注明致谢 arXiv |
| **DOAJ** | 开放获取期刊论文 | 期刊元数据 CC BY-SA 4.0，文章元数据 CC0 | OAI-PMH（免费版滞后约 30 天） | 乙 |
| **OpenAlex** | 全球学术文献元数据 | CC0 | 公开接口 | 乙（做检索底座和引文） |
| **PubMed Central** | 生物医学开放论文 | 各异 | OAI-PMH | 乙（按需） |
| **维基文库（Wikisource）** | 公有领域原典，中英文都有，含中文古籍 | CC BY-SA / 公有领域 | MediaWiki 接口 | 甲 |
| **国家哲学社会科学文献中心** | 中文学术期刊、外文期刊、古籍 | 公益免费，个人注册后可下载全文 | 无公开接口 | 丙；学校可签机构用户协议，机构内免登录 |
| **国家图书馆·中华古籍资源库** | 古籍影像 | 公益免费在线阅读 | 无公开接口 | 丙 |
| **中国科技论文在线** | 中文科技论文 | 免费 | 施工前实测 | 丙 / 乙 |
| **中国哲学书电子化计划（ctext）** | 先秦至近代中文原典 | 接口非商业免费，商业须授权 | api.ctext.org | 个人版乙；在线版收费前谈授权，之前丙 |

每个书库在接入前都要核两件事：许可条款（能否收割、能否存全文）和接口是否可用。**B0 已于 11-24 完成**，结果在 `library/sources.yaml`。古登堡、OAPEN、DOAB 拒绝云端 IP，到 Eddie 电脑上实测。没核过的不接。

## 三、选型

| 层 | 选用 | 许可 | 用途 |
| --- | --- | --- | --- |
| 统一检索与 AI 馆员 | **问渠自研**：OpenSearch + PostgreSQL / pgvector | Apache-2.0 / PostgreSQL 许可 | 一个搜索框搜所有书库；按意思搜；AI 馆员带出处回答 |
| 收割器 | 问渠自研，用 pyoai（OAI-PMH）、各家公开接口 | — | 定时收割书目，去重、合并同一本书的不同版本 |
| 阅读器 | 问渠数字教材阅读器 + pdf.js、Readium（EPUB） | Apache-2.0 / BSD | 甲档全文在问渠里直接读 |
| 作品库与机构库 | **DSpace 9** | BSD-3 | 学生作品、答辩录像、毕业设计、学校教材和论文；对外也能被别的图书馆收割（OAI-PMH） |
| 纸本业务（可选） | **Koha 25.11** | GPL-3 | 学校有纸本馆藏时才上：采访、编目、借还；以后规模大可换 FOLIO |
| 参考文献 | 对接 Zotero | AGPL-3 | 检索结果一键导入 |

## 四、AI 原生做什么

原则：AI 只提议，规则代码判定，人确认。

| 功能 | AI 做什么 | 把关 |
| --- | --- | --- |
| **AI 馆员** | 读者自然语言提问，AI 在所有书库里查，给答案、书单、章节；每句话附出处、许可和链接 | 只答查到的；查不到就说查不到，不编书名；甲档才引用全文段落 |
| **课程书架** | 读问渠每门课的大纲，自动从免费书库配齐参考书：首选 CC 教材，其次开放专著，再次论文 | 老师审定 |
| **实验室书架** | 虚拟实验室 86 个实验室各配一个书架。例如大学物理配 OpenStax，芯片配开放教材和 arXiv | 老师审定 |
| **中英对照导读** | 英文开放教材的章节由 AI 出中文导读和术语表（中英对照） | 标“AI 导读”，原文为准 |
| **去重与版本合并** | 同一本书在多个书库出现，合并成一条，列出各个来源和许可 | 代码按 ISBN / DOI / 书名作者规则判，AI 只处理规则判不了的 |
| **作品入库** | 虚拟实验室的作品和答辩录像自动入 DSpace，出永久链接 | 公开范围由学生和老师定 |

## 六、部署与合规

| 项 | 做法 |
| --- | --- |
| 服务器 | 见 6.1 |
| 国内 | 部署在国内服务器；国外书库收割在美国服务器做，再同步书目到国内。国内访问不了的原站，检索结果标注“境外原站” |
| AI | 国内 DeepSeek，美国 Claude |
| 版权 | 甲档只收公有领域和允许再分发的开放许可；每条记录带许可证和来源；收到权利人通知即下架 |
| 盗版 | 不接、不链接 Z-Library、LibGen、Anna's Archive 和网盘资源 |

### 6.0 两个版本（09:18 Eddie 定）

| | 个人版（现在） | 在线版（在线大学需要时） |
| --- | --- | --- |
| 装在哪 | Eddie 的 Windows 电脑 | 云服务器（见 6.1） |
| 用户 | Eddie 一人 | 全校师生，问渠统一登录 |
| 检索与向量 | 一个 SQLite 数据库文件：FTS5 全文检索（中文用 trigram 分词）+ sqlite-vec 向量检索 | OpenSearch + PostgreSQL / pgvector |
| 程序 | 一个 Python 程序：收割、检索、AI 馆员，本机浏览器打开 | 问渠图书馆前台 + 后台服务 |
| AI | 美国，用 Claude（密钥放环境变量） | 国内 DeepSeek、美国 Claude |
| 作品库 | 不装 DSpace；作品库等在线版 | DSpace 9 |
| 纸本 | 不装 Koha | 按需 |
| 收割 | 本机直接收（人在美国，各书库都能访问） | 美国服务器收割，同步国内 |

**个人版要多大的电脑：**
- 内存：运行时约占 3–4 GB。Eddie 的电脑 32 GB（09:20 告知），宽裕；arXiv 书目全收，不删减。
- 硬盘：约 60–100 GB。原始书目约 10 GB，检索索引约 10 GB，向量约 5 GB，全文精选 20–30 GB，余量留给备份。Eddie 的电脑只有 C 盘，空间够。
- 首次建向量：约 330 万条书目，笔记本 CPU 上跑一到两个晚上；之后每天只算新增的，几分钟。不用 GPU。
- 位置：建议放 `C:\Users\<用户名>\wenquest-library`，代码放公开仓库，数据不进仓库。

**上线时怎么搬**：收割回来的原始书目和统一的书目记录格式（`library/sources.yaml` 和记录格式定义），两个版本一样；上线时只换存储层，把记录导入 OpenSearch 和 PostgreSQL，不用重新收割。个人版积累的书架、AI 馆员问答记录一起搬。

### 6.1 服务器与容量（在线版）（2026-11-24 估算）

| 阶段 | 配置 | 说明 |
| --- | --- | --- |
| B0–B3：收割、统一检索、AI 馆员 | **8 核 / 16 GB 内存 / 200 GB SSD**，新开一台（国内） | 现有国内服务器（8 核 16 GB）已承载学习平台和数字工厂，不再加 |
| B4：DSpace 作品库 | **4 核 / 8 GB / 100 GB SSD**，再开一台 | DSpace 后端、Solr、前端合计 6–8 GB |
| 大文件 | 对象存储，按量付费 | 答辩录像、作品附件、全文 PDF |
| 收割 | 放美国服务器做，索引同步到国内 | 国外书库从国内收割慢或打不开 |

**内存 16 GB**：OpenSearch 6 GB；PostgreSQL + pgvector 5 GB（约 330 万条书目 × 384 维半精度向量 ≈ 2.5 GB，加索引和缓存）；收割、接口、AI 馆员、向量计算 3 GB；系统 2 GB。

**硬盘 200 GB**：系统与软件 30 GB；原始书目约 10 GB；检索索引约 15 GB；向量约 5 GB；全文精选 20–30 GB；其余给备份和增长。

**不全量收的**：
- 古登堡全格式镜像（约 200 万个文件，TB 级）：书目全收，全文只精选几千本。
- OpenAlex 全库（几亿条）：实时调接口，只缓存用到的。
- arXiv 全文 PDF：只收书目和摘要（约 300 万篇）。

**一次性计算**：330 万条书目首次生成向量，用 CPU 约 5–10 小时，之后每天只算增量，不用 GPU。向量模型选开源、可在国内部署的多语种小模型（384 维）。

**作品库增长**：按 100 名学生、每人每年 4 个作品、每段答辩录像约 400 MB（720p）算，一年约 160 GB，放对象存储。
