# 网页互动课件标准（所有课程）

> 2026-10-06 定。Eddie 看过《缝纫机设计与制造》第 1 讲样品后定为所有课程的标准：“这个就非常好……取代 ppt”“并把这个写成所有课程的标准”。来历见《实施细则 · 第 24 轮》。

**一句话：课件一律做成网页互动课件，取代 PPT。** 页面像 PPT 一样一页一页翻，但动画、虚拟实验、三维样机就在页里运行，当场可以操作。

## 一、形式

- 每讲（或每节）一个网页文件，单文件、自带全部内容（实验页内联；三维页的 three.js 从 cdnjs 取），能直接挂进课程、放进网页版教材，下载后双击也能放映。
- 16:9 页面，按窗口自动缩放，投影、录屏、手机上都不糊。
- **不再出 PPT**。已有课程的 PPT 在改造后由网页课件替换。

## 二、版面质量（逐页验收）

1. **一页一个意思**，每页最多 3 条；放不下就分页，不缩字号。
2. **字号**（以 1920×1080 计）：标题中文 64 像素、英文 30；正文中文 ≥ 44、英文 ≥ 24；图里最小的字 ≥ 22。
3. **中英对照**：中文大字在上，英文一行在下（产品原则不变）。
4. **图要大、要清楚**：按页面尺寸重画或重出，不把印刷用的横长组合图缩小塞进角落。
5. **风格统一**：深色舞台底、黄色强调色（问渠针脚虚线）、青色辅助；卡片、大数字、时间轴、流程、对比等固定版式。
6. **动画完整、不断循环**（2026-10-06 Eddie：“所有动画要完整的不断循环”）：页里的动画放完一遍要自动从头再来，包括会停下来的演示；整页嵌入、由学生操作的实验不自动循环。
7. **有节奏**：要点、卡片、事件逐个出现（相当于 PPT 的进入动画）；每讲至少 3 处“活”的页面（动画、实验或三维模型）。
8. **数字与教材一致**：算例数字由教材或课程包程序算出，不手写。

## 三、结构（理工科每讲）

封面（最好是活的三维模型或动画）→ 实际问题（以机器人为主）→ 分节：概念、动画、虚拟实验、建模求解 → 机器人联系与一个生活例子 → 回到实际问题的解答 → 小结与课后（作业、测验、实验报告在平台完成）。

## 四、放映与录课

- 翻页：→ / 空格 / PageDown 下一步，← 上一步，F 全屏，触屏左右滑。
- **S 讲者窗口**：中英讲稿（字号可调）、下一页、计时，与课件同步翻页；录课时观众窗口只有课件。
- 讲稿就是每页的讲者备注，以后做数字人也用它。
- 实验页可一键全屏做实验，Esc 返回。

## 五、制作方法

- 内容写在一个文本文件里（每页一个版式 + 中英文字 + 讲稿），程序生成网页；改哪儿只改文本，重新生成。
- 课件引擎（第 29 轮起各书共用）：`textbook/tools/webcourse/wc_slides.py`；每本网页版教材在 `textbook/web-editions/<书>/course/` 下放内容 `slides/chNN.yaml`、计算程序 `calc/chNN.py` 和按书配置 `course.yaml`（课名、讲数、分批、考试、视频目录），入口是本书的 `course/tools/build_slides.py`。参考实现仍是《缝纫机设计与制造》。**AI 建课从 2026-10-15 起直接生成**（第 32 轮附二）：网关里放同一引擎的副本（`services/gateway/app/production/wc_slides.py`，测试保证与这里一致），由课件设计师按本标准排页。
- 自检：逐页截图检查溢出与字号；无头浏览器试翻页、逐条出现、讲者窗口、嵌入实验；页面无报错。
