## 一、要解决什么

机器人厂造出了整机，但整机里的“电”——关节伺服驱动板、编码器、控制器、传感器、芯片——全是外购的黑箱（清单里写“型号待确认”）。
学生和企业用户能在数字工厂里算齿轮、跑有限元、标定机器人，却没法**分析一块电路、用仪器测一个传感器、仿真一颗芯片**，也看不到电路板是怎么造出来的。

目标：用开源工具和浏览器，把“电”这一块做成和机械一样能算、能测、能造：

1. **电路分析仿真**：画原理图 → 直流、交流、瞬态、容差分析 → 和手算对照；
2. **传感器虚拟仪器**：示波器、万用表、信号源、电源、频谱仪、逻辑分析仪，测的是有物理模型的传感器和电路；
3. **芯片设计仿真**：从 Verilog 到门级、晶体管级、版图（接已有的微电子实验）；
4. **电路板厂**：数字工业园的第四座厂，造机器人厂要的驱动板、编码器板、控制板，PCB 设计 → SMT 贴片 → 检测 → 测试全流程。

四件事用**同一块板子串起来**：关节伺服驱动板 DRV-JOINT 的原理图在电路仿真里算，出厂功能测试用虚拟仪器测，板上的编码器接口芯片在芯片仿真里设计，板子在电路板厂里造，造好卖给机器人厂装进关节模组。

## 四、电路分析仿真

**做成什么**：网页“电路台”——画（或打开）原理图，点分析，出曲线和读数；每道题能和手算公式对照。

| 项 | 方案 |
|---|---|
| 仿真引擎 | ngspice：浏览器里用已核对的 WebAssembly 版（`eecircuit-engine`，第 17 轮 RM5），大电路或批量（蒙特卡洛上千次）走服务器 ngspice |
| 分析种类 | 直流工作点、直流扫描、交流（波特图）、瞬态、参数扫描、蒙特卡洛容差、温度扫描、傅里叶（谐波） |
| 原理图 | 浏览器里简单的拖拽画图（电阻、电容、电感、电源、二极管、MOSFET、运放、受控源、开关）；复杂电路从 KiCad 原理图导出 SPICE 网表直接仿真（`kicad-cli sch export netlist --format spice`，容器档），**同一张图既仿真又出板** |
| 符号分析 | 教节点电压法、网孔电流法、传递函数时用 Python 的 Lcapy / SymPy（浏览器里用 Pyodide 跑），给出符号表达式，再代数值和 ngspice 对照 |
| 器件模型 | 只用开源或自写的通用模型（运放宏模型、MOSFET 一级 / BSIM、二极管）；厂商 SPICE 模型有版权限制，不收进库，用户可自己上传 |
| 和零件库连 | 零件库加“电子元件”大类（电阻、电容、电感、二极管、MOSFET、运放、栅极驱动、MCU 等），每个规格带 SPICE 模型、封装、三维模型（KiCad 开源封装库），电路台、电路板厂、清单都从这里取 |
| 机器人例题（第一批） | ① 关节驱动板的电流采样放大（采样电阻 + 差分放大，增益与带宽）；② 三相逆变桥一相的栅极驱动与死区（瞬态）；③ 母线电容与 LC 滤波（交流、纹波）；④ 编码器差分信号的线接收与 RC 滤波（噪声容限）；⑤ 24 V → 5 V 降压电源（效率、纹波）；⑥ 电机绕组 RL 电流环（阶跃响应）。每题的数从机器人厂的电机、关节模组数据算 |
| 检查 | 每道例题浏览器结果与服务器 ngspice 结果、手算公式三方对照，差超过 1% 构建失败（照第 17 轮 RM2） |

## 五、传感器虚拟仪器

**做成什么**：网页“仪器台”——一排虚拟仪器，探头接到“被测对象”上。被测对象是**有物理模型的传感器**或电路台里的电路节点，数据一样能来自数字工厂里正在运行的测试台。

| 项 | 方案 |
|---|---|
| 仪器 | 数字示波器（双 / 四通道、触发、光标、测量、FFT）、数字万用表（电压、电流、电阻、频率，带量程与精度等级）、函数信号发生器、可编程电源（限流）、频谱分析仪、逻辑分析仪（解码 SPI、I²C、UART、编码器 A/B/Z、SSI / BiSS）、数据采集与记录仪 |
| 仪器的“不完美” | 按真仪器建模：带宽、采样率、量化位数、输入阻抗、探头衰减、噪声、精度等级——测量误差和不确定度能按《机器人学》第 39 章算 |
| 传感器模型（第一批） | ① 应变片电桥力矩传感器（电桥 + 仪表放大器，温漂、蠕变）；② 增量 / 绝对值编码器（A/B/Z 相、细分误差、线数、抖动）；③ MEMS IMU（零偏、刻度因子、随机游走，能做 Allan 方差）；④ 霍尔电流传感器（零漂、带宽、非线性）；⑤ NTC 热敏电阻（非线性、自热）；⑥ 激光测距 / ToF（量程、噪声随距离）。参数全标示例值；机器人厂已有的传感器（ENC-ABS、关节测试台）用同一份模型 |
| 典型实验 | 用标准砝码标定力矩传感器（最小二乘、线性度、迟滞）；示波器看编码器信号、逻辑分析仪解码位置；IMU 静置 2 小时数据做 Allan 方差；万用表 + 信号源测放大电路的增益与带宽，对照电路台 |
| 接数字工厂 | 电路板厂的“功能测试（FCT）”和机器人厂的“关节测试台”就是这套仪器的自动化版：测试程序调用同样的仪器模型，测量值进 MES 和质量（第六节） |
| 真硬件（以后可选） | 仪器台留接口：浏览器 WebSerial / WebUSB 接学生手上的开源示波器、USB 数据采集卡、开发板，真数据和模型同屏对比；本方案第一期不做 |

## 六、芯片设计仿真

**做成什么**：在已有微电子实验上，加**一颗为驱动板设计的小芯片**当贯通案例，从 Verilog 一直做到版图。

| 层次 | 工具（已有） | 本方案加的内容 |
|---|---|---|
| 行为 / RTL | 浏览器：Yosys（WebAssembly）+ 门级仿真；容器：Icarus Verilog、Verilator、cocotb | 编码器接口芯片 WQ-ENCIF：正交解码 + 32 位计数 + 数字滤波 + SPI 输出；可选 PWM 发生器（带死区，配合四节例题②） |
| 门级 / 时序 | Yosys 综合、OpenSTA | 综合到 SKY130 标准单元，看面积、最高频率 |
| 晶体管级 | ngspice + SKY130（第 17 轮已校准） | 芯片输入施密特触发器、输出驱动的晶体管级仿真 |
| 版图 | OpenLane（RTL → GDS）、KLayout、Magic、Netgen | 跑通 WQ-ENCIF 的 GDS，DRC / LVS 干净 |
| 和板子连 | — | 芯片的行为模型放进电路台和虚拟仪器（逻辑分析仪看 SPI 输出）；DRV-JOINT 原理图里用它的符号和封装；芯片厂（以后）造它 |

## 七、电路板厂（数字工业园第四座厂）

**产品（第一期）**：关节伺服驱动板 DRV-JOINT（三种关节模组共用一种，按电流分档可选）、编码器读头板（ENC-ABS 里的电路板）、AGV 控制板 CTRL-AGV。机器人厂改为向电路板厂采购这几样（像第 51 轮 AGV 向减速器厂买 WQR-105 一样，两厂互发订单）。
