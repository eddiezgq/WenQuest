教学用的数字工厂、电路板厂、驱动板设计、芯片设计归电子会话（《电路板厂与电子仿真方案》，第 79–100 轮），本方案只调用那边已上线的能力，不重做、不改那边的代码。

## 一、要解决什么

贴片加工厂接客户的板子来料加工，最费人、最容易出事的是**新产品导入**：
- **资料包要人工核对**。客户发来的通常是三样：光绘文件（Gerber、钻孔文件）、物料清单（BOM）、元件坐标文件。工程师要逐项对：
  - 物料清单和坐标对不对得上；
  - 封装和焊盘对不对得上；
  - 极性怎么标；
  - 板子工厂做不做得出来；
  - 有没有湿敏件要烘烤。
  漏一项，轻则停线问客户，重则整批返工。
- **问题要反复问客户**。查出来的问题要写成工程问题单（EQ）发给客户确认，来回好几轮，往往拖掉几天。
- **报价靠经验**。点数、面数、工时、钢网、治具都要人算。
- **生产数据散在各台机器里**。锡膏检测、光学检测、在线测试、功能测试、回流炉温各有各的导出格式，出了问题很难追到“哪个料盘、哪一炉、哪个吸嘴”。

目标：浏览器里上传客户资料包，**几分钟出一份可制造性报告和问题单草稿**；量产后各机台数据汇到一处，做成控制图和逐板追溯。
AI 只起草（报告文字、问题单、给客户的说明），所有“能不能做、合格不合格”的判定由确定性程序做，缺数据就判“未知”。

## 三、产品：问渠贴片（暂名，第九节 Q1）

浏览器里用，不装软件；放在主域名下的 `/pcba/`，和轴承、凸轮一样一个容器。分三块，按第八节顺序做。

### A. 新产品导入（第一块，最容易单独卖）

1. **上传资料包**：
   - 光绘文件，Gerber RS-274X / X2 / X3，含钻孔文件；
   - 物料清单，CSV 或 Excel，各种列名用“列映射”一次配好；
   - 坐标文件。
   上传后在网页里看板子的正反面图。
2. **对资料**：
   - 物料清单的位号和坐标的位号一一对上，多的、少的、重复的列出来；
   - 坐标落在焊盘上，旋转方向和封装对得上；
   - 极性标记、第 1 脚有没有标。光绘文件里通常没有“哪个焊盘是第 1 脚”的信息，所以有极性的元件先列出请人确认（判“未知”）；光绘带 X2 元件属性时才自动核对（第 102 轮细则第二节第 6 条，11-06 改）；
   - 正反面贴片数各多少。
3. **可制造性和可装配性检查**：
   - 规则沿用第 88 轮那八项；
   - 再加贴片厂关心的：细间距器件、0201 及以下小件、底部焊端器件（QFN、BGA）的钢网与检测提示、元件离拼板工艺边的距离、需要选择焊或手工焊的通孔件。
   **每家工厂的工艺能力（最小线距、最小元件、设备能贴多大的板）是企业自己填的配置数据，不写进代码**。演示企业的数值标“示例值”。
4. **物料检查**：
   - 料号整理、封装与位号核对、湿敏等级（企业物料库里有才判，没有就标“未知”）、可替代料（企业自己维护的替代关系）。
   - 停产、缺货、价格要接元件分销商的数据接口，需要授权和密钥，第一期不做，显示“未查”。
5. **出结果**：
   - 一份报告：红黄绿每项、位置标在板图上、每条附“为什么”；
   - 一份工程问题单草稿：AI 按查出的问题起草给客户的问题和建议选项，工程师改完、确认后才能导出或发送；
   - 一份报价依据：点数、面数、通孔件数、细间距器件数。单价是企业自己的配置，软件只算量。

### B. 生产与质量（第二块）

1. **工程资料下发**：
   - 中性格式的贴片坐标与料站表；
   - 钢网开口建议，按企业自己的规则表；
   - 炉温曲线目标，取锡膏规格书的工艺窗口，由企业录入。
   各品牌贴片机的程序格式是厂家私有的，第一期不直接生成机器程序，只出中性文件和对照说明。
2. **机台数据汇总**：锡膏检测、光学检测、在线测试、功能测试、回流炉温的导出文件按“格式映射”导入（一种机器配一次），按工单、板序列号归到一起。
3. **追溯**：板序列号 → 工单 → 料盘批次 → 炉次与炉温曲线 → 检测与测试结果，正查、反查都能查。湿敏件开封计时，超时提醒。
4. **控制图与 AI 巡检**：QE1–QE5 接到企业数据上；不合格品、纠正措施进第 97 轮的质量 ERP。

### C. 客户门户（第三块）

客户在门户里上传资料包、看检查报告、逐条回复问题单、看订单进度和出货质量报告。每次确认留记录。

### 以后（第二批客户：做电子产品的企业）

- **KiCad 插件**：设计师在 KiCad 里一键跑同一套检查，相当于轴承、凸轮的 FreeCAD 工作台。KiCad 9 起插件走进程间接口（IPC API），作为独立进程运行，许可要求待核对（第十节）。
- **功能测试台接真仪器**：等电子会话做真硬件接口之后再接。

## 四、判定与 AI 的分工（照项目总规矩）

- 判定（对得上没有、做不做得出来、合格没有）全是确定性代码，不经过 AI；判定代码不调用网络和 AI。
- 缺数据（物料库没有湿敏等级、企业没填某项工艺能力）就判“未知”，不判“通过”。
- AI 只起草：报告文字、问题单、给客户的邮件，以及把客户的回复整理成修改清单。发给客户、写进 ERP 之前，都要人在界面上确认；每次 AI 运行留记录。
- 标准只写名称，例如 IPC-2221 线宽、IPC-7351 焊盘、J-STD-020 湿敏分级，不编条款号和数值。数值都是企业配置或示例值。
- 国内部署只用已备案模型（DeepSeek），Claude 只在美国用。客户的设计资料是企业机密，只存在该企业自己的空间里，不入仓库、不拿来训练。

## 四之一、支持企业的质量体系认证

> Eddie 08:45 问“这类企业有 ISO 质量标准吗”，08:47 同意加这一节。

贴片厂常见的认证和标准（只写名称，不编条款号和数值）：
- **体系认证**：ISO 9001（国内 GB/T 19001），几乎都有；汽车电子 IATF 16949；医疗 ISO 13485；航空航天 AS9100。ISO 14001、ISO 45001 常见，但不属于质量标准。
- **电子工艺标准**：IPC-A-610（焊好的板子怎样算合格，分 1、2、3 级）、J-STD-001（焊接）、J-STD-020 / J-STD-033（湿敏元件分级与管理）、IPC-7711/7721（返修）、ANSI/ESD S20.20 或 IEC 61340-5-1（防静电）；环保合规 RoHS、REACH。

软件要帮企业留住审核最常抽查的五类记录：

| 记录 | 做在哪一期 | 说明 |
|---|---|---|
| 验收等级跟订单走 | S1 | 新产品导入时订单就带上“按 IPC-A-610 第几级验收”（企业自填，不填就显示“未定”）；检查报告和后面的检验都按这一级 |
| 逐板追溯 | S3 | 板序列号 → 工单 → 料盘批次 → 炉次与炉温曲线 → 检测与测试结果 |
| 湿敏件管理 | S3 | 开封时间、暴露时长、烘烤记录、超时提醒；分级和允许时长由企业按自己的标准录入 |
| 不合格品与纠正措施 | S3 | 接第 97 轮质量 ERP |
| 防静电检查 | S3 | 腕带、工位、离子风机的点检记录 |

标准都是付费文件：软件只写标准名称，具体验收条件和数值由企业按自己买的标准录入；不预填“标准值”。记录签字后不可改，要改只能作废并写原因（照质量记录只增不改的做法）。
