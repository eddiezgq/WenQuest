## 二、做法（照第 49 轮缝纫机帮助，同一套写法，不重新发明）

1. **两款软件各两份帮助，一套源文件生成**：
   - 网页版：`learn.wenquestrobotics.com/static/help/bearing/`、`…/static/help/cam/`；软件右上角加“？帮助”，按当前页签（设计校核、合套选配、工艺……）跳到对应一节。
   - FreeCAD 版：随各自工作台下载包发（离线能看，视频只带 FreeCAD 录屏），工作台加“帮助”按钮；在线也放一份。
   - 源文件：`docs/帮助/轴承软件帮助/`、`docs/帮助/凸轮软件帮助/`（`sections/common`、`web`、`freecad` + `build.py`）。生成程序与版式**从缝纫机帮助抽出共用部分**（目录高亮、搜索、深浅色、打印、`::anim`、`::calc`、`::video`、`::try`、`::only` 指令），放 `docs/帮助/_帮助生成/`，三款软件共用；缝纫机帮助改用共用部分后重新生成，**内容逐字不变**（验收时比对）。
2. **页面形式**：同缝纫机：左栏目录随滚动高亮、可折叠、手机上收成按钮；深浅色；能打印。
3. **章节（轴承）**：
   - 共用：这是什么、系统设计（参数 → 计算核心 → 校核 → 零件图 / 三维 → 工艺 → 合套 → 检测，AI 只起草）、开源内核与参考专著（软件名、做什么、许可证）、**每类轴承怎么算**（几何、载荷分布、接触、成对与预紧、温度、交叉滚子、柔性、薄壁）、制造（合套、尺寸链、SPC、工艺、零件图）、产品库与云端、AI、标准与“未知”、典型案例、常见问题。
   - 网页版：第一次打开、各页签、导出、账号与企业授权。FreeCAD 版：安装、使用、控制台命令。
4. **章节（凸轮）**：同样结构；“怎么算”写运动规律、压力角与曲率、接触应力、加工误差与补偿、凸轮系统、圆柱凸轮。
5. **互动**：
   - **小计算器**（嵌在帮助里，来宾也能用）：轴承——游隙 → 接触角与轴向游隙（闭式解，页内算）、载荷分布（调 `/bearing/api/analyse`）、圆锥成对热态游隙（页内算）、四点接触桃形沟几何（页内画）、尺寸链蒙特卡洛（调 `/bearing/api/tolerance`）；凸轮——运动规律曲线、压力角随基圆半径（调凸轮接口）。页内算的式子与计算核心相同，验收时逐项对照。
   - **试一试**：带参数打开软件（轴承：`?example=` 与指定页签；凸轮同理）。软件现在只认 `?example=`，本轮补“打开到指定页签”。
   - **动画**（页内 SVG，数据来自计算核心真算）：钢球载荷随载荷方向转、预紧量曲线、圆锥成对冷态到热态、合套选配逐件配对、凸轮从动件运动与压力角、测量 → 误差 → 补偿。
6. **视频**：每款网页版约 6 段、FreeCAD 版约 3 段，每段 30–90 秒，Playwright / 虚拟显示器实录（第 49 轮工具），720p；**中文字幕 + AI 配音**（Eddie 11-05 定，见第六节）。
7. **典型案例**（数全部由计算核心算出，写成 `{{键}}`，改了核心重跑即更新）：轴承三个——深沟球从头设计到工艺；减速器圆锥成对冷态调游隙、热态校核；机器人腕关节四点接触薄壁轴承选预紧。凸轮两个——缝纫机挑线凸轮从设计到加工补偿；换刀机构凸轮系统。都用虚构示例，标明。
8. **诚实规则**：没做的不写成做了（额定载荷与寿命“等标准”、薄壁套圈按刚性、四点接触工艺未做等照实写）；只写软件名，不写企业客户名（精力等试点企业不出现）。
