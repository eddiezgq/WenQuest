## 一、这一轮做出什么

把方案里“同一块板串起来”的那条线接上：

```
KiCad 原理图 ──（取值一致）── 电路分析的采样、栅极、母线例题
     │
     ├─ PCB ── 可制造性检查（DFM）── Gerber、钻孔、三维
     │
     ├─ BOM ──（数量一致）── 电路板厂清单 SMT-DRV 的物料清单 ── ERPNext
     │
     └─ 测试点 ── 电路板厂“功能测试台”：测试程序用虚拟仪器测每块板 ── 质量、单件档案
```

学生在数字工厂打开“电路板设计”页，就能看驱动板的原理图、PCB 各层、三维、BOM、可制造性检查；
到电路板厂的“功能测试台”，能看到每块板的测试过程（示波器、万用表画面），也能自己拿虚拟仪器复测一块板。

## 二、决定（建议）

| 编号 | 决定 | 理由 |
|---|---|---|
| K-1 | **驱动板设计放进仓库**：`factory/designs/drv-joint/`（KiCad 工程，文本格式）。原理图分 7 页：48 V 输入与母线电容、辅助电源（12 / 5 / 3.3 V）、三相桥（6 个 MOSFET）、栅极驱动、三路相电流采样（采样电阻 + 放大器）、MCU 与烧录口、编码器接口与 CAN、连接器。板子 4 层，约 60 × 60 mm（示例） | 方案第七节“自己的开源设计” |
| K-2 | **元器件**：符号、封装、三维取 KiCad 官方库。要确切引脚的（MCU、栅极驱动、CAN 收发器、隔离器）用官方库里有的真实器件做**示例选型**，在原理图、BOM 和帮助里都标“示例选型，未经硬件验证”；电阻电容、MOSFET 只定封装和数值。电路板厂清单里这几样从“型号待确认”改成“示例选型 XXX”（单价仍是示例值） | 原理图要确切引脚，编不出来；库里的引脚是 KiCad 官方数据，不是我们编的（见 Q1） |
| K-3 | **怎么生成**：原理图和 PCB 由脚本生成（`tools/build.py`：写 KiCad 文件 → 按功能区摆放器件 → 用 **Freerouting** 自动布线 → 铺铜 → 设计规则检查），可以重复生成；人也能用 KiCad 打开继续改 | 我能写、能复核、能重来；手工画一块四层板没法验收 |
| K-4 | **产物**（脚本一次生成）：原理图（每页 SVG + 整份 PDF）、PCB 各层 SVG、Gerber + 钻孔（zip）、BOM（CSV）、贴片坐标、三维（网页用 GLB、FreeCAD 用 STEP）、两页的 SPICE 网表（采样、辅助电源）、设计规则检查报告（JSON）。KiCad 不装进数字工厂镜像：CI 里用 KiCad 官方容器生成，产物随仓库发布，网页只看产物 | 服务器不多背一个 2 GB 的工具；方案 Q8 的“容器档”先落在 CI（见 Q3） |
| K-5 | **可制造性检查（DFM）**，按一份“示例板厂工艺能力”（示例值：线宽 / 线距 0.127 mm、最小孔 0.3 mm、孔环 0.15 mm、阻焊桥 0.1 mm、元件到板边 0.5 mm、元件间距 0.25 mm）：① KiCad 设计规则检查；② 自己补的四项：元件到板边距离、极性元件方向是否统一（贴片和 AOI 好做）、**ICT 测试点覆盖率**（每个网络有没有测试点）、大电流走线宽度够不够（按 IPC-2221 由电流算线宽）。每项给结果、位置（在 PCB 图上标出来）和“为什么板厂在乎” | 方案“Gerber 做可制造性检查”；测试点覆盖率直接接到电路板厂的 ICT |
| K-6 | **BOM 与电路板厂清单一致**：脚本把 KiCad BOM 归到清单的物料编号（电阻、电容按封装归类），测试核对 `wenquest-pcb.yaml` 里 SMT-DRV 的数量与设计相同（采样电阻 3、MOSFET 6……）；数量不同的以设计为准改清单 | 方案“BOM 自动变成 ERPNext 物料” |
| K-7 | **与电路分析一致**：电路分析的“电流采样”“栅极驱动”“母线”例题的元件值（采样电阻、放大倍数、栅极电阻、母线电容）由测试与原理图核对；电路分析页加“打开驱动板原理图里的这一页” | 同一张图既仿真又出板 |
| K-8 | **网页“电路板设计”**（`/pcb-design`，“仿真与分析”下，各厂都能看）：原理图（逐页、可缩放）、PCB（层开关）、三维（零件库同一个三维查看器）、BOM（与电路板厂物料对照）、可制造性检查（点一项在 PCB 图上标出位置）、下载（KiCad 工程、Gerber、STEP） | 学生不装 KiCad 也能看完整设计 |
| K-9 | **电路板厂“功能测试台”**（`/fct`，只在电路板厂）：① 测试程序（上电电流 → 母线电压读数 → 三路电流采样：电流源注入、比对板上读数 → 栅极死区：示波器看上下管栅极波形 → 编码器接口：逻辑分析仪看 SSI 帧），每一步用第 82 轮的仪器模型画出画面；② 选一块做过 FCT 的板，按它车间里记下的测量值复现测试画面（同一块板每次一样）；③ 学生可以**复测**一块板：自己调示波器、万用表读数、判合格与否，复测记录写进这块板的单件档案（不改 SPC 里的原始测量值） | 方案“功能测试就是虚拟仪器的自动化版”；采样电阻那一批超差在复测里也看得出来 |
| K-10 | **零件库“电子元件”大类第一批**：驱动板 BOM 上的约 15 种（贴片电阻、电容各一个系列、采样电阻、MOSFET 封装、电感、端子、连接器、几颗示例选型的芯片），每个带 KiCad 封装、三维、通用 SPICE 模型（芯片没有的不写）、参数表；来源 KiCad 官方库，**先读许可证全文**（符号、封装、三维为 CC-BY-SA 4.0 附例外），登记来源后才入库 | 第 79 轮 C-7；freecad-ai-parts 规则“来源条款核实后才能入库” |

## 三、规则

1. 设计是**教学示例**：所有页面、原理图标题栏、BOM 都写“示例设计，未经硬件验证，不能直接投产”。
2. 不编参数：芯片引脚、封装尺寸取 KiCad 官方库；电阻电容数值由电路公式算（算法写在原理图注释和帮助里）；工艺能力、单价是示例值。
3. 生成要可重复：同一份脚本、同一版 KiCad 生成的产物逐字一致（CI 核对“提交的产物 = 重新生成的”）。
4. 已有行为不变：电路分析的读数、虚拟仪器、三座厂的现有测试不改断言（清单 SMT-DRV 数量按设计改的那几项除外，写明）。

## 五、施工顺序

1. 读 KiCad 库许可证全文，登记来源；确定示例选型（库里有的器件）。
2. 电路计算（母线电容、栅极电阻、采样放大倍数、辅助电源）→ 原理图生成 → PCB 摆放、自动布线、铺铜 → 设计规则检查清零。
3. 产物生成脚本、CI 里的 KiCad 容器步骤；DFM 四项自查。
4. BOM ↔ 清单、原理图 ↔ 电路分析的一致性测试；改清单。
5. “电路板设计”页；功能测试台页与复测记录。
6. 零件库电子元件第一批。
7. 帮助、验收、部署、同步。
