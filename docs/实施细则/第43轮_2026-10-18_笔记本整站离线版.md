# 实施细则 · 第 43 轮：笔记本整站离线版（带回国演示）

状态：**待 Eddie 确认**（2026-10-18 起草）

## 一、为什么做

Eddie 要回国，国内打不开美国服务器上的问渠。国内正式部署要先办 ICP 备案（1–3 周以上），来不及。
这一轮先做“笔记本整站离线版”：把线上的整套问渠——官网、学习平台、经典界面，连同现有课程、账号、教材、动画——原样装进 Eddie 的 Windows 笔记本，**断网也能打开**，回国当面演示用。

## 二、决定（2026-10-18 Eddie 已定）

1. **给谁用**：主要 Eddie 自己演示；暂不给国内老师学生开网址（以后要开再走香港服务器 / 国内备案，见《国内部署指南》）。
2. **数据**：线上现有的课程、账号原样带过去（线上没有学生数据）。
3. **范围**：整体网站，不是只有学习平台。

## 三、规则

### 1. 地址（笔记本上）

| 地址 | 是什么 | 对应线上 |
|---|---|---|
| http://localhost | 官网 | wenquestrobotics.com |
| http://learn.localhost | 学习平台 | learn.wenquestrobotics.com |
| http://classic.localhost | 经典界面（Moodle） | classic.wenquestrobotics.com |

- Chrome、Edge 自动把 `*.localhost` 指向本机，**不用改 hosts 文件**。
- 只用 http（不发证书），省掉证书警告。
- 官网、学习平台之间的链接都指向这三个地址（不跳回线上）。

### 2. 程序

- 用**线上正在跑的同一版镜像**（GitHub 自动构建的，ghcr.io），不在笔记本上重新构建：快、和线上一模一样。
- 全部服务都装：学习平台、经典界面、官网、动画、实验检查、配音、凸轮、三维视频关键画面。
- **数字工厂不装**（另一整套，内存要 8 GB 以上）；页面里指向数字工厂的地方显示“演示版未连接”。——**待 Eddie 确认**
- AI：设成国内模式（`WQ_REGION=cn`），只用 DeepSeek；Claude 在国内不用。断网时 AI 功能不可用，其余照常。
- 发信关掉（验证码写进日志），演示不需要。

### 3. 数据

- 在美国服务器上运行一个“打包带走”脚本，生成**一个文件**：数据库、上传的文件、网关数据（含教材动画）、全部教材构建结果、官网页面。
- Eddie 用一条命令把这个文件下载到笔记本（步骤写进帮助文件）。
- 笔记本上运行一个“恢复”脚本：装入数据，把内容里的网址从 `*.wenquestrobotics.com` 换成 `*.localhost`。
- **账号密码和线上一样**。

### 4. 以后更新

线上有了新内容（例如新写的教材章节），在笔记本上再跑一次“更新”：重新打包、下载、恢复。笔记本上自己改的内容会被覆盖（演示版不往回同步）。

## 四、交付物

1. `docker-compose.laptop.yml`、`deploy/Caddyfile.laptop`：笔记本版的服务和三个地址。
2. `tools/laptop/pack.sh`：服务器上打包（复用 `deploy/backup.sh`）。
3. `tools/laptop/install.ps1`：笔记本上一键安装 / 恢复 / 更新（PowerShell，Eddie 双击或粘贴一行运行）。
4. `docs/帮助/笔记本离线版使用说明.md`：从下载到演示的照做步骤，常见问题（端口被占、内存不够、忘记密码）。
5. 本细则的验收记录。

## 五、施工顺序与验收

1. 写笔记本版服务配置和三个地址；在云端工作环境里用真实镜像跑通（官网、学习平台、经典界面都打得开）。
2. 写打包、恢复脚本；在工作环境里用一份测试数据走通“打包 → 恢复 → 登录”。
3. 写帮助文件，推送上线（只加文件，不影响线上服务）。
4. Eddie 在美国服务器上打包、下载到笔记本、运行安装脚本。
5. **验收（Eddie 的笔记本上，拔掉网线 / 关掉 Wi-Fi）**：
   - 三个地址都能打开；
   - 用线上的账号登录学习平台，看得到原有课程；
   - 打开《机器人学》任意一节（含第 15 章以后），动画能播放，“在本页运行”的虚拟实验能操作；
   - 经典界面能登录；
   - 重启电脑后，打开 Docker Desktop 等一分钟，三个地址仍能打开。

## 六、需要 Eddie 准备 / 确认

1. 数字工厂要不要也装进笔记本（默认不装）。
2. 笔记本内存多大（建议 16 GB 以上；8 GB 只能开核心部分）、硬盘剩余空间（建议 60 GB 以上）。
3. 哪天出发：打包下载要在美国网络下完成（约 10–20 GB，看教材动画多少）。
4. 能用 SSH 登录美国服务器（`deploy` 用户）；不行的话我在帮助文件里给替代办法。
5. 现在笔记本上已经装好的那套（localhost:8080 / 8088 的全新空站）会被这次的离线版替换。
