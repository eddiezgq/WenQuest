这三种机和前三种不一样：前三种讲“主轴转一圈机构怎么动”；这三种讲“**一个花样 / 一片衣片怎么走完**”——针一针一针（花样机、刺绣机），机头一趟一趟（横机）。

## 二、决定（建议）

1. **统一的“进度角”**：渲染器原来按“主轴累计转角”驱动，这三种机沿用同一个驱动，只是意思变成进度——
   - 花样机、刺绣机：**每 360° = 一针**（主轴真的转一圈缝一针）；一针之内针杆上下按设计的入布 / 出布角，模板 / 绣框在离布窗口里移到下一针（移动占的转角 = `proto` 的 `mv`）。
   - 横机：**每 360° = 一趟**；一趟之内机头按这一趟的加速—匀速—减速走完行程（同 `flatknit.profile`），针按三角曲线起落。
   - 针、趟太多时用 `proto` 已抽样的那一串（最多 3000 条，出问题的那针 / 那趟一定保留），讲解片里“走一遍”这段快放。
2. **计算核心加三种机的三维零件**：`cad.parts3d(参数, 进度角, "pattern" | "embroid" | "flatknit")`，零件、尺寸照教材模型 15-1 / 16-1 / 17-1（**尺寸示意**，片里注明；运动、针迹、趟次按这台设计）：
   - 花样机：机头（针杆、机针、压脚）、针板、X / Y 两轴（导轨、滑台、同步带）、模板（按花样外形大小）、**已缝的针迹**（细管子，一针一针画出来）。
   - 刺绣机：机头（针杆架，按颜色左右换针杆）、绣框、X / Y 横梁；**头数按设计画，最多画 4 个**，多出来的字幕写“共 H 头”；已绣的针迹按颜色分色画，跳步、换色那段不画线（同 `proto` 的 `up`）。
   - 横机：前后针床、一排针（画 60 根示意，按设计机号排）、机头（几个系统就几套三角，同模型 17-1）、纱嘴、导轨；翻针时后针床摇床；织物按已织的趟数往下长。
3. **讲解片的段落**（软件自动写，同第 56 / 76 轮）：
   - 花样机：整机 → ① 刺布（一针慢放：入布角、出布角、离布窗口）→ ② 模板移动（X、Y 两轴在窗口里走完一针）→ ③ 走一遍花样（快放，针迹画出来，读数跟着变）→ ④ **最紧的一针**（转速上限最低的那针，慢放）→ 红黄灯（最多 3 项）→ 结论。
   - 刺绣机：整机（几个头一起绣）→ ① 刺布与换色（针杆架换针杆）→ ② 绣框移动 → ③ 绣一遍（快放，分色针迹）→ ④ **最难的一针**（所需加速度最大的那针，慢放）→ 红黄灯 → 结论。
   - 横机：整机 → ① 三角起针（机头经过时针一根根升起又落下）→ ② 机头一趟（加速、匀速、减速、换向停顿）→ ③ 翻针与摇床（有翻针才有这段）→ ④ 织一片（快放，织物长出来）→ 红黄灯 → 结论。
   - 出问题的地方：每项校核对到一针 / 一趟，规则同第 81 轮样机的“慢放到出问题的那一针 / 那一趟”（花样机：转速 / 窗口 → 最紧的一针，行程 → 超出最远的一针；刺绣机：加速度 → 最难的一针，DST 记录上限 → 第一条超出的；横机：摇床 → 第一个翻针趟，急停 / 选针 / 电机 → 最宽的一趟），红灯段在那里慢放、标题标红，对应部件亮红（同样机的 `matsOf` 对照表）。
   - 右侧面板读数：花样机——针号、这一针转速 / 上限、针尖高出针板；刺绣机——针号、颜色号、转速、所需 / 可用加速度；横机——第几趟、类型（编织 / 翻针 / 空行）、机头速度 m/s、累计用时。曲线：花样机、刺绣机画每针转速与上限，横机画每趟速度，光标跟着走。
   - 字幕里的数全由 `analyze` / `proto` 给，模型和参数锁定（同第 56 轮第七节 1）。片长约 45–80 秒。
4. **网页版**：“导出”页签的“出三维讲解片”六种机型都出现；出片、改片、小样、高清、只记账不收费、国内只开关键画面——都照第 56 轮，不另起。
5. **不做**：这三种机的零件 STEP / FreeCAD 零件（尺寸示意，同第 76 轮 Q3）；线的物理（针迹只画成细管子，横机织物画成一片网格，不画每个线圈）。
6. **帮助**：网页版“导出 → 三维讲解片”一节改成六种机型；花样机、刺绣机、横机三个案例各加一步“出讲解片”，各配两张关键画面；不另录屏。

## 七、施工中的偏差（已按此做）

1. **零件放在新文件 `sewcore/cad_seq.py`**（原写 `cad.py` 里加三个函数）：三种机共用的进度角、针迹、零件前缀表放一起，`cad.parts3d`、`cad.group_of` 转过去；平缝、包缝、绷缝的代码一行没动。
2. **场景另写在 `sewing_video_seq.py`**：这三种的段落结构和前三种不一样（快放途中停几次），硬塞进原函数会改动原来三种的场景。原来三种的场景已核对和改动前**逐字相同**（中、英、双语，标准和有红灯各一组）。
3. **上传的花样文件、意匠图不写进场景**：试的时候 logo 花样文件的场景有 5 万多字，超过平台“场景最多 4 万字”的检查，而且是给人和 AI 改的文件。改成：场景里带这台设计抽样后的轨迹（`_track`，最多 800 针 / 趟，出问题的那一针和它前一针一定留着，慢放时移动距离是真的；压缩成一串字），渲染器按它画、不再重算；它和参数一起锁定。文件本身仍只在项目里。
4. **结果表按名字取**：有花样文件、意匠图时结果表多出几行，按位置取会张冠李戴（试刺绣机 logo 时“刺布”那段的字幕成了“花样：针数 / 跳步 / 换色”）。改成按结果的中文名取，没有这一行就不写。
5. **曲线**：刺绣机画的是每针“所需 / 可用加速度”（红线 = 1，过线就走不完），比每针转速更能看出问题；横机画每趟实际达到的最高速度（行程短的趟到不了设定速度）。原写“刺绣机画每针转速与上限、横机画每趟速度”。渲染器的面板加了一种按针 / 按趟的曲线（场景里直接给数）。
6. **横机针床每床画 40 根针**（同模型 17-1，示意间距；机头行程按“针床有效宽 ↔ 画面针床长”折算），原写“画 60 根、按设计机号排”。真实机号的针距约 2 mm，几百根针在整机画面里看不出起落。
7. **横机“织一片”**：每隔若干趟看一整趟（每趟 1.2 秒，共 8 趟左右），不是连续快放——几百趟连续快放时机头来回闪，看不出东西。织物按已织用时往下长。
8. 片长：标准设置花样机 41 秒、刺绣机 44 秒、横机 46 秒；有红灯的 48–65 秒；logo 12 头 54 秒。都在原写的 45–80 秒左右（花样机标准设置略短）。
9. 刺绣机多头时字幕写“8 头（画 4 个）”，原写“共 H 头”，意思一样。
10. 刺绣机换色时针杆箱不左右换针杆（模型 16-1 也没有这个动画），段名改成“① 刺布”，字幕不提换针杆；颜色体现在分色画的针迹和读数“颜色”上。
11. 红灯段“对应部件”用透视突出（别的零件变半透明，同前三种机的讲解片），不另把零件涂红；标题标红、字幕写数值和判据。透视时已缝的针迹也留实的（试出关键画面时发现透视把刺绣机的针迹淡到看不见）。
12. **红灯正好在最紧的那一针上时只停一次**（标题写红灯项），不先放“最紧的一针”再重放；超行程、超 DST 上限只有亮红灯时才去超出的那一针（同样机的“慢放到出问题的那一针”），黄灯时看最紧的一针。
13. 横机一趟的画面按这一趟的真实用时走（全成型的趟数倍数只算进累计用时），样机页面是把倍数也乘进每一趟的用时；只在全成型时有差别。
14. 跳针 / 跳趟（快放时跳过中间的针 / 趟、重放）是同一时刻两个关键点，瞬间跳过去，不会有一帧画到中间。

独立 AI 审读（看代码和本细则，不看我的结论）查出：只有一针的刺绣花样文件出片报错（已改，只有一两针也能出）；跳的时候有一帧画到不相干的针 / 趟（第 14 条）；同一针重放三遍、超行程黄灯也去最远那针（第 12 条）；横机每趟用时和样机页面不同（第 13 条，保留计算核心的做法）；“画 4 个”是画面常数不是计算核心给的（第 9 条已说明）。测试补上：一两针的花样、跳是瞬间的、红灯关键画面正好停在那一针 / 那一趟、最紧一针标题里的数就是那一针的。审读核对过：三种机的运动、针迹、逐趟动作和教材模型 15-1 / 16-1 / 17-1 的页面、样机数据逐项一致，坐标换算、后针床镜像对；平缝、包缝、绷缝的场景和锁定与改动前逐字相同；场景最长约 2.6 万字，在 4 万字以内；渲染器每帧零件、管子点数不变。
