## 一、定位

| 项 | 内容 |
| --- | --- |
| 主要用户 | 中小轴承制造企业：设计轴承的内部结构，校核性能，定工艺，管检测和合套 |
| 附带用户 | 用轴承的设备企业：选型、寿命、配合与游隙、故障特征频率（与缝纫机软件、凸轮软件、数字工厂的数字孪生、零件库衔接） |
| 现状 | 平台里只有“用轴承”：数字孪生按样本额定动载荷 C 算 ISO 281 的 L10（`factory/digital/twin/models.py`）。没有能给轴承厂用的设计与制造计算 |
| 对标 | 商业软件有 MESYS、KISSsoft、舍弗勒 BearinX、SKF SimPro、Romax 等（贵、面向大厂）；开源的只有零散的小工具，例如 bstart-trb（MIT，切片法算圆柱、圆锥滚子轴承的接触应力分布）。我们的定位：中小轴承厂用得起、中文、设计到车间一条线 |

## 二、覆盖的轴承（第一期）

| 类型 | 要点 |
| --- | --- |
| 深沟球轴承 | 最大量的品种；沟曲率、球数与球径、游隙、径向与轴向联合载荷 |
| 角接触球轴承 | 接触角随载荷和转速变化；单列、成对（背对背、面对面、串联）与预紧；主轴高速（离心力、陀螺力矩） |
| 圆柱滚子轴承 | 线接触；滚子凸度（对数修形）与边缘应力；挡边型式 |
| 圆锥滚子轴承 | 内圈大挡边与滚子端面接触；成对与预紧；凸度 |

第二期另定：调心滚子、推力球与推力滚子、机器人用交叉滚子与薄壁轴承（含谐波减速器柔轮轴承），与第 58、63 轮机器人厂、零件库衔接。

## 三、功能

### 1. 设计与校核

- **主参数**：按外形尺寸（内径、外径、宽度，标准系列或自定）定内部设计：滚动体直径与数目、节圆直径、沟道曲率半径系数、接触角、游隙、滚子凸度、保持架兜孔；给出几何约束检查（滚动体间隙、套圈最薄处、沟肩高度）。
- **额定载荷与寿命**：基本额定动载荷 C、基本额定寿命 L10、修正额定寿命（润滑、污染、疲劳极限系数）、基本额定静载荷 C0 与静安全系数——按国家标准（与 ISO 281、ISO 76 对应）；系数表从购买的标准文本录入（第五节）。
- **内部载荷分布**：径向、轴向、力矩联合载荷，含游隙与倾斜，算每个滚动体的载荷和接触角；按 ISO 16281 的方法算修正参考寿命。
- **接触**：赫兹点接触（接触椭圆、最大接触应力、椭圆是否越过沟肩）；线接触用切片法算沿滚子的应力分布和边缘应力，帮助选凸度。
- **游隙链**：初始游隙 → 配合过盈后的安装游隙 → 内外圈温差下的工作游隙；配合选择。
- **高速**：离心力、陀螺力矩下的接触角变化（拟静力学）。
- **润滑与摩擦**：弹流油膜厚度和黏度比 κ（进修正寿命），摩擦力矩与发热估算。
- **故障特征频率**：外圈、内圈、滚动体、保持架通过频率，交给数字孪生的振动诊断。
- **计算书**：参数、校核、曲线、剖面图，打印 PDF；没填的数结果是“未知”，不算合格。

### 2. 制造

- **零件图与三维**：内圈、外圈、滚动体、保持架的工程图与 STEP（网页版简化三维，FreeCAD 出精确实体与工程图）。
- **工艺路线与工序卡**：车削 → 热处理 → 磨削（端面、外径、沟道、内孔）→ 超精 → 合套 → 检测；各工序余量分配、沟道磨削与超精参数（示例值，按厂里设备改）。
- **合套选配**：按实测的内圈沟径、外圈沟径和钢球分组，算出配对方案，让每套的径向游隙落在要求范围内、配不上的件最少——轴承厂合套工序的实际难点。
- **检测与质量**：沟道圆度与波纹度（谐波分析，与问渠凸轮的测量做法相同）、游隙、振动值数据导入，SPC 控制图，接问渠质量体系。

### 3. AI 帮什么（AI 只起草，判定由代码）

- 一句话需求 → 初步设计或选型草稿（数字由代码检查，不认 AI 编的数）；
- 用白话解释校核结果和改法；计算书的设计说明草稿；
- 读厂家样本 PDF 抽参数（零件库已有的做法），人工复核后入库。

## 六、规则

1. 判定只由确定性代码；AI 起草的数先过代码检查，人确认后才进项目。
2. 不编造标准数值和厂家数据：系数表等标准数据只从正版标准文本录入；厂家样本数据要有来源。
3. 没填或没录入的数据，结果为“未知”，不算合格。
4. 示例一律标“参数为虚构”。
5. 每个计算模块带标准题；测试写明出处。

## 七、收费思路
