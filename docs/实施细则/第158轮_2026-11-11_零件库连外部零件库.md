## 一、现在有什么、缺什么

| 外部库 | 内容 | 许可 / 条款 | 现在 |
|---|---|---|---|
| OpenPartsLibrary（GitHub alekssadowski95） | 直线导轨、铝型材、紧固件、板件，FreeCAD 装配 | AGPL-3.0 | 没进库。和我们的 Apache-2.0 不相容，不能搬 |
| SnapEDA / SnapMagic（含 Seeed 的 Open Parts Library 页面） | 电子元件符号、封装、部分 3D 模型 | 单个元件 CC BY-SA 4.0 + 设计例外；网站条款不许拿它的网站当来源在网上转发内容 | 没进库 |
| Seeed OPL KiCad 库（GitHub Seeed-Studio/OPL_Kicad_Library） | 约 340 种常备元件（电阻 113、连接器 55、芯片 50……），每种带厂商型号（MPN）和 Seeed 物料号（SKU）；另有 XIAO 等模块封装 | CC BY-SA 4.0 | 没进库 |
| FreeCAD-library | FreeCAD 零件 | CC BY 3.0 | **已接**：只收索引和缩略图，模型从原仓库固定提交下载（零件库页“F”部分） |
| bd_warehouse | 按参数生成螺钉、螺母、垫圈、轴承等 | Apache-2.0 | **已用**：标准件的造型程序（A 部分） |
| KiCad 官方元件库、MuJoCo Menagerie、robot_descriptions、ROS-Industrial | 电子元件、机器人模型 | 各自开源许可，已登记 | **已接** |
| FreeCAD 紧固件工作台 | ISO/DIN/ASME 紧固件 | GPL-2.0 | 没接；bd_warehouse 已覆盖同类件 |
| BOLTS | 标准件 | 整体 GPL-3.0，数据逐份不同 | 没接 |

缺的：
1. 零件库页上看一个件，没法顺手到外部库查同类件、厂商现货、别人的封装。
2. 电子件做物料清单时，不知道哪些料在 Seeed 深圳常备库（OPL）里——全用 OPL 的料，贴片最快 7 个工作日、价格也低。这是问渠贴片 11-06 定的“暂缓的供货查询”的一小步。

## 二、决定

1. **外部库一律“只链接、不搬内容”**：零件库页每个条目加“到外部库查”一组链接，链接按条目自己的标准号、型号或名称拼成对方网站的搜索地址，新窗口打开；
   不抓取、不转存对方页面和文件，链接旁写“外部网站，内容以对方为准”。AGPL、GPL、只许个人下载的库都只能这样接。
2. ~~Seeed OPL 只收“型号—物料号”索引~~（**11-11 22:45 Eddie“好”改为下面这条**，原因见第八节 158b）：
   **物料清单每一行也“只链接”**：问渠贴片检查结果、电路板设计页的物料清单，每行加“到外部库查”——芯片、功率管按型号查 SnapMagic、LCSC、DigiKey；
   电阻、电容、电感、晶振按“封装尺寸 + 数值”查 LCSC、DigiKey；JST 插座按型号查。规则和零件库页同一份代码。LCSC 就是嘉立创贴片用的深圳现货库，点开能看到有没有货、价格。
   **这一栏只是方便查找，不参与任何合格判定**；客户的物料清单不因此存到服务器（链接由客户自己点开）。
3. **不接 FreeCAD 紧固件工作台和 BOLTS**：标准紧固件已由 bd_warehouse 生成（同为 Apache-2.0），再接 GPL 的库只多了许可证上的麻烦。
4. **决策记录**：freecad-ai-parts 写一份 ADR（外部库只链接、不转存；不收 OPL 索引及原因）；链接类外部库不入库，不进 `sources.yaml`。

## 三、规则

### A 链接怎么拼（确定性，按条目类别）

| 条目 | 链接到 | 用什么查 |
|---|---|---|
| 电子元件（A-ELE-*） | 有型号：SnapMagic（SnapEDA）、LCSC、DigiKey；无型号：LCSC、DigiKey | 厂商型号；没有型号的用“封装 + 数值”，如 0402 100nF（施工时按核实结果定，见第八节 158a） |
| 机械标准件（A 部分 bd_warehouse 生成的） | MISUMI、McMaster-Carr | 英文名 + 规格，如 Socket head cap screw M5x16（标准号查得差，见第八节 158a） |
| 厂商件（伺服电机、减速器、驱动器、传感器） | 已有的“官方技术参数表”链接；另加厂商官网 | — |
| 机器人、机构 | 不加（已有原仓库链接） | — |

- 每个外部网站的搜索地址施工时逐个在浏览器里打开核实，打不开结果页或要求登录才能搜的不放。
- 地址模板集中写在一个配置文件里（网站名、地址模板、适用类别），以后换网站、加网站只改这一处。

### B 物料清单行的链接（确定性，按物料编号前缀与封装）

| 行 | 查询词 | 网站 |
|---|---|---|
| 物料编号以 `IC-`、`MOS-` 开头，数值是厂商型号 | 型号（如 `IR2101S`） | SnapMagic、LCSC、DigiKey |
| `CAP-`、`RES-`、`IND-`、`XTAL`，封装名里有四位尺寸码（`C_0402_1005Metric` → `0402`，`Crystal_SMD_3225-4Pin` → `3225`） | 尺寸码 + 数值补单位（`100n` → `0402 100nF`，`2m 1%` → `2512 2mOhm 1%`，`22u` 电感 → `22uH`） | LCSC、DigiKey |
| 封装名里有 JST 插座型号（`JST_XH_B4B-XH-A_…` → `B4B-XH-A`） | 插座型号 | LCSC、DigiKey |
| 其他（没有尺寸码的电解电容、二极管、端子、自研芯片 WQ-ENCIF 等） | 不出链接（不猜） | — |

- 代码只有一份：`factory/digital/web/src/lib/extlinks.js`（地址模板写在模块里）；问渠贴片页用它的副本 `services/eda/web/factory/extlinks.js`，测试核对两份逐字相同。
- 问渠贴片的检查结果加一张“物料清单（到外部库查）”表：同一物料编号、数值、封装合为一行，列出数量和链接；数据只回给上传的人，算完照旧删除。

## 八、施工记录

### 158a 零件库页“到外部库查”（11-11）

1. **配置与规则**：`factory/digital/web/src/lib/extlinks.js`（五个网站的搜索地址模板、三组、无型号电子件的查询模板写在模块的 `CFG` 里；纯函数 `extLinks(条目, 规格)`）。158a 时配置是单独的 `extlinks.json`，158b 为了让问渠贴片页（不经打包）也能直接用同一份代码，并进了 `extlinks.js`。
   - 电子件有型号：SnapMagic、LCSC、DigiKey；无型号的被动件：按模板“封装 + 数值”（如 `0402 100nF`、`2512 2mOhm`、`JST B4B-XH-A`）查 LCSC、DigiKey。
   - 其他标准件：英文名去掉括号和逗号后的说明 + 规格（如 `Socket head cap screw M5x16`），查 MISUMI、McMaster-Carr。
   - 厂商件：厂商官网；机器人、机构、夹具不出。缺数值不拼（不猜）。
2. **页面**：`/library` 条目详情“来源”页签最后加“到外部库查（查询词）”一组链接和一句“外部网站，内容以对方为准；这里只放链接，不转存对方的文件和参数”，中英文都有。
3. **核实**（11-11 用内置浏览器逐个打开）：
   - SnapMagic 按型号能出结果（IR2101S 出 8 种）；按“封装 + 数值”查不出，所以被动件不放它。
   - LCSC：型号（IR2101S → 立创 C2956）、`0402 10Ohm 1%`、`3225 8MHz crystal`、`0402 100nF capacitor` 都进到对应的结果或分类页。
   - DigiKey：地址是 `/en/products/result?keywords=`；型号、`0402 100nF`（20 条）、`2512 2mOhm`（57 条）、`terminal block 5mm 2 pin` 有结果；长句（`Current shunt 2512 2mΩ`）查不到，所以模板都用短词。
     连续快速打开时 DigiKey 会出一次真人验证页（自动化访问才有，正常点开不会）。
   - MISUMI：`ISO 4762 M5x16` 这种标准号查得很差，改用英文名 + 规格（`socket head cap screw M5x16` 直接进内六角螺钉分类；`Linear guideway HGH15CA` 进标准直线导轨）。
   - McMaster-Carr：`/products/<词>/` 能进对应品类（内六角螺钉、六角螺母）；轴承型号这类查询加载慢、不一定有结果，作为搜索入口保留。
4. **测试**：`tests/test_extlinks.py` 6 条（数值格式手算、型号三站、模板两站且不放 SnapMagic、缺模板缺数值不出、标准件去括号去逗号、厂商官网与机器人不出），经 node 跑网页同一份代码。
5. **截图**：`docs/截图/第158轮-外部零件库/158a-*.png`（本机真页面：芯片、螺钉、厂商件、0402 电容，中英文）。
