## 一、问题

“设计与工艺”页（`/work/engineer`）写死了演示工厂的输出轴 SH-301：在线设计、设计版本、键槽 G 代码、SH-301 的工艺路线。到了机器人厂、缝纫机厂、电机厂、传感器厂、电路板厂、芯片封测厂和企业自己的工厂，这一页读不到 SH-301，只剩空壳；电机厂帮助里写的“在设计与工艺能看到四张物料清单和两条工艺路线”也就落空。

## 二、决定

| 编号 | 决定 |
|---|---|
| E-1 | **演示工厂（减速器厂）不变**：仍是输出轴 SH-301 的在线设计、版本、G 代码、工艺路线 |
| E-2 | **其他工厂（含企业工厂）**：这一页换成“本厂产品的物料清单与工艺路线”。左边列出本厂所有有物料清单的物料（可接单的成品在前，自制的半成品在后）；选一个，右边显示：物料清单（物料号、名称、每件用量、单位、自制还是外购——自制件点一下就跳到它自己的清单）、工艺路线（工序、分钟/件、设备、一台一次装几件）、标准成本（材料 + 加工 / 件） |
| E-3 | 接口：新增 `GET /api/products/structure`，一次给出本厂全部有物料清单的物料及其清单、工艺路线、标准成本（数据取 `factory/data.py` 的 BOMS、ITEMS、PRODUCTS 和 `sim/engine.py` 的工艺路线、设备、炉子容量，与订单算料、车间仿真同一份）；`GET /api/routing/{item}` 的每道工序加 `batch`（一台一次装几件） |
| E-4 | 只读：本页不改物料清单和工艺路线（企业改清单走“产品登记 / 按单设计”，演示工厂改设计走在线设计） |
| E-5 | 英文表、帮助（各厂“产品与物料”一章写明在“设计与工艺”页能看到本厂物料清单与工艺路线；电机厂原有那句现在属实）；页面帮助说明 |
