## 〇、可行性（已在本机实测）

- Blender 4.2 能以 Python 模块（`bpy`）的形式装进工作环境，不用开界面，全程由程序控制。Blender 是开源软件（GPL），做出来的视频可以商用。
- 用教材里现成的三维模型（《机械制造技术》`textbook/mfgtech/models/*.glb`，共 23 个）试渲染 1280×720。本机没有显卡，结果如下：
  - **工程图风格**（Workbench，平涂、带阴影和边缘）：约 1.6 秒一帧。
  - **写实风格**（Cycles，真实光照和材质）：约 16 秒一帧。
  - 写实风格 1 分钟视频有 1800 帧，本机要 8 小时，所以写实片要**租 GPU** 渲染（仓库已有 Lambda 租用工作流 `gpu-run.yml`，照着做），估计几分钟一段。
- 结论：做得出来。工程图风格本机就能出片；写实风格放到租来的 GPU 上出片。

## 一、决定（建议）

1. **运动由我们自己算，Blender 只负责画。** 机械臂轨迹（运动学）、齿轮和连杆、缝纫机的针和挑线、流体走向，都用 Python 按物理公式算出每一帧的位置和角度，再写成 Blender 的关键帧。好处：数字准，和教材、虚拟实验同一套公式，能在片中标出读数；同一场景随时能换参数重出。Blender 自带的刚体、布料、流体模拟只用在“看效果”的地方（例如碎石飞溅、布料下垂），不用在要讲准数字的地方。
2. **模型来源，按顺序取：**
   - 教材和数字工厂已有的 glTF 模型；
   - 程序生成的参数化模型（齿轮、连杆、机械臂、传送带、简单机床，按尺寸自动建）；
   - FreeCAD 出的零件（另一个项目已有 FreeCAD 的 AI 零件库，导出 STL 或 glTF 即可）；
   - 开源模型库里授权允许商用的（CC0 或 CC-BY，记录出处）。
   - 不用有版权的商业模型，不仿任何品牌外观。
3. **三种风格，按用途选：**
   - **工程图风格**：白底或浅底、平涂配色、清楚的边线，可加剖面、透明外壳、尺寸标注。用于课堂讲原理，本机出片。
   - **写实风格**：真实材质、灯光、景深。用于课程封面、宣传片、科普片的“哇”镜头，租 GPU 出片。
   - **白板混搭**：三维镜头当素材，插进白板课和网页课件的画框里，和第 35 轮白板课的“插入视频”打通。
4. **一段三维视频 = 一个场景脚本**（`video3d/<名>/scene.py`）。里面写清：
   - 用哪些模型、怎么摆；
   - 运动从哪个计算程序来；
   - 镜头怎么走（环绕、推近、跟拍、剖开）；
   - 在哪一刻标什么字（中英，和白板课同样的字体）。
   - 出片：`python3 tools/blender/render.py <场景> [--style 工程|写实] [--draft]`。`--draft` 出低分辨率小样，几分钟就能看动作对不对。
5. **出片规格**：1920×1080，30 帧；网页用 WebM（录屏和白板课都要这个格式），对外发布用 MP4；中英字幕或标注烧进画面。
6. **AI 怎么参与**：AI 按“一段视频说明”（讲什么原理、哪个模型、要几个镜头）写场景脚本，再出小样；检查程序验证模型在画面内、不穿模、字不出框、动作和数字对得上。人只看小样，提意见改。
