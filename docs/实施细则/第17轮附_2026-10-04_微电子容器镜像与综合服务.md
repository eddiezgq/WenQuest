## 三、方案（建议）

### 3.1 镜像：在 IIC-OSIC-TOOLS 上加一层问渠的内容

`wenquest/micro-lab` = IIC-OSIC-TOOLS 2026.08（按摘要值锁定版本，不跟 latest）＋ 问渠层：

- `/foss/wenquest/`：各实验的起始文件与参考解（第 1 章：反相器原理图、版图脚本、仿真网表、8 位计数器的 LibreLane 配置）；
- `wqlab` 小工具：运行检查（DRC、LVS、时序、仿真）并把结果整理成实验报告要用的“结果名 → 数值”，格式与 GPU 实验的 `wqgpu submit` 一致，以后由调度服务回传问渠；
- 默认打开 SKY130，桌面上放好常用工具的快捷方式和中文说明。

自己从头编译全套工具要几个小时、几十个依赖，还得自己跟着上游升级。用维护良好的现成镜像，只做薄薄一层，升级时改一个版本号即可。

### 3.2 第 4 步全部在 GitHub Actions 里验收，不需要新服务器

新增手动工作流 `micro-lab.yml`（也在镜像相关文件变动时自动运行）：先给 GitHub 的运行机腾出磁盘（默认只有约 14 GB 空闲，删掉不用的预装软件可到 30 GB 以上），拉取镜像，然后无界面跑完下面的验收，把日志、版图图片、测得的数值作为构建产物保存。网页远程桌面也在运行机里启动，用无界面浏览器打开截图，确认能用。

给每个学生开容器（按班级预启动、计时、自动回收）属于第 5、6 步的平台工作，另起细则；那时沿用第 14 轮附 GPU 实验的调度做法（适配器、额度、计时、自动关机），只是机器换成 CPU 机型。

### 3.3 综合服务 `micro-synth`

- 形式：与现有的 `labcheck` 服务一样的小容器，只装 Yosys（约 150 MB），放进现有服务器的 docker compose，不对外开端口，只由网关调用。
- 接口：网关新增 `POST /api/micro/synth`（登录用户可用），提交 Verilog，返回 Yosys 的 JSON 网表和统计；手机端 Verilog 页拿到 JSON 后照旧用 DigitalJS 仿真和自动测试。
- 限制：源码不超过 64 KB；单次 20 秒超时；同时最多 2 个综合任务，其余排队；每个用户每分钟最多 10 次；容器无网络、只读文件系统、限 1 CPU 和 1 GB 内存。
- 页面行为：电脑浏览器默认仍在本机用 WebAssembly 版 Yosys（不占服务器）；手机、或本机加载超过 15 秒时，自动改用服务器综合；页面上显示当前用的是哪一种。

### 3.4 用 SKY130 校准第 1 章参数

在镜像里用 ngspice 加 SKY130 的 1.8 V 器件模型（`sky130_fd_pr__nfet_01v8` / `pfet_01v8`，W = 0.42 μm、L = 0.15 μm 起），测：饱和电流、阈值电压、反相器传输特性、FO4 延时、单位宽度栅电容。据此拟合 `params.json` 的有效参数（k′n、k′p、VT、Cg、Cd），并把“示意值 → 校准值”的对照、各题参考结果的变化写回第 17 轮第四节。校准后重新生成实验台、指导书、课件（构建脚本已经能一键完成）。

说明：长沟道公式拟合短沟道器件只能在一个工作区间内贴近，校准目标是 FO4 延时、饱和电流误差在 10% 以内，其余量作为“模型局限”写进课件第⑤步，这本身也是教学内容。

## 八、施工记录

**镜像（4a）。** `deploy/micro-lab/Dockerfile` 在 IIC-OSIC-TOOLS 2026.08 上加问渠层：默认工艺库 SKY130（`ENV PDK=sky130A`）、实验文件 `/foss/wenquest`、`wqlab` 小工具（tools / netlist / inv / flow / results）。基础镜像按摘要锁定：`hpretl/iic-osic-tools@sha256:3c371645b19c6f6564dc8c7b21e39ad1c1833d274fe5b85639afe1ba9d7987e7`；工作流按摘要拉取，Dockerfile 没锁摘要时直接报错，上游标签更新时只出提示。网页远程桌面（noVNC）在运行机里实测能打开，Xschem 显示反相器原理图、KLayout 显示反相器版图（截图以运行注释保存）。截图发现原理图里的中文标题显示成方框；补装中文字体后仍是方框（Xschem 的字体设置不走系统字体回退），改为原理图里只用英文标注（电路图惯例），中文说明放在指导书里。KLayout 首次打开会弹出使用提示，不影响使用，暂不处理。

**反相器版图（4b）。** `wenquest/ch1/build_inv.py`：Magic 用 SKY130 器件生成器画 NMOS（W 0.42 μm）、PMOS（W 0.97 μm），脚本连线、打电源轨和标签，跑 DRC、提取、Netgen LVS。镜像里：DRC 0、LVS 一致（同时核对器件尺寸，尺寸不符也判不通过）、面积 17.38 μm²。原理图 `inv.sch` 由 Xschem 在镜像里导出网表后参与 LVS。

**8 位计数器 RTL→GDS（4c）。** `wenquest/ch1/counter8/`，LibreLane 3，100 × 100 μm，时钟 10 ns。镜像里两次运行：流片就绪，setup 余量 4.98 ns、hold 余量 0.108 ns，DRC 0，LVS 0，用时 94–122 s，内存峰值 654 MB。

**SKY130 校准（4d）。** 先在会话环境里用器件库原始文件手工拼的模型卡校准（第一次）；镜像验收时用镜像里的完整模型库复核，饱和电流低 6%（n）、11%（p），FO4 高 8%，超过 3% 门限。按 3.4 节“在镜像里校准”，改以镜像结果为准：镜像验收工作流把结果写成运行注释，`calib/adopt.py` 采用并重新拟合，`生成脚本/regen_ch1.sh` 一次重新生成实验台、指导书、量规、课件、动画。新参数 k′n 84.5、k′p 34.8 μA/V²，|VT| 0.55 V，Cg 1.25、Cd 1.97 fF/μm；拟合误差：饱和电流 0%（由它反推 k′）、FO4（Wp/Wn = 2.25）−0.7% / +0.2%，满足 ≤ 10%。小尺寸比、轻负载下延时误差较大（FO1、Wp/Wn = 1 时 20%–33%），写进课件“模型局限”。校准后 1.4 节机器人任务“小于 0.3 ns”无解（最快 6 级也要 315 ps），改为“小于 0.35 ns”（最少 5 级），所有文字改由参数生成。各题新结果见第 17 轮第四节。

**综合服务（4e）。** `services/micro-synth`（FastAPI + Yosys，固定脚本），网关 `app/micro.py`（登录用户接口、12 小时签名链接、每人每分钟 10 次），docker-compose 新增内部服务（只读、1 CPU、1 GB），部署流程构建、推送镜像。Verilog 页：手机默认走服务器，电脑本机加载超过 15 秒或失败时改走服务器。
