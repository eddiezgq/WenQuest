## 一、这一轮做什么

前三期把一块板子的前三层做通了：
- 规格（L1）；
- 功能块与计算书（L2）；
- 电路与仿真（L3）。

第四层（板子）现在还是驱动板专用的写法：摆放坐标写在设计描述里，布线、检查都在 `factory/designs/tools/` 的驱动板脚本里。这一轮把板子层做成平台的通用部分：

1. **板子从设计描述生成**：板框、摆放、安装孔、铺铜、测试点阵列、网络分类，交给通用生成器，出 KiCad 板子，再用 Freerouting 自动布线。
2. **布局约束写进设计描述并检查**：例如功率回路要短、电流采样走开尔文接法、发热件离电解电容远。
3. **工艺检查补齐**：把第 88 轮驱动板脚本里的检查搬进统一检查引擎。KiCad 文件和光绘两条路都能查，按目标工厂的工艺能力表判定。
4. **热**：功率器件的损耗由计算书算出，板子温升用 CalculiX 算，结温和器件上限比。
5. **KiCad 手工改动读回**：人在 KiCad 里挪了器件，读回成设计描述里的摆放变化。
6. **一份报告**：电气（计算书）、工艺、热合在一份报告里，四种结论（通过、不通过、待核对、未知）一起统计。

例子仍是关节驱动板 A、B 两版，外加 24 V 变体。

## 二、决定

1. **板子生成做成通用的**：
   - 新建 `eda/wqeda/gen/board.py`，把 `factory/designs/tools/pcb.py` 和 `build.py` 里与驱动板无关的部分搬过来：板框、摆放、孔、铺铜、网络分类、Freerouting 的规则与禁布区、导入布线结果。
   - `build.py` 改成调用它，命令和产物位置不变，电子会话照常用。
   - **验收**：A、B 两版重新生成，原理图、物料清单、坐标、网表与现有产物一字不差；布线结果照第 102 轮的做法核对（DRC 0 错误、0 未连接，段数和过孔数只看量级，Freerouting 每次结果不完全一样）。
2. **布局约束（L4 `constraints`）**，第一版五种：
   - `loop`：功率回路。列出回路上的器件和网络（如上管、下管、母线电容），查焊盘围成的面积和最长边，不超过限值。
   - `kelvin`：开尔文采样。采样电阻两端的采样线必须从焊盘单独引出，不能和功率电流共用一段铜。
   - `near`：靠近。去耦电容离芯片电源脚不超过限值。
   - `apart`：远离。发热件和怕热件（电解电容、晶振、采样运放）之间不小于限值。
   - `edge`：接插件放在板边，朝外。
   
   每条约束的限值都是**设计规则**，要写出处（器件规格书或应用笔记的哪一页）；没有出处的标“示例值”，报告里照样显示出来。不编数。
3. **工艺检查**：在 P1 六项（D1、D2、D4、F1、F3、F5）上补齐第 88 轮的其余规则，全部改成只读板子模型的纯函数：
   - F2 最小线距、F4 阻焊桥、F6 器件外框间距、F7 极性方向统一；
   - T1 ICT 测试点覆盖率；
   - C1 大电流线宽：按 IPC-2221 由电流算出需要的线宽。电流取 L1 规格里的峰值相电流，这样规格改了，板子检查会跟着变。
   
   光绘里没有的信息（例如器件外框），这一项从光绘那条路判“未知”，不判通过。KiCad 自己的 DRC 结果作为一项收进报告（只有 KiCad 那条路有）。
4. **热分两步**：
   - **损耗**：每个功率器件的导通损耗（I²·Rds(on)）和开关损耗，由 P2 计算器按规格和器件数据算，写进计算书。器件数据没核对的，损耗照算，结论记“待核对”。
   - **温升**：用 CalculiX 把布好线的板子当成一块平板来算：
     - 铜层按铺铜面积折成等效导热；
     - 损耗放在功率器件焊盘处；
     - 两面对流换热，系数是假设值，报告里写明，可以改。
   
   得出板温，再算结温 = 板温 + 损耗 × 结到板热阻，和器件允许的最高结温比较。
   
   **标准题**：均匀发热平板对流、点热源大平板，两道和公式对照，误差不超过 5%。
5. **读回**：`python3 -m wqeda.readback <板子.kicad_pcb> <design.yaml>`：
   - 比对摆放（位置、转角、正反面）、孔、铺铜，列出变化，并写出一份新的设计描述（L4 换成板子上的值）；
   - 原理图和网络的改动这一期不读回，查到网表和设计描述不一致，就列成“不一致”，请人回到设计描述里改；
   - 布线结果不写进设计描述，仍留在 KiCad 文件里，设计描述只记它的指纹。
6. **一份报告**：`python3 -m wqeda.report <设计或变体> --factory <工艺能力表> --out <目录>`，出网页和 Markdown 两种：
   - 三章：电气（P2 计算书）、工艺（含布局约束）、热；
   - 开头统计四种结论，每一项都有“为什么”和出处；
   - 驱动板 A、B、24 V 三份放进仓库。
7. **判定不经过 AI**：这一期新增的检查、热、读回全是确定性代码，`test_purity.py` 把它们都纳入。这一期 AI 不新增功能（见第七节 Q1）。
8. **和电子会话的分工**：电子会话正在改 B 版（第 110 轮加抱闸，改 `drv-joint-b/variant.yaml`）。我只改生成和检查的程序，不改两版的设计内容。第 110 轮合并后再做 B 版的一字不差核对，避免两边同时改同一批文件。抱闸以后可以做成第十种功能单元，不在这一期。

## 六、风险

- **Freerouting 每次结果不完全一样**：只核对 DRC 和量级，不要求布线一字不差（P1 已是这样）。
- **CalculiX 平板模型是简化**：没有算器件本体、过孔导热、外壳。报告里写明这一点，只作为布局阶段的估算，不替代样板实测。
- **约束的限值**：很多是经验值，找不到出处的会标很多“示例值”。这是如实标注，不是缺陷。
- **和电子会话撞文件**：按第二节第 8 条错开。
