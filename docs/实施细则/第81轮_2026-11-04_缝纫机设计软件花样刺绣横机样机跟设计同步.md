## 二、决定（建议）

**共同做法**（同平缝机、绷缝机）：网关的计算结果里带一条“动作轨迹”给样机页面（计算核心算好：每一针 / 每一趟的位置、速度、是否出问题），页面照着走；设计参数一改，样机马上换成新的轨迹。出问题的部件标红，右上角给判定，“慢放到出问题的那一针（那一趟）”一键跳过去。页面里不另写公式，数全由计算核心给（和计算书、校核同一份）。轨迹太长时抽样（每条最多几千个点），读数照原值。

1. **电子花样机（模型 15-1）**
   - 模板上画这台设计的花样（内置花样或上传的 CSV 针位表），工作台按每一针的前瞻转速和运动规律走，主轴转速跟着变；针距、转速、运动规律改了，走法跟着变。
   - 标红：机针在布外窗口走不完（针扎下时工作台还在动）——机针和工作台标红，停在最紧的那一针；X / Y 电机峰值转矩、发热、转速——那台电机标红；同步带共振、弹性变形——那根带标红；花样超出工作台行程——压框标红；设计转速超机头——机头标红。
   - 读数：第几针、这一针的转速、X / Y 速度。
2. **多头刺绣机——新做三维模型 16-1**，放进教材第 16 章（中英文），“样机”页签用它，实验 16-1 保留为第二视图（同绷缝机的切换）：
   - 一排机头（按“头数”，多了就画前几个、其余示意）、横梁、绷架（X / Y 两向伺服、同步带）、每头一个绣框；绣框里按这台设计的花样文件（或示例 logo）一针一针绣出来，换色、跳步照文件。
   - 绷架按每针的转速和针长走；最长针那几针放慢、用颜色标出。
   - 标红：最长针在窗口里走不完（所需加速度超过驱动力给的）——绷架和那一针标红，停在那一针；转速超机头——机头标红；单针超过 DST 记录上限——那一针标红。
   - 读数：第几针、针长、转速、绷架加速度（所需 / 可用）。
3. **电脑横机（模型 17-1）**
   - 针床宽、系统数（三角座个数）、机号（针距）跟设计；机头按这张意匠图编出来的逐趟动作走：每趟的宽度、速度、换向停顿、翻针趟、摇床（后针床横移），没传意匠图时按教材 17.8 节算例的趟。
   - 标红：选针时间不够、选针位置误差超差——选针器标红；摇床在换向停顿里走不完——后针床标红，停在那一趟；急停距离不够——机头在针床端标红；织物放不下针床——织物标红；机头电机峰值、发热、转速——电机标红。
   - 读数：第几趟（编织 / 翻针 / 空行）、机头速度、这一趟用时、累计用时。
4. **网关**：三种机型的计算结果 `view` 改成同步方式（`setCfg`，带轨迹）；刺绣机的 `view` 换成新模型、`alt` 是实验 16-1；网关允许新页面。
5. **教材**：第 16 章加“三维模型 16-1　多头刺绣机”一段和引用；第 15、17 章的模型说明加一句“在设计软件里跟着设计参数走”；资源列表、课程包实验指导（M16-1）同第 73 轮做法。
6. **帮助**：“七个页签”里的样机一段改写；案例四（花样机）、案例五（横机）、案例七（刺绣机）各加一步“在样机里看出问题的那一针 / 那一趟”，配截图（不重录屏）。
7. **不做**：包缝机同步（见 Q3）；这三种机型的讲解片、三维零件（另做）。
