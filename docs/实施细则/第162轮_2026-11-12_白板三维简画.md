# 实施细则 · 第 162 轮：白板三维简画——人物、场景、讲故事

日期：2026-11-12
依据：Eddie 11-12：“那个白板软件可否也增加三维简画功能，出独特的三维动画”；看了第一版草案（以机构、零件为主）后：“我要人物画，场景，模拟一些工作场景。讲故事。你说的哪些我们有专业的软件”。
状态：**待 Eddie 确认**（第七节）

## 一、定位：只做专业软件不做的

| 要画的 | 用什么（已有，不重做） |
|---|---|
| 机构、零件、齿轮、机械臂运动 | 三维模型与 Blender 视频（第 36–38 轮）、`wq3d.js`、缝纫机设计软件、Manim 动画 |
| 公式、曲线、概念推导 | Manim（3Blue1Brown 风格） |
| 真实工厂、真实界面 | 数字工厂录屏、网页课件 |
| **人物在场景里做事、讲一个工作中的故事** | **本轮：白板三维简画** |

白板现在能画平面的方框、字和简笔图标，画不了“人”在“地方”里“做事”。本轮让白板讲故事：手绘风格的三维小人在三维场景里走动、操作、交谈，镜头像拍短片一样推、拉、摇、切。

## 二、决定

| 编号 | 决定 |
|---|---|
| S-1 | **人物**：手绘线条的三维小人（问渠自己画的原创形象，不仿任何已有卡通人物）。身体有关节，能摆姿势、走、做动作；脸是简笔表情（高兴、疑惑、着急、恍然大悟）。几种角色靠衣着和道具区分：工人（工装、安全帽）、工程师（工牌、图纸）、质检员（卡尺）、班组长（对讲机）、销售、客户、老师、学生；男女、高矮、肤色发型可选 |
| S-2 | **动作库**：走到某处、站、坐、转身、指、举手、点头、摇头、交谈（手势）、打电话、敲键盘、看屏幕、搬箱子、推小车、拧螺丝、操作机床、量尺寸、翻文件、在白板上写、握手、鼓掌。动作之间自动平滑过渡；走路按地面路线走，不穿墙 |
| S-3 | **场景**：几种现成场景，三维的、手绘线画：**车间**（机床、工作台、物料架、流水线、叉车）、**装配线**、**仓库**、**质检室**、**办公室**（工位、电脑、打印机）、**会议室**（长桌、投影）、**教室 / 实验室**、**客户现场**；外加生活场景（家里、街道、超市）。场景里的东西可以搬、可以加；也能放机器人（协作机械臂、搬运小车）当角色 |
| S-4 | **讲故事的镜头**：一个故事分几个镜头；每个镜头有机位和镜头运动（推近、拉远、横摇、绕着转、跟着人走、切到另一个镜头）。说话用手绘对话气泡，也可以只配旁白。镜头里可以插“画面中画”：人看的屏幕上放我们的数字工厂录屏或虚拟实验 |
| S-5 | **画风统一**：所有东西用白板同一套手绘线（rough.js）画出来；新镜头开头可以像现在一样一笔一笔画出场景和人，再开始动（也可以直接出现，节奏快时用）；人和东西转动时线条稳定不乱抖 |
| S-6 | **AI 原生**：老师给一句题目或一段要求（例：“一个新来的质检员第一天发现一批针杆超差，怎么追到原因”），AI 写故事和分镜：角色、场景、每个镜头谁在哪、做什么、说什么、镜头怎么动，配音后自动做成片。老师可以在编辑器里改台词、换角色和场景、拖人换位置、调机位，或者跟 AI 说一句意见让它重排 |
| S-7 | **和现有白板课混用**：一节白板课里可以一段平面板书、一段三维小故事；也可以整节都是故事。网页版和 MP4 都照现有方式出 |
| S-8 | **自己写，不加新的商用依赖**：三维计算和投影用自己的小段代码或已在仓库里的 three.js（MIT）；人物骨架、动作库、场景都是本项目自己画、自己写，可商用 |

## 三、规则

1. 只往后加：现有白板课、平面元素、已做好的课都不受影响。
2. 人物一律原创，不画真人、不画已有卡通形象，不出现品牌。
3. 故事以工作场景为主（工厂、机器人、质检、销售、研发），每门课保留一个生活例子（课程标准）。
4. 出视频速度：1280×720 每帧不超过 0.15 秒；超了就减少细节（斜线、背景物件）再录。

**第一步样片（给 Eddie 看，约 1 分半，中文）：《一批超差的针杆》**——缝纫机厂车间：
1. 镜头从车间全景推近质检室：质检员量针杆，皱眉（尺寸超差）；
2. 她拿着零件走到机加工位，和工人、班组长交谈；工人指机床；
3. 镜头绕到机床旁：工程师看电脑屏幕（屏幕里放数字工厂的 SPC 图录屏），恍然大悟（刀具磨损）；
4. 换刀、重新量，合格，三人点头；
5. 结尾一个生活例子镜头：家里有人用缝纫机，针走得顺。

## 六、风险

- 人物动作是这轮最难的部分：先用简单骨架 + 关键姿势插值，走路、搬东西这类常用动作手调到自然；样片里不自然的动作先换成简单动作，不硬上。
- 场景物件多时逐帧录制会慢：按第三节第 4 条减细节。
