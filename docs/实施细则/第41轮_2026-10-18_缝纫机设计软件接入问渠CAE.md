## 二、决定（建议）

### 1. 通道：学习平台网关 → 数字工厂枢纽 → 计算服务

- 枢纽加一组“设计软件接口”`/api/design-sw/*`，只认学习平台网关带的服务钥匙（新配置 `factory_cae_key`），不对外开放；枢纽再把任务交给已有的 cae 计算服务排队。
- 任务记在“企业单位 + 提交人”名下（单位用第 39 轮开通时填的单位名）；计算服务里登记为一个单独的工厂编号 `wq_sewing_saas`，不和教学工厂混在一起。
- 结果（数值、云图、Word 报告）回到缝纫机设计页的新页签“CAE 分析”里看；需要完整三维云图时“在数字工厂里打开”。
- 这要改《数字工厂资源接口约定》第一节第 4 条“学习平台只读，不写回数字工厂”：加一条例外——**设计软件可以提交计算任务**（只提交计算，不改零件库、不改生产数据）。国内部署同样走自己的服务器。

### 2. 每种 CAE 在缝纫机软件里做什么（第一批）

| CAE | 用法 | 结果回到哪 |
|---|---|---|
| **有限元强度 + 疲劳** | 选一个关键零件（平缝机：针杆曲柄、针杆连杆、挑线杆、挑线摇杆；包缝机：下弯针摆杆、球头连杆、引针连杆）和材料，一键送分析。几何用本软件生成的 STEP；约束、载荷自动加（轴孔为支承、销孔加力），载荷用本软件算出的一转内的惯性力曲线；疲劳按“每转一个循环 × 转速 × 每天开机小时”算寿命 | 校核表新增“强度安全系数”“疲劳寿命（年）”两项，判据：安全系数 ≥ 2、寿命 ≥ 5 年（每天 16 小时） |
| **模态分析** | ① 企业上传自己的机壳 STEP（选固定面）→ 算一阶固有频率，自动回填参数“机壳一阶固有频率”，共振校核改用实算值；② 针杆、下弯针摆杆的固有频率核高速共振 | 共振校核标注“实算” |
| **多体动力学 + 电机选型** | 按设计尺寸生成整套机构模型（平缝机：刺布曲柄滑块、挑线四杆、送布；包缝机：两套 RSSR、引针），算一转内各铰链力、主轴所需转矩和功率；用数字工厂的电机选型库选主轴伺服；轴承受力给出轴承寿命 | 新增“主轴电机选型”结果和“铰链力 / 主轴转矩”曲线；与本软件的解析结果对照，差别大时提示 |
| **设计优化** | 选目标和约束（例：挑线余量 ≥ 1 mm 时传动角最大；整机惯性力最小找平衡率；下弯针摆角 25–30° 时传动角最大），自动改参数试几十到几百次，给出最好的几组，一键回填 | 方案对比表，点“采用”回填参数 |

只用本软件公式就能算的优化（秒级）在网关里直接算，不占计算服务；要用到有限元的（例如“连杆最轻且安全系数 ≥ 2”）才送计算服务。

### 3. 第二批（同一轮，做完第一批再做）

| CAE | 用法 |
|---|---|
| **拓扑优化** | 平板零件（曲柄、摆杆）在载荷下找材料该留在哪 → 减重后的轮廓回到 DXF、STEP |
| **CAM** | 平板零件出铣削 / 线切割程序，偏心轮出车削程序，在数字工厂里试切 |
| **三维仿真视频** | 按设计尺寸一键出机构讲解片（第 38 轮的服务） |
| **提交到问渠工厂** | 网页版也能把整套零件送数字工厂设计审批（FreeCAD 已有） |

热分析和流体分析在第 42 轮花样机、刺绣机的电控箱、伺服电机上用。

### 4. 谁能用、用多少

- 来宾不能用 CAE；企业开通后才能用。
- 计算服务一次只算一个任务，大家排队；每个单位每天最多 20 个有限元 / 模态 / 动力学任务、5 个要用有限元的优化任务（数字可在后台改）。只用本软件公式的优化不限次数。

## 四、施工顺序与验收

1. 枢纽接口 + 网关通道：本地起数字工厂计算服务，网关提交一个有限元任务，排队、算完、取回结果。
2. 有限元 + 疲劳：平缝机针杆连杆在 6000 r/min（941 N）下的安全系数和寿命，与手算（连杆截面应力）同一量级；载荷、约束自动加对（截图核对）。
3. 模态：上传一个示例机壳，回填固有频率后共振校核跟着变。
4. 多体动力学：平缝机刺布机构的铰链力与本软件解析的惯性力一致（误差 < 5%）；主轴电机选型给出结果。
5. 优化：挑线机构、平衡率、下弯针三个例子各跑一次，最优解回填后校核全绿。
6. 第二批四项各走一遍。
7. 网页三种机型都走一遍，中英文都看；本地完整环境走一遍后推送，跟踪学习平台和数字工厂两边的部署。
