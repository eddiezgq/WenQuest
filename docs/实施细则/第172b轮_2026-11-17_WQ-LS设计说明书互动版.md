# 实施细则 · 第 172b 轮：WQ-LS 设计说明书改成网页教材风格（互动版）

日期：2026-11-17
依据：Eddie 11-17 22:32 看了第 172 轮上线的说明书：“这种说明书不是我们网页教材的风格，缺少动画，视频，交互，一点不震撼和显示水平”。
状态：**待 Eddie 确认**。

## 一、问题

第 172 轮做成的是“文档站”：原文排版、加目录和搜索。设计里本来就有的会动的东西（98 个零件每 2° 的运动、挑线四连杆、19 步装配、有限元结果、数控刀路、伺服仿真）一样都没在说明书里动起来，只剩静态图。

## 二、决定

| 编号 | 决定 |
|---|---|
| D-1 | **版面照《缝纫机设计与制造》网页版**：同一套颜色（针蓝、梭橙）、字体、章首、插图框、“动画 / 虚拟实验 / 三维模型”块（在本页运行、新窗口打开、全屏），浅色、深色两套。网址不变（`/wqls/spec/`），第 172 轮的目录导航、搜索、原文全文都保留 |
| D-2 | **首页是一台活的整机**：整页三维 WQ-LS 慢慢转着缝，零件按部件依次爆炸再合拢，叠一排大数字（5000 r/min、98 个零件、8 种变型、10 关、挑线量 88.7 mm…，数字从设计数据读，不手写）；往下是十关的卡片，每张卡片带一段会动的预览 |
| D-3 | **每关一个章首**：一句话说这一关解决了什么、3–4 个大数字结论、一个活的主图；下面是原文全文，互动块插在原文对应那一节的位置 |
| D-4 | **互动块（全部用设计程序算出的真数据，不手画）**，共 14 个，见第三节 |
| D-5 | **视频**：原有 5 段一转动画（刺布挑线、旋梭、送布、压脚、剪线）放进对应章节；另做一段**总览讲解视频**（约 3 分钟，“网页版 PPT + 真页面录屏”，AI 配音 kokoro，中英字幕），放首页。各关单独的讲解视频以后另开一轮 |
| D-6 | **中英**：页面框架、章首、大数字、互动块的标签和图注做中英对照；原文正文仍是中文（全文翻译以后另开一轮） |
| D-8 | **整机虚拟样机**（Eddie 11-17 22:38 “整体样机呢”）：说明书的核心是一台能“缝”的 WQ-LS 虚拟样机（第三节互动块 0），首页一打开就是它，各关的互动块都是它的局部。G8.1 第四、五步（动力学、有限元疲劳、虚拟样机验证）做完后，结果直接接进这台样机 |
| D-7 | **数据与原文一致**：互动块读的数据由 `spec_web.py` 从设计结果文件（`G8.1_运动学.json`、`挑线机构.json`、`machine.json`、`frames.bin`、`assembly`、有限元结果、`.nc` 程序等）打包；第 172 轮的一致性测试扩到这些数据 |
