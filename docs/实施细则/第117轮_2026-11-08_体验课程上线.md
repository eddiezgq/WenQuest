## 三、每门体验课里有什么（待确认）

- **课程说明**（第 0 节）：本书简介（`book.yaml` 的介绍）、适用专业、全书章目、怎么用（网页版、互动课件、虚拟实验、AI 助教）、“供体验、不计成绩”。
- **每章一节**，节里依次放：
  1. **本章导读**（页面）：本章各节标题；还在写的节标“编写中”。
  2. **网页版教材 · 第 N 章**（链接，打开平台教材页这一章）。
  3. **互动课件 · 第 N 章**（链接；这一章有课件才放）。
  4. **虚拟实验**（链接，每个实验一条；这一章有实验才放）。
  5. **本章 PDF**（链接）。
- 本轮不做每章测验（教材习题还没有标准答案库）；以后有了再加。

## 四、交付物

1. `textbook/tools/bookcourse.py`：读一本书的构建产物（`web/index.json`、课件、实验），写 `textbook/build/<书>/course/manifest.json`（课程包格式，`course_pack.py` 直接认）。教材构建（`build.py`）末尾调用。
2. 网关 `course_pack.py`：`POST /api/v1/admin/course-packs/publish-all`（依次发布每个课程包的每一批，已发布的跳过）；体验课发布后在目录里标“免费”（已有）。
3. 学习平台“管理 → 课程包”：“全部发布”按钮；体验课显示在课程包列表里。
4. 测试：`bookcourse.py` 对一本小书的产物生成清单并校验结构；网关 publish-all 用假 Moodle 走一遍。
5. 帮助《体验课程》（管理员怎么一键发布、老师和企业怎么加入）。

## 五、施工顺序与验收

`bookcourse.py` 与测试 → 网关 publish-all → 管理页按钮 → 本机完整环境：生成一本书的体验课、点“全部发布”、学生账号在课程目录里看到并加入、点开各链接 → 推送、部署（按增量）→ Eddie 在国内、美国各点一次“全部发布” → 国内用体验单位账号看课程目录验收。

## 七、施工记录（2026-11-08）

偏差（已按此做，写回这里）：
1. **清单不在构建时写，由网关当场生成**（`services/gateway/app/bookcourse.py`）：互动课件是教材构建之后另一步构建的，构建时写清单会漏掉课件；网关按服务器上已部署的教材生成，教材更新部署后自动跟着变。所以没有 `textbook/tools/bookcourse.py`。
2. **去掉“本章 PDF”链接**：PDF 接口要登录口令，课程里的链接直接打开会被拒；PDF 在网页版教材页上“下载 PDF”。
3. 本章导读页记的是发布那一刻的各节标题；网页版教材、课件、实验链接永远是最新内容。整章还没写的先按“建设中”大纲发布，写好后再按“全部发布”会换成完整的一节（课程包原有机制）。
4. 实验、章名太长会超过 Moodle 活动名上限（中英合起来 255 字），只取第一个分句（本机发布《数字集成电路设计》时踩到）。

| 交付物 | 做了什么 |
|---|---|
| 网关 `bookcourse.py` | 每本已部署教材生成课程包清单：第 1 节课程说明（供体验、不计成绩、章目），每章一节：本章导读、网页版教材（指到本章第一个写好的节）、互动课件（有才放）、虚拟实验（指到所在小节）；名字中英双语。 |
| 网关 `course_pack.py` | 课程包列表 = 现成课程包 + 各本教材体验课；`POST /api/v1/admin/course-packs/publish-all` 一本接一本发完全部批次，已发布的跳过、中断后再按接着发；发布后目录里“免费”。 |
| 学习平台 | “管理 → 课程包”顶上“全部发布”按钮；教材页认 `slides=<章>`（体验课里的“互动课件”链接直接跳到这一章课件）；没登录时登录后回到原来那一节。 |
| 测试 | `tests/test_bookcourse.py`（清单结构、空章不建、没写完的章当大纲、课件有才放、全部发布两本、再按不重复、学生不能按）。 |
| 帮助 | 《体验课程》。 |
