## 一、定位

- **名字**：问渠凸轮（WenQuest Cam）。
- **用户**：缝纫机、包装机、纺织机、印刷机、自动化装配线、发动机配气等用凸轮的企业的设计工程师和工艺、质检人员；学校里《机械原理》《机械设计》的凸轮一章也能用（教学版免费）。
- **一条线做完**：运动要求 → 运动规律 → 凸轮廓线 → 校核（压力角、曲率、接触应力、高速跳离）→ 计算书 → 加工程序（磨削、铣削）→ 实测廓线 → 误差分析 → 补偿后再加工。
- **和通用 CAD 的区别**：
  - 通用 CAD 能画凸轮，但不管“这条曲线在 5000 r/min 下会不会跳、会不会磨坏”；我们从运动要求出发，校核全做，**结果能写进计算书**；
  - 加工后测出来的误差能拿回来算：几个微米的廓线误差在高速下变成多大的加速度误差，补偿磨削能修掉哪些阶次，修完还剩多少；
  - 和平台贯通：计算书和加工程序可以进数字主线审批，批准后随工单派到车间（第 33 轮的集成平台）。

## 二、覆盖的凸轮与从动件

| 类别 | 内容 |
| --- | --- |
| 盘形凸轮 | 直动从动件（对心、偏置）、摆动从动件；滚子、平底、尖顶；外廓凸轮、力封闭（弹簧） |
| 槽凸轮 | 形封闭：内外两侧廓线、滚子与槽的间隙；挑线、送布凸轮的典型形式 |
| 共轭凸轮 | 两片盘形凸轮共同驱动一个从动件（第二版视需要；内核预留） |
| 圆柱凸轮 | 圆柱面上的槽，直动或摆动从动件；滚子用圆柱或锥形 |
| 弧面分度凸轮 | 弧面凸轮 + 滚子转盘的间歇分度机构：工位数、分度角 / 停歇角、中心距、滚子尺寸；空间包络求齿面 |

运动规律：等速、等加速等减速、简谐、摆线、修正梯形、修正正弦、修正等速、3-4-5 次多项式、4-5-6-7 次多项式、B 样条与用户点表（含电子凸轮表导入）。一个“运动程序”由多段（升、停、回、停）拼成，代码检查段与段之间位移、速度、加速度是否连续，不连续的地方标出来。

## 三、功能

### 1. 设计

- **运动程序编辑**：表格 + 曲线上直接拖；每段选运动规律；显示位移 s、速度 v、加速度 a、跃度 j 四条曲线和无量纲系数（Cv、Ca、Cj）。
- **机构参数**：基圆半径、偏距、滚子半径、摆杆长度和中心距、转速、从动件当量质量、弹簧刚度和预紧、工作载荷、材料（许用接触应力由企业填，或引用标明出处的数据，不编）。
- **廓线生成**：理论廓线（滚子中心轨迹）、实际廓线（等距线）；槽凸轮两侧；圆柱凸轮槽的两侧面；弧面凸轮的齿面（包络）。
- **校核**（全部由代码算，结果是 合格 / 不合格 / 未知，缺数据就是“未知”，不算合格）：
  - 压力角：全程最大值与企业给的许用值比；
  - 曲率：实际廓线最小曲率半径与滚子半径比，查根切和变尖；
  - 接触应力：赫兹线接触，载荷 = 工作载荷 + 弹簧力 + 惯性力；
  - 高速跳离：力封闭凸轮在给定转速下弹簧力是否始终压得住，算出不跳离的最高转速；
  - 凸轮轴驱动力矩曲线和峰值；
  - 弧面分度凸轮：分度时间内转盘的角速度、角加速度，滚子与齿面接触、压力角、干涉检查。
- **最小基圆搜索**：给许用压力角和最小曲率半径，求最小基圆半径（或中心距）。
- **动画**：凸轮转、从动件动，当前位置的压力角、受力箭头实时显示；空间凸轮用三维视图。
- **计算书**：所有输入、公式出处、曲线、校核结论和版本号；第一版在浏览器里排好版，用“打印 / 存为 PDF”导出（不在服务器上装中文字体和排版库），以后需要时再改服务器出 PDF；可提交数字主线审批。

### 2. 制造

- **刀具轨迹**：砂轮或铣刀中心轨迹（按刀具半径做等距），按弦高误差自动布点；槽凸轮两侧分别加工或用小于槽宽的刀走两刀；圆柱凸轮和弧面凸轮用四轴（旋转轴 + 直线轴）轨迹。
- **加工程序**：
  - 凸轮磨床：X–C 极坐标程序（FANUC 风格），砂轮半径修整后可更新；
  - 加工中心：平面铣削 XY 程序；四轴的圆柱、弧面凸轮程序；
  - 慢走丝：DXF 或点表；
  - 程序先在网页里仿真走一遍，查过切、欠切，再导出。机床参数按企业设备配置。
- **三维模型**：两种，各管一件事。
  - **设计模型（直接建模）**：盘形、槽、圆柱凸轮由公式算出理论廓线或槽面，拟合成 B 样条曲面再成实体，导出 STEP；拟合后逐点查偏差，超过公差就加密重拟。它是图纸、计算书和给企业 CAD 用的名义几何。
  - **弧面分度凸轮的设计模型按加工方法生成**：齿面是滚子空间运动的包络面，公式求再拟合不稳；改为让与滚子同尺寸的刀具按分度运动规律相对毛坯运动，扫出齿面，和实际加工同一原理。再在若干截面上用包络方程抽查（接触点公法线与相对速度垂直），写进标准题。
  - **加工模型（按程序切出来）**：用实际加工程序让刀具或砂轮沿刀心轨迹扫过毛坯，得到机床真正会做出的形状（刀具半径、布点、补偿量、修整后砂轮半径都在里面）；与设计模型对比，着色标出过切、欠切、残留和最大偏差所在转角。这就是“程序仿真”。
- **实测误差与补偿**：
  - 导入凸轮测量仪或三坐标的结果（升程-转角表，或 XY 点）；自动对相位、对基圆；
  - 误差曲线和谐波分解：一阶偏心、热处理变形的低阶、机床和颤振的高阶各占多少；
  - 加速度误差：误差曲线二阶导数 × ω²，在各转速下算峰值，给出“误差不超过多少才能跑到多少转”；
  - 补偿：按选定的阶次范围生成反向修正后的磨削程序，预测补偿后剩余误差；砂轮修整后半径不更新带来的误差单独算出来；
  - 每次测量和补偿留记录，同一批凸轮可以看趋势。

### 3. AI 帮什么

- 把一句话的要求变成运动程序草稿，例如“挑线杆在 0–120° 提升 18 mm，170–200° 停住等钩线”；AI 只写数据，代码检查连续性和可行性，人确认后才用。
- 解释校核结果：哪一段压力角超了，改基圆还是改运动规律，各自代价是什么。
- 起草计算书里的文字说明。
- 合规：国内部署用已备案模型（DeepSeek），美国用 Claude。AI 不算数，不判合格。

**标准题对照**：每个模块都带标准题，和教材公式或文献例题对照，测试里写明出处。例如各运动规律的最大速度、加速度系数和闭式解比；偏置直动滚子凸轮的压力角、曲率半径和解析式比；赫兹接触应力和手算比；数值包络得到的弧面凸轮齿面，检查每个接触点的公法线与相对速度垂直；误差补偿用已知谐波的合成误差检验能否按阶次复原。

**样例项目**（虚构参数，标明“示例”）：平缝机挑线槽凸轮、送布凸轮、包装机直动盘形凸轮、八工位弧面分度凸轮。

## 四之三、开源与商业软件调研（Eddie 23:17：“有没有高水平开源的软件”）

结论：**凸轮设计没有高水平的开源软件**，现有的都是个人或课程项目，只覆盖盘形凸轮的入门部分；空间凸轮、弧面分度凸轮、高速动力学、加工程序、误差补偿都没有。所以内核自己写，现成的开源项目只拿来做交叉对照。

| 项目 | 内容 | 许可证 | 我们怎么用 |
| --- | --- | --- | --- |
| `mechanism`（GitHub gabemorris12，PyPI） | 等速、简谐、摆线三种规律；按许用压力角求基圆；平底从动件求基圆和面宽；廓线点、SVAJ 图、动画 | MIT | 基础算例交叉对照 |
| `pylinkage` 的凸轮模块 | 简谐、摆线、修正梯形、3-4-5、4-5-6-7；直动和摆动，尖顶和滚子；压力角；点表样条 | 待核对 | 交叉对照（许可证核实前不复制代码） |
| 3DCamFollower（Cheng 等，ACM TOG / SIGGRAPH Asia 2021） | 研究代码：复合凸轮-从动件机构按给定轨迹和时序做空间运动 | MIT | 参考思路，不直接用 |
| 其他（CamFollowerJS、各类课程作业） | 盘形凸轮演示 | 不一 | 不用 |

商业软件作为对标：Norton 的 **DYNACAM**（designofmachinery.com，用户手册公开）、SolidWorks 合作伙伴插件 **CamTrax64**。它们的功能清单用来检查我们有没有漏项。

能用的开源**基础设施**：
- **几何与 STEP**：OpenCascade（Python 绑定 pythonocc-core，LGPL）；FreeCAD 本身（LGPL，FreeCAD 工作台直接用）。
- **刀路仿真**：OpenCAMLib（LGPL）可作为第 3 步“按程序切出来”的备选；FreeCAD 的 CAM 工作台有后处理器框架，可参考程序格式。
- **计算与界面**：NumPy / SciPy（BSD）；three.js（MIT）。

许可证都在采用前逐个核实，只用允许商用的；LGPL 组件作为库调用，不改其源码。

## 五、规则

1. 计算和合格判定全部由确定性代码完成；AI 只写数据、解释和起草文字。
2. 缺数据就是“未知”，不算合格；不编材料数据、许用值和厂家参数，企业填或引用标明出处的资料。
3. 内部统一单位（mm、rad、s、N、MPa），界面可显示角度和 r/min；单位换算只在输入输出处做。
4. 每个计算模块带标准题；不合格的提交不进 main。
5. 开源组件只用许可证允许商用的；几何内核作为服务器上的库调用。

### 第 3 步施工细节（2026-10-18，开工前写定）

Eddie 11:50“继续”。第 3 步按第三节第 2 小节做，盘形凸轮和槽凸轮（圆柱、弧面凸轮的四轴程序在第 4 步）。具体做法：

**1. 刀具轨迹**（`camkit/mfg.py`）
- 刀心轨迹 = 加工面沿法向等距一个刀具半径：外廓凸轮刀在外侧；槽凸轮内侧壁、外侧壁各一条（刀具半径必须不大于滚子半径；等于时两条重合，走一刀）。
- 过切检查：加工面凹处（曲率中心在刀具一侧）的曲率半径必须大于刀具半径，否则判“不合格”，并给出最小凹曲率半径和所在转角。磨削用大砂轮时这一项最要紧。
- 按弦高误差布点：在密集采样的刀心轨迹上贪心取点，使相邻两点之间按机床实际插补方式（X–C 是 X 与 C 线性插补，XY 是直线）走出来的轨迹与理论刀心轨迹的偏差不超过弦高公差。

**2. 加工程序**（FANUC 风格，机床参数做成可改的设置，默认值标“示例，按企业设备改”）
- 凸轮磨床 X–C：砂轮中心在 X 轴上，凸轮随 C 轴转；X 可选半径值或直径值；G93 反比时间进给，按 C 轴转速算每段时间；多遍磨削（每遍留量）加光磨圈数。刀心轨迹对凸轮中心不是“星形”（极角不单调）时不能用 X–C，提示改用铣削。
- 加工中心 XY：刀心坐标编程（不用 G41/G42），默认顺铣（外廓顺时针、槽外侧壁逆时针），分层下刀；槽内下刀写注释“预钻孔或螺旋下刀，按本厂工艺”，不替企业定。
- 慢走丝：DXF（R12，多段线，弦高公差布点）和点表 CSV（转角、x、y、半径）。

**3. 程序仿真（加工模型，二维）**
- 独立解析导出的程序文本（不用生成程序时的中间数据），按机床插补把每段细分，让刀具圆扫过毛坯，沿每个转角方向求剩下的材料边界；与设计廓线比，给出每度的法向偏差（正 = 欠切、多肉，负 = 过切），最大过切、最大欠切和所在转角。
- 判定：仿真偏差不超过“弦高公差 + 0.1 μm”为合格，说明程序本身没问题；零件公差由企业自己定，不在这里判。

**4. 三维模型 STEP**（`camkit/step.py`，纯 Python 写 AP214，不装几何内核）
- 廓线用周期三次 B 样条插值，逐点查拟合偏差（取相邻插值点中间的点与精确廓线比），超过 0.5 μm 就加密重拟。
- 外廓凸轮：B 样条廓线拉伸成实体，厚度 = 接触宽度。槽凸轮：圆盘毛坯铣出一条槽，槽深 = 接触宽度，盘厚和毛坯半径必须由用户填（不猜）。不做轴孔和键槽（没有数据就不画）。
- 本地用 OpenCASCADE（OCP）读回、做实体检查和体积对照，写进验收；线上不装 OCP。

**5. 实测误差与补偿**（`camkit/measure.py`）
- 导入：升程–转角表（用与设计相同的从动件，或测量仪设成相同的滚子半径和偏距测得），或廓线 XY 点（只对外廓 / 槽内侧壁）。XY 点按法向偏差 δn 换算成升程误差：直动 δs = δn / cos φ，摆动 δψ = δn / (L cos φ)。
- 对相位、对基圆：在整圈上搜相位差 Δ 和常数偏移 c 使误差平方和最小；Δ、c 单独报出（c 就是基圆或零点误差）。
- 谐波分解：误差按转角均匀重采样后做 FFT，给出每阶幅值和相位；分组：1 阶（偏心、装夹）、低阶、高阶，分组边界是可改的设置（默认 2–6 阶为低阶）。
- 加速度误差：误差曲线二阶导数（频域求，最高阶数可设，防测量噪声放大）× ω²；给转速就算峰值；给“许用加速度误差”就算“误差不变时最高能跑多少转”，以及该转速下每阶允许的最大幅值 A_k ≤ a / (k²ω²)。没给的项为“未知”。
- 补偿：选要修的阶次范围，把这些阶次的误差反向加到运动程序上（s_补 = s − e_所选阶次），按同样刀具和机床重新生成刀心轨迹和程序；预测补偿后剩余误差 = 没选的阶次 + 程序仿真偏差。
- 砂轮修整后半径不更新：用旧半径的程序、新半径的砂轮做仿真，单独给出由此产生的廓线误差和升程误差。
- 测量与补偿记录先存在项目文件里（每次一条：时间、数据、对齐结果、所选阶次）；云端和多人共用在第 7 步。

**6. 网页**：顶部加“设计 / 制造 / 测量与补偿”三个模式。制造：刀具与机床设置、刀心轨迹和砂轮位置动画、程序文本、仿真偏差图、下载（.nc、.dxf、.csv、.step）。测量与补偿：粘贴或上传测量表（另有“载入合成测量数据（演示）”，明确标注是合成的）、误差曲线、谐波柱状图、加速度误差、补偿程序下载和剩余误差。计算书加“制造”和“测量与补偿”两节（有数据时才出现）。

### 1. 换刀机构这套系统由什么组成

一个工作循环 = 凸轮轴转一圈（示例参数全部虚构，标“示例”）：

| 部分 | 内容 |
| --- | --- |
| 驱动 | 带制动器的电机 → 减速器（蜗杆或齿轮）→ 凸轮轴；每次换刀起动、转一圈、制动停在原位 |
| 弧面分度凸轮 | 装在凸轮轴上，带动输出轴上的滚子盘，使换刀臂转动：转过抓刀角（如 65°）抓住主轴和刀库上的两把刀 → 停（拔刀）→ 转 180° 交换 → 停（插刀）→ 反转回原位 |
| 槽凸轮 + 摆杆 | 同一根凸轮轴上，经摆杆、拨叉推动输出轴上下移动：拔刀（下行，如 115 mm）、插刀（上行） |
| 换刀臂 | 两端刀爪各夹一把刀（BT40 级），臂、刀、输出轴的质量和转动惯量 |
| 时序 | 两个凸轮的运动必须错开：换刀臂转动时轴向必须停在“拔出”或“插入”位；软件按时序图检查 |

### 2. 内核新增“凸轮系统”（`camkit/system.py`）

| 功能 | 做法 |
| --- | --- |
| 分度运动程序 | 允许“净分度”：凸轮轴转一圈，输出转过一个分度角（换刀臂每循环净转 180°），不再要求回到起点 |
| 多凸轮共轴、时序图 | 一根凸轮轴上多个凸轮，统一按凸轮轴转角画机器循环图；用户写联锁条件（“A 运动时 B 必须在某范围内”），代码逐度检查 |
| 驱动链与电机 | 凸轮轴上的等效转动惯量随转角变化 J(θ) = J_轴 + Σ J_输出·ψ′² + Σ m·s′²；凸轮轴转矩 T(θ) = Σ(J_输出·ψ′·ψ″ + m·s′·s″)·ω² + 外载 + 摩擦；加上起动、制动段，算电机峰值和均方根转矩、功率、制动角，按数字工厂的电机库选型 |
| 弹性动力学 | 输出端（换刀臂 + 输出轴 + 凸轮轴扭转）按单 / 两自由度弹性模型，算停歇段的残余振动（刀爪端摆动幅值、衰减时间）和跟随误差；刚度由用户填，或由 CAE 模态、有限元结果回填 |

与本节原定的三处出入：

- **CAE 通道用第 41 轮先建好的**：第 41 轮（缝纫机）先合进 main，按“谁先做谁建”，凸轮改用它的接口（`POST /api/design-sw/jobs` 带 `app=cam`、`kind`），只在上面加两样：按软件分工厂编号（凸轮记在 `wq_cam_saas`），以及上传整机 MJCF 的 `POST /api/design-sw/mbd/model`。接口约定升到 v0.18。改完在本地用真的计算服务把示例从头算了一遍，结果与之前一致。

- **模态不回填**：有限元算出的是换刀臂本身（孔固定）的固有频率，约 790 Hz；系统振动要的是含传动链的整体频率（示例 60 Hz、45 Hz），两者不是一回事，回填会把振动算得过小。所以不回填，网页和计算书里写明区别。
- **“优化后校核全绿”改为“满足用户填的限值”**：电机额定值、许用接触应力这些示例里没填的项，按规则只能是“未知”，搜索不会替用户编数。
