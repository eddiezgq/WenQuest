## 一、这一轮做出什么

第 100 轮的固件只读编码器。这一轮补上驱动板的本职：**磁场定向控制（FOC）带电机转、CAN 收指令发状态、出错保护**，
仍在 Renode 里跑编译出来的真固件，电机、减速器、负载和 CAN 主站都是仿真的：

```
CAN 主站（仿真）⇄ FDCAN1 ⇄ ┌─ 位置环 1 kHz → 速度环 2 kHz → 电流环 20 kHz（FOC）─┐ → TIM1 三相 PWM → 逆变桥 → 电机 → 减速器 1:100 → 负载
                           └──────── ADC 三相电流 ← INA240 ← 2 mΩ 采样电阻 ←─────┘        编码器 ← WQ-ENCIF（第 100 轮）
```

## 二、决定（建议）

| 编号 | 决定 | 理由 |
|---|---|---|
| M-1 | **控制**：电流环 20 kHz（TIM1 中心对齐 PWM 20 kHz，更新时刻触发 ADC 注入组采三相电流，中断里做 Clarke/Park、d/q 两个 PI、反 Park、SVPWM）；速度环 2 kHz、位置环 1 kHz（在电流环中断里分频）；电角度每次中断经 SPI 读 WQ-ENCIF 计数换算；上电先“对零”（d 轴通电流把转子拉到零位，记下编码器偏移） | 伺服驱动的标准结构；学生看得懂一层套一层 |
| M-2 | **CAN（示例协议，1 Mbit/s 经典 CAN，节点号 1）**：主站发 0x201 指令（模式：停 / 速度 / 位置；目标值），驱动板 100 Hz 发 0x181 状态（状态、关节角、速度、q 轴电流、母线电压），出错立即发 0x081 报警（故障码）；0x701 心跳 10 Hz。帧格式写进固件 `can_proto.h` 和页面 | 不套 CANopen 全套，够教学；帧格式一页说得清 |
| M-3 | **保护**：相电流超过 25 A（约 3 倍额定）立即关 PWM（MOE 清零）报“过流”；母线低于 36 V 报“欠压”；编码器芯片报错或不响应报“编码器故障”并停；CAN 指令 100 ms 收不到停机报“通信超时”。故障锁存，主站发“清故障”才恢复 | 驱动板必须有的几条 |
| M-4 | **被控对象（仿真）**：三相永磁同步电机 d/q 模型 + 逆变桥平均模型（48 V 母线、死区按 200 ns 折算）+ 减速器 1:100（Harmonic Drive CSF-17-100，**参数取自零件库**：减速比 100、额定 24 N·m）+ 负载（摆臂：转动惯量与重力矩）。电机用**第 88 轮的示例电机**（额定 1.27 N·m、力矩常数 0.15 N·m/A），零件库里没有的电阻、电感、极对数、转子惯量、摩擦、负载尺寸**一律标“示例值”**，并写明它们彼此自洽（额定电流 ≈ 8.5 A 与板子设计一致；电气时间常数、电流环带宽算给学生看） | 不编数：有库的用库，没有的明示示例 |
| M-5 | **Renode 外设**（C#，地址、偏移、中断号对照 ST 官方 CMSIS 头文件 `stm32g431xx.h` 核对）：TIM1 子集（PSC、ARR、CCR1–3、CR1、DIER、SR、BDTR.MOE，更新中断 25）、ADC1 注入组子集（JDR1–3、ISR.JEOC、IER，中断 18）、FDCAN1 子集（经典 CAN；消息 RAM 按 G4 布局：Rx FIFO0、Tx 缓冲；中断 21）。电机外设把三者和物理模型连在一起；第 100 轮的 WQ-ENCIF 外设改为从电机取位置 | Renode 没有 G4 的这些外设，照第 100 轮自写 |
| M-6 | **场景**（判据都对物理真值）：① 上电对零、CAN 报“就绪”；② 电流环：q 轴 2 A 阶跃，上升时间 ≤ 1 ms、超调 ≤ 10 %；③ 速度环：电机 1500 rpm 阶跃，稳态误差 ≤ 1 %；④ 位置环：CAN 指令关节转 90°，到位误差 ≤ 0.05°、超调 ≤ 2°；⑤ 重力负载下保持位置：摆臂水平，位置误差 ≤ 0.05°；⑥ 保护：注入过流（相间短路）→ 1 个 PWM 周期内关管、CAN 报警；注入编码器芯片不响应 → 停机报警；清故障后能再转 | 覆盖三环、通信、保护 |
| M-7 | **页面**：B 版“固件”标签扩成两部分：“编码器（第 100 轮）”和“电机控制与 CAN（本轮）”；新部分有控制框图、六个场景曲线（电流 / 速度 / 关节角，设定 vs 实际）、CAN 帧记录表（时刻、ID、方向、数据、解释）、示例电机参数表（来源一列写“零件库”或“示例”）；源码、下载包同第 100 轮 | 学生看得到三环和总线 |
| M-8 | 第 100 轮的六个编码器场景保留并照旧通过（固件加了电机控制后重跑）；CI 照旧重新编译、重跑、逐字核对；帮助加一段；freecad-ai-parts 同步 0 差异 | 不倒退 |

## 三、规则

1. 寄存器地址、偏移、位、中断号都对照 ST 官方 CMSIS 头文件核对，注释写寄存器名；测试把固件 `regs.h` 与该头文件里的数逐一比对（头文件不进仓库，测试里记下核对过的数）。
2. 不编数：电机与负载里零件库没有的参数标“示例值”；结果全部由真跑产生。
3. A 版、B 版硬件产物一字不动；页上照旧写“示例固件，仿真验证；芯片未流片、B 版不投产”。
