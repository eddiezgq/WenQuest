## 三、方案

### 3.1 素材接入（地基，其余三样都用它）

1. 网关读取零件库 `latest.json` → `index.json`（接口约定第二节），建课时交给课程设计师和主讲教授：**课程设计书**里写明贯穿全课的机器人和本课程用到的库条目（编号 + 版本）。
2. 写每一课时，AI 从设计书和索引里挑本课要用的条目和工厂数据；**生成前复制一份进这门课**（模型、缩略图、图纸、许可），记入资料清单“来自数字工厂”。
3. 每门课自动生成“素材来源”页（讲义末尾、课件最后一页、视频片尾）。
4. 库未发布前：用数字工厂第 2 轮附录 B 的三个样例（6207 轴承、UR5e、四杆机构）加 MuJoCo Menagerie 里两台机器人，在本地做一个**临时样例库**开发和测试，库上线后切换地址即可。

### 3.2 插图（新角色：插图师）

1. 每课由主讲教授在课时设计里列出 3–6 张插图（用途、要表达什么、放在哪一页）；插图师**用程序画矢量图（SVG）**，不用文生图（保证尺寸、公式、标注准确）。
2. 插图种类与画法：
   - 原理示意、受力图、坐标系与变换、运动学简图 → 插图部件库（和动画部件同一套：坐标系、连杆、关节、机器人、箭头、尺寸线）；
   - 框图、流程图、工艺路线 → 自动布局图；
   - 零件图、机器人示意图 → 直接用库的 SVG 图纸（接口约定 R3），插图师只加标注和中英标题；
   - 数据图（控制图、曲线）→ 用工厂真实数据画。
3. 每张插图中英标注（按课程语言设置：中文 / 英文 / 中英对照），编号“图 2.3”，讲义里有图注和来源。
4. 质量：插图渲染成图片交给审稿人做**切题检查**（同第 3 轮）；审稿清单加“插图切题、标注正确”。

### 3.3 三维动画

1. 新增**三维渲染**：在动画服务旁加一个三维渲染器（无头浏览器 + three.js，MIT 许可，本地打包，不连外网），输入“场景脚本”（加载哪些 glTF、相机路径、各关节随时间的角度、字幕），输出 MP4。
2. 动画师按分镜决定用 **Manim（公式、平面推导）** 还是 **三维**，或先三维后公式拼成一段。
3. 第一批三维动画模板（动画师在模板上填本课内容，不从零写）：
   - 机器人关节运动：按关节角序列（由本课的正/逆运动学算出）转动各连杆，画末端轨迹和坐标系；
   - 装配与爆炸图（减速器、关节模组）；
   - 齿轮啮合、四杆等机构运动（用库给的运动采样表）；
   - G 代码刀路回放（数字工厂设计发布的 G 代码）；
   - AGV 轨迹回放、车间设备状态（工厂真实数据）。
4. 质量：与第 3 轮相同——相似度检查、关键帧切题检查、失败标“需要你处理”。

### 3.4 讲解视频（微课）

**两种来源，同一个播放器：**

| 来源 | 流程 |
|---|---|
| **A. 老师亲讲**（Eddie 先讲几次课） | 老师上传讲课录像（手机、电脑录屏、会议录像都可以）→ 自动语音识别出逐字稿和时间轴 → 生成中文字幕 → AI 翻译英文字幕（老师可逐句改）→ AI 生成**英文配音**（按英文字幕、对齐时间轴）→ 发布：原声中文 + 英文配音，两种字幕 |
| **B. AI 讲解**（其余课时） | 主讲教授写讲稿（按课件逐页，中英两版）→ 语音合成中、英两条配音 → 按配音时长把课件页、插图、动画片段、三维片段排成时间线 → 合成视频 + 字幕 |

- **播放器**：配音“中文 / English”一键切换（接着当前时间继续播）；字幕“中文 / English / 中英 / 关”。学生端、课件演示里都用这个播放器；小程序同样支持。
- **长度**：每课 8–15 分钟；分段（按知识点）带目录，可跳转。
- **老师可改**：逐句改字幕和讲稿，改完只重合成配音和受影响的片段。
- **语音识别**：服务器本地运行开源识别模型（不出境，国内可用）。
- **语音合成**：国内部署只用已备案的国内服务（如阿里云、讯飞）；美国部署可用其他服务。

### 3.5 三维虚拟实验

1. 实验工具包加三维场景：`api.scene3d()`，可载入课内复制的 glTF（机器人按关节分节点），提供关节拖动、末端轨迹、坐标系显示、相机旋转；three.js 随工具包本地打包（实验页仍然不能访问网络）。
2. 第一批实验模板：机器人正运动学（拖关节看末端位姿与矩阵）、逆运动学（拖目标点求关节角，多解对比）、雅可比与奇异位形（速度椭球）、机构调参（四杆能否整周转、急回、传动角）。
3. 实验检查服务加三维检查：页面能渲染（WebGL 可用）、画面不空、任务能完成；截图进课件。
4. **工厂实验**（学生在数字工厂里完成任务、成绩回写问渠）放到以后的轮次，依赖数字工厂“工作台内嵌问渠课程”。

## 四、试点与验收（机器人课程）

在《现代机器人学》中选 **2 课**（建议：刚体运动与位形空间；正运动学），每课都要有：

| 项目 | 验收 |
|---|---|
| 插图 | ≥ 4 张，中英标注，至少 1 张来自库图纸或工厂数据；审稿清单通过 |
| 三维动画 | ≥ 1 段，用库里的真实机器人（如 UR5e），关节运动与本课公式一致 |
| 讲解视频 | 第 1 课用 Eddie 亲讲录像（A）；第 2 课 AI 讲解（B）；两课都能切换中/英配音和中/英/双语字幕 |
| 三维实验 | 第 2 课 1 个（正运动学），通过试运行，任务能完成 |
| 来源 | 素材来源页列出全部库条目与许可 |

## 五、施工顺序

1. **素材接入**（本地临时样例库）+ 课程设计书、资料清单的“来自数字工厂”。
2. **插图师** + 插图部件库 + 切题检查。
3. **三维渲染器** + 三维动画模板。
4. **三维实验**：工具包三维场景 + 检查服务 WebGL。
5. **讲解视频**：播放器（配音/字幕切换）→ B（AI 讲解）→ A（老师录像：识别、翻译、英文配音）。
6. 试点 2 课：本地走通 → 上线 → Eddie 验收；帮助文件、方案更新。

库正式上线后（数字工厂第 2 轮第 3–6 步），把临时样例库换成正式地址，重跑试点课。

## 六、需要 Eddie 定的

1. **你的声音**：第 1 课英文配音用普通 AI 声音，还是用你的声音（“声音复刻”，需你录一段样本并同意授权；国内服务商也提供，需备案）？
2. **录课方式**：你打算怎么录——对着电脑讲课件（录屏 + 摄像头小窗）、还是教室实录？这决定视频画面的排法。
3. **AI 讲解的声音**：中文男声/女声、英文男声/女声，各选一个（到时给你试听几个）。
4. **试点 2 课**选哪两课（上面是建议）。
5. 服务器：三维渲染和视频合成比较吃 CPU；数字工厂上线后服务器若升到 16 GB 内存，本轮一般够用；不够时再加一台专门做渲染的小机器——到时报告你。
