## 二、原则（Eddie 20:20 定）

服务器只做**体验**：不需要一直实时运行的东西，不需要积累的数据。有人来看时现场跑，没人看时不跑。

### 乙：停掉“实时运行”，改成“打开才跑”（要改程序，确认后施工）

| 编号 | 做什么 |
| --- | --- |
| 乙1 | 数字工厂各厂（减速器厂、演示厂、9 座分厂）平时**全部停着**。有人打开某座厂的网页时，自动启动这座厂（约 1 分钟，页面显示“工厂正在开工”）；30 分钟没人访问自动停 |
| 乙2 | 数字工厂里的 ERPNext 跟着厂一起：有厂在开工时才启动，所有厂都停了它也停 |
| 乙3 | 启动时从最近一次快照接着跑，不需要历史；看板只显示这次开工以来的数据 |
| 乙4 | 美国、国内两边同样做 |
| 乙5 | 学习平台、官网、工业软件前门（数控编程、轴承、电路板）照常一直开着：它们本身不耗资源，只在有人用时才算 |

预计效果：美国教育服务器平时 56 个工厂容器停掉，负载从 18.9 降到 1–2，内存和交换区不再吃满；硬盘不再涨。
