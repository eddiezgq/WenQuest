## 一、决定

1. **国内的教育服务是“开发服务 + 在线体验”，不是对外开课。** 对外提供的服务写成五项：
   - 学习系统（问渠 AI 学习平台）
   - 电子教材开发
   - 虚拟实验开发
   - 数字工厂开发
   - CAD、CAM、CAE 集成化解决方案

   国内服务器上的学习平台、数字工厂、缝纫机与凸轮软件只给**单位**做在线体验，用来看效果、谈合同。正式使用时按合同为客户单独部署（客户自己的服务器或私有云，第 48 轮已说明）。
2. **账号只发给单位，不发给个人。** 学校、企业都算“单位”。国内服务器上关闭个人自助注册；单位通过官网“预约演示”申请，管理员审核后开通。
3. **名额上限**：同时有效的单位不超过 **100 家**；每家单位默认 **5 个账号**（管理员可以调，最多 20 个）。两个数都写在服务器设置里（`WQ_CN_MAX_ORGS=100`、`WQ_CN_ORG_SEATS=5`），以后改不用改代码。
4. **体验期**：默认 **90 天**，到期后这家单位的账号不能再登录（数据保留，续期后恢复）；管理员可以延长。到期前 7 天平台给管理员列出提醒。
5. **实名**：账号由管理员按单位提供的名单开通，每个账号登记姓名和手机号，符合“后台实名”的要求；手机短信验证（第 48 轮第十四节第 3 项）可以等正式运营再接，不再是上线前提。第 48 轮第十四节第 2 项（关不关自助注册）由本条定为“关”。

## 二、平台怎么做（只在国内服务器上生效）

| 部分 | 做法 |
|---|---|
| 单位表 | 网关新增单位：名称、类型（学校 / 企业 / 其他）、联系人、手机、邮箱、账号数、体验到期日、状态（体验中 / 已到期 / 已停用）、来源（哪一条预约申请）。存在网关的数据目录 |
| 开通 | 管理页新增“单位”一栏：从“预约演示”的申请一键“开通体验”（带入单位和联系人），或手工新建；超过 100 家时不能再开，提示先停用到期的 |
| 账号 | 在单位下“添加账号”：姓名、手机、邮箱（Moodle 要邮箱）；平台生成初始密码，首次登录必须改；超过这家单位的账号数时不能再加。账号可停用、重置密码 |
| 登录 | 登录时检查账号所属单位：到期或停用的，提示“体验已到期，请联系问渠科技续期”，不能进入 |
| 注册页 | 国内服务器上注册页改为说明页：“体验账号按单位开通，请到官网预约演示”，链接到官网 `/contact/`；注册接口在国内服务器上拒绝个人注册 |
| 老师申请 | 国内服务器上不走“老师资格审核”（第 3 轮）：单位开通的账号默认能建课（体验 AI 建课）；管理员可以对单个账号关掉 |
| 能体验什么 | 学习平台（AI 建课、AI 助教、网页互动课件、虚拟实验）、缝纫机设计软件、凸轮设计软件、数字工厂演示（只读的演示工厂）。在线体验不开放 GPU 实验、三维视频渲染等耗资源的功能（服务器 4 核 8 GB） |
| 管理员提醒 | 管理页列出：单位数 / 100、各单位账号数、7 天内到期的单位 |
