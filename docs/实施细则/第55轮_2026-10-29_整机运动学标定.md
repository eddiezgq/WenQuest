## 一、现在的样子

机器人厂的“整机标定”工位现在只是两个随机数：位置重复精度（名义 0.018 mm）、标定后绝对定位误差（名义 0.30 mm），
按“名义值 + 散布”合成，背后没有机器人的几何、没有测量、也没有“标定”这个动作。学生看不到标定是怎么做的，《机器人学》里的
DH 参数（第 13 章）、最小二乘辨识（26.3 节）在数字工厂里没有落脚点。

## 二、决定（建议）

| 编号 | 决定 | 理由 |
|---|---|---|
| K-1 | **每台 WQ-CR5 有一组“真实”的几何误差**（学生看不到）：6 个关节各自的 DH 参数偏差（连杆长度、偏距约 ±0.2 mm，扭角、零位约 ±0.02°，示例值），其中关节零位偏差取自这台机器人装的 6 台关节在关节测试台上测得的零位残差 | 标定要有“被找出来的东西”；零位接上关节测试，实验 25 的“测试台零位漂移”会让整机标定前的误差变大，两个实验连起来 |
| K-2 | **整机标定工位真的做标定**：激光跟踪仪（示例：测量噪声 0.02 mm）测末端在 N 个位姿下的位置 → 用名义 DH 参数算出的位置与测量值比较 → 最小二乘（列文伯格-马夸特法）辨识参数偏差 → 补偿 → 另取 20 个位姿验证。测量特性“标定后绝对定位误差”改为由这一过程算出；另加“标定前绝对定位误差” | 数据有来历：标定前约 1–3 mm，标定后约 0.1–0.3 mm（示例量级），与教材和厂商资料的量级一致，数值标“示例” |
| K-3 | **网页“整机标定”页**（机器人厂）：按出厂编号看一台机器人的标定——测量位姿（三维）、每个位姿的误差（标定前 / 后）、辨识出的参数偏差、条件数；可以**自己选位姿**（数量、分布：集中在一小块 / 铺满工作空间）重新辨识，看位姿太少或太集中时条件数变大、辨识不准 | 标定最要紧的工程判断是“测哪些位姿”，要能动手试 |
| K-4 | **实验 26：一台协作机器人的运动学标定**（4 学时，个人或 2 人）。任务：① 用名义 DH 参数算一个位姿下的末端位置（与平台核对）；② 选测量位姿，看条件数；③ 辨识，回答“哪几个参数偏得最多”；④ 用验证位姿判这台机器人合不合格（标定后 ≤ 0.5 mm）；⑤ 位姿选得不好时会怎样（对比两组位姿）；⑥ 复盘：零位偏差从哪来（关节测试台）。自动评 60 分 + 报告 40 分，指导书、报告模板中英对照 | 与实验 24、25 同一套做法 |
| K-5 | **计算放在枢纽的确定性代码里**（numpy），带标准题：给定已知偏差合成的测量数据，辨识结果与真值相差在噪声量级内；名义参数下的正运动学与教材第 13 章的算例一致 | 计算可核对，不靠 AI |
| K-6 | **课程**：实验 26 挂《机器人学》第 13 章（DH）与 26.3 节（最小二乘辨识）的课后实验，也作《数字工厂实训》机器人工程方向的选做；以后开《机械臂与智能制造》（c04）时再挂一次 | 让教材和数字工厂对上 |
| K-7 | **效率（Eddie 10-29：先考虑效率、跑通）**：CI 服务器演练里“两厂互发订单”那一段只在 `hub/park.py`、`hub/supply.py`、桥接、机器人厂清单改动时跑；本轮新的标定演练也只在标定相关文件改动时跑。其余推送照旧走机器人厂闭环 | 平时推送快约 20 分钟；第 51 轮一个问题要重跑整轮是主要耗时 |

## 三、规则

1. 名义 DH 参数是 WQ-CR5 的**示例值**（量级与常见 5 kg 协作臂相同，不照抄任何厂商的数），页面标“示例”；误差量级、测量噪声也标“示例”。
2. 减速器厂、机器人厂已有的实验和测试不改断言通过；实验 24 的“整机标定”任务照常自动打勾。
3. 一台机器人的“真实”偏差只在仿真里，平台页面、接口、AI 都不显示（老师页面可以看，用于讲评）。

## 四、交付物与验收

| 交付物 | 验收 |
|---|---|
| 几何误差模型、标定计算 | 标准题：已知偏差 → 辨识误差小于 0.02 mm 量级；位姿太少 / 太集中时条件数明显变大（测试） |
| 整机标定工位 | 本机与 CI：做一台 WQ-CR5，标定前误差 1–3 mm、标定后 ≤ 0.5 mm，测量值进质量页 |
| 关节零位接上整机 | 测试：注入“测试台零位漂移”后，整机标定前的误差变大，标定后仍能补回来 |

| 实验 26 | CI：一个“学生”答完拿 60 分 |
| 帮助、指导书、课程 | 机器人厂一册加一章；帮助测试通过；课程大纲更新 |
| CI 效率 | 只改文档或无关代码的推送不跑两厂、标定演练 |
