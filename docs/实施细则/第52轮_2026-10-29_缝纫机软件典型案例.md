# 实施细则 · 第 52 轮：缝纫机设计软件的典型案例（帮助里加“典型案例”）

状态：**已完成**（2026-10-29 起草；同日 Eddie 确认：四个案例（平缝、包缝、绷缝、花样，刺绣机先不做），每个案例一段网页版录屏 + 平缝机一段 FreeCAD 录屏；同日施工完）

起因：Eddie 10-29：“我觉得缺乏典型案例，比如平缝机从零配件到整机，包缝机，绷缝机和花样机再找典型机构和零件。”

## 一、现状

第 49 轮的两份帮助按“功能”讲（页签、AI、CAE、零件库），每样功能用的是零散的例子；缺一条把软件从头用到尾的线，也缺各机型最有代表性的机构和零件。软件和教材里现成的东西够做案例：

| 机型 | 现成可用的 |
|---|---|
| 平缝机 | 教材虚拟样机的 27 个零件编号（机壳 F、刺布 N、挑线 T、钩线 H、送布 D、传动 S、附件 X 七组）；16 个机构零件可导出 STEP；7 个平板零件能出数控程序；21 项校核、30 针试缝、尺寸链、调机卡；针杆曲柄 / 连杆的有限元与疲劳、减重、机壳模态、刺布机构动力学、主轴电机选型 |
| 包缝机 | 斜向引针（曲柄滑块）、下弯针空间四杆（RSSR）、上弯针空间四杆、差动送布、切刀；下弯针摆杆有限元与减重（留 50% 合格、留 40% 不合格，是现成的好例子）；11 个可数控的零件 |
| 绷缝机 | 五种线迹（401、406、407、602、605）的弯针定时与让针；耗线量与线团计划 |
| 电子花样机 | 离布窗口、前瞻调速、X / Y 伺服与同步带、上传针位表、伺服选型（换带轮就合格）、花样模板（槽板）数控编程 |

## 二、决定（待 Eddie 确认，括号里是建议）

1. **四个案例**，每个机型一个，按 Eddie 点的四种机型（刺绣机先不做，建议以后补）：

   | 案例 | 主线 | 典型机构 | 典型零件 |
   |---|---|---|---|
   | **一、平缝机：从零件到整机**（最完整，作主线案例） | 一个零件 → 一个机构 → 整机 → 提速改型 → 出件进工厂 | 刺布（曲柄滑块）、挑线（四杆）、钩线（旋梭定时）、送布 | 针杆曲柄（强度、疲劳、减重、复核、数控铣削） |
   | **二、包缝机：空间四杆的弯针** | 下弯针要摆多大、传动角够不够、会不会卡死；差动送布；切刀 | 下弯针 RSSR 空间四杆、差动送布 | 下弯针摆杆（有限元、减重留 50% / 40% 对比、数控） |
   | **三、绷缝机：五种线迹与用线计划** | 换线迹时弯针定时怎么调；一张订单要多少线团 | 弯针让针与定时 | （没有三维零件）订单耗线量表 |
   | **四、电子花样机：一个口袋盖花样** | 转速上限 → 前瞻调速 → 每针用时 → 伺服选型（换带轮合格）→ 模板槽板数控 | X / Y 伺服与同步带 | 花样模板（槽板）的铣削程序 |

2. **每个案例的写法**（同一结构）：
   - 实际问题（一两句，企业里真会遇到的事）；
   - 一步一步：在软件里做什么 → 看到什么数 → 和什么判据比 → 下一步为什么这么做；
   - 结果：哪几个文件（计算书、STEP、DXF、G 代码、调机卡、物料表），关键数一张表；
   - “试一试”：一键带着案例参数打开软件；
   - 一段录屏（网页版，中文字幕，不配音，同第 49 轮）；平缝机案例另录一段 FreeCAD 版（新建设计 → 16 个零件 → 改型 → 本机有限元 → 导出 STEP）。
3. **数字全由程序算**：新写一个“案例脚本”，用网页版同一套接口把四个案例从头跑到尾（含数字工厂真算的有限元、疲劳、模态、动力学、减重、复核、数控），结果存 `data/cases.json`；帮助里的数全从这里取。这个脚本同时当回归检查：以后改了计算核心，重跑一遍就知道案例还成不成立。
4. **平缝机“整机”部分**加一个动画：27 个零件按七组拆开、再装回（用教材虚拟样机的零件编号表和三维模型），旁边是“零件 → 机构 → 整机”的对照表（每个零件属于哪个机构、软件里哪项校核管它、能做哪种 CAE / 数控）。
5. **放在哪**：两份帮助都加“典型案例”一大节（四个小节），排在“快速上手”之后；网页版帮助首页加一个“从案例开始”的入口。FreeCAD 版里网页操作的步骤照写，并注明哪些步骤在 FreeCAD 里做。
6. **只中文**，同第 49 轮。

## 六、施工中的偏差（已按此做）

1. **“典型案例”一大节 = 一个总览节 + 四个案例节**：每个案例在左栏目录里单独一条（案例一的小节最多，放一节里目录太长）。网页版排在“快速上手”之后；FreeCAD 版排在“十六个按钮”之后（FreeCAD 版没有“快速上手”节，“十六个按钮”就是它的上手）。两份帮助首页都加了“第一次用？从案例开始”。
2. **整机拆装动画用二维斜视图，不用三维引擎**：直接读教材虚拟样机的同一个三维模型，按样机的机构库摆到主轴 0°，投影后每个零件取外轮廓（数据约 12 KB）；三维网格原样带进来要近 600 KB，帮助页面太重。能按七组只看一组、鼠标指零件看编号和名称。
3. **平缝机 6000 r/min 案例多了一步“电机”**：真算发现机构改完全部合格后，通用电机表里没有够用的电机（转矩够的只到 5000 r/min，转得到 6000 的额定转矩不够）。这正好接上本单位零件库：案例里录一台**示例**高速主轴伺服 SV-3000H（不对应任何厂家），再选型就选中它。脚本和录屏里都是临时录入、用完删掉。
4. **包缝机案例的主线改成“上弯针黄灯 → 设计优化”**：算例本身只有一盏黄灯（上弯针传动角 39°），用设计优化“上弯针”目标消掉最直观；“下弯针摆大一点行不行”作对照（偏心半径 6、8 mm 的黄灯表），差动送布、切刀各一段。
5. **针杆曲柄减重只轻 3%**：曲柄大部分是轴毂和平衡块，减重意义不大，案例照实写“不减”，减重的好例子放到包缝机下弯针摆杆（留 50% 合格、留 40% 不合格）。
6. **花样机案例多了“产能”一步**：真算发现转速 1800 → 2000 每小时只多 3 件（282 → 285），一个周期 12.8 秒里真正缝的只有两秒多；写进案例，提醒先看上下料时间。
7. **机壳模态用一个简化 C 形机壳**：案例脚本生成（底板 + 立柱 + 机臂，HT200），存成 `media/case-ls-frame.step` 供读者下载照着做。
8. **本地跑案例脚本要调高数字工厂 hub 的每日上限**（一次二十来个计算任务，默认 20 个）：`WQ_DESIGN_SW_DAILY=500 WQ_DESIGN_SW_OPT_DAILY=50`，只在本地；线上不变。
9. **录屏工具的两处修正**：FreeCAD 控制台打字改成逐字插入（模拟按键会把 `;`、`=` 打错）；剪等待段从真正开始等的时候算（不剪掉打命令的画面）。
