## 一、照前几座厂的路子

新厂只写一份清单，只补这座厂特有的东西（第 85、103、125 轮）。电机厂的物料、BOM、工艺、设备、检验特性、布局写进 `factory/plants/wenquest-motor.yaml`，其余各领域按清单接上。

**电机厂做什么**：协作机器人关节和 AGV 驱动轮用的永磁同步伺服电机（带失电制动抱闸）。

```
定子线：来料检验 → 铁芯叠压 → 绕线（2 台）→ 嵌线整形 → 浸漆烘干 → 定子测试（电阻、匝间、耐压）
转子线：磁钢粘贴 → 充磁 → 动平衡
总装线：电机总装（压轴承、装抱闸、装端盖）→ 抱闸测试 → 电机终检（反电势、齿槽转矩、空载电流）→ 包装
```

工业园链条：**芯片厂 → 电路板厂 → 传感器厂 → 机器人厂 ← 电机厂**（机器人厂的四种电机都向电机厂买）。

### 偏差

- D-1（M-3）：ERPNext 一种物料一张检验模板（清单检查强制），所以一台电机的全部测量（定子测试、动平衡、抱闸、终检）都记在“电机终检”这道工序上，名称里写明是哪台设备测的。
- D-2（M-4）：细则写“磁钢贴歪 → 齿槽转矩出现每圈一次的低次成分”不准确：10 极 12 槽电机里，每块磁钢和槽作用产生的是每圈 12k 次分量；磁钢均匀、贴准时 12、24 次互相抵消，只剩每圈 60 次。贴歪后出来的低次成分是**每圈 12、24 次**，页面和帮助按这个写。
- D-3（M-4）：匝间问题不改反电势波形（模型里留了“某一相系数”参数，这一轮四种问题都不用它）；绕线张力问题表现在定子测试的三相电阻不平衡、匝间冲击面积差上。
- D-4（测试）：机器人厂的电机都改向电机厂买以后，没有物料再向“示例·伺服电机供应商”买，ERPNext 不再给它建来料检验模板；`test_park.py` 的模板名单去掉“进货检验-servo”（数据变了，不是放宽断言；本机没有 PostgreSQL，这项在 freecad-ai-parts CI 里发现）。
