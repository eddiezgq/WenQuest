## 一、这一轮做出什么

第 88 轮的驱动板 DRV-JOINT（A 版）由 MCU 的定时器直接数编码器脉冲；第 92、93 轮设计了编码器接口芯片 WQ-ENCIF。
这一轮出 **B 版**：编码器 A/B/Z 经原来的 RC 滤波进 WQ-ENCIF，芯片计数后 MCU 用 SPI 读。整条链“芯片 → 板 → 工厂”在同一块板上接上。

```
编码器 J3 ─ RC 滤波（例题 4）─ WQ-ENCIF（QFN-16，1.8 V 核心 / 3.3 V IO，50 MHz 有源晶振）─ SPI1 ─ MCU
                                                                                    （SSI 绝对值编码器改用 SPI3，引脚不变）
```

## 二、决定（建议）

| 编号 | 决定 | 理由 |
|---|---|---|
| B-1 | **B 版是“设计对照”，不投产**：电路板厂（`wenquest-pcb`）照旧生产 A 版，物料清单、工序、测试都不变；B 版只在“电路板设计”页上和 A 版并排看。理由：WQ-ENCIF 是未流片的示例芯片，现实里买不到，不能进工厂的采购和生产 | 不编造供应；A 版已验收的东西一律不动 |
| B-2 | **改动**：① 加 U14 WQ-ENCIF（QFN-16 3×3 mm，带散热焊盘）；② 加 Y2 50 MHz 3.3 V 有源晶振（芯片时钟）；③ 加 U15 1.8 V 低压差稳压器（芯片核心电源，与 A 版 3.3 V 那颗同系列同封装）；④ 去耦电容各一；⑤ MCU 引脚：PA4/PA5/PA6/PA7 改为 SPI1 的 NSS/SCK/MISO/MOSI 接芯片，PB1 接芯片复位，PB0 空出；SSI 仍在 PB3/PB4（改用 SPI3 复用功能，引脚不变）。其余电路不动 | 按 STM32G431 的引脚复用表选；改动最少 |
| B-3 | **芯片的符号和封装**：符号由脚本生成，放工程自带库（`wq.kicad_sym`），引脚按第 92 轮的端口；封装用 KiCad 官方库的 QFN-16 3×3 mm 0.5 mm 节距。引脚分配：1 ENC_A、2 ENC_B、3 ENC_Z、4 GND、5 CLK、6 RST_N、7 VCCD（1.8 V）、8 GND、9 CS_N、10 SCLK、11 MOSI、12 MISO、13 VDDIO（3.3 V）、14 GND、15/16 不接、散热焊盘 GND | 同一套生成流程；不另起炉灶 |
| B-4 | **生成**：同第 88 轮的脚本链（设计描述 → KiCad 原理图 / PCB → Freerouting → DRC → 导出），A、B 两版共用一份设计描述（B 版在 A 版上打补丁），产物放 `factory/designs/drv-joint-b/out/`；CI 同样重新导出、逐字核对 | 两版不会走样 |
| B-5 | **验收线**：DRC 0 错误、0 未连接；可制造性检查 10 项全过；B 版 BOM 比 A 版多出的就是上面这几项（测试核对差异清单） | 同第 88 轮 |
| B-6 | **页面**：“电路板设计”页顶上加“A 版 / B 版”切换；B 版的原理图“编码器接口”一页、PCB、BOM 都能看，另有“A→B 改了什么”一栏（器件、网络、MCU 引脚的差异表）；芯片设计页链到 B 版 | 学生看得到“芯片上板”具体改了哪些 |
| B-7 | MCU 固件不在本轮（A 版也没有）；在差异表里写明 B 版固件要改的配置：SPI1 模式 0、≤ 5 MHz（芯片要求 SCLK ≤ 时钟 / 10）、SSI 改 SPI3 | 范围 |
| B-8 | 帮助“电路板设计”一节加一段；freecad-ai-parts 同步 0 差异（ADR 不新开，属 ADR-0084/0085 范围，PR 里说明） | 同前几轮 |
