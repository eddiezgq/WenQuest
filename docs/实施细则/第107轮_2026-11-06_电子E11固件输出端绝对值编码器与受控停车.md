## 一、这一轮做出什么

第 102 轮的固件开机时把关节当在 0°（电机侧增量编码器只知道转了多少，不知道在哪），停机或出故障就关输出，摆臂会在重力下落下。
这一轮：

1. **读输出端绝对值编码器**（板上 J4，SSI 经两片 RS-485，第 88 轮已有电路；MCU 用 SPI3 读，第 98 轮已定 PB3 / PB4）：开机就知道关节在哪；
2. **双编码器互检**：电机侧（经减速比 100 换算）和输出侧两个角度对不上 → 报“减速器 / 编码器不一致”故障（减速器打滑、联轴器松了都会这样）；
3. **受控停车**：通信超时这类不危险的故障，先减速停住、**保持位置不断电**，等主站来清故障；过流、编码器故障这类危险的才立即关输出。

**抱闸**：板上没有抱闸驱动电路（要加功率管、接口、续流），属于电路改版；电路板设计现在由“问渠电子”那条线（设计描述 YAML）维护，本轮不改硬件，
在页面和细则里写明“断电后无抱闸，摆臂会落下；真关节要抱闸，留给后续电路改版”。

## 二、决定（建议）

| 编号 | 决定 | 理由 |
|---|---|---|
| A-1 | **SSI 帧（示例格式）**：24 个时钟读一帧，第 1 位为起始位（恒 1），接着 17 位单圈位置（二进制，高位先出，131 072 计数/圈），再 1 位错误位（0 正常），其余补 0；SPI3 主机、模式 3、170 MHz / 128 ≈ 1.33 MHz；1 kHz 读一次 | 常见 17 位单圈绝对值编码器的帧；分辨率 0.0027° |
| A-2 | **开机**：对零前读绝对位置，固件的关节角 = 绝对编码器角度（安装零点偏移写在固件常量，示例 0）；以后位置环、CAN 报的关节角都按绝对角度；开机位置不在 0° 也能直接去目标 | 第 102 轮“开机位置当 0°”的毛病 |
| A-3 | **互检**：1 kHz 比较“电机计数 ÷ 减速比”与绝对编码器角度，差超过 0.5°（示例）连续 10 ms → 故障码 6“减速器 / 编码器不一致”，立即关输出；SSI 错误位置位或帧不对（全 0 / 全 1）连续 5 次 → 故障码 5“输出端编码器” | 双编码器是关节模组的常规安全手段 |
| A-4 | **受控停车**：故障分两类——立即关输出（过流 1、编码器 3、输出端编码器 5、不一致 6）；受控停车（通信超时 4、欠压 2）：按轨迹减速度停住，通信超时**保持当前位置不断电**，欠压停住后再关输出（母线还在掉，保持不住） | 与工业驱动的“停止类别 0 / 1 / 2”对应，讲给学生 |
| A-5 | **仿真**：Renode 加 SSI 编码器外设（挂在 SPI3，从电机模型取输出轴角度）；可注入“减速器打滑”（输出侧相对电机侧突然错开若干度）、“SSI 线断”（读回全 1）。平台描述加 SPI3（地址对照 ST 官方头文件） | 同第 100/102 轮做法 |
| A-6 | **场景**（电机控制那一组接着编号）：⑦ 开机在 37.5° → 固件报 37.5°（≤ 0.01°）、指令 90° 直接走 52.5°；⑧ 输出端编码器线断 → 故障 5、关输出；⑨ 减速器打滑 2° → 故障 6、关输出；⑩ 摆臂在 90° 时主站不再发指令 → 故障 4，摆臂保持在 90°（1 s 内偏差 ≤ 0.05°）、输出不断；对比：同情况下欠压 → 停住后关输出、摆臂落下 | 覆盖 A-2～A-4 |
| A-7 | 第 100 轮六个、第 102 轮六个场景照旧通过（第 102 轮 ⑥ 的通信超时那一步改成核对“保持”而不是“关输出”，写明）；页面“电机控制与 CAN”加这四个场景、协议表加故障码 5、6；CI 照旧重跑核对；帮助加一段；freecad-ai-parts 同步 0 差异 | 不倒退 |

### 偏差

- S-1（A-6 ⑦）：“开机在 37.5°”的场景用**水平面里转的关节**（去掉摆臂重力，像 SCARA 第一轴）——对零后输出关着、又没有抱闸，有重力时摆臂会在去目标之前先落下，看不出“开机就知道在哪”。
