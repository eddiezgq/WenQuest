## 一、这一轮做出什么

第 98 轮的 B 版板上，MCU（STM32G431）经 SPI1 读编码器接口芯片 WQ-ENCIF。这一轮写这段**固件**，并在 **Renode**（开源的单片机仿真器，跑的就是编译出来的真固件）里跑：

```
虚拟电机（转速曲线）→ WQ-ENCIF 寄存器级模型（Renode 外设）⇄ SPI1 ⇄ STM32G431 固件（真 .elf）→ 内存里的遥测区 → 测试 / 页面
```

预检（施工前已做）：Renode 1.15.3 官方便携版能装能跑；自写的 STM32G431 平台描述、运行时编译的 C# 芯片外设、SPI 收发、GPIO 片选、读内存都通了。

## 二、决定（建议）

| 编号 | 决定 | 理由 |
|---|---|---|
| F-1 | **固件范围**：只做编码器这一路——上电复位芯片（PB1）→ 读 ID 核对 `ENC1`（0x454E4331）→ 写控制寄存器（使能、滤波 3）→ 1 kHz 节拍读计数和状态 → 算角度（10000 计数/转，2500 线 ×4，第 88 轮的示例编码器）、转速、圈数；Z 相锁存值；芯片报错（A/B 同时跳）时记故障并写 1 清除；ID 不对时停在“芯片缺失”故障。电机控制（PWM、电流环）、CAN 不在本轮 | 先把“芯片上板”这一路跑通 |
| F-2 | **写法**：C 语言、不用厂商库，寄存器地址只写用到的那几个，逐个注明 RM0440（STM32G4 参考手册）的出处；arm-none-eabi-gcc 编译；SPI1 模式 0、8 位、16 MHz/4 = 4 MHz（≤ 芯片时钟 50 MHz/10）；40 位一帧（8 位命令 + 32 位数据）、PA4 软件片选 | 学生看得懂每一行；不引第三方代码 |
| F-3 | **输出**：板上没有调试串口，只有 SWD；固件把结果放在内存里一个固定的“遥测区”（结构体），测试和页面通过读内存拿到——相当于调试器经 SWD 实时看变量 | 与真板一致，不为仿真加硬件 |
| F-4 | **仿真平台**：Renode 没有 STM32G4，自写平台描述 `stm32g431.repl`（Cortex-M4F、128 KB Flash、22 KB SRAM、GPIOA/B、SPI1、SysTick），地址按 RM0440；芯片用 C# 写寄存器级外设 `WqEncif.cs`，规则同第 92 轮规格（寄存器 0–4、40 位帧、写 1 清除），编码器输入由“虚拟电机”给：按设定的转速曲线算计数，Z 相每转一次；可注入 A/B 同跳错误 | 芯片 RTL 已在第 92/93 轮与 Python 模型逐拍比对过，这里用寄存器级即可，跑得快 |
| F-5 | **场景**（测试逐一核对，判据都是物理真值）：① 上电：ID 对、配置写入；② 正转 600 rpm：转速读数误差 ≤ 1%，角度连续；③ 反转、过零（计数从 0 往负走，补码处理）；④ Z 相：锁存值与真值一致；⑤ 注入错误：固件记一次故障并清除，之后正常；⑥ 芯片不响应（ID 不对）：固件停在“芯片缺失”，不乱报数 | 覆盖正常与异常 |
| F-6 | **产物**：`factory/designs/drv-joint-b/fw/`（源码、链接脚本、Makefile）、`renode/`（平台、外设、脚本）、`out/`（.elf/.bin/.map 大小、各场景结果 JSON 与曲线数据）；CI 在“电路板设计（KiCad）”任务里装编译器和 Renode，重新编译、重跑、逐字核对结果 JSON | 同第 88/98 轮的“重新导出核对” |
| F-7 | **页面**：“电路板设计”B 版加“固件”标签：整条链示意图；源码逐文件看（带注释）；固件大小；六个场景的结果（转速、角度曲线：设定 vs 固件读到）；下载固件包（源码 + .elf + 仿真脚本，本机装 Renode 可复现） | 学生看得到程序真在读芯片 |
| F-8 | 帮助“电路板设计”一节加一段；freecad-ai-parts 同步 0 差异（属 ADR-0084/0085 范围，PR 里说明） | 同前几轮 |
