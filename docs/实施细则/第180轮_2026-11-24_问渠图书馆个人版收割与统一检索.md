## 一、决定

| 编号 | 决定 |
| --- | --- |
| 1 | 个人版是一个本机程序：Python 写，浏览器打开 `http://127.0.0.1:8765`，只监听本机，不对外开放 |
| 2 | 数据全在一个 SQLite 文件：FTS5 全文检索（trigram 分词，中英都能搜）+ sqlite-vec 向量检索。不装数据库软件，不用 Docker |
| 3 | 检索是“关键词 + 按意思”混合：两路结果按 RRF（倒数排名融合）合并 |
| 4 | 向量模型：多语种 384 维开源小模型，用 ONNX Runtime 在 CPU 上跑，不用 GPU。首选 paraphrase-multilingual-MiniLM-L12-v2（Apache-2.0）；施工时用第七节的中文题实测，不达标换 multilingual-e5-small（MIT） |
| 5 | 全文“按需入库”：甲档书在打开或预取时才下载存本地；乙档只存书目；丙档只给入口 |
| 6 | 每个书库一个“收割器”，限速、标识（User-Agent）、增量规则都写在 `sources.yaml` 里，代码照表执行 |
| 7 | 收割完的原始数据和统一书目记录，格式和以后的在线版一样；上线时只换存储层 |

## 二、本轮接哪些书库、收多少

| 书库 | 档 | 本轮怎么收 | 估计条数 |
| --- | --- | --- | --- |

| DOAJ | 乙 | OAI-PMH，只收理工类（LCC 的 Q 科学、T 技术）文章书目 | 施工时实测，预计百万级 |
| OpenStax | 甲 | 129 本书目；PDF 全部预取 | 129 |

| OAPEN | 甲 | OAI-PMH 全量书目；PDF 按需下载 | 施工时实测 |
| DOAB | 乙 | OAI-PMH 全量书目，和 OAPEN 合并去重 | 施工时实测 |
| Open Textbook Library | 乙 | JSON 目录全量 | 约 1500 |
| 维基文库（中文） | 甲 | 不全量；检索时实时查，打开时缓存全文 | 按需 |
| OpenAlex | 乙 | 不收割；检索时实时补充，结果缓存 | 按需 |
| ctext | 乙 | 不收割；检索时实时查（非商业，个人版可用） | 按需 |

| 国家哲学社会科学文献中心、中华古籍资源库、中国科技论文在线 | 丙 | 检索结果末尾给“到某某站搜同一个词”的入口 | — |

**首次收割与建向量**：在 Eddie 电脑上，arXiv 全量约 3–5 小时（受 arXiv 限速），建向量一到两个晚上；之后每天凌晨 2 点由 Windows 任务计划程序自动跑增量，几分钟完成。

## 三、统一书目记录

每条记录的字段（个人版、在线版共用）：

| 字段 | 说明 |
| --- | --- |
| `id` | 问渠内部编号 |
| `work_key` | 同一部作品的合并键：有 ISBN / DOI 用它；没有就用“规范化书名 + 第一作者 + 年份” |
| `source`、`source_id` | 来自哪个书库、它那边的编号 |
| `type` | 书 / 教材 / 论文 / 原典 |
| `title`、`authors`、`year`、`language`、`subjects`、`abstract` | 书目内容 |
| `isbn`、`doi` | 有就填，没有不填 |
| `license` | 许可原文（如 CC BY 4.0、公有领域（美国）） |
| `tier` | 甲 / 乙 / 丙（按 `sources.yaml` 和单条许可算） |
| `landing_url`、`fulltext_url` | 原站页面、全文地址 |
| `local_path` | 甲档已下载时的本地文件 |
| `harvested_at` | 收割时间 |

规则：缺的字段不填，不猜；许可读不出来的按乙档处理；同一 `work_key` 的多条记录在检索结果里合成一条，列出各个来源和许可。

## 四、界面（中英切换）

| 页面 | 内容 |
| --- | --- |
| 首页 | 一个搜索框；下面一行写“已收 X 条，来自 Y 个书库，上次更新 Z” |
| 结果页 | 左边筛选：来源、类型（书 / 教材 / 论文 / 原典）、语言、许可、能否全文、年份。每条结果：书名、作者、年份、来源标记、许可、档（“本地全文 / 去原站 / 入口”），按钮：阅读（甲）、去原站、导出到 Zotero（RIS 文件）。末尾一行丙档入口 |
| 详情页 | 书目全部字段；同一部作品的各个来源与许可；封面（有就显示） |
| 阅读页 | EPUB 用 epub.js（BSD-2），PDF 用 pdf.js（Apache-2.0），维基文库用网页正文；页头写许可和来源 |
| 收割管理页 | 每个书库一行：状态、条数、上次收割、下次收割、最近错误；“立即收割”按钮；日志 |
| 设置页 | 数据位置、每日收割时间、磁盘占用 |

## 五、安装

| 项 | 做法 |
| --- | --- |
| 位置 | `C:\Users\<用户名>\wenquest-library\`，下分 `app\`（程序）、`data\library.db`（数据库）、`data\fulltext\`（全文）、`data\raw\`（收割原始数据）、`logs\`、`backups\` |
| 要装的 | Python 3.12（没有就由安装脚本从 python.org 装）；Python 包：fastapi、uvicorn、httpx、sickle（OAI-PMH）、lxml、sqlite-vec、onnxruntime、tokenizers、pyyaml。网页用的 epub.js、pdf.js 随程序附带 |
| 程序从哪来 | 只取 WenQuest 仓库的 `library/` 目录（稀疏检出，不下整个仓库） |
| 一键安装 | `library/install.ps1`：建目录、装 Python 与包、取程序、下载向量模型、建数据库、注册每日收割任务、桌面放一个“问渠图书馆”快捷方式 |
| 启动 | 双击快捷方式：启动本机服务并打开浏览器 |
| 卸载 | `uninstall.ps1`：删除每日任务和快捷方式；数据目录保留，由 Eddie 自己决定删不删 |
| 备份 | 每周把 `library.db` 复制到 `backups\`，保留 4 份 |

## 六、施工顺序

1. 记录格式与数据库表（FTS5、sqlite-vec）。
2. 收割器：每个书库一个；每个都带离线测试样本，测试不联网。
3. 去重合并。
4. 检索：关键词、按意思、混合排序、筛选。
5. 网页界面与阅读页。
6. 安装、启动、每日任务脚本。
7. 云端测通：arXiv、OpenAlex、OpenStax、DOAJ、维基文库、ctext、Open Textbook Library（云端能连的）。
8. Eddie 电脑上安装：首次收割，实测古登堡、OAPEN、DOAB（云端连不上的三个），把结果写回 `sources.yaml`。
9. 对照第七节逐条验收，写回本细则；写帮助文件 `docs/帮助/问渠图书馆个人版.md`。

## 九、风险

| 风险 | 应对 |
| --- | --- |
| DOAJ 理工类文章量很大 | 先收最近 10 年；不够再往前补 |
| 中文两个字的词（如“齿轮”）trigram 分词搜不到 | 两字词改用按意思检索加 LIKE 兜底；施工时用验收第 1 题实测 |
| Windows 上 SQLite 扩展加载失败 | 用 sqlite-vec 官方 Python 包自带的加载方式；不行就改用 Python 自带的 SQLite 加 numpy 暴力检索（330 万 × 384 维，单次约 1 秒，可接受） |
| 书库限速或封 IP | 严格按 `sources.yaml` 限速；出错自动退避，第二天再试，不加大并发 |
