## 一、原则

1. **图书馆的职能一样不少**：发现、馆藏、阅读、参考咨询、编目、学科服务、文献管理、知识服务。
2. **AI 原生**：每项职能都由 AI 先干活，读者只提要求、做确认；不是在旧系统上加一个聊天框。
3. **每句话有出处**（*Every answer has a source*）：AI 说的每一句都标来源，引用的原文由代码逐字核对，核不上的句子不显示。
4. **AI 只提议，代码判定，人确认**：
   - 许可判定、去重、引文核对由代码做。
   - 改书目、删书由人确认。
5. **守许可**：AI 只读本地有全文的书（甲档和 Eddie 自己导入的）；乙档只读书目和摘要，丙档只给入口。

## 二、功能清单

### 2.1 发现（统一检索）

| 功能 | 说明 |
| --- | --- |
| 一个搜索框 | 同时搜收割来的书库、现场查询的书库、Eddie 自己的文库 |
| 混合检索 | 关键词（SQLite FTS5，trigram 分词）+ 按意思（向量）两路，按 RRF 合并 |
| **AI 理解提问** | 输入一句话（“想找讲谐波减速器柔轮疲劳的中英文资料”），AI 拆成检索词、同义词、中英对照词，自动加筛选；把它怎么理解的显示出来，可以改 |
| 筛选 | 来源、类型（书 / 教材 / 论文 / 原典 / 我的文档）、语言、许可、能否全文、年份、学科 |
| 去重合并 | 同一部作品多个来源合成一条，列出各来源与许可 |
| 丙档入口 | 结果末尾“到国家哲学社会科学文献中心 / 中华古籍资源库 / 中国科技论文在线搜同一个词” |

### 2.2 馆藏（书库收割 + 我的文库）

| 功能 | 说明 |
| --- | --- |
| 书库收割 | 见第三节；每天凌晨自动增量 |
| **我的文库** | Eddie 把自己的 PDF、EPUB、Word、Markdown 拖进来（包括自己写的书稿、讲义、标准文件），全文入库，只在本机 |
| **AI 编目** | 导入的文件由 AI 读版权页 / 首页，起草书名、作者、年份、ISBN、摘要、关键词、分类号（中图法 + 美国国会图书馆分类）；代码校验格式；Eddie 一键确认或修改 |
| 监视文件夹 | 可指定一个文件夹，新放进去的文件自动导入、编目 |
| 许可管理 | 每条记录带许可和档位；按 `sources.yaml` 自动计算，读不出就按乙档 |

### 2.3 阅读

| 功能 | 说明 |
| --- | --- |
| 阅读器 | EPUB（epub.js）、PDF（pdf.js）、网页正文、Markdown；记住读到哪 |
| 高亮、批注、书签 | 存本地，可导出 |
| **中英对照阅读** | 英文书一键出中文对照（按段），反之亦然；译文缓存，标“AI 译文，以原文为准” |
| **AI 导读** | 每章开头：本章讲什么、要点、术语表（中英对照）、先修知识 |
| **划词解释** | 选中一段，AI 解释或推导，引用本书前后文 |
| **朗读** | 本机 AI 语音（Kokoro，CPU 运行），中英文都能读 |

### 2.4 参考咨询（AI 馆员）

| 功能 | 说明 |
| --- | --- |
| **AI 馆员** | 自然语言问；先检索再回答；每句带出处编号，点开跳到原文位置；查不到就说查不到，并建议去哪个书库或入口找 |
| **问一本书** | 在某本书里问问题，只用这本书回答 |
| **跨书比较** | “这三本书对柔轮应力的算法有什么不同”，按书列出、各带出处 |
| 引文核对 | AI 引用原文的每一句，代码在本地全文里逐字查找，核不上就删掉这句并标注 |
| 对话记录 | 每次问答存档，可再打开、可导出 |

### 2.5 学科服务

| 功能 | 说明 |
| --- | --- |
| **学科导航** | 四个专业（机械工程、机器人工程、微电子、计算机与人工智能）加 Eddie 自己的方向（多体动力学、有限元、FreeCAD 内核、夹具、缝纫机、历史），每个学科一页：核心教材、经典专著、近期论文、开放课程 |
| **新书新论文通报** | 订阅主题；每天增量收割后，AI 从新增里挑出相关的，写一句话说明为什么相关；首页显示“今日新到” |
| **阅读路线** | 说目标（“三个月入门多体动力学”），AI 从馆藏排出由浅入深的书单和章节，每本说明为什么选 |
| **文献综述起步** | 给一个题目，AI 列出相关文献、分组、各组要点，全部带出处；只做起步材料，不代写 |

### 2.6 文献管理

| 功能 | 说明 |
| --- | --- |
| 我的书架 | 自建书架（例如“多体动力学书参考”“机器人学教材”），一本书可进多个书架 |
| 引文导出 | GB/T 7714、APA、IEEE 格式；RIS、BibTeX 文件（Zotero 可导入） |
| 笔记 | 读书笔记与批注汇总成一份，可导出 Markdown |

### 2.7 管理

| 页面 | 内容 |
| --- | --- |
| 收割管理 | 每个书库：状态、条数、上次 / 下次收割、最近错误、立即收割、日志 |
| AI 用量 | 本月 AI 调用次数和花费；**每月上限**（默认 20 美元，到了只停 AI 功能，检索阅读照常） |
| 设置 | 数据位置、每日收割时间、AI 模型、磁盘占用、备份 |

## 四、AI 怎么接

| 项 | 做法 |
| --- | --- |
| 模型 | Claude，用 Eddie 的 API 密钥（放 Windows 环境变量，不进仓库）。日常问答、导读、编目用 Sonnet；跨书比较、文献综述用 Opus；可在设置里改 |
| 检索增强 | 全文切段（约 500 字一段）建向量；回答前先检索相关段落，只把这些段落交给 AI |
| 出处 | 每段带“书—章—页 / 位置”；AI 回答里每句标编号；代码检查编号存在、引文逐字可查 |
| 缓存 | 导读、译文、编目结果都缓存，同一内容不重复花钱 |
| 本机 AI | 向量（ONNX Runtime，多语种 384 维小模型）和朗读（Kokoro）都在本机 CPU 上跑，不花钱、不用 GPU |
| 断网 | 没网时检索、阅读、朗读照常；AI 功能提示“需要联网” |

## 六、安装

| 项 | 做法 |
| --- | --- |
| 位置 | `C:\Users\<用户名>\wenquest-library\`：`app\` 程序、`data\library.db` 数据库、`data\fulltext\` 全文、`data\mine\` 我的文库、`data\raw\` 收割原始数据、`models\` 本机模型、`logs\`、`backups\` |

| 启动 | 双击快捷方式：启动本机服务（只监听 127.0.0.1:8765）并打开浏览器 |

## 十、风险

| 风险 | 应对 |
| --- | --- |
| AI 费用 | 每月上限；缓存；日常用 Sonnet |
| AI 编造出处 | 引文逐字核对，核不上不显示；验收第 4 条专测 |
| DOAJ 量太大 | 先收最近 10 年 |

| 书库限速或封 IP | 按表限速，出错退避，不加并发 |
| 工作量大 | 分 A–D 四段，每段给 Eddie 看一次 |
