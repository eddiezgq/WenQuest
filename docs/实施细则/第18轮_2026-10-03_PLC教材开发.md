### 2.2 篇幅与结构

- 导论 1 章 + 十一篇 47 章 = **48 章，约 1400 页**（另附录：指令速查、厂家对照、I/O 与电气图样例）。
- 十一篇：控制基础与 PLC 硬件（2–6）、IEC 61131-3 编程语言（7–13）、程序设计方法（14–18）、运动控制（19–23）、工业通信（24–29）、人机界面 SCADA 与批处理（30–32）、安全（33–36）、调试测试与虚拟调试（37–40）、新一代控制器（41–43）、典型设备的控制（44–45）、综合项目（46–48）。
- 一本书覆盖国内“电气控制与 PLC”“PLC 原理及应用”“运动控制系统”“工业控制网络”“组态与 HMI”“机械安全”“自动化系统集成课程设计”，以及研究生“分布式控制与工业 4.0”。提纲第四节给出八种开课方式。
- **项目导向**（吸取《机械制造技术》v0.2 的意见，一开始就这样写）：每篇一个篇首项目（上料输送线、自动分拣线、箱体装配工位、机器人上下料与飞剪、产线联网、操作站、工作站安全、整线交付），本篇各章的任务单是它的里程碑，篇末验收；每章都有现场故障案例。
- **厂家中立**：正文按 IEC 61131-3 与 PLCopen；每章末附西门子、三菱、汇川、罗克韦尔、CODESYS 写法对照。程序能导出 PLCopen XML，带到真实 PLC 上用。

- 《机器人学》第 37 章“控制器硬件”保持入门深度（37.2 梯形图一节），注明“详见《PLC 原理及实践》”；机器人与 PLC 的握手、直接控制在本书第 23 章。
- 《缝纫机设计与制造》第 12 章（自动单元、吊挂）、第 13 章（电磁铁与伺服）、第 20 章（电控原型）与本书第 45 章衔接，用同一个吊挂模型。

- 数字工厂：减速器产线的设备、节拍、MES 数据同源；数字工厂总线早就为真实 PLC 留了位置（`plc/<设备>` 与 `sim/<设备>` 同格式，见数字工厂第 1 轮），本书把它用起来。

### 2.4 “每次课都像电气自动化工程师一样工作”

沿用《机械设计》《机械制造技术》的工程任务单机制，换成电气自动化工程师的工作内容：

| 项 | 做法 |
|---|---|
| 任务单 | 每章至少一张。老师（或 AI）在班级工厂里以“自动化任务”下达：被控设备、动作与节拍、安全要求、交期、要交什么 |
| 交付物 | 功能规格书、I/O 表、电气原理图、PLC 程序（PLCopen XML）、HMI 画面、自动化测试用例与报告、调试记录、FAT/SAT 记录、操作维护说明 |
| 提交与评审 | 提交 → **自动化测试**先跑（测试用例驱动虚拟设备，含故障注入，逐条判定）→ **AI 程序评审员**（双线圈、互锁、急停与复位、扫描相关竞态、命名注释、PLCopen 编码准则；只提意见，可给建议分）→ 老师批准或退回 |
| 进入车间 | 批准的程序下载到数字工厂的**虚拟 PLC**，控制仿真设备运行一个班次 → 产量、节拍、报警、停机回到学生手里复盘 → 再提一次改进 |
| 评分 | 按工程交付评：测试通过率、评审意见已关闭、班次产量与停机、文件完整。评分细则写进实验说明文件，自动生成评分量规 |

### 2.5 本书需要新增的能力（请 Eddie 在 Q4 确认）

**先说结论**：PLC 课的核心是“写程序、对着设备跑、证明它对”。平台现在没有 PLC 编程环境，需要**自研两件（浏览器 PLC 实验台、三维虚拟设备库）**，**新增四个开源软件**（OpenPLC Runtime、FUXA、Eclipse 4diac、open62541/asyncua；pymodbus 是 Python 库），都按 CalculiX 的方式作为独立进程放进计算容器，不影响在线服务。

| 能力 | 用在 | 做法 | 软件 |
|---|---|---|---|
| **浏览器 PLC 实验台**〔PLC〕 | 全书 | 网页里编辑梯形图、ST、SFC、FBD（IEC 61131-3 常用子集），在浏览器里按扫描周期执行；扫描周期逐步播放、在线监视、强制、趋势；导入导出 PLCopen XML。网页端可用；小程序里只能看不能编 | 自研（TypeScript 解释器） |
| **三维虚拟设备库**〔VP〕 | 全书 | 约 16 台设备（提纲第五节），每台有与真实设备一致的 I/O 表、接线图、传感器抖动与故障注入；与实验台直接连，也能经 Modbus 与真 PLC 运行时连 | 自研（three.js，零件库模型） |
| **PLC 运行时**〔RT〕 | 第 4、10、25、28、29、36、39、42 章及综合项目 | 学生程序在服务器上用 MatIEC 编译、OpenPLC 执行，真实扫描周期、Modbus TCP；每个学生一个隔离的运行实例，限时 | **新增** OpenPLC Runtime（GPL，独立进程） |
| **自动化测试**〔TST〕 | 全书，第 38 章最重 | 测试用例写成表格（给输入序列、期望输出与时限），平台在实验台或运行时上自动执行，含故障注入、状态覆盖率，出测试报告；任务单提交时自动跑 | 自研 |
| **工业通信**〔NET〕 | 第 24–29、36 章 | Modbus（pymodbus）、OPC UA 服务器与客户端（open62541 / asyncua）、MQTT（Mosquitto，已有）；报文抓包文件在网页里逐字段解释 | **新增** open62541 / asyncua、pymodbus |
| **HMI / SCADA**〔HMI〕 | 第 17、30–32 章 | 网页组态画面、报警、趋势、配方 | **新增** FUXA（MIT 许可）；Node-RED（已有） |
| **IEC 61499**〔DIS〕 | 第 41 章 | 4diac IDE 是桌面软件，平台提供 FORTE 运行时与示例工程下载 | **新增** Eclipse 4diac（EPL） |
| **数字工厂虚拟 PLC** | 第 12、29、39 章及综合项目 | 批准的程序在 OpenPLC 运行时里控制数字工厂的仿真设备，经总线 `plc/<设备>` 收发消息 | 自研桥接 + OpenPLC |
| **AI 程序评审员** | 全书 | 规则先行（双线圈、未互锁、急停复位、WHILE 循环、未用变量、命名），模型只负责把意见写成通顺的话 | 自研 |
| 计算书〔PY〕 | 全书 | 响应时间、通信负载、PID 整定、凸轮表、安全距离、PL 计算 | 已有工具，只加内容 |

**服务器**：实验台和虚拟设备都在学生浏览器里跑，不占服务器；OpenPLC 运行实例每个约几十 MB 内存，同时 50 个没问题，更多时排队。

**实物（可选，Q5）**：程序可导出 PLCopen XML，导入 CODESYS 系（汇川等）基本可用，导入西门子 TIA 需要少量手工调整；如果要在学校实验室用真 PLC，建议后面另配实验箱（如 S7-1200 或汇川小型 PLC + 输送线模型），书里每章末的厂家对照就是为这个准备的。

### 2.6 样章

建议先做**第 15 章“顺序控制设计”**：它一次用上本书全部新能力——实验台（ST、SFC、梯形图）、三维虚拟设备（电梯、装配工位）、自动化测试（状态覆盖）、AI 程序评审员、数字工厂虚拟 PLC——又是 PLC 课最核心、最能体现“像工程师一样工作”的内容（从控制要求说明写到测试报告）。样章之后从第 1 章顺序写。
