规则（与《机械设计》相同）：
- 主要参照都是国外高水平教材和专著；国内教材（第 J 组）只用来核对国内课程和考研大纲的覆盖面。例外是**工艺尺寸链**和**加工误差统计分析**，这两项是国内课程的重点、国外教材讲得少，第 51、53 章以 Wade、Fischer 等国外专著为主，国内教材作对照；
- 只参照选材和深度，文字、图、习题全部原创；
- 清单注的是“哪一部分内容”，不写章号；写每一章之前逐条核对版本、章节和页码，写进章末参考文献和 `textbook/mfgtech/conventions/参考书目.md`；没写年份的标准和注“最新版”的书，写章时查现行版本补上。

工艺数据按现行国家标准，同时对照 ISO（提纲第二节第 11 条）：铸件公差 GB/T 6414 / ISO 8062-3、模锻件公差 GB/T 12362、冲压件公差 GB/T 13914、塑件公差 GB/T 14486 / ISO 20457、焊缝符号 GB/T 324 / ISO 2553、焊缝质量 ISO 5817:2023、刀片型号 ISO 1832、表面结构 ISO 21920 等。**这些数据做成数字化工艺数据表**（`textbook/mfgtech/std/`），与《机械设计》的标准表（`textbook/mechdesign/std/`）和零件库的 `library/std_tables/` 用同一种格式，重复的表（如极限与配合）只存一份，三处引用。每条注明标准号和表号；手册里的经验数据（切削用量、单位切削力、加工余量）注明手册和版次。

### 2.4 “每次课都像工程师一样工作”的做法

沿用《机械设计》第 11 轮 2.4 节的工程任务单机制，换成工艺工程师的工作内容。

| 项 | 做法 |
|---|---|
| 工艺任务单 | 每章至少一张。老师（或 AI）在**班级工厂**（工厂第 10 轮）的 ERPNext 里以“工艺任务”下达：零件、批量、设备、交期、要交什么 |
| 交付物是车间文件 | 铸造工艺图、锻件图、冲压工艺卡与排样图、模具总装图、焊接工艺规程（WPS）、机械加工工艺过程卡与工序卡、数控程序与刀具清单、夹具图、过程 FMEA 与控制计划、检验计划、首件检验报告、8D 报告 |
| 提交与评审 | 走已有的“设计发布与审批”，增加**工艺类文件**：提交 → **AI 工艺评审员**先审（基准选择、余量与尺寸链、切削参数是否在设备能力内、焊缝符号与标准合规、模具结构常见错误，只提意见、不打分）→ 老师批准或退回 |
| 进入车间 | 批准后 ERPNext 的**工艺路线、工时、BOM 自动更新**（数字工厂已能更新 BOM 与设计版本，本轮扩展到工艺路线和工时）→ 车间终端派工 → 仿真设备加工 → 三坐标与在线检测 |
| 质量复盘 | 尺寸数据、Cpk、废品和成本回到学生手里；学生再提一次工艺改进，形成闭环 |
| 工具链标注 | 每个实验和任务单标明工位：〔CAD〕〔PLM〕〔ERP〕〔MES〕〔QMS〕〔FEA〕〔FAT〕〔MBD〕〔CAM〕〔PY〕，以及本书提出的〔THM〕〔CFD〕〔CNC〕〔AM〕〔SPC〕（见 2.5 节） |
| 评分 | 按工程交付物评：工艺文件正确完整、评审意见已关闭、零件加工检验合格、成本与交期达标。评分细则随每张任务单写进实验说明文件，自动生成评分量规 |

不是每章都走完整条链。第 50 章“工艺规程设计”的任务单走全链（工艺分析 → 工艺规程 → 评审 → 更新 ERPNext 工艺路线 → 派工 → 仿真加工 → 三坐标 → 控制图），成形各章以〔THM〕〔CFD〕〔PY〕仿真和工艺文件为主。

### 2.5 本书需要新增的能力

**先说结论**：你列的开源软件全部用上；制造工艺比机械设计多了“热”和“流动”两类计算，以及“机床运行 G 代码”这一步，需要**扩展一个已有求解器、新增四个开源软件**。新增的都按 CalculiX 的方式，作为独立进程放进计算容器调用（都是 GPL / AGPL 类许可，独立进程调用不影响在线服务），请你在 Q4 确认。

| 能力 | 用在 | 做法 | 软件 |
|---|---|---|---|
| **热与非线性有限元**〔THM〕 | 第 4、6、10、11、15、17、21、28 章 | 扩展工厂第 11 轮的计算服务：瞬态传热（含凝固潜热）、热—力顺序耦合、弹塑性大变形与接触。教学题：圆棒淬火、箱座凝固与 Niyama 判据、镦粗、V 形弯曲回弹、T 形接头焊接变形（Goldak 移动热源）、模具冷却。同一规模上限（约 20 万单元、5 分钟） | CalculiX（已有求解器，用它已有的传热、塑性、接触功能），不增加新软件 |
| **充型流动**〔CFD〕 | 第 10、28、62、63 章 | 铸件浇注充型（OpenFOAM 的自由液面求解器）；注塑充填（openInjMoldSim，基于 OpenFOAM 的开源注塑求解器，有公开的验证论文）。三维充型计算量大，**教学版只算简化几何，书中的典型算例预先算好、可回放**；同时写一个浏览器里的 Hele-Shaw 二维半充填程序，学生能即时改浇口看结果 | **新增** OpenFOAM、openInjMoldSim |
| **虚拟数控机床**〔CNC〕 | 第 46–48、61 章 | G 代码在虚拟机床上运行：插补、加减速、螺距补偿、材料去除显示、碰撞检查；学生写的程序先在这里过，再派到仿真车间 | **新增** LinuxCNC（仿真配置）、CAMotics；与工厂第 13 轮 CAM 合做，不另起一套 |
| **增材切片**〔AM〕 | 第 29、32–33、63 章 | 服务器上用命令行切片：给出打印时间、用料、支撑，接 ERPNext 算成本、接车间派工 | **新增** PrusaSlicer |
| **质量统计**〔SPC〕 | 第 53、56–58 章 | 扩展自研 QMS：测量系统分析（重复性与再现性）、过程能力（Cp、Cpk、Pp、Ppk）、控制图判异、过程 FMEA 与控制计划模板，数据直接取车间检测记录 | 自研（Python 统计） |
| 工艺计算书与实验台〔PY〕 | 全书 | 与第 11 轮同一个浏览器内 Python 和计算书模板；新增切削（正交切削、Kienzle 力、Taylor 寿命、叶瓣图、粗糙度）、成形（冲裁力、排样、回弹、模锻力）、焊接（Rosenthal、碳当量）、注塑（Cross–WLF、Tait、锁模力、冷却时间）、尺寸链（极值、概率、蒙特卡罗）、定位误差等实验台 | 已有工具，只加内容 |
| 工艺文件编制器 | 全书，第 50、61 章最重 | 网页里编写工艺过程卡与工序卡（JB/T 9165 格式）：工序简图从三维模型截取，工序、工时、设备直接对应 ERPNext 的工艺路线，导出 Word / PDF；铸造工艺图、焊缝符号用 FreeCAD TechDraw | 自研 + FreeCAD |
| 工艺路线回写 | 全书 | 批准的工艺文件自动更新 ERPNext 工艺路线（工序、工作中心、工时）；现在只回写设计版本和 BOM，本轮扩展 | 自研 + ERPNext |
| AI 工艺评审员 | 全书 | 在第 11 轮“AI 评审员”上加工艺规则：基准原则、余量与工序尺寸、切削参数 vs 机床功率与刀具、焊缝符号与 WPS 要素、模具与塑件设计规则、FMEA 评分一致性 | 自研 |
| 数字化工艺数据表 | 全书 | 见 2.2 节；与《机械设计》、零件库共用格式和重复表 | 自研 |
| 有限元、疲劳 | 第 16、21、27、33、52、54 章 | 工厂第 11 轮，已上线，直接用 | Gmsh + CalculiX、pyLife |
| 多体动力学 | 第 23、29、49、55、59 章 | **依赖工厂第 12 轮**；之前先用浏览器内 MuJoCo（零件库已用）做简单演示 | MuJoCo、Project Chrono |
| 数控编程 | 第 33、46–48、61–62 章 | **依赖工厂第 13 轮**；已有的键槽 CAM（`freecad/wq_cam_keyway.py`）先用 | FreeCAD CAM / OpenCAMLib |

每做一种新类型，先在样章或最早用到它的那一章里用，用无头浏览器试做通过。

**服务器**：热分析和弹塑性分析与第 11 轮的线性静力同一量级，8 GB 服务器能跑教学题；三维充型（OpenFOAM、openInjMoldSim）明显更吃内存和时间，教学版先“预算好 + 简化题在线算”。如果以后要让每个学生都在线跑三维充型，需要单独一台计算服务器——到时我先测，再告诉你。

### 2.6 与另五本书和平台课程的关系

- **与《机械设计》分工**：设计书第 4 章（公差）、第 6 章（制造工艺与 DFM/DFA）、第 26 章（焊接胶接铆接的设计计算）、第 43 章（数控加工与 CAM）、第 44 章（数字主线）、第 49 章（夹具与自动化装备）是从**设计者**的角度讲制造，作为入门和接口；本书从**工艺者**的角度讲透。两书互相注明章号；设计书第 43 章保持入门深度，深入内容放本书第 46–48 章（Q6）。
- **与《机器人学》分工**：《机器人学》讲运动学、控制和编程；本书第 23、49、55、59 章讲机器人在制造中的工艺应用。
- **与《大学物理》**：传热、流体、固体力学的原理在物理书里，本书讲工程应用。
- **术语**：六本书同一个中文术语的英文名必须一致（术语一致检查扩展到六本书）；本书术语以《机械工程名词》和 GB/T 4863 为准。
- **数据**：材料数据与工厂有限元服务的材料库同源；工艺路线、工时、费率与数字工厂的 ERPNext 同源；标准表与《机械设计》、零件库共用。
- **平台课程**：本书成为 AI 建课里“机械制造技术基础”“工程材料及成形技术基础”“机械制造工艺学”“数控技术”“模具设计”“焊接工艺”等课程的主教材。
