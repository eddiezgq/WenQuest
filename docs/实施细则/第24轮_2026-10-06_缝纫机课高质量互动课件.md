## 三、方案

### 3.1 课件改成网页互动课件（建议，Q1）

每讲一个网页课件（单个 HTML 文件，和虚拟实验一样能直接挂进课程、放进网页版教材）：

- **动画、虚拟实验、三维样机直接嵌在页面里，当场可以操作**：讲到哪页，那页就是活的实验——拖滑块、转样机、点零件、试缝，和学生自己做的是同一个页面。不用切换窗口。
- **PowerPoint 做不到这一点**：PPT 里只能放视频、图片和链接，网页实验在 PPT 里无法运行（要装第三方插件，不稳定）。所以另外导出一份 .pptx 给需要 PowerPoint 的老师：实验页放一张大截图 + “点此运行”链接，其余页面与网页课件相同。

### 3.2 “高质量、有震撼力”的具体标准（写成检查项，逐页验收）

1. **一页一个意思**：每页最多 3 行字；正文中文 ≥ 36 号（1080p 下约 48 像素），英文 ≥ 28 号；看不清的不出现在页面上，细节放讲稿和讲义。
2. **图要大**：插图至少占页面一半，组合图拆成单幅逐张出现；图中最小的字在 1080p 下不小于 22 像素。教材图有网页源文件（`figsrc/`），按幻灯片尺寸重新出图，不是把原图缩小。
3. **画面风格统一、电影感**：深色舞台底、大标题、强调色只用一两种；三维样机做封面和章节过渡（大角度环绕、慢放成线的大特写）。
4. **有节奏**：要点逐条出现；关键公式逐步推出；机构图上用高亮框、箭头引导视线；每讲至少 3 个“活”的页面（动画、实验或样机）。
5. **数字与教材一致**：算例页的数字由课程包程序算出（同第 23 轮规则）。

### 3.3 录课模式（建议，Q3）

Eddie 每天自己录视频，课件按录课来设计：

- **讲者视图**：另一个窗口（或第二块屏幕）显示当前页、下一页、讲稿（课程包里每页都有讲稿）、计时器；观众窗口只有课件。
- **提词**：讲稿可以大字滚动，跟着翻页走。
- **一键录制**（可选）：在浏览器里录“课件画面 + 麦克风 + 摄像头小窗（可开关、可拖动位置）”，存成视频文件。不想用也可以照常用 OBS 等软件录。
- **画面留位**：每页右下角留出摄像头小窗的位置，不挡内容。
- 以后做数字人：录下来的视频和讲稿就是数字人的素材，本轮不做。

### 3.4 中文版、英文版分开（建议，Q2）

不再中英挤在一页。每讲一个课件，右上角切换“中文 | English”，两种语言的页面、动画、实验各自完整显示（实验本来就有中英两版）。B 站录中文版，YouTube 录英文版。

### 3.5 和第 23 轮（自动配音视频）的关系（Q5）

Eddie 改为自己录课，第 23 轮缝纫机课的“自动配音成片”建议**暂停**：工具和第 2 讲样片保留（以后做数字人可用）；B 站、YouTube 发布改为发 Eddie 自己录的视频，上传资料（标题、简介、章节时间点、字幕）仍可由工具生成。

### 8.1 Q1：照《大学物理》的做法（已实现的部分直接用）

查了《大学物理》第 1 章课件（`samples/大学物理/课程资料/第1章 质点运动学/第一章课件.pptx`）和平台的课件放映器（`services/gateway/app/slides.py`、`apps/web/src/components/SlidePresenter.vue`），已经实现的是：

- 课件仍是 **.pptx**，在 PowerPoint 里也能放；
- **动画页**：动画以视频嵌进 PPT，放到这一页就在原位播放（PowerPoint 和平台放映器都能播）；
- **虚拟实验页**：实验大截图 + “打开虚拟实验”按钮（链接）。在平台放映器里，点它或工具栏的“⚗ 去做实验”，**实验就在课件旁边打开、可以直接操作**，切回课件停在原页，再切过去实验参数还在；在 PowerPoint 里点链接用浏览器打开实验。

所以缝纫机课照这个做：.pptx + 嵌入动画视频 + 实验页按钮，在平台上放映即可当场操作实验。不另做网页课件（3.1 作废）。

缝纫机课要补的两件事：
1. **动画视频**：缝纫机课的动画是网页动画（301 线迹形成、虚拟样机慢放成线等），没有现成的视频。用第 23 轮的录屏工具把它们录成 MP4（无声、只录画面），嵌进 PPT。三维样机的环绕、拆开、慢放成线也录成短片，做封面和过渡。
2. **放映器认出缝纫机课的实验**：放映器按实验名里的编号找实验，缝纫机课的实验叫“虚拟实验 2-1”（短横），课件里写“实验 2.1”时对不上，会打开本讲的第一个实验。改为短横和点都认。
