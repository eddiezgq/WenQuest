## 四、施工顺序与验收

1. 每段先写讲稿（一句话定位 + 3～5 个要点 + 打开方式），放 `docs/课程视频/首页简介/<编号>/讲稿.yaml`，Eddie 审讲稿（可以一次审完 16 段）。
2. 录屏、合成配音、出片；自查（画面对得上讲稿、字幕不压画面、没有真实个人信息）。
3. 英文版私密上传 YouTube、中文版放下载页 → Eddie 在 YouTube 公开、在 B 站投稿 → 发回 BV 号（YouTube 编号工作流自动记下）→ 填进 `catalog.yaml` → 两站首页上线。
4. 首页“▶ 视频”按钮和弹出播放器可以先做（没有 BV 号的不显示），不等视频。

## 五、成本与时间

- 配音租 GPU：16 段 × 约 2 分钟，合计约 2～3 美元；GitHub Actions 运行时间每段约 20～40 分钟。
- 节奏建议：每天 3～4 段，约一周做完；先做 1（全貌）、2（平台）、7（数字工厂）、17（评价与校情）。
