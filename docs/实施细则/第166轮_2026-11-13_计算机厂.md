## 一、照前几座厂的路子

新厂只写一份清单，只补这座厂特有的东西（第 85、103、125、131 轮）。物料、BOM、工艺、设备、检验特性、布局写进 `factory/plants/wenquest-computer.yaml`，其余各领域（订单、计划、ERP、MES、质量、设备、三维车间、AI 巡检、帮助）按清单接上。

**计算机厂做什么**：四类整机，自己做主板、内存条、机箱和笔记本外壳，CPU、内存颗粒、硬盘、屏幕、电池、电源外购。

```
主板线（SMT）：来料检验 → 锡膏印刷 → 锡膏检测 → 贴片（2 台）→ 回流焊 → 光学检测 → X 光检测（BGA）→ 插件波峰焊 → 在线测试 → BIOS 烧录
内存条线：贴片 → 回流 → 内存测试（高低温、时序余量）→ 贴标签
结构件线：激光切割 → 数控折弯 → 压铆 → 喷粉（台式、服务器机箱）；CNC 加工 → 阳极氧化（笔记本 A、C 面铝壳）
整机线：CPU 安装与涂导热硅脂（点胶机）→ 整机装配（台式 / 笔记本 / 服务器三个工位）→ 开机自检与系统灌装 → 老化（老化房）→ 整机功能测试 → 包装
整机柜：上架、布线（电源、网络）→ 整机柜联调（满载、散热、功耗）→ 整柜出货
```

| C-3 | **车间（约 26 台设备，示例布局）**：上面五条线的设备；`equip.py` 补没有的设备类别（X 光检测、BIOS 烧录台、内存测试机、激光切割机、数控折弯机、压铆机、喷粉线、CNC、阳极氧化线、点胶机、老化房、整机柜联调台等，保养、故障、功率、危险源、点检项都是示例值）；贴片、回流、光学检测沿用电路板厂的类别 | 计算机制造的标准工序 |
| C-4 | **测量特性（示例名义值和散布）**：主板——锡膏厚度、BGA 空洞率（X 光）、在线测试通过；内存条——时序余量、高低温测试错误数；结构件——折弯角度、孔位偏差、笔记本壳平面度、阳极膜厚；整机——CPU 满载温度、风扇噪声、待机功耗、开机时间、内存带宽、老化通过；整机柜——满载功率、进出风温差、交换机链路误码 | 进 MES、质量、控制图 |
| C-5 | **老化曲线（本厂独有的追因手段，相当于电机厂的终检波形）**：每台整机老化出一条曲线——CPU 温度、风扇转速、整机功耗随时间（满载压力测试 + 空闲交替）。硅脂少 → 满载温度高且上升快；风扇坏 → 某一路转速掉、温度跟着上去；内存焊点虚 → 老化中途报内存错误（曲线上有标记）；电源纹波大 → 功耗曲线抖。只存生成参数，网关还原；满载温度、平均功耗由曲线算出（测试核对一致）。页面“整机老化曲线”只在计算机厂导航里出现 | 老化房的温度 / 功耗记录是整机厂的真实追因手段 |
| C-6 | **四种隐藏问题与措施**：① 点胶机针头半堵，硅脂量少（只影响它点过的整机满载温度）；② 回流炉某温区偏低（BGA 空洞率上升，老化中出现内存错误）；③ 折弯机后挡料偏移（机箱孔位偏，整机装配卡、返工）；④ 内存测试机一个测试座接触不良（假不良，好条被判坏）。各有对症措施，另有看似有理但不对症的（老化时间加长、风扇调高转速、终检放宽） | 与前几座厂“隐藏问题”同一套 |

## 三、规则

1. 前七座厂行为不变；机器人厂只改控制柜拆出工控机（C-7）。现有测试不改断言通过（工厂名单类测试按数据加一项，不是放宽）。
2. 不编参数：外购件通用名称 + “型号待确认”；单价、工时、名义值、散布都标示例值。
3. 计算机厂从清单起来后，订单 → 算料 → ERPNext → 车间 → 检测 → 入库 → 开票整条走通。
4. 效率优先：服务器演练只作参考，不卡上线（Eddie 11-10 定）。
