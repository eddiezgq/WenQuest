### 2. 作业卡“时间重叠”（417）

- 查实：出现在两张**不同工单**、同一工位的作业卡之间（例如 PO-JOB00012 和 PO-JOB00005）。原因是教学情景每次重载，工厂时钟回到情景起点，新工单的工时和上一次情景里同一工位的工时落在同一段时间，ERPNext 按“一个工位同一时间只能做一件”拒收。
- 这 8 次失败里，没有一次是它造成的（它在日志里出现，是因为失败后把桥接的错误全打出来）；但它是真毛病，会让情景重载后的作业卡记不上工时。
- **本轮不改**（偏差）：要改得动情景重载怎么处理上一次的作业卡（作废、或工厂时钟不回退），影响教学情景，单独开一轮、先和 Eddie 定。

### 3. 改动

- `factory/digital/tests/closed_loop.py`：供应链段急单前注入“备选下一批：正常”，检验必须合格；任务 4 超时诊断。
- `factory/digital/tests/check_cae.py`：轴承报警缺失时的诊断。
- 本机数字工厂单元测试 553 通过、11 失败（失败的是本机缺求解器等环境，和 main 上一样，不涉及这两个脚本）。

### 4. 验收方式的偏差（待 Eddie 定）

细则写的是“推到分支手动连跑 3 次”。查了工作流：手动触发数字工厂部署会连带**把分支部署到服务器**，分支落后于 main 时会把别的会话已经上线的东西暂时退回去，不能这么跑。改为：**合并后看 main 上接下来 3 次带演练的运行**（别的会话推送也会触发，不额外花用量），3 次都一次通过算验收通过；出现新的偶发按第一节的办法查。
