## 二、Eddie 要在外面申请的（程序不等它们，批下来填 `.env`）

**阿里云短信服务**（1～2 个工作日）
1. 阿里云控制台搜“短信服务”，开通。
2. “国内消息 → 签名管理 → 添加签名”：签名“问渠科技”，适用场景“验证码”，来源选“企事业单位全称或简称”，上传营业执照。
3. “模板管理 → 添加模板”：类型“验证码”，内容 `您的验证码为：${code}，5 分钟内有效，请勿泄露于他人。`
4. “访问控制 RAM → 用户 → 创建用户”：只勾“OpenAPI 调用访问”，给它授权 `AliyunDysmsFullAccess`，得到 AccessKey ID 和 Secret（**只填进服务器 `.env`，不要发到聊天里**）。
5. 审核通过后服务器 `.env` 填：`WQ_SMS_ACCESS_KEY_ID`、`WQ_SMS_ACCESS_KEY_SECRET`、`WQ_SMS_SIGN=问渠科技`、`WQ_SMS_TEMPLATE=SMS_xxxxxx`（模板 CODE），重启网关。

**微信开放平台**（认证几天，网站应用审核 1～7 天）
1. https://open.weixin.qq.com 注册开发者账号（用公司邮箱）。
2. “账号中心 → 开发者资质认证”：企业认证，300 元/年，上传营业执照等。
3. 认证通过后“管理中心 → 网站应用 → 创建网站应用”：名称“问渠科技学习平台”，网站地址 `https://learn.wenquestech.online`，授权回调域 `learn.wenquestech.online`，上传网站信息登记表（盖章）。
4. 审核通过后得到 AppID、AppSecret，服务器 `.env` 填 `WQ_WECHAT_WEB_APPID`、`WQ_WECHAT_WEB_SECRET`（Secret 不要发到聊天里），重启网关。
