## 一、定位：一句话要一段工程级三维仿真视频

- **用户**：老师（课件、讲课视频），学生（实验报告、毕业设计展示），企业（产品展示、方案汇报、投标演示、操作培训、售后说明）。
- **用户做的事**：说一句要什么（“六轴臂从料台抓件放上传送带，透视电机，标关节角”），或者从平台里已有的东西一键出发：一个零件或装配、一次多体动力学仿真、一次有限元或流体结果、一个 CAM 刀路、一台数字孪生设备。
- **平台做的事**：AI 写场景脚本 → 运动由我们的求解器算（逆运动学、MuJoCo 多体动力学、刀路、流场）→ Blender 渲染 → 叠中英标注和读数 → 出 MP4 / WebM。几分钟先看低清小样，满意再出高清。
- **和别家的区别**：
  - **动作是算出来的**，不是动画师手调的，读数可信，可以写进报告和课件；
  - **和平台数据贯通**：设计、仿真、工艺、孪生的结果直接变成视频，不用导出再找人做；
  - **不装软件**，浏览器里下单，云上渲染。

## 二、在平台里长什么样

1. **入口**（三处，同一个功能）：
   - 数字工厂里每个结果页（多体、有限元、流体、CAM、孪生）上的 **“出三维视频”** 按钮；
   - AI 建课和白板课的 **“插入三维视频”**；
   - 独立的 **“三维视频”** 菜单：写一句要求，选模型（零件库、上传 STEP 或 glTF、程序生成的机械臂和机构）。
2. **小样**：先出 960×540、每秒 15 帧的低清版，约几分钟；网页上直接看，可以逐条提意见（“镜头再近一点”“第 3 步慢一点”“加剖面”），AI 改脚本重出。
3. **高清出片**：1920×1080，30 帧，MP4 和 WebM，中英标注，可选配音（平台 AI 声音）。
4. **风格**：
   - 工程图风格（默认，便宜快）；
   - 写实风格（产品宣传、投标，用 GPU）；
   - 透视、剖面、慢放、读数面板、轨迹线、力和力矩箭头，都是可选的“镜头效果”。
5. **交付**：进用户的素材库，可插进课件、白板课、报告；企业版可以下载原文件，可以加自己的标志。

## 三、技术路线

| 部分 | 做法 |
| --- | --- |
| 场景脚本 | 第 36 轮的 `scene.py` 改成通用格式：模型、运动来源、镜头、效果、标注都用数据描述（YAML），AI 只写数据，不写代码 |
| 运动来源 | 逆运动学路线（样片 A 那套）；数字工厂多体动力学（MuJoCo）结果；CAM 刀路回放；有限元变形和云图；流体流线；孪生的运行记录 |
| 模型来源 | 零件库（`library/`，含机械臂、腿式机器人等，只用许可证允许商用的）；教材 glTF；用户上传 STEP（转 glTF）；程序生成的参数化机构 |
| 渲染 | Blender（GPL，作为服务器上的独立程序调用，不分发，平台代码不用公开）。工程图风格用 CPU；写实风格用 GPU |
| 出片速度 | 帧切成多份并行渲染。开发和内部出片用 GitHub 免费构建机；平台上给用户出片用自己的渲染机：CPU 机器并行，写实走租用 GPU（照 `gpu-run.yml`，用完关机） |
| 检查 | 程序自动查：模型在画面内、不穿模、字不出框、读数与计算一致、每段动作在镜头里完整 |
| AI | 国内用 DeepSeek，美国用 Claude（照合规规定）；AI 只负责写场景数据和解释，不负责算运动 |

## 四、收费思路（以后，先做教学）
