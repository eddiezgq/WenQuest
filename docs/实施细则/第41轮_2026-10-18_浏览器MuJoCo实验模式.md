## 一、决定

1. **用 MuJoCo 官方的浏览器版。**
   - 包：npm 包 `@mujoco/mujoco`，由 Google DeepMind 维护，Apache-2.0 授权。
   - 版本：3.14.0，与教材构建、数字工厂用的 Python 版 `mujoco==3.14.0` 同一版本。
   - 线程：用单线程版。它不需要服务器另设安全头，手机上也能跑。
   - 已实测：同一个摆的模型走 2000 步，浏览器版与 Python 版的角度、角速度在 10 位有效数字上完全一样。所以书里的数字由 Python 程序算出，学生在网页上看到的是同一个结果。
2. **自己托管，不走外网。**
   - 文件放 `site/vendor/npm/@mujoco/mujoco@3.14.0/`（第 34 轮的做法），国内也能用。
   - 计算核心约 10 MB，压缩传输约 3 MB。只有用到物理仿真的实验才下载，下载一次后浏览器会缓存。
3. **实验框架加“物理仿真”模式。** 实验页的写法照旧（`WQ.lab({...})`，有场景、参数、任务、图例），只多一项 `physics`：
   - 模型：写在实验里的一段 MJCF（MuJoCo 的模型文件），或从书的模型库里取。
   - 参数映射：滑块改的是模型里的量，例如质量、阻尼、负载、控制输入。
   - 运行：按“开始”后实时步进，可以暂停、慢放、复位。
   - 显示：用现有的三维画布（three.js）按刚体位姿画；曲线区画能量、关节力矩、角速度等随时间的变化。
   - 判定：任务按仿真状态自动判，例如“能量误差在 0.1% 以内”“哪个关节先超限”。
4. **机器人模型：物理参数和外观分开取。**
   - 物理参数取 MuJoCo Menagerie（DeepMind 维护的模型集）的 UR5e、Franka FR3，与零件库、数字工厂同一个固定提交。各模型的许可证照零件库规则逐个核对（UR5e 是 BSD-3 条款）。
   - 原版网格有 32 MB，太大，网页版不带网格。碰撞用简单形体（胶囊、方块）代替，并在书里注明。
   - 外观用书里已有的零件库 glTF（每台约 0.8 MB），按连杆坐标系把两者对上。
   - 简单物体（方块、圆柱、两连杆、陀螺）由实验直接写 MJCF。
5. **构建时核对。**
   - 教材构建对每个物理仿真实验，用 Python 版 MuJoCo 跑同一个模型，算出指导书里的数字和任务阈值，并检查任务确实能完成。
   - 实验试做（无头浏览器）照旧。
6. **先给第 23 章用，后面各章跟着用。**
   - 第 23 章“刚体动力学基础”：转动不同形状的物体看稳定性（网球拍定理）；
   - 第 24 章：两连杆自由下落的能量曲线；
   - 第 25 章：UR5e 搬重物时六个关节的力矩；
   - 第 27 章：调夹紧力抓住零件；
   - 第 29 章：UR5e 抓取。
   - 以后《大学物理》《机械设计》也可以用同一个模式。
