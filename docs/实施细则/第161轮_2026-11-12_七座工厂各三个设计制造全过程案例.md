## 一、要做成什么样

每个案例都像平缝机 WQ-LS（第 138 轮）那样，从一张设计任务书一路做到工厂里造出来、检验合格，**每一步都用问渠自己的软件算、仿真、出结果**，结果全部可以重新生成。

三个案例的关系：**简单（A，一个零件或一个模块）→ 中等（B，一个部件）→ 完整（C，整台产品）**，A、B 正好是 C 里的零部件。学生先做 A，再做 B，最后做 C 时 A、B 直接用上。

每个案例都走这八步（简单案例的某些步可以很短，但不跳）：

| 步 | 内容 | 产出 |
|---|---|---|
| 1 任务书 | 用途、性能指标、工况、约束 | 设计任务书（一页） |
| 2 方案 | 两三个方案比较、选定 | 方案比较表、简图 |
| 3 计算 | 强度、寿命、电磁、电路等按教材方法手算 | 计算书（中英对照，每个数有出处） |
| 4 仿真 | 有限元、模态、热、多体动力学、电路仿真、固件仿真等 | 仿真结果图、对照手算 |
| 5 三维与图纸 | FreeCAD 三维、工程图 / KiCad 原理图与 PCB / 版图 | 模型、图纸、BOM |
| 6 工艺 | 工艺路线、工序卡、CAM 刀路（G 代码）/ 贴片程序 / 测试程序 | 工艺文件 |
| 7 制造 | 在这座数字工厂里下单、算料、排产、车间加工、检验，看合格率和成本 | 工单、检验记录、成本 |
| 8 总结 | 校核结果一览（全绿才算过）、改了哪些设计、留给学生的问题 | 案例总结 |

## 三、放在哪、怎么看

- 资料：`docs/设计/<工厂>/<案例号>_<名称>/`（任务书、计算书、图、模型、工艺、制造记录、总结），每个案例一个生成脚本 `tools/cases/<案例号>.py`，改参数重跑即全部更新。
- 网页：数字工厂每座厂加一页“设计案例”，三张卡（A、B、C），点进去按八步展开，每步有“打开这个软件”按钮（在线设计、有限元、电路分析、电路板设计、芯片设计、零件库选型……），带着这个案例的参数打开。
- 第 7 步“制造”用这座厂本身：案例的零件 / 产品就是厂里的物料，学生可以照着下单走一遍。
- 帮助：每座厂的帮助加“设计案例”一章（中英）。
- 诚实标注：都是**示例设计，经计算和仿真校核，没有实物试制**。
