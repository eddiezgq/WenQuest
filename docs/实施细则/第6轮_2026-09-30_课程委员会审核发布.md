## 二、流程

```
老师和课程负责人讨论、修改（几轮都可以）
        │  老师点“提交审核”
        ▼
AI 预审（独立的审核专家，不是写课的团队）── 预审意见 ──► 老师：可以改了再交，也可以带着意见交委员会
        │
        ▼
课程委员会审核：看课件、讲义、视频、实验、作业和 AI 预审意见
        ├─ 批准 ──► 自动发布给学生
        └─ 退回（写明意见）──► 回到老师，改完再提交（AI 重新预审）
```

- 现在的“通过并发布”按钮改成 **“提交审核”**；委员会批准前，学生看不到。
- 已经发布的课不受影响；之后再改，也要走一遍审核（只审改动部分）。

## 三、AI 预审

- **谁来审**：一位独立的“审核专家”（用 Claude Opus，开深度思考），**不看写课团队的自评**，只看成品和教材、课程设计书、课程标准。
- **审什么**（每项给 ✓ / ✗ / 存疑，并指出位置）：

| 方面 | 内容 |
|---|---|
| 学术正确 | 概念、公式、推导、数值和单位；与主教材及教材研读笔记一致 |
| 课程标准 | 实际问题 → 概念 → 动画 → 虚拟实验 → 建模求解，五步齐全；机器人问题是本课的，另有一个生活例子 |
| 完整 | 讲义、课件、讲解视频、动画、虚拟实验（能完成）、实验指导书和报告模板、练习与答案、教案 |
| 教学 | 目标清楚、难度与学生层次相符、前后课衔接、课时量合理 |
| 双语 | 中英对照一致、术语统一 |
| 来源与合规 | 素材来源和许可、工厂数据注明、无个人信息、无版权问题 |

- **预审意见**：总体结论（建议批准 / 修改后批准 / 建议退回）、问题清单（严重程度、位置、怎么改）、亮点；存档。
- 老师看到意见后：点“按意见修改”交给课程负责人改（仍是提议—确认），或者直接“提交委员会”（意见随附）。

## 四、课程委员会

- **成员**：管理员在“管理”页指定（问渠账号），其中一位是**主任**。
- **审核页**（委员登录后左侧“课程审核”）：待审列表；每项可看学生视角的全部内容、AI 预审意见、老师的说明；写意见；**批准 / 退回**。
- **通过规则**、**审核单位**、**老师本人能否审自己的课**：见第六节，待 Eddie 定。
- **通知**：提交、批准、退回都发站内信和邮件给相关人。
- **记录**：每次提交、预审意见、委员意见、结论和时间都留档，可追溯。
