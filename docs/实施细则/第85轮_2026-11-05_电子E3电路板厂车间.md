## 三、规则

1. 减速器厂、机器人厂行为不变：现有测试不改断言通过（机器人厂改供应商的那两样除外，相应测试跟着改并写明）。
2. 不编参数：外购件写通用名称 + “型号待确认”；单价、工时、名义值、散布都标示例值。
3. 电路板厂从清单起来后，订单 → 算料 → ERPNext → 车间 → 检测与测试 → 入库 → 开票整条走通；机器人厂向它买驱动板也走通。
