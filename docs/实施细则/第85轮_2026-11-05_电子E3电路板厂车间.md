## 一、照机器人厂的路子

机器人厂（第 45 轮）证明了“新厂只写一份清单、不改代码”：物料、物料清单、工艺、设备、检验特性、布局写进 `factory/plants/<厂>.yaml`，
ERPNext、订单与计划、车间仿真、质量、成本、三维车间、设备维护、能源、安全、人员、经营、AI 巡检都按清单接上；

| B-1 | **清单 `factory/plants/wenquest-pcb.yaml`**：问渠电路板厂（示例）。产品三种：**关节伺服驱动板 DRV-JOINT**、**AGV 控制板 CTRL-AGV**、**编码器读头板 ENC-RD**（以后卖给传感器厂）；物料：PCB 光板（外协板厂）、MCU、栅极驱动、功率 MOSFET、采样电阻、电容、连接器、锡膏等，一律写通用名称 + “型号待确认”、示例单价，不编厂商型号 | 方案 Q2；外购件不编型号 |
| B-2 | **SMT 车间（约 13 台设备，示例布局）**：锡膏印刷 SP-1、锡膏检测 SPI-1、贴片机 PP-1 / PP-2、回流炉 RF-1、自动光学检测 AOI-1、选择焊 SW-1、在线测试 ICT-1、烧录 PG-1、功能测试 FCT-1、三防涂覆 CC-1、老化房 BI-1、包装台 PK-1；`equip.py` 加这些设备类别（维护项目、危险源、能耗按类别有缺省值） | 方案第七节表格 |

| B-4 | **仿真车间里的电子厂问题**（给以后的追因实验）：钢网堵孔（锡膏体积逐渐偏低 → 少锡）、回流炉温漂（峰值温度下降 → 冷焊）、PP-2 某个吸嘴磨损（只在一台、一个料位偏移）、一批采样电阻超差（FCT 采样误差偏大）；每个有对症的措施（擦钢网、校炉温、换吸嘴、隔离批次），措施后消失 | 与减速器厂、机器人厂“隐藏问题”同一套（`sim/errors.py` 按厂分） |

## 三、规则

1. 减速器厂、机器人厂行为不变：现有测试不改断言通过（机器人厂改供应商的那两样除外，相应测试跟着改并写明）。
2. 不编参数：外购件写通用名称 + “型号待确认”；单价、工时、名义值、散布都标示例值。
3. 电路板厂从清单起来后，订单 → 算料 → ERPNext → 车间 → 检测与测试 → 入库 → 开票整条走通；机器人厂向它买驱动板也走通。

## 五、施工顺序

1. 清单（物料、BOM、工艺、设备、布局、测量特性）→ 本地起一座电路板厂，接单走通。
2. 设备类别与仿真里的电子厂问题、措施。
3. 机器人厂改供应商、两厂互发订单；CI 演练。
4. 各领域打开、AI 巡检规则；帮助一册。
5. 部署、线上走一遍；同步。
