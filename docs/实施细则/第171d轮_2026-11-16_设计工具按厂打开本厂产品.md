# 实施细则 · 第 171d 轮：设计工具按厂打开本厂的零件和产品

日期：2026-11-16
依据：第 171 轮后的计划第 2 项（Eddie 11-15 “好，开始”、11-16 “继续”）：好几个页面默认打开、写死的是减速器厂的输出轴 SH-301，在别的厂打开不对。
状态：**已完成**（11-16，结果见第三节）。

## 一、决定

| 编号 | 决定 |
|---|---|
| D-1 | 每个厂定一个**主零件**、一个**主产品**，由清单推出来，不另写：演示工厂是 SH-301 / WQR-105；其余厂主产品 = 清单第一个产品，主零件 = 清单里第一个自制件（没有自制件取第一个半成品，再没有取主产品）。`/api/config` 的 plant 里给出 `main_part`、`main_product` 和本厂有工艺路线的物料表 `make_items` |
| D-2 | **工艺规程与 AI 评审**（`/process`）：演示工厂仍是 SH-301、SH-101；别的厂列本厂所有有工艺路线的物料，默认打开主零件 |
| D-3 | **仿真与分析**（`/cae`）：默认选的零件不在本厂零件表里时，改选主零件（在表里时）或不选 |
| D-4 | **厂情中枢的推演**（插单）：插单的件数标签、插进去的零件用主零件；网关推演里没写零件时同样默认主零件 |
| D-5 | **质量**：新建 8D 没选特性时默认主零件；网关接口 `/api/quality/8d`、`/api/quality/spc` 的默认零件同样改成主零件 |
| D-6 | **AI 提议弹窗**：“本轮只下达输出轴 SH-301”只在演示工厂显示；**设计发布**页的示例物料号写本厂主零件 |
| D-7 | 演示工厂（减速器厂）里一切照旧：在线设计台、键槽编程、实验 7 这些本来就只属于 SH-301 的功能不动 |
