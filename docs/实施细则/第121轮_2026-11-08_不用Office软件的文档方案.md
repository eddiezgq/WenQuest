# 实施细则 · 第 121 轮：不用 Office 软件——在线文档两条路（OnlyOffice + 网页文档）

日期：2026-11-08
起因：Eddie 11-08 14:03（美东）定方向：老师和工程师从头到尾不用装 Office、WPS。两条路结合：
- **日常生成和修改走“网页文档”**：教材、报告、工艺卡在问渠里是结构化数据，浏览器里看到的是页面，直接在页面上改；AI 写初稿，人改；需要报送时一键导出 Word / PDF。这是主体。
- **外来的 Word / Excel，或必须按对方模板填写的，用 OnlyOffice 在浏览器里打开**，文件存在我们自己的服务器上。

状态：**已定**（Eddie 11-08 14:16“按建议”：先装现有两台服务器；网页文档先做实验报告；ERP 接入放阶段 C）。阶段 A 已上线（11-08），第 1、6 项验收通过，第 2–5、7 项待实际账号走一遍。

## 一、现状（2026-11-08 核实）

| 项目 | 现状 |
|---|---|
| 学生交实验报告 | 下载《实验报告模板》（docx）→ 电脑上用 Word 填 → 在问渠“作业”上传（`docs/帮助/虚拟实验与实验报告使用说明.md`）。**要装 Office，正是要去掉的那一步。** |
| 平台生成的文件 | 计算书、调机卡（docx）、参数表（xlsx）、实验指导书 / 报告模板、评价报告（html + docx）由网关用 python-docx 等生成（`services/gateway/app/production/docgen.py`、`sewing.py`、`gpulab.py` 等），只能下载，不能在线改。 |
| 老师上传的资料 | 建课时 AI 读取老师上传的 doc / docx / wps 等（`materials.py`），只读不改。 |
| 学习平台 | Moodle 5.2（`moodle/Dockerfile` 的 `MOODLE_502_STABLE`），网页端 uni-app + Vue 3。 |
| 问渠ERP | ERPNext，和平台在同一台国内服务器上（容器 `qms-erp-*`）。 |
| 国内服务器 | 4 核、内存 7.5 GB（用了 3.3 GB，可用 4.2 GB）、交换 2 GB、磁盘 99 GB（用 41%）。 |

外部事实（已核对出处）：
- **OnlyOffice Docs 9.4（2026-05）起，社区版取消了 20 个同时连接的上限**，同时改成单进程、不再需要 RabbitMQ 和数据库；许可证仍是 AGPL v3，另加了署名条款（保留“关于”页、不得用其商标）。所以“用户多了就要买企业版”这条已不成立。
- 官方系统要求：内存 4 GB 以上、交换 4 GB 以上、磁盘 40 GB 空闲。
- Moodle 插件 `mod_onlyofficeeditor` 最新 v6.2.0（2026-10-29），要求 Moodle 4.5 以上，已支持到 5.3，**我们的 5.2 可以用**。同一家还有作业提交插件 `assignsubmission_onlyoffice`（学生在作业里直接在线写 Word 提交），它对 Moodle 5.2 的支持施工前再核对，不支持就先只用 `mod_onlyofficeeditor`。
- 文档服务器必须能被用户浏览器访问，同时能回调 Moodle（POST），双方用 JWT 密钥互认。
- ERPNext 没有现成的 OnlyOffice 集成，要自己写一个小应用。

## 二、决定

| 编号 | 决定 |
|---|---|
| D-1 | **选 OnlyOffice，不选 Collabora**：Word / Excel / PPT 兼容性最好，界面像 Office，有现成 Moodle 插件；9.4 起社区版无连接数上限。Collabora 只作备选，本轮不部署。 |
| D-2 | **国内、美国各部署一套**，文件不出境：国内文档只在国内服务器，美国同理。~~用已备案主域名下的子域名 `docs.<主域名>`~~ **施工时改为路径 `learn.<主域名>/docs/`**（2026-11-08，见第七节）：不用两边各加一条域名解析，证书沿用现有的；OnlyOffice 官方支持这种“虚拟路径”反向代理。 |
| D-3 | 用官方镜像 `onlyoffice/documentserver`，**固定版本号、不改代码**（满足 AGPL 和署名条款：不改就无需另行公开源码，“关于”页保留）。国内镜像经现有 mirror-cn 任务同步到国内镜像仓库。 |
| D-4 | 安全：开 JWT，密钥部署时自动生成写 `.env`；文档服务器只认我们自己的平台回调；不开放匿名“演示页”。 |
| D-5 | **OnlyOffice 自带的 AI 插件：国内关闭**（只能接国内已备案模型，以后要用时接 DeepSeek 再开）；美国也先关，统一由问渠自己的 AI 入口做。 |
| D-6 | **网页文档是主体**：新文档优先做成网页文档；OnlyOffice 只处理外来文件和必须按对方模板填写的文件。平台生成的 docx / xlsx（计算书、调机卡、参数表、评价报告）以后逐个改成“网页文档 + 一键导出”，不再只是下载件。 |
| D-7 | **网页文档的数据**：一份文档 = 结构化内容（标题、段落、表格、公式、图片、填写栏、来自实验或计算的数值引用），存在平台数据库；每次保存留版本，提交 / 签字后只读（要改就新版本）。 |
| D-8 | **导出**：Word 用现有 docgen 版式（宋体 / 黑体、A4、页边距）；PDF 交给 OnlyOffice 的转换服务（docx → pdf），不再另装 LibreOffice。 |
| D-9 | **AI 的分工**：老师、工程师的文档（教学文件、工艺卡、报告）AI 写初稿，人改；**学生的实验报告 AI 不代写**——AI 只把虚拟实验的数据、曲线自动填进报告，批改时给评分建议（已有），由老师复核。 |
| D-10 | 小程序端：网页文档可看、可填写栏和表格；复杂排版的编辑只在网页端。OnlyOffice 只在网页端用。 |

## 三、分三个阶段

### 阶段 A：OnlyOffice 上线（本轮施工）

1. `docker-compose.yml` 加 `docs` 服务（`onlyoffice/documentserver:<固定版本>`，`mem_limit: 2g`，数据卷存缓存和日志）；Caddyfile 在 `learn.<主域名>` 下加 `/docs/`；JWT 密钥部署时生成。
2. Moodle 镜像装 `mod_onlyofficeeditor` 和 `assignsubmission_onlyoffice`（固定版本），`setup_wenquest.php` 自动填文档服务器地址和密钥。
3. 国内镜像同步：mirror-cn 的基础镜像清单加上 OnlyOffice。
4. 网关加 `docs` 健康检查，进运维页。
5. 帮助：`docs/帮助/在线编辑Word和Excel.md`（老师怎么在课程里新建 / 上传后在线编辑、多人同时改；学生怎么在作业里在线写 Word 提交）。

### 阶段 B：网页文档 + 实验报告网页版（下一轮，细则另写）

- 问渠文档：数据结构、编辑器（网页端块编辑器）、版本、导出 Word / PDF。
- 第一个用上的：**实验报告**——学生在页面上写，虚拟实验数据自动填入，提交进 Moodle 作业（老师批改流程不变），评分量规照旧；老师可一键导出全班报告。
- Word 模板仍保留下载，作为过渡。

### 阶段 C：工程侧（再下一轮）

- 问渠ERP（ERPNext）附件用 OnlyOffice 在线打开、编辑、存回（写一个小的集成应用）。
- 工艺卡、调机卡、计算书改成网页文档 + 导出。

## 七、施工记录（阶段 A）

偏差与细节（施工中定，已写回上文）：

1. **地址改为 `learn.<主域名>/docs/`**（原定 `docs.` 子域名）：省掉两边的域名解析和证书，Caddy 用 `handle_path /docs/*` 转给容器 `docs`，并把 `X-Forwarded-Host` 带上 `/docs` 前缀（官方虚拟路径做法）。
2. **回调走 Caddy 的内网别名**：Moodle 只认自己的公网域名，所以文档服务回调用 `https://classic.<主域名>`；生产配置给 Caddy 在内网加同名别名，回调不出服务器。因为别名是私有地址，文档服务设 `ALLOW_PRIVATE_IP_ADDRESS=true`（所有请求仍要 JWT 签名）。
3. **版本**：`onlyoffice/documentserver:10.0.0.1`（2026-10 发布的最新版；9.4 起社区版无连接数上限）。Moodle 插件 `mod_onlyofficeeditor` v6.2.0、`assignsubmission_onlyoffice` v4.2.0，都固定到提交号。
4. **插件全关**：容器 `PLUGINS_ENABLED=false`，Moodle 插件设置 `editor_security_plugin=0`、宏关闭。
5. **作业插件可带模板**：老师可以把《实验报告模板》的内容放进作业的默认模板，学生在线填写——阶段 B 网页版做好之前的过渡。
6. CI 新增一步：核对 `docker-compose.yml` 与 `deploy.yml` 国内同步清单里的 OnlyOffice 版本一致，且 Docker Hub 上有这个镜像。
7. **第一次部署（11-08）**：美国服务器上线成功；国内服务器失败——`update.sh` 先拉镜像、后换国内镜像名，国内服务器去 Docker Hub 拉 OnlyOffice 超时。已把换名移到拉镜像之前；其他服务没受影响（拉镜像失败就停，旧版照常运行）。
8. **部署后自动验收**：新增 `deploy/check-docs.sh`，两边部署任务最后都跑一遍：`/docs/healthcheck` 为 `true`、网关 `/api/health` 的 `docs` 为 `ok`、Moodle 插件地址已填、各容器内存。结果在部署日志里，不通时出注释。
