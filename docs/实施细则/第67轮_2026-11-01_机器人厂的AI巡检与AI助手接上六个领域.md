## 二、决定（建议）

| 编号 | 决定 | 理由 |
|---|---|---|
| K-1 | `demo_only` 改成“这个领域在本厂打开了才跑”：采购与来料（W3–W7）、设备（M2–M7）、能源（N1–N6）、财务（F2–F7）、安全（E1–E7）、人员（H1–H5）、销售 R3 在机器人厂跑起来 | 页面和数据都在，报警跟上 |
| K-2 | 客户 C1–C4 读的是减速器厂“现场的减速器”的投诉表，机器人厂继续不跑（它有第 64 轮的 RS1、RS2）；C5（报价到期没跟进）读的是两厂共用的线索与报价，放开 | 不重复报警 |
| K-3 | 写死的减速器厂设备改成按本厂找：瓶颈 / 关键设备取清单里负荷最重的那台（机器人厂是整机标定 CAL-1、磨床 GRD-R1 之一，按工时算）；“严重”的来料取清单的关键物料（`key_materials`：谐波减速器、伺服电机、WQR-105、铝棒）；没有热处理炉的厂 N3 / N5 不挂 ht-01 | 规则对任何清单都成立 |
| K-4 | AI 助手：本厂打开了的领域，工具和问法放开（财务、能源、人员、供应商、设备、安全）；“投诉 / 服务 / 客户”在机器人厂指到“客户与服务（现场的机器人）”页的数据（第 64 轮），回答“哪几台在报警、哪批减速器、派了什么工单” | 助手和页面说的是同一件事 |
| K-5 | 每条放开的规则在机器人厂造一个能触发它的场景，测试“触发、给出处理方案、不出错”；处理方案（第 17 轮的推演选项）里写死减速器厂的，同样改成按本厂找 | 不只是“不报错”，要真能用 |
| K-6 | CI：机器人厂演练加一项——巡检规则全部在跑、没有出错的；问助手三个问题（“哪台设备保养逾期”“哪个客户应收逾期”“现场哪台机器人在报警”）有答案 | 与前几轮同一套 |
