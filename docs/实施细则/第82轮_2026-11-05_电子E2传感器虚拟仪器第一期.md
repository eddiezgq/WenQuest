## 一、这一轮做出什么

数字工厂“仿真与分析”里多一页 **“虚拟仪器”**（`/instruments`）：左边选一个**测量任务**（被测对象 + 接线已经摆好），右边一排**仪器**，
像在实验桌上一样调旋钮、读数、存数据；每个任务最后要算出一个结果（标定系数、速度、Allan 方差、带宽……），平台按模型参数核对。
被测对象是 6 种有物理模型的传感器，参数与机器人关节、驱动板上用的同一份；E1 电路分析算出的波形也能“送到示波器”里看。

## 二、决定（建议）

| 编号 | 决定 | 理由 |
|---|---|---|
| V-1 | 仪器 7 种：**数字示波器**（2 / 4 通道、时基、伏 / 格、触发电平与沿、光标、自动测量：频率、峰峰值、有效值、上升时间；FFT）、**数字万用表**（直流 / 交流电压、电流、电阻、频率，量程与精度等级 ±(读数% + 字)）、**函数信号发生器**（正弦 / 方波 / 三角 / 脉冲，频率、幅值、偏置）、**可编程电源**（电压、限流）、**频谱分析**（示波器 FFT 加窗）、**逻辑分析仪**（解码编码器 A/B/Z、SPI、UART）、**数据记录仪**（长时间记录、导出 CSV） | 方案第五节；本科电子测量实验的常用仪器 |
| V-2 | 仪器按真仪器建模“不完美”：带宽（一阶低通）、采样率与混叠、量化位数、输入阻抗（对高阻信号源有负载效应）、探头 1× / 10×、本底噪声、万用表精度等级；每个读数旁可展开“这个读数的不确定度”（按《机器人学》第 39 章 39.1 节的 A 类 + B 类合成） | 学生要学的正是“仪器也有误差” |
| V-3 | 传感器 6 种（参数示例值，写在一份 `sensors.json`，网页模型和测试共用）：① 应变片电桥力矩传感器（全桥 + 仪表放大器，灵敏度、非线性、迟滞、温漂、零漂）；② 增量式编码器（A/B/Z，2500 线，细分误差、抖动）+ 绝对值编码器（SSI 输出）；③ MEMS IMU（陀螺零偏、角度随机游走、零偏不稳定性；加速度计零偏与噪声）；④ 霍尔电流传感器（灵敏度、零漂、带宽、非线性）；⑤ NTC 热敏电阻（B 值 / Steinhart–Hart、分压电路、自热）；⑥ 激光测距（ToF，噪声随距离增大、量程） | 方案第五节；①②④ 是关节和驱动板上的，③⑥ 是 AGV、人形用的 |
| V-4 | 6 个测量任务（第三节），每个：目的、接线图、要用的仪器、步骤、要提交的结果；提交后平台按模型参数核对（允许误差写明），对的打勾 | 有任务才是实验，不只是玩仪器 |
| V-5 | 全部在浏览器里算（仪器和传感器都是 JavaScript 模型，带固定随机种子，可复现）；服务器只给参数、核对结果、生成实验记录 | 仪器要实时响应旋钮；不占服务器 |
| V-6 | **接 E1**：电路分析页每条瞬态曲线旁加“送到示波器”，在仪器台用示波器看（带示波器自己的带宽、量化、噪声），对比“理想曲线”和“仪器看到的” | 方案“能接电路台的节点” |
| V-7 | 每个任务能导出数据（CSV）和**实验记录**（Word：接线、仪器设置、读数、结果与核对、不确定度） | 与 E1 计算书同一套 |

## 三、6 个测量任务

| # | 任务 | 被测对象与接线 | 用到的仪器 | 要算出的结果（平台核对） |
|---|---|---|---|---|
| 1 | 力矩传感器标定 | 电桥力矩传感器 + 仪表放大器，电源供桥，万用表读输出；砝码 0→满量程→0 加载 | 电源、万用表、数据记录仪 | 灵敏度（最小二乘斜率）、零点、非线性（% FS）、迟滞（% FS） |
| 2 | 编码器测速与解码 | 电机按设定转速转，编码器 A/B/Z 进示波器和逻辑分析仪 | 示波器、逻辑分析仪 | 转向、转速（由 A 相频率 = 转速 × 线数 / 60）、每转计数、Z 脉冲间隔 |
| 3 | IMU 静置零偏与 Allan 方差 | IMU 静置 2 小时（仿真瞬间生成），记录陀螺输出 | 数据记录仪 | 零偏、角度随机游走 ARW（τ = 1 s 处）、零偏不稳定性（Allan 曲线最低点） |
| 4 | 霍尔电流传感器：灵敏度与带宽 | 电源 + 负载给直流电流测灵敏度；信号发生器扫频给交流电流，示波器看幅值 | 电源、万用表、信号发生器、示波器 | 灵敏度（mV/A）、零点、−3 dB 带宽 |
| 5 | 热敏电阻测温曲线 | NTC 在恒温槽里 0–100 ℃ 分几档，分压后万用表读电压 | 电源、万用表 | 拟合 B 值（或 Steinhart–Hart 系数）、某一温度的测量不确定度 |
| 6 | 激光测距的噪声与平均 | 靶板放在 0.2–5 m 几个距离，每处采样 N 次 | 数据记录仪 | 各距离的标准差、平均 N 次后的标准差（≈ σ/√N），噪声随距离的规律 |

## 四、规则

1. 传感器、仪器参数都是示例值，只有一份 `sensors.json`（网页模型、测试、实验记录共用），标“示例值”；能对上机器人厂的（编码器线数、关节力矩量程、电机电流）取同一个数。
2. 每个任务的“正确结果”由参数用公式算（不是拿模型跑出来的数当答案），测试里用同一个随机种子让模型跑一遍，核对模型输出与公式在允许误差内（比如 Allan 曲线的 ARW 与设定值差 < 10%）。
3. 随机数固定种子，同一个学生同一个任务每次数据相同；不同学生种子不同（各自的数不一样，不能抄）。
4. 不改 E1 电路分析的读数和接口，只加“送到示波器”。
