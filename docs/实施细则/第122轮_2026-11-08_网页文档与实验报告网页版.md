## 二、决定

| 编号 | 决定 |
|---|---|
| D-1 | **先做通用的“问渠文档”底座，第一个用户是实验报告。** 底座本轮只开放给实验报告；老师自己新建网页文档（教学文件等）放下一轮，不在本轮界面上出现。 |
| D-2 | **文档 = 有结构的内容块**：标题、段落（可写公式，LaTeX）、表格（可指定哪些格子可填）、图（由表格数据画，或上传图片）、勾选项、填写栏。存网关自己的 `webdocs.db`；国内、美国各存各的，不出境。 |
| D-3 | **报告模板和 Word 模板同一个来源**：构建教材时由同一份 `lab/NAME.yaml` 同时生成 docx 模板和网页模板（JSON），栏目、表格、思考题、量规完全一致，不写两遍。 |
| D-4 | **实验数据进报告，两层**：<br>① **所有实验都有**：实验页加“记入报告”按钮，把此刻的场景、参数、读数记成一行，进报告第四部分的“实验记录”表（自动带时间）。学生再据此填正式数据表。<br>② **逐步加**：数据表的格子可写 `{{名}}`（和 GPU 实验同一写法），实验程序报出同名的数时自动填进去。本轮给《大学物理》第 1 章的实验做齐，作为样板；其余以后由 AI 建课流程补。 |
| D-5 | **作图**：报告里“插入图”选表格的两列，画散点 / 折线（可加拟合直线），满足模板“至少一张图”。图随数据变，导出时变成图片。 |
| D-6 | **保存与版本**：边写边自动保存（草稿）；点“提交”时存一个只读版本，交进作业。老师退回（Moodle 的“重新开放”）后学生在新版本上改，旧版本保留可看。 |
| D-7 | **交进 Moodle 作业，老师流程不变**：提交时网关生成报告的 Word 文件作为附件交进作业；作业开了在线文本的，同时放一份网页版正文（AI 评分建议读这份）。老师在问渠或经典界面照常打开、批改、打分。 |
| D-8 | **导出**：Word 用 `docgen` 版式；PDF 由阶段 A 的 OnlyOffice 转换（docx → pdf），不另装软件。老师在作业页可“导出全班报告”（一个压缩包，每人一个 PDF 或 Word）。 |
| D-9 | **AI 不代写学生报告**（第 121 轮 D-9）：报告编辑器里没有“AI 写”按钮；AI 只做两件事——把实验数据填进去（D-4），批改时给评分建议（已有）。保留“九、AI 使用声明”。 |
| D-10 | **中英对照**：栏目标题中英对照，和 Word 模板一致；学生用中文或英文写都可以。 |
| D-11 | **小程序端**：能看、能填表格和填写栏、能提交；公式和作图只在网页端编辑（第 121 轮 D-10）。 |
| D-12 | **Word 模板继续提供下载**，作为过渡；帮助里把网页版写成首选。 |

## 三、界面（定稿前的样子）

**入口（三处，同一份报告）**：
- 教材里每个实验旁边，在“实验指导书 / 实验报告模板（Word）”前面加 **“在线写报告”**；
- 虚拟实验页顶部 **“写报告”**；
- 作业页：老师把作业关联到某个实验后，学生的“添加提交”变成 **“在线写报告”**。

**报告页（电脑）**：左边报告，右边可以展开虚拟实验（和课件里“课件 | 虚拟实验”切换一样）；实验里点“记入报告”，左边的记录表马上多一行。顶部：保存状态、“导出 Word / PDF”、“提交”。

**报告正文**：按 Word 模板的顺序——表头（姓名、学号自动填，班级、同组、日期可改）→ 一 至 八 → 九 AI 使用声明 → 评分量规（只读）。每个部分是一个可编辑区；数据表就是网页表格，直接点格子填。

**老师**：作业的提交列表里点开学生报告（网页版，带版本），右边是评分和 AI 评分建议；“导出全班报告”在列表上方。

## 四、交付物

1. **网关 `webdocs` 模块**：文档的存取、自动保存、版本、提交（只读快照）、导出 Word / PDF、全班导出；测试。
2. **网页模板生成**：`labdocs.py` 增加“网页报告模板”（JSON），`build.py` 构建教材时随 docx 一起产出；测试保证 docx 与 JSON 栏目一致。
3. **网页端编辑器**（uni-app）：报告页、表格编辑、公式、作图、勾选、自动保存、提交；小程序端只读 + 填写。
4. **实验页“记入报告”**：`labkit/kit.js` 加按钮和向外层页面的消息；`{{名}}` 自动填；《大学物理》第 1 章实验补齐 `{{名}}` 作样板。
5. **作业提交**：网关把报告（Word 附件 + 在线文本）交进 Moodle 作业；作业关联实验的设置。
6. **帮助**：重写 `docs/帮助/虚拟实验与实验报告使用说明.md` 的“写报告”部分；新增 `docs/帮助/网页文档与在线实验报告.md`。
7. **方案**：`docs/方案/建设方案.md` 第 121 轮那一节补上阶段 B 的结果。

## 五、施工顺序与验收

施工顺序：网关底座（1）→ 网页模板（2）→ 编辑器（3）→ 实验数据（4）→ 作业提交与导出（5）→ 帮助、方案（6、7）→ 本地完整环境用老师、学生账号走一遍 → 推送上线。

验收：
1. 《大学物理》第 1 章任一实验：网页报告的栏目、表格、思考题、量规与 Word 模板逐项一致（自动测试对比全部 370 个实验）。
2. 学生账号：打开报告 → 在右边实验里点三次“记入报告”，记录表多三行；第 1 章样板实验的 `{{名}}` 格子自动填好。
3. 填表、写公式、插一张由表格两列画的图；关掉浏览器再打开，内容都在。
4. 提交后报告变只读；作业里能看到 Word 附件和正文；老师打开、打分、看 AI 评分建议。
5. 老师重新开放后，学生在新版本上改再交，旧版本可看。
6. 导出 Word 用 Word / WPS 打开版式正常；导出 PDF 正常；“导出全班报告”压缩包里每人一份。
7. 小程序：能看报告、填表格、提交。
8. 国内服务器：报告存在国内，导出 PDF 走国内的 OnlyOffice；页面上没有任何 AI 代写入口。
9. 网关测试、教材构建（全书、不带 `--only`）、前端测试全绿。
