## 一、照电路板厂的路子

电路板厂（第 85 轮）证明了“新厂只写一份清单、不改代码”：物料、BOM、工艺、设备、检验特性、布局写进 `factory/plants/<厂>.yaml`，
ERPNext、订单计划、车间仿真、质量、成本、三维车间、设备、能源、安全、人员、经营、AI 巡检都按清单接上。芯片厂照这条路，只补芯片厂特有的东西。

**芯片厂是什么样的厂**：真正的晶圆厂（光刻、刻蚀、离子注入……）投资以百亿计，学校和中小企业的现实做法是**设计自己做（第 92、93 轮）、晶圆交代工厂流片（多项目晶圆，MPW）、
封装测试自己做或交封测厂**。本轮建的就是这座**封装测试厂**：收代工厂来的晶圆，测、切、封、再测，出成品芯片。

```
芯片设计（第 92/93 轮，GDS）→ 代工厂流片（外协，SKY130 多项目晶圆）→ 本厂：来料检验 → 晶圆测试 CP → 减薄 → 划片 → 装片 → 键合 → 塑封 → 激光打标 → 电镀 → 切筋成型 → 成品测试 FT → 编带包装
```

### 偏差

- S-1（C-1）：产品的一个单位定为**一片晶圆的批次**（约 34 000 只、编带 12 盘），不是“一盘 3000 只”。工厂清单的物料清单只能“一个出一个”，一片晶圆出几万颗芯片表达不了；
  封测厂本来就按晶圆批流转，CP 良率、晶圆图也按片统计。
- S-2（C-1）：芯片尺寸 0.80 × 0.80 mm 是示例估计——第 92 轮版图只有内核（0.15 × 0.16 mm），没有焊盘环；每片颗数由这个尺寸算出（37 748）。
- S-3（C-4）：塑封料受潮按“从注入起塑封机 mld-1 用的料”出现，不按塑封料批号（仓库还没记塑封料批号；QS6 同理待数据）。
- S-4：同步时发现别的会话（P102）让 `factory/designs/tools/drv_joint.py` 依赖仓库根下的 `eda/`；freecad-ai-parts 写 ADR-0086 把 `eda/` 也作为共有代码，同步工具同时比对它。
