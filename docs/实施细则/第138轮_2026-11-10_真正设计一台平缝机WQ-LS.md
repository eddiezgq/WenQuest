## 一、为什么

第 135 轮 33a 用程序拼出了平缝机全部 357 个零件，但机壳是方块拼的，配色是乱的。Eddie：“这是产品，不是玩具和游戏”，“如果你给老板和工程师看，这能是专业的东西吗”。答案是不能。

- “没有，我们就真正设计一个缝纫机”

- “来个真正震撼的东西”

本轮要做的不是再画一个模型，而是**像一家缝纫机厂那样，把一台平缝机从设计任务书一路做到出厂手册**：参数、机构、强度、铸件、三维、图纸、工艺、检验、手册、讲解片，全部出自同一套设计数据。这一整条链，本身就是问渠能拿给缝纫机厂老板和工程师看的东西。

## 四、规则

1. **每个尺寸都有出处**：来自设计软件的计算、教材、工艺方案，或公开的同类机型参数（如针杆行程 30.7–35 mm、压脚手抬 5.5 mm / 膝抬 13 mm、DB×1 机针、旋梭与主轴 2:1）。出处都写进设计说明书。查不到的标“待定”，不编。
2. **校核全绿才往下走**：定时、钩线、送布、挑线、强度、模态、干涉，任何一项不合格都先改设计。
3. **机构真能转**：转一圈手轮，针杆、挑线、旋梭、送布、抬牙按时序动。每 2° 做一次干涉检查，零件不能互相穿过。
4. **铸件按铸件设计**：壁厚均匀，有拔模斜度、铸造圆角、加强筋、轴承座凸台、加工面和基准；和工艺方案的加工顺序对得上。
5. **标准件用真实尺寸**：螺钉、螺母、垫圈、挡圈按 ISO/GB，用紧固件工作台生成；轴承用零件库或手册尺寸。
6. **每一关先给 Eddie 看**，过关再往下，不拿数字充数。我先按“能不能给客户看”自己评一遍，不合格直接说。
7. **诚实标注**：这是问渠的示例设计，经过计算和三维校核，**没有经过实物试制**。手册、图纸、讲解片都标“示例设计”；所有数值标示例值。
8. 不开 Lambda。渲染用本机 CPU 或 GitHub Actions；慢就降分辨率或分批出，不上 GPU。

## 五、分关（每关一次给 Eddie 看）

### G1 设计任务书与总体方案

- **设计任务书**：用途，性能（转速、针距、压脚、机针、面料范围），选项（T 自动剪线 / E 电子针距 / D 少油旋梭），外形尺寸，重量目标。
- **总体布置**：机臂空间、底板与台板开孔、上轴和下轴的位置、同步带、电机直驱位置。
- **机构运动简图和时序图**：从设计软件算出（针杆位移、挑线量、梭尖、送布牙轨迹）。
- 给 Eddie 看：任务书（一页）、总体布置图、时序图。

### G2 分析计算、动力学与仿真

Eddie 10:04 补充：“从分析计算设计，仿真，动力学，plm等等”。所以这一关是一套完整的工程分析，不只是校核几个数。

| 分析 | 做什么 | 用什么 |
|---|---|---|
| 运动学 | 针杆、挑线、旋梭、送布牙在一整圈里的位移、速度、加速度；定时、钩线、送布、挑线量的校核 | 设计软件 `sewcore` |
| **动力学** | 5000 r/min 下转一圈：各运动件的惯性力，主轴需要的驱动力矩（含缝纫阻力矩），每个轴承的反力随转角的变化，整机的振动力和振动力矩，平衡块怎么配（平衡率扫一遍，选振动最小的） | 刚体动力学计算。质量和转动惯量**从 FreeCAD 实体零件里算出来**（G4 后用实体数据复算一遍） |
| 强度与疲劳 | 上轴、下轴、针杆曲柄、连杆在动力学算出的载荷下的应力和疲劳安全系数（教材 33.11、DIN 743 流程）；刚度与临界转速 | 问渠 CAE（有限元）加教材的手算方法，两种结果对照 |
| 机壳振动 | 机壳模态（前几阶固有频率和振型），在动力学算出的振动力作用下的响应；一阶要避开 5000 r/min 的一倍、二倍频 | 问渠 CAE（模态、谐响应），用 G3 的机壳铸件实体 |
| 轴承与传动 | 轴承寿命（L10）；同步带选型与张力；直驱电机力矩和转速是否够 | 计算加手册数据 |
| 热 | 电控箱温升（第 62 轮已有）；连续高速运转时轴承和旋梭的温升估算 | 问渠 CAE（热） |
| 缝纫仿真 | 线迹形成过程：挑线量与耗线量是否匹配、交织点位置、送布与针的配合 | 设计软件的虚拟样机 |

- 出《设计计算书》，中英对照，每个结论附计算过程、出处和图（位移曲线、力矩曲线、轴承力极坐标图、应力云图、振型图）。
- 分析结果反过来改设计：例如轴承力太大就换轴承、移支点；机壳模态不够就加筋。改完重算，直到全绿。
- 给 Eddie 看：计算书和校核结果表。

（G3 有了机壳实体、G4 有了全部零件实体以后，动力学、强度、模态都用实体数据**再算一遍**，结果写回计算书。）

### G3 外观与机壳铸件（最关键的一关）

## 九、附：现成模型调查结果（2026-11-10）

| 来源 | 结论 |
|---|---|
| CGTrader、TurboSquid 等商店 | 多为只有外壳的网格模型，没有内部机构。有一个 STEP 格式的，标价 1000 美元，也只有机身。 |
| Sketchfab | 有扫描得到的网格（CC BY-NC-SA），禁止商用。 |
| GrabCAD | 商用要逐个征得作者同意，个人使用为主。 |
| GitHub 开源硬件 | 没有工业平缝机的整机工程模型。 |
| **能用的** | FreeCAD 紧固件工作台（GPL-2，只当工具用，生成的标准件归我们）；FreeCAD 零件库（CC-BY 3.0，可商用，手册里注明出处）里的轴承等标准件。 |
