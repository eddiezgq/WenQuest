## 三、规则

1. 减速器厂行为不变：现有工厂测试不改断言通过；减速器厂导出的第 2 版清单与代码逐项一致。
2. 不编参数：外购件只写零件库里有的型号；数字不是来自零件库、计算或文献的，一律标“示例”。
3. 机器人厂从清单起来后，订单 → 算料 → ERPNext → 车间 → 测试标定 → 入库 → 开票，整条走通（闭环演练加一段机器人厂）。
4. 示例缝纫机厂补上产品后也要能走通同一条（第 30 轮 §三.3 补齐）。
5. 推送前本地跑通工厂全部测试、网页构建；本地版用机器人厂清单起一次。

### 施工中发现、写回细则的偏差（2026-10-24）

本机全套（假 ERPNext + 枢纽 + 仿真车间 + 桥接）用机器人厂清单起来走闭环时，发现以下几处与细则的设想不同，按下面办：

| 编号 | 发现 | 怎么办 |
|---|---|---|
| D-1 | “开票”属于经营与财务（E7），只在减速器厂开，机器人厂走不到规则 3 的“开票” | 其他工厂的**教学版**只开“订单做完开票”这一小段（`finance.bill_orders`）；期初应收、收款模拟、预算、信用仍只在减速器厂。企业工厂（生产模式）不变 |
| D-2 | 采购到货属于供应链（E5），机器人厂的请购单不会到货，外购件用完就做不下去 | 期初库存按“整机、AGV、三种关节各约 5 台”配（示例值）；班级工厂导数据时照旧打开“允许负库存”；WQR-105 的安全库存定在期初库存上，所以**每张 AGV 订单都会向减速器厂请购**（按采购批量 10 台取整）。请购单这一期只是记录 |
| D-3 | 多层 BOM：上一层工单比下一层先完工时，完工入库领不到半成品 | 帮助、演练都写明“按层下达”：下一层完工入库再下达上一层（闭环演练 `tests/plant_loop.py` 就这样做） |
| D-4 | 外购件放在外购件库，整机、部件工单却从原材料库领料 | 算料给出的领料仓库按物料类别：自制件、部件 → 半成品库，外购件 → 外购件库，原材料 → 原材料库（`mrp.SOURCE_OF`，桥接照填） |
| D-5 | 关节测试、整机标定的测量值不建检验单；导入脚本又把“检验工序”都设成质检门，作业卡会卡住 | 测量消息带上检验模板，桥接在**那道工序**的作业卡上建检验单（订阅所有设备的 measurement 主题）；质检门只设在清单里写了测量特性的工序。演示工厂不变 |
| D-6 | 导入脚本 `seed.py` 对 `demo_data: false` 的清单不建物料、BOM、库存 | 清单写了产品（第 2 版）就照建：物料、工艺路线、BOM、期初库存（按类别进库） |
| D-7 | CI 的班级工厂一步原来走减速器厂的闭环 | 改成演练机器人厂（`classes.yaml` 里第一座按清单起的班级工厂）：接 WQ-CR5、WQ-AGV300 各 1 台，走到开票。减速器厂的闭环由教学工厂、演示工厂两步覆盖 |
| D-8 | Excel 模板少了“关键物料” | “库存”表加一列“关键物料顺序” |
| D-9 | 帮助：机器人厂是 `demo_data: false`，帮助会缺省打开企业版 | 帮助加第三册“机器人厂”，只在按 `wenquest-robot` 清单起的厂里显示、并且是那里的缺省一册；新动画两个（多层物料清单、关节测试台），视频剧本三段 |

| D-10 | 真 ERPNext 里整机（WQ-CR5、WQ-AGV300）完工入库不成功，部件、自制件都成功 | 成品的序列号是减速器厂的（编号规则写死 WQR105-）；清单里的成品不设序列号 |
| D-11 | 部署时班级工厂两座以后，CI 只给演练的那座生成工作台密钥，服务配置起不来 | CI 照 `deploy/update.sh` 先给每个班生成密钥 |
