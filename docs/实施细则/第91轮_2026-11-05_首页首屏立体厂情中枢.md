## 一、决定

| 编号 | 决定 |
|---|---|
| D-1 | 两站首页首屏（国内版“问渠科技”原来的“一条渠、数据像水流”动画；美国官网原来的双摆）都换成同一个**立体厂情中枢** |
| D-2 | **三层叠成一座立体网络**：底层“设备层·车间实况”（17 台设备：数控车床、加工中心、热处理炉、磨齿机、装配线、试验台、立库、3 台 AGV、关节测试台、负载跑合台、协作机器人总装、总电表、三坐标、客户现场机器人）；中层“数据层·实时数据”（25 路关键信号 + 每台设备 2～4 路常规信号，共约 75 个点）；顶层“事件层·业务与决策”（订单、排产、工单、预测性维护、质量预警、8D、批次追溯、MRP、采购、供应商、售后、能耗、AI 简报、厂长决策）。对象名都取自问渠数字工厂（减速器厂 WQR-105、机器人厂 WQ-CR5、实验 7 情景） |
| D-3 | **映射关系**：设备→数据是竖线（这台设备产生哪些数据）；数据→事件、事件→事件是弧线（哪个数据触发哪个业务事件、事件之间的因果）。数据包不停从设备往上流；每 1.6 秒点亮“事件链”的下一步，金色数据包沿链走，节点亮起并显示当时的数值或动作 |
| D-4 | **6 条事件链轮播**：主轴振动超限→预测性维护→APS 重排→订单交期风险→AI 简报→厂长加班；齿形误差连升→SPC 判异→质量预警→8D→批次隔离；库存低于安全线→MRP 缺料→采购申请→供应商交期→工单延后；现场机器人背隙超限→售后→追到减速器批次→关节测试台复测→供应商 8D；峰时功率超限→能耗异常→热处理移到谷时；孔径偏大→质量预警→刀具寿命→换刀→补做 |
| D-5 | 首屏文字下方显示：对象 / 关系数、每分钟数据量、当前事件链名称和已走到的步骤（中英随页面语言） |
| D-6 | 慢慢自转，鼠标可拖动旋转、悬停看任一节点（含数据点的实时值）；手机上网络在上、文字在下；“减少动态效果”的设置下只画一帧；不用外部库（纯 Canvas），首屏不加载三维引擎 |
