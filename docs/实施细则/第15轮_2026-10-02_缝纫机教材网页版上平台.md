## 二、决定

### 2.1 分两步

| 步 | 做什么 | 本轮 |
|---|---|---|
| 第 1 步 | 把现成的网页版整本放进仓库，部署到服务器，在“教材”书架上出现，点开即读 | 是 |
| 第 2 步 | 按问渠教材格式（`textbook/<书>/book.yaml`、一节一个 Markdown、程序出数、实验 js + 说明文件、自动生成指导书和报告模板）逐章改写 | 否，另写细则 |

### 2.2 第 1 步的做法

| 项 | 做法 |
|---|---|
| 代号 | `sewing`（书名《缝纫机设计与制造》/ *Sewing Machine Design and Manufacturing*） |
| 源文件 | 网页版的生成源（章节片段、实验、插图、构建脚本）放 `textbook/web-editions/sewing/src/`；`build.py` 生成成品。成品不进仓库，由 CI 构建 |
| 图片 | 原有 PNG 转成 WebP（宽 2000 px 以内），仓库体积约减到三分之一 |
| 存放 | CI 把成品复制到服务器 `/opt/wenquest/textbook/sewing/webed/`，与其他书同一目录、同一套部署步骤 |
| 谁能看 | 与其他教材一样，登录后可读（第 7 轮 Q2）。网关发一个有时效的阅读链接（`/api/v1/textbook-web/<令牌>/index.html`），书内的相对链接都在这个前缀下，所以章节、实验、插图都能正常打开 |
| 书架 | `/api/v1/textbooks` 列出网页版书时带 `web: true`；书架卡片显示“网页版”标记 |
| 打开方式 | 点卡片后在平台页面里嵌入整本书（保留平台顶栏），右上角有“新窗口打开” |
| 中英 | 书内自带中英切换；平台语言为英文时直接打开英文首页 |
| 小程序 | 小程序里显示“请在网页端阅读”（实验页和三维模型在小程序里跑不了） |
