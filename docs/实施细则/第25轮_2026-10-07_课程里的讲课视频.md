# 实施细则 · 第 25 轮：课程里的讲课视频（待 Eddie 确认）

> 2026-10-07 Eddie：“学习平台课程哪里要有一个视频模块，把视频链接放上去”。

## 一、现状

- 公开课视频（第 21–23 轮）发在 B 站（中文）和 YouTube（英文），平台课程里没有入口。
- 单元页已有“讲解视频”区，但只播放上传到平台的 mp4；外部视频链接现在只显示成一行普通链接，不能在页里播放。

## 二、决定（建议）

1. **每讲最上面一个“讲课视频”区**，在课件之前：视频就在页里播放，不跳出平台。
   - 中文界面放 B 站版，英文界面放 YouTube 版；下面一行小字可切换另一个语言版本，也可“在 B 站 / YouTube 打开”。
   - 国内打不开 YouTube 时，英文界面也退回 B 站版（若有）。
2. **课程导航加“视频”页**：按讲列出全部讲课视频（缩略标题、时长），点开就到那一讲播放。
3. **链接从哪里来**：
   - 公开课视频：每讲在仓库里记一个链接文件 `docs/课程视频/<课>/<讲>/链接.yaml`（`bilibili: BV…`、`youtube: …`）。课程包生成时把它变成该讲的“讲课视频”活动；已发布的课程点“管理 → 课程包 → 更新”自动加上。
   - 其他课程的老师：在课程编辑里“添加 → 视频链接”，粘贴 B 站或 YouTube 网址即可，平台自动识别成可播放的视频。
4. **只认 B 站和 YouTube 两家**的网址（嵌入播放器的地址固定），其他网址仍按普通链接显示。

## 三、规则

- YouTube 视频**公开**（Eddie 10-07：“youtube不能公开吗”）。接口项目未过 Google 审核前，接口上传的视频锁定为私密：英文成片由 Eddie 在 YouTube Studio 手动上传并设为公开（标题、简介、标签、封面、字幕由我备好），同时提交接口审核，通过后改为自动上传、直接公开。B 站投稿审核通过后才能播放。
- 视频活动算学习进度：打开播放即记“已看”。
- 不在平台存视频文件，只存链接；播放走 B 站 / YouTube 自己的播放器。

2. 课程包与“更新”：第 2、3 讲有链接后点“更新”，两讲出现视频且排在课件前。
