## 一、要解决什么

缝纫机卖出去以后，经销商和修理工要订配件：哪个零件坏了、它叫什么、编码是多少、一台用几个。行业里靠一本**配件手册（零件图册）**：
每个部件一页**爆炸图**（零件拉开排列，每个零件标一个序号），旁边一张表：序号、编码、名称、数量、备注。

现在多数厂是工程师在 CAD 里一页页画、在 Word/Excel 里一行行填，BOM 一改就对不上。问渠 PLM 里已经有已发布的 BOM、零件和三维模型，
手册应当**从这些数据自动生成**，BOM 出新版本，手册跟着出新版。

## 二、决定（草案）

| 编号 | 决定 |
|---|---|
| D-1 | 手册是 PLM 模块里的一项，按**型号**出（例如 `WQ88-0000-5TA`），内容来自这个型号**已发布**的 BOM（逐层展开）。没发布的不进手册 |
| D-2 | 一页一个部件：爆炸图 + 零件表（序号、编码、名称中文 / 英文、数量、备注、是否可单独订购）。部件下面还有部件的，表里那一行写“见第 N 页” |
| D-3 | **爆炸图在网页里做**：部件有三维模型的，网页把它的零件按装配位置显示出来，自动沿装配方向拉开、自动标序号；工程师可以拖动零件、转视角、挪序号，满意后点“保存”，存成图片和序号位置。没有三维模型的部件，上传一张图（PDF、PNG、SVG，比如 FreeCAD TechDraw 出的爆炸图），在图上点几下把序号放好 |
| D-4 | 网页里看三维（原方向 B）：零件页、BOM 页加“三维”一栏，挂了 STEP 的直接在网页里转动查看。三维在**看的人的浏览器里**算，服务器不装 FreeCAD，不多占内存 |
| D-5 | 出两种手册：**PDF**（打印、发邮件）和**网页版**（手机打开、可转动三维、点零件看编码）。中英文对照，一本里同时有中文和英文 |
| D-6 | 英文名：零件多一个“英文名称”字段。没填的，AI 按零件名和类别起草英文名（国内用已备案模型），工程师看过后确认才进手册；没确认的显示中文名并标出来 |
| D-7 | 手册有版次：按发布时型号的 BOM 版本生成，写版次和日期；再生成时列出“与上一版相比”的变化（新增、删除、换了编码的零件）。旧版留着 |
| D-8 | 给经销商：每本手册可以开一个**只读分享链接**（不用登录，可随时作废），或下载 PDF。链接只看手册，看不到别的 |

## 三、规则

1. 只用已发布的 BOM 和零件；型号的 BOM 不是“已发布”时，“生成手册”按钮不能点，并说明原因。
2. 部件拉开的爆炸图，零件的相对位置来自三维模型；**没有位置数据的不猜**，显示“这个部件没有三维装配位置，请上传图”。
3. 序号在一页内从 1 开始；同一个零件在一页里出现几次，只标一个序号，数量写在表里。
4. 标准件（螺钉、垫圈、挡圈等）默认列在表里但不画进爆炸图（可以逐个改）；这是行业惯例，图更清楚。
5. 零件“是否可单独订购”默认：外购件和自制零件是，部件看它有没有自己的编码可以卖（默认否，工程师可改）。
6. 手册里不出现成本、供应商这些内部信息。
7. 分享链接只读、可作废、有访问次数记录；作废后打开显示“链接已作废，请联系厂家”。

## 四、数据从哪来

1. **BOM 和零件**：PLM 里已有。
2. **三维模型**：
   - FreeCAD 推送：现在只送每个零件的 STEP 和装配关系，**没送零件在装配里的位置**。本轮让“问渠 PLM”插件同时送每个部件的装配位置（每个零件的位移和转角），收件箱写入时存到 BOM 行上。
   - 上传 STEP 装配：STEP 文件本身带位置，读进来时一起存。
   - Excel 旧 BOM：没有三维，只能上传图。
3. **演示（蓝湾缝纫机械）**：问渠缝纫机设计软件（`services/gateway/app/sewcore/cad.py`）能按参数生成平缝机和包缝机的**机构三维**（上轴、针杆、挑线、旋梭、送布等），把它们对到蓝湾对应的部件上，这几页有真的三维爆炸图；机壳、电控、台板这些部件没有三维，用生成的示意图上传。见 Q3。

## 五、界面

- **型号页**多一块“配件手册”：版次列表、生成新版、下载 PDF、打开网页版、分享链接。
- **爆炸图编辑页**（每个部件一页）：左边三维（或上传的图），右边零件表；拖动、转视角、挪序号、“标准件画不画”，保存。
- **零件页、BOM 页**：多一栏“三维”，可转动查看。
- **手册网页版**：目录（按部件）→ 每页爆炸图 + 表；手机上能看；中英文切换或对照。

### 27a 网页里看三维、装配位置（2026-11-08 晚，质量 ERP PR #123）

- BOM 每一行多存“装配位置”：每用一次一个（位移 + 转角），数量是 3 就有 3 个；没人送来的就空着，**不猜**。
- 来路：
  - FreeCAD 插件现在同时送每个零件在部件里的位置（链接也算）；每个零件的 STEP 改成按零件自己的坐标导出（位置跟着装配关系走，不重复算）。
  - 上传 STEP 装配文件：把文件里每个零件的位置读出来。
  - 真 FreeCAD 1.0 实测：同一个部件，插件送的位置和从 FreeCAD 导出的 STEP 里读出的位置**完全一致**（存成测试样件，以后每次自动检查）。
- 写入收件箱时位置进 BOM 行；在 BOM 页手工保存时，数量没变的行位置保留，数量改了的行位置清掉（对不上就不猜）；出新版本时位置跟着复制。
- 网页：零件页每个 STEP 文件旁多一个“三维”，点开就能转动；BOM 页多一块“三维”，点“显示装配三维”，把下面所有有模型、有位置的零件按位置摆好（没有自己模型的部件，往下一层找）。没模型或没位置的零件列在下面，注明原因。
- 三维在看的人的浏览器里算（three.js + OpenCascade 的网页版，打开三维时才下载，约 7 MB），服务器不装 FreeCAD、不多占内存。两个新库已登记进《第三方开源组件说明》（OpenCascade 是 LGPL-2.1，原样使用）。

### 27b 细化（施工前写定）

1. **英文名称**：零件多“英文名称”和它的状态（没有 / AI 草稿 / 已确认）。零件页能填、能确认；配件手册页一次“AI 起草英文名”，给这个型号所有还没英文名的零件起草（国内用已备案模型；没配 AI 时说明“没有 AI，请手填”），草稿要人确认，没确认的进手册时显示中文名并标“英文名待确认”。
2. **爆炸图页**：每张 BOM 版本（部件）一页，存：方式（三维 / 上传图）、视角、拉开程度、每个零件的挪动量、不画的零件、气泡位置、保存时的截图。BOM 出新版本时，新版本的爆炸图从上一版的设置开始（按零件对上），工程师再调。爆炸图是排版，不是设计数据：BOM 已发布也能调（要 `plm:edit`），每次保存记历史。
3. **序号**：一页里按 BOM 行的顺序编 1、2、3……；标准件（紧固件类）也有序号、列在表里，但默认不画、不放气泡（规则 4），可逐个改成画。
4. **三维方式**：本页只摆这个部件**直接**下面的零件；下面的子部件当成一整块（它有自己的一页）。自动拉开：每块沿“从部件中心指向它的中心”的方向推开，拉开程度可调；点选一块后可按 X / Y / Z 方向微调。气泡自动放在零件旁边、带引线，可拖动。“保存”时存下设置和一张带气泡的截图（PNG）。
5. **上传图方式**：上传 PNG / JPG（PDF 请先导出成图片），选表里一行，在图上点一下放它的气泡，可拖动。
6. 页面入口：BOM 页“三维”旁多一个“爆炸图”。

### 27c 细化（施工前写定）

1. **手册按版次存**：从型号（或任何已发布 BOM 的部件）生成。生成时把整棵 BOM 树里每个部件当时的已发布版本、页面截图、零件表（含英文名）**定格**存下来，成为第 N 版；以后 BOM 再改，这一版不变，要再生成才有新版。
2. **页顺序**：第 1 页是型号本身（下面的部件写“见第 N 页”），然后按 BOM 顺序逐个部件一页（深度优先）。同一个部件在树里出现多次只占一页。
3. 树里有任何一张 BOM 不是“已发布”，不能生成，列出是哪几张。某页没有爆炸图：只放零件表，并注明“本页无爆炸图”。英文名未确认的显示中文名、标“英文名待确认”，生成前提示有几个。
4. **PDF**：服务器生成（ReportLab，开源 BSD 许可；中文字体用 Droid Sans Fallback，Apache-2.0，打进程序镜像），A4 横向，每页上面是爆炸图、下面是零件表；封面有型号、版次、日期，目录按部件。
5. **与上一版相比**：按页列出新增、去掉、数量改了的零件（按编码比）。
6. **分享链接**：给经销商的只读网址（不用登录）：看手册各页的图和表、下载 PDF；可随时作废，作废后显示“链接已作废，请联系厂家”；记打开次数和最后打开时间。
   **偏差（相对 D-5）**：分享链接里**不放可转动的三维模型**——三维模型是设计数据，经销商拿到 STEP 就等于拿到零件的全部几何；分享链接只给爆炸图和零件表。公司内部（登录后）看手册时，每页可以点开三维。
