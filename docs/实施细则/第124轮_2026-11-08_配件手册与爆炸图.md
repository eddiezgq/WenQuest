## 一、要解决什么

缝纫机卖出去以后，经销商和修理工要订配件：哪个零件坏了、它叫什么、编码是多少、一台用几个。行业里靠一本**配件手册（零件图册）**：
每个部件一页**爆炸图**（零件拉开排列，每个零件标一个序号），旁边一张表：序号、编码、名称、数量、备注。

现在多数厂是工程师在 CAD 里一页页画、在 Word/Excel 里一行行填，BOM 一改就对不上。问渠 PLM 里已经有已发布的 BOM、零件和三维模型，
手册应当**从这些数据自动生成**，BOM 出新版本，手册跟着出新版。

## 二、决定（草案）

| 编号 | 决定 |
|---|---|
| D-1 | 手册是 PLM 模块里的一项，按**型号**出（例如 `WQ88-0000-5TA`），内容来自这个型号**已发布**的 BOM（逐层展开）。没发布的不进手册 |
| D-2 | 一页一个部件：爆炸图 + 零件表（序号、编码、名称中文 / 英文、数量、备注、是否可单独订购）。部件下面还有部件的，表里那一行写“见第 N 页” |
| D-3 | **爆炸图在网页里做**：部件有三维模型的，网页把它的零件按装配位置显示出来，自动沿装配方向拉开、自动标序号；工程师可以拖动零件、转视角、挪序号，满意后点“保存”，存成图片和序号位置。没有三维模型的部件，上传一张图（PDF、PNG、SVG，比如 FreeCAD TechDraw 出的爆炸图），在图上点几下把序号放好 |
| D-4 | 网页里看三维（原方向 B）：零件页、BOM 页加“三维”一栏，挂了 STEP 的直接在网页里转动查看。三维在**看的人的浏览器里**算，服务器不装 FreeCAD，不多占内存 |
| D-5 | 出两种手册：**PDF**（打印、发邮件）和**网页版**（手机打开、可转动三维、点零件看编码）。中英文对照，一本里同时有中文和英文 |
| D-6 | 英文名：零件多一个“英文名称”字段。没填的，AI 按零件名和类别起草英文名（国内用已备案模型），工程师看过后确认才进手册；没确认的显示中文名并标出来 |
| D-7 | 手册有版次：按发布时型号的 BOM 版本生成，写版次和日期；再生成时列出“与上一版相比”的变化（新增、删除、换了编码的零件）。旧版留着 |
| D-8 | 给经销商：每本手册可以开一个**只读分享链接**（不用登录，可随时作废），或下载 PDF。链接只看手册，看不到别的 |

## 三、规则

1. 只用已发布的 BOM 和零件；型号的 BOM 不是“已发布”时，“生成手册”按钮不能点，并说明原因。
2. 部件拉开的爆炸图，零件的相对位置来自三维模型；**没有位置数据的不猜**，显示“这个部件没有三维装配位置，请上传图”。
3. 序号在一页内从 1 开始；同一个零件在一页里出现几次，只标一个序号，数量写在表里。
4. 标准件（螺钉、垫圈、挡圈等）默认列在表里但不画进爆炸图（可以逐个改）；这是行业惯例，图更清楚。
5. 零件“是否可单独订购”默认：外购件和自制零件是，部件看它有没有自己的编码可以卖（默认否，工程师可改）。
6. 手册里不出现成本、供应商这些内部信息。
7. 分享链接只读、可作废、有访问次数记录；作废后打开显示“链接已作废，请联系厂家”。

## 四、数据从哪来

1. **BOM 和零件**：PLM 里已有。
2. **三维模型**：
   - FreeCAD 推送：现在只送每个零件的 STEP 和装配关系，**没送零件在装配里的位置**。本轮让“问渠 PLM”插件同时送每个部件的装配位置（每个零件的位移和转角），收件箱写入时存到 BOM 行上。
   - 上传 STEP 装配：STEP 文件本身带位置，读进来时一起存。
   - Excel 旧 BOM：没有三维，只能上传图。
3. **演示（蓝湾缝纫机械）**：问渠缝纫机设计软件（`services/gateway/app/sewcore/cad.py`）能按参数生成平缝机和包缝机的**机构三维**（上轴、针杆、挑线、旋梭、送布等），把它们对到蓝湾对应的部件上，这几页有真的三维爆炸图；机壳、电控、台板这些部件没有三维，用生成的示意图上传。见 Q3。

## 五、界面

- **型号页**多一块“配件手册”：版次列表、生成新版、下载 PDF、打开网页版、分享链接。
- **爆炸图编辑页**（每个部件一页）：左边三维（或上传的图），右边零件表；拖动、转视角、挪序号、“标准件画不画”，保存。
- **零件页、BOM 页**：多一栏“三维”，可转动查看。
- **手册网页版**：目录（按部件）→ 每页爆炸图 + 表；手机上能看；中英文切换或对照。
