- WQ-LS 的设计资料全在仓库 `docs/设计/WQ-LS/`，共 19 篇 Markdown 和 180 多个图、视频、工程图、数据文件（约 40 MB）。现在只能在 GitHub 上一篇篇翻，没有总目录，公式不显示，很多图（G3 的外观方案、G5 的铸造仿真等）在文章里没引用，看不到。
- 线上已有的网页三维整机 `/wqls/`（第 138 轮 G6.1）只带了其中 10 篇计算书的单页，给零件点进去看那一节用，没有目录，也不全。

## 二、决定

| 编号 | 决定 |
|---|---|
| D-1 | 网址：数字工厂 **`https://factory.wenquestrobotics.com/wqls/spec/`**，和网页三维整机同一处，公开、不用登录。三维整机页顶上、数字工厂“设计案例 WQ-LS”、《缝纫机设计与制造》第 27 章各加一个入口 |
| D-2 | **完整**：`docs/设计/WQ-LS/` 下 19 篇全部上（README、G1–G8、GC、标准），原文一字不删；每个关的文件夹里文章没引用的图、视频、工程图、数据文件，放在那一关末尾的“附图与附件”里——图直接显示，视频能播放，PDF 工程图在网页里打开，STEP、数控程序、JSON 能下载 |
| D-3 | 版面：左边总目录（按 G1 任务书 → G2 计算书 → G3 外观与机壳 → G4 零件与整机 → G5 工艺 → G6 网页三维 → G7 工程图与物料清单 → G8 整机补全与虚拟样机 → GC 控制器 → 标准），右边当前这篇的小目录；首页是总览：每一关做到哪、主参数、“示例设计，没有实物试制”的说明。手机上目录收成按钮。浅色、深色都能看 |
| D-4 | 公式（G2 计算书里的 LaTeX）在生成时转成浏览器自带的数学排版（MathML），不另加外部库 |
| D-5 | 全文搜索：输入“挑线”“旋梭”这类词，列出所有篇里出现的段落，点进去跳到那里 |
| D-6 | G7 没有文章：生成一页“工程图与物料清单”，物料清单（`物料清单.json`）排成表，工程图逐张列出能打开 |
| D-7 | 每篇页头写原文在仓库的位置和最后修改日期；文章之间的链接（如“见 G4/刺布与挑线机构.md”）在网页里互相能点 |
| D-8 | 生成和同步：新脚本 `tools/wqls/spec_web.py` 从 `docs/设计/WQ-LS/` 生成到 `factory/digital/web/public/wqls/spec/`（和三维整机现在的做法一样，生成结果提交进仓库）。大图缩到宽 1600 像素；工程图 PDF 和三维整机共用已有的 `/wqls/dwg/`，不放两份。新增大约 25 MB |
| D-9 | 防止网页和原文对不上：加测试 `factory/digital/tests/test_wqls_spec.py`，原文改了没重新生成就报红；`factory.yml` 的触发路径加上 `docs/设计/WQ-LS/**`、`tools/wqls/spec_web.py` |
| D-10 | 只有中文（原文就是中文）；页头一行英文说明“Design documentation (Chinese original)”，和现在的计算书单页一样 |
