### 2.2 参考书与标准（由我选定；2026-10-02 按 Eddie 意见改为以国外教材为主、逐章列出）

> Eddie 2026-10-02 10:22：“这些参考教材要以国外高水平教材为主，每一章请罗列所有参考资料。”

全部参考资料单独成文：`docs/教材/机械设计/01_参考资料.md`。

| 部分 | 内容 |
|---|---|
| 总书目 | 约 110 种，分 A–K 组，每本一个代号：A 机械设计综合（Shigley 第 12 版、Norton、Juvinall、Mott、Collins、Hamrock、Childs、Roloff/Matek、Niemann）；B 机构学（Norton《Design of Machinery》、Uicker、Erdman、Waldron、McCarthy、Hartenberg–Denavit、Howell）；C 设计方法、材料与制造（Pahl–Beitz、Ulrich–Eppinger、Ullman、Dieter、Boothroyd–Dewhurst、Ashby、Dowling、Kalpakjian）；D 力学、强度与疲劳（Gere、Timoshenko、Roark、Peterson、Johnson、Anderson、Stephens–Fatemi、Schijve、Haibach、FKM）；E 分析、仿真与优化（Logan、Cook、Bathe、Shabana、Haug、Featherstone、Rao、Bendsøe–Sigmund、Martins–Ning）；F 传动、支承、连接与精密设计（Litvin、Dudley、Harris、Hamrock、Khonsari、Bickford、Wahl、Slocum、Blanding、Rivin）；G 公差、质量、可靠性与数字化（Krulikowski、Henzold、O'Connor、Meeker、Montgomery、Phadke、Juran、Stark、Smid、Altintas）；H 机器人与智能装备（Springer 机器人手册、Lynch–Park、Siegwart、Birglen）；I 历史与伦理（Needham、Reuleaux、Petroski）；J 国内对照；K 软件文档 |
| 逐章清单 | 52 章每章列出：教材（注明对应内容）、专著与手册、经典文献（原始论文，如 Hertz 1882、Miner 1945、Reynolds 1886、Lundberg–Palmgren 1947、Freudenstein 1955）、标准（ISO / GB / DIN / VDI / ASTM / ASME / IEC）、软件与数据（开源软件文档、问渠零件库编号、数字工厂数据） |

规则：
- 主要参照都是国外高水平教材和专著；国内教材（第 J 组）只用来核对国内课程和考研大纲的覆盖面，不作为选材和写法的依据；
- 只参照选材和深度，文字、图、习题全部原创；
- 清单注的是“哪一部分内容”，不写章号（版本之间章号会变）；写每一章之前逐条核对版本、章节和页码，写进章末参考文献和 `textbook/mechdesign/conventions/参考书目.md`；没写年份的标准，写章时查现行版本补上。

设计数据按现行国家标准，同时对照 ISO（提纲第二节第 10 条）：极限配合 GB/T 1800.1-2020、几何公差 GB/T 1182-2018、齿轮 GB/T 3480 / ISO 6336、轴承寿命 GB/T 6391 / ISO 281、螺栓 VDI 2230、轴 DIN 743 等。**这些标准的数据做成数字化标准表**（`textbook/mechdesign/std/`），书里的程序、虚拟实验和数字工厂共用一份，每条注明标准号和表号。

### 2.3 篇幅与结构

- 导论 1 章 + 九篇 51 章 = **52 章，约 1600 页**（另附录约 120 页，以标准数据表为主）。
- 九篇：设计方法与工程表达（2–6）、强度刚度与失效（7–13）、机构分析与设计（14–23）、连接与弹性元件（24–27）、机械传动（28–32）、轴系支承与运动部件（33–37）、现代设计方法与数字化（38–44）、机器人与智能装备（45–49）、综合设计（50–52）。
- 一本书把国内的“机械原理”和“机械设计”合在一起，另含“互换性与测量技术”“课程设计”和研究生“现代设计方法”。提纲第四节给出八种开课方式的章节表。
- 两台贯穿全书的产品：**WQR-105 减速器**（数字工厂的产品，输出轴 SH-301，额定 350 N·m）和**协作机器人关节模组**（零件库谐波减速器、交叉滚子轴承）。全书例子落在它们身上，参数一致。

### 2.4 “每次课都像工程师一样工作”的做法

这是本书和前三本最大的不同。

| 项 | 做法 |
|---|---|
| 工程任务单 | 每章至少一张。老师（或 AI）在**班级工厂**（工厂第 10 轮）的 ERPNext 里以“设计任务”下达：需求、约束、交期、要交什么 |
| 交付物是工程文件 | 设计计算书（浏览器里运行的 Python，自动生成 Word）、三维模型、分析报告（有限元 / 疲劳 / 多体，工厂已能出 Word 报告）、国标图纸、加工程序、检验记录 |
| 提交与评审 | 走已有的“设计发布与审批”：提交 → **AI 评审员**先审（规范、计算、图面，只提意见、不打分）→ 老师批准或退回 → 批准后 ERPNext 物料、BOM、工艺自动更新 |
| 制造与检验 | 批准的设计派到仿真车间加工，三坐标检验，质量数据回到学生手里复盘 |
| 工具链标注 | 每个实验和任务单标明用到的工位：〔CAD〕〔PLM〕〔ERP〕〔MES〕〔QMS〕〔FEA〕〔FAT〕〔MBD〕〔CAM〕〔PY〕 |
| 评分 | 按工程交付物评：计算书正确、图纸合规、评审意见已关闭、加工检验合格。评分细则随每张任务单写进实验说明文件，自动生成评分量规 |

不是每章都走完整条链：第 33 章“轴”的任务单走全链（计算 → 建模 → 有限元 → 疲劳 → 出图 → 审批 → 数控加工 → 三坐标检验），机构各章以〔PY〕〔MBD〕为主。

### 2.6 与另三本书和平台课程的关系

- **分工**：《机器人学》第 30–34 章讲机器人选型和用法；本书讲设计计算。重叠处本书讲透，《机器人学》注明“详见《机械设计》第 x 章”。《大学物理》讲力学原理，《线性代数》第 40 章讲刚度矩阵的数学；本书讲工程应用。
- **术语**：四本书同一个中文术语的英文名必须一致（沿用术语一致检查，扩展到四本书）；本书术语以《机械工程名词》为准。

- **平台课程**：本书成为 AI 建课里“机械原理”“机械设计”“机械设计基础”课程的主教材。
