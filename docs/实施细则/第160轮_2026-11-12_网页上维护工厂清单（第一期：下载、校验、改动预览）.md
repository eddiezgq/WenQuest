# 实施细则 · 第 160 轮：网页上维护工厂清单（第一期：下载、上传校验、改动预览）

状态：**施工中（第一期）**。第一期不碰在用的数据，按长期授权直接施工；**第二期（上线：改在用清单、补建 ERPNext 物料、重启）动企业正式数据，等 Eddie 确认后再做。**

## 一、现状

企业改产品、物料清单、工艺路线只有一条路（帮助“工厂清单”一章）：在电脑上用命令生成 Excel 模板 → 填 → 命令行导入成 `plant.yaml` → 交给我们放进仓库 → 服务器 `.env` 指过去、重启。厂里的工艺员、厂长在网页上做不了任何一步，连“现在在用的清单”都拿不到 Excel。

## 二、决定

| 编号 | 决定 |
|---|---|
| W-1 | **分两期**。第一期（本轮）：网页上**下载**在用清单的 Excel、**上传**改好的 Excel、**校验**（错按表、行、列说清）、**改动预览**（和在用清单比，加了 / 删了 / 改了哪些），校验通过的存为“待上线清单”。不改在用的清单，不碰 ERPNext |
| W-2 | 第二期（下一轮，Eddie 确认后）：管理员点“上线”——待上线清单写成服务器上的清单文件、旧清单留底可回滚、ERPNext 补建新物料 / 物料清单 / 工艺路线、重启枢纽。在那之前，上线照旧由我们拿“待上线清单”的 yaml 按帮助的第 3 步做 |
| W-3 | 位置：“设计与工艺”页（第 155 / 157 轮的“本厂物料”那一块）上方加一张卡“工厂清单（Excel）”：**下载在用清单**、**上传改好的清单**、最近几份待上线清单（谁、什么时候、改了什么、下载 yaml）。演示工厂也有（下载到的就是减速器厂的清单，可以当模板） |
| W-4 | 权限：工艺员（设计工程师）、厂长、老师可以下载和上传；其他角色只看到“本厂物料” |
| W-5 | 改动预览比这些：物料（新增、删除、名称 / 类别 / 单位 / 单价 / 供应商改了）、物料清单（父件新增 / 删除，子件和用量的增删改）、工艺路线（工序增删、每件分钟改了）、成品（新增、删除、售价改了）、工序与设备（新增、删除）。每类最多列 50 条，超出写“还有 N 条” |
| W-6 | 接口：`GET /api/plant/workbook`（在用清单的 Excel，用 `plant_xlsx.write_template` 写出）；`POST /api/plant/workbook`（上传 Excel：`import_workbook` 校验，过了就和在用清单比、存为待上线）；`GET /api/plant/pending`（最近 10 份）；`GET /api/plant/pending/{id}.yaml`。比较写成纯函数 `factory/plant_diff.py`，单独测 |
| W-7 | 待上线清单存数据库表 `plant_pending`（编号、上传人、时间、文件名、清单 yaml、改动摘要），不落到服务器文件 |
| W-8 | 英文表、帮助（企业版“工厂清单”一章把“三步”改成网页做法、命令行做法留作备选；第二期之前写明“上线仍由我们做”） |
