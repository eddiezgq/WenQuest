## 一、现在的样子

- 三维视频（一句话写的、样片、缝纫机讲解片）的旁白固定用一个声音：中文晓贝（女）、英文 Heart（美式女声），语速 1.1。
- 平台语音服务本来就有 16 个声音：中文 8 个（晓贝、晓妮、晓晓、晓伊四个女声，云健、云希、云夏、云扬四个男声），英文 8 个（美式、英式，男女都有）。“讲解视频”（讲课视频）那边老师已经能选声音，每个声音有一小段试听（`/api/v1/studio/voices`）。
- 每句旁白按“声音 + 语速 + 文字”缓存，换声音只重合成换了的部分。

## 二、决定（建议）

1. **在哪里选**（Eddie 定：视频页和设计软件都能选）：
   - **三维视频工作页**：“配旁白”开关旁边加“声音”和“语速”两项，只在旁白开着时出现。声音按视频的语言列出（中文视频列 8 个中文声音，英文视频列 8 个英文声音），每个声音能“试听”一小段（用讲课视频那边现成的试听）。改了就重配一次旁白：段落拉长按新声音、新语速重算；对话里写“换成云健（男）、标准语速，重配好了，片长 X 秒”。
   - **网页版缝纫机设计软件**：“导出”页签“出三维讲解片”框里，“配旁白”后面加声音下拉（带试听）和语速三档，跟着字幕语言变（中文、中英两行列中文声音，English 列英文声音）。
   - **FreeCAD 版**：“出三维讲解片”对话框里，“配旁白”下面加声音、语速两个下拉框；声音列表从问渠服务器取（连不上就只有默认声音一项）。FreeCAD 里没有试听，到网页里试听。
   - 语速三档：慢 1.0、标准 1.1（现在的默认）、快 1.25。
2. **默认**（Eddie 定：一律用平台默认）：每段新视频都从平台默认开始——中文晓贝（女）、英文 Heart（美式女声），标准 1.1；不记老师上次的选择。选了的声音、语速记在这段视频上，以后改片、重配照用。
3. 声音只认语音服务里有的、语言要和视频对上；语速只认三档。传错的退回平台默认，并在对话里说明。
4. **中英两行的视频**：念中文，选中文声音；只出英文的选英文声音。（第 99 轮的规则不变）
5. **不做**：每句用不同的声音；老师上传自己的录音替换某一句；背景音乐。
6. **帮助**：《三维仿真视频使用说明》第“二之〇”节加“选声音、调语速”；缝纫机软件帮助里讲解片那一段加一句“到视频页可以换声音、语速”。

## 三、交付物

| 交付物 | 位置 |
|---|---|
| 视频记声音、语速；配音按记下的声音、语速合成 | `services/gateway/app/video3d.py`（`revoice`、`create`）、`sewing_voice.py`（声音、语速从参数来，默认不变） |
| 接口：声音列表（带试听）、改声音 / 语速；缝纫机出讲解片带声音、语速 | `video3d_api.py`：`GET /api/v1/video3d/voices`（三维视频的用户都能看）、`POST /api/v1/video3d/{id}/voice` 加 `voice`、`speed`；`sewing_video.py`：`POST /api/v1/sewing/video` 加 `voice_name`、`speed`，`GET /api/v1/sewing/video/voices`（钥匙也能取，给 FreeCAD） |
| 网页：视频页、设计软件的声音下拉 + 试听、语速三档 | `apps/web/src/pages/video3d/edit.vue`、`components/sewing/SewDesigner.vue`、`api.ts`、`i18n.ts` |
| FreeCAD：对话框两个下拉 | `services/gateway/app/sewcore/freecad/wqsew_gui.py`、`wqsew_net.py` |
| 测试 | 换声音、换语速后重配；缝纫机讲解片不选时和现在一字不差；选了的声音、语速从设计软件一路带到配音；语速只认三档；声音只认语音服务里有的、语言要对；FreeCAD 对话框取列表、连不上只有默认 |
| 帮助 | `docs/帮助/三维仿真视频使用说明.md`；缝纫机软件帮助（网页版“导出”、FreeCAD“出三维讲解片”两处） |
