# 实施细则 · 第 179 轮：问渠凸轮“导入廓线、反求从动件运动”

状态：**施工中**（2026-11-24 起草；同日 Eddie 定“按建议”，见第五节）

起因：11-24 一位用户问 Eddie：“我们设计凸轮时不一定严格按行程和运动规律，用点表（转角、位移）表示，量取的转角和位移不准，能不能直接把设计好的凸轮廓线导进去？”Eddie 11-24 说“开始”。

## 一、现状

| 入口 | 现在能做的 | 不够的地方 |
|---|---|---|
| 设计 → 运动规律 | 升—停—回分段，选运动规律 | 用户手里只有廓线、没有规律时用不上 |
| 设计 → 点表 | 粘贴（转角, 位移） | 点表要用户自己从图上量，量不准；位移误差两次求导后在加速度里放大很多 |
| 测量与补偿 → 廓线 XY 点 | 实测廓线与**已有设计**比，算误差谐波和补偿 | 前提是先有设计；只适合小误差，不能单靠一条廓线求运动 |

结论：缺“只给廓线 → 求从动件运动”这条路。

## 二、决定（建议，待定）

1. **设计页加第三种输入“导入廓线”**，和“运动规律”“点表”并列。
2. **接受的文件**：
   - XY 点表（CSV / TXT，两列 x、y，单位 mm，凸轮坐标系）；
   - DXF（CAD 导出的二维线框）：认 LINE、ARC、CIRCLE、LWPOLYLINE（含凸度圆弧）、POLYLINE、SPLINE；首尾相接拼成一条封闭廓线，拼不上的报出断开的位置。
3. **用户还要填**（廓线本身定不了这些）：凸轮回转中心（默认 DXF 原点，可改）、从动件类型（直动 / 摆动，滚子 / 平底 / 尖顶）、滚子半径、偏距（摆动：中心距、摆杆长）、凸轮转向、零位（默认“从动件最低点为 0°”，可改成“DXF 的 +x 方向为 0°”，用于有键槽零位的零件）。
4. **反求算法**（计算核心 `services/cam/camkit/inverse.py`，纯代码、不用 AI）：
   - 廓线先按弦高 0.001 mm 加密成光滑的封闭曲线；
   - 凸轮每转 0.1°（一圈 3600 点），把廓线转到该位置，求从动件刚好贴住廓线的位置：
     - 直动尖顶：直线 x = e 与廓线的交点；
     - 直动平底：廓线在从动件方向上的最远点；
     - 直动滚子：滚子圆心沿 x = e 往下压，碰到廓线即停（等价于廓线的等距线与直线的交点）；
     - 摆动三种：同理，改成绕摆动中心转的角度，用二分法求；
   - 得到位移 s(θ)；基圆半径、升程、各段起止角自动报出来。
5. **求导与平滑**：s(θ) 再求速度、加速度、跃度。廓线的小毛刺会在加速度里放大，所以加一个“平滑程度”设置：默认按廓线精度自动取（平滑样条），可手动调；结果页同时画“未平滑”“平滑后”两条加速度曲线，让用户看清平滑去掉了多少，不偷偷改结果。
6. **接上现有分析**：反求出的 s(θ) 作为 0.1° 的点表程序，直接进现有的压力角、曲率、接触应力、动力学、加工程序、测量补偿，后面一律不改。
7. **反求校验**：用反求出的运动按现有正算重新生成廓线，和导入的廓线比，报出最大法向偏差；超过 0.005 mm（可设）时提示“导入的廓线和所选从动件对不上”（例如滚子半径填错、中心点错）。
8. **范围**：本轮做盘形凸轮（外廓）。槽凸轮（两侧廓线）、圆柱凸轮、弧面凸轮以后再说（见第五节 Q2）。

## 六、施工中的偏差（11-24）

1. **自动平滑的定法改了**：原写“按廓线的散布（三阶差分估噪声）定残差”。施工中用示例 DXF（穿过 720 个点的样条）一试，廓线误差是成片相关的起伏（百分之几微米、每个拟合点重复一次），三阶差分估不出来，平滑后加速度仍有 ±5% 的毛刺（峰值偏 15%）。改为：**广义交叉验证定平滑强度，且位移最多改动 1 µm**（摆动：摆杆端 1 µm）；弱 / 强 / 更强约为自动的 0.3 / 3 / 10 倍。改后示例加速度峰值 2.861（原运动规律 2.853），本软件导出的廓线来回误差都在 0.1% 以内。
2. **零位“升程开始处”**：光滑运动规律离开停歇是渐变的，找到的起点会晚零点几度（帮助里写明；要严格零位用“按图上方位”）。
3. **FreeCAD 不另加按钮**：选中草图再点原来的“凸轮”，软件问“用它当廓线吗”；回答“否”照旧打开项目文件。新文件 `services/cam/freecad/wq_cam_outline.py`。
4. **FreeCAD 验收放进 CI**：本会话的机器装不了 FreeCAD，在 `cam.yml` 加 `freecad` 作业：取官方 FreeCAD 1.1.4，跑 `services/cam/tools/check_freecad_outline.py`（建斜放、转过的草图 → 反求 → 建实体，直动滚子、摆动平底各一）。
5. 接口请求上限 4 MB → 8 MB（DXF 可能有几 MB）。示例项目 `sewing-feed-outline.json` 里带着 DXF 原文，网页打开示例就能看到导入结果；由 `services/cam/tools/make_outline_example.py` 生成。
6. 出错提示的中文放在计算核心 `camkit/inverse.py`（`ERR_ZH`），网页接口和 FreeCAD 共用。
