# 实施细则 · 第 84 轮：国内版的注册与收费（方案）

## 一、现在的样子（第 50 轮）

- 国内学习平台**不开放个人注册**：单位在官网“预约演示”申请，管理员审核后按单位开通体验账号（每家默认 5 个，90 天），账号登记姓名和手机号（后台实名）。
- **不收费**：体验免费；正式使用按合同为客户单独部署（第 48 轮）。
- 备案是**非经营性 ICP 备案**；生成式 AI 服务登记编号（`WQ_AI_REG`）还空着。

## 二、要收费，先要过的几道关（法规和手续）

以下按公开资料整理，正式办理以主管部门（浙江省通信管理局、属地网信办、税务）和律师意见为准。

| 关 | 说明 | 影响 |
|---|---|---|
| **ICP 经营许可证**（增值电信业务，B25 信息服务） | 网站上**在线收费**（会员、订阅、按次付费）属于经营性互联网信息服务，一般要办经营许可证，而不只是现在的备案。常见条件：公司注册资本一般不少于 100 万元、经营范围含相关增值电信业务、有技术人员、服务器在境内；审核约 1～2 个月，有效期 5 年，每年年检 | 在线支付这条路的前提 |
| **生成式 AI 服务登记** | 对公众提供用到大模型的服务（我们调用已备案的 DeepSeek），要在属地网信办做登记，拿到编号放在页面上（`WQ_AI_REG`） | 开放个人注册前要办 |
| **实名** | 个人注册要手机号 + 短信验证码（网络安全法的“后台实名”） | 要接短信服务（阿里云短信：签名、模板要审核，公司主体可以办） |
| **收款** | 微信支付、支付宝的**企业商户号**：营业执照 + 对公账户；费率约 0.6% | 在线支付要这两样 |
| **发票** | 企业客户要增值税发票（多为电子发票）：税务 UKey 手工开，或接第三方开票接口 | 对公收费必需 |
| **业务范围** | 经营范围里的教育咨询“不含许可类培训”；对个人卖“课程”容易被看成培训。卖的是**软件服务**（学习平台、设计软件的使用）比卖“课程”稳妥 | 决定收什么费、怎么写 |

## 三、建议：分两步走

### 第一步（马上可做，不用新许可）：单位签约、对公付款

- 保留“按单位开通”，在官网把**体验 → 正式**的路径写清楚：体验 90 天 → 签服务合同 → **对公转账**付款 → 开增值税发票 → 管理员把这家单位改为“正式”、调账号数和到期日。
- 平台补三样（小改动）：单位的“正式 / 体验”状态和到期日、到期前提醒、管理页一张“合同与收款”记录（合同号、金额、开票状态，只是记录，不在网上收钱）。
- 报价：按单位、按年、按账号数（例如每校每年若干元含 N 个账号），具体数字由 Eddie 定。
- 这一步网站上**不出现在线支付**，签约和付款都走线下合同，与现在的非经营性备案、经营范围都不冲突（以律师意见为准）。

### 第二步（办好许可之后）：个人自助注册、在线支付

前提：ICP 经营许可证、生成式 AI 服务登记、微信 / 支付宝商户号、短信服务都办好。
- 注册：手机号 + 短信验证码，登记姓名；未成年人另有规定（先不对未成年人开放）。
- 套餐：免费体验额度（AI 次数、项目数有上限）+ 付费订阅（月 / 年），卖“软件服务使用权”，不卖“课程”。
- 支付：网页用微信 Native（扫码）、支付宝电脑网站支付；小程序里用微信 JSAPI。支付结果回调到网关，自动开通、续期。
- 发票：个人可选开电子普票（接开票接口）。
- AI 生成内容标识、投诉举报入口、用户协议和隐私政策（按收费改写）。
