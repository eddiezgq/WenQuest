## 二、新增规则

**R6 建模主线（每节课必须有）**：每节课一个主问题（机器人方向）和一个生活例子。主问题按五步展开，课件、虚拟实验、实验报告用同一个问题贯穿：

1. 实际问题：从机器人或工程场景中来，带典型数据。
2. 建立模型：说明做了哪些简化（质点、忽略空气阻力、匀速等）。
3. 求解：用本节公式算出结果。
4. 检验：用虚拟实验验证。
5. 修正：指出模型在哪里失效，怎样改进。

**R7 实验指导书**（每个虚拟实验一份，中英对照）：实验目的 · 实验原理 · 实验环境与参数范围 · 实验步骤 · 数据记录表 · 注意事项 · 思考题 · 与实际问题的联系。

**R8 实验报告**：
- 固定栏目：实验名称、目的、原理、步骤、数据记录与处理、结果与误差分析、**实际问题的建模与求解**、结论、思考题、AI 使用声明。
- 数据表按实验预先排好，学生填数。
- 评分量规：原理 20 · 数据 25 · 分析 25 · 实际问题 20 · 规范 10。AI 给评分建议，教师复核后发布。
- 提交：Word 模板上传，或问渠在线填写（本轮完成 Word 模板和在线表单的字段设计；在线填写功能放进平台开发轮次）。

**R9 双语**：课件每页标题、要点、公式说明采用中英对照；动画字幕中英两行；虚拟实验界面可切换中 / EN；指导书和报告模板中英对照。

## 附录：在线实验报告表单字段设计

表单与 Word 模板栏目一一对应；数据表按实验定义，AI 批改时直接读取结构化数据。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| lab_id | 选择 | 是 | 1.1 – 1.5，决定下面的数据表结构 |
| student_id、name、class、partner、date | 文本 / 日期 | 前四项是 | 学号、姓名自动带出 |
| objectives | 多行文本 | 是 | 实验目的 |
| principles | 多行文本 ＋ 公式 | 是 | 支持 LaTeX 公式输入 |
| procedure | 多行文本 | 是 | 简要步骤 |
| data_tables | 结构化表格（按 lab_id） | 是 | 行列与指导书数据表一致；数值单元格校验为数字；可附“测量值 / 理论值”成对字段 |
| data_processing | 多行文本 ＋ 图片 | 是 | 计算过程；至少上传一张图，或由平台根据表格自动作图 |
| results_errors | 多行文本 | 是 | 结果与误差分析；平台自动计算相对误差供参考 |
| model_problem | 文本 | 自动 | 本实验的机器人问题（只读） |
| model_step1 … model_step5 | 多行文本 | 是 | 实际问题的五步：问题、模型与假设、求解、实验检验、局限与改进 |
| conclusion | 多行文本 | 是 | 结论 |
| questions[] | 多行文本（按思考题数量） | 是 | 思考题逐题作答 |
| ai_use | 多选 ＋ 文本 | 是 | 未使用 / 解释概念 / 检查计算 / 其他，及说明 |
| attachments | 文件 | 否 | 可附实验截图、计算表格 |
| lab_task_status | 自动 | — | 从虚拟实验读取的任务完成情况（平台接入实验后提供） |
| ai_score_suggestion | 自动 | — | 按量规 5 项给出的建议分和评语，仅教师可见 |
| teacher_score、teacher_feedback | 教师填写 | — | 复核后的分数与评语，发布后学生可见 |
