# 实施细则 · 第 157 轮：白板三维简画（手绘风格的三维动画）

日期：2026-11-12
依据：Eddie 11-12：“那个白板软件可否也增加三维简画功能，出独特的三维动画”。
状态：**待 Eddie 确认**（第七节）

## 一、现在有什么、缺什么

白板课（第 35 轮）现在只有平面：方框、箭头、手写字、简笔画图标，用 rough.js 画成手绘线；“动作”也只有平面里的转、移、持续转、流动、闪。
要画立体的东西（机械臂、齿轮箱、缝纫机机头），只能画成一张固定角度的平面图，不能转过来看，零件也不能沿自己的轴转。

另一头，平台已有的三维（`production/three/wq3d.js`、教材的三维模型、Blender 视频）都是“渲染图”风格，和白板的手绘画面放在一起不搭。

**要的就是两者合起来：真三维的东西，用手绘线画出来，并且能转、能拆、能动。** 市面上的白板软件（VideoScribe 等）只有平面手绘，三维软件只有渲染图，这是问渠自己独有的画面。

## 二、决定

| 编号 | 决定 |
|---|---|
| S-1 | **新元素“三维简画框”**：画板上的一块区域，里面放一个小三维场景。场景每一帧按镜头投影成线条，用和平面元素同一套 rough.js 手绘线、同一支笔画出来，所以和白板其它内容是一个画风 |
| S-2 | **画法**：只画轮廓线和棱线（看得见的实线；被挡住的线可选画成浅虚线，像机械制图）；面填白或淡色，可加手绘斜线表示明暗（按光照方向疏密不同）。每条线固定随机种子，转动时线条不乱抖；需要“活泼感”时可开轻微抖动 |
| S-3 | **画出来的过程**：和平面元素一样跟着讲稿时间一笔一笔画——先画大轮廓、再画细节，最后上明暗；手跟着笔尖走 |
| S-4 | **三维动作**（按讲稿时间进行，拖进度同步）：**环绕**（镜头绕着东西转一圈或转到某个角度）、**关节转**（零件绕自己的轴转到某角度，如机械臂第 2 关节抬 60°）、**持续转**（齿轮、主轴、旋梭）、**滑移**（沿轴移动，如针杆上下）、**联动**（曲柄—连杆—滑块、凸轮—从动件按机构关系一起动，不是各转各的）、**拆开 / 合拢**（爆炸图）、**剖开**（一刀切开看里面）、**轨迹**（某一点走过的路径留下一条手绘线，如针尖、机械臂末端）、**推近**（镜头推到某个零件） |
| S-5 | **标注跟着走**：手写标签和引线挂在三维点上，东西转到哪、标签跟到哪；转到背面时标签自动淡出 |
| S-6 | **东西从哪来**：① 基本体（方块、圆柱、圆锥、球、管、带孔板、箭头、三维线）；② **零件库**（像 `icons.py`）：齿轮、轴承、电机、连杆、六轴机械臂、曲柄滑块、凸轮从动件、简化的缝纫机机头与针杆机构、传送带；③ AI 用前两样拼新场景。（第 3 步再加：导入平台已有的三维模型，抽出轮廓线和棱线，画成手绘风格） |
| S-7 | **网页版多一样东西**：暂停时学生可以用手指/鼠标拖着三维简画转着看，点“继续”回到讲解的角度。MP4 照常逐帧录 |
| S-8 | **AI 原生**：AI 排画板时，讲到立体结构、机构运动、空间关系，就放三维简画框并配动作（从零件库挑或用基本体拼）；老师也可以只说一句“这里画个三维的机械臂，第二关节抬起来”。编辑器里可以拖着调镜头角度、换零件库里的东西、请 AI 重排 |
| S-9 | **自己写，不加新依赖**：投影和遮挡在播放器里用自己的小段三维计算（基本体都是凸形，按面远近排序即可）；不引入新的商用授权。网页版和出视频用同一份代码（和现在一样） |

## 三、规则

1. 只往后加：现有白板课、平面元素和动作、已做好的课不受影响，旧课不重做也能照常播放和出视频。
2. 三维场景存在课文件里（Excalidraw 场景里的一个框，带 `wq_3d` 描述），编辑器打开不丢。
3. 实际问题以机器人为主，保留一个生活例子（课程标准）。
4. 出视频速度：一个三维简画框每帧不超过 0.1 秒（1280×720），否则降细节（减少斜线）再录。

**样片三段（第 1 步给 Eddie 看）**：
1. **机器人**：三关节机械臂画出来 → 镜头环绕半圈 → 第 2、3 关节依次抬起 → 末端画出一条轨迹（约 30 秒）；
2. **缝纫机**：机头里主轴—曲柄—针杆机构，主轴持续转、针杆跟着上下，针尖画出轨迹；再拆开成爆炸图、合拢（约 30 秒）；
3. **生活例子**：门的合页与门绕轴转开，镜头推近合页（约 15 秒）。

## 六、风险

- 三维模型导入（第 3 步）的线条可能太密，要自动挑主要棱线；做不好就只用零件库。
- 遮挡用按面排序，零件互相穿插时个别线会画错；零件库里避免穿插，AI 拼的场景出图后自动截图检查。
