## 一、这一轮做出什么

方案里“同一块板串起来”的最后一段：板上的编码器接口芯片，从 Verilog 一直做到版图。

```
规格（寄存器表、时序） ── Verilog RTL ── 仿真（与 Python 参考模型逐拍比对）── 波形
                                   │
                                   ├─ Yosys 综合到 SKY130 标准单元 ── 门数、面积
                                   │
                                   └─ LibreLane（OpenROAD）布局布线 ── GDS ── DRC / LVS 干净、时序收敛
                                                                         │
行为模型（JS）── 虚拟仪器的逻辑分析仪看 A/B 相和 SPI 帧 ── 电路板设计页“编码器接口”一页链接过来
```

学生在数字工厂打开“芯片设计”页，能看芯片规格、Verilog、仿真波形、综合结果、版图（分层、可缩放）、检查结果，并下载全部文件；
在虚拟仪器里能把 WQ-ENCIF 接到编码器上，转动电机，看逻辑分析仪上 A/B 相、毛刺被滤掉、SPI 读出的计数。

## 二、决定（建议）

## 三、规则

1. 教学示例：页面、RTL 文件头、产物说明都写“示例设计，未流片，未经硅验证”。
2. 不编数：面积、门数、时序、功耗都取工具报告原值；SKY130 工艺数据来自开源工艺库（Apache 2.0，第 17 轮已登记）。
3. 可重复：RTL 仿真结果逐字一致；版图产物记录工具版本与镜像摘要；CI 核对“提交的产物与这次跑出来的”门数、面积、检查结论一致（GDS 本身随工具版本可能有细微差别，不比逐字）。
4. 已有行为不变：微电子实验镜像原有的检查（反相器、校准、8 位计数器、贯通项目）照旧通过；虚拟仪器原有例题读数不变。
