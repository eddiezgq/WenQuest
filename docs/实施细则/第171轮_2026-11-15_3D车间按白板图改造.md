## 一、决定

| 编号 | 决定 |
|---|---|
| T-1 | **不另做一个页面**：就在数字工厂现有的“3D 车间”（左栏“设计与工艺 → 3D 车间”，`/3d`）上改，**所有厂都有**；实时状态、刀路回放这些现有功能保留 |
| T-2 | **分车间**：3D 场景里每个车间画一块有颜色的地面、矮墙轮廓、大字车间名。顶上一排按钮：“全厂 / ① 机壳铸造车间 / ② …”，点一个镜头飞过去；点地面上的车间也进去。缝纫机厂用白板图的五个车间 + 计量室 + 库房（写进缝纫机厂清单 `zones:`）；其他厂清单没写车间的，按设备的区域（生产、质检、库房、物流、研发）自动分区，区的范围取区里设备的外框 |
| T-3 | **参观（tour）**：“开始参观”按钮。先看全厂，再按车间顺序一站一站走：每个车间先看全貌，再走到车间里每类工位的代表设备（同一工作中心只停一台，每车间最多 8 站）。每站底部一张说明卡：第几站、哪个车间 / 哪台设备、做哪些零件的哪几道工序、这台现在的状态；“上一站 / 下一站 / 自动播放（每站 6 秒）/ 结束”。说明全由清单数据拼出来，不另编 |
| T-4 | **点开所有设备**：所有设备（含库位、计量室、物流小车）都能点。右侧面板分四页：**状态**（现有：灯色、工单、待加工、保养）、**工艺卡**（这台做的零件的工艺过程：全部工序、工时、物料清单，当前工序高亮；点一行跳到那道工序的设备）、**工序卡**（这道工序的设备、工作中心、工时、是否检验工序、前后工序；缝纫机厂另有工艺方案里的定位夹紧、工步与要点、工序检验）、**检验规程**（这道工序的测量特性：名义值、上下限、单位；计量室抽检；缝纫机厂另有铸造检验点、通用规程）。一台设备做几种零件、几道工序时，先在顶上选“零件 · 工序” |
| T-5 | **路线**：工艺卡上“在 3D 里画路线”，按工序顺序在设备之间画箭头（跨车间的也画），再点一次清掉 |
| T-6 | **数据**：全部取自清单（设备、位置、工序、工艺路线、工时、物料清单、测量特性、抽检）；缝纫机厂另读白板图生成脚本从《缝纫机厂工艺方案》拆出的工序规程，存成 `factory/plants/docs/wenquest-sewing.procdocs.json`，网关有就带上，没有就只给清单数据。不编参数 |
| T-7 | 接口：新增 `GET /api/plantmap`（车间、设备的工序、工艺路线、物料清单、测量特性、抽检、缝纫机厂的工序规程）；`/api/layout` 不变 |
| T-8 | 手机：面板改成底部抽屉；车间按钮可横向滑动；参观照样能用 |
| T-9 | 英文界面：按钮、标题都有英文；清单里的中英名照现有方式显示；缝纫机厂工艺方案的原文是中文，英文界面里注明“原文中文” |

**偏差**

1. T-2 原定“清单没写车间的厂按设备区域自动分区”：试了以后各厂的检验工位、库位夹在生产设备中间，按区域画框会互相压住，看不清。改成**清单没写车间的厂整厂算一个车间**（不画框，参观按工作中心一站一站走，最多 12 站）；以后哪座厂要分车间，在清单里写 `zones:` 就行（Excel 里是“车间分区”表）。
2. 减速器厂（演示工厂）的测量特性在仿真代码里（输出轴三坐标 8 项），检验规程页从那里取；其余工序没有单独记录的特性，页面写“由后面的检验工序把关”。
3. 英文界面里工序名取清单的英文部分（如 “Core making”），不带工序号；工艺方案原文是中文，注明 “(source in Chinese)”。
