## 二、决定（建议，待确认）

| D-2 | **网页文档 = 课程里的一个条目**。底层是 Moodle 的“页面”（问渠已能新建），正文由网页文档生成；源内容（内容块）存网关 `webdocs.db`。所以经典界面、手机、小程序都能看，Moodle 的备份和权限照常有效。 |
| D-3 | **可见范围两档**：“仅老师”（教案等，课程里的老师、助教能看能改，学生看不到）和“学生可见”（指导书、通知等）。默认“仅老师”；点“发布给学生”才对学生出现。 |
| D-4 | **编辑器在第 122 轮报告页基础上放开**：老师可以自由增删、上下移动内容块。块的种类：标题（三级）、段落（公式 `$…$`）、列表、表格（增删行列）、图片（上传或由表格作图）、提示框、分隔线。不做字体、字号、页边距之类的排版——要这些就用 OnlyOffice 改 Word。 |
| D-5 | **模板起步**：新建时选“空白”或一个模板；本轮模板：**教案、实验指导书、通知 / 说明**。教案的栏目和 AI 建课生成的 `教案.docx` 一致（`docs.py` 的 `plan()`），指导书和教材 `lab/NAME.yaml` 生成的指导书一致。 |
| D-6 | **AI 帮老师写**（第 121 轮 D-9：老师的文档 AI 写初稿，人改）：<br>① **AI 写初稿**：新建时说一句要求（如“第 3 章刚体转动，2 学时教案，机器人关节举例”），可勾选课程里的教材 / 资料作依据，AI 按模板写出整份文档；<br>② **改这一块**：每块旁边可让 AI “改写 / 扩写 / 缩写 / 译成中英对照”，结果先给老师看，点“采用”才替换。<br>国内用 DeepSeek，美国用 Claude（合规规定）。学生实验报告里仍然没有任何 AI 写作入口。 |
| D-7 | **AI 建课流程接上**：建课生成教案、实验指导书时，**同时生成网页文档**（教案“仅老师”，指导书“学生可见”），原来的 docx 继续保留；老师以后在网页上改。 |
| D-8 | **多人改与版本**：同课程的老师都能改；不做实时协同，沿用第 122 轮“后保存的一方提示重新载入”。自动保存草稿；每次“发布”存一个版本，可查看、可“恢复成这一版”。学生看到的永远是最近发布的版本，老师改草稿不影响学生。 |
| D-9 | **导出**：Word / PDF 随时可导（同第 122 轮）；一章或一门课的教案可“批量导出”成一个压缩包，方便报送。 |
| D-10 | **小程序端**：老师、学生都能看；老师在手机上能改文字段落和表格，加图、AI、调块顺序只在电脑网页上。 |

## 三、界面（定稿前的样子）

**新建**：课程编辑里某一节点“添加” → **“网页文档”** → 选“空白 / 教案 / 实验指导书 / 通知”，填标题；可选“让 AI 写初稿”（一个要求框 + 勾选依据资料）→ 进入编辑页。

**编辑页（电脑）**：中间是文档；每块悬停出现“↑ ↓ 删除 + 插入”和“AI 改这一块”；顶部是保存状态、可见范围（仅老师 / 学生可见）、“发布”、“导出 Word / PDF”、“版本”。右边可展开“AI 助手”面板，显示 AI 给的改写稿，点“采用”或“不要”。

**课程页**：网页文档和其它条目一样显示，图标不同；“仅老师”的标“仅老师”。学生点开是排好版的只读页面。

## 四、交付物

1. **网关**：`webdoc.py` 补齐自由文档的块（列表、提示框、分隔线、上传图片）和“模板”机制；`webdocs_api.py` 加课程文档的新建、保存、发布（写进 Moodle 页面）、版本恢复、批量导出、AI 初稿与改块；测试。
2. **模板**：教案、实验指导书、通知三个模板，栏目和现有 docx 一致；测试比对。
3. **网页端**：文档编辑页（由报告页拆出共用的块编辑组件，报告页继续用）；课程“添加”菜单加“网页文档”；小程序端查看和简单编辑。
4. **AI 建课流程**：`studio.py` 生成教案、指导书时同时写网页文档。
5. **帮助**：新增 `docs/帮助/老师用网页文档.md`；`在线编辑Word和Excel.md` 加“网页文档还是在线 Word，怎么选”。
6. **方案**：`docs/方案/建设方案.md` “文档与办公”一节补上本轮结果。

## 五、施工顺序与验收

施工顺序：网关（1）→ 模板（2）→ 编辑器拆共用组件、文档页（3）→ AI 初稿与改块（1 的 AI 部分）→ 建课流程接上（4）→ 帮助、方案（5、6）→ 本地完整环境用老师、学生账号走一遍 → 推送上线 → 服务器上实测 AI 初稿和导出。

验收：
1. 老师新建空白网页文档，加标题、段落、公式、表格、图片，调顺序；关掉再开内容都在。
2. 老师用“让 AI 写初稿”建一份教案：栏目与 `教案.docx` 一致，内容贴合要求；对其中一块“改写”“译成中英对照”，采用后替换，不采用不变。
3. “仅老师”的文档学生账号在问渠和经典界面都看不到；发布给学生后能看到排好版的页面；老师再改草稿，学生看到的不变，直到再次发布。
4. 两个老师账号同时改同一份，后保存的一方收到提示，不会互相覆盖；版本可查看、可恢复。
5. 导出 Word 版式正常、导出 PDF 正常；一章教案批量导出压缩包每份都在。
6. AI 建课新生成一节：课程里有教案、指导书两份网页文档（可见范围正确），docx 仍在。
7. 实验报告（第 122 轮）功能不受影响；学生报告里仍无 AI 写作入口。
8. 国内服务器 AI 走 DeepSeek，文档存在国内；小程序能看、能改文字和表格。
9. 网关测试、前端测试全绿；上线检查（含 PDF 实测）通过。
