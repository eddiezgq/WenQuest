## 一、照前几座厂的路子

电路板厂（第 85 轮）、芯片厂（第 103 轮）证明了“新厂只写一份清单，只补这座厂特有的东西”。传感器厂照这条路：
物料、BOM、工艺、设备、检验特性、布局写进 `factory/plants/wenquest-sensor.yaml`，ERPNext、订单计划、车间仿真、质量、成本、三维车间、设备、能源、安全、人员、经营、AI 巡检都按清单接上。

**传感器厂做什么**：协作机器人每个关节里都有两种传感器——测角度的**绝对值编码器**和测力矩的**关节扭矩传感器**（碰撞检测、拖动示教靠它）。本厂做这两种：

```
编码器线（洁净间）：来料检验 → 码盘清洗 → 码盘粘接对心（2 台）→ 读头装调（调间隙）→ 精度标定（对照基准编码器，写补偿表）→ 温度循环 → 终检 → 包装
扭矩传感器线：来料检验 → 应变片粘贴 → 胶固化 → 组桥焊线 → 温度补偿 → 砝码标定 → 终检 → 包装
```

工业园的链条就此接上：**芯片厂（WQ-ENCIF）→ 电路板厂（驱动板 B 版、编码器读头板 ENC-RD）→ 传感器厂（编码器）→ 机器人厂（关节）**。

| N-3 | **测量特性**：编码器——精度（整圈误差峰峰值，角秒）、一次谐波（偏心）、细分误差、信号幅值（平均、最低）；扭矩传感器——非线性、滞后、零点、蠕变、零点温漂（都按满量程 %）。名义值、规格限、散布都是示例值 | 进 MES、质量、控制图 |
| N-4 | **编码器误差曲线（本厂独有的追因手段，相当于芯片厂的晶圆图）**：每台编码器标定时出一条整圈误差曲线 + 谐波分解 + 信号幅值随角度的曲线；偏心表现为**每圈一个周期**（一次谐波），读头间隙不对表现为**信号幅值低、细分误差大**，码盘脏污表现为**某个角度一处尖峰、幅值掉坑**。只存生成参数，网关按参数还原；**精度、一次谐波、细分误差、幅值由曲线算出来**（测试核对一致）。页面“编码器误差曲线”只在传感器厂导航里出现 | 谐波分析是编码器行业的真实做法；学生看曲线形状就能分出三种原因 |
| N-5 | **四种隐藏问题与措施**：① 粘接对心机 cb-2 的对心夹具磨损（只有 cb-2 粘的码盘偏心变大）；② 读头装调台的间隙塞规磨损（间隙偏大 → 幅值低、细分误差大）；③ 洁净间过滤器堵塞（码盘脏污 → 局部尖峰）；④ 固化炉 cur-1 温度偏低（应变胶没固化透 → 扭矩传感器蠕变、滞后、温漂变大）。各有对症措施，另有看似有理但不对症的（重做补偿表把一次谐波“补平”、加大读头增益、终检加严） | 与前四座厂“隐藏问题”同一套；“补偿表掩盖偏心”是真实的坑 |

## 三、规则

3. 传感器厂从清单起来后，订单 → 算料 → ERPNext → 车间 → 检测 → 入库 → 开票整条走通。
