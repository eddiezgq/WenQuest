## 二、决定（建议）

1. **第六个机型“电脑横机”**，页面、项目、出件、CAE、零件库、AI 助手、FreeCAD 工作台照第 42 轮花样机的做法加一套，不另起炉灶。横机和花样机一样，价值在运动、电控和产量，**不出机构零件**。

2. **设计参数**（分组；默认值全用教材 17.8 节算例）：

   | 组 | 参数 |
   |---|---|
   | 基本 | 机号 E（针距 p = 25.4 / E）、针床有效宽度、系统数、选针点跨度（三角座跨度 L_k） |
   | 机头运动 | 最高速度 v、加速度 a、换向停顿（摇床、换纱嘴）、换向余量（自动 = 按补偿方式算 / 手填） |
   | 选针 | 选针器延迟 T_d、吸合—释放周期 T_c、选针器段数（多段选针把相邻针分开选）、提前量补偿方式（不补偿 / 固定提前量 / 按实时速度） |
   | 度目与线圈长度 | 目标线圈长度 l*、∂l / ∂d（约 2）、度目步进每步、测长精度、闭环增益 k |
   | 摇床与制动 | 摇床行程（针距数）、摇床伺服速度与加速度、制动加速度、针床两端留空 |
   | 衣片（花型） | 衣片针数、罗纹 / 提花 / 收针翻针各多少横列，提花几色（定一趟能织几行）；全成型选项（隔针编织） |
   | 机头驱动（选型用） | 机头运动质量、同步带轮半径、减速比、传动效率（教材没给，同第 42 轮刺绣机的做法补上，标“示例值”） |
   | 周期与产能 | 每天开机时间、一人看几台 |

3. **校核**（约 12 项，每项注出处和改法）：
   - 选针时间：t_n = p / v ≥ T_c / 段数（算例 E12、1.2 m/s：1.76 ms ≥ 1.2 ms 合格；E18 同速就不合格）。
   - 选针位置误差：按补偿方式算全速区和加速区的最大误差，≤ 0.25 个针距（不补偿时滞后 0.34 p，红；固定提前量加速区约 0.28 p，红或黄，看换向余量）。
   - 换向余量：固定提前量时 c ≥ v² / (2a)（算例 72 mm）。
   - 摇床：在“换向 + 三角座离开针床”的时间里走完、停稳。
   - 制动：急停距离 v² / (2a_brake) 在针床两端留空以内（算例 36 mm）。
   - 度目闭环：度目每步对应的线圈长度变化、测长精度够不够把线圈长度控制在 ±1%（教材 17.7 的结论：测长好于 0.5%、度目到 0.01 mm 量级）。
   - 机头驱动电机：峰值、有效转矩（按一趟的加减速算）。
   - 全成型（选了才有）：隔针编织后的等效机号。
   - 产量不设灯，放主要结果：一趟行程与用时、一片用时、每小时 / 每班件数。

4. **主要结果与曲线**：一趟的机头速度—位置曲线（标出换向余量、三角座跨度、织物宽度）；选针误差沿针床的分布（同虚拟实验 17-1 的标红）；**改进方案对照表**——基准、按实时速度补偿、加系统、提速，各自一片用时（教材 17.8 的表，按当前参数重算）。

5. **样机页签**：教材三维模型 17-1（只看结构和动作，不随参数变，同包缝机、花样机）；旁边链接虚拟实验 17-1、17-2。

6. **花型怎么来**：第一期用衣片的“横列构成”（罗纹、提花、收针翻针各多少横列）算产量，和教材 17.8 一致；**意匠图上传、编译成逐行机头动作放以后**（虚拟实验 17-2 已有编译器，以后接进来）。

7. **CAE**（同第 42 轮的口径）：
   - **机头伺服选型**：按一趟的加减速算峰值、有效转矩，通用电机表 + 本单位零件库一起比，留 1.2 倍余量。
   - **设计优化**：目标“一片用时最短”，在选针不出红灯的约束下找速度、加速度、补偿方式、系统数的最好组合（教材 17.8 的结论“提速收益小、加系统收益大”由优化器自己找出来）。
   - **模态**：针床、机架这类长件用上传 STEP 的办法（同机壳、绷架）；判据用“一阶固有频率 × 机头经过一枚针的时间”这一类，施工时按教材口径定，写回本细则。
   - 不做多体动力学、不做数控（横机的零件——三角、针床——不是平板件，不适合第 41 轮的平板铣削编程）。

8. **出件**：计算书（含改进方案对照表）、调机卡（选针提前量标定、度目闭环设定、摇床对针、新花型低速试织等，取自教材 17.9“现场要点”）、参数表与曲线（Excel）、参数文件（FreeCAD）。不出 STEP、DXF、宏。

9. **FreeCAD 工作台**：加“新建横机设计”（校核、参数，和网页版一字不差；没有三维零件）。

10. **帮助**：两份帮助加横机；第 52 轮的“典型案例”加**案例五：电脑横机——一片前片要织多久**（教材 17.8：选针跟不跟得上 → 换向余量 → 三个改进方向，提速只快 8%、加系统快 30%），照第 52 轮的做法由案例脚本真算、录一段网页版录屏。

11. **教材**：第 17 讲不改；软件的结果和 17.8 节逐项对上即可。
