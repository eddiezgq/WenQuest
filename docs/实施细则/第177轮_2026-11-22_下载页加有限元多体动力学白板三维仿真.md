## 一、起因与决定

- 11-22 Eddie：“没看见有限元和多体动力，另外把白板和三维仿真也放上去”；“其他我提的软件也搞好”。
- **问渠有限元、问渠多体动力学**：freecad-ai-parts 已有单独安装包（ADR-0096、ADR-0102：同一份代码，`build.ps1 -Edition fea|mbd`，FreeCAD 1.0.2 便携版 + 自己的品牌、免费 / 专业两档），但只出过 CI 验收用的测试版（认测试授权公钥，产物不得发布，留 7 天）。本轮出**正式构建的测试版（beta）**：不加 `-TestBuild`，免费版功能直接能用；专业版功能要授权文件，正式签名密钥还没定，先不开（下载页写明“专业版功能暂不开放”）。
- **白板课、三维仿真**：是平台上的在线功能，没有可安装的软件。下载页各加一张“在线使用”卡片，点进去到平台页面（美国 learn.wenquestrobotics.com、国内 learn.wenquestech.online，路径 `/pages/whiteboard/whiteboard`、`/pages/video3d/video3d`）。

## 二、规则

- 安装包在 wenquest-cad 仓库打（不动 freecad-ai-parts 的 CI）：取 freecad-ai-parts 固定提交，`build.ps1 -Edition fea|mbd`；装好后检查：安装目录文件齐全、`edition.json` 是对应版本且 `test_build` 为 false、带的 Python 能导入工作台；静默卸载干净。过了才发布到 wenquest-cad 的 GitHub 发布版（标签 `fea-v<版本>`、`mbd-v<版本>`，附 SHA-256）。
- 国内：同问渠 CAD，传阿里云 OSS（`cn-oss.yml` 按产品键），上海服务器留一份备用（`cn-server-file.yml`）。
- 下载清单 `versions.json` 加 `wqfea`、`wqmbd`；`pack.py` 加 `--installer 键 版本 网址 大小MB 校验码`（同 `--wqcad`，保留同一个包的国内地址）。
- 下载页（`tools/wqlicense/download_page.py` 生成）：加四张卡片。安装包两张同问渠 CAD 的样式（Windows 10/11 64 位、下载、使用说明）；在线两张（“在线使用”标签，按钮“打开”，没有版本、校验码）。
