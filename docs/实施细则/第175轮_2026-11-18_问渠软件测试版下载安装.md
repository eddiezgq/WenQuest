## 二、决定（建议）

| 编号 | 决定 |
|---|---|
| D-1 | **一个下载中心**：官网“下载”页（美国 wenquestrobotics.com/download，国内 wenquestech.online/download，同一套文件、同时更新）。每个软件一张卡：版本号、更新日期、适用系统、下载按钮、中英安装教程、校验码 |
| D-2 | **测试版授权一年**：登录账号后在下载页“申请测试授权”，自动发一个授权码（绑定账号，有效期 365 天，到期日写在授权码里，带签名，改不了）。软件第一次打开要输授权码；到期后打不开新文件、提示续期（已有文件不锁）。授权由学习平台账号系统发，国内、美国各自签发，两边都认 |
| D-3 | **能更新**：软件每次启动（联网时）查一次下载中心的版本清单，有新版提示“更新”，点了下载安装；授权码不用重输。不联网照常用到授权到期 |
| D-4 | **保护代码**：① 三个仓库改为私有（Eddie 在 GitHub 设置里改，见第四节）；② 下发的包里不放 Python 源码：我们自己的计算核心、AI 工作台编译成二进制（Nuitka / Cython，Windows、Linux 各一份），只留调用接口；③ 最核心的算法（AI 设计零件、零件库建库、各软件的计算核心里有专利价值的部分）放服务器上，软件联网调用——不下发就偷不走；④ 授权码校验本身也编译进去 |
| D-5 | **问渠 CAD 的安装包**：GitHub 的 Windows 机器上编译（一次约 6–8 小时，超过单个任务 6 小时上限就分两段缓存接力），出带安装向导的 `问渠CAD-测试版-0.3-Setup.exe`（Inno Setup，约 1 GB）：装完桌面有“问渠 CAD”，自带 Python、Qt、CalculiX，不用装 Git、VS、pixi。不签代码签名证书（测试版），教程里写“Windows 提示未知发布者，点‘仍要运行’” |
| D-6 | **许可边界（必须照做）**：问渠 CAD 改的是 FreeCAD 和 OCCT 的代码，这两者是 LGPL：**一旦对外发安装包，改过的 FreeCAD / OCCT 源码（27 + 6 个补丁）必须随包提供或给下载地址**，并允许用户替换这些库。我们自己写的 AI 工作台、计算核心是独立的程序，可以不公开、可以编译保护。也就是说：补丁本身保护不了，要保护的是 AI 和计算核心——这与第 D-4 条一致 |
| D-7 | **工作台类（缝纫机、轴承、凸轮）**：继续做成 FreeCAD 工作台，但统一进下载中心，同样一年授权、能更新、核心编译；装在问渠 CAD 里自动可用，装官方 FreeCAD 1.1 也能用 |
| D-8 | **数字工厂、问渠电子**：网页版不需要下载；数字工厂另出“单机版”（一键安装包，内含 docker 配置）放到下一轮，本轮不做 |
| D-9 | **安装教程中英两版**：每个软件一页“下载 → 安装 → 输授权码 → 第一次打开 → 更新 → 卸载”，每步配真画面（录屏，不截图）；问渠 CAD 另附系统要求和常见问题（智能应用控制、杀毒误报、未知发布者） |

2. **测试版发给谁**：任何注册用户都能申请（授权一年），还是你审核后才发？
