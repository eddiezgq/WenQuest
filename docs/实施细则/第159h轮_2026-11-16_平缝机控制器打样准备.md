## 一、目标

## 三、规则

1. 只认厂家规格书（或立创转存的同一份）：写名称、版本、页码；读不到的照实写“未核对”，不猜。
2. 改了原理图或封装：重出产物，设计规则检查 0 错误 0 未连、安全距离四条、统一报告不能出现新的“不通过”；关节驱动板的产物逐字不变。
3. 不编价格、交期；板厂工艺只引其公开页面并写查询日期。
