# 行业解决方案的演示稿和介绍片（第 44 轮起，先做缝纫机）

一份内容，三样东西：**演示稿**（像幻灯片一样翻页，三维样机等页面能直接操作）、**讲稿全文**（可打印）、**介绍片**（画面就是演示稿，配音是讲稿，用 Eddie 本人声音合成）。都在官网“缝纫机企业解决方案”页：wenquestrobotics.com/solutions/sewing/（首页“缝纫机设计与制造”卡片上的“看介绍”）。

## 拿去企业讲

1. 打开方案页，点“放映演示稿”（新窗口）。按 F 全屏。
2. 按 S 打开讲者窗口：上面是这一页的讲稿、下一页的标题和计时；两个窗口一起翻页。投影只投演示稿那个窗口。
3. 翻页：→、空格、PageDown 下一步；← 上一步。要点一条条出现。
4. 三维样机、花样机、刺绣机那几页是活的，可以拖动、操作；讲完按 → 继续。
5. 没有网的时候：提前把方案页打开一遍（三维页要从官网取 three.js），或者放介绍片。

## 改内容

内容只有一份：`textbook/web-editions/sewing/course/slides/sol_enterprise.yaml`（每页一个版式、中文内容、`notes` 讲稿）。数字不手写，用 `{{sol_enterprise.键:格式}}`，由 `course/calc/sol_enterprise.py` 调缝纫机设计软件的计算核心算出；单独运行这个程序能看到全部数字。截图是 `textbook/web-editions/sewing/img/sol_*.webp`（本地完整环境里软件的真实界面）。

改完：

```
python3 site/solutions/sewing/build.py      # 重出 deck.html、script.html、index.html
```

推送到 main 就上线。规则：不点任何企业、品牌的名字；不写价格；中文画面不放网址和二维码。

## 重出介绍片

1. 讲稿：完整版 `docs/课程视频/解决方案/缝纫机-完整版/讲稿.yaml`（只写开场的话，其余用演示稿每页的讲稿）；短版 `docs/课程视频/解决方案/缝纫机-短版/讲稿.yaml`（`skip` 跳过的页、`say` 换成更短的话）。都写了 `langs: [zh]`，只出中文。
2. GitHub → Actions → “Lecture videos 公开课视频” → Run workflow：task `render`；lectures 填 `docs/课程视频/解决方案/缝纫机-短版 docs/课程视频/解决方案/缝纫机-完整版`；voice `clone`；engine `cv2`；upload `none`；lang `zh`。
3. 跑完，`预览/` 里有关键画面拼图、字幕、上传资料、时长；成片在这次运行的下载页（Releases 里 `lecture-video-运行号`）。
4. 网页用的版本：压成 720p（`ffmpeg -i lecture.mp4 -vf scale=-2:720 -c:v libx264 -crf 28 -preset slow -c:a aac -b:a 96k -movflags +faststart`）放 `site/solutions/sewing/video/short.mp4`、`full.mp4`，封面 `short.jpg`、`full.jpg`，字幕转成 `short.vtt`、`full.vtt`，再跑一次 `build.py`，推送。
5. B 站手动投稿：用下载页里的中文成片和 `cover_bilibili.png`，标题、简介、标签照 `上传资料.zh.md`，勾选 AI 合成声明。

## 做别的行业

照缝纫机的做法：在对应教材的课程包里放 `slides/sol_<行业>.yaml`（写 `talk: {id, name}` 和 `only_zh: true`）、`calc/sol_<行业>.py`，在 `site/solutions/<行业>/` 放一份 `build.py`，在 `docs/课程视频/解决方案/` 下放讲稿。课件引擎的“演讲稿模式”和视频工具的“只出中文”是通用的。
