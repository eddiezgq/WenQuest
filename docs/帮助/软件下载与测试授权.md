## 能下载什么

| 软件 | 形式 | 说明 |
|---|---|---|
| 问渠 CAD | Windows 安装包（约 1.4 GB） | FreeCAD 1.1.4 + 27 处内核修正 + AI 工作台；美国下载放 GitHub 发布版，国内放对象存储（开通前国内页显示“准备中”） |
| 问渠缝纫机、问渠轴承、问渠凸轮 | FreeCAD 工作台 zip | 装在问渠 CAD 或官方 FreeCAD 1.1 里；问渠程序是 Python 3.11 字节码，不含源码 |

网页版软件（问渠电子、数字工厂等）不用下载。

## 授权码怎么来的

- 下载页“领取一年测试授权”：用全站登录换令牌（`/api/v1/auth/sso`），再调 `POST /api/v1/license/beta`。已有没过期的码会原样再给一次（换电脑用同一个码）。
- 码的样子 `WQ1.<内容>.<签名>`：内容写账号号、地区、到期时间，Ed25519 签名。私钥由服务器的 `WQ_SECRET_KEY` 推出来——**改了 `WQ_SECRET_KEY`，所有旧码失效，而且软件里内置的公钥也要换（重新打包）**。
- 软件端 `tools/wqlicense/wq_license.py` 内置美国、国内两把公钥（`KEYS`），两边发的码都认；码存 `%APPDATA%\WenQuest\license.txt`。
- 查公钥：`curl https://<站>/api/v1/license/public-key`。

## 发新版本（维护者）

1. 工作台：`python3 tools/wqlicense/pack.py`（要本机有 `python3.11`）→ 写 `site/download/files/*.zip`、`.sha256` 和 `site/download/versions.json`；提交、推送、部署后两站同时更新。
2. 问渠 CAD：在 `wenquest-cad` 仓库手动启动 “WenQuest CAD installer”（版本号输入框），几个小时后出 GitHub 发布版；再 `python3 tools/wqlicense/pack.py --wqcad <版本> <下载网址> <大小MB> <SHA256>` 登记。
3. 下载页由 `tools/wqlicense/download_page.py` 生成（美国版直接写；国内版由 `tools/site_cn/build.py` 生成并过合规检查）。改了页面要两个都重跑。
4. 软件联网时读 `versions.json` 比版本号，有新版就提示。

## 常见问题

- **Windows 说“未知发布者”**：测试版没买代码签名证书，点“更多信息 → 仍要运行”。
- **国内页下载 zip 404**：`deploy/site-handle/cn.caddy` 的共享文件规则要含 `zip|exe|sha256`（本轮已加）。
