### 等标准正文的

| 内容 | 标准 | 现在 |
|---|---|---|
| 额定动载荷、额定寿命 | GB/T 6391（对应 ISO 281） | “未知” |
| 额定静载荷、静安全系数 | GB/T 4662-2025（等同 ISO 76） | “未知” |
| 按内部载荷分布的修正参考寿命 | ISO 16281:2025 | “未知” |
| 外形尺寸与目录对照 | GB/T 297 等 | 产品库核对里为“未知” |
| 公差等级 | GB/T 307.1、钢球标准 | 尺寸链、工艺的偏差由企业填 |

### 计算里的简化

- 套圈按刚性（柔性轴承除外）。薄壁轴承、交叉滚子的套圈实际会变形，刚度比算出来的低。
- 低速静力学：除角接触高速外不计离心力和陀螺力矩；圆锥滚子不计挡边摩擦。
- 圆锥成对的温度：滚子按内圈温度，外圈径向按自身温度，配合按调整时温度。
- 接触刚度在薄壁轴承里按自由接触角取常数（曲率随角度变化很小），接触应力按实际角度算。
- 零件图不画倒角、退刀槽、保持架、凸度；预紧的薄壁轴承图上按零游隙画。

### 还没做的

推力球与推力滚子、调心滚子轴承；四点接触薄壁轴承和交叉滚子的工艺模板（等企业给工艺）；双列圆锥能在产品库里查、暂不能计算。
