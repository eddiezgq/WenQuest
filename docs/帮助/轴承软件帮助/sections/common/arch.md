::anim{id=arch}

| 层 | 是什么 | 在哪 |
|---|---|---|
| 计算核心 | 纯 Python，不联网、不调 AI；网页版服务和 FreeCAD 工作台共用同一份 | `services/bearing/bearingkit/` |
| 计算服务 | 网页版的接口：校核、零件、合套、SPC、工艺、尺寸链、产品库核对 | `services/bearing/app.py`，网址 `/bearing/api/` |
| 网页版 | 四个页面，项目存浏览器或云端 | `apps/bearing/` |
| FreeCAD 工作台 | 同一个表单、同一个核心，本机建模出图 | `services/bearing/freecad/` |
| 云端与 AI | 账号、企业授权、云端项目、产品库、AI 起草（经问渠网关） | `services/gateway/` |

规矩：

1. **判定只由程序做**。AI 起草的数先过程序检查，人确认后才进项目。
2. **不编数据**。许用值、材料、温度、线膨胀系数、工艺留量都由企业填；标准里的系数从买来的正版标准录入，录入前结果为“未知”。
3. **示例一律标“虚构”**。
