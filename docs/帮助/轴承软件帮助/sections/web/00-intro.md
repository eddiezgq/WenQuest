问渠轴承把滚动轴承专著里的几何、接触、载荷分布和制造工艺做成了工程工具：填外形尺寸和内部设计，选它装在什么设备里，软件算出每个滚动体的载荷、接触应力、刚度和游隙，逐项判合格、不合格或“未知”；再往下出零件图、STEP、工艺路线和工序卡，做合套选配和检测 SPC。

| | 网页版（本帮助） | FreeCAD 工作台 |
|---|---|---|
| 在哪用 | 浏览器打开就用，不登录也能算 | 装进 FreeCAD 1.1，在本机算 |
| 适合 | 方案比较、合套选配、检测与 SPC、工艺、云端项目、产品库、AI 起草 | 在三维 CAD 里建精确实体、出工作图和工序简图 |
| 计算核心 | 同一份 | 同一份——同一个项目文件，两边结果逐项相同 |

**第一次用？从案例开始**：[典型案例](#cases)里有三个，从实际问题一步一步做到结论，每步都有“试一试”。

现在能算的轴承：

| 类型 | 能做的 |
|---|---|
| 深沟球、角接触球 | 载荷分布、接触应力与接触椭圆、游隙链（配合与温差）、油膜、故障频率；角接触高速离心力、成对预紧 |
| 圆柱滚子 | 切片法线接触、凸度与倾斜、端部受载 |
| 圆锥滚子 | 单列（挡边力）、成对与两端支承（调游隙或预紧、刚度、调整量曲线）、配合与温度对工作游隙的影响 |
| 谐波减速器柔性轴承 | 内圈随凸轮变形、外圈薄圆环弯曲、钢球载荷、交变应力幅 |
| 交叉滚子 | 正反交替滚子、预紧、倾覆刚度 |
| 薄壁轴承 | 四点接触、角接触（可成对）、深沟三种截面，钢球作为自由体 |

额定载荷、寿命和静安全系数按国家标准，标准正文录入前一律显示“未知”，不算合格。
