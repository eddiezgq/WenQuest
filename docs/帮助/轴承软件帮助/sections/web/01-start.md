### 打开

- 官网“解决方案 → 行业专用软件 → 轴承设计与制造”，点“在线使用”；或直接打开 `/bearing/`。
- 不登录也能用：改参数、看全部结果、打印计算书、下载 STEP 都行。项目自动存在你自己的浏览器里，也可以“保存为文件”带走。
- 页面右上角“？帮助”按当前页面打开本帮助对应的一节。

### 从头校核一个轴承

<ol class="steps">
<li>点 <b>新建</b>，左边最上面选类型（深沟球、角接触、圆柱、圆锥、谐波柔性、交叉滚子、薄壁）。</li>
<li><b>应用场景</b>：选轴承用在哪——通用（直接填力）、减速器齿轮轴、电机转子、机床主轴、汽车轮毂、机器人关节、凸轮轴。软件按场景把齿轮力、不平衡、切削力等换算到这个轴承上，每一步公式和数都列在中间“载荷从哪来”。</li>
<li><b>外形尺寸</b>和<b>钢球（滚子）与沟道</b>：内径、外径、宽度；滚动体直径、个数、节圆直径、沟曲率系数、游隙或接触角、挡肩高度。</li>
<li><b>校核限值</b>：许用接触应力、最小钢球间隙、最小壁厚，按企业标准或客户要求填。软件不替你编许用值，没填的项是“未知”。</li>
<li>中间看图（剖面、每个钢球的载荷），右边看校核；点 <b>计算书</b> 打印或存成 PDF。</li>
</ol>

### 结论怎么读

- <b style="color:var(--ok)">合格</b>：有数、有限值、满足。
- <b style="color:var(--bad)">不合格</b>：有数、有限值、不满足；下面写着原因和改法方向。
- <b style="color:var(--warn)">未知</b>：缺数据（没填的许用值、还没录入的标准）。**未知不算合格**——总结论会写“有项目缺数据，暂不能判定合格”。
- 计算值：只给数、不判（刚度、受载滚动体数等）。

### 先试一个：游隙和接触角

深沟球轴承的径向游隙一变，自由接触角和轴向游隙就跟着变。下面这个小计算器和软件用同一组公式：P_d = d_o − d_i − 2D_w，A = (f_i + f_o − 1)D_w，cos α₀ = 1 − P_d/(2A)，G_a = 2√(A² − (A − P_d/2)²)。
