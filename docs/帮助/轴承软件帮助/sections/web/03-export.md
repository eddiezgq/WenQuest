| 文件 | 在哪 | 说明 |
|---|---|---|
| 计算书 | 顶部 **计算书** → 打印 / 存 PDF | 输入、剖面与载荷图、校核、载荷推导、方法与依据、设计说明 |
| 项目 `.wqbearing.json` | **保存为文件** / **打开文件** | 网页版和 FreeCAD 工作台互通 |
| 截面图、DXF、STEP | **零件图与三维** | 整套、内圈、外圈、单个滚动体 |
| 工艺模板 `.wqprocess.json`、工序卡 | **工艺** 页 | 模板在同类轴承间套用；工序卡每道一页 |
| 配套清单 CSV | **合套选配** | 每套的内圈、外圈、钢球组和游隙 |
| FreeCAD 工作台 | **零件图与三维 → 下载 FreeCAD 工作台**（`/bearing/api/freecad.zip`） | 见 FreeCAD 版帮助 |
| 产品库空表格、FreeCAD 用的产品库 | **产品库** | 开通企业授权的单位 |
