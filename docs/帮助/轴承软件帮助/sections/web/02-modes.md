### 应用场景：载荷从哪来

| 场景 | 填什么 | 软件替你算什么 |
| --- | --- | --- |
| 通用 | 径向力、轴向力、力矩、转速 | — |
| 减速器齿轮轴 | 模数、齿数、压力角、螺旋角、齿轮位置、跨距、几个工况 | 圆周力、径向力、轴向力（含轴向力在节圆上的力偶），分到本轴承 |
| 电机转子 | 转子质量、剩余不平衡、带拉力 | 重力、不平衡离心力、带拉力，每 10° 算一次 |
| 机床主轴 | 悬伸、跨距、切削工况 | 前后轴承反力 |
| 汽车轮毂 | 车轮载荷、转弯侧向加速度、两排间距 | 直行、左右转弯下每排的力；外圈转 |
| 机器人关节 | 轴线方向、总重、力臂、两轴承间距、摆角 | 倾覆力矩；摆动时疲劳一项“不适用”，提示伪布氏压痕 |
| 凸轮轴 | 一圈内的力表 | 每个转角下本轴承的力和接触应力曲线 |

载荷系数 f_p 按冲击程度从手册或企业规范取值，软件不替你编；不填时疲劳一项为“未知”。静强度取接触应力最大的工况（名义载荷）；疲劳取各旋转工况乘 f_p 后最不利的。

### 图怎么看

- **剖面**：过轴线的半剖面，套圈打剖面线；虚线是最重钢球的工作接触线，黄色粗弧是接触椭圆长轴范围。
- **钢球（滚子）载荷**：正视图，径向力向下；颜色越深载荷越大，外圈外面的短线长短与载荷成正比。交叉滚子、薄壁轴承分两组（两条对角线或两列）一组向外、一组向内。
- **游隙链**、**故障特征频率**、**最重载钢球**（载荷、工作接触角、接触椭圆半轴）。
- **调整量曲线 / 预紧量曲线**：成对、交叉滚子、薄壁轴承填了曲线范围就画；竖线是当前值，软件不推荐“最佳值”。

### 校核项

| 校核 | 怎么算 | 需要填 |
| --- | --- | --- |
| 相邻滚动体间隙 | 节圆上弦长减滚动体直径 | 可选：最小间隙 |
| 沟底（滚道）壁厚 | 沟底直径与内径 / 外径之差的一半 | 可选：最小壁厚 |
| 工作游隙 | 初始 − 配合 + 温差，为负判不合格（深沟球被预紧） | 过盈量、温度 |
| 静强度：最大接触应力 | 赫兹接触，接触应力最大的工况 | 静强度许用接触应力 |
| 疲劳：最大接触应力 | 各旋转工况 × f_p，取最不利 | f_p、疲劳许用接触应力 |
| 接触椭圆不越过挡肩 | 工作接触角 + 椭圆半长对应的角，小于挡肩角 | 挡肩高度 |
| 预紧不脱开 | 各工况下所有滚动体（对角线、两列）都保持接触 | 预紧 |
| 刚度 | 平衡点上刚度矩阵的逆（另外几个方向自由） | — |
| 油膜厚度、λ | Hamrock–Dowson（点接触）、Dowson–Higginson（线接触） | 转速、黏度、黏压系数、粗糙度 |
| 额定载荷与寿命 | GB/T 6391、GB/T 4662、ISO 16281 | 标准正文录入前“未知” |

总结论取最差的一项：有不合格就是“不合格”；没有不合格但有“未知”，就是“有项目缺数据，暂不能判定合格”。
