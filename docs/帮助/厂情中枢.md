# 厂情中枢

数字工厂工作台左侧“工作区 → **厂情中枢**”（本期开放给厂长、计划员和老师）。

它把整个工厂放在一张图里：订单、工单、设备、刀具、零件、检验、库存、供应商、卖出去的设备、客户……每一样东西都是一个**对象**，对象之间有**关系**，每一次变化都有**记录**。
- 所有数字都能点到原始数据，看清它从哪来。
- 一路点下去，就能把散在各个系统里的事情串起来。

这是第 17 轮的第一期（17A：工厂本体与对象浏览器）。异常和追因（17B）、推演和动作（17C）、AI 代理（17D）都建在它上面。

## 一、全貌地图

打开厂情中枢，先看到的是全貌地图。

**两排色块：**
- 上排是**价值链**：经营与战略 → 市场与客户 → 销售与交付 → 产品与研发 → 供应链 → 计划与排产 → 生产执行 → 质量 → 仓储与物流 → 客户服务。
- 下排是**支撑面**：设备维护、安全健康环境、人员与组织、能源与公用、财务。
- 最下面是**中枢**自己的对象（工程任务单、提议，以后还有异常、场景、动作）。

**每一块显示四样东西：**
- 对象总数（大数字）；
- 有数据的类型数 / 全部类型数；
- 最近 24 小时的变化次数；
- 一排小方块，每个方块是一类对象。小方块的颜色是**数据成熟度**：

| 颜色 | 含义 |
|---|---|
| 深青 | 已有数据：工厂现在就在产生 |
| 浅青 | ERPNext 可启用：ERPNext 里有这类单据，开起来就有数据 |
| 浅黄 | 教学模拟：由教学模拟器产生 |
| 灰色虚线 | 待采集：要上采集应用或接外部系统（后续各领域包） |
| 青色点线 | 后续各期生成：异常、场景、动作、AI 运行，17B–17D 才有 |

“亮着”和“暗着”的地方一眼可见，这也是工厂数字化还缺什么的清单。

**操作：**
- 点一个领域，下方展开它的全部对象类型：数量、成熟度、数据来源。
- 点对象类型，进入这类对象的列表。
- 在列表里可以按属性加条件筛选（例如“刀具 · 设备 = grd-01”），并导出 CSV。

## 二、搜索

地图上方的搜索框什么都能搜：订单号、工单号、零件序列号、设备号、物料编码、客户名。

- **同一个东西的不同叫法都能找到。** 例如轴承在 ERPNext 里叫 BRG-6207，零件库里叫 A-BRG-DG/6207，平时就叫 6207；搜这三种写法，进的是同一个对象。
- 结果右边写着怎么匹配上的：别名、编号、包含、相近。
- 输错几个字时会给出“相近”的结果。

## 三、对象 360 页

点任何对象，进入它的 360 页。

**顶部**
- 类型、编号、名称、状态色；
- 所属领域、首次出现时间、最近更新时间；
- 其他叫法（别名）。

**左栏：属性**
- 每个数值带单位。
- 数值旁边的 ⓘ 是**来源**：点开显示产生这个数值的那条原始总线消息，包括时间、发送方、主题和完整内容。
- 例如测量值来自检验站的哪一条记录，订单交期来自 ERPNext 的哪一次同步。

**中间：关系图**
- 默认显示一跳。右上角可以选到三跳。
- 颜色按领域区分，中间带黄圈的是当前对象。
- **单击**一个点：展开它的邻居，并突出与它相连的关系。
- **双击**一个点：进入那个对象的 360 页。
- 鼠标停在点上，下方显示全名。

**右栏：时间线**
- 按时间倒序列出这个对象经历的事：出现、开工、每道工序完工、换刀、停机与恢复、检验不合格、ERPNext 单据变化……
- 属性变化写成“旧值 → 新值”。
- 右上角可以按事件种类筛选。
- 每条都能点 ⓘ 看原始记录。

**底部：相关对象**
- 按关系分组，例如零件的“加工于（工序任务）”“测量”“搬运记录”“装入（减速器总成）”。
- 加工记录上写着当时的设备、刀具、节拍和**刀具剩余寿命**。
- 每组最多显示 50 个；“导出 CSV”导出全部分组。

**手机**
- 手机上也能看：三栏变成上下排列。

## 四、各页上的对象链接

下面这些页面上的单号、序列号、设备号带了下划虚线：
- 首页的订单、客户、AGV、在运零件；
- 车间终端的当前工单、零件、待做工单；
- 订单与计划的工单、物料、销售订单、缺料物料；
- 质量的零件、工单、不合格品单；
- 数字孪生的设备序列号、出厂工单、输出轴。

使用方法：
- 鼠标停一下，弹出摘要卡：几个关键属性、状态、关系概况。
- 点击进入 360 页。

## 五、一个完整的例子：从现场的一台减速器追到磨床的砂轮

1. 在“数字孪生”里打开一台现场设备，点它的序列号，进入“现场设备”360 页。
2. 相关对象里，“出厂序列号”是它出厂时的减速器总成；点进去。
3. 总成的“装入”分组列出装进去的输出轴 SH301-…；点进去。
4. 输出轴的“测量”分组：6 项检测值，每个都能看到原始检验记录。
5. 输出轴的“加工于”分组：7 道工序，每道都写着设备、节拍和刀具。
   - 磨外圆那一道写着 GRD-01 的砂轮编号（如 grd-01/3），以及当时的剩余寿命。
6. 打开“对象列表 → 刀具 / 砂轮”，或在关系图上从工序任务展开，就能看到同一片砂轮还磨过哪些轴。
7. 再从这些轴继续点，就能找到它们装进了哪些总成、卖给了哪些客户。

这条链在 17B 里会自动走：一旦某台设备报警，系统直接列出同一片砂轮磨出的其他轴，以及它们所在的客户。

## 六、数据从哪来、多快更新

**来源**
- **总线消息**：设备状态与事件、检验测量、不合格品、AGV、跑合试验、设计发布与 G 代码、AI 提议；ERPNext 单据也经桥接发到总线。
  - 这些都是**实时**的，延迟一般 2–5 秒。
- **不在总线上的数据**：每分钟对账一次。包括：
  - 设计与工艺提交、8D、质量问题情景；
  - 数字孪生（现场设备、维修单）、工程任务单；
  - 计算服务的分析作业、看板指标、工单成本、零件库主数据。

**教学和生产分开**
- 教学模式和生产模式的对象互不可见。

**情景重置**
- 老师重置实验 7 情景时，教学模式的本体一起清空，从主数据重新开始。

**权限**
- 每类对象和属性有敏感级别：0 公开、1 内部、2 部门、3 受限。
- 学生只能看到 0、1 级。例如看不到“质量问题情景”（老师注入的隐藏问题），也看不到客户联系人、人员等部门级对象。
- 老师在教学模式能看到全部。

**底部的同步状态**
- 显示已处理到第几条总线消息、落后多少条、有没有跳过的坏消息。
- 厂长（老师）可以点“从头重建本体”：清空当前模式的本体，从总线历史从头算一遍。结果和实时同步完全一样（自动测试核对）。
