# 课程菜单使用说明（老师和学生）

> 适用版本 v0.11.0（第 3 轮 B1 步）。这些功能都在问渠里直接完成，不需要去其他页面。
> 作业、测验、成绩、日历、收件箱在 B2 步完成后补充到本说明；老师编辑课程在 B3 步。

## 公告

- **学生**：左侧课程菜单点“公告”，最新的在最上面，新公告带黄色标记。内容长的点“展开全文”。点“评论”可以看大家的回复。
- **老师**：点右上角 **发布公告**，填标题和内容（空一行就是分段），点“发布公告”。每条公告下面可以 **编辑** 或 **删除**。

## 讨论

- 进入“讨论”看到课程的讨论区（只有一个时直接打开）。每个话题显示发帖人、时间、回复数和未读数。
- 点 **发起讨论**，写话题和内容后发布。
- 点进话题可以看全部回复，回复会缩进显示在它回复的那条下面。每条下面可以 **回复**；自己的帖子可以 **编辑**、**删除**。
- **老师** 在话题页右上角可以 **置顶**、**锁定**（锁定后不能再回复）。
- 新建的课程会自动带一个“课程讨论区”。

## 在线课堂（腾讯会议 / Zoom）

- **老师**：点 **安排在线课**，填主题，选平台（腾讯会议 / Zoom / 其他），选日期、开始时间和时长，填会议链接和/或会议号、密码，可以写一句说明，点“保存”。这次课会自动出现在课程日历里。之后可以 **编辑**、**删除**。
- **学生**：看到“正在进行 / 即将开始 / 已结束”三栏。开课前 15 分钟起显示为“进行中”，点 **进入会议** 打开腾讯会议或 Zoom；没有链接的点“复制会议号”。在微信小程序里点“进入会议”会复制链接，粘贴到浏览器或会议软件即可。

## 成员与分组

- **成员**：名单按老师、助教、学生排列，可以按姓名或邮箱查找、按小组筛选。老师还能看到邮箱和最近访问时间。
- **添加成员（老师）**：点 **添加成员**，每行填一个用户名或邮箱，点“添加”，加入为学生。结果会列出：已添加、原来就在课程里、找不到的账号。
- **移出课程（老师）**：学生一行右边点“移出课程”，确认即可。已交的作业和成绩会保留。
- **小组（老师）**：在“小组”页填名称点 **新建小组**；每个小组可以 **调整成员**（勾选学生后保存）、**改名**、**删除**。页面会提示还有哪些学生没分组。
- **AI 分组（老师）**：点 **AI 分组**，用一句话说要求（例如“4 人一组，每组成绩均衡”），点“生成方案”。AI 给出分组和理由，组名可以直接改。满意就点 **替换现有小组**（先删掉原来的小组）或 **保留现有小组，另建这些组**；不满意就改要求再生成。确认之前什么都不会改。
- **学生**：在“小组”页看到全部小组和组员，自己的小组标“我的小组”。
