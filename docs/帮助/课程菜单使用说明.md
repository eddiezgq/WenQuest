# 课程菜单使用说明（老师和学生）

> 适用版本 v0.13.0（第 3 轮 B 步完成）。所有功能都在问渠里直接完成，问渠里已经没有“经典界面”的入口。

## 公告

- **学生**：左侧课程菜单点“公告”，最新的在最上面，新公告带黄色标记。内容长的点“展开全文”。点“评论”可以看大家的回复。
- **老师**：点右上角 **发布公告**，填标题和内容（空一行就是分段），点“发布公告”。每条公告下面可以 **编辑** 或 **删除**。

## 讨论

- 进入“讨论”看到课程的讨论区（只有一个时直接打开）。每个话题显示发帖人、时间、回复数和未读数。
- 点 **发起讨论**，写话题和内容后发布。
- 点进话题可以看全部回复，回复会缩进显示在它回复的那条下面。每条下面可以 **回复**；自己的帖子可以 **编辑**、**删除**。
- **老师** 在话题页右上角可以 **置顶**、**锁定**（锁定后不能再回复）。
- 新建的课程会自动带一个“课程讨论区”。

## 在线课堂（腾讯会议 / Zoom）

- **老师**：点 **安排在线课**，填主题，选平台（腾讯会议 / Zoom / 其他），选日期、开始时间和时长，填会议链接和/或会议号、密码，可以写一句说明，点“保存”。这次课会自动出现在课程日历里。之后可以 **编辑**、**删除**。
- **学生**：看到“正在进行 / 即将开始 / 已结束”三栏。开课前 15 分钟起显示为“进行中”，点 **进入会议** 打开腾讯会议或 Zoom；没有链接的点“复制会议号”。在微信小程序里点“进入会议”会复制链接，粘贴到浏览器或会议软件即可。

## 成员与分组

- **成员**：名单按老师、助教、学生排列，可以按姓名或邮箱查找、按小组筛选。老师还能看到邮箱和最近访问时间。
- **添加成员（老师）**：点 **添加成员**，每行填一个用户名或邮箱，点“添加”，加入为学生。结果会列出：已添加、原来就在课程里、找不到的账号。
- **移出课程（老师）**：学生一行右边点“移出课程”，确认即可。已交的作业和成绩会保留。
- **小组（老师）**：在“小组”页填名称点 **新建小组**；每个小组可以 **调整成员**（勾选学生后保存）、**改名**、**删除**。页面会提示还有哪些学生没分组。
- **AI 分组（老师）**：点 **AI 分组**，用一句话说要求（例如“4 人一组，每组成绩均衡”），点“生成方案”。AI 给出分组和理由，组名可以直接改。满意就点 **替换现有小组**（先删掉原来的小组）或 **保留现有小组，另建这些组**；不满意就改要求再生成。确认之前什么都不会改。
- **学生**：在“小组”页看到全部小组和组员，自己的小组标“我的小组”。

## 作业

- **学生**：在“作业”或单元里点开一份作业。上面是截止时间、满分和提交方式，下面是要求。
  - 在线填写的直接在框里写（公式可以用 LaTeX）；要交文件的点 **添加文件**（实验报告模板填好后从这里交），每个文件不超过 50 MB。
  - 点 **提交**。如果老师开了“草稿”，可以先 **保存草稿**，写完再点“提交”。
  - 截止前可以点 **修改提交**：改文字、移除或添加文件。
  - 批改后，这里显示分数和老师评语。
- **老师**：打开作业就是批改页。上面是学生人数、已提交、待批改；左边是名单（待批改的排在前面，逾期的有红色标记）。
  - 点一个学生，右边显示他交的文字和文件（点文件名下载）。
  - 点 **AI 评分建议**：AI 按作业要求和评分量规读学生的文字和 Word/PDF 文件，给出分数、分项得分和评语草稿。你可以改，改完点 **保存**；**保存并批下一份** 会直接打开下一位待批改的学生。AI 的建议不会自动保存。

## 测验

- 在“测验”或单元里点开一份测验：看到限时、可作答次数、满分、截止时间，以及自己做过的记录和最高分。
- 点 **开始答题**。上方是倒计时和“交卷”，左边是题号（答过的变蓝），可以 **逐题作答** 或 **全部显示**。支持单选、多选、判断、填空、数值题。答案每分钟自动保存，换题时也会保存；时间到自动交卷。
- 交卷后显示得分，每题标出对错、正确答案和解析（老师设置了“截止后才公布”的，截止后才能看）。
- 老师出题见下面“编辑课程 → 测验”。

## 成绩

- **学生**：看到每项作业和测验的得分、百分比和老师评语，以及课程总评。点项目名称可以直接打开它。
- **老师**：全班成绩表（每行一个学生、每列一项，最后一行是平均分），可以按姓名查找；点列名打开那项作业或测验去批改。

## 日历

- 课程菜单里的“日历”只显示这门课；左侧导航的“日历”汇总你的所有课程。
- 月视图里：在线课堂是红色，作业是黄色，测验是蓝色，其他课程事件是绿色。点某一天，右边列出当天的安排；下面是“接下来”的安排。作业、测验点名字就能打开。
- **老师** 在课程日历里可以 **添加事件**（例如期中考试），也可以删除自己加的事件。在线课堂会自动出现在日历里。

## 收件箱

- 左侧导航点“收件箱”。“消息”是和老师、同学的对话（有未读数），“通知”是平台发来的提醒。
- 点 **写消息**：按课程列出所有人，可以一个个点选，也可以一键选“全部老师”“全部同学”或某个小组。多人时会分别发给每个人。
- 点一个对话就能看记录、直接回复；页面每 20 秒自动刷新。

## 编辑课程（老师）

进入方式：课程“单元模块”页右上角 **编辑课程**，或课程首页右侧“老师工具”里的 **编辑课程**。改完点 **完成编辑**。

- **课程设置**：改课程名称、简介，设置学生能不能看到这门课。
- **章节**：每章可以 **改名**、写 **简介**、**对学生隐藏/显示**、用 ↑ ↓ 调顺序、**删除**（章里有内容时会提醒：内容和学生的提交、成绩会一起删除）。最下面填名称点 **添加章节**。
- **章节里的内容**：每一项可以 **编辑**、**改名**、**对学生隐藏/显示**、↑ ↓ 调顺序、**移到…** 别的章、**删除**。
- **添加内容**：每章下面点类型：
  - **页面**：写讲义正文。工具栏有标题、列表、链接、公式（输入 LaTeX）；点“预览”看公式效果；`</>` 可以直接改 HTML。
  - **文件**：选一个或多个文件上传（课件 PPT 上传后学生可以直接在网页上演示）。
  - **作业**：名称、作业要求（含评分标准，AI 评分时按这里的标准）、截止时间、满分、提交方式（在线填写 / 上传文件、最多几个文件）。
  - **测验**：见下一节。
  - **链接**：外部网址，例如 PhET 仿真。
  - **讨论区**：一个新的讨论区。
  - **在线课**：转到“在线课堂”安排腾讯会议 / Zoom。
- 课程是双语的时候，名称和正文分“中文”“English”两栏填写。
- 在活动页里，老师右上角也有 **编辑** 按钮。

## 测验出题（老师）

- 在“测验”页点 **新建测验**，或在编辑课程里某章点“测验”。
- **设置**：名称、说明、限时（分钟）、可作答次数、满分、何时公布答案（交卷后立即 / 测验截止后 / 不公布）、开放时间和截止时间。
- **AI 出题**：选一章、题数，可以写一句要求（例如“多出计算题、难度中等”），点 **出题**。AI 按这一章的讲义写题（带答案和解析），题目加到下面，你可以逐题修改、删除、调顺序。
- **手动出题**：最下面选题型添加：单选（点字母标出正确选项）、多选（可标多个）、判断、填空（可以填几个都算对的答案；题干里用 ______ 表示空）、数值题（答案和允许误差）。每题有分值和解析。公式用 `\( \)` 包起来。
- 点 **保存**。已经有学生作答的测验，题目不能再改，只能改设置。
