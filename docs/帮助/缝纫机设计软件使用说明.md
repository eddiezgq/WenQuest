# 缝纫机设计软件使用说明（平缝机第 39 轮；包缝机、绷缝机第 40 轮；接入问渠 CAE 第 41 轮）

问渠“缝纫机设计与制造”软件有两种用法，计算核心是同一份，同一组参数结果完全一样：

- **网页版（在线使用）**：官网首页 → 解决方案 → 企业 → 行业专用软件 → 缝纫机设计与制造 → “在线使用”；或直接打开 learn.wenquestrobotics.com/pages/sewing/sewing。
- **FreeCAD 工作台“问渠缝纫机”**：开通企业账号后，在网页版“导出”页下载安装包，装进 FreeCAD 1.0。

现在有三种机型：**平缝机**（教材第 3–8、23 讲）、**包缝机**（504 三线、514 四线，第 9 讲）、**绷缝机**（401、406、407、602、605，第 10 讲）。页面上方点机型切换；链接后面加 `?machine=overlock` 或 `?machine=cover` 可直接打开包缝机、绷缝机。

| 机型 | 校核什么 | 样机页签 | 另外能出 |
|---|---|---|---|
| 平缝机 | 21 项：针杆惯性力、钩线、挑线、送布、张力、整机惯性力、共振、尺寸链；30 针虚拟试缝 | 三维虚拟样机（调机参数同步，能看故障） | STEP、FreeCAD 宏、DXF |
| 包缝机 | 11 项：送布窗口余量、下弯针摆角 / 传动角 / 卡死临界 / 针尖速度、上弯针传动角、差动送布平整度、切刀时机与重叠量 | 教材的包缝机三维结构模型（只看结构转动，不随参数变） | STEP、FreeCAD 宏、DXF |
| 绷缝机 | 7 项：钩线回升、弯针尖高度、间隙、针下行让弯针、针在弯针平面下不相碰、定时离窗口边缘、窗口时间 | 教材的弯针动画（参数同步） | **耗线量与线团计划**（订单件数、缝长、损耗、线团长度 → 每根线用多少米、几个线团） |

说明：包缝机上弯针最小传动角 39° 会显示“注意”——教材算例机就是这样，第 9 讲解释了为什么先保留。绷缝机第一期没有三维零件，三维样机以后单做。

## 谁能用什么

| 账号 | 能做的事 |
|---|---|
| 来宾（不登录）、未开通的账号 | 改参数，看三维样机、校核、时序与曲线、零件与制造，全部能看；**不能保存、不能导出** |
| 已开通的企业账号 | 以上全部，加上：保存机型项目（同一单位的人共享），导出 7 种文件，下载 FreeCAD 工作台 |
| 管理员 | 在网页版最下面“开通企业账号”里开通或收回（价格未定，目前手动开通） |

### 管理员怎么开通一个企业账号

1. 让对方先在学习平台注册一个账号。
2. 管理员登录，打开“缝纫机设计”页面，拉到最下面“开通企业账号（管理员）”。
3. 填对方的登录名或邮箱、单位名称（同一单位填同一个名字，项目才能共享），点“开通”。
4. 对方刷新页面，左栏出现“缝纫机设计”，页面上方显示“已开通 · 单位名”。
5. 要收回，在同一列表里点“收回”。

## 网页版怎么用

1. **左边改参数**：分七组（基本参数、刺布机构、挑线机构、钩线机构、送布机构、线张力、平衡与机壳）。拖滑块或直接输数字，右边马上重算。“恢复教材算例参数”回到教材第 3–8 讲的算例。
2. **右上方结论条**：绿色 = 全部合格；黄色 = 有需注意的；红色 = 有不合格的。
3. **六个页签**：
   - 三维样机：教材的平缝机虚拟样机，调机参数（定时、间隙、张力、送布、转速、平衡）跟你的设计同步，可以试缝、看故障标红。下面是主要结果（连杆比、惯性力、钩线角、供线量、整机惯性力、共振转速等）。
   - 校核：21 项，每项有数值、判据、出自第几讲，不合格的给出怎么改；上面是 30 针虚拟试缝的结果。
   - 时序与曲线：全机运动时序图，针尖位移、挑线供线与耗线、送布牙轨迹、整机惯性力四张曲线。
   - 零件与制造：各机构零件的关键尺寸、梭尖间隙尺寸链与合格率、装配调机顺序。
   - CAE 分析（已开通）：见下一节。
   - 导出：见下。
4. **保存项目**（已开通）：上方项目条里填名字点“保存”；“另存为”复制一份；下拉选项目打开。

## CAE 分析（已开通的企业）

用当前这组参数，把零件和机构交给问渠数字工厂的计算服务算；算完的结果会自动写进同一组参数导出的设计计算书（“CAE 分析结果”一节）。每个单位每天最多提交 20 个计算任务（有限元、模态、动力学、零件减重，页签右上角显示今天用了几个）、100 个数控程序；电机选型和设计优化不占次数。

| 分析 | 怎么用 | 判据 / 结果 |
|---|---|---|
| 零件强度与疲劳（有限元） | 选零件（平缝机：针杆连杆、针杆曲柄；包缝机：引针连杆、引针曲柄、下弯针摆杆），点“提交计算”。材料在左边“主轴电机（CAE 选型用）”一组里选。约束、载荷自动加：轴孔支承，销孔加一转里最大的力；疲劳按一转的受力曲线算，每针一个循环 | 安全系数 ≥ 2；寿命 ≥ 5 年（每天 16 小时、每年 300 天）。可看应力云图、下载 Word 报告 |
| 机壳固有频率（模态） | 点“选择 STEP 文件”上传机壳模型（30 MB 以内），选材料，提交。最低的水平面当底面固定 | 二阶激振频率 / 一阶固有频率 ≤ 0.90。平缝机算出的一阶频率在参数范围内时，点“采用”回填“机壳一阶固有频率”，共振校核随之更新 |
| 机构动力学 | 点“算动力学”：按你的曲柄半径、连杆长、针杆组件质量建多体模型，算刺布（引针）机构所需的主轴转矩 | 与本软件公式对照，相差 ≤ 5% |
| 主轴电机选型 | 点“电机选型”：整机各机构的惯性转矩加缝纫阻力矩，峰值和均方根各留 1.2 倍余量，从电机表里挑最小的够用的主轴伺服 | 推荐型号、对照表、一转的转矩曲线 |
| 设计优化 | 选目标（平缝机：挑线机构、平衡率、最高转速；包缝机：下弯针、上弯针、差动比；绷缝机：弯针定时），几秒给出最好的三组，每组标出红灯、黄灯数；点“采用”回填 | 结果可复现（每次一样） |
| 零件减重（拓扑优化） | 在“减重与加工”里选零件（同强度分析的零件）和要留下的材料（40%、50%、60%，不含孔周围的毂和平衡块），提交。按一转里受力最大的那个力，在现在的外形里找材料该留在哪。算完看减重后的形状和质量比，可下载轮廓 DXF、三维 STEP | 一定要点“送有限元复核”：同一组受力、同一材料，判据仍是安全系数 ≥ 2、寿命 ≥ 5 年。包缝机下弯针摆杆受的力有一部分垂直于板面，减重计算管不到这部分，留 50% 以上并以复核结果为准（例：留 50% 安全系数 2.9、寿命约 32 年，合格；留 40% 不合格） |
| 数控编程（铣削） | 选平板零件（平缝机：针杆曲柄、针杆连杆、挑线曲柄、挑线杆、挑线摇杆、两个偏心轮；包缝机：引针曲柄与连杆、弯针偏心轮与摆杆、下弯针、两个送布臂），点“出铣削程序”；减重后的零件在它的结果里点“出铣削程序” | 立式加工中心，外轮廓、型腔（含铣穿的减重孔）、钻孔，自动选刀和切削参数；“试切”检查撞刀、过切、超程、转速、主轴功率，0 错误为合格。工件零点在零件上表面、外形中心。可看刀路俯视图、下载 G 代码 |

“计算任务”里列出本单位这个机型的全部任务和排队位置，点一个看结果。数字工厂没接上时页签会提示，设计优化和电机选型照常可用。

## 导出的文件

| 文件 | 用途 |
|---|---|
| 设计计算书（Word） | 结论、参数、主要结果、全部校核、5 张图、零件参数、尺寸链与公差建议、调机顺序 |
| 调机卡（Word） | 装配车间用：7 步调机，每步给目标值，带确认格 |
| 参数表与运动曲线（Excel） | 参数、零件尺寸、校核、每 2° 的运动曲线数据 |
| 三维模型（STEP） | 16 个机构零件（上下轴、针杆曲柄、连杆、针杆、机针、挑线曲柄、挑线杆、摇杆、旋梭、两个送布偏心轮、针板、送布牙），任何 CAD 都能打开 |

## FreeCAD 工作台

安装（只做一次）：

1. 在网页版“导出”页点“下载安装包”，得到“问渠缝纫机-FreeCAD工作台.zip”。
2. 打开 FreeCAD，在 Python 控制台（菜单“视图 → 面板 → Python 控制台”）输入 `App.getUserAppDataDir()` 回车，显示的就是用户数据文件夹。
3. 在这个文件夹里找到（没有就新建）`Mod` 文件夹，把压缩包里的 `Mod\WenQuestSewing` 整个文件夹复制进去。
4. 重启 FreeCAD，在工作台下拉列表里选“问渠缝纫机”。

工具栏 11 个按钮：新建平缝机设计、新建包缝机设计、新建绷缝机设计、重新计算、校核结果、时序图、转动机构、导出 STEP、导入参数、导出参数、提交到问渠工厂。

- 在模型树里选中“平缝机设计”，属性面板里就是全部设计参数（分组与网页版相同），改完按 Ctrl+R 或“重新计算”，零件和校核一起更新；双击“平缝机设计”打开校核结果。
- “提交到问渠工厂”要先装数字工厂企业版的“问渠”工作台（宏包），整套零件进设计审批。

## 说明与限制

- 计算模型与判据出自教材《缝纫机设计与制造》第 3–8 讲和第 23 讲；线环、送布、张力、机壳振动是教材里的示意模型。结论用来比较方案和调机，不代替样机试验。
- 三维样机按教材的标准尺寸演示；改了曲柄半径、连杆长这类机构尺寸后，零件形状请看导出的三维模型或在 FreeCAD 里看。
- 三维模型是机构级的参数化零件，机壳、底板等请在此基础上自己建模。
- 来宾试算每个网络地址每分钟最多 120 次。
- 减重后的轮廓按计算网格取出、已经圆顺过，出图前仍可在 CAD 里再修；太窄（最小立铣刀 Ø3 放不进）的减重孔会自动填回。绷缝机没有三维零件，不能减重和编程。
- CAE 分析的零件模型是机构级的简化零件（平板加孔）；有限元结果用来比较方案、找薄弱处，定型前仍要按实际零件图复核。动力学按低速仿真再按转速平方换算（只有惯性载荷时这样换算是精确的），不含重力和摩擦。
