# 问渠凸轮使用说明

网址：<https://wenquestrobotics.com/cam/>（官网“解决方案 → 行业专用软件 → 凸轮设计与制造”，产品页 `/cases/cam.html`）。
演示不用登录；项目自动存在你自己的浏览器里，也可以“保存为文件”带走、“打开文件”接着做。开通了的企业登录后还可以把项目存到云端，同单位的人共用（第八节）。

## 一、从头设计一个凸轮（以缝纫机挑线槽凸轮为例）

1. 点 **新建**，左上角改项目名称。
2. **机构**页：
   - 从动件选“摆动”，接触选“滚子”，勾“槽凸轮（形封闭）”；
   - 填基圆半径 r_b、滚子半径 r_r、中心距 a、摆杆长 L、接触宽度 b；
   - 凸轮转向按实际选逆时针或顺时针。
3. **运动程序**页：一行一段，类型选“升 / 停 / 回”，填转角（度）、行程（摆动从动件是摆角，度），选运动规律。
   - 所有段加起来必须是 360°，右下角“合计”变绿才算对；
   - 不想用公式的，勾“用点表”，直接贴转角和位移两列（每行一个点，至少 8 个），按周期三次样条连起来。
4. **载荷与材料**页：转速、从动件当量质量（摆动的是转动惯量）、弹簧刚度和预压量、工作载荷、两种材料的弹性模量和泊松比。不填的项目，相关校核就是“未知”。
5. **校核限值**页：许用压力角（推程、回程）、许用接触应力、最小曲率半径。软件不替你编许用值。
6. 中间看凸轮转动：**播放 / 暂停**，拖“凸轮转角”滑块，或者直接在下面任一条曲线上点、拖，凸轮跟着转到那个角度。红线是接触点法线，蓝虚线是从动件运动方向，两者夹角就是压力角。
7. 右边 **校核**：每一项是 合格 / 不合格 / 未知 / 不适用，总体结论取最差的一项。“未知”下面有提示，告诉你缺什么。
8. 压力角或根切不合格时，到“机构”页点 **求最小基圆**：按许用压力角和曲率要求求出最小基圆半径并填进去。
9. 点 **计算书**：输入、运动程序（含 Cv、Ca）、校核、全部曲线、凸轮廓线、方法与依据排在一页里；点“打印 / 存为 PDF”，在浏览器打印对话框里选“另存为 PDF”。

## 二、校核项说明

| 校核 | 怎么算 | 需要填 |
| --- | --- | --- |
| 无刚性冲击 / 无柔性冲击 | 段与段接头处速度、加速度是否连续 | — |
| 推程 / 回程最大压力角 | 接触点法线与从动件运动方向的夹角 | 许用压力角 |
| 不根切 | 理论廓线外凸处曲率半径大于滚子半径；槽凸轮两侧都查 | 滚子半径 |
| 实际廓线最小曲率半径 | 廓线一、二阶导数 | 可选：最小曲率半径限值 |
| 高速不跳离 | 弹簧力 + 载荷 + 惯性力始终大于 0，算出不跳离的最高转速；槽凸轮是形封闭，不适用 | 转速、质量、弹簧 |
| 滚子换侧次数（槽凸轮） | 接触力换向的次数，每次都在槽间隙处有冲击 | 转速、质量 |
| 最大接触应力 | 赫兹线接触 | 材料、接触宽度、许用接触应力 |
| 凸轮轴峰值力矩 | 接触力 × 类速度 | 转速、质量 |

## 三、制造（顶部“制造”）

1. 选加工方式：**磨削 X–C**（凸轮磨床，凸轮随 C 轴转、砂轮沿 X 进退）、**铣削 XY**（加工中心）或**慢走丝**（只出 DXF 和点表）。
2. 填刀具半径（砂轮或铣刀）和弦高公差（默认 0.001 mm）。槽凸轮的刀具半径不能大于滚子半径；等于时一刀同时磨出两侧。
3. “机床设置”里的数值是示例：X 轴半径值还是直径值、磨削时凸轮转速、各遍留量、光磨圈数、程序号；铣削的主轴转速、进给、每层切深、安全高度、顺铣。请按本厂设备改。
4. 中间看机床上的凸轮：磨削时凸轮按 C 转、砂轮在 X 轴上进退；铣削时刀具沿刀心轨迹走。红点是仿真里最大过切处，绿点是最大欠切（多肉）处。
5. 右边校核：
   - **不过切**：凹处曲率半径必须大于刀具半径，否则会把凹处磨坏（大砂轮最常见）；
   - **X–C 能走**：刀心轨迹对凸轮中心不是“星形”时 X–C 走不了，改铣削或换小砂轮；
   - **程序仿真偏差**：软件把导出的程序文本重新读一遍，让刀具扫过毛坯，和设计廓线比；不超过弦高公差 + 0.1 µm 为合格（这只说明程序没问题，零件公差由企业自己定）。
6. 下载：加工程序 .nc、廓线 .dxf（R12 多段线）、点表 .csv（每 0.5° 一行：升程和廓线坐标）、三维模型 .step。
   - 外廓凸轮的厚度取接触宽度；槽凸轮要另填毛坯半径和盘厚，槽深取接触宽度。不画轴孔和键槽。
   - 下载 STEP 时会显示 B 样条拟合的最大偏差（一般在 0.01 µm 量级）。
7. **砂轮修整后没更新半径**：填实际砂轮半径，点“算误差”，看用旧半径的程序磨出来廓线和升程各差多少。

## 四、测量与补偿（顶部“测量与补偿”）

1. 选数据格式：
   - **升程表**（转角, 升程，每行一个点）：用与设计相同的从动件，或把测量仪设成同样的滚子半径和偏距测得；摆动从动件的升程用度；
   - **廓线 XY 点**：凸轮坐标系下的廓线点（外廓或槽内侧壁）。
2. 粘贴数据或选文件。想先看效果，点“载入合成测量数据（演示）”——这是软件按设计升程加上已知误差造出来的，只作演示。
3. “自动对相位”：测量零位没和零件（键槽、销孔）对准时勾上，软件求相位差；零位已经对准时不要勾，结果更准（自动对相位会把一部分形状像“错开一点角度”的误差当成相位差）。
4. 填转速（不填用设计转速）和**许用加速度误差**，点“分析”。看：
   - 相位差、基圆 / 零点误差；
   - 误差曲线、谐波柱状图（红 = 1 阶偏心和装夹，黄 = 低阶热处理变形等，蓝 = 高阶机床和颤振；低阶到第几阶可改）；
   - 误差引起的加速度误差曲线和峰值，以及“这样的误差最高能跑多少转”，表里还列出该转速下每阶允许的最大幅值（超了标红）。
5. **补偿**：选要修的阶次（例如 1–6），点“生成补偿程序”。软件把这些阶次的误差反向加到运动程序上，按“制造”里的刀具和机床重新出程序，并预测补偿后剩下的误差（就是没选的那些阶次）。下载补偿后的 .nc。
6. 点“记下这次测量”，结果记在项目里（保存为文件时一起带走），同一批凸轮可以看趋势。
7. 计算书里会多出“制造”和“测量与补偿”两节（做过才出现）。

## 五、凸轮系统（以加工中心换刀机构为例）

一台机器往往是一根凸轮轴上装几个凸轮，各管一个动作，彼此要错开。“示例…”里选“加工中心凸轮式换刀机构”：弧面分度凸轮转换刀臂（停—转 65°—停—转 180°—停—回 65°），槽凸轮 + 摆杆让换刀臂下拔、上插。

1. **系统设计**（顶部第一个）
   - 左边按页签填：凸轮轴与驱动（转速、起动/制动转角、惯量、传动比、效率；电机额定值照样本填，不填就是“未知”）、每个凸轮（运动程序、尺寸、输出惯量和负载、弹性频率）、联锁与限值。
   - 中间是时序图（凸轮轴转一圈各凸轮的位置，阴影是运动段，下面一行是时间；点或拖时序图可以选转角），凸轮轴转矩和电机转矩曲线。
   - 右边是校核：联锁（前一个动时后一个必须停着）、电机峰值/均方根转矩和转速、弧面凸轮的压力角、啮合、筋厚、根切、接触应力，槽凸轮的各项。
   - 下面是停歇段残余振动（每个停歇段开始时刀尖还在晃多少）和**设计搜索**：每种运动规律都试一遍；填了允许振动或电机额定值时，再求满足它们的最高转速。点“采用”换上那种规律。
2. **三维与制造**：整机动画（拖动旋转、滚轮缩放、可暂停和拖转角）。弧面凸轮的模型按加工方法生成（与滚子同尺寸的刀具沿每个滚子的路径扫过毛坯）；可下载弧面凸轮 STL、四轴（A 凸轮 + B 转台）加工程序 .nc、换刀臂 STEP。
3. **CAE 分析**：换刀臂的有限元强度、固有频率、疲劳寿命，以及整机多体动力学（MuJoCo）与本软件解析结果的对照。
   - 没登录也能看示例的预先算好的结果；提交新的计算要用问渠企业账号登录，计算在问渠数字工厂的计算服务上排队，每个单位每天有用量上限。
   - 注意：表里的“固有频率”是换刀臂本身（孔固定）的频率，系统振动用的是含传动链的整体频率，两者不同。
4. **计算书**：参数、运动程序、时序图、全部校核、转矩与振动、CAE 结果、方法与依据，可打印或存 PDF。

## 六、在 FreeCAD 里用（第 5 步）

网页版里点“下载 → FreeCAD 工作台 .zip”（“三维与制造”和“制造”页都有）。

1. 装 FreeCAD 1.1。把压缩包里的 `Mod\WenQuest` 文件夹复制到 FreeCAD 的用户 Mod 目录，重启 FreeCAD：
   Windows `%APPDATA%\FreeCAD\Mod`，macOS `~/Library/Application Support/FreeCAD/Mod`，Linux `~/.local/share/FreeCAD/Mod`。
   已经装过问渠数字工厂的宏包也没关系：解压到同一个 WenQuest 文件夹，两边的按钮都在。
2. 工作台列表里选“问渠”，点“凸轮”，选网页版“保存为文件”存下的项目（`examples` 文件夹里有示例）。
3. 软件用与网页版同一个计算内核重算校核，结果逐项相同（在“报告视图”里看摘要），并建出零件：
   - 盘形 / 槽凸轮：与网页版 STEP 同一个实体。槽凸轮要在项目里填毛坯（半径、板厚），没填时只建示意件，不导出。
   - 弧面分度凸轮：精确实体。工作面（滚子接触的两侧齿面）按啮合方程求出，偏差 ≤ 0.25 µm，与网页版的四轴程序对照在弦高公差内；槽底按刀具端面直径扫出，比平底刀实际加工最多多留约 0.7 mm 的料（非工作面，偏安全）。
   - 换刀臂（凸轮系统里有换刀臂时）。
4. 凸轮系统按时序装配：在模型树里选“凸轮系统”，改属性“转角”，转塔和换刀臂按时序转、上下动。
5. 导出到你选的文件夹：每个零件的 STEP、加工程序（弧面凸轮的四轴程序；单个凸轮在网页版“制造”里填了刀具时出程序）、
   盘形凸轮的点表 CSV、每个零件一张 A3 工作图（SVG，用浏览器打开可打印成 PDF；技术要求留给工程师填）。
6. 缺 Python 包（scipy、shapely）时点“凸轮”会提示一条安装命令，照着在 FreeCAD 的 Python 控制台里运行即可。弧面凸轮建模约一分钟。

## 七、AI 起草（第 6 步，要登录）

AI 只起草，判定全由代码；草稿要你点“采用”才进项目。每人每天 30 次（三项共用）。

1. **一句话起草运动程序**：在“运动程序”上方点“AI 起草”，写一句要求，例如“主轴转一圈：前 100° 用摆线规律推出 40 mm，停 80°，再用 120° 退回，其余停着”。
   - 草稿表里**黄色**的格子是句子没给的数：软件不替你编，在句子里补上再起草，或采用后在表里填。
   - AI 自己写了句子里没有的数，会被清空并提示；**蓝色**的数是代码补的（一圈剩下的停歇角、回到起点的行程、分度凸轮的净分度）。
   - 草稿可用时，按当前机构先把全部校核算一遍给你看；满意再点“采用这个草稿”，不满意点“撤销采用”回到原来的程序。
   - 运动规律是 AI 的建议（鼠标停在行上可看理由）；句子里点名的规律照用。
2. **校核解释**：校核栏下点“AI 解释这些校核”，用白话说哪几项不合格或未知、可以怎么改。文字里的每个数都和校核结果核对过，含其他数的句子整句删掉。
3. **计算书设计说明**：打开计算书，“设计说明”一节可以自己写，也可点“AI 起草设计说明”再改；随项目保存，打印时只印文字。
4. 国内服务器用 DeepSeek，美国服务器用 Claude；每次调用都留记录（谁、哪项、句子前 200 字、是否通过代码检查），不存项目全文。

## 八、云端项目（第 7 步，开通的企业账号）

和缝纫机设计软件是同一份企业开通：开通了的单位，成员登录后把项目存到云端，换台电脑、换个人都能接着做。没登录或没开通时一切照旧（浏览器里自动保存、保存为文件）。

1. **登录**：顶栏右边点“登录”，用问渠账号登录后回到凸轮页面；顶栏显示你的名字和单位。
2. **存到云端**：点顶栏“云端项目”→“存到云端…”，写个名称→“存为新项目”。单个凸轮和凸轮系统都能存；左下角显示“云端：名称，第几版”。
3. **以后保存**：照常改（改动先自动存在本机），改好了点“云端项目”→“保存到云端”，存成新的一版。想留一份不同的，用“另存一份…”。
4. **打开**：“云端项目”里“本单位的项目”列出名称、类型、版本、最后谁在什么时候存的；点一下就打开。打开示例、新建或打开文件，就和云端项目脱开（不会误存到别的项目上）。
5. **两人同时改**：不锁定。如果你打开之后同事已经存过新版，你再保存时会提示“某某在几点存过第几版……所以没有保存”，可以选：
   - **把我的另存一份**：你的修改存成一个新项目（名称后加“（我的）”，可以改），对方的版本不动；
   - **打开对方的版本**：换成对方存的内容（放弃你没存的修改）。
6. **历史版本**：每个项目保留最近 20 版，展开“历史版本”看每一版是谁、什么时候存的；点“恢复这一版”把它存成新的一版（不删除任何一版）。
7. **删除**：列表里点“删除”，再点一次“确定删除？”。谁建、谁存、谁恢复、谁删，平台都留记录。
8. 限制：每家单位最多 500 个云端项目，单个项目 2 MB 以内（测量记录很多时可能超过，可先清理测量记录或存成文件）。

## 九、示例

“示例…”下拉里有四个虚构参数的示例：挑线槽凸轮、送布抬牙凸轮（5000 r/min 下跳离不合格，作反例）、包装机推料凸轮、加工中心凸轮式换刀机构（凸轮系统）。
网址后加 `?example=编号` 直接打开某个示例，加 `&embed=1` 是只看动画和校核的嵌入版（产品页右边就是它）。

## 十、给维护的人

- 计算内核 `services/cam/camkit/`（纯 Python + numpy/scipy；制造 `mfg.py`、STEP `step.py`、测量 `measure.py`），接口 `services/cam/app.py`，网页 `apps/cam/`（Vue 3 + Vite）。
- 镜像 `services/cam/Dockerfile`（在仓库根目录构建，先编网页再装内核），容器 `cam`，Caddy 把主域名的 `/cam/` 去掉前缀转给它。
- 测试：`cd services/cam && pip install -r requirements-dev.txt && python -m pytest -q`；部署工作流里也跑。
- 与开源 `mechanism` 包的交叉对照：`pip install mechanism && python tools/crosscheck_mechanism.py`。
- STEP 用 OpenCASCADE 读回检查（只在本地）：`pip install cadquery-ocp && python tools/crosscheck_step_occ.py <示例名> <文件.step>`。
- 凸轮系统：内核 `camkit/system.py`（时序、转矩、振动）、`globoidal.py`（弧面凸轮）、`globoid_mfg.py`（模型与四轴程序）、`atc_arm.py`（换刀臂）、`cae_setup.py`（给 CAE 的模型）、`system_opt.py`（设计搜索）；接口 `system_api.py`，CAE 转发 `cae_bridge.py`（经网关 `/api/v1/industry/me` 认身份，经数字工厂枢纽 `/api/design-sw/*` 提交，密钥 `WQ_FACTORY_CAE_KEY` 由部署脚本生成）。示例的 CAE 结果存在 `examples/atc-globoidal.cae.json`。
- FreeCAD：工作台入口是数字工厂的 `factory/digital/freecad/Mod/WenQuest/`（`InitGui.py` 只用顶层语句，代码在 `wq_workbench.py`，与 freecad-ai-parts 同步）；凸轮页 `services/cam/freecad/wq_cam.py`（建模、装配、导出）和 `wq_cam_drawing.py`（工作图）；弧面凸轮精确实体 `camkit/globoid_solid.py`（同一组曲面数据分别给 OpenCASCADE 和 FreeCAD 建实体）。包由凸轮服务 `/api/freecad.zip` 现打。本地验收：`python tools/check_freecad.py <FreeCADCmd 路径>`（四个示例逐项对比网页版结果，检查实体、装配中滚子与槽贴合不干涉）。
- 云端项目：网关 `services/gateway/app/cam_projects.py`（`/api/v1/cam/projects`，数据 `<data_dir>/cam.db`：项目、版本、记录三张表；开通沿用缝纫机的 licenses），凸轮服务 `projects_api.py` 转发登录 cookie（`/api/me`、`/api/projects/*`），网页 `apps/cam/src/cloud.js` 和 `components/CloudPanel.vue`。测试：网关 `tests/test_cam_projects.py`，凸轮服务 `tests/test_projects.py`。
- 产品页由 `tools/site_cases/cam_page.py` 生成：`python3 tools/site_cases/build.py`。
