# 三维仿真视频使用说明（第 38 轮）

一句话要一段工程级三维仿真视频：机构怎么动、零件里面发生了什么，可以剖开、透视、慢放，带中英标注和读数。动作由程序算出（机械臂按逆运动学，缝纫机按虚拟样机的机构），不是手调的动画，读数可以写进课件和报告。

**负担在 AI：** 你说要什么，AI 写场景；你提意见，AI 改。AI 只用平台已有的模型，不凭空造形状。

## 一、谁能用

| 账号 | 怎样用 |
| --- | --- |
| 老师（能建课的账号） | 直接能用，左边菜单 **三维视频** |
| 企业客户 | 在官网“三维仿真视频”页点 **申请开通**；管理员开通后，左边菜单出现 **三维视频** |
| 学生 | 不能用（看不到菜单，接口也拒绝） |

收费：老师开课免费；其他用途按租用机器的时间收费，**11 月上线**。现在都不收费，平台只记下每次用了多少机器时间。

## 二、出一段视频

1. 左边菜单 **三维视频**。两种开始方式：
   - 在上面的框里写一句要求，点 **AI 写场景**，例如“讲清楚平缝机旋梭怎样钩住线环、在布里扣成线结，先整机再特写”；
   - 在 **从样片开始** 里挑一段，点 **照这个改**（复制一份给你改，原样片不变）。
2. 进入工作页：
   - 左边是和 AI 编导的对话；
   - 中间是出片区，有三个标签：关键画面、小样、高清；
   - 下面是时间线（每条标注在第几秒出现）。
3. **出关键画面**：6 张静帧，约 1–2 分钟，先看构图和镜头对不对。点图片可以放大。
4. 不满意就在左边 **提意见**，例如“镜头再近一点”“第 3 步慢一点”“这里加剖面”“标注改成……”，点 **按意见改**。AI 改完场景，再出关键画面看。
5. **出小样**（960×540，整段）：平台临时租一台渲染机器，约 6–10 分钟，其中开机约 3–5 分钟。可以离开页面，回来看进度（等机器 → 开机 → 准备环境 → 已渲染多少帧 → 合成）。
6. **出高清**（1920×1080，MP4 和 WebM）：约 15–30 分钟。出完点 **下载**。
7. 场景改过以后，旧的关键画面和视频会标“场景改过了，这一版是旧的”，需要时重出。

机器出完视频就自动关机。正在出的可以点 **取消出片**，机器马上关掉。

## 三、用到课里

- **白板课**：编辑白板课时点 **插入**，在“我的三维视频”里选（有高清用高清，没有就用小样）。
- **网页课件、其他地方**：下载 MP4 后上传。

## 四、高级：直接改场景文件

工作页下方点 **直接改场景文件（高级）**，改完点 **检查并保存**。平台会先检查：
- 只能用已有模型；
- 时间不能超出视频长度；
- 标注不能太长（中文 46 字以内，否则会出框）；
- 镜头关键点要写全。

不合格会列出哪里不对，不保存。格式见仓库 `tools/blender/场景格式.md`。

## 五、管理员

**三维视频** 页最下面是 **管理：开通账号与用机记录**：
- 填企业客户的账号名或邮箱（备注写公司名），点 **开通**；**取消开通** 后对方就看不到菜单了。
- 用机记录：每次出片用的机型、用时、花费，以及合计。

服务器上的设置（`.env`）：
- `VIDEO3D_LAMBDA_KEY`：Lambda 的 API 密钥。不填就用云端 GPU 实验的 `WQ_GPU_LAMBDA_KEY`。两个都没有时，只能出关键画面，页面上会提示。
- 同时最多开 2 台机器，一台最长 3 小时，没有空闲机器最多等 60 分钟。这些在网关设置里可改（`WQ_VIDEO3D_MAX_MACHINES` 等）。

## 六、它是怎么做的（给维护的人）

- **关键画面**：服务器上的 `blender` 容器（Blender 4.2 + 渲染器 + 平缝机虚拟样机网页）。这个容器没有密钥、不能上网，一次只出一个。
- **小样和高清**：网关在 Lambda 上租一台机器（按 `WQ_VIDEO3D_LAMBDA_TYPES` 的顺序挑有空的机型，默认先 A10）。经 JupyterLab 传上去渲染器包、场景文件和 `run.sh`，在后台运行。网关每 15 秒读一次进度，出完取回视频，然后关机。
- 每次开机都记在 `video3d.db` 的 `run` 表里。网关重启后，会接着跟进没出完的。
