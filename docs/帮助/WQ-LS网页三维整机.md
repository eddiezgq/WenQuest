# WQ-LS 网页三维整机（第 138 轮 G6.1）

问渠设计的工业直驱平缝机 WQ-LS，整台机器在网页上：98 个零件、每 2° 的真实运动、8 种变型。

## 在哪里打开

- **数字工厂**：地址 `/wqls/index.html`（不用登录）。“设计与工艺 → 本厂物料”里选问渠缝纫机厂的物料（如 LS-101、WQ-LS），卡片右上角点“在三维整机里看 ↗”，打开时已选中这个零件。设计案例“问渠工业直驱平缝机 WQ-LS”第 5 步也有链接。
- **教材**：《缝纫机设计与制造》第 27 章 27.3 节“三维模型 27-2”，点“在本页运行”；“互动资源”页也有。

## 怎么用

1. **转起来**：默认在慢慢转。“暂停 / 播放”，慢、中、快；拖滑块到任意转角。想亲手转：点“手轮”视角，在右端的手轮上按住拖。
2. **换状态**：压脚放下 / 手抬 / 膝抬；针距 3 mm / 5 mm / 倒缝 5；选项 T（自动剪线）、E（电子针距）、D（少油旋梭），左上角显示型号（如 WQ-LS-TED）。开了 T 才能看“剪线那一转”和“拨线”。
3. **看里面**：机壳“半透明”或“隐藏”；“剖开”选左右 / 前后 / 上下，拖滑块移动剖面，剖到的地方是橙色；“爆炸”滑块把各部件推开，配“按部件着色”更清楚。
4. **点零件**：右下角出卡片：物料号、自制还是外购、材料、质量；机壳有图纸 PDF；有计算书的点“计算书”跳到那一节。再点空白处或 × 关掉。
5. **中英文**：右上角切换。
6. **手机**：控制面板在下面，点“控制”展开 / 收起；单指转、双指缩放平移。

小技巧：地址后面加 `?part=LS-301` 直接选中旋梭，加 `?opt=TED` 打开旗舰型，加 `?fps=1` 显示帧率。

## 数据从哪里来、怎么更新

设计改了以后，按 `docs/设计/WQ-LS/G6/网页三维整机.md` 第一节重跑：建各状态整机 → `tools/wqls/render/web_tess.py` → `tools/wqls/g6_web.py <整机目录根> <机壳目录> factory/digital/web/public/wqls`，推送后数字工厂和教材一起更新。物料号在 `tools/wqls/part_codes.yaml`。
