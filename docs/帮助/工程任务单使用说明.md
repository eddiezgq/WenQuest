# 工程任务单使用说明（2026-10-02 起）

《机械制造技术》《机械设计》每章至少有一张**工程任务单**：学生扮演工艺员、设计工程师、质量工程师，在问渠数字工厂里完成一份真实的工程工作，交的是工程文件（工艺规程、计算书、工艺卡、检验记录），而不是习题答案。

## 一、任务单在哪里

- 教材正文里的绿色**任务卡片**（例如《机械制造技术》50.9 节的“任务 50.1”）：写明编号、角色、建议学时、经过的数字工厂工位（〔PLM〕发布与审批、〔ERP〕物料与工艺路线、〔MES〕派工、〔QMS〕检验、〔PY〕计算书……）、背景和交付物。
- 卡片上方三个下载链接：
  - **任务单（Word）**：背景与要求、输入资料及在哪里找、交付物与验收标准、工作步骤、AI 评审要点、评分；
  - **评分量规（Word）**：每个评分项的分值和满分标准，留有得分、评语栏；
  - **空白计算书（Word）**：公式、出处已经填好，代入和结果留空，学生照着填。

## 二、老师怎样用（2026-10-02 起，课程里一键下达）

1. **下达**：在学习平台课程左侧菜单点“任务单” → “从教材选任务单” → 选任务单、班级工厂、交期 → “下达”。平台自动在课程里建一项满分 100 的作业（进成绩簿），并把任务单发到该班级工厂。再下达一次同一张任务单 = 改交期。
2. **看进度**：同一页列出每个学生的状态（未提交 / 待审阅 / 修改中 / 已批准 / 已评分）、没关闭的 AI 意见数、AI 建议分和成绩。
3. **审阅**：点“审阅”进入数字工厂的审阅页：左边逐项看交付物（PDF 直接预览，模型链接到设计发布的三维审阅，分析链接到仿真与分析），右边是意见。AI 设计评审员的意见带“必改 / 建议”标记，学生逐条回复；老师看过回复后点“关闭”，也可以加自己的意见。
4. **批准或退回**：“必改”意见全部关闭后才能批准；有原则性问题点“退回修改”并写明原因，学生修改后重新提交（第二轮 AI 重新审）。批准时，任务里的设计发布、工艺规程一并生效（ERPNext 版本加一），之后学生下工单、车间加工、三坐标检验，检验结果出现在任务页。
5. **评分**：批准后在审阅页按评分量规逐项打分（AI 建议分按各项分值比例给出，只供参考），可写评语。
6. **成绩回传**：回到课程“任务单”页点“成绩回传”，已评分的成绩和各项分数、评语写进课程作业，成绩簿里就能看到；改分后再点一次即可。

## 三、学生怎样做

1. 在课程“任务单”里点“到数字工厂去做”（或在数字工厂左侧点“我的任务”），打开任务页：背景、交期、进度条（提交 → AI 评审 → 老师批准 → 加工 → 检验 → 评分），以及任务单、评分量规、空白计算书的下载链接。
2. 逐项交交付物：上传文件（按规定格式）；“设计发布”类上传 STEP 模型（可附图纸），进待审、任务批准时一起生效；“分析”类选自己在仿真与分析里算完的作业；“工艺规程”类选自己的工艺规程提交；“更改单”逐行填受影响的物料、改什么、理由。
3. 随时点“AI 预检”看意见（不记录）；都交齐后点“提交审批”。
4. 逐条回复评审意见（改了什么，或为什么不改）；被退回就改好后“重新提交”。
5. 批准后按任务单下工单、跟踪加工和检验；最后在任务页看分数和评语。

## 四、AI 评审员检查什么（工艺规程）

目前按规则检查：工序表是否完整、工序和工作中心是否存在且匹配；工序顺序（先粗后精、调质位置、热处理后磨削、键槽位置、检验在最后）；粗基准、精基准是否写明、是否统一；粗车和精车的公差是否超出经济精度，末道尺寸和粗糙度是否满足图纸；相邻工序余量的最小值是否大于零；切削功率是否超过机床功率；工时是否小于基本时间；是否附了计算书。

它**不**检查：每道工序所需的最小余量（式 50.6.3）、其他加工方法的经济精度、尺寸链计算、方案是否最优。这些由老师判断。评审员的意见是建议，不是批准。

## 五、《机械设计》的任务单（设计类）

以样章第 33 章的 **TS-33-1“WQR-105 输出轴 SH-301 改版”**为例（8 学时）：学生扮演设计部门的设计工程师，经过〔CAD〕〔FEA〕〔FAT〕〔PLM〕〔ERP〕〔CAM〕〔MES〕〔QMS〕八个工位：

1. 在 ERPNext 里核对 SH-301 的材料、工艺路线和检验模板；
2. 按装配顺序排结构，写出 A 版的评审意见，定 B 版各段尺寸；
3. 在空白计算书里写受力、四个截面的静强度和疲劳校核、刚度、临界转速（公式和出处已填好，台阶的应力集中系数要自己用有限元或图表换掉）；
4. 用 FreeCAD 或 build123d 建 B 版模型，在数字工厂“仿真与分析”里做有限元和疲劳寿命，下载 Word 报告；
5. 出零件图，连同计算书、报告、工程更改申请一起提交“设计发布与审批”；
6. 批准后跟踪键槽加工和三坐标检验，把检验结果和复盘写在计算书末尾。

设计类任务单的交付物是计算书、三维模型、分析报告、零件图和工程更改申请。评审要点写在任务单第五部分。

## 六、现状

- **已上线（2026-10-02）**：课程里下达与成绩回传、数字工厂“我的任务”与审阅页、AI 设计评审员（交付物齐全；计算书的结果、代入、出处和校核结论；更改单必列物料；STEP 模型的台阶圆角、轴承位长度、键槽同一母线；分析作业是否本人、算完、零件对；零件图上标注项“有没有”）。AI 设计评审员只用规则，不用模型。
- 工艺规程的网页界面由第 13 轮单独做；在此之前，“工艺规程”类交付物要先在后台接口提交，再在任务页选上。
- 小组方式还没有做，目前每张任务单按个人提交。
- 学习平台与数字工厂之间用“任务单钥匙”通信，部署时自动生成、复制；如果课程“任务单”页提示“还没有接上数字工厂”，等下一次学习平台部署完成即可。
