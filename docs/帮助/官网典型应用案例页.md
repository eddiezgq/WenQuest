# 官网典型应用案例页

网址：https://wenquestrobotics.com/cases/ （首页“数字化工厂”一节点“三个典型应用”）。

## 访客看到什么

三个应用，每个一页：协作机器人关节、SCARA 机器人、直驱平缝机。每页有：

1. 一句话问题和四个关键数字；右边是能拖动旋转的三维零件（可切换零件）。
2. 12 步流程条：设计院 6 步、数字工厂 6 步。点任意一步，下面显示这一步做了什么、得出的数、产出的文件（布局图、选型表、数控程序片段、工单表），以及对应的课和实验。绿色“通过”，黄色“待确认”（零件库缺数据，没有估值），灰色“不适用”。
3. 还没定下来的地方：演练里卡住的问题，可作课堂题目。
4. 这个案例用到的课（照实标“已上线 / 编写中 / 建设中”）、自己动手的实验、注册入口、成果文件链接。

右上角“EN / 中文”切换语言，与首页共用同一设置。

## 怎样更新

内容和数字都在 `tools/site_cases/cases.py`。改完运行：

```bash
python3 tools/site_cases/build.py
```

再提交 `site/cases/` 推送即上线。数字只能取自 freecad-ai-parts 仓库 `examples/apps/out/` 的演练结果；演练重跑后先核对再改。详细说明见 `tools/site_cases/README.md`。
