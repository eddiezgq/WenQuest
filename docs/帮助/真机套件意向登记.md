# 缝纫机真机套件意向登记（第 20 轮）

## 给访客

官网“课程”表里，《缝纫机设计与制造》这一行有“真机套件意向登记”的链接，地址是 `https://wenquestrobotics.com/kits.html`。页面有中英两版，右上角切换，不需要注册账号。

登记的内容：
- 想要的套件：A 机头拆装套件、A+ 开窗剖切展示机、B 整机、C 控制套件，可以多选；
- 机型；
- 能接受的价位；
- 用途；
- 国家或地区；
- 数量；
- 邮箱。

登记不是订单，不用付款。

## 给管理员

查看和导出登记：

1. 用管理员账号登录学习平台。
2. 打开“管理 → 课程包”。
3. 页面下方有“缝纫机真机套件意向登记”卡片，显示登记条数和各套件的累计套数。
4. 点“下载表格”，得到全部登记的表格（CSV，用 Excel 打开）。下载只能在网页端做，小程序里不行。

登记数据保存在服务器的 `data_dir/kit-interest.db` 里。有人写信要求删除时，找技术人员按邮箱删除对应记录。

## 防垃圾提交

- 同一网络地址每小时最多提交 8 条。
- 页面里有一个隐藏的输入框，机器人填了它，提交会被悄悄丢弃。
