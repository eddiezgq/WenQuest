# 官网首页

网址：https://wenquestrobotics.com/

## 结构

顶栏十项都能点开（手机上点“菜单”）：解决方案（学校与培训机构 / 企业 / 行业专用软件，第 33 轮）、关于我们、专业、课程、数字工厂、虚拟实验室、学习平台、教师与合作、招生与学费、捐赠；左上角“问渠”回首页，右边中英切换和登录 / 注册。

页面从上到下：首屏（双摆动画、三个按钮）→ 数字条 → 解决方案（学校与培训机构四张卡；企业：数字工厂集成平台通栏卡 + CAD、CAM、CAE、ERP、厂情中枢五张卡 + 行业专用软件：凸轮设计与制造、缝纫机设计与制造）→ 四个专业 → 一节课怎么上 → 课程地图（通识 / 基础 / 专业 / 特色四层，状态照实写）→ 数字工业园（案例、五座工厂）→ 虚拟实验室 → 学习平台 → 教师、学校与企业 → 招生与学费 → 关于我们（愿景使命、创办人、捐赠、联系）。

## 怎样改

不要直接改 `site/index.html`，它是生成的。改 `tools/site_home/template.html`（文字、版式）或 `tools/site_home/build.py`（课程地图的课程清单 TIERS），然后：

```bash
python3 tools/site_home/build.py
```

数字条（教材、章数、动画、实验、数字工厂实验）每次运行时从仓库重新统计，日期自动更新。提交 `site/index.html` 推送即上线。
