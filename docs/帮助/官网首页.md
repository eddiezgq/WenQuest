## 结构

顶栏第一项“全貌”（问渠全貌、视频、全部视频）；其余十项都能点开（手机上点“菜单”）：解决方案（学校与培训机构 / 企业 / 行业专用软件，第 33 轮）、关于我们、专业、课程、数字工厂、虚拟实验室、学习平台、教师与合作、招生与学费、捐赠；左上角“问渠”回首页，右边中英切换和登录 / 注册。

页面从上到下：首屏（双摆动画、三个按钮）→ 数字条 → **问渠全貌**（五组小卡，每样都能点开，第 80 轮）→ **看视频认识问渠**（白板科普最新 6 期、缝纫机课示范，第 80 轮）→ 解决方案（学校与培训机构四张卡；企业：数字工厂集成平台通栏卡 + CAD、CAM、CAE、ERP、厂情中枢五张卡 + 行业专用软件：凸轮设计与制造、缝纫机设计与制造）→ 四个专业 → 一节课怎么上 → 课程地图（通识 / 基础 / 专业 / 特色四层，状态照实写）→ 数字工业园（案例、五座工厂）→ 虚拟实验室 → 学习平台 → 教师、学校与企业 → 招生与学费 → 关于我们（愿景使命、创办人、捐赠、联系）。

## 怎样改

不要直接改 `site/index.html`，它是生成的。改 `tools/site_home/template.html`（文字、版式）或 `tools/site_home/build.py`（课程地图的课程清单 TIERS），然后：

```bash
python3 tools/site_home/build.py
```

数字条（教材、章数、动画、实验、数字工厂实验）每次运行时从仓库重新统计，日期自动更新。提交 `site/index.html` 推送即上线。

## 问渠全貌总图：加一样新东西（第 80 轮）

总图的内容只写在 `tools/site_home/catalog.yaml`：找到对应的组（学习平台与课程、内容制作软件、数字工业园、工程软件、虚拟实验室），照旁边的样子加一行：中英名称、中英一句话、网址，要登录的写 `login: true`。含英文逗号的文字要加引号。然后：

```bash
python3 tools/site_home/build.py
```

站内链接（以 `/` 开头）找不到文件时，这一步会报错停下。`learn.`、`factory.`、`demo.` 的链接要自己打开核对一次。

## 视频（第 80 轮）

- 首页和视频列表页 `/videos.html` 的视频都嵌 YouTube（点了画面才加载），有 B 站号的同时给 B 站链接。
- **只显示公开的视频**。工作流“Site videos 官网视频清单”每天读一次 YouTube 频道里的播放列表，写 `site/data/videos.json` 自动提交；要马上更新，到 GitHub → Actions → Site videos → Run workflow。
- 读哪几个播放列表、缝纫机课固定放哪几讲（“最典型”的），写在 `catalog.yaml` 的 `videos` 一节。白板科普的播放列表名是“问渠白板科普”“WenQuest Whiteboard Science”。
- 一期视频在 YouTube Studio 里设为公开后，第二天自动出现在首页；没有公开视频时，该栏显示“即将上线”。

## 入口检查（第 143 轮，2026-11-10）

每加一个产品或一座厂，确认两站首页都能点到：

- **美国站**：首页总图（`catalog.yaml`）、“解决方案 → 行业专用软件”一栏（`template.html`）、页脚“帮助”。现有入口：学习平台各主要页、数字工厂各页与工程软件、演示工厂、减速器厂 / 机器人厂 / 电路板厂 / 芯片厂 / 传感器厂 / 电机厂 / 缝纫机厂、问渠 ERP、问渠电子、凸轮、轴承（软件和产品介绍页）、虚拟实验、评价、校情、视频、案例、帮助目录。
- **国内站**：首页和教育服务页“已开通的单位直接进入”一组（`tools/site_cn/build.py` 的 `ENTRIES`）：学习平台、AI 建课、电子教材、白板课、三维仿真视频、缝纫机软件（要登录），凸轮、轴承（在线试用），问渠质量 ERP 演示；质量 ERP 页、缝纫机页的首屏也有入口。国内站只链本站子域名（`learn.`、`qms.`），不链美国域名，`check_cn.py` 会查。数字工厂国内部署后再加入口。
