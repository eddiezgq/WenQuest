# WQ-LS 设计说明书网页版（第 172 轮）

问渠工业直驱平缝机 WQ-LS 的全部设计文档放在一个网站上：G1 设计任务书 → G2 动力学与强度 → G3 外观与机壳 → G4 零件与机构 → G5 机壳工艺 → G6 网页三维 → G7 工程图与物料清单 → G8 整机补全与虚拟样机 → GC 控制器 → 企业标准。原文一字不删；文章里没引用的图、视频、工程图、数据文件，在每关最后的“附图与附件”里。

示例设计：经计算和三维校核，没有实物试制，数值是示例值。

## 在哪里打开

- **网址**：数字工厂 `https://factory.wenquestrobotics.com/wqls/spec/`，不用登录。
- **网页三维整机**（`/wqls/index.html`）左上角面板里点“设计说明书 ↗”。
- 数字工厂设计案例“问渠工业直驱平缝机 WQ-LS”第 5 步；教材《缝纫机设计与制造》第 27 章“三维模型 27-2”下面的“设计说明书 ↗”。

## 怎么看

1. **总目录**（左边）：按关排，点一篇打开；打开的这篇自动展开它的各节，点哪节跳到哪节；往下读时，读到的那一节自动高亮。
2. **本篇目录**（右边，宽屏才有）：这篇的全部小节，同样随滚动高亮。
3. **翻篇**：页底“上一篇 / 下一篇”；页顶路径“总览 › G4 零件与机构 › 旋梭组”点“总览”回首页；右下角 ↑ 回到顶部。
4. **搜索**：右上角输入词（按 `/` 直接到搜索框），列出所有篇里出现的段落，点结果跳到那一节；多个词用空格隔开表示都要有；Esc 清除。
5. **文件**：文章里写到的文件名（如 `G4/挑线机构.json`）是链接，点开看或下载；图点一下看原图；视频直接播放；工程图 PDF 在新窗口打开。
6. **手机**：左上角“☰ 目录”打开总目录，点一篇后自动收起。
7. **打印**：浏览器打印只打正文，不带目录。

## 怎么更新（给维护的人）

原文在仓库 `docs/设计/WQ-LS/`。改了里面任何文件，运行

    python3 tools/wqls/spec_web.py

重新生成 `factory/digital/web/public/wqls/spec/`，一起提交。没重新生成，数字工厂的测试 `test_wqls_spec.py` 会报红。推送后“数字工厂部署”自动上线。

新增文章放进某一关的文件夹就会出现在那一关；要排到指定位置，改 `spec_web.py` 顶上的 `GROUPS`。
