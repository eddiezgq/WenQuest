# 国内体验账号（自动开通）

给谁看：申请在线体验的单位联系人（第一部分）和管理员 Eddie（第二部分）。依据：《实施细则 · 第 96 轮》。

## 一、申请的人

1. 打开问渠科技官网，点右上角“注册”（或“预约演示”），勾选“申请在线体验账号”。
2. 填单位名称、姓名、手机、**邮箱**，点“获取验证码”，把邮箱收到的 6 位数字填进“邮箱验证码”。没收到请看垃圾邮件。
3. 勾选同意《隐私政策》，点“提交”。页面显示“在线体验已开通”，账号和初始密码发到你的邮箱，体验期 90 天。
4. 登录学习平台：账号填邮箱或手机号，密码填邮件里的初始密码。登录后尽快改密码。
5. **给同事开账号**：登录后点左上角头像 →“我的单位（给同事开账号）”→ 填同事的姓名、手机（邮箱选填）→“开通账号”。页面显示一次登录信息，点“复制”用微信发给同事。同事用手机号或邮箱登录。名额用完、要延长体验，联系问渠科技。
6. 在“我的单位”里还可以给同事“重设密码”“停用 / 恢复”。

**问渠质量 ERP**：申请时“想了解的产品”勾了“问渠质量 ERP”的，另外收到一封“问渠质量 ERP 体验账号”邮件。那是**多人共用的演示企业**（海港五金供应，数据是虚构的），每晚还原成演示数据，30 天到期，请不要录入真实数据；想用自己的数据试，回复那封邮件，我们开独立的试点企业（免费 3 个月，数据保留）。

如果页面显示“已收到，我们会在 2 个工作日内审核开通”，说明这次转人工了（例如这个单位、邮箱或手机号已经申请过，或当天自动开通名额已满），管理员会尽快处理。

## 二、管理员

- 学习平台“管理 → 体验单位”：自动开通的单位标“自动开通”。顶上一行“官网申请自动开通：开（每天最多 20 家）· 点此关闭”，出问题点一下就关，之后的申请回到人工审核；再点打开。
- 规则：同一单位名、同一邮箱、同一手机号只自动开通一次；每个网络地址每小时最多 2 家；每天最多 20 家（`.env` 的 `WQ_CN_AUTO_DAILY`）；总数受体验单位上限（`WQ_CN_MAX_ORGS`）限制；手机填座机的转人工。转人工的申请照样在“从官网的预约申请带入”里。
- **转成质量 ERP 试点**：单位卡片上点“转成质量 ERP 试点”，把试点邀请发到这家单位的邮箱（名称自动带上），对方按邮件开通独立的一套。试点名额见“试点企业”页。
- **设负责人**：管理员开的单位，在账号那一行点“设为负责人”，这个人登录后就有“我的单位”，可以自己给同事开账号（例如杰克科技的郑吉）。
- 自动开通的账号和管理员开的一样：可以建课、用 AI 功能（只用已备案的 DeepSeek，AI 生成内容标注“AI 生成”）。
- 邮件经阿里云邮件推送发出（`noreply@notice.wenquestech.online`）；新域名的信可能进垃圾箱，告诉对方看一下。
