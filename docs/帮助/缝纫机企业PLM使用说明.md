# 缝纫机企业 PLM 使用说明（第 109 轮：零件库与 BOM 版本）

PLM 是问渠质量 ERP 里的一个模块，管零件、零件的版本和 BOM（物料清单）。
企业清单里打开 `plm` 模块后，左边栏“工程设计”下会出现“零件”。国内演示企业（海港五金供应，虚构）已经打开。

已做好：**零件库与编码**、**BOM 版本**、**设计变更（ECN）**、**型号衍生配置**、**接设计数据**（FreeCAD 推送、STEP 和 Excel 导入），
**三维与爆炸图**、**配件手册**（第 124 轮），以及一家完整的**缝纫机演示企业**（见本文最后一节）。

## 谁能做什么

| 角色 | 能做的 |
|---|---|
| 老板 | 全部 |
| 工程设计（新角色） | 看、建零件、改设计中的内容、签字发布、设置编码规则 |
| 质量、运营经理 | 只能看 |
| 其他角色 | 看不到 PLM |

## 零件

1. **零件主数据就是 ERPNext 的物料**。在“零件”页点“新建零件”，填名称、类别、自制 / 外购、单位和这个类别的参数，
   点“新建”：系统发编码，同时在 ERPNext 里建物料（物料组“PLM”）。也可以填老编码；ERPNext 里已有这个物料时，要勾“ERPNext 里已有这个物料：关联它”，并且单位要和 ERPNext 里一致。
   物料建好后单位不能再改；改名称会同步到 ERPNext。
2. **编码**：每个类别一个前缀（电机 MOT、机针 NDL、旋梭 HOK、送布牙 FDG、轴 SFT……），后面是流水号，例如 `HOK-00001`。
   老板或工程设计角色可以在“零件编码规则”里改前缀和位数。
3. **查重**：同一类别里必填参数都一样（数值相差 1% 以内）的零件会先列出来，请先看能不能复用；确实是新零件再点“确实是新零件，新建”。
4. **类别和参数**沿用缝纫机设计软件“本单位零件库”的类别（电机、机针、针杆组件、轴套、同步带、带轮、连杆、机壳），
   另加旋梭、送布牙、轴、凸轮、轴承、紧固件、电子件、部件 / 整机、其他。带 * 的是必填参数。
5. **文件**：设计中的版本可以挂三维模型（STEP、FCStd、STL、IGES）、图纸（PDF、DXF、DWG、SVG）、图片，每个不超过 50 MB。
6. **发布**：必填参数齐全、ERPNext 里有物料，先“保存”，再输入自己的密码签字发布（有没保存的修改时不能发布）。**发布后这个版本锁定**，参数、说明、文件都不能再改。
7. **改已发布的零件**：先在“变更”里发起一张**产品**类变更并批准，再回到零件页选这张变更，点“新建版本”（A → B，跳过 I、O、Q）。
   新版本带着上一版的参数和文件，改好再签字发布，上一版变成“已被替代”。

## BOM

1. 自制件的零件页最下面有“建立 BOM”。外购件没有 BOM。
2. 在 BOM 页逐行填零件编码（输入编码或名称会提示）、数量、备注，点“保存”。单位跟零件走；数量最多 6 位小数。
3. **发布前检查**（缺数据的检查结果是“未知”，不算通过）：
   - 至少一行；
   - 所有子件都已发布；
   - 没有零件包含自己（A 用 B、B 又用 A）；
   - 每行都有数量和单位；
   - 外购件在“合格供应商”名录里有已批准的供应商（名录里没有这个零件 = 未知）；
   - 装配件本身在 ERPNext 里有物料。
4. 全部通过后输入密码签字发布。**系统在 ERPNext 里建一张 BOM 草稿**，要有人到 ERPNext 里打开并提交，
   提交后生产才按它来。BOM 页会显示它在 ERPNext 里是“草稿（待提交）”还是“已提交”。
5. **改已发布的 BOM**：同零件一样，选一张已批准的产品变更，点“新建 BOM 版本”；新版本带着上一版的明细，
   页面上列出“与版本 A 相比的变化”（新增、删除、改动的行）。
6. 零件页的“用在哪里”列出所有用到它的 BOM。

## 设计变更（ECN）

已发布的零件、BOM 要改，走质量模块的“变更”，类型选“产品”。开了 PLM 的企业，这种变更页上多一块“设计变更（PLM）”：

1. **改哪些零件**：输入编码或名称加零件，选“改零件 / 改 BOM / 零件和 BOM 都改”，自动带出现在的版本。
2. **生效方式**：立即、用完库存后、某日起（填日期）、某序列号起（填起始序列号）。
3. **分析影响**：程序列出每个零件用在哪些部件和整机（★ 是整机）、库存、在途采购单、未完工单、整机未发货订单。
   没有数据的写“未知”，不当成 0。零件清单改了要重新分析。
4. **AI 起草影响说明**：AI 只读这张分析表起草一段说明，放进“评估说明”，请读一遍、改好再保存；
   句子里有分析表里没有的数字会提示出来。没有 AI 时，分析表本身作为草稿放进去。
5. **提交**：除了变更原有的要求，还要有零件、生效方式和按现在零件清单做的分析。提交后这些都锁定。
   加过零件的人算这张变更的编辑人，不能自己批准。
6. **批准后**：零件页、BOM 页选这张变更新建版本（变更页每行有“去新建”）。只能给变更里列出的零件、按列出的“改什么”新建版本。
7. **标“已实施”**：每个零件按“改零件 / 改 BOM”在这张变更下出了新版本并已发布才行。
8. **从纠正措施发起**：纠正措施页右上角“发起设计变更”，新建一张挂着这条纠正措施的产品变更。

## 型号衍生配置

自制的“部件 / 整机”零件，BOM 发布后，零件页多一块“型号配置”：

1. **选项组和规则**：每组一个名称和代码（1–4 位字母或数字），组里每个选项一个名称和代码。
   每个选项可以“改 BOM”：加零件（填数量）、去掉零件、换零件（去掉 X 换成 Y，数量不填就和原来一样）。
   规则写“A 要求 B”或“A 和 B 不能同时选”（同一组的选项本来就只能选一个）。改完点“保存”。
2. **生成型号**：每组选一项，点“生成”。不符合规则会说明是哪一条。
   - 型号编码 = 基础机型编码 + 各组选项代码，例如 `ASM-00002-7S`；名称 = 基础机型名称 + 各选项名称；
   - 在 ERPNext 里建成普通物料；
   - 自动建一张 BOM 草稿 = 基础机型已发布的 BOM 加上各选项的改动，请看过后签字发布。
   - 同一组选择只生成一次，再选会打开已有的型号。
3. **型号矩阵**：列出已生成的型号、各组选了什么、BOM 版本和状态。
   “和配置表一致”不是“是”的，会列出差在哪里（例如基础 BOM 出了新版本、某个选项换了零件）。
   已生成的型号不会自动改，请走设计变更修改。

## 接设计数据（FreeCAD、STEP、Excel）

左边栏“工程设计 → 设计数据”是收件箱。三种来路都进这里，每送来一批是一张“待核对”的单子：

1. **FreeCAD 推送**：
   - 装“问渠 PLM”插件：把质量 ERP 仓库 `freecad/WenQuestPLM` 文件夹复制到 FreeCAD 的 Mod 目录，重启。装了缝纫机工作台的，工作台里也会多出这两个按钮。
   - 老板在质量 ERP“集成”页新建一把钥匙，勾“从 FreeCAD 把设计数据送进 PLM 收件箱（plm:send）”。
   - FreeCAD 里点“问渠 PLM 设置”，填质量 ERP 地址和钥匙；打开模型，点“推送到 PLM”。
   - 送出的内容：零件、部件（App::Part、装配），装配关系（链接装几次算几个），每个零件的 STEP；零件属性里有 PartNumber / Code / WQCode 就带上编码，设了材料就带材料和按密度算的质量。
2. **上传 STEP**：只读装配结构和零件名，不读几何；文件留在这批记录上。
3. **上传 Excel 旧 BOM**：表头写“父件编码、子件编码、数量”（平铺表），或“层级、编码、数量”（层级表，层级写 1、2、3 或 .2、..3 或 1.2.1）；有“名称、单位、自制/外购、类别”也写上。

**核对**：
- 页面顶上一行统计：共几行、对上已有零件几个、新零件几个（其中外购几个）、有下层零件的几个。行按装配层级缩进排列。
- 编码和已有零件一样的自动对上；名称相近的会提示“可能是”。
- 其他行是“新零件”，类别和自制 / 外购**已按文件或名称猜好**（文件里写了就用；有下层的是部件；否则看名称末尾，“上轴前轴套”是轴套；螺钉、轴承、电机、电子件、机针、旋梭、同步带默认外购）。请看一遍，不对的改掉。
- 行多时：上面可以按名称或编码搜、只看“新零件”或某一类；勾选多行，一次改类别或自制 / 外购，点“应用”。
- 编码在 ERPNext 里已有物料的，会提示；确实是同一个，勾“关联 ERPNext 物料”。
- 下面有零件的必须是自制部件。
- 它的 BOM 已发布的，要选一张列了它、已批准的设计变更。
- 改完点“保存”。下面列出所有还不能写入的原因（例如装配包含了自己、两行对上同一个零件），全部解决才能写入。

**写入（签字）**：
- 要么全部写成，要么一个都不写：任何一个零件或 BOM 建不成，整批保持“待核对”，并说明原因。
- 新零件建好，STEP 挂到设计中的版本上，有下层零件的建成 BOM 草稿。BOM 已是草稿的，替换明细。
- 然后在 ERPNext 建物料（旧 BOM 的单位如“个、支、根”ERPNext 里没有就先建上）。某个物料建不成，记在这批的历史里，到那个零件页点“重试”。
- 不发布任何东西，发布照前面的步骤签字。

**演示文件**：质量 ERP 仓库 `demo/plm/` 里有一台虚构的平缝机（WQ-8800D）：347 个零件、29 个部件、5 层。
`python demo/plm/lockstitch_bom.py` 写出 Excel 旧 BOM；`lockstitch_freecad.py` 在 FreeCAD 里搭出同样结构的模型，可以试“推送到 PLM”。

**不采用**：写原因，点“不采用”。

## 三维与爆炸图（第 124 轮）

1. **看三维**：零件页每个 STEP 文件旁有“三维”，点开能转动、缩放。BOM 页“三维”一块点“显示装配三维”，把下面有模型、有装配位置的零件按位置摆好；
   没模型或没位置的零件列在下面并写明原因。三维在你的浏览器里算，第一次打开要下载约 7 MB。
2. **装配位置从哪来**：FreeCAD 插件推送时一起送；上传 STEP 装配文件时从文件里读。没人送来的位置就空着，系统不猜。
3. **爆炸图**：BOM 页点“配件手册爆炸图”。每张 BOM 版本（一个部件）一页：
   - **用三维模型**：只摆这个部件直接下面的零件，子部件当一整块（它有自己的一页）。拖“拉开程度”自动拉开；点一个零件后按 ±X / ±Y / ±Z 微调；
     “居中显示”；“放气泡”自动在零件旁放带引线的序号，再拖到合适的地方。
   - **用图纸**：没有三维的部件上传 PNG / JPG（PDF 请先存成图片），在右边表里点一行，再在图上点零件，放它的序号。
   - 标准件（螺钉、垫圈等紧固件）默认只进表、不画，右边“画出”可逐个改。
   - 点“保存”：存下设置和一张带序号的图，这张图就是配件手册里的那一页。BOM 出新版本时，爆炸图从上一版的设置开始，再调。
4. **英文名**：右边表里每个零件可以填英文名并“确认”；“AI 起草英文名”一次给整个部件树里还没英文名的零件起草（国内用已备案模型），
   **草稿要人逐个确认**，没确认的进手册时显示中文名、标“英文名待确认”。

## 配件手册（第 124 轮）

1. **在哪里**：整机或部件的零件页（自制、有 BOM）多一块“配件手册”。上面先列出挡住生成的东西：哪几张 BOM 还没发布、哪几页还没有爆炸图、
   几个英文名没确认，点名字直接过去补。
2. **生成**：点“生成新的一版”。整棵 BOM 树里每个部件一节（先整机，再按 BOM 顺序往下），用到两次的部件只占一节；
   每节上面是爆炸图，下面是零件表（序号、编码、中文名、英文名、数量；子部件写“见第 N 节”）。
   **生成后这一版就定格了**，以后 BOM 再改，这一版不变；要再点一次“生成新的一版”，新版会列出与上一版相比新增、去掉、数量改了的零件。
3. **PDF**：版次表里点“PDF”，A4 横向：封面和目录、与上一版相比、各节。点“第 N 版”看公司内部的手册页，每节有“爆炸图与三维”可以点进去转三维。
4. **给经销商的链接**（要有发布权限）：写上给谁，点“生成链接”。**网址只显示这一次，请马上复制**发给经销商。
   经销商不用登录，手机上也能看：最新一版的目录、各节的图和表、下载 PDF，中英对照；**看不到三维模型和任何设计文件**。
   表里能看到每个链接打开了几次、最后一次什么时候；点“作废”后对方打开会看到“这个链接已作废，请联系制造商”。

## 缝纫机演示企业：蓝湾缝纫机械（演示）

一家虚构的缝纫机厂，单独装在国内服务器上，网址 **https://sewing.qms.wenquestech.online** ，每晚还原。演示数据（零件、BOM、三维、手册等）有改动时，部署会把蓝湾清空重装一次，期间约 20 分钟打不开；体验账号和老板密码都保留。

**怎么进**：官网申请体验、勾“问渠质量 ERP”，开通邮件里有两个工作台：海港五金（五金批发）和蓝湾缝纫机械，同一个账号和初始密码，
两边各自改密码。在蓝湾，体验账号是“工程设计 + 质量”，能自己走设计变更。

**里面有什么**：
- 两条产品线：平缝机 WQ-8800D（347 个零件、5 层 BOM）、包缝机 WQ-737（221 个零件），螺钉、轴承等标准件和机架、线架部件两台机共用；
  全部零件和 BOM 已发布，ERPNext 里有生产 BOM。
- 型号配置：平缝机按针距（5 / 7 mm）、剪线（自动 / 无）、抬压脚（自动 / 膝控）配出 4 个型号；包缝机四线、五线 2 个型号。
- 约 90 天的业务：期初库存、旋梭采购和来料检验（梭尖硬度）、18 张完工的工单、给 8 家经销商的订单和发货；还有 2 张没开工的工单、
  3 张没发货的订单、2 张在途的旋梭采购单。
- 已经走完的设计变更：针板 A → B（针孔倒角加大）。设计数据收件箱里有一批待核对的 FreeCAD 推送（绕线器座改铝压铸）。
- **现成的配件手册**：型号 `WQ88-0000-5TA` 的第 1 版（29 节）。上轴、挑线、针杆、下轴、旋梭、送布 6 节是问渠缝纫机设计软件生成的机构三维拉开的爆炸图；其余部件没有三维，用的是标明“示意图（演示）”的方块图。英文名全部由人写好、确认。演示里没有现成的经销商链接（网址只显示一次），请自己生成一个，用手机打开看看，再作废试试。

**演示故事**（预先放到“CAPA 已开、原因写好”，后面自己走）：
1. 旋梭供应商来函换了梭尖材料，变更记录只看了材质证明和一批常规抽检就关了；换料后的批次梭尖硬度 58.3–58.9 HRC（以前约 60.6），
   在规格内但接近下限。
2. 两家经销商投诉断线 → 质量开了 CAPA，原因写好了。
3. **你来做**：打开“质量 → 纠正措施 → CAPA-00001”，点右上角“发起设计变更” → 在变更页的“设计变更（PLM）”加旋梭 `WQ88-1711`（改零件），
   生效方式选“用完库存后” → 点“分析影响”：用在 4 个平缝机型号（包缝机不用旋梭，所以不在里面）、库存 120 件、在途 2 张采购单、
   2 张未完工单、3 张未发货订单 → 可以点“AI 起草影响说明” → 填好评估、提交。
4. 批准要另一个人（编辑过的人不能批，这是规矩）：体验时请找同事用另一个体验账号批准。批准后回旋梭零件页“新建版本”出 B 版、签字发布，
   回变更页标“已实施”，再回 CAPA 加措施、标完成，进入“有效性验证”。
