# 零件与机器人库（第一期）

课程和数字工厂共用的零件、机器人三维模型库。第一期先把现成的放上来：标准件、开源机器人，以及 FreeCAD 零件库的索引。自建的机器人、机构与案例、二维图、AI 选型放在第二期（数字工厂第 2 轮 L13）。

## 一、在哪里看

打开 https://factory.wenquestrobotics.com，用问渠账号登录，左栏“资源 → 零件与机器人库”。

| 标签 | 内容 | 下载 |
|---|---|---|
| A 标准件 | 螺栓、螺钉、螺母、平垫圈、弹簧垫圈、平键、圆锥销、挡圈、O 形圈、骨架油封、螺塞、深沟球/角接触/圆柱滚子/圆锥滚子轴承（15 个族、900 多个规格，尺寸按国标、DIN 和 bd_warehouse 自带尺寸表；每族的出处在“来源”页） | 当前规格的 glTF；整族的 STEP、STL 压缩包 |
| B 机器人 | MuJoCo Menagerie 里许可合格的机器人 68 台：机械臂、夹爪、四足、人形、移动机器人、无人机等 | glTF（按连杆分节点）；原始 MJCF 模型链接到原仓库固定版本 |
| D 机器人零部件 | 厂商目录：谐波减速器（Harmonic Drive CSF，试做），以后陆续加电机、驱动器、传感器、夹爪等。参数照厂商样本录入，每行注明出处；三维是按样本外形尺寸生成的示意外形（页面黄色提示），厂商 CAD 请到厂商网站下载 | 示意外形的 glTF、STEP、STL |
| FreeCAD 零件库 | 约 2 900 个机械、电子、电气、气动零件的索引和缩略图 | 点击后从 FreeCAD 原仓库下载 FCStd、STEP、STL；使用时须按 CC BY 3.0 署名 |

**怎么用**

- **检索**：输入名称、编号、标准号、规格或工厂物料号，比如 `6207`、`GB/T 1096`、`M8x25`、`UR5e`、`BRG-6207`。输入的恰好是某个规格时，详情直接打开这个规格。
- **筛选**：类别、来源；勾“WQR-105 用到”只显示减速器用到的标准件。
- **厂商参数**：Universal Robots 的 6 个型号有“参数”页（官方技术参数、DH 参数、出处）。UR5e、UR10e 用开源的可动模型，其余按 DH 参数生成示意模型（关节位置和连杆长度准确，外形简化）。
- **自建机器人**：SCARA、Delta 并联机器人、差速小车（问渠自建，参数化）。SCARA 和小车可下载 URDF；Delta 是闭链，拖单个关节不能保持闭合，点“播放运动”看动平台走一圈，也可下载运动表（CSV）。
- **详情**：三维模型可拖动旋转、滚轮缩放。标准件点规格表的一行换规格；机器人拖关节滑块看运动；“零位”复位，有初始姿态的（如人形、四足的站立姿态）可点“初始姿态”。“来源”页有原仓库、许可和署名。
- **复制编号**：课件、作业里引用零件时用编号，比如 `A-BRG-DG/6207`。
- **从 ERPNext 过来**：减速器的标准外购件（轴承、键、螺栓、垫圈、销、油封、螺塞等）在 ERPNext 物料页上有“零件库编号”和“零件库页面”，点链接直接打开这个规格。

## 二、怎么更新（给维护者）

零件库的程序和条目在仓库 `library/`，模型文件不进仓库，由 GitHub 自动生成。

1. 改 `library/` 下的条目或程序，本地跑 `python3 library/tools/validate.py` 和 `cd library && python3 -m pytest -q tests`。
2. 推送到 main。工作流“Parts library 零件库发布”会依次：取来源仓库固定版本 → 校验 → 测试 → 生成全部模型（约 20～30 分钟）→ 发布到 GitHub Releases（`library-v年.月.序号`）→ 解包到数字工厂服务器。
3. 发布完成后，工作台页面自动读新版本（`https://factory.wenquestrobotics.com/library/latest.json`）。服务器保留最近 3 个版本。

**更换来源版本**：改 `library/vendor/menagerie.yaml` 或 `library/vendor/freecad_library.yaml` 里的 `commit`；Menagerie 换版本后运行 `python3 library/tools/import_menagerie.py` 重新生成机器人条目，看许可有无变化。

**本地生成**（需要先把两个来源仓库克隆到 `library/vendor_src/`，或用环境变量 `WQ_MENAGERIE`、`WQ_FCLIB` 指向它们）：

```bash
pip install -r library/requirements.txt
python3 library/tools/build.py --only A-BRG-DG --limit 5   # 只试一个族的 5 个规格
python3 library/tools/build.py --version 2026.10.0         # 全部，输出在 library/build/
```

## 三、给学习平台（接口）

- 库地址 `WQ_LIBRARY_URL` 第一期为 `https://factory.wenquestrobotics.com`，文件都在 `/library/` 下，允许 `learn.`、`factory.` 和本机开发地址跨域读取（GET、HEAD）。
- `library/latest.json`：当前版本和 `index.json` 的位置（不缓存）。
- `library/<版本>/index.json`：每个规格一行（编号、名称、类别、标准、主参数、许可、工厂物料号、文件）；`collections` 列出只收索引的外部库（FreeCAD 零件库，文件 `freecad-library.json`）；`categories` 是类别代号的中英文名称。
- `library/<版本>/<条目>/entry.json`：条目全部信息、每个规格的参数和文件；机器人另有 `robot`（连杆、关节表，约定 R4）。
- 带版本号的文件内容不再改变，可长期缓存。格式细节见《docs/方案/数字工厂资源接口约定》第二节。
