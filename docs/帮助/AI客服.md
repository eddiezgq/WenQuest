# AI 客服（问问问渠）

官网、视频页、评价与校情演示页、帮助网页的右下角有一个 **💬 问问问渠**（英文页面是 **Ask WenQuest**）按钮。点开就能问：某个模块是什么、怎么用、在哪里打开、要不要登录。不用登录。

## 它怎么回答

- **只按问渠的使用说明回答**：知识来自 `docs/帮助/` 里的使用说明、首页清单和国内版官网文字稿。每个回答下面列出 **出处**，点开就是那篇使用说明。
- **两档**：
  - **检索档**（两站都有，免费）：从使用说明里找出最相关的几段，显示摘要和出处，标“非 AI 生成”。
  - **AI 档**（美国站）：找出资料后，由模型只依据这几段组织成简短回答，标“AI 生成”。每天有调用次数上限，超了自动改用检索档。
- 资料里没有的，客服会说“这个我不确定”，并给出“联系我们 / 预约演示”的链接。
- 不报价格（请预约演示）、不承诺使用说明里没写的功能、不会要身份证号等个人信息。
- 每个网络地址每小时最多问 20 个问题。

## 国内站（问渠科技）

- 现在只用 **检索档**：从使用说明里找出相关段落给你看，不调用大模型。
- 网信办的生成式 AI 服务登记办好、`.env` 里填了 `WQ_AI_REG` 之后，国内站自动开 AI 档，只用已备案的 DeepSeek。
- 国内站只用不含国内版官网禁用词的段落，出处只显示标题（帮助网页暂不上国内站）。

## 管理员：看大家问了什么、补资料

- 记录只存时间、问题、所在页面、档位、有没有答上，**不存网络地址**，只看最近 30 天。
- 登录后打开 `/api/v1/admin/assist-log?missed=1`，列出没答上的问题。把这些问题的答案补进 `docs/帮助/` 里对应的使用说明，客服就会答了。

## 维护的人：资料改了怎么让客服跟着改

1. 改 `docs/帮助/` 里的使用说明（部署、运维、开发类的不进客服，名单在 `tools/assistant/build_kb.py` 的 `EXCLUDE`）。
2. 跑 `python3 tools/assistant/build_kb.py`：重新生成知识库 `services/gateway/app/assist_kb.json` 和帮助网页 `site/help/`。
3. 跑考题：`cd services/gateway && python -m pytest -q tests/test_assist.py`。考题在 `tests/data/assist_questions.yaml`（60 道，中英），要求正确的资料排在前 3 条的比例不低于 90%。
4. 推送、部署。

- 每天 AI 档调用次数上限：服务器 `.env` 里的 `WQ_ASSIST_AI_DAILY`（默认 300）。
- 别的页面要挂客服，在页面末尾加一行：`<script src="/assist.js" defer></script>`。
