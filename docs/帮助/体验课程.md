# 体验课程

给谁看：管理员（第一部分）和来体验的老师、企业的人（第二部分）。依据：《实施细则 · 第 117 轮》。

## 一、管理员：一键发布

1. 用管理员账号登录学习平台 → “管理” → “课程包”。
2. 列表里有现成课程包（《数字工厂实训》《缝纫机设计与制造》）和每本教材的“体验课”（《机器人学》· 体验课 等，按服务器上已部署的教材自动出现）。
3. 点顶上的“全部发布”，确认。一本接一本发，要几分钟到十几分钟，可以离开这一页；回来能看到每门课的进度。已经发布的跳过；中途出错的，那一门显示原因，再点“全部发布”从断的地方接着发。
4. 发布后这些课程在“课程目录”里标“免费”，登录的人都能点“免费加入”。
5. 教材写了新的章节：再点一次“全部发布”。整章原来没写的会换成完整的一节；链接打开的永远是最新的教材内容。
6. 国内、美国两个平台各点一次。

## 二、老师和企业：怎么看

1. 登录学习平台 → 左边“目录” → 找“体验课”或现成课程 → “免费加入”。
2. 课程第 1 个单元是课程说明；之后每章一个单元，里面有：本章导读、网页版教材、互动课件（有的章才有）、虚拟实验。
3. 体验课**不设作业、考试，不计成绩**，只供体验；内容随教材持续更新，标“编写中”的小节写好后会补上。
4. 本章 PDF 在网页版教材页上下载。
