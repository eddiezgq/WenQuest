# PLC 实验台使用说明（《PLC 原理及实践》各章实验 · 第 18 轮）

PLC 实验台是网页里的一台虚拟 PLC，接着一台虚拟设备（输送线、电动机、电梯、计件输送线……）。学生在网页上写程序、下载、运行、测试。不用装软件，也不用真设备。

## 页面上有什么

- **程序**：写程序的地方。
  - 可选的语言：结构化文本 ST、梯形图 LD、顺序功能图 SFC、功能块图 FBD。每个实验开放哪几种，由实验决定。
  - 按钮：
    - **编译并下载**：每次改完程序都要按，错误会标在对应的行上。
    - **看等价的 ST**、**导出 PLCopen XML**：查看和导出程序。
    - **恢复初始程序**：回到实验给的起始程序。
- **I/O 与监视**：列出每个输入、输出的名称、地址、当前值，以及实验指定要监视的变量。
- **时序图**：最近几秒的输入、输出、变量随时间的变化。
- **测试**：
  - **运行全部测试**：自动操作设备，检查程序对不对。
  - **程序检查**：找出双线圈之类的常见错误。
- **操作面板**：设备上的按钮、开关。有的实验还有“故障”按钮，用来注入传感器损坏、触点熔焊等故障。
- **运行控制**：运行、停止、**单步扫描**（一次只执行一次扫描）、**慢放 ×0.1**、**断电再上电**。

## 状态栏

状态栏显示 PLC 的状态，可能是以下几种：

- 未下载
- 运行 RUN
- 停止 STOP
- 故障 STOP

此外还显示已经扫描的次数和扫描周期。

第 4 章起，有的实验按程序实际执行的语句数计算每次扫描的时间：

- 每次扫描的时间 = 固定开销 + 每条语句的时间。
- PLC 自由循环：一次扫描结束，马上开始下一次。
- 状态栏还会显示本次扫描时间、最长扫描时间，以及超时次数（固定循环时）。
- 程序越长，扫描越慢。
- 一次扫描超过实验规定的最大循环时间（如 150 ms），看门狗就让 PLC 停机，状态栏显示“故障 STOP”和原因。要先改程序、再下载，PLC 才能重新运行。

## 常见问题

- **按钮按了没反应**：先看状态栏是不是“运行 RUN”；程序改过以后要重新“编译并下载”。
- **数字和书上不完全一样**：虚拟设备里有随机因素，比如接触器的电弧时间、工件到达的时刻。用“运行全部测试”判断程序对不对，不用一个个去比数字。
- **PLC 自己停了**：看状态栏的提示。常见原因：
  - 循环没有结束（一次扫描执行了太多步）；
  - 扫描时间超过了最大循环时间。
  
  PLC 程序里不能原地“等”一个输入，见教材 4.3.3 节和第 10 章。
