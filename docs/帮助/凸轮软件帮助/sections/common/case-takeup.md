### 问题

平缝机挑线槽凸轮（示例，虚构）：摆动从动件、滚子半径 {{tk.rr}} mm、基圆半径 {{tk.rb}} mm、中心距 {{tk.a}} mm、摆杆长 {{tk.L}} mm，{{tk.rpm}} r/min。运动程序：升（修正正弦）—停—回（4-5-6-7 次多项式）—停。

::try{label="打开这个示例" example=sewing-takeup-groove}

### 第一步：校核

{{tk.n_checks}} 项里关键的几项：

| 项 | 结果 |
|---|---|
| 推程 / 回程最大压力角 | {{tk.phi_r}}° / {{tk.phi_b}}°（示例许用 {{tk.phi_lim}}°） |
| 实际廓线最小曲率半径 | {{tk.rho}} mm（滚子 {{tk.rr}} mm，不根切） |
| 滚子换侧次数 | 每转 {{tk.flank}} 次（槽凸轮形封闭，接触力换向处在槽间隙里有冲击） |
| 最大接触应力 | {{tk.stress}} MPa——没填许用值，所以是“未知” |
| 凸轮轴峰值力矩 | {{tk.torque}} N·m |

压力角离许用值还很远。“求最小基圆”给出 **{{tk.rb_min}} mm** 就够（卡在推程压力角）——基圆还可以缩，凸轮能做得更小更轻；用多大由企业结合结构定。

### 第二步：磨削程序

顶部 **制造**，选磨削 X–C，砂轮半径取 {{tk.rr}} mm（与滚子一样大，一刀同时磨出槽的两侧），弦高公差 1 µm：

- **不过切**：凹处曲率半径 {{tk.gouge}} mm 大于砂轮半径；
- **程序仿真偏差**：软件把导出的程序读回来让砂轮扫过毛坯，和设计廓线比，最大 {{tk.sim}} µm（限 {{tk.sim_lim}} µm）；
- 程序 {{tk.pts}} 个点，凸轮转一圈约 {{tk.turn}} s。

### 第三步：测量与补偿

顶部 **测量与补偿**，点“载入合成测量数据（演示）”——软件按设计升程加上已知误差造出来的，只作演示。勾“自动对相位”，填示例许用加速度误差 {{tk.acc_lim}} rad/s²（虚构），点“分析”：

- 测量零位与零件差 **{{tk.shift}}°**（合成数据里放的就是 1.5°）；
- 误差引起的最大加速度误差 **{{tk.acc}} rad/s²**，超过许用值；按这个误差，最高只能跑约 **{{tk.rpm_max}} r/min**；
- 选 1–6 阶补偿，点“生成补偿程序”：误差均方根从 **{{tk.rms0}}** 降到 **{{tk.rms1}}** µrad（剩下的是没选的高阶和噪声），下载补偿后的程序。
