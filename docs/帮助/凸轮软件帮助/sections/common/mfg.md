### 制造

- 加工方式：**磨削 X–C**（凸轮随 C 轴转、砂轮沿 X 进退）、**铣削 XY**、**慢走丝**（只出 DXF 和点表）。填刀具半径和弦高公差；槽凸轮刀具不能大于滚子，等于时一刀磨出两侧。
- 校核：**不过切**（凹处曲率半径大于刀具半径）；**X–C 能走**（刀心轨迹对凸轮中心是“星形”）；**程序仿真偏差**（程序读回来让刀具扫过毛坯，和设计廓线比，不超过弦高公差 + 0.1 µm 为合格——说明程序没问题，零件公差由企业定）。
- 下载：加工程序 .nc、廓线 .dxf、点表 .csv（每 0.5° 一行）、三维 .step（B 样条拟合偏差一般在 0.01 µm 量级）。
- **砂轮修整后没更新半径**：填实际半径，点“算误差”，看用旧半径的程序磨出来差多少。
- 圆柱凸轮用四轴（A 转凸轮、X 沿轴线）：刀具与滚子同样大时一刀成槽，小一号时两侧各走一刀；程序读回扫槽，与精确槽侧面比法向偏差。

### 测量与补偿（盘形凸轮）

- 数据：升程表（转角, 升程）或廓线 XY 点；没有数据时“载入合成测量数据（演示）”。
- 自动对相位：零位没和键槽、销孔对准时勾上；对准了就别勾，结果更准。
- 结果：相位差、基圆 / 零点误差、误差曲线、谐波（红 = 1 阶偏心和装夹，黄 = 低阶热处理变形，蓝 = 高阶机床和颤振）、误差引起的加速度误差和“这样的误差最高能跑多少转”。
- **补偿**：选要修的阶次，软件把这些阶次的误差反向加到运动程序上，按“制造”里的刀具和机床重新出程序，并预测剩下的误差。
