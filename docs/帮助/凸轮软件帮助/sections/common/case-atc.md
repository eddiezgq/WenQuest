### 问题

加工中心凸轮式换刀机构（示例，虚构）：凸轮轴 {{atc.rpm}} r/min，经 {{atc.ratio}}:1 减速由电机带动。弧面分度凸轮：停—转 65°—停—转 180°—停—回 65°；槽凸轮 + 摆杆：在换刀臂停着时下拔、上插。

::try{label="打开这个示例" example=atc-globoidal}

### 第一步：时序与联锁

“系统设计”页中间是时序图：凸轮轴转一圈，两个凸轮各在什么位置，阴影是运动段。联锁校核：**一个动时另一个必须停着**，两条都合格。一次换刀循环（起动到制动停住）{{atc.cycle}} s。

### 第二步：电机与振动

| 项 | 结果 |
|---|---|
| 电机峰值转矩 | {{atc.peak}} N·m |
| 电机均方根转矩（一次换刀） | {{atc.rms}} N·m |
| 凸轮轴峰值功率 | {{atc.power}} W |
| 停歇时换刀臂端部残余振动 | {{atc.vib_i}} µm |
| 停歇时拔插刀端部残余振动 | {{atc.vib_p}} µm |

电机额定值没填（照样本填），所以电机几项是“未知”；残余振动没给允许值，也是“未知”。

### 第三步：设计搜索——换运动规律

“设计搜索”把每种运动规律都试一遍（两个凸轮一起换）：

{{atc.opt_table}}

振动最小的几种规律都让弧面凸轮的压力角超了；在全部合格的里面，软件选 **{{atc.best}}**（示例本来用的就是它）。给了允许振动、电机额定值时，还会求满足它们的最高转速。点“采用”换上那种规律。

### 第四步：CAE

“CAE 分析”页：换刀臂有限元（{{atc.el}} 个单元）最大应力 {{atc.vm}} MPa、安全系数 {{atc.sf}}；换刀臂本身（孔固定）一阶固有频率 {{atc.f1}} Hz；还有疲劳寿命和整机多体动力学（MuJoCo）与解析结果的对照。示例结果是 {{atc.cae_date}} 用数字工厂计算服务同一套程序算的；提交新计算要企业账号。
