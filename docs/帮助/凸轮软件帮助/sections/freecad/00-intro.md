---
问渠凸轮工作台用与网页版同一个计算核心：打开网页版“保存为文件”存下的项目，重算校核（结果逐项相同，摘要在“报告视图”里），建出零件——盘形与槽凸轮、圆柱凸轮（槽侧面按啮合方程拟合，偏差 ≤ 0.25 µm）、弧面分度凸轮的精确实体、换刀臂；凸轮系统按时序装配，改属性 Angle（凸轮轴转角）看动作；导出 STEP、加工程序、点表和 A3 工作图。

| | FreeCAD 工作台（本帮助） | 网页版 |
|---|---|---|
| 在哪用 | 本机 FreeCAD 1.1 | 浏览器 |
| 适合 | 精确实体、装配、工作图、在 CAD 里接着设计 | 设计与校核、制造程序、测量与补偿、系统设计、CAE、AI |

**第一次用？** 先装好工作台（下一节），再打开[典型案例](#cases)里任意一个示例项目。
