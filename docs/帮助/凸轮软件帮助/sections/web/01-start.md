### 打开

- 官网“解决方案 → 行业专用软件 → 凸轮设计与制造”，点“在线使用”；或直接打开 `/cam/`。
- 不登录也能用。项目自动存在你自己的浏览器里，也可以“保存为文件”带走。右上角“？帮助”打开本帮助对应的一节。

### 从头设计一个凸轮

<ol class="steps">
<li><b>新建</b>：选盘形凸轮或圆柱凸轮。</li>
<li><b>运动程序</b>：一行一段，升 / 停 / 回，填转角和行程，选运动规律；合计 360° 变绿才算对。不想用公式的，用点表。</li>
<li><b>机构</b>：从动件（直动 / 摆动）、接触（滚子 / 平底）、基圆半径、滚子半径、中心距、摆杆长、接触宽度；勾“槽凸轮”就是形封闭。</li>
<li><b>载荷与材料</b>、<b>校核限值</b>：转速、质量或转动惯量、弹簧、工作载荷、材料；许用压力角、许用接触应力。软件不替你编许用值，没填的是“未知”。</li>
<li>中间看凸轮转（可以拖曲线选转角），右边看校核；压力角或根切不合格时，“机构”页点 <b>求最小基圆</b>。</li>
</ol>
