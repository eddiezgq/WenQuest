问渠凸轮把凸轮机构的设计、校核和制造做成了工程工具：拼出一圈的运动程序，选机构尺寸，软件算出压力角、曲率、接触应力、跳离转速、凸轮轴转矩，逐项判合格、不合格或“未知”；再出磨削或铣削程序、廓线 DXF、STEP，把测量数据贴进来分析误差、生成补偿程序。几个凸轮装在一根轴上时，按凸轮系统算时序、联锁、电机转矩和残余振动。

| | 网页版（本帮助） | FreeCAD 工作台 |
|---|---|---|
| 在哪用 | 浏览器打开就用，不登录也能算 | 装进 FreeCAD 1.1，在本机算 |
| 适合 | 设计、制造程序、测量与补偿、凸轮系统、CAE、云端项目、AI 起草 | 精确实体（含弧面凸轮、圆柱凸轮）、装配、工作图 |
| 计算核心 | 同一份 | 同一份——同一个项目文件，两边校核逐项相同 |

**第一次用？从案例开始**：[典型案例](#cases)里有两个，从实际问题一步一步做到出程序。

能做的凸轮：

| 类型 | 能做的 |
|---|---|
| 盘形凸轮（外廓、槽凸轮） | 直动或摆动从动件、滚子或平底；{{n_laws}} 种运动规律或点表；压力角、根切、曲率、接触应力、跳离、滚子换侧；求最小基圆 |
| 圆柱凸轮 | 直动或摆动、圆柱或锥形滚子；槽展开图；四轴加工程序 |
| 凸轮系统 | 一根凸轮轴上几个凸轮：时序、联锁、电机转矩、停歇残余振动、设计搜索；弧面分度凸轮；换刀臂 CAE |
| 制造 | 磨削 X–C、铣削 XY、慢走丝；程序读回仿真；砂轮半径误差 |
| 测量与补偿 | 升程表或廓线点；对相位、谐波分析、加速度误差；按阶次补偿出新程序 |
