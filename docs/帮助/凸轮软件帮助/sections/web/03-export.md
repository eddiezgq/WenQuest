| 文件 | 在哪 | 说明 |
|---|---|---|
| 计算书 | 顶部 **计算书** → 打印 / 存 PDF | 输入、运动程序（含 Cv、Ca）、校核、曲线、廓线；做过制造、测量的再加两节 |
| 项目 .json | **保存为文件** / **打开文件** | 网页版和 FreeCAD 工作台互通 |
| 加工程序 .nc | **制造** | 磨削 X–C、铣削 XY；补偿后的程序在“测量与补偿” |
| 廓线 .dxf、点表 .csv、三维 .step | **制造** | 外廓凸轮厚度取接触宽度；槽凸轮另填毛坯半径和盘厚 |
| 弧面凸轮 STL、四轴程序、换刀臂 STEP | 凸轮系统 **三维与制造** | — |
| FreeCAD 工作台 .zip | **制造** 或 **三维与制造** 页的“下载” | 见 FreeCAD 版帮助 |
