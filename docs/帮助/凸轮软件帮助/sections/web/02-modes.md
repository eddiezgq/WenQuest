### 设计页

左边按页签填运动程序、机构、载荷与材料、校核限值；中间凸轮转动（红线是接触点法线，蓝虚线是从动件运动方向，夹角就是压力角），下面是位移、速度、加速度、压力角、曲率曲线，点或拖曲线凸轮跟着转；右边校核。

### 校核项

| 校核 | 怎么算 | 需要填 |
| --- | --- | --- |
| 无刚性冲击 / 无柔性冲击 | 段接头处速度、加速度是否连续 | — |
| 推程 / 回程最大压力角 | 接触点法线与运动方向的夹角 | 许用压力角 |
| 不根切 | 理论廓线外凸处曲率半径大于滚子半径 | 滚子半径 |
| 实际廓线最小曲率半径 | 廓线一、二阶导数 | 可选：限值 |
| 高速不跳离 | 弹簧力 + 载荷 + 惯性力始终大于 0；槽凸轮不适用 | 转速、质量、弹簧 |
| 滚子换侧次数（槽凸轮） | 接触力换向次数 | 转速、质量 |
| 最大接触应力 | 赫兹线接触 | 材料、接触宽度、许用接触应力 |
| 凸轮轴峰值力矩 | 接触力 × 类速度 | 转速、质量 |

总结论取最差的一项；没填的限值结果是“未知”，不算合格。
