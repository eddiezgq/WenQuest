# 问渠质量 ERP 试点企业：邀请、注册、自动开通

给谁看：问渠的管理员（Eddie）。依据：《实施细则 · 第 97 轮》，wenquest-ops ADR-0025。

## 一句话

在学习平台“管理 → 质量 ERP 试点”填对方邮箱、点“发邀请”；对方打开邮件里的链接，填单位名称、简称和联系人，用这个邮箱收验证码确认；服务器自动给这家装一套独立的问渠质量 ERP（约 15 分钟），把账号和初始密码发到对方邮箱。免费试用 3 个月。

## 管理员怎么做

1. 登录学习平台（管理员账号）→ 左侧“管理” → “质量 ERP 试点”。
2. 顶上看名额（默认 3 家，`.env` 的 `WQ_PILOT_MAX`）和服务器可用内存（少于 1.5 GB 就开不了新的，要先升级服务器）。
3. “邀请一家企业”：填对方邮箱（单位名称可不填，会写进邀请信），点“发邀请”。邀请 7 天有效、只能用一次；也可以“复制邀请链接”用微信发给对方。
4. 下面列出各家：排队开通 → 正在开通 → 使用中（点网址直接打开）；开通失败会写原因，同时发邮件给管理员。
5. “停用”：这家的系统停下，记录保留；“恢复”再起来。
6. **对方收不到验证码邮件**（第 151 轮）：在“最近的邀请”里找到这条（状态“等对方注册”），点“给验证码”。页面当场显示一个 6 位码，不发邮件，你用电话、微信或自己的邮件转给对方，让他在邀请页填进去。这个码 24 小时内有效；再点一次“给验证码”，旧码就作废。同一行的“复制邀请链接”可以再拿到链接，不用重新发邀请。
   - 对方点“发验证码”时如果邮件没发出去，邀请页会直接提示“邮件没发出去，请联系邀请你的人要验证码”。
7. **替对方直接开通**（第 151 轮补充）：同一行点“直接开通”，填单位全称、简称（网址里用，如 `acme`）和联系人，点“开通”。不用对方填验证码，装好后（约 15 分钟）账号和初始密码会发到受邀的邮箱。

## 对方看到什么

- 邀请邮件里的链接打开是“开通问渠质量 ERP 试点”页：单位全称、简称（网址里用，小写字母、数字或 -，例如 `acme` → `https://acme.qms.wenquestech.online`）、联系人姓名、邮箱验证码。
- 提交后页面显示“排队开通 / 正在开通”，可以关掉；好了收到邮件：工作台网址、ERPNext 网址、账号、初始密码。
- 登录后在“我的账户”改密码，在“人员”页自己添加同事。

## 背后怎么转的

- 网关不碰 Docker：开通申请写进服务器的 `/opt/wenquest/pilot-queue`（网关里是 `/pilot-queue`）；质量 ERP 那边的 `pilot-runner.sh`（deploy 用户每分钟跑一次）接过去，运行 `tenant.sh new`，装在 `/opt/wenquest/qms-tenants/<简称>`，再把结果写回这个文件夹。初始密码只在发给对方的邮件里，文件发完就删。
- 网址 `<简称>.qms.<主域名>`、`<简称>.qms-erp.<主域名>` 的证书按需办：Caddy 先问网关“这家开通了没有”，开了才办。
- 每家每天 04:15 前后备份，留 7 份；质量 ERP 每次部署时逐家升级。

## 第一次启用前（一次性）

1. **DNS**：在阿里云“云解析 DNS”的 `wenquestech.online` 下加两条 A 记录：主机记录 `*.qms` 和 `*.qms-erp`，记录值都是 `139.224.32.125`（美国服务器在美国 DNS 加同样两条，指向美国服务器）。
2. **质量 ERP 那边部署一次**（wenquest-ops 的 PR 合并后自动部署到国内），装好 `tenant.sh`、`pilot-runner.sh` 和每分钟的定时任务。
3. **问渠这边部署一次**：网关带上开通文件夹和新页面。
4. 管理页顶上显示“服务器可用内存 …”（不是“开通程序没在运行”）就可以发邀请了。

## 出问题

- 管理页显示“开通程序没在运行”：质量 ERP 那边还没部署，或服务器上的定时任务没装（`crontab -l | grep pilot-runner`）。
- 开通失败：看服务器上 `/opt/wenquest/qms/pilot-<简称>.log` 的最后几行。修好后删掉那家目录 `/opt/wenquest/qms-tenants/<简称>` 之前先问清楚（会丢数据）；或者换个简称重新邀请。
- 证书错误（ERR_SSL_PROTOCOL_ERROR）：多半是通配解析 `*.qms`、`*.qms-erp` 没加，或刚加还没生效。
