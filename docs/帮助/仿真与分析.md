# 仿真与分析（有限元强度、疲劳寿命）

数字工厂工作台左侧“专业软件 → **仿真与分析**”。不用装软件，在浏览器里设置，服务器计算（Gmsh 划网格、CalculiX 求解、pyLife 算疲劳）。教学模式、生产模式都能用；公共工厂、演示工厂、各班级工厂都有。

配套实验：**实验 8 输出轴强度与疲劳校核**，页面右上角可下载指导书和报告模板（Word）。

## 一、四步算一次强度

1. **零件**：下拉框里是已经发布过三维模型的物料（输出轴 SH-301 总有），选好点“读入”；也可以直接上传任何 CAD 导出的 STEP（30 MB 以内）。
2. **材料**：12 种常用材料（45 钢、40Cr、20CrMnTi、Q235、Q345、HT200、QT500-7、6061-T6、7075-T6、304、ABS、PA66）。点“出处”能看到每个数值来自哪本标准或手册。
3. **约束与载荷**，两种方法：
   - **一句话**：在框里写，例如“两个 Ø35 轴承位支承（左边那个止推），右端 Ø30 轴伸限制转动，键槽侧面加 350 N·m 扭矩，45 钢调质”，点“AI 填表”。AI 只填表，下面会列出它把哪句话理解成了哪个面；没看懂的会标出来，请手动补上。
   - **点选**：点“+ 固定 / 轴承支承 / 限制转动 / 力 / 压力 / 扭矩”加一行，再到右边模型上点面（再点一次取消）。鼠标停在面上会显示面号、类型、直径和面积。

   | 种类 | 什么时候用 |
   |---|---|
   | 固定 | 焊死、夹紧，三个方向都不能动 |
   | 轴承支承 | 圆柱面，只限制径向（轴能转）；勾“止推”再限制轴向。一根轴至少一个止推 |
   | 限制转动 | 圆柱面，联轴器、键连接的那一端 |
   | 力 | 总力（N），均匀分布在所选面上，填 x、y、z 三个分量（向下是 −y） |
   | 压力 | 垂直压在面上（MPa） |
   | 扭矩 | 绕轴线（N·m），按到轴线的距离分布 |

   SH-301 还有“填入示范题”按钮，一键填好额定工况。
4. **网格**：粗（快）、中、细（慢）。点“开始计算”。

**一次算一个任务，其余排队**，页面会显示前面还有几个。中等网格一般 5–20 秒。教学版上限约 20 万个单元、5 分钟，超了会提示把网格调粗。

## 二、看结果

- **云图**：Von Mises 应力 / 位移 / 疲劳寿命切换；“变形放大”拖动看变形；“剖切”看内部；鼠标停在哪里就显示那里的应力、位移。粉点是最大应力，青点是最大位移。
- **四张卡片**：最大应力（在哪几个面）、安全系数（强度 ÷ 最大应力；小于 1 红、小于 1.5 黄）、最大位移、网格规模和用时。脆性材料（HT200）没有屈服强度，按抗拉强度算。
- **两点要注意**：
  - 约束面附近的高应力是理想约束造成的，评估最大值时已经避开（页面会写出避开前的数值）。
  - 没有圆角的内角（尖角）处应力理论上没有上限，网格越细数值越大。看“位置”和“趋势”，并按规范的应力集中系数校核。
- **AI 解释与建议**：点“请 AI 解释结果”，AI 讲最危险在哪、为什么、怎么改，并给出可以一键执行的建议：
  - “换成 40Cr 重算”：同一零件、同一工况，换材料直接重算；
  - “到设计台试：键槽轴段 Ø40 → Ø44”：打开设计与工艺页，参数已经填好、改动说明已经写好；看过校核和三维再发布，回来重新读入零件再算。
- **下载计算报告（Word）**：设置、材料出处、网格、结果表、应力和位移云图（算过疲劳的还有疲劳一节和疲劳云图）、结论、AI 解释。

## 三、疲劳寿命

结果下方的“疲劳寿命”：

1. **载荷谱**：
   - **恒幅**：最大、最小值和频率。计算工况里有扭矩时按 N·m 填；没有扭矩时按“计算工况的倍数”（1 = 计算时的载荷，−1 = 反向）。
   - **跑合试验台转矩记录**：仿真车间每台减速器跑合试验时记录的输出轴转矩（带式输送机 启动—运行—停机 × 3，75 秒）。选一条记录能看到曲线。载入或重置实验 7 情景时，会补上最近交付的几台减速器的记录。
2. **表面状态**（磨削、精车……）、**尺寸系数**（直径 30–50 mm 约 0.85）、**附加缺口系数 Kf**（有限元已经算出形状造成的应力集中，一般填 1）。
3. **Haibach**：勾上时，低于疲劳极限的应力幅也计损伤（偏安全）；不勾就是原始 Miner。
4. 点“计算疲劳寿命”，得到最危险点的寿命（小时、循环次数，或“无限寿命”）、修正后的疲劳极限，以及最危险点损伤最大的几个循环（可以照着手算核对）。云图切到“疲劳寿命”看各处寿命，红色寿命最短。

算法：线弹性比例加载 → 载荷谱当作重复的块做雨流计数（pyLife 四点法）→ Goodman 平均应力修正 → 修正后的 S-N 曲线 → Miner 线性累积损伤。

## 五、限制

- 线弹性、小变形；不考虑接触（键与槽、过盈配合）、塑性、残余应力、表面硬化。用于教学和方案比较，正式设计请按标准复核。
- 一个 STEP 里可以有多个实体，但它们之间没有连接关系（不算装配体接触）。
- AI：国内部署用 DeepSeek，美国用 Claude；没配模型时用规则理解一句话和写解释，规则能认端面、轴肩、外圆 / 孔 Øxx、键槽侧面 / 底面、面编号、方向和材料。用到模型时，次数计入每人每小时的 AI 上限。
