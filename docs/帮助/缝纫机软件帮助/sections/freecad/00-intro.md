FreeCAD 是开源的参数化三维 CAD。“问渠缝纫机”工作台把问渠缝纫机设计软件的计算核心装进 FreeCAD：设计对象的属性就是设计参数，改了按 Ctrl+R，机构零件和 {{checks_lockstitch}} 项校核（平缝机）一起更新；可以在这些零件上继续建模、出图，导出 STEP，提交到问渠工厂审批，还能用 FreeCAD 自带的求解器在本机做有限元。

| | FreeCAD 工作台（本帮助） | 网页版 |
|---|---|---|
| 在哪用 | 本机 FreeCAD 1.0，计算不用联网 | 浏览器 |
| 适合 | 在三维 CAD 里继续建模、出图、本机有限元 | 方案比较、团队共享项目、CAE、零件库管理 |
| 结果 | 同一组参数，两边结果完全一样（参数文件互通） | |

**第一次用？从案例开始**：[典型案例](#cases)里有平缝、包缝、绷缝、花样四个案例；案例一另有 FreeCAD 里的做法和录屏。
{: .start }

五种机型：{{name_lockstitch}}（{{checks_lockstitch}} 项校核）、{{name_overlock}}（{{checks_overlock}} 项）、{{name_cover}}（{{checks_cover}} 项）、{{name_pattern}}（{{checks_pattern}} 项）、{{name_embroid}}（{{checks_embroid}} 项）。平缝机、包缝机有三维机构零件；另外三种是校核和计划（没有三维零件）。

### 联网才能用的三样

AI 助手、插入本单位零件、提交到问渠工厂要联网和凭证；其余（新建、改参数、校核、时序、转动、导出、本机有限元、帮助）都在本机，断网也能用。本帮助随安装包，断网也能看；只有网页版的录像和小计算器要联网。
