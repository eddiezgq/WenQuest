### 改参数

<ol class="steps">
<li>点“新建平缝机设计”。模型树里出现“平缝机设计”，下面挂着各机构零件。</li>
<li>在模型树里选中“平缝机设计”，属性面板里就是全部设计参数，分组同网页版（基本参数、刺布机构、挑线机构……），参数名前面带 <code>P_</code>。</li>
<li>改一个值（例如转速改成 6000），按 Ctrl+R 或“重新计算”：零件形状和校核一起更新；属性“结果 → Status”写着结论。</li>
<li>双击“平缝机设计”或点“校核结果”看红绿灯列表。</li>
</ol>

### 和网页版互通

- 网页版“导出 → 参数文件”得到 `.wqsew.json`，FreeCAD 里选中同机型的设计点“导入参数”，{{checks_all}} 项校核的结论和数值完全相同。
- FreeCAD 里“导出参数”得到同样格式的文件，存档或交给同事在 FreeCAD 里导入；网页版目前没有导入参数文件的入口。
- 花样机上传的针位表存在设计对象的 `PatternPoints` 属性里，随参数文件一起带。
- 横机的意匠图（第 70 轮）：属性“花型从哪里来”（`P_src`）选 file，“花样”一栏的 `StitchFile` 选意匠图文字表（CSV / TXT）或提花色码图（PNG），Ctrl+R 重算。
- 刺绣机的花样文件（第 69 轮）：属性“花样从哪里来”（`P_src`）选 file，“花样”一栏的 `StitchFile` 选 DST 或 CSV 针位表，Ctrl+R 重算——针数、最长针、换色从文件来，每一针按自己的长度调速。从网页版导出的参数文件带着花样，导入后接着算。

### 三维样机与标红（第 94 轮）

六种机型新建后都有三维零件，和网页版“样机”页签、三维讲解片是同一套，改参数 Ctrl+R 后零件跟着变：

- **转动**：平缝机、包缝机、绷缝机转主轴（属性“显示 → Phi”是主轴转角）；花样机、刺绣机一针针走（每 360° 一针），横机一趟趟走（每 360° 机头走一趟）。这三种的属性“显示 → 进度”写着现在走到第几针 / 第几趟，“显示 → 进度角”可以直接改（每 360° 一针 / 一趟），跳到想看的那一针。横机一格走得多一些（一趟约 0.8 秒），慢转时每格是平时的六分之一。
- **标红**：重新计算后，红灯校核项对应的部件涂红、黄灯的涂橙（送布红灯就是送布牙红，钩线红灯就是旋梭红……，对应关系同网页版样机和讲解片）；全绿就是原来的颜色。整机的项（平缝机机壳共振、整机惯性力）不涂色——不然整台都红，看不出是哪个机构。
- **停到出问题的地方**：“校核结果”里**双击**红 / 黄灯那一行，对话框关上，三维停到出问题的转角（平缝机 6000 r/min 针杆惯性力停在下止点 180°；花样机停到最紧的那一针；横机停到摇床没走完的那一趟），出问题的部件被选中，状态栏写着停在哪里；再点“转动机构”就从这里慢转（每格 1°），看清楚怎么出的问题。整圈都要看的项（例如机壳共振）只选中部件，不停到某个转角。

### 出三维讲解片（第 94 轮）

点“出三维讲解片”：选字幕语言（中文 / 英文 / 中英两行）、勾不勾“配旁白”（默认勾上），再选声音和语速（第 102 轮：声音列表从问渠服务器取，英文字幕列英文声音、中文和中英两行列中文声音；第一项“平台默认”；语速慢 / 标准 / 快；FreeCAD 里不能试听，要试听到网页版或“三维视频”页），点“出讲解片”。当前设计发到问渠服务器（要联网和钥匙，同“AI 助手”），服务器自动写好讲解片——整机、各机构，再把红黄灯慢放到出问题的地方，和网页版“导出 → 三维讲解片”一模一样；接着自动用浏览器打开这段视频的页面，在那里看关键画面、提意见修改、出小样和高清、下载 MP4。浏览器里要用钥匙主人的账号登录；网页版“三维视频”里也找得到这段片子。

::img{src=fc-94-video.jpg caption="“出三维讲解片”对话框"}

::video{src=fc-09-video title="从 FreeCAD 出三维讲解片（有旁白）：选语言、配旁白 → 服务器写好 → 在浏览器里打开这段视频的页面"}

- 配旁白要几分钟；服务器没装语音服务时出无声的片子，对话框里会说。
- 国内站（服务器地址设成国内站）只出关键画面和配旁白，小样、高清在美国站出。
- 钥匙不对、没开通、没联网，对话框里直接说是哪一样。

### 提交到问渠工厂

要先装数字工厂企业版的“问渠”工作台（数字工厂“设计与工艺”页下载宏包）。点“提交到问渠工厂”，整套零件合成一个组件，弹出提交对话框：填物料编号和改动说明，进设计审批；批准后版本号加一，STEP 挂到 ERP 物料上。没装“问渠”工作台时，先“导出 STEP”，再到数字工厂网页上传。
