### 分层

| 层 | 组成 | 说明 |
|---|---|---|
| 用户界面 | 网页版（uni-app / Vue + three.js）；FreeCAD 工作台（PySide 界面） | 两个入口，同一份计算核心 |
| 计算核心 | `sewcore`（Python） | 六种机型的参数表、公式、判据、试缝、零件尺寸、三维零件清单；纯函数，不联网 |
| 服务 | 问渠网关（FastAPI） | 认人与开通、项目、导出、AI 助手、本单位零件库、FreeCAD 钥匙、把计算任务交给数字工厂 |
| 计算 | 数字工厂计算服务 | 排队算有限元、疲劳、模态、动力学、拓扑、数控；每单位每天有上限 |
| AI | 统一模型接口 | 国内 DeepSeek、美国 Claude；没配时规则版 |
| 数据 | 网关数据目录（项目、零件库、AI 记录）；数字工厂数据库；ERPNext | 按单位隔离；日常备份 |

### 一次“改转速”背后发生了什么

<ol class="steps">
<li>网页里拖“最高转速”滑块；250 毫秒后把整组参数发给网关。</li>
<li>网关调计算核心：算出各机构尺寸、运动曲线、时序、{{checks_lockstitch}} 项校核、30 针试缝；几十毫秒返回。</li>
<li>网页更新结论条、校核、曲线，并把调机参数同步给三维样机。</li>
<li>（需要时）点“CAE 分析”：网关按同一组参数生成零件和工况，交给数字工厂排队；求解器算完，网关取回结果、判定、写进计算书。</li>
<li>（需要时）导出：计算书、STEP、DXF；STEP 进审批，批准后进 ERP 和车间。</li>
</ol>

### 两个入口怎么保持一致

FreeCAD 工作台安装包里带的就是服务器上的那份计算核心（同一批文件），参数文件 `.wqsew.json` 两边互通：网页版导出、FreeCAD 导入，{{checks_all}} 项校核的结论和数值完全相同。FreeCAD 里的零件由同一份“零件清单”生成，和网页版导出的 STEP 一致。

### 安全与数据

- **按单位隔离**：项目、零件库、CAE 任务、AI 记录都带单位；查询只认本单位。
- **两种凭证**：网页用学习平台的登录；FreeCAD 用每人一把的钥匙（只存哈希，只显示一次，可作废），只能读零件库、下载 STEP、用 AI 助手。
- **AI 合规**：国内部署只用已备案模型；发给模型的只有设计参数和校核结果。
- **部署**：问渠服务器上的容器（网关、网页、数字工厂、计算服务）；国内版可以部署在国内服务器。推送代码后自动测试、构建、上线。
