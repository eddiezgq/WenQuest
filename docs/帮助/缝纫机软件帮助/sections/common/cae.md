传统做法：买仿真软件、学建模、学划网格、自己判断约束和载荷加在哪、加多大，一个零件一两天。这里的做法：**设计参数已经说清楚零件长什么样、受多大的力、怎么支承**，所以软件把这些全自动做好，你按一下就算，结果自动写进计算书。

::only{web}
入口：页签“CAE 分析”（已开通的企业）。
::end

网页版“CAE 分析”页签交给问渠服务器算（下面各小节）；FreeCAD 里还能用 FreeCAD 自带的 Gmsh + CalculiX 在本机算零件有限元，见本节最后一小节。
::end

### 有限元：四步全自动

::anim{id=fea}

软件替你做的四件事：

1. **几何**：按当前参数生成零件（和导出的 STEP 同一个），不用自己建模。
2. **网格**：Gmsh 剖成二次四面体（尺寸自动定）。
3. **约束与载荷**：从“一转里连杆力最大的那一刻”取力（平缝机教材算例是针杆下止点，{{fea_force}} N），轴孔固定、销孔加力——这一步最容易出错，也最需要经验，这里全自动。
4. **求解与判定**：CalculiX 算等效应力和位移，按材料算安全系数；然后接着算疲劳。

教材算例的针杆曲柄（45 钢调质，{{cae_date}} 实算）：服务器上最大等效应力 {{fea_vm}} MPa、安全系数 {{fea_sf}}；同一个零件、同一组约束载荷，用 FreeCAD 自带的 Gmsh + CalculiX 在本机算是 {{fc_vm}} MPa，相差 {{fea_diff}}%（网格不同）。

::only{web}
<ol class="steps">
<li>左边“主轴电机（CAE 选型用）”一组里选材料。</li>
<li>“CAE 分析”里选零件（平缝机：针杆连杆、针杆曲柄；包缝机：引针连杆、引针曲柄、下弯针摆杆），点“提交计算”。</li>
<li>“计算任务”里看排队位置；算完点开：应力云图、安全系数、疲劳寿命，可下载 Word 报告；结果自动写进同一组参数的计算书。</li>
</ol>

### 疲劳：每针一个循环

::anim{id=fatigue}

零件坏，多半不是一次被拉断，而是每针一次、一天几百万次的反复受力慢慢累出裂纹。软件把一转里的受力曲线当成一个载荷块：热点应力随力按比例变，pyLife 做雨流计数，按材料 S–N 曲线（考虑表面、尺寸、平均应力修正）和 Miner 法则累积损伤，算出能用多少小时、多少年。

### 多体动力学：主轴要多大劲

::anim{id=mbd}

按你的曲柄半径、连杆长、针杆组件质量自动建一个多体模型（MuJoCo），让主轴匀速转，算出驱动刺布（引针）机构要的主轴转矩，和本软件的公式对照。教材算例（{{cae_date}} 实算）：MuJoCo 峰值 {{mbd_peak}} N·m，公式 {{mbd_formula}} N·m，相差 {{mbd_diff}}%。公式可信，以后改参数就直接看公式；动力学用来核对和看完整曲线。

“电机选型”把整机各机构的惯性转矩加上缝纫阻力矩，峰值和均方根各留 1.2 倍余量，从电机表里挑最小够用的：教材算例峰值 {{motor_peak}} N·m、均方根 {{motor_rms}} N·m，推荐“{{motor_pick}}”。本单位零件库里有电机的，**自家电机一起比**，表里标“本单位”。

花样机、刺绣机、横机没有主轴机构，选的是直线运动的伺服：花样机 X / Y 轴、刺绣机绷架按每针的加减速算；横机机头按走一趟的加速、匀速、减速算（系统越多机头越重）。设计优化里横机的目标是“一片用时最短”：补偿方式、系统数逐个试，机头速度、加速度在范围里找，选针、摇床、制动、电机都不许出红灯（见案例五）。

### 拓扑减重：材料该留在哪

::anim{id=topo}

在“减重与加工”里选零件和留多少材料（40%、50%、60%），软件按一转里最大的力，在现在的外形里找传力的路线。算完看形状和质量比，可下载轮廓 DXF、三维 STEP；**一定要点“送有限元复核”**，同一组受力和材料再算强度和寿命。减重后的零件还能直接“出铣削程序”。

### 电控箱：热、电容寿命、开关时间 {#cae-ebox}

六种机型的“CAE 分析”页签都有“电控箱”一项（第 62 轮，模型见教材第 18 章）。它算的是**这台机配的那只电控箱**：

- **电流从设计来**：平缝机、包缝机的主轴按一转的转矩均方根 ÷ 电机转矩常数（默认 1 N·m/A，教材算例正好 3 A）；花样机 X / Y、刺绣机绷架、横机机头按各自伺服的转矩。改了设计（例如转速），电控箱跟着变。绷缝机、花样机、刺绣机的**主轴**软件里还没有转矩模型，主轴电流手填（默认 3 A）。起停时的电流是驱动器的限流值，要按你的驱动器改。
- **当场出**：功率级平均损耗（起停只占一小部分时间，却贡献一大半热量）→ 箱内空气、散热器、起停时的结温峰值 → 母线电容寿命（十度法则）→ 共模电流；八项红黄灯（散热器过热报警、结温上限、电容寿命、共模电流、开关频率、开关时间窗口、最热车间、飞絮堵塞后），四张曲线（间歇缝纫的结温、开关时间折中、飞絮堵塞、电容寿命随车间温度），一张**改进方案对照**（加散热面积、加风扇、开关时间改到窗口中间、起停限流、定期清理，每行给关键数和还剩几盏灯）。
- **CAE 复核**：数字工厂按你填的外壳尺寸（长宽高、壁厚、顶面翅片）建一只铝外壳，功率模块贴在顶板里面。没有风扇时算**静止空气里的自然对流**（热空气往上浮带动空气流动，OpenFOAM），有风扇时算风吹过外壳；得到每个外表面的散热系数，加上辐射，再算外壳的温度场（CalculiX），反算“箱子到车间”的热阻，代回公式重算结温和电容寿命。和按尺寸的公式相差 15% 以内算对得上。没有风扇的约 10 分钟；一次复核用掉本单位当天计算次数里的 2 次（流体、温度场各 1 次）。也可以**上传本单位自己的外壳 STEP**（封闭的外形）：温度场按外壳整体均匀发热，复核的同样是“箱子到车间”这一段。
- **出件**：看过电控箱以后，计算书多一节“电控箱”（参数、结果、校核、改进方案），参数表多一页；“外壳 STEP”下载这只参数化外壳。上面那行可以一句话问 AI，例如“车间夏天 40 度、飞絮堵塞 0.3，会不会报过热”——AI 改环境和电控箱参数，计算核心重算，红灯照实列出，点“采用”才填进去。

判据（结温 125 °C、过热报警 100 °C、电容寿命 5 年、共模电流 0.8 A……）都是教材的示意值，按本单位的器件资料改。

::only{freecad}
FreeCAD 工作台里点“电控箱”按钮：常改的几项参数、校核和改进方案和网页版一样；“在文档里建外壳”把参数化外壳建进当前文档，用“文件 → 导出”存 STEP。流体和温度场的 CAE 复核在网页版做。
::end

### 超出这些的分析：自己定工况

缝纫机页签里的分析，约束和载荷是按机构自动定的。要算别的件、别的工况（例如机壳上一个支架、自定义的冲击载荷），到问渠数字工厂“仿真与分析”页：上传任意 STEP，**一句话说工况**（例如“左边两个孔固定，右端面向下 500 N，45 钢”），AI 填好约束载荷表，并列出它把哪句话理解成了哪个面，你核对后再算；同样有有限元、热、多体动力学、流体。

::only{freecad}
### 在 FreeCAD 本机做有限元

FreeCAD 1.0 自带 Gmsh 和 CalculiX，工作台带了一个程序，把网页版同样的零件、约束和载荷在本机建成一套普通的 FreeCAD 有限元分析——建好后在模型树里，切到 FEM 工作台可以自己改约束、载荷、网格再算。

先新建（或选中）一个平缝机或包缝机设计，然后在 Python 控制台（视图 → 面板 → Python 控制台）里：

```python
import wqsew_fem
r = wqsew_fem.run()            # 针杆曲柄；针杆连杆写 run(part="ConnectingRod")
print(r)
```

教材算例在 FreeCAD 1.0.2 里的结果：{{fc_el}} 个二次四面体单元，最大等效应力 {{fc_vm}} MPa（服务器上 {{fea_vm}} MPa）。疲劳、模态、动力学仍用网页版“CAE 分析”页签。
