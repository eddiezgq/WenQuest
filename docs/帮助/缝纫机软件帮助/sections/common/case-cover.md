**实际问题**：针织 T 恤的下摆、袖口用绷缝机缝。车间一天要换好几种线迹；采购要知道一张订单（{{cv_Q}} 件，每件缝长 {{cv_L}} cm，损耗按 {{cv_W}}% 算，线团每个 {{cv_cone}} m）得备多少线。绷缝机没有三维零件，这个案例用到“样机”“校核”“零件与制造”三个页签和“CAE 分析”里的设计优化。

### 第一步　弯针定时窗口有多窄 {#case-cv-window}

绷缝机的弯针要在机针回升、线环张开的那一刻从针后穿过去：偏早了，弯针尖高出线环、针下来时让不开弯针；偏晚了，机针已经回升太多，线环收缩，钩不住。软件把这几条约束一起算，得出**弯针定时窗口**。

<ol class="steps">
<li>打开绷缝机（教材算例，406 两针绷缝，{{cv.n}} r/min）。“样机”页签下面：弯针定时窗口 <b>{{cv_window}}°</b>——只有 {{cv_wwidth}}° 宽，在最高转速 {{cv.n}} r/min 下只有 {{cv.window_ms}} 毫秒。</li>
<li>“弯针（第 10 讲）”一组里，“弯针定时（相对标准）”拖到 <b>−6°</b>（来早了）：{{cv_dphi_m6}}。</li>
<li>拖到 <b>+6°</b>（来晚了）：{{cv_dphi_p6}}。</li>
<li>（“弯针定时离窗口边缘”这一项的数值栏显示的是定时本身和窗口两端，离边缘差多少要自己减：−6° 已经出了窗口 2.5°。）</li>
<li>不想自己试：“CAE 分析 → 设计优化”，目标“弯针定时：放在窗口正中”，给出 <b>{{cv_opt}}°</b>，全部合格，点“采用”。</li>
</ol>

**车间里的意思**：软件要求定时离窗口两边各留 1.5°，所以装机时弯针定时只能偏离窗口正中 ±{{cv_tol}}°——要用定时规调，不能凭眼睛。
