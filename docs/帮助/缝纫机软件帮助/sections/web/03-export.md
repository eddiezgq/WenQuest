| 文件 | 用途 |
|---|---|
| 设计计算书（Word） | 结论、参数、主要结果、全部校核、图、零件参数、尺寸链与公差建议、调机顺序；算过 CAE 的有“CAE 分析结果”一节；用 AI 写过设计说明并勾选的，有“设计说明”一节 |
| 调机卡（Word） | 装配车间用：逐步调机，每步给目标值，带确认格 |
| 参数表与运动曲线（Excel） | 参数、零件尺寸、校核、每 2° 的运动曲线数据 |
| 三维模型（STEP） | 机构零件，任何 CAD 都能打开 |
| FreeCAD 宏 | 不装工作台也能用：FreeCAD → 宏 → 执行，生成可编辑的零件 |
| 平板零件轮廓（DXF） | 曲柄、连杆、挑线杆、摇杆、偏心轮、旋梭的外形与孔，圆弧加直线，可直接下料、线切割 |
| 参数文件（.wqsew.json） | 给 FreeCAD 工作台“导入参数”，或存档 |

绷缝机、花样机、刺绣机、横机没有三维零件，不出 STEP、宏、DXF。“文件语言”可选中文或英文。

FreeCAD 工作台安装包也在这一页下载，安装见 FreeCAD 版帮助。

### 三维讲解片 {#export-video}

六种机型在这一页都有“出三维讲解片”：给客户、车间看“我们这台的机构怎么动”（花样机、刺绣机、横机是“一个花样 / 一片衣片怎么走完”，见本节后面）。不用写一句话，软件按当前这组参数自动写好讲解片——

1. **整机**（约 6 秒）：平缝机、包缝机的零件就是导出 STEP 的那些，尺寸、每个主轴转角的位置都按你的设计；绷缝机的零件照教材三维模型 10-1，机构尺寸是示意，针、弯针的运动和线环按你的设计算。
2. **各机构**（每个约 8 秒）：平缝机刺布、挑线、钩线、送布，包缝机刺布、下弯针、上弯针、送布与差动、切边，绷缝机引线、弯针、钩线、撑线器（602、605）、送布；其余零件变半透明，底部字幕写这个机构的主要结果（数由计算核心给）。
3. **红黄灯项**（有的话，最多三项，每项约 7 秒）：在出问题的转角慢放，标题写“⚠ 不合格”或“注意”，字幕写数值和判据。例如 6000 r/min 时“针杆下止点惯性力”在 180° 附近慢放；绷缝机弯针定时 −6° 时“针下行时让开弯针”在针尖下到弯针平面的那一刻慢放。
4. **结论**：全部合格，或几项不合格、几项注意。

右边的读数面板随主轴转：主轴转角；平缝机另有针尖高出针板、旋梭转角和针尖高度曲线（标着最低点和钩线时刻）；绷缝机另有针尖高出弯针平面、弯针尖左右位置和针尖高度曲线（标着钩线、针到弯针平面两个时刻）。字幕跟“文件语言”走，只出中文或只出英文。

**旁白**（第 90 轮）：按钮上面的“配旁白”默认勾着。软件把画面上每一段的标题和底部字幕念出来（平台自己的语音，中文女声；文件语言选英文就念英文）：数一字不差，只改读法——“r/min”念“转每分”、“≤”念“不超过”、小数逐位念（0.282 念“零点二八二”）、线迹代号逐位念（406 念“四零六”）。旁白比这一段画面长的，这一段整体放慢拉长，读完再进下一段，所以片子会比不配旁白时长（大约 70–100 秒）；慢放的地方、关键画面停的那一刻都不变。配旁白要一两分钟，配好接着出关键画面；关键画面没有声音，小样、高清里有。在“三维视频”页改了字幕或节奏，旁白自动重配。不想要声音就把勾去掉。

点按钮后跳到平台的“三维视频”页：先出关键画面（自己服务器，免费，一两分钟），看过再出小样、高清（租云端 GPU，几分钟到十几分钟），可下载 MP4。还可以在左边对 AI 说“第 3 段慢一点”“钩线那段镜头拉近”，AI 改镜头、节奏和字幕；**设计参数和数值改不了**——场景里那台机器每次都按你的设计重置。片子只有自己和平台管理员看得到。眼下出片先不收费，平台计费上线后按机器时间计。国内站暂时只出关键画面。

**绷缝机的钩线段**：转到钩线角前 30°，用 7 秒慢慢走过各针的钩线角，弯针从右往左依次钩住每根针的线环；针线、线环、弯针线、覆盖线是示意画法（线环大小按教材第 5 章的模型随针回升张开），不是线的物理仿真。绷缝机不出 STEP（尺寸是示意，不能当设计图）。

平缝机、包缝机的讲解片只讲机构，不画线。

**花样机、刺绣机、横机**（第 89 轮）讲的是一个花样、一片衣片怎么走完，片子按针（趟）走：

1. **整机**：花样机的机头、X / Y 两轴、压框模板；刺绣机按头数画（最多 4 个头，多的字幕写总头数）；横机的两块斜针床、机头、纱嘴。
2. **① 一针（一趟）慢放**：花样机看针在布中模板不动、出布后在离布窗口里移到下一针；刺绣机几个头一起扎、针在布中绷架停住；横机看机头经过时针按三角一根根升起又落下。
3. **② 移动**：花样机 X、Y 两轴；刺绣机绷架；横机机头一趟的加速、匀速、减速和换向停顿。横机有翻针的，再加一段“翻针与摇床”。
4. **③ 快放走完**：针迹一针一针画出来（刺绣机按颜色分色）；横机每隔若干趟看一趟，织物往下长。途中在**最紧的一针**（花样机：这一针的转速上限最低；刺绣机：所需加速度最大）停下慢放，红黄灯项在出问题的那一针 / 那一趟停下慢放（规则同“样机”页签的“慢放到出问题的那一针 / 那一趟”；红灯正好在最紧的那一针上时只停一次）。
5. **结论**。

读数面板：第几针（趟）、这一针转速和上限（花样机）、颜色和所需 / 可用加速度（刺绣机）、机头速度和累计用时（横机）；曲线是每针转速（花样机，红线是上限）、所需 / 可用加速度（刺绣机，红线 = 1）、每趟最高速度（横机），光标跟着走。上传的花样文件、意匠图照样能出片：场景里带的是抽样后的针迹 / 逐趟动作（最多 800 针 / 趟），不是原文件。机构尺寸是示意（教材模型 15-1、16-1、17-1），不出 STEP。
