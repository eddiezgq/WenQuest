### 刺绣机：上传花样文件 {#emb-file}

刺绣机的“断线与产能”一组里，“花样从哪里来”可以选“上传花样文件（DST / CSV）”（第 69 轮）：

- **DST**：工业多头机通用的花样格式（教材 16.5 节），制版软件都能另存。别的格式（家用机格式、制版源文件）请在制版软件里另存为 DST。
- **CSV 针位表**：每行 x, y（mm，绝对坐标），可加第三列：0 针、1 跳步、2 换色。
- 读出来：针数、跳步、换色次数、外框、最长针；“花样针数”“最长针长”“换色次数”三个参数不再手填。每一针（含跳步）按自己的长度取转速上限，再前瞻调速（“每针允许转速变化”，示例值 100 r/min）——长针降速、短针回到设计转速，产能和交期按每针的转速加起来算。跳步也按同样的窗口限速（实际跳步不落针、不受窗口限制，但大绷架长跳步同样要降速），偏保守。不上传文件时，整个花样都按最长那一针的转速算，偏保守。
- 多出来的：花样图（按颜色，红色是要降速的针）、每针转速曲线、“花样里各种针长的针数和用时”表；校核多了“花样外框在绷架行程以内”“调速以后的平均转速”。填了“订单件数”“要求交期”，还算这张订单要几天、校核赶不赶得上。
- 点“用示例花样”可以先拿程序生成的一枚徽章试（案例七用的就是它）。文件最大 600 KB、15 万条记录（常见的大花样几万针）；花样跟项目、参数文件一起存。

### 横机：上传意匠图 {#knit-file}

横机的“衣片”一组里，“花型从哪里来”可以选“上传意匠图（文字表 / 色码图）”（第 70 轮）：

- **意匠图文字表（CSV / TXT）**：一行一个意匠行，**第一行先织**（起口）；每格一个符号（表格软件里的空白格当“不织”），和教材虚拟实验 17-2“横机操作与制版”同一套：`K` 前编、`P` 后编、`T` 集圈、`>` 右移（绞花 / 放针）、`<` 左移（绞花 / 收针）、`.` 不织；符号后面可跟颜色（纱嘴）号 1–6（`K2`）。格子之间用逗号、空格都行；只用一种颜色时也可以一个字符一格。实验 17-2 里画的图点“导出意匠图（CSV）”就是这个格式。
- **提花色码图（PNG）**：一个像素 = 一枚针 × 一个意匠行，**最下面一行先织**（和织物的样子一样）；每种颜色一个纱嘴（最多 6 种），全部前编；透明 = 不织。
- 各家制版软件自己的格式不读（都不公开），请导出成这两种之一。
- 软件按实验 17-2 的编译器编成逐趟的机头动作：每个意匠行先插翻针横列（前→后、摇床、后→前），再按颜色分编织横列，纱嘴在另一头时插空行；查“空针翻针”“摇床超过 ±4 针”“移到针床外”（红灯）、“连续集圈超过 4 行”（黄灯）。多系统时一个意匠行的几个颜色合进一趟（同 17.8 节）。
- 一片用时逐趟加：每一趟的行程 = 这一趟用到的针的宽度 + 三角座跨度 + 两端换向余量（近似：没算机头从上一趟停的地方空走到这一趟起点的路，小色块时偏少一点）；翻针横列按“翻针横列机头速度”（示例值 0.4 m/s），其余按机头最高速度。改进方案对照、设计优化、机头电机的发热都按这张意匠图逐趟算。
- 多出来的：意匠图预览（红框是编译错误）、每一趟的用时曲线、编译后的机头动作表（前 40 趟）。点“用示例意匠图”可以先拿一件程序生成的提花前片试（案例五用的就是它）。意匠图跟项目、参数文件一起存。
