### 打开

- 官网首页 → 解决方案 → 企业 → 行业专用软件 → 缝纫机设计与制造 → “在线使用”；或直接打开 learn.wenquestrobotics.com，左栏“缝纫机设计”。
- 不登录也能用（来宾试算）：改参数、看全部结果都行，只是不能保存、不能导出。
- 页面右上角“？帮助”按当前页签打开本帮助对应的一节。

### 选机型、改参数

<ol class="steps">
<li>页面上方点机型：平缝机、包缝机、绷缝机、电子花样机、多头刺绣机、电脑横机。</li>
<li>左边是设计参数，分组列出（基本参数、刺布机构、挑线机构……）。拖滑块或直接输数字，右边马上重算。</li>
<li>右上方结论条：<b style="color:var(--ok)">绿</b> = 全部合格；<b style="color:var(--warn)">黄</b> = 有需要注意的；<b style="color:var(--bad)">红</b> = 有不合格的。</li>
<li>“恢复教材算例参数”回到教材的算例机。</li>
</ol>

::try{label="平缝机转速提到 6000，看哪几盏灯变红" machine=lockstitch tab=checks p='{"n":6000}'}

转速提到 6000 r/min 时会亮 {{n_bad6}} 盏红灯：{{bad6}}。原因和改法都写在“校核”页签每一项下面——针杆惯性力随转速平方涨，要减轻针杆组件；二阶激振频率跟着涨，要把机壳做刚。把针杆组件质量降到 0.10 kg、机壳一阶固有频率提到 240 Hz，{{n_bad6}} 盏都会变绿。
