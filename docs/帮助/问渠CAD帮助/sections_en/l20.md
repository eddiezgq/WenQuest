### What you will be able to do {#l20-goal}

<ul>
<li>Know that “no error” is not “correct”: check solids with Check geometry.</li>
<li>Know how the official FreeCAD and WenQuest CAD behave in the cases below.</li>
<li>Find the chapter of “FreeCAD kernel: decode, verify, correct” behind each patch.</li>
</ul>

### “Successful” modelling that is not {#l20-fillet}

::video{src=wqcad-l20a title="Screen recording: a 20 mm cube, all edges filleted with radius 11 — official FreeCAD 1.1.4 reports success and Check geometry finds an invalid solid; WenQuest CAD reports an error at once, and radius 5 works (about 2 min)"}

- A radius above half the edge cannot be built. The official build's kernel “finishes” and hands back a broken solid (shell not closed, faces open), and FreeCAD stores it without checking. Everything built on it, and every file exported from it, is broken too.
- WenQuest CAD checks fillet and chamfer results and refuses broken ones (chapter 18). In scripts, a failed fillet names the radius and how many edges failed (chapter 42).
- Habit: after a complex feature, run Part Design → Check geometry.

### Changing dimensions and recomputing {#l20-recompute}

::video{src=wqcad-l20b title="Screen recording: a sketch with a redundant dimension, width 30 changed to 40 — the official build silently snaps back to 30, WenQuest CAD takes 40; a box made too small for its fillet, recompute — the official build shows the later Cut as fine although it was never recomputed, WenQuest CAD marks it to recompute (about 2 min)"}

- Both vertical sides dimensioned 20 is a redundant constraint. The official build refuses to change any dimension while one exists, leaving only a line in the report view; WenQuest CAD makes the change and still reports the redundancy for you to delete (chapter 21).
- When a feature fails, the features after it cannot be recomputed. The official build shows them as up to date with the old shape — easy to use by mistake; WenQuest CAD marks them to recompute (chapter 22).

### Calculation and export {#l20-calc}

::video{src=wqcad-l20c title="Screen recording: in the Python console, the volume of a cylinder in B-spline form — off by 0.86 % in the official build, exact in WenQuest CAD; two parts of an assembly exported to STEP with colours and imported back — 4 parts in the official build, 2 in WenQuest CAD (about 2 min)"}

- Parts imported from other CAD systems mostly have B-spline surfaces. The official build's integration for volume, centre of mass and inertia is inexact on them: 0.86 % for a cylinder, 0.09 % for the inertia of a sphere; mass and moments of inertia follow. WenQuest CAD uses accuracy-controlled integration there (chapter 28).
- Exporting an assembly with colours from a macro or script writes every part twice in the official build (chapter 33).
- The demos use the Python console: macros, scripts and the AI workbench all call FreeCAD this way, and the GUI uses the same functions underneath.

### The 28 patches {#l20-list}

None of these changes is in the official FreeCAD 1.1.4. “Ch.” is the chapter of “FreeCAD kernel: decode, verify, correct”.

| # | Ch. | What it fixes |
|---|---|---|
| 1 | 2 | Placement matrices: reject scaling and shear |
| 2 | 3 | Point at a distance on a curve: uses a tolerance |
| 3 | 4 | Face curvature: sign relative to the face normal |
| 4 | 5 | Mesh flattening: reports the distortion |
| 5 | 5 | Unwrap commands: relative tolerance, distortion report |
| 6 | 7 | Mesh triangulation: exact predicates, no bad faces |
| 7 | 18 | Invalid fillet or chamfer results are errors (first part of this lesson) |
| 8 | 19 | Offset and thickness: check the thickness first and the result after |
| 9 | 20 | Helix: error when the pitch makes it intersect itself (in this lesson's check it did not trigger for a pitch–height helix; being investigated) |
| 10 | 21 | Sketch dimensions: a redundant constraint elsewhere no longer blocks the change (second part) |
| 11 | 22 | After a failed feature, later ones stay marked to recompute (second part) |
| 12 | 22 | Defeaturing reports features it did not remove |
| 13 | 25 | Curvature takes the limit at points such as a sphere's pole |
| 14 | 26 | Check geometry warns when planar faces meet outside the edge tolerance |
| 15 | 27 | Nearest point on a curve: end points and equidistant cases |
| 16 | 28 | Volume, centre of mass, inertia: accuracy-controlled on B-spline faces (third part) |
| 17 | 29 | Multi-fuse: result independent of input order |
| 18 | 30 | Regression tests for the book's findings |
| 19 | 31 | Shapes in the document are not changed in place by tolerance edits |
| 20 | 33 | Exporting an assembly with colours: no duplicate parts (third part) |
| 21 | 34 | CAM area offset uses the area parameters |
| 22 | 35 | Memory held by the undo stack can be queried |
| 23 | 38 | Mesh degenerate-face repair: no out-of-bounds write, no endless loop |
| 24 | 39 | Reverse-engineering fits: check normals, map inlier indices, distance threshold |
| 25 | 40 | B-spline surface fitting: reject ragged point grids |
| 26 | 42 | Error messages name the exception class and the failed fillet or chamfer |
| 27 | 43 | Sewing uses its tolerance; checks report statuses in context |
| 28 | 28 | Volume of an invalid solid no longer hangs (found while checking this lesson, a side effect of patch 16; fixed from 0.3.2) |

### On your own {#l20-self}

1. In WenQuest CAD, fillet all edges of a 20 mm cube with radius 9.9, 10 and 10.5; see which work and which are refused, and check the working one with Check geometry.
2. Sketch a rectangle, add one dimension too many, see how the solver messages report the redundancy, then delete it.
3. In the Python console, convert a sphere of radius 10 to B-spline (`Part.makeSphere(10).toNurbs()`), take its volume and compare with 4/3 π r³.
