### What you will be able to do {#l21-goal}

<ul>
<li>Explain how the work is split: AI drafts, code checks, a person confirms.</li>
<li>Use the “Selection” window to find designs from a one-sentence requirement, read “pass / fail / to be confirmed”, and know that “to be confirmed” is not a pass.</li>
<li>Look up which datasheet and page a value in the library came from and whether it was reviewed; set a company library and see what data its parts lack.</li>
<li>Replay an upper-shaft design in “AI part design” and read the checks of every round.</li>
</ul>

### Three rules first {#l21-rules}

- **AI only drafts**: it turns words into a form, proposes designs, asks questions. Changing the model or writing to the company library needs a person to confirm in the window.
- **Code decides whether it works**: torque, speed, fits, strength, life… are all deterministic calculations, not AI. There are three results: pass, fail and **to be confirmed**. Missing data means to be confirmed, **never pass**.
- **Every AI run is logged**. You can learn without an AI key: the AI replies in these recordings are recordings of a real model, and the panels say “replayed”.

### Choosing parts and checking them {#l21-select}

::video{src=wqcad-l21a title="Recording: one-sentence requirement (arm joint 2, 25 N·m, 30 rpm) → AI fills the form and shows the words each value came from → search the real vendor library: nothing for 220 V single-phase; change to three-phase 200 V and include designs to be confirmed: 2 designs, both to be confirmed (flange data missing) → place in the layout → checks C1–C11 → BOM (about 3 minutes)"}

- Menu “AI Parts → Selection”. Write one sentence at the top and click “Parse”: AI only fills the form below, and each value shows the words in the sentence it came from; what the sentence does not say (the safety factor) takes the default, and says so. **A person checks the form**, then clicks “Find designs”. (In the recording the sentence is in Chinese, because the recorded AI reply is for that sentence.)
- Searching and checking are done by code. The public library holds real vendor parts: Yaskawa motors and drives, Harmonic Drive reducers, NSK bearings, ROBOTIS smart actuators, with parameters taken from the vendors' published datasheets.
- Nothing is found for 220 V single-phase: the library data for these drives says three-phase input. **If nothing fits, it says so** and does not make do with something close.
- With three-phase 200 V there is still nothing without “Include designs to be confirmed”; with it ticked there are 2 designs, both **to be confirmed**: for the flange between motor and reducer the library lacks the bolt circle, hole count and so on, so code cannot tell whether they fit. Everything else (torque, speed, supply, fieldbus…) passes.
- “Place in layout” joins the motor, reducer and drive at their ports in a document (FapLayout). The “Checks” window lists C1–C11, each with the numbers used and what they were compared with; for missing data use “Add data” or “Import datasheet”, and every extracted value needs a person's review. The “BOM” window: vendor, model, mass, data sources; export CSV / JSON.

| Check | What it looks at |
|---|---|
| C1 | Interface type: can the two ports connect |
| C2 | Shaft–bore fit: diameters, tolerances, key |
| C3 | Flange fit: bolt circle, hole count, hole type, pilot |
| C4, C5 | Continuous and peak torque (referred to the motor, with the efficiency curve) |
| C6 | Reducer overload protection |
| C7 | Speed |
| C8 | Inertia ratio (only when a load inertia is given) |
| C9 | Supply: AC/DC, voltage, phases, current |
| C10 | Encoder and fieldbus |
| C11 | Bearing and envelope (only with a bearing or an outer diameter limit) |

### The parts library and the company library {#l21-library}

::video{src=wqcad-l21b title="Recording: in the parts library, where each value of the Harmonic Drive CSF-25 comes from and whether it was reviewed → menu “Company library”, choose the folder (a demo sewing-machine company, fictional) → after a restart two made-in-house parts appear → the data of upper shaft LS-101 and what it lacks → export the completeness report → place it in the model (about 2 minutes)"}

- Menu “AI Parts → Parts library”: search by category, model or parameter range. For a part, every value shows the datasheet and page it came from, the condition, and whether a person reviewed it.
- The **company library** holds a company's own parts — made-in-house parts and bought-in parts that are not in the public library — in one folder; the data stays with the company and is layered over the public library. Choose the folder in “AI Parts → Company library” (an empty folder creates a new library); it takes effect after FreeCAD restarts.
- The demo company's two made-in-house parts were entered with AI's help: AI read the company's parts list (41 rows) and proposed each part's type, an engineer confirmed; sizes and mass were measured by code from the 3D models. Measured values are marked “not reviewed”. (Building a company library from a parts list with AI is a script in the AI workbench tutorial, not part of the CAD window.)
- “Completeness report…”: for every part in the library, what data is missing, which checks it leaves to be confirmed, and what to fill first, exported to Excel. In the recording: 67 parts (65 public, 2 company), 52 with complete data.

### AI part design {#l21-design}

::video{src=wqcad-l21c title="Recording: AI part design — load the example “Sewing machine upper shaft” and start the design (replayed): conditions, AI's questions, the checks of every round; round 1 passes at Ø46 and 3.55 kg, weight is reduced until round 4 passes at 0.28 kg; the 3D model and drawing are made and read back; a replayed example does not go into the company library (about 2.5 minutes)"}

- Menu “AI Parts → AI part design…”. Choose the part type (stepped shaft) and write the requirement: speeds, motor, where each part sits and what it weighs, material, the required safety factor and bearing life; the bearing model can be left open. The example uses illustrative data.
- The split: **AI lists the conditions and proposes designs; bearing seats, shoulders, the safety factor at every step, critical speed and bearing life are all checked by code**. Failed items go back to AI, up to 4 rounds; after a pass it goes back to AI to lose weight, up to 3 rounds, and the lightest passing round is used.
- “Conditions”: each number AI read from the text, next to the original words. “AI questions”: where the text is unclear, AI asks instead of guessing (for example whether bearing life is at 5000 or 5500 r/min). “Rounds”: the sizes of each design and the result of every check.
- After it passes, the 3D model and drawing are made, then the sizes are read back from the model and compared with the design segment by segment; the drawing comes out only if they match.
- In real use the engineer fills in the drawing number and their name and clicks “Confirm into enterprise library”; a replayed example cannot go in.

### Try it yourself {#l21-self}

1. Fill in the “Selection” form directly (no AI): 10 N·m continuous, 20 N·m peak, 30 rpm, 200 V, 3 phases; search and see the verdicts and which checks are to be confirmed.
2. Find the NSK 6201 bearing in the parts library and see which datasheet page its dynamic load rating comes from.
3. In “AI part design”, load the example and start the design; in “Rounds”, find the critical speed ratio of round 4.
