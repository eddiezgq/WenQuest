### What you will be able to do {#l18-goal}

<ul>
<li>Tolerances: double-click a dimension, put the tolerance class (e.g. h5) in the format, tick Arbitrary tolerances and type the upper and lower deviations.</li>
<li>Technical notes: insert an annotation and write one note per line in its Text property.</li>
<li>Export: File → Export PDF (for the shop or a supplier); the toolbar's DXF button for other CAD systems.</li>
<li>Parts list: the Assembly workbench's Bill of Materials fills in index, name and quantity and follows the assembly on recompute.</li>
<li>Assembly drawing: a view of the whole assembly, the parts list, balloons numbering the parts, the title block.</li>
</ul>

### Tolerances, notes, PDF {#l18-tol}

::video{src=wqcad-l18a-en title="Recording: ⌀8 becomes ⌀8 h5 (upper 0, lower −0.006) → annotation with technical notes → general tolerances ISO 2768-f in the title block → export PDF LS-201 (about 80 s)"}

- Deviations of ⌀8 h5: from ISO 286-2, IT5 for 6–10 mm is 6 µm and the upper deviation of h is 0, so 0 / −0.006.
- In the dimension settings, Format controls the main number (`⌀%.0f h5` shows ⌀8 h5); with Arbitrary tolerances ticked, the upper and lower boxes show exactly what you type.
- The notes follow the machine's own LS-201 drawing: harden and temper 58–62 HRC, hard-chrome plate 5–8 µm and polish; Ra 0.2 on the outside diameter, straightness 0.005/100; general tolerances ISO 2768-f (GB/T 1804-f on the Chinese drawing). The chamfer note is this lesson's model, 0.5 × 45° (LS-201 says unspecified chamfers C0.3).
- The ISO frame comes with “General tolerances: ISO 2768-m”; change it so it matches the notes.
- If a PDF of the same name exists, the export asks whether to replace it.

### Assembly drawing: parts list, view, balloons {#l18-asm}

::video{src=wqcad-l18b-en title="Recording: Bill of Materials in the assembly, drop Description and File Name → A3 frame → view of the assembly, rotate right → spreadsheet view for the parts list → balloons 1–4 → title block → export PDF LS-200 (about 170 s)"}

- Make the Bill of Materials with the assembly active (double-click it in the tree). It lists four rows: Frame, ShaftCrank, Rod, NeedleBarAssy, one each.
- The parts list isn't on the toolbar: menu TechDraw → Views from other workbenches → Spreadsheet view. If the table is too small, raise its Scale property.
- The side view (Rotate right once) shows crank, rod and needle bar in one plane, clearer than the front view. The mechanism is 190 mm tall and fits on A3 landscape at 1:1.
- Balloons: select the view, click Balloon, click on a part; move the circle with the X and Y properties; number the parts in parts-list order.
- LS-200 is a practice number for this lesson; it is not in the machine's drawing list.

### Follow along {#l18-do}

<ol class="steps">
<li>Open lesson 17's needle-bar drawing and double-click the ⌀8 dimension: format <code>⌀%.0f h5</code>, untick Equal tolerance, tick Arbitrary tolerances, upper 0, lower −0.006, OK.</li>
<li>Insert an annotation with the four notes in its Text property; position X = 112, Y = 84, text size 4. Set the frame's General tolerances to ISO 2768-f.</li>
<li>File → Export PDF, file name LS-201.</li>
<li>Open lesson 16's slider-crank, double-click the assembly to activate it, Bill of Materials, delete the Description and File Name columns, OK.</li>
<li>TechDraw workbench, A3 landscape frame; select the assembly, Insert view, Rotate right, OK; scale 1:1, X = 130, Y = 160.</li>
<li>Select the BOM and insert a spreadsheet view from the menu; properties: cell end C5, scale 1.5, X = 335, Y = 95.</li>
<li>Select the view and balloon the four parts 1–4; fill in the title block (title, document type, drawing number, scale, material “see BOM”); export PDF.</li>
</ol>

### On your own {#l18-self}

1. Change ⌀8 to h6 and look up the deviations yourself (answer: 0 / −0.009).
2. Add a Material column to the parts list (Add Column in the Bill of Materials task), type GCr15, C45 and so on, and look at the table on the sheet.
3. Export the part drawing as DXF with the DXF button and open it in another CAD program.
