### What you will be able to do {#l02-goal}

<ul>
<li>Create an empty document and add primitives with the Part workbench; undo, redo; name the file when you first save it.</li>
<li>Know that an .FCStd file stores “objects + how they were made”, not just shapes.</li>
<li>Read parent/child relations in the model tree: what depends on what; change an object and everything after it is recomputed.</li>
<li>Export STEP (for other CAD), STL (3D printing), DXF (2D drawings); import a STEP someone gives you.</li>
</ul>

### New, save, undo {#l02-save}

| To… | Menu | Shortcut |
|---|---|---|
| New empty document | File → New; or “Empty File” on the start page | Ctrl+N |
| Open | File → Open | Ctrl+O |
| Save / Save as | File → Save / Save As | Ctrl+S / Ctrl+Shift+S |
| Undo / Redo | Edit → Undo / Redo; curved arrows on the toolbar | Ctrl+Z / Ctrl+Y |

FreeCAD's own file is <code>.FCStd</code> (really a zip holding each object's parameters and shape). Saving also leaves an <code>.FCBak</code> backup in the same folder; if a file is damaged, rename the backup to .FCStd and open it.

### Dependencies: change the earlier, the later follows {#l02-dep}

FreeCAD is **parametric**: every object remembers how it was made. “Cut” remembers “cube minus cylinder”, so in the model tree the cube and cylinder move under “Cut” (they are used up by the cut and hidden by default). Change the cylinder's radius or position and the cut recomputes itself. Click the objects below to see what changing each one affects:

::anim{id=deps}

::video{src=wqcad-l02b-en title="Recording: Boolean cut, change the cylinder's radius and position in the properties (about 45 s)"}

FreeCAD's result in the recording: a 10 × 10 × 10 block with a through hole of radius 3, volume {{dep.v}} mm³ (= 1000 − π × 3² × 10).

### Exporting and importing {#l02-io}

| Format | For | What it holds |
|---|---|---|
| STEP (.step / .stp) | Other CAD (SolidWorks, Creo, NX, CATIA…) | The exact solid shape; no parameters, no history |
| STL (.stl) | 3D printing, mesh software | Triangles (approximate shape) |
| DXF (.dxf) | 2D drawings, laser cutting | Flat lines |
| FCStd | FreeCAD / WenQuest CAD | Everything: objects, parameters, dependencies, colours |

Select the objects to export in the model tree first, then File → Export and choose the file type. STEP shows an export settings box; the defaults are fine.

::video{src=wqcad-l02c-en title="Recording: export the needle bar as STEP, then import it to check (about 55 s)"}

The imported needle bar has a volume of {{nb.v}} mm³, the same as the original in WQ-LS — STEP carries the shape completely, but not the parameters or dependencies.

### Follow along {#l02-do}

<ol class="steps">
<li>New empty document, switch to the Part workbench, add a cube and a cylinder; undo and redo once; save as <code>practice.FCStd</code>.</li>
<li>Select the cube, Ctrl-select the cylinder, click “Cut”; in the properties set the cylinder radius to 3 and position x, y to 5; save.</li>
<li>Open the WQ-LS machine, select <code>needle_bar</code>, export <code>needle_bar.step</code>; new empty document, import it.</li>
</ol>

### On your own {#l02-self}

1. In “practice”, change the cylinder height to 5: is the hole still through? Why?
2. Delete “Cut” (select it, press Delete): what happens to the cube and cylinder? Undo.
3. Export the needle bar as STL and open it in your computer's 3D viewer.
