### 学完能做什么 {#l17-goal}

<ul>
<li>图纸 = 图框模板 + 视图 + 标注。视图是从三维模型投影出来的，模型改了，图跟着变。</li>
<li>插入视图时选投影方向；长轴类零件横放（“顺时针转”）。</li>
<li>标尺寸：在视图上选边（Ctrl 多选），点尺寸工具；尺寸的位置在属性里调 X、Y。</li>
<li>局部视图：圆心、半径、比例；放大图上的尺寸按真实大小标。</li>
<li>标题栏：点图框上的字段，直接输入。</li>
</ul>

### 图框模板 {#l17-template}

问渠 CAD 带的图框（插入模板页时选）：

| 图框 | 用在哪 |
|---|---|
| `A4_Landscape_CN_CLIP.svg` 等 CN 系列 | 国标（GB/T 10609.1 标题栏），中文版本课用 A4 横 |
| `A4_Landscape_ISO5457_minimal.svg` 等 ISO 系列 | 国际标准，英文版本课用 |
| ASME 系列 | 美国标准 |

### 视图和第一批尺寸 {#l17-view}

::video{src=wqcad-l17a title="录屏：插入 A4 图框 → 插入视图、顺时针转成横放 → 挪位置 → 总长 180、⌀8 → 局部视图（油槽，半径 4，5:1）（约 140 秒）"}

- 视图的位置（X、Y）以图纸左下角为原点，单位毫米。
- 直径：TechDraw 的“直径尺寸”只认圆；轴类从侧面看是两条线，用“竖直尺寸”量出 8，再用“插入 ⌀ 前缀”。
- 局部视图的圆心坐标相对于主视图的中心（这根针杆的中心在 90 mm 处，第一道槽在 39.25～39.75，所以圆心 X = 39.5 − 90 = −50.5 附近，取 −49.5 把两道槽都圈进来）。

### 油槽尺寸、标题栏 {#l17-dims}

::video{src=wqcad-l17b title="录屏：放大图上标 0.5、1.5、0.2 → 主视图上标 39.25 → 填零件名、材料、图号、比例（约 120 秒）"}

做完的图和整机自带的 LS-201 针杆零件图（第 138 轮由三维模型生成）对照：⌀8、材料 GCr15、比例 1:1 一致。LS-201 上的长度写的是 179——量的是两端 0.5 倒角之间的圆柱段；本课量的是两个端面之间，180。两道油槽（宽 0.5、间隔 1.5、深 0.2、距下端 39.25）LS-201 上没有标，本课补上了。LS-201 还有 ⌀8 h5、Ra 0.2 和技术要求——下一课加。

### 跟着做 {#l17-do}

<ol class="steps">
<li>打开针杆（或第 9 课做的两道槽的针杆），TechDraw 工作台，插入模板页：A4 横图框。</li>
<li>选针杆，插入视图，顺时针转，确定。属性 X = 125、Y = 140。</li>
<li>两端短线 → 水平尺寸 180；上下两条轮廓线 → 竖直尺寸 8 → 插入 ⌀ 前缀。</li>
<li>选视图 → 局部视图：X = −49.5、Y = 3.5、半径 4、比例自定义 5。属性 X = 235、Y = 92。</li>
<li>放大图上：槽底短线 → 0.5；两槽之间 → 1.5；外圆线 + 槽底线 → 竖直尺寸 0.2。主视图：左端线 + 第一道槽左边 → 39.25。</li>
<li>点标题栏字段：零件名称、材料、图号、比例。</li>
</ol>

### 自己做 {#l17-self}

1. 给针杆加一个左视图（插入视图时勾选投影组里的“左视图”），看端面的倒角圆。
2. 用“剖视图”在油槽处剖一刀，看槽的截面形状。
3. 把局部视图改成 10:1，尺寸会不会变？（不会：尺寸标的是真实大小。）
