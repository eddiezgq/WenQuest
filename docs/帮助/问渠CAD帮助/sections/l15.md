### 学完能做什么 {#l15-goal}

<ul>
<li>装配文件里放的是零件的“链接”，零件本身还在自己的文件里；改零件，装配跟着变。</li>
<li>每个装配至少固定一个零件（“固定”），其余零件靠关节定位。</li>
<li>关节 = 在两个零件上各选一个几何元素（圆边、平面、点），软件把两处对齐，只留下这种关节允许的运动。</li>
<li>自由度：空间里一个零件 6 个；旋转关节留 1 个（转），滑动关节留 1 个（移）。</li>
</ul>

### 针杆机构是个曲柄滑块 {#l15-mech}

上轴带着曲柄转，曲柄销推连杆，连杆小头推着针杆接头，针杆在针杆套里上下走。本课用 4 个零件（文件里都按整机 STEP 的位置）：

| 零件 | 里面有什么 | 在机构里 |
|---|---|---|
| 机架 | 前轴承 + 针杆套（机头里不动的两件） | 固定 |
| 上轴曲柄 | 上轴（截到 x = 60 的一段）+ 曲柄 + 曲柄销 | 转（曲柄半径 15.5） |
| 连杆 | 连杆 | 摆动（两孔中心距 55） |
| 针杆组件 | 针杆 + 针杆接头 | 上下滑 |

上轴、曲柄、曲柄销在整机里用螺钉连成一体，这里先合成一个零件，少几个固定关节。

### 插入零件、固定 {#l15-insert}

::video{src=wqcad-l15a title="录屏：创建装配 → 插入组件：机架（固定）、上轴曲柄、连杆、针杆组件（约 60 秒）"}

- 插入别的文件里的零件前，装配文件要先存盘（零件文件也要存过）。
- 插入的第一个零件，软件会问要不要固定——选“是”。
- 后插入的零件会错开一点，免得叠在一起；它们的位置不重要，关节会把它们拉到位。

### 加关节 {#l15-joints}

::video{src=wqcad-l15b title="录屏：激活装配 → 旋转 ×3（上轴/轴承、曲柄销/连杆大头、接头销/连杆小头）→ 滑动（针杆/针杆套）（约 85 秒）"}

| 关节 | 选什么 | 留下的运动 |
|---|---|---|
| 固定 Fixed | 任意两处 | 没有 |
| 旋转 Revolute | 两个圆边（同轴） | 绕轴转 |
| 圆柱 Cylindrical | 两个圆边 | 绕轴转 + 沿轴移 |
| 滑动 Slider | 两个圆边或平面 | 沿轴移 |
| 球 Ball | 两个点 | 绕点转 |
| 距离、平行、垂直、角度 | 面、边 | 约束一个量 |

数自由度：3 个活动零件 × 6 = 18；3 个旋转关节各去掉 5、滑动去掉 5，一共去掉 20——比 18 还多，是因为平面机构里有的约束是重复的（冗余），求解器会处理。看效果：机构只剩曲柄转这 1 个自由度，转多少，连杆、针杆的位置就定了。

### 跟着做 {#l15-do}

<ol class="steps">
<li>打开 4 个零件文件；新建文件并存盘。</li>
<li>装配工作台：创建装配，插入组件：机架（固定选“是”）、上轴曲柄、连杆、针杆组件。</li>
<li>旋转关节：机架轴承孔在 x = 51 处的圆边 + 上轴同一处的圆边。</li>
<li>旋转关节：曲柄销端头圆边 + 连杆大头孔圆边；连杆小头孔 + 接头销。</li>
<li>滑动关节：针杆套的孔边 + 针杆上任一圆边。</li>
</ol>

### 自己做 {#l15-self}

1. 把滑动关节换成圆柱关节，再拖针杆试试：针杆能转了——实际上是针夹的方向定住它，所以要用滑动。
2. 不合并零件：把上轴、曲柄、曲柄销分开插入，用两个固定关节连起来。
3. 拖曲柄（装配激活时直接拖零件），看连杆、针杆怎么跟着走。
