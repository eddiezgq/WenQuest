### 学完能做什么 {#l19-goal}

<ul>
<li>建分析：FEM 工作台“模型 → 新建分析”。</li>
<li>约束与载荷：固定（选面）、力（选面，给大小和方向）、离心（选实体，给转轴和转速）。</li>
<li>计算并核查：网格、求解器不用自己设；手建的分析先选材料库的材料（数值有出处）。</li>
<li>看核查：反力平衡、网格质量、最大应力收敛、最大位移收敛；有一项不过就不给安全系数。</li>
<li>出报告：语言、编号、版次，Word 一份，装了 LibreOffice 时同时出 PDF。</li>
</ul>

### 手建分析、计算并核查 {#l19-run}

::video{src=wqcad-l19a title="录屏：FEM 工作台新建分析 → 固定轴孔 → 曲柄销受力 752.5 N、方向沿“力的方向”线 → 离心：整个零件、绕“转轴”线、83.333 Hz → 计算并核查、选 45-QT → 看结果（约 3 分钟，计算那一段跳过）"}

- 力从哪来：第 16 课问渠多体动力学算出，上轴 5000 r/min 时曲柄销受力峰值约 752 N。这里按最不利的方向（销中心指向轴心）一次加上，是偏保守的静力算法。
- 两条辅助线是文件里预先画好的：“力的方向”从销中心指向轴心，“转轴”是上轴轴线。力的方向要先选中线、再点任务面板里的“方向”。
- 离心载荷的频率单位是 Hz（每秒转数）：5000 r/min ÷ 60 = 83.333 Hz。选择模式要点“实体”，整个零件都受离心力。
- 选面时，窄的孔面不好点：可以先转一转视图，或者在模型树里选。点到了边或顶点，用“移除”去掉再加。
- 材料选 45-QT（45 钢调质），屈服强度 355 MPa。材料库的数值都有出处，报告里列明；FEM 自己的材料卡不用。
- 本课的结果：最大 von Mises 应力约 8.4 MPa，安全系数约 42；三层网格最大应力相差 0.21%、最大位移相差 0.24%，四项核查都通过。曲柄的强度很富裕——要减重、换铝，改了再算一遍。
- 计算要一两分钟（看电脑），期间软件还能用。

### 出报告 {#l19-report}

::video{src=wqcad-l19b title="录屏：选中分析 → 求解 → 出报告（零件库）→ 语言、编号 WQ-FEA-019、版次 A → 不让 AI 写解释 → Word 和 PDF → 翻看各节（约 90 秒）"}

- 报告各节：结论摘要、算例（零件、材料与出处、约束、载荷、分析步）、网格与可信度核查、结果云图、解释与建议（AI 起草时才有）、局限、审核清单、可追溯信息（程序版本、文件指纹、改版记录）。
- 让 AI 写“解释与建议”是可选的：数字都由程序填，AI 不判定合不合格，写出来要工程师判断。
- 算完以后又改了约束或载荷，出报告会拒绝：先重新“计算并核查”。
- 报告是专业版功能；免费版能算、能看结果和核查。

### 一句话起草（AI） {#l19-ai}

::video{src=wqcad-l19c title="录屏：问渠有限元入门例子 02 肩关节空心轴 RJ-201 → 一句话起草（AI，录制回放）→ 看追问、确认算例 → 计算并核查：最大应力网格不收敛、整体“不通过”、不给安全系数（约 2 分钟，计算那一段跳过）"}

- 一句话要说清：零件、材料、怎么固定、受什么载荷（数和单位）。AI 把它变成 FEM 里的约束、载荷和材料，程序逐项核对（面找不找得到、单位对不对、材料在不在库里）；AI 拿不准的列成“追问”，程序不采用的列成“未采用”。
- 人要看追问、在 FEM 里补好或判断不需要，勾“追问都已处理”、写确认人，点“确认算例”。没确认的 AI 草稿不能算。
- 录屏里 AI 的回复是真实模型的录制回放（面板上标“回放”）；自己用要有 AI 密钥（美国用 Claude、国内用 DeepSeek）。一句话起草是专业版功能。
- 这个例子的结果：反力平衡、网格质量、位移收敛都通过，但最大应力越加密越大、不收敛——疑似台阶尖角处的应力奇异点，整体“不通过”，不给安全系数。这是对的：尖角处的峰值不能当设计依据，要加圆角，或看离开尖角处的应力。

### 跟着做 {#l19-do}

<ol class="steps">
<li>打开课程文件“针杆曲柄”，切到 FEM 工作台，“模型 → 新建分析”。</li>
<li>“模型 → 机械边界条件和载荷 → 固定边界条件”：添加，点轴孔（⌀17）内表面，OK。</li>
<li>“力载荷”：添加，点曲柄销孔的面；力 752.5 N；选中“力的方向”线，点“方向”；OK。</li>
<li>“离心载荷”：选择模式“实体”，添加，点曲柄；转轴的“添加”，点“转轴”线；旋转频率 83.333 Hz；OK。</li>
<li>“求解 → 计算并核查（零件库）”，材料选 45-QT，等算完；看提示框里的整体可信度。</li>
<li>看应力云图，对照：最大约 8.4 MPa、安全系数约 42。</li>
<li>选中分析，“求解 → 出报告（零件库）”，填编号，不用 AI，打开 Word / PDF 看看。</li>
<li>（有 AI 密钥时）新建文件，导入一个零件，选中它，“求解 → 一句话起草（AI）”，照录屏写一句话，看追问、确认、计算。</li>
</ol>

### 自己做 {#l19-self}

1. 把力改成两倍（1505 N），重新计算并核查：最大应力大约变成多少？（静力线性：力加倍，力引起的那部分应力也加倍；离心那部分不变。）
2. 材料改成铝合金（材料库里找），比较安全系数。
3. 只留固定和力、删掉离心载荷再算一遍，看离心力占了多少。
