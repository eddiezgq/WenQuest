### 学完能做什么 {#l03-goal}

<ul>
<li>新建“参数实体”（Body），在 XY 平面上开一张草图。</li>
<li>用圆、多段线、圆弧、直线工具画轮廓；画圆时直接键入直径。</li>
<li>把线切换成构造线（只帮忙定位，不成形）。</li>
<li>关闭草图，用“凸台”把它拉成实体。</li>
</ul>

本课做两样东西：**压脚杆套环**（外径 {{pc.od}}、内孔 {{pc.id}}、厚 {{pc.t}} mm，和 WQ-LS 设计里的一样），以及**针夹的轮廓**（下一课加约束、定尺寸）。

### 草图是什么 {#l03-what}

FreeCAD 做零件的基本路子：**先在一个平面上画二维草图，再把草图变成三维**（凸台、挖槽、旋转……）。草图里的每条线有两种东西：

- **几何**：线、圆、圆弧——形状；
- **约束**：重合、水平、竖直、直径、距离——把形状“钉住”。

草图编辑时右边“草图编辑”一栏随时告诉你还差多少：“约束不足：n 个自由度”“完全约束”（全绿）或“过约束 / 冗余约束”（红字）。下面这个小实验模拟画圆的两下：先点圆心，再拖出半径或键入直径——看约束和自由度怎么变。

::anim{id=circle}

### 录屏：压脚杆套环 {#l03-collar}

开始页 → 参数实体 → 新建草图 → XY 平面 → 圆工具：点原点，键入 16 回车；工具还开着，再点原点，键入 8 回车 → 右边显示“完全约束” → 关闭草图 → 凸台，长度 3。

::video{src=wqcad-l03a title="录屏：压脚杆套环，从新建到凸台（45 秒）"}

录完软件算出的体积是 {{pc.v}} mm³，和 WQ-LS 真零件一样。

::anim{id=collar}

### 录屏：针夹的轮廓 {#l03-clamp}

针夹夹在针杆下端：上面一段圆弧（半径 {{nc.R}}），下面一个方耳朵（宽 {{nc.w}}，伸到中心下方 {{nc.dep}}），中间是套针杆的孔（直径 {{nc.bore}}）。这一课只把形状画出来，尺寸先不管准不准：

<ol class="steps">
<li><b>多段线</b>：右上 → 右下 → 左下 → 左上，点四下；右键结束，Esc 退出。软件自动给竖线加“竖直”、给横线加“水平”、给连着的点加“重合”。</li>
<li><b>圆弧</b>（圆心、起点、终点）：先点原点，再点右上角的端点，绕过上面，点左上角的端点。</li>
<li><b>圆</b>：圆心在原点，键入直径 8。</li>
<li><b>直线</b>：从下往上画一条竖线，再点“切换构造线”：它变成蓝色虚线——中心线，只用来定位。</li>
</ol>

::video{src=wqcad-l03b title="录屏：多段线、圆弧、圆、构造线画针夹轮廓（45 秒）"}

画完右边写着“约束不足：6 个自由度”——形状对了，大小还能被拖动。下一课把它定死。

### 常用的草图工具 {#l03-tools}

| 工具 | 怎么画 | 画的时候键入 |
|---|---|---|
| 直线 | 起点、终点 | 长度、角度 |
| 多段线 | 一点一点点下去；右键结束；按 M 切换直线 / 圆弧段 | 每段长度 |
| 圆 | 圆心、圆上一点 | 直径 |
| 圆弧 | 圆心、起点、终点（逆时针） | 半径、角度 |
| 矩形 | 两个对角 | 长、宽 |
| 构造线 | 先画，再“切换构造线”（或画之前先切换） | — |

画的时候直接打数字就是“屏上输入”：数字进到光标旁的小框里，回车确认，软件同时加上对应的尺寸约束。

### 跟着做 {#l03-do}

<ol class="steps">
<li>照第一段录屏做出压脚杆套环，保存为 <code>压脚杆套环.FCStd</code>。</li>
<li>新建一个参数实体，在 XY 平面画针夹轮廓（多段线 + 圆弧 + 圆 + 一条构造中心线），保存为 <code>针夹草图.FCStd</code>，下一课用。</li>
</ol>

### 自己做 {#l03-self}

1. 用“矩形”工具画一个 20 × 10 的长方形，凸台 5 mm。看右边自由度：矩形工具自动加了几个约束？
2. 把套环的内孔改成 8.2（双击草图进入编辑，双击“8 mm”那个尺寸改数），看凸台跟着变。
