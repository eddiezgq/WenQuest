### 学完能做什么 {#l01-goal}

<ul>
<li>说出菜单、工具栏、工作台、模型树、属性、三维视图、导航立方体、报告视图、状态栏各管什么。</li>
<li>用 CAD 导航方式：中键拖 = 平移，中键 + 左键拖 = 旋转，滚轮 = 缩放。</li>
<li>前 / 上 / 右 / 轴测视图来回切；转乱了一键“适应全部”。</li>
<li>点选一个零件，在属性里看它的数据。</li>
</ul>

本课用的文件：WQ-LS 平缝机整机（110 个零件，按八个部件分组）。

“工作台”是 FreeCAD 最特别的地方：同一个窗口，换一个工作台，工具栏就换一套——画草图用“草图”，做零件用“零件设计”，装配用“装配”，出图用“工程图”。问渠 CAD 多一个 “AI Parts” 工作台（第 21 课讲）。

### 鼠标和视图 {#l01-nav}

问渠 CAD 默认用“CAD”导航方式（状态栏右下角写着）：

| 想做什么 | 鼠标 | 键盘 / 按钮 |
|---|---|---|
| 平移（拖着走） | 按住中键拖 | — |
| 旋转 | 按住中键，再按左键，拖 | 导航立方体上的箭头 |
| 缩放 | 滚轮（以鼠标所在点为中心） | — |
| 标准视图 | 点导航立方体的面或角 | 0 轴测、1 前、2 上、3 右、4 后、5 下、6 左 |
| 转乱了 | — | “适应全部”按钮（放大镜） |
| 选零件 | 左键点；点空白处取消 | — |

::video{src=wqcad-l01b title="录屏：鼠标导航、标准视图、选零件（43 秒）"}

### 首选项：单位、语言、导航方式 {#l01-pref}

菜单“编辑 → 首选项”。最常改的三样：

- **单位**：“常规 → 语言和数字格式 → 默认单位系统”。机械设计用“标准（mm、kg、s）”。
- **语言**：同一栏。改了要重启软件。
- **导航方式**：“显示 → 导航栏 → 3D 导航”。习惯了别的软件可以换，本课程一律按“CAD”讲。

::video{src=wqcad-l01c title="录屏：首选项在哪里（25 秒）"}

### 跟着做 {#l01-do}

<ol class="steps">
<li>打开问渠 CAD，开始页点“打开文件”，打开课程附带的 <code>WQ-LS.FCStd</code>。</li>
<li>按 0（轴测），再点“适应全部”。</li>
<li>中键拖：把整机移到画面左边；中键 + 左键拖：转到能看见手轮的一面；滚轮：放大到看清针杆。</li>
<li>按 1、2、3，分别从前、上、右看；再点导航立方体的一个角回到轴测。</li>
<li>在模型树里展开“主轴与挑线”，点 <code>crank</code>（曲柄）：三维里它变绿，左下属性里显示它的名字和位置。</li>
<li>点空白处取消选择。</li>
</ol>

### 自己做 {#l01-self}

1. 在三维视图里直接点手轮，看模型树里哪一项被选中了。
2. 把“机壳”组隐藏（选中它按空格），看清里面的机构；再按空格显示回来。
3. 打开首选项，确认单位是“标准（mm、kg、s）”，然后按“取消”。
