### 学完能做什么 {#l18-goal}

<ul>
<li>公差：双击尺寸打开设置，格式里写公差带代号（如 h5），勾“任意公差”填上、下偏差。</li>
<li>技术要求：插入注释，在属性“文本”里一行写一条。</li>
<li>导出：文件 → 导出 PDF（给车间、外协）；工具栏的 DXF 按钮导出 DXF（给别的 CAD）。</li>
<li>明细表：装配工作台的“材料清单”，序号、名称、数量自动生成，零件变了重算跟着变。</li>
<li>装配图：插入整个装配的视图，放上明细表，用“气球”给零件编序号，填标题栏。</li>
</ul>

### 公差、技术要求、导出 PDF {#l18-tol}

::video{src=wqcad-l18a title="录屏：⌀8 改成 ⌀8 h5（上偏差 0、下偏差 −0.006）→ 插入注释写技术要求 → 导出 PDF LS-201（约 80 秒）"}

- ⌀8 h5 的偏差：查 GB/T 1800.2（ISO 286-2），6～10 mm 段 IT5 = 6 µm，h 的上偏差为 0，所以是 0 / −0.006。
- 尺寸设置里，“格式”管主数字（`⌀%.0f h5` 显示成 ⌀8 h5）；“任意公差”勾上后，上、下偏差框里写什么就显示什么。
- 技术要求照整机自带的 LS-201 针杆图写：淬火、回火 58–62 HRC，外圆镀硬铬 5–8 µm 后抛光；外圆 Ra 0.2，直线度 0.005/100；未注尺寸公差 GB/T 1804-f。倒角写的是本课模型的 0.5×45°（LS-201 写的是未注倒角 C0.3）。
- 导出 PDF 时如果同名文件已存在，会问“替换吗”。

### 装配图：明细表、视图、零件序号 {#l18-asm}

::video{src=wqcad-l18b title="录屏：装配里“材料清单”删掉“说明”“文件名”两列 → A3 图框 → 插入装配视图、向右旋转 → 插入电子表格视图放明细表 → 气球 1–4 → 填标题栏 → 导出 PDF LS-200（约 150 秒）"}

- 材料清单要在装配“激活”时做（双击模型树里的装配），出来的是 4 行：机架、上轴曲柄、连杆、针杆组件，各 1 件。
- 明细表不在工具栏上：菜单“工程图 → 来自其他工作台的视图 → 电子表格视图”。表格太小可以在属性里把比例调大。
- 侧视图（向右旋转一次）上曲柄、连杆、针杆都在一个平面里，比主视图看得清。机构高 190 mm，A3 横图框 1:1 放得下。
- 气球：选中视图，点“气球”，在零件上点一下；圆圈的位置在属性 X、Y 里调，序号按明细表的顺序。
- 图号 LS-200 是本课练习用的，整机的图纸清单里没有这个号。

### 跟着做 {#l18-do}

<ol class="steps">
<li>打开第 17 课的针杆零件图，双击 ⌀8 尺寸：格式 <code>⌀%.0f h5</code>，取消“相等公差”，勾“任意公差”，上偏差 0、下偏差 −0.006，确定。</li>
<li>插入注释，属性“文本”写四行技术要求；位置 X = 100、Y = 84，字号 4。</li>
<li>文件 → 导出 PDF，文件名 LS-201。</li>
<li>打开第 16 课的曲柄滑块，双击装配激活，点“材料清单”，删掉“说明”“文件名”两列，确定。</li>
<li>工程图工作台，插入 A3 横图框；选中装配，插入视图，向右旋转，确定；比例 1:1，X = 130、Y = 160。</li>
<li>选中材料清单，菜单插入电子表格视图；属性：结束单元格 C5、比例 1.5、X = 335、Y = 95。</li>
<li>选中视图，用“气球”给四个零件编号 1–4；填标题栏（名称、图号、比例、材料“见明细表”）；导出 PDF。</li>
</ol>

### 自己做 {#l18-self}

1. 把 ⌀8 的公差带改成 h6，自己查表填偏差（答案：0 / −0.009）。
2. 在明细表里加一列“材料”（材料清单任务里“添加列”），手填 GCr15、45 钢等，再看图上的明细表。
3. 用 DXF 按钮把零件图导出成 DXF，用别的 CAD 软件打开看看。
