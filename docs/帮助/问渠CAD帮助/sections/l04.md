### 学完能做什么 {#l04-goal}

<ul>
<li>读懂草图编辑栏：约束不足 n 个自由度 / 完全约束 / 冗余约束 / 过约束。</li>
<li>先选对象、再点约束按钮，加几何约束；加尺寸约束并键入数值。</li>
<li>知道“冗余”是什么、怎么在约束列表里找到并删掉。</li>
<li>把上一课的针夹轮廓定死，凸台 {{nc.t}} mm 成针夹。</li>
</ul>

### 自由度：图形还能怎么动 {#l04-dof}

一个点在平面里有 2 个自由度（x、y），一条线 4 个，一个圆 3 个（圆心 2 + 半径 1），一段圆弧 5 个。每个约束吃掉 1 个或 2 个。全部吃完 = **完全约束**：草图变绿，尺寸可靠。

### 几何约束 {#l04-geo}

规矩：**先选，再点**。在草图里点一下就加进选择（不用按 Ctrl）；点端点选的是点，点线中间选的是线。

| 约束 | 选什么 | 作用 |
|---|---|---|
| 重合 / 点在线上 | 两个点；或一个点 + 一条线 | 点重合；或点落在线上 |
| 水平 / 竖直 | 一条线（或两个点） | 线水平 / 竖直 |
| 平行 / 垂直 / 相切 | 两条线（或线 + 圆弧） | 方向关系 |
| 相等 | 两条线或两个圆 | 一样长 / 一样大 |
| 对称 | 两个点 + 一条线（或一个点） | 关于线（点）对称 |
| 锁定 | 一个点 | 位置钉死 |

::video{src=wqcad-l04b title="录屏：点在线上、对称；冗余约束怎么来的、怎么删（60 秒）"}

录屏里有个常见的坑：下边线已经有“水平”，再加“左右两个下角关于 Y 轴对称”——对称已经包含了“两点一样高”，于是软件报 **冗余约束**（红字）。办法：撤销，在约束列表里选中那条“水平”，按 Delete，再加对称。

### 尺寸约束 {#l04-dim}

| 约束 | 选什么 | 键入 |
|---|---|---|
| 半径 / 直径 | 圆或圆弧 | 半径 / 直径 |
| 水平距离 / 竖直距离 | 一条线，或两个点 | x / y 方向的距离 |
| 距离 | 两个点；点 + 线（垂直距离）；一条线（长度） | 距离 |
| 角度 | 两条线 | 角度 |

针夹还剩 3 个自由度：圆弧半径、耳朵宽、耳朵伸多长。加三个尺寸：圆弧半径 {{nc.R}}、下边线水平距离 {{nc.w}}、原点到下边线的距离 {{nc.dep}} → **完全约束** → 关闭草图，凸台 {{nc.t}}。

::video{src=wqcad-l04c title="录屏：三个尺寸定死草图，凸台成针夹（50 秒）"}

### 过约束、冗余怎么查 {#l04-over}

<ol class="steps">
<li>红字“冗余约束”或“过约束”后面列着是哪几条（点它，三维里相关的约束变红）。</li>
<li>约束列表里选中多余的那条，按 Delete；或者把它改成“参考”尺寸（只显示、不约束）。</li>
<li>拿不准就 Ctrl+Z 撤销刚加的那条——过约束几乎总是最后加的那条引起的。</li>
</ol>

### 跟着做 {#l04-do}

<ol class="steps">
<li>打开上一课的 <code>针夹草图.FCStd</code>，双击草图进入编辑，读右边的自由度。</li>
<li>中心线：下端点 + 下边线 → 点在线上；上端点 + 圆弧 → 点在线上。</li>
<li>删掉下边线的“水平”，加左右下角关于 Y 轴对称。</li>
<li>圆弧半径 5.5；下边线水平距离 7；原点 + 下边线距离 7 → 完全约束。</li>
<li>关闭草图，凸台 8 mm，保存。</li>
</ol>

### 自己做 {#l04-self}

1. 给下边线再加一个“水平距离 7”，看软件怎么说；然后用约束列表删掉它。
2. 把半径 5.5 改成 6，凸台跟着变；改回来。
3. 回到第 3 课的矩形：用“对称”让它关于原点居中，再加两个尺寸，做到完全约束。
