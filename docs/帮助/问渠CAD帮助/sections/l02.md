### 学完能做什么 {#l02-goal}

<ul>
<li>新建空文档，用“零件”（Part）工作台加基本体；撤销、重做；第一次保存起名字。</li>
<li>知道 .FCStd 文件里存的是“对象 + 它们怎么来的”，不只是形状。</li>
<li>读懂模型树里的父子关系：谁依赖谁；改了被依赖的对象，后面的自动重算。</li>
<li>导出 STEP（给其他 CAD）、STL（三维打印）、DXF（二维图）；导入别人给的 STEP。</li>
</ul>

### 新建、保存、撤销 {#l02-save}

| 想做什么 | 菜单 | 快捷键 |
|---|---|---|
| 新建空文档 | 文件 → 新建；或开始页“空文件” | Ctrl+N |
| 打开 | 文件 → 打开 | Ctrl+O |
| 保存 / 另存为 | 文件 → 保存 / 另存为 | Ctrl+S / Ctrl+Shift+S |
| 撤销 / 重做 | 编辑 → 撤销 / 重做；工具栏弯箭头 | Ctrl+Z / Ctrl+Y |

FreeCAD 自己的文件是 <code>.FCStd</code>（其实是个压缩包，里面有每个对象的参数和形状）。保存时同一个文件夹里会留一个 <code>.FCBak</code> 备份，存坏了可以改回 .FCStd 打开。

### 依赖：改前面的，后面跟着变 {#l02-dep}

FreeCAD 是**参数化**的：每个对象记得自己是怎么来的。“剪切”记得“从立方体里减去圆柱”，于是在模型树里，立方体和圆柱收到“剪切”下面（它们被剪切用掉了，默认隐藏）。改圆柱的半径或位置，剪切自己重算。下面点不同的对象，看改它会影响谁：

::anim{id=deps}

::video{src=wqcad-l02b title="录屏：布尔剪切，在属性里改圆柱半径和位置（约 45 秒）"}

录屏里软件算出的结果：10 × 10 × 10 的方块挖掉半径 3 的通孔，体积 {{dep.v}} mm³（= 1000 − π × 3² × 10）。

### 导出给别人、导入别人的 {#l02-io}

| 格式 | 给谁用 | 存的是什么 |
|---|---|---|
| STEP（.step / .stp） | 其他 CAD（SolidWorks、Creo、NX、CATIA……） | 精确的实体形状；不带参数、不带“怎么来的” |
| STL（.stl） | 三维打印、网格软件 | 三角面片（近似形状） |
| DXF（.dxf） | 二维图、激光切割 | 平面线条 |
| FCStd | FreeCAD / 问渠 CAD | 全部：对象、参数、依赖、颜色 |

先在模型树里选要导出的对象，再“文件 → 导出”，选文件类型。STEP 会弹出一个导出设置，默认就行。

::video{src=wqcad-l02c title="录屏：针杆导出 STEP，再导入核对（约 55 秒）"}

导入回来的针杆体积 {{nb.v}} mm³，和 WQ-LS 里的原件一样——STEP 把形状完整带过去了，但参数和依赖不会带过去。

### 跟着做 {#l02-do}

<ol class="steps">
<li>新建空文档，换“零件”工作台，加一个立方体、一个圆柱；撤销、重做各一次；保存为 <code>练习.FCStd</code>。</li>
<li>选立方体、再 Ctrl 选圆柱，点“剪切”；在属性里把圆柱半径改成 3，位置 x、y 改成 5；保存。</li>
<li>打开 WQ-LS 整机，选 <code>needle_bar</code>，导出 <code>针杆.step</code>；新建空文档，导入它。</li>
</ol>

### 自己做 {#l02-self}

1. 在“练习”里把圆柱的高改成 5：孔还穿通吗？为什么？
2. 把“剪切”删掉（选中按 Delete），立方体和圆柱会怎样？撤销回来。
3. 把针杆导出成 STL，用电脑自带的三维查看器打开看看。
