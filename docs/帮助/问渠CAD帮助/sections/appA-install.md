### 下载和授权 {#appA-dl}

官网“软件下载”页（美国 wenquestrobotics.com/download，国内 wenquestech.online/download）：登录后点“领取一年测试授权”，复制授权码；下载问渠 CAD 安装包（约 1.4 GB）。

### 安装 {#appA-install}

<ol class="steps">
<li>双击安装包。Windows 可能提示“已保护你的电脑 / 未知发布者”（测试版没买代码签名证书）：点<b>更多信息 → 仍要运行</b>。</li>
<li>选语言 → 同意许可 → 选安装位置（默认即可）→ 安装，约 3–5 分钟。</li>
<li>桌面上双击“问渠 CAD”。首次启动会弹窗要授权码（给 AI Parts 等问渠工作台用），粘贴进去点确定；以后不再问。不粘贴也能用 FreeCAD 本身，只是问渠的工作台不加载。</li>
<li>首次启动会出“欢迎”页：语言选“简体中文”，单位选“标准（mm、kg、s）”，导航方式选“CAD”（本课程都按 CAD 讲）。</li>
</ol>

### 排错 {#appA-fix}

- **双击没反应**：可能是 Windows 的“智能应用控制”拦下了（Windows 安全中心 → 应用和浏览器控制）。公司电脑请找管理员。
- **杀毒软件报毒**：测试版没有代码签名，个别杀毒软件会误报；从官网下的安装包可以核对页面上的 SHA-256 校验码。
- **界面是英文**：编辑 → 首选项 → 常规 → 语言，选“简体中文”，重启。
