# 本地测试环境（给开发会话用）

在云端工作环境里搭一套完整的问渠：Moodle 5.2 + PostgreSQL 16 + 接口网关 + 网页端。用来在推送上线前，真的导入课程、用老师和学生账号把页面走一遍。

## 一键搭建

```bash
tools/local/setup.sh
```

脚本做的事：下载 Moodle 5.2 源码并安装依赖 → 启动 PostgreSQL（端口 5433）→ 把 `plugins/` 里的插件链接进 Moodle → 安装 Moodle → 开启网关需要的 Web 服务 → 建测试账号 → 启动网关（AI 用假数据）→ 构建网页端并启动。

| 服务 | 地址 |
|---|---|
| Moodle 经典界面 | http://localhost:8080（管理员 admin / Admin#2026） |
| 接口网关 | http://localhost:8090 |
| 问渠网页端 | http://localhost:8088 |

测试账号：`teacher1`（有建课权限）、`student1`–`student3`，密码都是 `Test#2026`。

## 注意

- 网关用 `WQ_AI_PROVIDER=fake`，讲义正文是占位内容；线上用真实模型。要看“生成中途离开再回来”，在 `gateway.env` 加 `WQ_AI_FAKE_DELAY=4`（假模型每次调用等 4 秒），再重启网关。
- 环境被沙盒停掉后（网页打不开、Moodle 返回 000），运行 `/home/claude/local/start-all.sh` 一次性拉起数据库、Moodle、网关和网页端。只重启网关用 `/home/claude/local/start-gateway.sh`。**不要**用 `pkill -f <含 uvicorn 的词>`，会把当前命令行自己也杀掉。
- `router.php` 代替线上的 Apache：处理 `pluginfile.php/…` 这类路径，并把中文文件名解码。
- 测试用的浏览器（开源 Chromium）不能解码 H.264，所以 MP4 视频在截图测试里放不出来；Chrome、Safari、微信里正常。
- 工作环境访问不到境外 CDN 和 Moodle 下载站，所以 MathJax 已打包进网页端（`apps/web/src/static/h5/mathjax`），中文语言包在本地环境里没有。
- 用 Playwright 测上传时：测试浏览器的“选择文件夹”读不出文件内容（沙盒限制，真实浏览器正常），改用内存文件 `setFiles([{name, mimeType, buffer}])`，`name` 里带上相对路径即可保留文件夹结构。
- 后台进程（Moodle、网页端）要用 `setsid nohup … &` 启动，否则命令结束时会被一起关掉。
