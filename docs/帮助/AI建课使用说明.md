# AI 建课使用说明（老师）· AI 教授团队

> 适用版本 v0.10.0（第 3 轮 A2 步）。原来的“一键生成”已经去掉（D30）。
> 教授团队以《大学物理》第 1 章为标杆、AI 为主、资料为辅：没有资料，只说一句要求（例如“大学物理（上）第 2 章 牛顿运动定律”）也能建课。

## 团队里有谁

| 角色 | 做什么 |
|---|---|
| 课程负责人 | 和你对话：提问、汇报进度、记下你的决定。你只需要和它说话 |
| 资料馆员 | 逐个看资料，分清主教材、辅助教材、参考资料、课件、教案、讲义、习题、答案、试卷、实验、评分标准、素材；读出主教材目录 |
| 课程设计师 | 出大纲和教学日历，给每一课定好它的机器人问题；另写每课的实验指导书内容和教案 |
| 主讲教授 | 按标杆逐课撰写中英对照的课时：机器人问题 → 概念 → 讲义与例题 → 动画 → 虚拟实验 → 回到问题五步建模求解 → 生活例子 → 小结与自测。用自己的学科知识设计，你的资料用来对齐教材顺序和符号 |
| 动画师 | 把主讲教授的分镜做成 3Blue1Brown 风格动画（中英字幕），服务器渲染成视频 |
| 实验师 | 按课时里定好的机器人场景、生活场景、参数和任务写这一课的网页虚拟实验（版式、操作与第 1 章标杆一致）；服务器先自动试运行：不报错、画面不空白、参数都能调、每个任务按“示范做法”真能完成，才交给你 |
| 习题与测评 | 每课出练习和参考答案 |
| 审稿人 | 对照原文核对每一课；有错退回重写一次，仍有问题会把意见摆给你 |

## 四个阶段（每一步你确认后才往下走）

1. **了解要求**：左侧点“AI 建课” →“新建课程项目”。把资料文件夹拖进对话框（单个文件最大 190 MB；旧版 .doc/.ppt/.xls 也能读），也可以先打字说说这门课。然后点 **交给教授团队**。
2. **资料盘点**：资料馆员看完后，右边“资料清单”列出每份资料的身份和章节，主教材前面有 ★，拿不准的标黄，读不了的标红并说明原因（例如扫描版 PDF）。课程负责人在对话里一次问清楚要确认的事（最多 5 个），点选项就能回答。身份不对就在清单里改，然后“保存”。都对了点 **资料清单没问题，出大纲**。
3. **大纲与日历**：右边“大纲与日历”可以直接改课程名、章名、课时名、学习目标和周次，上下调顺序，删课、加课、加章，改完点“保存”。定了就点 **大纲定稿，开始逐课建设**——这时平台上会建好课程和各章（学生还看不到任何课时）。
4. **逐课建设**：点 **写下一课**。主讲教授写、习题与测评出题、审稿人核对，完成后在“课时进度”里标“待你审阅”：
   - 看正文、练习和参考答案、审稿意见；
   - “本节产出”列出这一课的全部文件：**动画**（可直接播放，也已嵌入课件动画页）、**虚拟实验**（直接在页面里操作；课件的机器人问题页和实验页换成了实验的真实画面）、**课件**（中英对照 PPT）、**实验指导书**、**实验报告模板**（含评分量规和 AI 使用声明）、**教案**（仅教师可见）。点文件名下载检查，点 **预览课件** 直接在页面上看每一页；
   - 写一课大约需要 5–10 分钟，其中渲染动画 2–5 分钟、试运行实验约半分钟；动画做不成时会用简版动画并在审稿意见里说明，可以按意见重写；实验三次都没通过试运行时，这一课先不带实验，审稿意见里写明原因，点 **⚗ 重做实验** 只重做实验（课件会跟着换图）；
   - 课件里的虚拟实验页暂时是占位图，虚拟实验做好后会自动换上；
   - 满意就点 **通过并发布**，这一章里依次出现：讲义、动画、课件、练习、实验指导书、实验报告模板，以及**本章的虚拟实验页**（每章一个：发布 2.2 时，2.2 的实验自动加进“第2章 虚拟实验”，不会多出文件；学生在课件里点“去做实验 2.2”直接切过去）；参考答案和教案只有老师看得到；一章的第一课发布时，这一章的课件、讲义、实验、视频等原始文件也一起挂上；
   - 不满意就写下修改意见，点 **按意见重写**；也可以直接在对话里说“第 3 课加一个 AGV 转弯的例子”。

## 节奏

在“课时进度”的“建课节奏”里选：
- **我点“写下一课”才写**；
- **每天自动写一课**：选一个钟点（按你电脑的时区），服务器每天到点写下一课。上一课你还没审，就不写下一课，不会积压。

仪表盘右边“待办”会提示“N 课待审阅”和“N 个问题待回答”。

## 其他

- 团队在工作时，页面上方显示谁在做什么，旁边有 **停止**，已写好的内容都保留。
- 所有东西存在服务器上：关掉页面、换电脑，回到“AI 建课”点开项目就能接着做。
- 出错时对话里会显示原因代码（例如 `ai_timeout`），可以直接再点一次，或者把截图发给管理员。
