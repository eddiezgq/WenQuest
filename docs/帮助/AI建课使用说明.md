# AI 建课使用说明（老师）· AI 教授团队

> 适用版本 v0.10.x（第 3 轮·教授团队重建，2026-09-30）。原来的“一键生成”已经去掉（D30）。
> 教授团队按第 1 章标杆的**完整度**建课（内容、动画、实验、课件、作业一样不少），但**内容是这门课自己的**：先为这门课写一份《课程设计书》，每一课都照它来，不套用别的课的例子。AI 为主、资料为辅：没有资料，只说一句要求（例如“机器人学导论，本科高年级专业课”）也能建课。
> **你说的话就是要求**：你在描述或对话里指定的教材、课程定位、要求，团队每个角色都必须照办。

## 团队里有谁

| 角色 | 做什么 |
|---|---|
| 课程负责人 | 和你对话：提问、汇报进度、记下你的决定。你只需要和它说话 |
| 资料馆员 | 逐个看资料，分清主教材、辅助教材、参考资料、课件、教案、讲义、习题、答案、试卷、实验、评分标准、素材；读出主教材目录。**你指定的教材一定照办**：按书名、作者、文件名去找；找不到就直接告诉你，请你点选，不会假装找到。扫描版 PDF（每页是图片）会自动做中英文文字识别 |
| 课程设计师 | 出大纲和教学日历，同时写《课程设计书》：这门课的学科与对象、贯穿全课的机器人（例如一台六轴机械臂加一台移动机器人）、每章用什么动画和实验、符号约定；另写每课的实验指导书内容和教案 |
| 主讲教授 | 按标杆逐课撰写中英对照的课时：机器人问题 → 概念 → 讲义与例题 → 动画 → 虚拟实验 → 回到问题五步建模求解 → 生活例子 → 小结与自测。用自己的学科知识设计，你的资料用来对齐教材顺序和符号 |
| 动画师 | 把主讲教授的分镜做成 3Blue1Brown 风格动画（中英字幕），用课程设计书里的机器人和本课的公式画，服务器渲染成视频 |
| 实验师 | 按课时里定好的机器人场景、生活场景、参数和任务写这一课的网页虚拟实验（版式、操作与第 1 章标杆一致）；服务器先自动试运行：不报错、画面不空白、参数都能调、每个任务按“示范做法”真能完成，才交给你 |
| 习题与测评 | 每课出练习和参考答案 |
| 审稿人 | 对照原文核对每一课；有错退回重写一次，仍有问题会把意见摆给你。动画和实验还要过两道检查：**相似度检查**（和范例、和本课程其他课大段雷同就退回）和**切题检查**（看动画关键画面、实验截图和字幕，不是讲本课就退回，最多重写 2 次）。每课给你一张**审稿清单** |

## 四个阶段（每一步你确认后才往下走）

1. **了解要求**：左侧点“AI 建课” →“新建课程项目”。把资料文件夹拖进对话框（单个文件最大 190 MB；旧版 .doc/.ppt/.xls 也能读），也可以先打字说说这门课。然后点 **交给教授团队**。
2. **资料盘点**：资料馆员看完后，右边“资料清单”列出每份资料的身份和章节，主教材前面有 ★，拿不准的标黄，读不了的标红并说明原因。扫描版 PDF 会自动识别文字，识别过的文件后面注明“已识别 N 页”。团队定的主教材不对，点任何文件后面的 **☆** 就把它设为主教材。你指定的教材在资料里找不到时，课程负责人会直接说“没有在资料里找到《某某》”，列出候选文件请你点选。课程负责人在对话里一次问清楚要确认的事（最多 5 个），点选项就能回答。身份不对就在清单里改，然后“保存”。都对了点 **资料清单没问题，出大纲**。
3. **大纲与日历**：右边“大纲与日历”可以直接改课程名、章名、课时名、学习目标和周次，上下调顺序，删课、加课、加章，改完点“保存”。大纲下面是 **《课程设计书》**：学科与层次、学生、教材、机器人平台、符号约定、动画风格、每章的动画/实验/机器人问题、不要出现的内容。之后每一课、每个动画和实验都按它写——哪里不对点 **修改** 直接改（标“你改过”，以后不会被 AI 覆盖）；已经写好的课想跟着改，点“重写”。定了就点 **大纲定稿，开始逐课建设**——这时平台上会建好课程和各章（学生还看不到任何课时）。
4. **逐课建设**：点 **写下一课**。主讲教授写、习题与测评出题、审稿人核对，完成后在“课时进度”里标“待你审阅”：
   - 先看 **审稿清单**：教材对应章节已参照、机器人问题是本课的、动画切题（附截图）、实验切题且能完成（附截图）、数值和单位已核对、中英一致。每项 ✓ / ✗ / ?，并注明是“自动检查 + AI”还是“AI 自查”；
   - 团队没能做好的，这一课标红 **需要你处理**，框里写明缺什么、为什么，并有 **重做动画** / **重做实验** 按钮。这时对话里也不会说“审稿通过”；
   - 再看正文、练习和参考答案、审稿意见；
   - “本节产出”列出这一课的全部文件：**动画**（可直接播放，也已嵌入课件动画页）、**虚拟实验**（直接在页面里操作；课件的机器人问题页和实验页换成了实验的真实画面）、**课件**（中英对照 PPT）、**实验指导书**、**实验报告模板**（含评分量规和 AI 使用声明）、**教案**（仅教师可见）。点文件名下载检查，点 **预览课件** 直接在页面上看每一页；
   - 写一课大约需要 5–10 分钟，其中渲染动画 2–5 分钟、试运行实验约半分钟；动画三次都没做成合格的（出错、和别的课雷同、或不切题）时，先放一段只有本课文字和公式的简版动画，这一课标“需要你处理”，点 **重做动画** 只重做动画；实验三次都没通过检查时，这一课先不带实验，同样标“需要你处理”，点 **重做实验**（或 ⚗ 重做实验）只重做实验（课件会跟着换图）；
   - 课件里的虚拟实验页暂时是占位图，虚拟实验做好后会自动换上；
   - **讲解视频**：每课自动做一段 AI 讲解（中英配音、中英字幕），也可以上传你自己的讲课录像，自动出字幕和英文配音，详见《讲解视频使用说明》；
   - 满意就点 **通过并发布**，这一章里依次出现：讲义、讲解视频、动画、课件、练习、实验指导书、实验报告模板，以及**本章的虚拟实验页**（每章一个：发布 2.2 时，2.2 的实验自动加进“第2章 虚拟实验”，不会多出文件；学生在课件里点“去做实验 2.2”直接切过去）；参考答案和教案只有老师看得到；一章的第一课发布时，这一章的课件、讲义、实验、视频等原始文件也一起挂上；
   - 不满意就写下修改意见，点 **按意见重写**；也可以直接在对话里说“第 3 课的动画换成机械臂末端画轨迹”。

## 资料清单：随时加、随时下载

- 右边“资料清单”顶部有 **＋ 上传文件**、**＋ 上传文件夹**，任何阶段都能用，也可以直接把文件拖进来。
- 大纲定稿后再加的资料，AI 会马上分类，并在对话里告诉你：还没写的课会自动用上；写好还没发布的课可以点“重写”；已经发布的课不会自动改；资料里如果有大纲没有的章，会提醒你。
- 每个文件后面：**↓** 下载原文件，**✕** 删除（删前会确认；删掉的资料以后写课不再用，已经写好的课不受影响）。清单右上角 **全部下载（zip）** 按原文件夹打包。
- 资料清单只有你自己能看到。

## 节奏

在“课时进度”的“建课节奏”里选：
- **我点“写下一课”才写**；
- **每天自动写一课**：选一个钟点（按你电脑的时区），服务器每天到点写下一课。上一课你还没审，就不写下一课，不会积压。

仪表盘右边“待办”会提示“N 课待审阅”和“N 个问题待回答”。

## 较早建的项目

- 在《课程设计书》出现之前建的项目，“大纲与日历”里会显示 **生成课程设计书**：先生成、看过改过，再写课或重写还没发布的课。
- 资料清单里主教材下面有 **↻ 重新读目录**：扫描版会先识别文字再读目录。Word 版教材没有页码，读不出按页的目录，写课时按章节标题找内容；有 PDF 版的话，上传后点 ☆ 设为主教材更好。
- 已经发布的课时不能再让团队重写（发布要严格），要改请在课程页手工改；课程下架、删除、恢复见《课程下架删除与恢复》。

## 其他

- 团队在工作时，页面上方显示谁在做什么，旁边有 **停止**，已写好的内容都保留。
- 所有东西存在服务器上：关掉页面、换电脑，回到“AI 建课”点开项目就能接着做。
- 出错时对话里会显示原因代码（例如 `ai_timeout`），可以直接再点一次，或者把截图发给管理员。
