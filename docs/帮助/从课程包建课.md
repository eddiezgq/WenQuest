# 从课程包建课（第 16 轮）

适用：由一本网页版教材生成整门课程（目前是《缝纫机设计与制造》），不经过 AI 建课工作室，由管理员一键发布。

## 管理员怎么发布

1. 用管理员账号登录 https://learn.wenquestrobotics.com → 左侧“管理” → 顶部“课程包”。
2. 卡片上按批列出：第 1 批（第 1–8 讲）、第 2 批（第 9–22 讲 + 期中考试）、第 3 批（第 23–31 讲 + 期末考试），每批显示已发布几讲。
3. 点某一批的“发布”，确认。第一次会先建好课程并在课程目录**免费上架**，然后逐讲发布；页面每 3 秒刷新进度，一批大约几分钟。
4. 发布完显示“✓ 已发布”。点“打开课程”可以直接进课程看。
5. 如果中途出错（比如服务器重启），卡片上会写原因；**再点一次“发布”会从中断处继续**，已发的不会重复。

点后面的批次，会把前面没发的批次一起补上。

## 每讲有什么

讲义（本讲导入 + 教材本章 + 解答与小结）→ 动画（中文版、英文版）→ 中英对照课件（PPT，备注里是讲稿）→ 练习 → 实验指导书 → 实验报告模板 → 虚拟实验或三维模型（中文版、英文版）→ 作业 → 测验（可做 3 次）。老师另外能看到练习参考答案和教案。第 33 节“考试”放期中、期末（限时 120 分钟、一次）。

## 课程包在哪里、怎样修改

- 内容：`textbook/web-editions/sewing/course/lessons/chNN.json`（格式见同目录 `FORMAT.md`），改完运行 `python3 textbook/web-editions/sewing/course/tools/check.py all` 检查。
- 生成：`python3 textbook/web-editions/sewing/course/tools/build_course.py 输出目录`（本地看效果用）；推送 main 后由 CI 自动生成并部署。
- 已经发布的讲次不会被重新发布。修改已发布讲次的内容，目前请在课程里直接编辑对应活动（或删掉该讲后告诉开发者重置该讲的发布记录）。
- 发布记录：服务器上网关数据目录 `course-packs/sewing.json`。

## 还没有的

- 讲解视频：每页 PPT 都有中英讲稿，视频另行生成后补进各讲。
