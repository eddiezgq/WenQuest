# 公开课视频：制作与发布（第 22 轮）

> 各门课共用的设置（声音、密钥、频道、做一讲的步骤）见 `docs/课程视频/00_公共设置.md`。声音已定为 Eddie 本人声音（CosyVoice2）；下面第一节的授权都已完成（2026-10-07），留作以后重设时参考。

问渠的公开课一节一讲，每讲约 15 分钟：讲课约 10 分钟，加上虚拟实验、数字工厂、作业约 5 分钟。中英两版，烧录字幕，配音用 Eddie 本人的声音（AI 合成）。中文版发 B 站，英文版发 YouTube。

讲稿在 `docs/课程视频/<课>/<节>/讲稿.yaml`，可以直接改文字；工具说明见 `tools/video/README.md`。

## 一、Eddie 需要做一次的事

### 1. 录样音

照《实施细则 · 第 22 轮》附录 A 的稿子录：中文约 3 分钟，英文约 1 分钟。

- 安静房间，手机离嘴 20–30 厘米；
- 用正常讲课的语速和语气；
- 可以分几段录；
- 发 m4a 或 wav 到对话里。

样音会加密后再放进仓库（仓库是公开的），只有 GitHub Actions 能用密码解开。合成在临时租用的 GPU 机器上做，样音用完即删。

### 2. 设样音密码 `VOICE_KEY`

1. 打开 GitHub 仓库 → Settings → Secrets and variables → Actions → New repository secret。
2. Name 填 `VOICE_KEY`，Secret 填 Claude 在对话里给你的那串密码。
3. 点 Add secret。

GPU 机器用的 `LAMBDA_KEY` 等三个密钥，与《人工智能》GPU 实测共用，已经设过，不用再设。

### 3. 授权 YouTube（约 15 分钟）

1. 打开 https://console.cloud.google.com ，用 YouTube 频道所属的 Google 账号登录，新建项目 “WenQuest Video”。
2. 打开 “API 和服务 → 库”，搜 “YouTube Data API v3”，点“启用”。
3. 设置 “OAuth 同意屏幕”：
   - 用户类型选“外部”，应用名 “WenQuest Video”，邮箱填自己；
   - 保存后点**“发布应用”**，改成“正式版”。只停在“测试”状态的话，授权 7 天就失效。
   - 应用没经过 Google 验证也没关系，授权时会有提示，点“继续”即可。
4. 打开 “凭据 → 创建凭据 → OAuth 客户端 ID”：
   - 类型选 “Web 应用”；
   - “已获授权的重定向 URI”填 `https://developers.google.com/oauthplayground`；
   - 创建后记下 **客户端 ID** 和 **客户端密钥**。
5. 打开 https://developers.google.com/oauthplayground ，在右上角齿轮里设置：
   - 勾选 “Use your own OAuth credentials”；
   - 填入上一步的客户端 ID 和密钥。
6. 在左边 “Input your own scopes” 一栏填入下面两行，点 Authorize APIs，用频道账号登录并同意：
   `https://www.googleapis.com/auth/youtube.upload https://www.googleapis.com/auth/youtube.force-ssl`
7. 点 “Exchange authorization code for tokens”，复制 **Refresh token**。
8. 回到 GitHub 仓库密钥，新建三个：`YT_CLIENT_ID`、`YT_CLIENT_SECRET`、`YT_REFRESH_TOKEN`。

关于“私密”：Google 审核通过之前，用接口上传的视频只能是私密的。每次上传后，要在 YouTube Studio 里检查一遍，再手动改成“公开”。想去掉这一步，可以在 Google 的 “YouTube API Services Audit” 表单申请审核，一般要几周。

### 4. B 站

B 站不对个人开放投稿接口。我们的做法：

- **现在**：每讲的中文成片、封面、标题简介，从 GitHub 下载后由 Eddie 在 B 站创作中心手动投稿。投稿时：
  - 分区选“知识 → 校园学习”；
  - 勾选“作者声明：使用 AI 合成技术”。
- **以后**：Eddie 在 B 站开放平台（open.bilibili.com）申请开发者和视频投稿权限，批下来后再接自动上传。具体名称以开放平台页面为准。

## 二、做视频（每讲）

1. **写讲稿**：Claude 写 `讲稿.yaml`，过独立 AI 审读后提交。
2. **生成**：在 GitHub → Actions → “Lecture videos 公开课视频” → Run workflow，按下表填：

   | 选项 | 填法 |
   |---|---|
   | task | render |
   | lectures | 讲稿目录 |
   | voice | clone（本人声音）；kokoro 是占位声音，只用于看排版 |
   | upload | none 或 youtube |

3. **下载**：约 1–2 小时后，在这次运行页面最下方的 Artifacts 下载 `videos`。每讲中、英文各一个文件夹，内容如下：

   | 文件 | 内容 |
   |---|---|
   | `lecture.mp4` | 成片，已烧录字幕 |
   | `lecture.srt` | 字幕文件 |
   | `cover_youtube.png`、`cover_bilibili.png` | 封面 |
   | `upload.md` | 标题、简介（含章节时间点）、标签、投稿设置 |

**试听**：task 选 audition，会用两种模型（Fun-CosyVoice3、CosyVoice2）各合成同一段中英文，结果加密后提交到 `docs/课程视频/声音样本/试听/`。2026-10-07 已选定 CosyVoice2；只在换样音时才需要重新试听。

## 三、常见问题

- **数字工厂录屏缺失**：画面会显示“素材待补”。把录屏文件放进 `docs/课程视频/素材/factory/` 后重做。
- **改了一句讲稿**：重新运行即可，只有改动的句子重新合成。
- **视频里的数字**：全部由教材程序算出，与书一致，讲稿里不手写。

## 把讲课视频挂到课程里（第 25 轮）

学生打开某一讲，最上面就是“讲课视频”：中文界面播放 B 站版，英文界面播放 YouTube 版，可切换，也能“在 B 站 / YouTube 打开”。课程导航里的“视频”页按讲列出全部视频。打开播放即记“已看”。

**公开课视频（课程包课程，如《缝纫机设计与制造》）**

1. B 站投稿审核通过、YouTube 视频设为**公开**后，把链接告诉 Claude（或自己在仓库里写）：`docs/课程视频/缝纫机/NN/链接.yaml`

   ```yaml
   bilibili: BV1xx411c7mD                       # B 站视频号（BV 开头），或整个网址
   youtube: https://www.youtube.com/watch?v=…   # YouTube 网址，或 11 位视频号
   ```
2. 推送上线后，到 **管理 → 课程包**，点“更新”。已发布的讲次会自动加上讲课视频；还没发布的讲次，发布时一起带上。

**其他课程的老师**

课程编辑里点“添加 → 链接 / 视频”，粘贴 B 站（`bilibili.com/video/BV…`）或 YouTube 网址即可，平台自动识别成可播放的视频。其他网址仍是普通链接。B 站短链接（b23.tv）请先在浏览器里打开，复制完整网址再粘贴。

**注意**：YouTube 上“私密”的视频别人看不了。接口未过 Google 审核前，自动上传的视频锁定为私密，英文版请在 YouTube Studio 手动上传并设为公开。
