网址：<https://wenquestrobotics.com/bearing/>（官网“解决方案 → 行业专用软件 → 轴承设计与制造”，产品页 `/cases/bearing.html`；国内版 `/solutions/bearing/`）。

现在能用的：深沟球轴承和角接触球轴承的设计校核（第 64 轮第 2 步），按典型应用场景加载和判强度（第 3 步），圆柱滚子轴承（第 4 步之一），单列圆锥滚子轴承（第 4 步之二）。高速、配对预紧、制造、FreeCAD 和 AI 在后面加入。

## 一、从头校核一个轴承

1. 点 **新建**，左上角改项目名称；左边最上面选 **深沟球轴承** 或 **角接触球轴承**。
2. **外形尺寸**：内径 d、外径 D、宽度 B。
3. **钢球与沟道**：
   - 钢球直径 Dw、球数 Z；节圆直径 dm 不填就按 (d + D)/2；
   - 内、外沟曲率系数 fi、fo = 沟道半径 ÷ 钢球直径，在 0.5 到 0.6 之间；
   - 深沟球轴承填初始径向游隙 Pd（直径方向）；角接触球轴承填接触角 α₀；
   - 内、外圈挡肩高度（从沟底量起）：用来检查接触椭圆会不会越过挡肩。
4. **材料**：弹性模量和泊松比（套圈和钢球同一种材料）。默认值是钢的常用值，请按实际材料改。
5. **载荷与转速**：径向力 Fr、轴向力 Fa、力矩 M、内圈转速 n（外圈不转）。
   - 不填力矩时，按轴把内圈扶正（不倾斜）计算，结果里给出轴承作用在轴上的力矩；
   - 填了力矩时，内圈自由倾斜到力矩平衡，结果里给出内圈倾角。
   - 角接触球轴承单独受纯径向力时没有平衡位置，要有轴向力。
6. **配合与温度**（深沟球轴承）：轴和座孔的过盈量（直径方向）、内外圈温度。软件按厚壁圆筒算出配合把游隙吃掉多少，再按内外圈温差算工作游隙；载荷分布按工作游隙算。
7. **润滑**：工作温度下润滑油黏度 η₀（Pa·s）、黏压系数 α（1/Pa）、两表面综合粗糙度 σ（µm）。
8. **校核限值**：许用接触应力、钢球最小间隙、套圈最小壁厚，按企业标准或客户要求填写。软件不替你编许用值，没填的项结果是“未知”。
9. 中间看图，右边看校核，点 **计算书** 打印或存成 PDF。

## 二、应用场景：轴承用在哪

左边最上面“应用场景 → 用在哪”。同一个轴承，装在不同的设备里，力怎么来、怎么变、按什么判都不一样，所以先选场景：

| 场景 | 填什么 | 软件替你算什么 |
| --- | --- | --- |
| 通用：直接填力 | 径向力、轴向力、力矩、转速 | — |
| 减速器齿轮轴 | 模数、齿数、压力角、螺旋角；齿轮到轴承 A 的距离、两轴承跨距；本轴承是 A 还是 B、哪个承受轴向力；几个工况（功率、转速、时间占比） | 分度圆、转矩、圆周力、径向力、轴向力，再按跨距分到本轴承（轴向力在节圆上产生的力偶也算进去） |
| 电机转子 | 转子质量、剩余不平衡量、带拉力与带轮位置和方向、轴向力、转速 | 重力、不平衡离心力、带拉力分到本轴承；不平衡随轴转，每 10° 算一次 |
| 机床主轴 | 悬伸、跨距；几个工况（切削径向力、轴向力、转速、占比） | 前、后轴承反力（悬伸放大前轴承的力），轴向力给前轴承 |
| 汽车轮毂 | 车轮载荷、转弯侧向加速度、滚动半径、两排间距、轮心面偏移；本轴承是外排还是内排；直行、左右转弯的时间占比 | 三个工况下每排的径向力和轴向力；外圈转；某排被提离时提示 |
| 机器人关节 / 摆臂 | 轴线水平或竖直、总重、力臂、两轴承间距（单个轴承不填）、摆角 | 竖直轴时的倾覆力矩（成对轴承分成一对径向力；单个轴承直接承受力矩） |
| 凸轮轴、缝纫机主轴 | 一圈内的力表（转角, Fx, Fy，可加 Fz），载荷位置、跨距、转速 | 每个转角下本轴承的力；画出一圈内的接触应力曲线 |

**载荷系数 fp**：按冲击程度从手册或企业规范取值，软件不替你编；不填时疲劳校核显示“未知”。

**两种强度判据**（“校核限值”里分别填）：
- **静强度**：取所有工况里接触应力最大的那个工况（名义载荷），对比“静强度许用接触应力”。低速、摆动、冲击峰值主要看这一项。
- **疲劳**：每个旋转工况的载荷乘 fp，取最不利的，对比“疲劳许用接触应力”。机器人关节这类摆动的场景，疲劳一项显示“不适用”，并提示小角度摆动容易产生伪布氏压痕。

额定寿命、静安全系数按国家标准，标准正文录入前显示“未知”。

中间“载荷从哪来”列出推导的每一步（公式和数值）和各工况结果表，接触应力最大的工况加底色标出；凸轮轴和电机画一圈内的应力曲线。计算书里同样有这一节。

## 三、圆柱滚子轴承

左边最上面选 **圆柱滚子轴承**（NU / N 型：只承受径向力）。

- **滚子与凸度**：滚子直径、滚子长度、有效接触长度（滚子长度减两端倒角）、滚子数、节圆直径、径向游隙。
- **滚子素线**：直线（无凸度）、全长圆弧（填凸度圆弧半径）、中间直线两端圆弧（再填中间直线段长度）、点表（每行“到滚子中点的距离, 降量”，可填实测值）。
- **内外圈相对倾斜**（角分）：轴的挠曲、座孔不同心引起，按实测或计算填，所有工况都按这个倾斜算。

计算方法是切片法：把有效长度分成 41 片，每片按 Palmgren 线接触变形公式承载（公式适用于钢），再按赫兹线接触算每片的接触应力。中间多一张“最重载滚子：沿长度的接触应力”曲线：凸度够时两端没有载荷；倾斜时峰值偏向一端。

多出的校核：
- **滚子两端不受载（凸度足够）**：端部切片有载荷就判不合格。切片法算不出受载端部的应力集中，所以软件不给那个数，直接提示加大凸度或减小倾斜；直线滚子会提示“需要凸度”。
- **轴向力、力矩**：NU / N 型不承受，出现就判不合格，提示改由别的轴承承受或改填倾斜。

示例“减速器输出轴圆柱滚子轴承”：倾斜 3′、中间直线两端圆弧凸度，两端不受载；把凸度圆弧半径改成 500 mm，就能看到端部受载、校核变红。

### 圆锥滚子轴承（单列）

选 **圆锥滚子轴承**，在“滚子与凸度”里填：滚子平均直径、滚子长度、有效接触长度、滚子数、节圆直径、外圈（杯）滚道角 α（即接触角）、内圈（锥）滚道角、挡边推力方向（不填按垂直挡边面、沿滚子轴线）、滚子大端球基面半径；凸度和倾斜与圆柱滚子相同。

- 每个滚子受外圈、内圈、挡边三个力，按力的平衡算出内圈接触力和挡边力（与外圈接触力成比例）。
- 单列圆锥滚子轴承受径向力时必须有轴向力，否则内圈会被推出来，软件会提示填轴向力或配对使用。在“减速器齿轮轴”场景里，把本轴承设为承受轴向力的固定端即可。
- 轴向游隙在安装时调整，这里按零游隙计算；配对和预紧在第 4 步之三加入。
- 多出的结果：最大挡边力、挡边接触应力（滚子大端按球面、挡边按平面近似，填了球基面半径才算），滚道下壁厚按滚子平均直径估算并注明“近似”。

示例“减速器斜齿轮轴圆锥滚子轴承（固定端）”（虚构）。

## 四、图怎么看

- **剖面**：过轴线的半剖面，套圈打剖面线。蓝色虚线是最重载钢球的工作接触线，旁边写着工作接触角；两段黄色粗弧是内、外圈接触椭圆的长轴范围。没填挡肩高度时，图上的挡肩只是示意，下方会提示“未知”。
- **钢球载荷**：正视图，径向力向下（红箭头）。钢球颜色越深载荷越大，外圈外面的棕色短线长短与载荷成正比，虚线圆圈表示不受载的钢球；最重的钢球旁写着载荷值。
- **游隙链**（深沟球轴承）：初始 → 内圈配合 → 外圈配合 → 温差 → 工作，单位 µm；工作游隙为负说明被预紧了。
- **故障特征频率**：转频、保持架 FTF、外圈 BPFO、内圈 BPFI、钢球自转 BSF（Hz），做振动诊断时用来对频谱。
- **最重载钢球**：载荷、工作接触角、内外圈接触椭圆半轴。

## 五、校核项说明

| 校核 | 怎么算 | 需要填 |
| --- | --- | --- |
| 相邻钢球间隙 | 节圆上相邻两球心的弦长减球径 | 可选：最小间隙限值 |
| 内、外圈沟底壁厚 | 沟底直径与内径 / 外径之差的一半 | 可选：最小壁厚限值 |
| 沟道口宽度小于套圈宽度 | 挡肩高度处沟道的宽度 | 挡肩高度 |
| 工作游隙 | 初始游隙减去配合吃掉的量，再加温差的影响；为负判不合格（深沟球轴承被预紧） | 配合过盈量、温度 |
| 最大钢球载荷、受载钢球数 | 静力学载荷分布：套圈刚性、低速，不计离心力和陀螺力矩 | 载荷 |
| 静强度：内、外圈最大接触应力 | 赫兹点接触，椭圆积分精确解；接触应力最大的工况 | 静强度许用接触应力 |
| 疲劳：内、外圈最大接触应力 | 各旋转工况 × 载荷系数 fp，取最不利 | 载荷系数 fp、疲劳许用接触应力 |
| 接触椭圆不越过挡肩 | 工作接触角加椭圆长半轴对应的角度，小于挡肩对应的角度 | 挡肩高度 |
| 最小油膜厚度、λ | Hamrock–Dowson 公式，最重载钢球的内圈接触 | 转速、黏度、黏压系数、粗糙度 |
| 额定动、静载荷与寿命 | 按 GB/T 6391、GB/T 4662、ISO 16281 | 标准正文录入前一律“未知” |

总结论取最差的一项：有不合格就是“不合格”；没有不合格但有“未知”，就是“有项目缺数据，暂不能判定合格”。

## 六、示例

顶部 **示例** 里有两个，尺寸和参数都是虚构的，不是任何厂家或标准中的型号：

- 减速器输入轴深沟球轴承：径向力加少量轴向力，轴过盈配合、内外圈有温差；
- 主轴角接触球轴承：轴向力为主的联合载荷，8000 r/min；
- 六个应用场景各一个：减速器中间轴（三个工况）、电机转子（带传动、不平衡）、铣床主轴前轴承（精铣、粗铣）、轮毂轴承外排（反例：直行够、转弯超限）、机器人肩关节（竖直轴、摆动）、缝纫机凸轮轴（一圈内变化的力）。示例里的限值和载荷系数也是虚构的。

## 七、方法与依据

Harris & Kotzalas《Rolling Bearing Analysis》第 5 版（几何、载荷分布、运动学）；Johnson《Contact Mechanics》（赫兹接触）；Hamrock & Dowson《Ball Bearing Lubrication》（点接触油膜）；Dowson & Higginson《Elasto-hydrodynamic Lubrication》（线接触油膜）；Palmgren《Ball and Roller Bearing Engineering》（线接触变形，经 Harris & Kotzalas 引用）；配合按厚壁圆筒（Lamé）。每个计算模块带标准题，和闭式解或公开公式对照（`services/bearing/tests/`）。
