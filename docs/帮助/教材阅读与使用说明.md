# 问渠教材阅读与使用说明（2026-10-01 起）

问渠自编教材在平台上直接阅读。第一本是《机器人学》，正在逐章编写，写好一节，上线一节。

## 阅读

1. 登录后，左侧点 **教材**，打开《机器人学》。
2. 左边是目录，按篇、章、节排列：
   - 点章名展开这一章的各节；
   - 已经写好的节可以点开；
   - 还没写的节标“待写”，是灰色。
   手机上点上方的 **☰ 目录** 打开目录。
3. 右边是正文。公式、插图都在正文里直接显示；“动画”“虚拟实验”的位置目前是虚线框，做好后会换成可以播放、可以操作的内容。
4. 每节末尾有上一节、下一节的链接。
5. 算例后面的“程序”框：点开能看到计算这个算例的 Python 程序，下面是程序的运行结果。书中的数字都由这些程序算出。

## 下载 PDF（老师）

有建课权限的老师，在正文上方会看到 **⤓ 本章 PDF**，点一下下载整章的 PDF，可以打印或发给学生。下载链接一小时内有效，过期再点一次即可。

学生看不到 PDF 按钮，在平台上阅读。

## 给编写者

教材的源文件在仓库的 `textbook/` 目录，写法和检查规则见 `textbook/README.md`。推送到 main 后，系统自动检查、生成网页和 PDF 并上线。任何一项检查不通过，都不会上线。
