# 问渠教材阅读与使用说明（2026-10-01 起）

问渠自编教材在平台上直接阅读。目前有三本：《机器人学》、《大学物理》和《线性代数》（后两本 2026-10-02 起），都在逐章编写，写好一章，上线一章。《线性代数》先上线的是样章第 18 章“奇异值分解”。

## 阅读

1. 登录后，左侧点 **教材**，在书架上选一本书打开。
2. 左边是目录，按篇、章、节排列：
   - 点章名展开这一章的各节；
   - 已经写好的节可以点开；
   - 还没写的节标“待写”，是灰色。
   手机上点上方的 **☰ 目录** 打开目录。
3. 右边是正文。公式、插图都在正文里直接显示。
   - **动画**在正文里直接点播放，有中英字幕。新写的动画上线后由服务器自动制作，通常几分钟到半小时，这期间显示“动画制作中”。
   - **虚拟实验**处有两个按钮：**▶ 在本页运行**，实验就在正文里展开，做完再点一次收起；**↗ 打开实验**，在新页面打开本章的实验页，并直接跳到这个实验（屏幕小或想同时看正文和实验时用）。实验在浏览器里直接做，不用装软件；每个实验有几个任务，做到了自动打勾。任务进度只保存在当前这台设备的浏览器里。
   - 《线性代数》的实验多用“线性变换演示台”：拖动矩阵元素，看平面网格和单位圆怎样变形，读出奇异值、特征值等；图像类实验（如第 18 章的低秩逼近）直接在浏览器里对图像做矩阵分解，第一次打开要算一两秒。
   - 有的实验是三维的（例如第 12 章的 UR5e、SCARA）：用的是问渠零件库里的真实机器人模型，鼠标拖动可以转动视角，滑块控制各关节。第一次打开需要几秒钟加载模型。
   - 有的实验带电路仿真器（例如第 39 章的应变片电桥、自动检测工位）：实验区上方是可编辑的电路图，鼠标移到导线上可以看电压，双击元件可以改参数；下方是虚拟仪表和报告。电路仿真器是开源的 CircuitJS，已内置在页面里，不需要联网。
   - 按钮旁边有“实验指导书（Word）”和“实验报告模板（Word）”两个下载链接。指导书写明实验原理、步骤、数据表、注意事项和思考题；报告模板按平台统一的格式（八栏正文、AI 使用声明、评分量规），学生填好后在“作业”中上传。
   - 手机微信小程序里，动画显示封面，实验显示提示，请在网页端观看、操作和下载指导书。
   - 每章开头有“本章提要”，末尾有“本章小结”：速查表、历史注记和参考文献。
   - **本章互动资源**：每章的第一页（本章提要）上方列出本章全部的动画和虚拟实验，点一下就跳到正文中它所在的位置。
   - **全书互动资源**：目录上方的 **◆ 互动资源**，按章列出全书的动画和实验，每项一句话说明，老师上课时可以直接从这里调用。
4. **中文 / English**：目录上方可以切换正文语言，选择会记在这台设备上。已出英文版的章（目前第 4、12、39 章）显示英文正文、英文插图、英文实验文档（Word）和英文 PDF；动画本来就有中英字幕；实验页打开时为英文界面。还没有英文版的节，切到 English 时显示中文，并在上方注明“英文版待出”。
5. **章的状态**：章名旁的小标签表示这一章到了哪一步：草稿、AI 审稿、初审、团队审阅、定稿。审阅团队请以标签为准，确认读的是哪一稿。
6. 每节末尾有上一节、下一节的链接。
7. 算例后面的“程序”框：点开能看到计算这个算例的 Python 程序，下面是程序的运行结果。书中的数字都由这些程序算出。

## 下载 PDF（老师）

有建课权限的老师，在正文上方会看到 **⤓ 本章 PDF**，点一下下载整章的 PDF，可以打印或发给学生。切到 English 时下载的是英文版 PDF（该章有英文版时）。审阅团队审稿也用这两种 PDF：在 PDF 上批注，交 Eddie 汇总。下载链接一小时内有效，过期再点一次即可。

学生看不到 PDF 按钮，在平台上阅读。

## 给编写者

教材的源文件在仓库的 `textbook/` 目录，写法和检查规则见 `textbook/README.md`。推送到 main 后，系统自动检查、生成网页和 PDF 并上线。任何一项检查不通过，都不会上线。
