# 问渠教材阅读与使用说明（2026-10-01 起）

问渠自编教材在平台上直接阅读。第一本是《机器人学》，正在逐章编写，写好一节，上线一节。

## 阅读

1. 登录后，左侧点 **教材**，打开《机器人学》。
2. 左边是目录，按篇、章、节排列：
   - 点章名展开这一章的各节；
   - 已经写好的节可以点开；
   - 还没写的节标“待写”，是灰色。
   手机上点上方的 **☰ 目录** 打开目录。
3. 右边是正文。公式、插图都在正文里直接显示。
   - **动画**在正文里直接点播放，有中英字幕。新写的动画上线后由服务器自动制作，通常几分钟到半小时，这期间显示“动画制作中”。
   - **虚拟实验**处有“打开实验”按钮，在新页面打开本章的实验页，并直接跳到这个实验。实验在浏览器里直接做，不用装软件；每个实验有几个任务，做到了自动打勾。任务进度只保存在当前这台设备的浏览器里。
   - 手机微信小程序里，动画显示封面，实验显示提示，请在网页端观看和操作。
   - 每章开头有“本章提要”，末尾有“本章小结”：速查表、历史注记和参考文献。
4. 每节末尾有上一节、下一节的链接。
5. 算例后面的“程序”框：点开能看到计算这个算例的 Python 程序，下面是程序的运行结果。书中的数字都由这些程序算出。

## 下载 PDF（老师）

有建课权限的老师，在正文上方会看到 **⤓ 本章 PDF**，点一下下载整章的 PDF，可以打印或发给学生。下载链接一小时内有效，过期再点一次即可。

学生看不到 PDF 按钮，在平台上阅读。

## 给编写者

教材的源文件在仓库的 `textbook/` 目录，写法和检查规则见 `textbook/README.md`。推送到 main 后，系统自动检查、生成网页和 PDF 并上线。任何一项检查不通过，都不会上线。
