# 数字工厂英文版：怎么切换语言

第 130 轮起，数字工厂（factory、pcb.factory、chip.factory 等）有英文界面。

## 默认是哪种语言

- **美国站**（wenquestrobotics.com 的各个子域名）：默认**英文**，不管浏览器是中文还是英文。
- **国内站**（wenquestech.online）：默认**中文**，和原来一样。
- 自己电脑上（localhost）：默认英文。

## 怎么切换

- 进了工厂：顶栏右边“帮助”左侧有 **中文 / EN** 两个按钮，点一下整页就换过来。
- 登录页：卡片右上角也有 **中文 / EN**。
- 切过一次，这台电脑、这个浏览器会记住（存在浏览器里）；以后打开还是你选的语言。想回到按站点的默认，清掉浏览器里这个网站的数据就行。

## 现在哪些已经是英文

- **第一批**：外壳与导航、登录页、首页总览、3D 车间、电路分析、虚拟仪器、电路板设计（含固件）、芯片设计、功能测试台、零件与机器人库，以及五座厂的厂名、设备名、物料名。
- **第二批**：工厂运营各页（订单与计划、设计与工艺、车间、质量与 8D、设备维护、人员、采购与来料、能源、安全环保、经营与财务、客户与服务、情景导演、我的任务）、厂情中枢各页（总览、全貌地图、规则目录、推演工作台、动作收件箱、AI 运行记录、提醒、日报周报、对象页），以及全部实验任务页（实验 7、实验 15–31 的任务说明、提示和选项）。

还是中文、第三批再做的：
- 后台写的文字：AI 今日简报和提议、厂情中枢的异常标题和原因、规则说明、设备停机原因、投诉和隐患记录、情景导演的旁白、实验的判分反馈、Word 计算书和实验记录；演示员工的姓名；
- 帮助与实验指导；工程软件（仿真与分析、数控编程、流体、优化、运动与动力、数字孪生、虚拟 PLC）。
- 固件源码里的注释是代码的一部分，不翻译。

英文还没有的地方会显示中文，不会空白或出错。英文用词见 `factory/digital/docs/术语表_英文.md`。
