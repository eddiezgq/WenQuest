# 评价系统与校情中枢演示（第 83 轮）

面向高校的本科教学审核评估、专业认证、校内教学评估。数据全部是模拟的（一门《大学物理（上）》、30 人模拟班）。

## 打开

- 评价系统：https://wenquestrobotics.com/eval/ ——三个标签：学生端（8 步、成绩单）、教师端（终审队列、照抄型样例 S006）、学校端（课程目标达成度、报告下载）。
- 校情中枢：https://wenquestrobotics.com/xq/ ——三个学院、六个专业的毕业要求看板（红 = 低于 0.70）；点专业看指标点明细；改进任务可“下达”（演示，不保存）。
- 首页“问渠全貌 → 学习平台与课程”里各有一张卡。

## 报告（网页 + Word）

| 报告 | 谁出 | 位置 |
|---|---|---|
| 课程目标达成情况评价报告 | 问渠（课程层） | `/eval/课程目标达成情况评价报告.html`、`.docx` |
| 课程教学质量报告 | 问渠（课程层） | `/eval/课程教学质量报告.html`、`.docx` |
| 毕业要求达成情况评价报告 | 校情中枢（专业层） | `/xq/毕业要求达成情况评价报告.html`、`.docx` |

改进措施在演示稿里由规则生成；正式版由 AI 起草，都要教师确认。

## 重新生成

```bash
python3 services/eval/r5/pipeline.py      # 评价流水线（11 条规则检查）

```
