2026-09-28 · 给新窗口（新会话）接手用。先读本文件，再读 `docs/实施细则/` 里最新一轮。（本文件已放入 GitHub 仓库，路径均为仓库内路径。）

## 一、项目是什么

问渠 WenQuest：AI 原生的学习管理系统。自研前端（uni-app，网页 + 微信小程序）＋ 接口网关（FastAPI）＋ Moodle 5.2 作为无界面的后台引擎。同时服务两个对象：

- 美国机器人学院（wenquestrobotics.com），中英双语；
- 国内高校推介（国内部署只用已备案模型，Claude 只用于美国）。

## 二、工作规则（务必遵守）

1. **先定方案，再施工**：每轮改动先写进《实施细则 · 第 N 轮》，用户确认后才动手；施工严格按细则，偏差要写回细则。
2. **文档体系**：总方案（持续修订）＋ 每轮实施细则 ＋ 帮助文件（随功能编写）。
3. **AI 原生**：老师的资料再乱，也由 AI 整理；没有资料只给要求，也要能建课。
4. **课程标准**：一门课要完整（内容、PPT、视频、作业、测验、考试）；理工科每节课“实际问题 → 概念 → 动画 → 虚拟实验 → 建模求解”；3Blue1Brown（Manim）风格动画；课件中英对照；每个实验有指导书和报告模板。
5. **实际问题**：以机器人例子为主，保留一个生活例子。
6. **沟通**：用户是中文母语，回复用中文，结论先行、少术语。

## 五、代码要点（给接手的开发者）

- `services/gateway/app/`：`main.py`（全部接口）、`moodle.py`（Moodle 客户端，内部地址连接并带 Host 头以通过 wwwroot 校验）、`course_builder.py`（AI 建课）、`materials.py`（资料提取与分类）、`ai.py`（Claude / DeepSeek / fake 三种模型接入）、`multilang.py`（中英内容解析）。
- `plugins/local_wenquest/`：自研 Moodle 插件（0.4.0），`create_course` 一次事务建整门课（页面、链接、作业、文件资源，可设学生不可见）。
- `apps/web/src/pages/create/create.vue`：AI 建课与上传资料建课界面。
- 名称用 `<span lang class=multilang>`，正文 HTML 用 `{mlang}`（需 filter_multilang2），网关按用户语言解析。
- 本地测试环境的坑：Moodle 要求请求 Host 与 wwwroot 一致；PHP 本地上传上限要调到 200M；不要用 `pkill -f <含命令行里出现的词>`，会把自己的 shell 杀掉。
