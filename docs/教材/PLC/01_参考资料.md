# 《PLC 原理及实践》参考资料（v0.1，2026-10-03）

> 配合《PLC 原理及实践》提纲 v0.1。沿用 Eddie 对另几本书的要求：参考教材以国外高水平教材为主，每一章罗列全部参考资料。
>
> **用法**
> 1. 第一部分是**总书目**，每本书一个代号；第二部分**逐章列出**该章的参考资料：教材与专著（注明对应内容）、经典文献、标准、软件与数据。
> 2. **以国外高水平教材为主**；国内教材（第 K 组）只用来核对国内课程、考研和职业技能等级标准的覆盖面。
> 3. **只参照选材和深度**，文字、图、程序、习题全部原创。厂家手册只用来核对厂家写法（每章末“厂家对照”）。
> 4. 教材注“哪一部分内容”，不写章号。**写每一章之前逐条核对版本、章节和页码**，写进该章章末参考文献和 `textbook/plc/conventions/参考书目.md`。版次、年份不确定的注“最新版”，写章时核对；标准以写作时的现行版本为准。
