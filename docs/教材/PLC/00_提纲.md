# 《PLC 原理及实践》教材提纲（v0.1，2026-10-03）

> 定位：一本**高水平、全面、项目导向**的可编程控制器（PLC）教材。从一个按钮、一个接触器讲起，讲清 PLC 的硬件与扫描执行、IEC 61131-3 的五种编程语言、程序设计方法、模拟量与 PID、运动控制、工业通信、人机界面与 SCADA、机械安全与功能安全、工控网络安全、调试与**自动化测试**、虚拟调试，直到 IEC 61499、软 PLC 和 AI 辅助编程；最后用六个完整的工程项目把全书串起来。为机器人服务（机器人工作站、上下料、机器人与 PLC 的握手和直接控制），但不限于机器人——同样服务产线、包装、物流、过程控制、缝制设备和楼宇设备。一本书覆盖国内的“电气控制与 PLC”“PLC 原理及应用”“可编程控制器技术”“运动控制系统”“工业控制网络”“组态与 HMI”“机械安全”“自动化系统集成课程设计”，以及研究生的“分布式控制与工业 4.0”。内容全面，老师授课时自己取舍；同时是电气自动化工程师的案头参考书。先写中文，再出英文版。
> 做法与另几本书相同（见《实施细则 · 第 7–14 轮》）：一节一个源文件，算必有仿真，动画配示意图，每个实验有指导书和报告模板，章首提要、章末小结，独立 AI 审稿，Eddie 一章一审。
> **本书特有**：每次课都像电气自动化工程师一样工作——拿到一张任务单（被控设备、动作要求、安全要求、交期），交出工程师真正交付的一整套东西：I/O 表、电气原理图、PLC 程序、HMI 画面、**自动化测试用例与测试报告**、调试记录、操作维护说明；程序先在**浏览器 PLC 实验台**上对着**三维虚拟设备**跑通，再下载到**数字工厂**里控制仿真产线，最后可以导出到真实 PLC（见第一节第 9–12 条）。

## 一、写法（沿用另几本书；PLC 的补充见第 9–12 条）

1. **起点**：高中数学和物理，加上电路的最基本知识（欧姆定律、串并联）。用到的电工电子、电机、控制理论和网络知识，第一次用到时讲清，并注明“详见《大学物理》第 x 章 /《机器人学》第 x 章 /《缝纫机设计与制造》第 x 章”。
2. **循循善诱**：每一节从一台具体的设备出发（多半来自数字工厂的减速器产线、问渠零件库里的机器人和缝纫机教材里的自动单元），先用继电器电路或最朴素的程序试，看哪里不够（自锁丢了、两个线圈同时得电、急停后自己又启动），再自然地引出新方法。先看现象（扫描周期里信号怎样走、定时器为什么“晚了一拍”），后讲道理。
3. **叙述，不罗列**：正文用连贯的段落讲道理。指令表、参数表放在“速查”里，正文讲清它们从哪里来、怎么用、什么时候会出错。
4. **总结只放在章的首尾**：章首提要；章末小结（主线叙述 + 关键指令与设计步骤速查 + 历史注记 + 参考文献与标准）。节内不反复总结。
5. **完善每一个细节**：时序不跳拍；每条指令说清它在扫描周期哪一步生效；每个数字（响应时间、通信周期、PID 参数、安全距离、PL 等级）都能用程序复算；初学者容易弄混的地方单独讲透（如“输入映像”和“实际输入”、“线圈”和“置位”、“常开触点”和“常开按钮”、“源型”和“漏型”、“TON”和“TOF”、“功能”和“功能块”、“实例”和“类型”、“周期”和“循环时间”、“急停”和“停止”、“PL”和“SIL”、“仿真通过”和“现场可用”）。
6. **学术，但不晦涩**：语言书面、准确、克制；重要结论写成编号的**定义**、**定理**、**设计准则**；公式和程序按节编号，如 (15.3.2)、程序 15-4；交代方法的来龙去脉和局限。
7. **动画代替不了示意图，两个都要**。PLC 尤其如此：动画演示扫描周期、信号在梯形图里“流动”、SFC 的步怎样激活、报文在总线上怎样走；示意图标清时序、地址和接线。
8. **文风**：以《机器人学》样稿 4.1 为准。第一章写好后，Eddie 确认文风再往下写。
9. **PLC 特有：每节课都是一份工程工作**。每一章至少有一张**工程任务单**，学生按电气工程师、PLC 程序员、调试工程师、测试工程师的方式完成，交付工程文件而不是“作业答案”：
   - 任务单由老师（或 AI）在班级工厂里以“自动化任务”下达，写明被控设备（三维虚拟设备或数字工厂里的仿真设备）、动作与节拍要求、安全要求、交期、要交什么；
   - 交付物是现场真正用的东西：**控制要求说明（功能规格书）**、**I/O 分配表**、**电气原理图与接线图**、**PLC 程序（PLCopen XML 导出）**、**HMI 画面**、**自动化测试用例与测试报告**、**调试记录与问题清单**、**FAT/SAT 验收记录**、**操作与维护说明**；
   - 交付走**程序发布与审批**：提交 → **自动化测试先跑**（平台用测试用例驱动虚拟设备，逐条判定通过与否，含故障注入）→ **AI 程序评审员**再审（双线圈、未互锁、急停处理、扫描周期相关的竞态、命名与注释、PLCopen 编码规范，只提意见，可给建议分供老师参考，成绩由老师给）→ 老师批准或退回 → 批准的程序下载到数字工厂的**虚拟 PLC**，控制仿真产线运行一个班次 → 产量、节拍、报警、停机时间回到学生手里复盘，再提一次改进；
   - 不是每章都走完整条链；每个任务单标明经过哪些工位（见第 11 条）。
10. **PLC 特有：“设计、仿真、测试、调试”闭环**。同一个控制任务，先设计（I/O 表、时序图、状态图），再在实验台上仿真运行，再写自动化测试证明它对（包括故障和误操作），最后到数字工厂里“现场调试”——仿真产线会出传感器抖动、气缸卡滞、通信中断这些真实问题。讲清楚：仿真通过为什么不等于现场可用，测试用例怎样覆盖现场才会出的问题。
11. **PLC 特有：工具链标注**。每个实验和任务单标明用到的工具，读者一眼看出这节课在工厂的哪个工位（与另几本书的标记一致，新增的见《实施细则 · 第 18 轮》2.5 节，待确认）：

## 二、编写原则

1. **全面**：每章标出层次：
   - 【基础】本科“电气控制与 PLC”“PLC 原理及应用”必修（覆盖国内同名教材和职业技能等级标准的全部内容）；
   - 【进阶】“运动控制系统”“工业控制网络”“组态与 HMI”“机械安全”等专业课，工程师进修；
   - 【专题】IEC 61499、软 PLC、AI 辅助编程、综合项目，可整章跳过。
   第四节给出**课程路线表**，列出八种开课方式各用哪些章节。
2. **厂家中立，标准为本**：正文以 IEC 61131-3（第 3 版）和 PLCopen 为准，程序用标准语法；每章末附**厂家对照**：西门子 S7-1200/1500（TIA Portal）、三菱 FX5/iQ-R（GX Works3）、汇川 AM/H5U（InoProShop，基于 CODESYS）、罗克韦尔（Studio 5000）、CODESYS 的写法差异（地址、指令名、定时器、数据块），读者拿到任何一家的 PLC 都能上手。
3. **程序必能运行，测试必能复现**：书中每一段程序都在〔PLC〕实验台和〔RT〕运行时上跑过，附自动化测试用例；书里的时序图、响应时间、PID 曲线由程序生成，自动核对。
4. **设备必有三维模型，章章有任务**：每类被控对象都有一台〔VP〕三维虚拟设备（I/O 点与真实设备一致，带传感器噪声与故障注入）；每章配一张工程任务单。实验和任务单都有指导书、报告模板（工程任务单的“报告”就是工程文件、测试报告和评审记录）。
5. **项目导向**：每篇开头给一个**篇首项目**（一台设备从控制要求到验收），本篇各章的任务单是它的里程碑，篇末验收；第十一篇六个综合项目各是一整套工程交付。
6. **现场问题**：每章有“现场故障案例”——现象、排查过程、根本原因、整改、预防（如：设备偶尔不动作——输入滤波与扫描周期；急停复位后电机自己转——自锁与复位逻辑；计数少了——高速脉冲超过扫描能力；通信一断全线停——看门狗与降级运行）。
7. **数据和图与另几本书一致**：数字工厂减速器产线的工作中心、节拍、设备 I/O 与 MES 同源；机器人参数与零件库一致；缝制自动单元与《缝纫机设计与制造》第 12、13、20 章一致。
8. **术语**：以 GB/T 15969（IEC 61131）系列、GB/T 2900 电工术语和《电气工程名词》为准；同一中文术语的英文名在七本书里一致（术语一致检查扩展到本书）。
9. **图形符号**：电气图按 GB/T 4728 / IEC 60617，文字代号按 GB/T 5094 / IEC 81346；梯形图、功能块图、SFC 按 IEC 61131-3；国内教材常见的旧符号在“厂家与国内写法对照”里说明。

### 导论

**第 1 章 PLC 与工业自动化**【基础】

- 1.3 PLC 是什么、不是什么：与继电器、单片机、工控机、DCS、运动控制器、机器人控制器的分工
- 1.4 自动化金字塔与 ISA-95：传感执行层、控制层、监控层、MES、ERP——PLC 在中间
- 1.5 标准与生态：IEC 61131、PLCopen、IEC 61499、OPC UA；主要厂家与国产 PLC
- 1.6 电气自动化工程师做什么：一个项目从报价、设计、编程、FAT、现场调试到 SAT 和维护
- 1.7 本书怎样用：实验台、三维虚拟设备、数字工厂、工程任务单和自动化测试
- 配套：
  - 动画：继电器柜改成 PLC 柜——同一台设备，接线怎样变少、修改怎样变快；
  - 实验：第一次在实验台上写程序：一个按钮点亮一盏灯，再让它自锁〔PLC〕〔VP〕；
  - 工程任务：参观数字工厂减速器产线，列出每个工作中心的设备、传感器和执行器，交“产线自动化调研表”〔MES〕。

### 第一篇 控制基础与 PLC 硬件

> 篇首项目：**减速器产线的上料输送线**——从电气原理图、选型、I/O 表到第一个程序。本篇各章的任务单是它的里程碑。

**第 2 章 电气控制基础**【基础】
- 2.1 开关量与模拟量；控制电路与主电路
- 2.2 低压电器：按钮、开关、熔断器、断路器、接触器、热继电器、中间继电器、时间继电器
- 2.3 经典继电器控制电路：点动、自锁、互锁、正反转、星三角启动、顺序启动、多地控制
- 2.4 电气图的读与画：原理图、接线图、端子图；GB/T 4728 / IEC 60617 图形符号与 IEC 81346 代号
- 2.5 从继电器电路到逻辑：为什么继电器电路就是布尔表达式
- 2.6 电气柜：布置、接地、屏蔽、电源、散热与 IEC 60204-1 的基本要求
- 2.7 现场故障案例：接触器“打嗝”——自锁触点接触不良
- 配套：
  - 动画：电动机正反转电路，互锁触点怎样防止相间短路；
  - 实验：继电器电路仿真——搭正反转电路，故意拆掉互锁看后果〔PLC〕；
  - 工程任务：画上料输送线主电路和控制电路原理图（继电器版），交原理图与元件清单。

**第 3 章 PLC 硬件**【基础】
- 3.1 PLC 的组成：CPU、存储器、电源、I/O 模块、通信模块、背板总线
- 3.2 一体式、模块式与分布式 I/O；小型、中型、大型 PLC
- 3.3 数字量输入：源型与漏型、输入滤波、隔离、两线制与三线制传感器接线（IEC 61131-2）
- 3.4 数字量输出：继电器、晶体管、晶闸管输出；感性负载与续流、负载能力
- 3.5 模拟量 I/O：4–20 mA、0–10 V、热电阻与热电偶、分辨率与精度
- 3.6 特殊模块：高速计数、脉冲输出、称重、温度控制
- 3.7 PLC 选型：点数、余量、速度、通信、安全、成本——一张选型计算书
- 3.8 现场故障案例：传感器亮了、PLC 没收到——源型漏型接反
- 配套：
  - 动画：源型与漏型接线中电流的流向；
  - 实验：在实验台上为三线制光电开关、电磁阀、4–20 mA 液位计接线并验证〔PLC〕〔VP〕；
  - 工程任务：上料输送线 PLC 选型与 I/O 分配表、PLC 接线图〔PY〕。

**第 4 章 扫描周期与执行模型**【基础】
- 4.1 循环扫描：读输入、执行程序、写输出、通信与诊断
- 4.2 输入映像与输出映像：程序看到的“现在”是哪一刻
- 4.3 扫描时间、看门狗与循环时间监控
- 4.4 响应时间：输入滤波 + 扫描 + 输出延迟，最坏情况怎样算
- 4.5 任务：循环任务、周期任务、事件与中断任务，优先级与抢占（IEC 61131-3 任务模型）
- 4.6 扫描带来的“怪事”：双线圈、一拍延迟、边沿丢失、程序顺序决定结果
