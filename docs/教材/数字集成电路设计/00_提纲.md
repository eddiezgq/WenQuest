> 定位：微电子专业的核心课教材。从一个 CMOS 反相器讲起，讲清门电路、时序元件、互连线、功耗、算术电路、存储器、时钟与时序、标准单元与版图、工艺偏差与可靠性，直到用开源工具把一个模块从 RTL 做到可流片的版图。所有数字基于开源工艺 SKY130：书中的参数由 SPICE 校准，书中的计算由程序给出，实验在浏览器或问渠微电子实验镜像里做。实际问题以机器人为主（关节电机驱动、编码器、传感器接口、控制芯片），每节保留一个生活中的例子。先写中文，再出英文版。

## 一、写法

1. **起点**：学过数字电子技术（逻辑门、触发器、状态机）和电路原理；半导体器件物理可以同时修。用到的器件知识在第一次出现时讲清，并注明“详见《半导体器件物理》第 x 章”（该书在第二批）。
2. **循循善诱**：每一节从一个具体的机器人问题出发（关节驱动板的光耦输入、编码器抗干扰、电机控制芯片的时钟、驱动大负载、巡线小车的功耗……），先用最朴素的电路试，看哪里不够，再引出新方法。先看现象，后讲道理。
3. **叙述，不罗列**：正文用连贯的段落；参数表、单元库数据放在“速查”里。
4. **总结只放在章的首尾**：章首提要；章末小结（主线叙述 + 关键公式与设计步骤速查 + 历史注记 + 参考文献）。
5. **一个模型贯穿全书**：第 1 章按 SKY130 校准的长沟道模型（`labs/micro/kit/models`，浏览器实验与书中程序共用）是全书的“手算模型”；每章都把手算结果和 SPICE 或综合、时序工具的结果对照，讲清模型在哪里够用、在哪里失效——这本身是教学内容（第 1 章已这样做）。
6. **学术，但不晦涩**：重要结论写成编号的**定义**、**设计准则**；公式和程序按节编号，如 (4.2.3)、程序 4-2。
7. **动画代替不了示意图，两个都要**：动画演示电荷怎样流动、信号怎样在链上传播、时钟沿怎样推进流水线；示意图标清尺寸、节点和时序。
8. **文风**：以《机器人学》样稿 4.1 为准；第 1 章成书后，Eddie 确认文风再往下写。

## 二、编写原则

1. **全面**：每章标出层次——【基础】本科“数字集成电路设计”必修内容（覆盖国内同名教材）；【进阶】研究生和设计工程师；【专题】可整章跳过。
2. **工艺为本，数字可复算**：全书用 SKY130（1.8 V、L = 0.15 μm）；器件参数、单元库数据取自开源 PDK，书中每个数字由程序算出并自动核对。其他工艺节点（如 IHP SG13G2、GF180）在“工艺对照”里出现，讲清趋势。
3. **实验分两档**：浏览器档（自写模型、ngspice 与 Yosys 的 WebAssembly 版，电脑手机都能做）和镜像档（Magic、KLayout、Netgen、LibreLane、OpenSTA，在问渠微电子实验镜像里做）。每章至少一个浏览器档实验；镜像档实验标【镜像】，在线容器服务上线前由教师演示或学生在电脑上装镜像做。
4. **每个实验按 R4**：3–4 个自动判定任务 + 1 个开放问题，配指导书（R7）和报告模板（R8），中英对照。
5. **术语**：以《微电子学名词》和 GB/T 相关标准为准；同一中文术语的英文名在问渠各书一致（术语一致检查扩展到本书）。
6. **参照书**：Rabaey 等《Digital Integrated Circuits: A Design Perspective》、Weste 与 Harris《CMOS VLSI Design》、Sutherland 等《Logical Effort》、国内同名教材；逐章参考资料列在 `01_参考资料.md`（随第 1 章成书时写）。

## 三、提纲

### 第一篇 基础

**第 1 章 CMOS 反相器**【基础】
- 1.1 MOSFET 开关与 CMOS 反相器
- 1.2 电压传输特性与噪声容限
- 1.3 尺寸与对称
- 1.4 传播延时与反相器链
- 1.5 功耗
- 配套（第 2 步已做）：
  - 动画 5 段：开关路径、传输特性扫描、尺寸与对称、反相器链、功耗；
  - 实验（浏览器）5 个：光耦输入、编码器抗干扰、时钟缓冲、驱动大负载、巡线小车控制芯片；
  - 实验（镜像）：反相器版图，DRC 与 LVS。

**第 2 章 组合逻辑门**【基础】
- 2.1 静态 CMOS 门：与非门、或非门与复合门的串并联结构
- 2.2 门的尺寸：等效反相器与最坏情况
- 2.3 逻辑努力：电气努力、逻辑努力与最优级数
- 2.4 有比逻辑与传输管逻辑
- 2.5 动态逻辑与多米诺逻辑【进阶】
- 配套：
  - 动画：串联 NMOS 为什么慢——两个开关串起来的电阻；逻辑努力的“路径努力”怎样分摊；
  - 实验（浏览器）：逻辑努力计算器——给电机控制芯片的地址译码器选级数和尺寸，与 ngspice 结果对照；
  - 实验（镜像）：二输入与非门版图（贯通项目步骤二，与 SKY130 标准单元比较）。

**第 3 章 时序元件**【基础】
- 3.1 锁存器与触发器：结构与时序参数（建立、保持、时钟到输出）
- 3.2 时序约束：建立时间与保持时间的推导
- 3.3 亚稳态与同步器：为什么异步输入要打两拍
- 3.4 时钟门控与复位【进阶】
- 配套：
  - 动画：亚稳态——触发器在两个稳态之间“犹豫”；
  - 实验（浏览器）：同步器 MTBF——编码器信号进入控制芯片，选同步级数使平均故障间隔达标。

**第 4 章 互连线**【基础】
- 4.1 导线的电阻与电容：SKY130 各金属层的参数
- 4.2 RC 延时：Elmore 延时与分布式 RC 线
- 4.3 插入缓冲器：长线怎样变快
- 4.4 串扰与耦合【进阶】
- 4.5 电感与传输线效应【专题】
- 配套：
  - 动画：信号沿分布式 RC 线“扩散”而不是“传播”；
  - 实验（浏览器）：长线与中继器——电机控制芯片里横跨芯片的时钟线，选中继器的个数和尺寸使延时最小。

### 第二篇 性能、功耗与运算

**第 5 章 功耗与低功耗设计**【基础】
- 5.1 动态功耗与短路功耗（接第 1.5 节）
- 5.2 漏电：亚阈值漏电、栅漏电与温度
- 5.3 降压与频率调节（DVFS）
- 5.4 时钟门控与电源门控
- 5.5 功耗分析的流程【进阶】
- 配套：
  - 实验（浏览器）：电池供电的巡检机器人——在性能约束下选电压、频率和门控策略，使续航最长。

**第 6 章 算术电路**【基础】
- 6.1 加法器：行波进位、超前进位、进位选择
- 6.2 并行前缀加法器【进阶】
- 6.3 乘法器：阵列乘法器与 Booth 编码
- 6.4 移位器与比较器
- 配套：
  - 动画：进位怎样一位一位“走”过行波进位加法器；
  - 实验（浏览器，Verilog）：电机速度控制器里的 16 位加法器——比较三种结构的延时与面积（Yosys 综合到 SKY130 单元）。

**第 7 章 存储器**【基础】
- 7.1 存储器的组织：阵列、译码与灵敏放大
- 7.2 SRAM 单元：读稳定与写能力
- 7.3 寄存器堆与 FIFO
- 7.4 非易失存储器概览【专题】
- 配套：
  - 动画：SRAM 读操作——位线放电与灵敏放大器翻转；
  - 实验（浏览器，ngspice）：6 管 SRAM 单元的蝴蝶曲线与静态噪声容限，调尺寸比使读写都可靠。

**第 8 章 时钟与时序分析**【基础】
- 8.1 同步系统的时序：时钟周期、偏斜与抖动
- 8.2 静态时序分析：路径、余量与关键路径
- 8.3 流水线与重定时
- 8.4 时钟树与时钟分布【进阶】
- 8.5 跨时钟域【进阶】
- 配套：
  - 动画：时钟沿推进流水线，关键路径“卡住”整个系统；
  - 实验（浏览器）：时序分析器——找出电机控制芯片里的关键路径，插入流水线使 50 MHz 达标；
  - 实验（镜像）：用 OpenSTA 读真实布线后的时序报告。
