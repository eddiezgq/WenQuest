## 一、写法（沿用《机器人学》提纲第一节；本书的补充见第 9–13 条）

1. **起点**：会 C/C++ 和 Python 编程，学过线性代数。概率统计、多元微积分（链式法则、梯度）、计算机体系结构（缓存、流水线）第一次用到时从头讲清，附录速查。
2. **循循善诱**：每一节从一个具体的问题出发——一段跑得太慢的程序、一个训练不收敛的模型、一项改变了某个行业的成果——先用最朴素的办法试，看哪里别扭，再自然地引出新概念。先直观、后严格。
3. **叙述，不罗列**：正文用连贯的段落讲道理。下面“每节的结构”是写作时内部的顺序，不是每节都出现的小标题。
4. **总结只放在章的首尾**：章首提要；章末小结（主线叙述 + 关键概念与公式速查表 + 历史注记 + 参考文献）。节内不反复总结。
5. **完善每一个细节**：推导不跳步；每个记号说明含义和单位；每个数字都能用程序复算；行主序还是列主序、张量的维度顺序、FLOPs 是否把乘加算作两次这类约定写明白；初学者容易弄混的地方单独讲透（如“线程”与“核心”、“显存带宽”与“PCIe 带宽”、“参数量”与“激活量”、“训练”与“推理”的瓶颈为何不同）。
6. **学术，但不晦涩**：语言书面、准确、克制；重要内容写成编号的**定义**、**定理**，给出推导；公式按节编号，如 (5.8.2)；交代概念的来龙去脉（谁、哪一年、为解决什么问题）。
7. **动画代替不了示意图，两个都要**：每个动画都配一张由程序画出的静态示意图，PDF 里只有图也能读懂。
8. **文风**：以《机器人学》样稿 4.1 为准。第 1 章写好后，Eddie 确认文风再往下写。
9. **本书特有：数量级贯穿全书**。每章至少一处“算一算”：一次前向传播多少次乘加、一个模型要多少显存、一块 GPU 一秒能做多少次运算、训练一个大模型要多少度电。先用量级估出答案，再用程序精确计算，对照两者。人工智能的许多“为什么”，答案就在数量级里。
10. **本书特有：性能必须实测**。上篇每个 CUDA 程序都给出在指定 GPU 上的实测时间和吞吐量，并与理论峰值、Roofline 上限对照；书中的性能数字由程序在云端 GPU 上测出，注明 GPU 型号、驱动和 CUDA 版本，不抄厂商宣传数字。
11. **本书特有：上下两篇互相回扣**。下篇每章“算力与工程”一段写明该应用用了什么模型、多大规模、多少算力、靠上篇哪些技术才成为可能（注明“见 x.y 节”）；上篇讲技术时，也指出它在下篇哪个应用里起了决定作用。
12. **本书特有：应用案例写实，不神化**。下篇每项成果都交代问题本来有多难、此前的方法做到哪里、AI 方法究竟改进了多少（用原始论文或权威评测的数字）、还有哪些局限和争议、付出了什么代价（数据、算力、能耗）。不写“颠覆”“革命性”这类词，让数字说话。
13. **本书特有：前沿内容注明时间**。模型、芯片、榜单、法规变化快，凡这类内容在正文注明“截至 2026 年某月”，每次再版前更新；写每章前联网核对最新情况。原理性内容（反向传播、SIMT、注意力）写成不随时间过时的样子。

## 二、编写原则

1. **全面**：每章标出层次，方便老师取舍：
   - 【基础】本科“人工智能导论”“深度学习”“GPU 并行编程”课程的必修内容；
   - 【进阶】本科选讲或研究生“高性能计算”“大模型系统”课程；
   - 【专题】应用与前沿，可整章跳过。
   第四节给出**课程路线表**，列出七种开课方式各用哪些章节。
2. **算必有仿真**：每个算例都有可运行的程序，复现书中每个数字；书里的数由程序填入，自动核对。需要 GPU 的程序，构建时读取云端实测记录（带 GPU 型号与时间戳），并核对记录与程序版本一致。
3. **编程必有实验**：每段编程内容都配一个虚拟实验：
   - 不需要 GPU 的（NumPy 神经网络、注意力计算、调度与访存的可视化模拟）在浏览器里运行，不用装软件；
   - 需要 GPU 的（CUDA 核函数、PyTorch 训练、模型推理）在云端 GPU 容器里运行，打开即用的 Jupyter 环境，预装 CUDA 工具包、PyTorch、Triton、Nsight 命令行工具。
   每个实验有指导书、报告模板和自动检查。
4. **每节同一结构**（写作时的内部顺序）：
   - 上篇：
     1. 实际问题（多半是一段程序或一个模型遇到的事）；
     2. 概念与原理；
     3. 推导或分析；
     4. 算例与“算一算”；
     5. 程序与实测结果；
     6. 可视化与动画（3Blue1Brown 风格）；
     7. 虚拟实验；
     8. 生活中的例子；
     9. 工程师笔记（常见坑、调优经验、在昇腾和 ROCm 上的对应做法）；
     10. 习题（概念题、计算题、编程题、性能分析题四类）。
   - 下篇（每章统一）：
     1. 问题背景：问题本来有多难，此前做到哪里；
     2. 数据；
     3. 模型与方法；
     4. 算力与工程（回扣上篇）；
     5. 成果与影响（用原始数字）；
     6. 局限、风险与伦理；
     7. 案例实验（每章两个以上，可复现的小规模版本）；
     8. 习题（概念题、分析题、编程题、讨论题四类）。
5. **贯穿全书的案例与数据**：与问渠其他教材共用零件库模型和数字工厂数据：
   - 数字工厂减速器车间的零件图像（缺陷检测）、振动信号（预测性维护）、检测记录（质量数据）；
   - 零件库的 UR5e 机械臂、Unitree Go2 四足、差速 AGV、四旋翼（强化学习、具身智能、调度）；
   - 一个贯穿上篇的小型 Transformer（约一千万参数），从第 2 章的定义到第 9 章的训练和推理优化，都用它做算例，让读者看到同一个模型在每一层技术里的样子。
6. **自成体系**：本书用到的内容在本书讲完整，不依赖其他教材；与问渠其他教材只共用零件库模型和数字工厂数据。
7. **术语兼顾国内外**：英文术语第一次出现时中英并列（如“线程束（warp）”）；业界习惯用英文的（kernel、warp、Tensor Core）正文统一一个中文名并在术语表注明英文。术语以全国科学技术名词审定委员会《计算机科学技术名词》为准，没有收录的按业界通行译法，并在术语表登记。
8. **原创**：参照国外高水平教材、经典论文和官方文档（见《参考资料》），只参照选材和深度，文字、图、习题全部原创；插图全部重画，数据自己算、自己测。
9. **代码与版本**：CUDA C++ 以 CUDA 12.x 为准，Python 以 3.12、PyTorch 2.x 为准；每章开头注明所用版本。程序开源在问渠仓库，读者可在云端环境一键运行。

**篇幅估算**：32 章。上篇每章约 40 页（约 400 页），下篇每章约 30 页（约 660 页），全书约 **1060 页**（中文版），另附录约 80 页。可分上下两册：上册“人工智能与 CUDA”（第 1–10 章），下册“人工智能典型与成功应用”（第 11–32 章）。
