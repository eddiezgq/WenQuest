### 2.1 结构约束（论文原文五条，教材照抄这五条即可）

论文小标题为"Architecture guidelines for stable Deep Convolutional GANs"：

## 3. VAE（Kingma & Welling 2013）

论文：*Auto-Encoding Variational Bayes*，arXiv:1312.6114（ICLR 2014）。

### 3.1 ELBO 与重参数化（原式）

| 项目 | 原文形式 | 口径 | 类型 |
|---|---|---|---|
| 式 (1) | $\log p_\theta(x^{(i)}) = D_{KL}\!\left(q_\phi(z|x^{(i)})\,\|\,p_\theta(z|x^{(i)})\right) + \mathcal{L}(\theta,\phi;x^{(i)})$ | 边缘似然 = KL（不可算）+ 下界 | 论文正文（式 1） |
| 式 (2)（下界） | $\log p_\theta(x^{(i)}) \ge \mathcal{L}(\theta,\phi;x^{(i)}) = \mathbb{E}_{q_\phi(z|x)}\!\left[-\log q_\phi(z|x) + \log p_\theta(x,z)\right]$ | — | 论文正文（式 2） |
| **式 (3)（教材最常用的 ELBO 形式）** | $\mathcal{L}(\theta,\phi;x^{(i)}) = -D_{KL}\!\left(q_\phi(z|x^{(i)})\,\|\,p_\theta(z)\right) + \mathbb{E}_{q_\phi(z|x^{(i)})}\!\left[\log p_\theta(x^{(i)}|z)\right]$ | **"KL 正则项 + 重构项"这个讲法的原始出处就是式 (3)** | 论文正文（式 3） |
| 式 (4)（重参数化的一般形式） | $\tilde z = g_\phi(\epsilon, x)$，其中 $\epsilon \sim p(\epsilon)$ | — | 论文正文（式 4） |
| **重参数化技巧（高斯情形）** | 第 2.4 节原话："a valid reparameterization is $z = \mu + \sigma\epsilon$, where $\epsilon \sim \mathcal{N}(0,1)$"；第 3 节的 VAE 写成 $z^{(i,l)} = \mu^{(i)} + \sigma^{(i)} \odot \epsilon^{(l)}$，$\epsilon^{(l)} \sim \mathcal{N}(0, I)$ | **这就是 μ + σ⊙ε 的原文出处** | 论文正文（第 2.4、3 节） |
| 式 (6) SGVB 估计量 A | $\tilde{\mathcal{L}}^A = \frac1L\sum_l\left[\log p_\theta(x^{(i)},z^{(i,l)}) - \log q_\phi(z^{(i,l)}|x^{(i)})\right]$ | — | 论文正文（式 6） |
| 式 (7) SGVB 估计量 B | $\tilde{\mathcal{L}}^B = -D_{KL}\!\left(q_\phi(z|x^{(i)})\,\|\,p_\theta(z)\right) + \frac1L\sum_l \log p_\theta(x^{(i)}|z^{(i,l)})$ | B 式把 KL 解析算掉，方差更小 | 论文正文（式 7） |
| 式 (8) 小批估计 | $\mathcal{L}(\theta,\phi;X) \approx \frac{N}{M}\sum_{i=1}^{M}\tilde{\mathcal{L}}(\theta,\phi;x^{(i)})$ | — | 论文正文（式 8） |
| **式 (10)（可直接写进教材的 VAE 目标）** | $\mathcal{L} \approx \frac12\sum_{j=1}^{J}\left[1 + \log\big((\sigma_j^{(i)})^2\big) - (\mu_j^{(i)})^2 - (\sigma_j^{(i)})^2\right] + \frac1L\sum_l \log p_\theta(x^{(i)}|z^{(i,l)})$ | 高斯先验 + 高斯后验 | 论文正文（式 10） |
| 附录 B 的解析 KL | $-D_{KL}\!\left(q_\phi(z)\,\|\,p_\theta(z)\right) = \frac12\sum_{j=1}^{J}\left[1 + \log(\sigma_j^2) - \mu_j^2 - \sigma_j^2\right]$，先验 $\mathcal{N}(0,I)$、后验 $\mathcal{N}(\mu,\sigma^2 I)$，$J$ 为 $z$ 的维数 | — | 论文正文（附录 B） |

## 6. DDPM（Ho、Jain、Abbeel 2020）

论文：*Denoising Diffusion Probabilistic Models*，arXiv:2006.11239（NeurIPS 2020）。

### 6.1 前向过程与训练目标（原式）

| 项目 | 原文形式 | 口径 | 类型 |
|---|---|---|---|
| **前向过程闭式解（式 4 附近）** | 记 $\alpha_t := 1 - \beta_t$、$\bar\alpha_t := \prod_{s=1}^{t}\alpha_s$，则 $q(x_t|x_0) = \mathcal{N}\!\left(x_t;\ \sqrt{\bar\alpha_t}\,x_0,\ (1-\bar\alpha_t)I\right)$ | **这就是 $\bar\alpha_t$ 的定义与"一步跳到任意 t"的出处** | 论文正文（式 4 区域） |
| **简化训练目标（式 14）** | $L_{\text{simple}}(\theta) := \mathbb{E}_{t,x_0,\epsilon}\left[\left\lVert \epsilon - \epsilon_\theta\!\left(\sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon,\ t\right)\right\rVert^2\right]$，$t$ 在 $\{1,\dots,T\}$ 上均匀取 | **"训练目标就是预测噪声 ε"的原文出处** | 论文正文（式 14） |
| 算法 1（训练） | 重复：$x_0\sim q(x_0)$；$t\sim\text{Uniform}(\{1,\dots,T\})$；$\epsilon\sim\mathcal{N}(0,I)$；对 $\nabla_\theta\lVert\epsilon-\epsilon_\theta(\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon,\,t)\rVert^2$ 做一步梯度下降；直到收敛 | 四行就是全部 | 论文正文（算法 1） |
| 算法 2（采样） | $x_T\sim\mathcal{N}(0,I)$；对 $t=T,\dots,1$：$z\sim\mathcal{N}(0,I)$（$t=1$ 时 $z=0$），$x_{t-1} = \frac{1}{\sqrt{\alpha_t}}\left(x_t - \frac{1-\alpha_t}{\sqrt{1-\bar\alpha_t}}\epsilon_\theta(x_t,t)\right) + \sigma_t z$；返回 $x_0$ | — | 论文正文（算法 2） |
| **T 与噪声调度** | **T = 1000**（全部实验）；$\beta_t$ **线性**从 $\beta_1 = 10^{-4}$ 升到 $\beta_T = 0.02$ | 原话"a linear schedule from β1 = 10⁻⁴ to βT = 0.02" | 论文正文（第 4 节） |
| 方差不学 | $\Sigma_\theta(x_t,t) = \sigma_t^2 I$，$\sigma_t$ 是**不训练的、随时间变的常数**；试了两种：$\sigma_t^2=\beta_t$ 与 $\sigma_t^2=\tilde\beta_t = \frac{1-\bar\alpha_{t-1}}{1-\bar\alpha_t}\beta_t$，论文说**两者结果相似** | 论文另说：$x_0\sim\mathcal{N}(0,I)$ 时前者最优，$x_0$ 定在一点时后者最优 | 论文正文（第 3.2 节） |

## 13. 为什么这些数字不能横向直接比较

1. **FID 不是一个"绝对分"**。它依赖：用哪一版 Inception 权重、真实侧用训练集还是测试集、生成多少张图、是否取训练全程最低值。DDPM 的 **3.17 是对训练集算**的，同一个模型**对测试集是 5.24**；StyleGAN 的 FID 是 **5 万张、全程最低值**；StyleGAN2 **根本没写用多少张**。四舍五入到小数点后两位的 FID 放在一起排名，没有意义。
2. **FID 与 IS 都随样本数 N 变，而且偏差依赖模型本身**。Chong & Forsyth（CVPR 2020）证明"**排名会随 N 翻转**"，并用两个结构完全相同的 DCGAN 演示过。**FID 原论文（Heusel 2017）没有讨论这件事**，它只说自己用 5 万张。教材讲"FID 小样本有偏"必须引 Chong & Forsyth，不能引 Heusel。
3. **Parzen 窗似然与 FID 完全不可比**，而且 GAN 原论文自己就说 Parzen 估计"方差偏高、在高维里表现不好"。另外 **GAN 原论文的 CIFAR-10 根本没有似然数值**，只有样本图。
4. **引导强度 w 有两套记法，差 1**。Ho & Salimans 式 (6) 的约定是 $\tilde\epsilon = (1+w)\epsilon_c - w\epsilon_\varnothing$，**w = 0 表示不引导**；而很多实现（包括 LDM 论文里的 s）用 $s = 1+w$，**s = 1 表示不引导**。把"w = 7.5"和"s = 7.5"当同一件事就错了。
5. **"FID 随引导强度单调下降"是论文原话里的一句不准确表述**。表里 IS 单调上升，FID **先降后升**（64² 最优在 w≈0.1，128² 在 w≈0.3）。教材要写"存在最优 w"。
6. **采样步数要连 η 一起引**。DDIM 的 20 步 FID 6.84 是 **η=0（完全确定性）** 的；同样 20 步，η=1（即 DDPM）是 **18.36**，用 DDPM 原方差 $\hat\sigma$ 则是 **133.37**。只说"20 步"不说 η，差了 20 倍。
7. **"算力"要分清是训练、采样还是单项消融**。LDM 引言里的"150–1000 V100 天"**是引 ADM 那篇的**，不是 LDM 自己的；LDM 第 4.1 节的"单块 A100"只是该节消融实验的固定预算；SVD 论文里"8 块 A100、约 16 小时"**只是多视角微调那一项**，基模型三阶段训练的硬件**根本没写**。
8. **视频数据集的"小时数／年数"要连过滤阶段一起引**。SVD 的 LVD 原始是 **1.52 亿片段 / 50.64 年（LVD-F）**，而 LVD-10M-F 只有 **230 万片段 / 0.78 年**；三个训练阶段的分辨率（256×384 / 320×576 / 576×1024）与数据量也各不相同。
9. **Sora 什么都没公布**。官方报告自己写"模型与实现细节不在本报告内"。能引的只有：最长约一分钟、1920×1080 与 1080×1920 及其间各种尺寸、图片最高 2048×2048、时空块 + 扩散 transformer、用了 DALL·E 3 的重标注技术。**参数量、数据量、算力一律写"未公布"**。
10. **"显式／隐式标识"是中国办法的法定术语，C2PA 的"硬绑定／软绑定"是技术术语，两套不要混讲**。办法第五条要求的是**文件元数据里的隐式标识**（含内容属性、服务提供者名称或编码、内容编号），数字水印只是"鼓励"；C2PA 的硬绑定是密码学哈希、软绑定是指纹／水印。而 SynthID-Text 是**文本采样层的水印**，既不是元数据也不是图像水印。
11. **C2PA 的"训练与数据挖掘"断言已经在 2.0 版里删掉了**。拿它讲"C2PA 可以声明不许用于训练"是过时的。
12. **SynthID 的"效果"只有定性结论可引**。论文正文**没给 TPR@FPR 数字**（只在图里），能引的硬数字是**延迟 +0.57%** 与**线上 2000 万条回答、点赞点踩差 0.01%/0.02% 且不显著**。
