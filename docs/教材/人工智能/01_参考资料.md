# 《人工智能》参考资料（v0.1，2026-10-02）

> 配合《人工智能》提纲 v0.1。参照《机械设计》参考资料 v0.2 的做法：以国外高水平教材、经典论文和官方技术文档为主，每章列出该章全部参考资料。
>
> **用法**
> 1. 第一部分是**总书目**，每种资料一个代号（如 [PMPP]）；第二部分**逐章列出**该章的参考资料：教材（注明对应内容）、经典论文、技术文档与数据集、标准与法规。
> 2. **以国外高水平教材和原始论文为主**；国内教材（第 K 组）只用来核对国内课程的覆盖面。
> 3. **只参照选材和深度**，文字、图、习题全部原创。下篇的成果数字一律取自原始论文或权威评测，不转引二手资料。
> 4. 教材注的是“哪一部分内容”，不写章号。**写每一章之前，逐条核对版本、章节和页码，并联网核对该领域截至写作时的最新进展**，核对结果写进该章的章末参考文献（`textbook/ai/conventions/参考书目.md` 同步更新）。
> 5. 官方文档（CUDA、PyTorch、ROCm、CANN 等）以写作时的现行版本为准，章末注明版本号和访问日期。
