## 一、写法（v0.3，最重要的一条）

1. **起点**：只要求高中数学：函数、三角函数、平面几何。书里用到的其他数学，从头讲起：
   - 向量、矩阵、微积分的必要部分；
   - 微分方程、概率、李群。
   电路从欧姆定律讲起，编程从第一行 Python 讲起。
2. **循循善诱**：每一节从一个具体的问题或现象出发（多半是机器人遇到的事），先用最朴素的办法试，看哪里别扭，再自然地引出新概念。推导一步一步走，每一步说清“为什么要这样做”。先直观、后严格；新名词第一次出现时，先用日常的话说它是什么，再给定义。
3. **叙述，不罗列**：正文用连贯的段落讲道理，不用一串要点代替解释。下面“每节的结构”是写作时内部的顺序，不是每节都出现的小标题。
4. **总结只放在章的首尾**（2026-10-01 Eddie 补充：“章首提要和章末小结还是要的”）：
   - **章首提要**：用一段话说明这一章要解决什么问题、为什么重要、和前后章的关系，再列出学完能做到的几件事；
   - **章末小结**：用简短的叙述串起本章的主线，附本章关键公式和概念的速查表，便于复习和工程查阅；
   - 节内不反复总结，一节结束时只用一两句话交代下一节要解决什么问题。
5. **完善每一个细节**，具体包括：
   - 推导不跳步；
   - 公式里每个符号都说明含义和单位；
   - 每个数字都能用程序复算；
   - 正负号、顺时针还是逆时针、度还是弧度这类约定写明白；
   - 初学者容易弄反、弄混的地方单独讲透。
6. **样稿**：见《样稿_文风_4.1.md》（4.1 平面转动与旋转矩阵，v0.4 按学术文风重写）。正文按这个写法写，定稿前以它为准对齐。
7. **学术，但不晦涩**（v0.4）：
   - 语言书面、准确、克制，不用口语和卖关子的句式；
   - 重要内容写成编号的**定义**、**定理**，给出证明或完整推导；
   - 公式按节编号，如 (4.1.3)；
   - 交代概念的来龙去脉：谁、在哪一年、为解决什么问题提出；
   - 每章末附参考文献；
   - 循循善诱体现在推导的顺序和每一步的说明上，而不是靠口语化。

## 二、编写原则

1. **全面**：从零基础的数学到具身智能，每章标出层次，方便老师取舍。
   - 【基础】本科必修；
   - 【进阶】本科选讲或研究生；
   - 【专题】研究前沿，可整章跳过。
2. **旋量为主线**：全书统一用旋量、指数积和李群的语言，干净、统一，从运动学一直贯通到动力学和控制。DH 法单独一章讲，作为与工业界的对接。
3. **算必有仿真**：每个算例都给出可运行的程序，复现书中的每个数字，并附仿真结果和可视化（曲线、三维动画或交互图）。书里的数和程序算出的数必须一致，由程序自动核对。
4. **编程必有实验**：每段编程内容都配一个浏览器里的虚拟实验，不用装软件。实验有指导书、报告模板和自动检查。
5. **电路必有仿真与检测**：每个电路都可以在浏览器里仿真，并用虚拟示波器、万用表测量；“自动检测模拟”按规格判定合格与否。
6. **每节同一结构**：
   1. 实际问题：以机器人为主；
   2. 概念；
   3. 推导；
   4. 算例；
   5. 仿真与结果；
   6. 可视化与动画：3Blue1Brown 风格；
   7. 编程；
   8. 虚拟实验；
   9. 生活中的例子；
   10. 工程师笔记；
   11. 习题。
7. **贯穿全书的五台机器人**：全部来自问渠零件库的真实模型，参数一致，前后章节可以互相引用。

   | 机器人 | 库中模型 | 主要用于 |
   |---|---|---|
   | 六轴协作臂 | UR5e | 运动学、动力学、控制、编程的主线 |
   | 七轴冗余臂 | Franka Panda / xArm7 | 冗余、力控、学习 |
   | 四足机器人 | Unitree Go2 | 足式运动学、动力学、步态控制 |
   | 移动机器人 | 差速 AGV（数字工厂车间） | 移动运动学、定位、调度 |
   | 四旋翼 | 库中无人机 | 空中机器人 |

   另有并联机构 Delta/Stewart 和 SCARA；零件库还没有的，向数字工厂提需求（R8）。
8. **工业场景来自问渠数字工厂**：减速器车间的上下料、AGV 送料、检测数据。
9. **原创**：参考 Lynch & Park、Murray–Li–Sastry、Craig、Siciliano《机器人手册》、Spong 等，但不照抄文字、图和习题；插图全部重画，数据自己算。
10. **前沿章节注明时间**：具身智能等变化快的内容，正文注明“截至某年某月”，每次再版前更新。

**篇幅估算**：61 章。因为从零讲起、推导不跳步，每章约 25–35 页，全书约 1750 页（中文版）。可按篇分册出版。
