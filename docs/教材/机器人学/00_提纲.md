# 《机器人学》教材提纲（草稿 v0.1，2026-10-01）

> 定位：一本**机器人手册式**的教材，内容全面，老师授课时自己取舍。先写中文，再出中英对照版。
> 状态：提纲草稿，等 Eddie 讨论确认。确认之前不写正文、不开发工具。

## 一、编写原则

1. **全面**：从数学基础到具身智能，覆盖本科高年级到研究生入门。每章标出层次：
   - 【基础】本科必修；
   - 【进阶】本科选讲或研究生；
   - 【专题】研究前沿，可整章跳过。
2. **算必有仿真**：每个算例都给出可运行的程序。程序复现书中的每个数字，并附仿真结果和可视化（曲线、三维动画或交互图）。书里写的数和程序算出的数必须一致，由程序自动核对。
3. **编程必有实验**：每段编程内容都配一个虚拟实验，在浏览器里直接做，不用装软件。实验有指导书、报告模板和自动检查。
4. **每节同一结构**：
   1. 实际问题：以机器人为主；
   2. 概念；
   3. 推导；
   4. 算例；
   5. 仿真与结果；
   6. 可视化与动画（3Blue1Brown 风格）；
   7. 编程；
   8. 虚拟实验；
   9. 生活中的例子；
   10. 习题。
5. **贯穿全书的五台机器人**：全部来自问渠零件库的真实模型，参数一致，前后章节可以互相引用。

   | 机器人 | 库中模型 | 主要用于 |
   |---|---|---|
   | 六轴协作臂 | UR5e | 运动学、动力学、控制、编程的主线 |
   | 七轴冗余臂 | Franka Panda / xArm7 | 冗余、力控、学习 |
   | 四足机器人 | Unitree Go2 | 足式运动学、动力学、步态控制 |
   | 移动机器人 | 差速 AGV（数字工厂车间） | 移动运动学、定位、调度 |
   | 四旋翼 | 库中无人机 | 空中机器人 |

   另有并联机构 Delta/Stewart 和 SCARA；零件库还没有的，向数字工厂提需求（R8）。
6. **工业场景来自问渠数字工厂**：减速器车间的上下料、AGV 送料、检测数据，用于结构设计、控制和系统集成各篇。
7. **原创**：参考 Craig、Lynch & Park、Siciliano《机器人手册》、Spong 等，但不照抄文字、图和习题；插图全部重画，数据自己算。

**篇幅估算**：约 54 章，每章 20–25 页，全书约 1200 页（中文版）。
