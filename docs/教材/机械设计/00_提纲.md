> 定位：一本**高水平、全面**的机械设计教材，从零件的强度讲到机构、传动、轴系、现代设计方法和整机设计；为机器人服务，但不限于机器人——同样服务通用机械、汽车与农机、机床与自动化装备、医疗器械。一本书覆盖国内的“机械原理”“机械设计”“机械设计基础”“互换性与测量技术”“机械设计课程设计”，以及研究生的“现代设计方法”“精密机械设计”。内容全面，老师授课时自己取舍；同时是工程师的案头参考书。先写中文，再出英文版。

## 一、写法（沿用《机器人学》提纲第一节；机械设计的补充见第 9–12 条）

1. **起点**：高中数学和物理，加上本书第 2 篇讲到的力学要点。用到的微积分、线性代数、材料力学，第一次用到时讲清，并注明“详见《大学物理》第 x 章 /《线性代数》第 x 章”。
2. **循循善诱**：每一节从一个具体的工程问题出发（多半来自数字工厂的减速器产线和问渠零件库里的机器人），先用最朴素的办法试，看哪里不够，再自然地引出新方法。先直观、后严格。
3. **叙述，不罗列**：正文用连贯的段落讲道理。设计手册式的表格放在“标准与数据”里，正文讲清表格从哪里来、怎么用、什么时候不能用。
4. **总结只放在章的首尾**：章首提要；章末小结（主线叙述 + 关键公式与设计流程速查表 + 历史注记 + 参考文献与标准）。节内不反复总结。
5. **完善每一个细节**：推导不跳步；每个系数说明来源和适用范围；每个数字都能用程序复算；单位和符号前后一致；初学者容易弄混的地方单独讲透（如“强度”和“刚度”、“应力集中系数 $K_t$”和“疲劳缺口系数 $K_f$”、“基本额定寿命”和“修正寿命”、“公差”和“偏差”）。
6. **学术，但不晦涩**：语言书面、准确、克制；重要结论写成编号的**定义**、**定理**、**设计准则**；公式按节编号，如 (11.4.2)；交代方法的来龙去脉和它的局限。
7. **动画代替不了示意图，两个都要**。
8. **文风**：以《机器人学》样稿 4.1 为准。第一章写好后，Eddie 确认文风再往下写。
9. **机械设计特有：每节课都是一份工程工作**。每一章至少有一张**工程任务单**，学生按工程师的方式完成，交付工程文件而不是“作业答案”：
   - 任务单由老师（或 AI）在班级工厂的 ERPNext 里以“设计任务”下达，写明需求、约束、交期；
   - 交付物是工程文件：**设计计算书**（浏览器里运行的 Python，自动生成 Word）、**三维模型**（build123d 或 FreeCAD）、**分析报告**（有限元、疲劳、多体）、**图纸**（按国标）、**加工程序**、**检验记录**；
   - 交付走**设计发布与审批**：提交 → AI 评审员先审（规范、计算、图面）→ 老师批准或退回 → 批准后 ERPNext 物料、BOM、工艺自动更新 → 仿真车间加工、三坐标检验 → 质量数据回到学生手里复盘。
   - 不是每章都走完整条链；每个任务单标明经过哪些工位（见第 11 条）。
10. **机械设计特有：设计是“算、画、验”反复迭代**。同一个零件，先手算（教会道理），再查标准（教会规范），再用有限元或多体仿真核对（教会怀疑），三者结果放在一起比较，讲清楚差在哪里、为什么差、该信哪个。
11. **机械设计特有：工具链标注**。每个实验和任务单标明用到的软件，读者一眼看出这节课在工厂的哪个工位：

    | 标记 | 工位 | 开源软件 | 状态 |
    |---|---|---|---|
    | 〔CAD〕 | 三维建模、出图 | FreeCAD、build123d；SolidWorks 提交宏（有正版的学校） | 已有 |
    | 〔PLM〕 | 设计发布与审批、参数配置器 | 自研 | 已有 |
    | 〔ERP〕 | 物料、BOM、工艺路线、成本 | ERPNext | 已有 |
    | 〔MES〕 | 派工、车间执行、设备数据 | 自研 | 已有 |
    | 〔QMS〕 | 三坐标检验、控制图、不合格品处置 | 自研 | 已有 |
    | 〔FEA〕 | 有限元分析 | Gmsh + CalculiX | 数字工厂第 11 轮 |
    | 〔FAT〕 | 疲劳寿命 | pyLife（博世开源） | 数字工厂第 11 轮 |
    | 〔MBD〕 | 多体动力学（替代 ADAMS） | MuJoCo、Project Chrono | 数字工厂第 12 轮 |
    | 〔CAM〕 | 数控编程 | FreeCAD CAM / OpenCAMLib | 数字工厂第 13 轮 |
    | 〔PY〕 | 设计计算书、机构演示台 | 浏览器内 Python（与第 9 轮同一工具） | 本轮新增 |

12. **机械设计特有：历史与工程伦理如实交代**。中国的贡献——《考工记》、指南车、苏颂水运仪象台的擒纵机构（1088 年）、《天工开物》——在相应章节如实交代，不夸大；工程失败的案例（彗星客机疲劳、塔科马海峡大桥、凯悦酒店走廊垮塌等）讲清技术原因和设计者的责任。

## 二、编写原则

1. **全面**：每章标出层次：
   - 【基础】本科“机械原理”“机械设计”“机械设计基础”必修（覆盖濮良贵《机械设计》、孙桓《机械原理》和考研大纲的全部内容）；
   - 【进阶】研究生“现代设计方法”“精密机械设计”、工程师进修；
   - 【专题】机器人与智能装备、综合项目，可整章跳过。
   第四节给出**课程路线表**，列出八种开课方式各用哪些章节。
2. **算必有仿真**：每个算例都有可运行的 Python 程序，复现书中每个数字；书里的数由程序填入，自动核对。凡是查表得到的系数，程序里引用同一张数字化的标准表，并注明标准号和表号。
3. **编程必有实验，设计必有任务**：每段计算方法配一个浏览器里的虚拟实验；每章配一张工程任务单。实验和任务单都有指导书、报告模板（工程任务单的“报告”就是计算书和评审记录）。
4. **每节同一结构**（写作时的内部顺序，不是每节都出现的小标题）：
   1. 工程问题：以数字工厂减速器和问渠零件库的机器人为主；
   2. 工作原理与直观（失效现象、受力路径、运动关系）；
   3. 理论与推导；
   4. 算例（按设计计算书的格式写：已知、求、计算、结论）；
   5. 标准与数据（国标、ISO 对照；怎么查、怎么插值、适用范围）；
   6. 建模与仿真（有限元 / 多体 / 程序，与手算对照）；
   7. 动画与可视化（3Blue1Brown 风格）；
   8. 虚拟实验；
   9. 工程实践：任务单在本节的那一步；
   10. 生活中的例子（每节保留一个）；
   11. 工程师笔记（常见设计错误、经验数据、选型窍门、标准更新）；
   12. 习题（概念题、计算题、设计题、工程项目四类）。
5. **贯穿全书的两台产品**：
   - **WQR-105 二级圆柱齿轮减速器**（数字工厂的产品，零件库 `C-RED-WQR105`）：额定输出转矩 350 N·m，输出轴 SH-301。从第 1 章的需求一直做到第 50 章的课程设计，书中强度、齿轮、轴、轴承、键、螺栓、润滑、公差、加工、检验的例子都落在它身上，参数全书一致；
   - **协作机器人关节模组**（问渠零件库的谐波减速器 `D-RDC-HD-CSF`、交叉滚子轴承 `A-BRG-CR`、UR5e 的关节尺寸）：机器人方向的主线，第 51 章做成综合项目。
   另有零件库里的 UR5e、Franka Panda、Unitree Go2、差速 AGV，以及机构库（四杆、曲柄滑块、凸轮、槽轮、棘轮、蜗杆、丝杠、带、轮系）。
6. **工业数据来自数字工厂**：载荷谱用仿真车间跑合试验台的转矩记录（`test.torque`）；材料数据用有限元服务的材料库（12 种，逐条出处）；成本用 ERPNext；尺寸检验数据用三坐标记录；质量控制图用车间的检测数据。
7. **与另三本书的分工**：
   - 《机器人学》第四篇“结构与机电设计”第 30–34 章讲机器人选型和用法；本书讲设计计算的完整方法。重叠处（减速器、结构强度、末端执行器）本书讲透，《机器人学》注明“详见《机械设计》第 x 章”。
   - 《大学物理》讲力学原理，《线性代数》第 40 章讲刚度矩阵的数学；本书讲工程应用。
   - 四书术语一致（构建时核对）。
8. **符号、单位与标准**：
   - 单位用国际单位制，应力 MPa、力矩 N·m、长度 mm；
   - 符号用国内教材通行写法，第一次出现时注明 Shigley 等英文教材的写法（如疲劳极限 $\sigma_{-1}$ 与 $S_e$）；
   - 术语以全国科学技术名词审定委员会《机械工程名词》为准；
   - 设计数据按现行国家标准，同时给出对应的 ISO 标准；美国标准（ASME、AGMA）在英文版和相应章节对照。标准更新时，由程序引用的标准表统一修改。
9. **原创，以国外高水平教材为主**：全部参考资料见 `docs/教材/机械设计/01_参考资料.md`——第一部分是总书目（每本书一个代号），第二部分逐章列出该章的教材、专著与手册、经典文献、标准和软件文档。
   - 主要参照是英、德、美的经典教材和专著：Shigley（第 12 版，2024）、Norton《Machine Design》与《Design of Machinery》、Juvinall、Uicker、Erdman、Pahl–Beitz、Ulrich–Eppinger、Ashby、Peterson、Stephens–Fatemi、Harris、Litvin、Niemann、Roloff/Matek、Slocum、Shabana、Bendsøe–Sigmund、Springer 机器人手册等；
   - 国内教材（濮良贵《机械设计》、孙桓《机械原理》、机械设计手册）只用来核对国内课程和考研大纲的覆盖面；
   - 只参照选材和深度，不照抄文字、图和习题；插图全部重画，数据自己算；
   - 写每一章之前逐条核对版本、章节和页码，写进章末参考文献。
10. **主要标准**（数字化成标准表，程序引用；以写作时现行版本为准，出处写到表号）：
    - 制图与公差：GB/T 4457–4460、GB/T 14689 等机械制图标准；GB/T 1800.1-2020 / ISO 286-1 极限与配合；GB/T 1182-2018 / ISO 1101 几何公差；GB/T 131 / ISO 1302 表面结构；ASME Y14.5-2018（对照）；
    - 零件设计：GB/T 3480 / ISO 6336 齿轮承载能力；GB/T 6391 / ISO 281 滚动轴承额定寿命；VDI 2230 第 1 部分 高强度螺栓连接；DIN 743 轴的承载能力；GB/T 1096 平键；GB/T 1239 / EN 13906 圆柱螺旋弹簧；GB/T 10095 / ISO 1328 齿轮精度；
    - 材料：GB/T 699、GB/T 3077 等钢材牌号与性能，与 ASTM、EN、JIS 对照；
    - 安全与可靠性：GB/T 15706 / ISO 12100 机械安全；GB/T 7826 / IEC 60812 FMEA。

**篇幅估算**：导论 1 章 + 九篇 51 章 = **52 章**。每章约 25–35 页，全书约 **1600 页**（中文版），另附录约 120 页（以标准数据表为主）。规模相当于 Shigley 机械设计、孙桓机械原理、Norton 机构学三本合在一起，再加现代设计方法和机器人装备两篇。可分上中下三册：上册设计基础与机构（第 1–23 章），中册零件设计（第 24–37 章），下册现代方法、机器人装备与综合设计（第 38–52 章）。
