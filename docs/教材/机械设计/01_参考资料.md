# 《机械设计》参考资料（v0.2，2026-10-02）

> 配合《机械设计》提纲 v0.2。Eddie 要求（2026-10-02 10:22）：“这些参考教材要以国外高水平教材为主，每一章请罗列所有参考资料。”
>
> **用法**
> 1. 第一部分是**总书目**，每本书一个代号（如 [SHI]）；第二部分**逐章列出**该章的全部参考资料：教材（注明对应内容）、专著与手册、经典文献、标准、软件文档。
> 2. **以国外高水平教材为主**：每章的主要参照都是英、德、美的经典教材和专著；国内教材（第 J 组）只用来核对国内课程和考研大纲的覆盖面，不作为选材和写法的依据。
> 3. **只参照选材和深度**，文字、图、习题全部原创。
> 4. 教材注的是“哪一部分内容”，不写章号：各书版本之间章号会变。**写每一章之前，逐条核对版本、章节和页码**，核对结果写进该章的章末参考文献（`textbook/mechdesign/conventions/参考书目.md` 同步更新）。
> 5. 标准以写作时的现行版本为准；没写年份的，写章时查到现行版本再填。
