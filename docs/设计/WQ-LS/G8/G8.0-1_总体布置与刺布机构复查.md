### 结构上的两点不同（要说清楚为什么）

1. **上轴支承**
   - 我们：两只深沟球轴承（前 6202、后 6201）。
   - DDL-8700：上轴是三只滑动轴套，前、中、后各一只，叫 MAIN SHAFT BUSHING FRONT / INTERMEDIATE / REAR [4]。
   - 球轴承的寿命已在 G2 算过：前轴承约 1.6 万小时。
   - 要做的事：比较“球轴承、滑动轴套”在噪声、润滑、成本上的差别，定下用哪种，写进设计说明。
2. **旋梭传动**
   - 我们：上轴经同步带带下轴，下轴经一对齿轮带旋梭轴。
   - DDL-8700：竖轴加两对锥齿轮 [4]。
   - 同步带方案在新机型里常见，不改；把选它的理由写进设计说明。

## 二、刺布机构：零件对照与缺项

DDL-8700 零件表里刺布部分的组成 [4]：
- 针杆、针杆上导套、针杆下导套；
- 针杆夹头组件（带紧定螺钉）、滑块；
- 针杆线钩（两处）、橡胶塞；
- 针杆曲柄、曲柄连杆、平衡块、左旋螺钉；
- 挑线杆里 4 只滚针轴承。

| 零件 | WQ-LS 现状 | 缺什么 |
|---|---|---|
| 针杆 | Ø8 圆柱，两端倒角 | 缺两条刻线：一条定针杆高度，一条定旋梭定时，DDL-8700 就是这样调的 [3]。缺上端油槽、下端针孔与紧针螺孔的细节。Ø8 的出处待查。 |
| 针杆导套 | 机壳里留了 Ø12 孔，写了“含油轴套 Ø8 × Ø12”，**但轴套没有建成零件，BOM 里也没有** | 补成两个零件（上、下导套），选材和配合要写明 |
| 针杆连接块（夹头） | 有，靠一个夹紧螺钉固定在针杆上 | 夹紧螺钉要换成零件库的标准件 |
| **滑块与导槽** | **没有** | DDL-8700 有 SLIDE BLOCK [4]：夹头上的滑块在机壳导槽里上下滑动，承受侧向力，防止针杆转动。要补滑块，机壳上补导槽 |
| 针夹、紧针螺钉 | 针夹有；螺钉只是个圆柱 | 螺钉换标准件 |
| 针杆线钩 | 一处，长在针夹上 | 参照机有两处 [4]，按面线路径核对 |
| 连杆与滚针轴承 | 连杆有；注释写了“内装滚针轴承”，**轴承没建** | 从零件库选滚针轴承（HK 系列）装上，核寿命 |
| 曲柄、平衡块、曲柄销 | 有 | 销的轴向固定方式（参照机用左旋螺钉 [4]）要定 |
| 上端橡胶塞、防油 | 没有 | 补 |

### 要查清的依据（下一步）

1. 针杆直径、导套长度和间距：查专利和教材里的范围，按针杆受力和导套比压校核。
2. 滑块和导槽的尺寸与间隙。
3. 缝纫机专用英制细牙螺钉：参照零件表里的规格写法，如 9/64-40、11/64-40、1/4-40、15/64-28 [4]。找到尺寸标准或厂家目录后建模，收进零件库。
4. 钩线时机针回升量 2.0 mm：用钩线几何复核，再在针杆上刻出对应的刻线。
