# WQ-LS 选配件：自动剪线 T、电子针距 E（G4.8，2026-11-13）

**一句话**：剪线用下轴上的剪线凸轮带动动刀，电磁铁只管把滚子推进凸轮槽，所以进刀、剪断的时刻由凸轮定死，不受电磁铁快慢影响；剪线时另一个电磁铁拉开夹线器，停针后拨线钩把线头拨到压脚上面。电子针距用一台闭环 42 步进电机经 1 : 2 同步带转调节器，去掉 G4.7 的针距旋钮和倒缝扳手，回针靠电机换向。D（少油旋梭）只是旋梭镀 DLC 膜，不改形状，只进零件清单和工艺卡。

**程序**
- 尺寸和计算：`tools/wqls/g4_opt.py <零件目录>` → `选配件.json`（零件按其中的 `geo` 画）。
- 零件：`tools/wqls/cad/opt.py`（由 `cad/mech.py` 调用）。选项用环境变量 `WQ_OPT=T,E`（不给 = 基本型），8 种变型都能生成；带 E 的去掉针距拉杆、旋钮、倒缝扳手、拉簧。
- 一转运动：`g4_mech.py`，`WQ_TRIM=sew`（平时缝纫）/ `trim`（剪线那一转）/ `wipe`（针停在 80°，拨线钩扫一下）。
- 机壳上的凸台和孔：`cad/housing.py` 的 `opt_seats()`；加工：`g5_cam.py` 的 `opt_holes()`，工序 80 第 9 步（按选项跳段）。
- 干涉检查：`cad/mech_check.py`；动刀和旋梭、梭壳、送布牙排按 0.5 mm 查（`TIGHT`）。

**针板下面的空间**：机座顶板在针板座处开口 x −22…29.5、y ±18；旋梭顶 z −6.5；送布牙排两排齿最低时底面 −3.9，侧梁在 |y| 11.3 以外、从 x −6.5 开始。

- 刀片平面 z −5.9…−4.9：离齿排 1.0，离旋梭顶 0.6。
- 刀片走侧梁中间的开口；动刀低的一段都在 x < −6.5，侧梁那里还没有东西。
- 所以**送布牙排不用改**。

**凸轮**（凸轮转角 = φ，下轴 1 : 1）：

| 段 | φ | 动刀 |
|---|---|---|
| 静止、入口段 | 75°–280° | 在最后；滚子可以在 100°–275° 之间任何时候进槽 |

| 停 | 340°–20° | 钩住连布的面线和底线；线环脱出梭壳，挑线杆开始收线 |
| 回程 | 20°–75° | 52.4° 时刀刃越过定刀刃，剪断 |

| 项 | 数 | 要求 |
|---|---|---|
| 动刀摆角 / 剪线摆轴转角 | 22.6° / 9.0° | |
| 滚子升程 | 4.66 mm（槽按拉杆的真实运动算） | |
| 最大压力角 | 30.9° | ≤ 35° |
| 剪线力（两根线按 15 N）→ 拉杆 / 滚子 | 65.8 N / 52.0 N | |
| 滚子对凸轮槽接触应力 | 279 MPa | ≤ 1500（渗碳淬火） |
| 剪线那一转多出的主轴力矩 | 0.43 N·m | 电机峰值 ≥ 3 N·m（G2）；剪线转速只有 300 r/min，没有惯性力矩的起伏 |

**电磁铁合上**：入口段 100°–275°，宽 175°。电磁铁延迟从 5 ms 变到 15 ms，在剪线转速下转过的角度远小于 175°（到 2750 r/min 都装得下），所以电磁铁快慢不影响剪线。

**停针和剪线转速**：

- 动刀 75° 回到最后，停针窗口从 75° 开始。
- 上限取两者中较小的：针尖碰 3 mm 布面前留 5°，是 91.3°；拨线钩要从停住的针尖下面扫过（针尖离钢丝顶 ≥ 1.0），是 84°。
- 窗口 75°–84°。按停车减速度 5745 rad/s²，剪线转速上限 406 r/min（要求 ≥ 300；默认 300）。

**线头**（估算，首件试缝核对）：

| 项 | 数 | 要求 |
|---|---|---|
| 针眼外的面线 | 65 mm（剪断时针眼高 16.2 + 到刀片平面 5.4 + 到定刀刃 8 + 线环绕梭壳半圈 35；松线让挑线杆从线团抽线，线环不缩） | ≥ 35 |
| 布底下的底线头 | 13.4 mm（刀片平面深 5.4 + 针孔到定刀刃 8） | ≤ 15（细则写 5，做不到，见细则偏差 3） |

## 三、松线电磁铁和拨线器

| 件 | 做法 | 数 |
|---|---|---|
| 松线电磁铁 | G4.7 的立轴拨杆上加一条朝 +y 10 的臂，电磁铁在机臂里拉它往 −x；支架用两颗螺钉从机臂前壁外面拧进去 | 需要 9.3 N（夹线簧最大 8.4 N + 张开 0.5 mm 的增量，乘杠杆比）；选 Ø16、行程 3 mm 时 15 N，余量 1.61；夹线盘张开 2.7 mm（≥ 0.5） |
| 剪线电磁铁 | 推摆杆沿摆轴 5 mm | 需要 11 N（回位弹簧 9 N + 摩擦 2 N）；选 Ø22、行程 5 mm 时 22 N，余量 2.0 |
| 拨线器 | 竖轴在 (−30, −10)，从机头底板的轴座（Ø4 H7）伸下来；钢丝 Ø1.2 在 z 4.6，长 31；收回时朝 −100°（压脚前外侧），一下扫 115°，钩尖过针前 | 电磁铁在机头里经半径 5 的小曲柄转轴；扫一下约 60 ms |

控制器（GC）三路电磁铁驱动：剪线、拨线、松线。原来第三路留给自动抬压脚（AK），AK 不在 8 种变型里；以后要加 AK，GC 再加一路。

## 四、电子针距

调节器每 1 mm 针距转 3.52°。从 +5 换到 −5 要转 35.2°，而且要在送布牙沉在针板下面的空闲角里（两头各留 10°，184.5°）转完。调节器受的送布力矩上界 368 N·mm（G4.6）。

可用力矩按“转速 n_c 以下 80% 保持力矩，以上恒功率下降”估算（24 V 驱动的典型样本，选型时按实际样本复核）：

| 电机 | 传动比 | 保持力矩 / 送布力矩 | 全程 ±5 换向最高转速 | ±3 回针最高转速 |
|---|---|---|---|---|
| **42 步进 48 mm（带磁编码器）** | **1 : 2** | **2.39** | **1640 r/min** | **2300 r/min** |
| 42 步进 48 mm | 1 : 3 | 3.59 | 1280 | |
| 42 步进 60 mm | 1 : 2 | 3.17 | 1500 | |
| 57 步进 56 mm | 1 : 1 | 2.61 | 1800 | 2530 |

选 42 步进 48 mm + 1 : 2 同步带（HTD 3M，12 齿 / 24 齿）：GC 现有的 24 V、TMC2226 驱动带得动；针距分辨率 0.016 mm（16 细分）；编码器读电机转角，丢步能发现、能补。

- 回针时控制器按回针针距限转速：±5 mm 1600 r/min、±3 mm 2200 r/min。工业平缝机回针转速一般也设 1600–1800。
- 细则原写“换向 ≥ 2500 r/min，比倒缝电磁铁快得多”，按力矩算做不到（细则偏差 1）。电子针距的好处是针距能编程（起缝加密、转角加密、对条对格），不是回针更快。

布置：电机在机座里 x 220…268，轴心 (y −24, z −35)；电机板 x 268…272 螺在机座顶板下两个凸台上。调节器轴往左伸到 x 283，上面装 24 齿带轮。倒缝按钮在机头前面（x −30、z 80）。立柱上旋钮和倒缝扳手的孔，带 E 的机器不加工，装盖板。
