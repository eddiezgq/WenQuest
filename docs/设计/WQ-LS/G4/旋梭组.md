# WQ-LS 旋梭组：下轴、同步带、1 : 2 齿轮、旋梭轴、旋梭（G4.5，2026-11-11）

**传动路线**：上轴 → 同步带 1 : 1 → 下轴 → 一对斜齿轮 1 : 2 → 旋梭轴。旋梭的转速是上轴的 2 倍：5000 r/min 时为 10 000 r/min，梭尖线速度 14.1 m/s。

**程序**
- 零件：`tools/wqls/cad/hook.py`，由 `cad/mech.py` 调用。
- 计算：`tools/wqls/g4_hook.py`，结果在 `旋梭组计算.json`。
- 齿轮校核工具：`factory/digital/cae/gears.py`，带测试 `tests/test_gears.py`。
- 一转运动：`g4_mech.py`。
- 干涉检查：`cad/mech_check.py`。
- 机座的轴承座：`cad/housing.py` 的 `lower_seats()`。

## 一、位置怎么定的

旋梭轴的位置在 G1 已经由钩线几何反推出来：针的正下方，z = −21.5。

下轴的位置要同时满足两个条件：

| 条件 | 数 | 为什么 |
|---|---|---|
| 齿轮中心距 | 31.058 | 斜齿 mn 1、z 20 / 40、β 15° 的标准中心距（不变位） |
| 同步带中心距 | 237.000 | 中心距固定、不加张紧轮时，带长 2C + 3z 必须正好是节距 3 的整数倍 |

两个圆的交点，就是下轴的位置：**z = −35.36，y = 27.79**，在旋梭轴后面偏下。G1 的 −36 / 26 只是估计，现在 `spec.py` 由这两个条件算出。

- **齿形**：齿轮的齿形是真的渐开线（端面齿廓沿齿宽扭转）。两齿轮在中心连线上按“齿对齿槽”定相位，一转 180 个位置里实体都不重叠。
- **转向**：下轴经同步带与上轴同向转；旋梭轴经外啮合齿轮反向转。在钩线角 206.1° 时，梭尖正好转到针的正上方，向后（+y）运动。旋梭要配这个转向的那一种（左旋梭或右旋梭），外购时按这个转向订。

## 三、载荷

上轴的角加速度取两项相加（偏保守）：
- **急停**：电机用峰值力矩 3 N·m 制动，总惯量 5.2×10⁻⁴ kg·m²，约 5 700 rad/s²，0.09 s 停下。
- **一转之内的转速波动**：G2 算的 ±1.37%，每转两次，约 7 500 rad/s²。这一项在高速缝纫时一直都有。

两项合计 13 200 rad/s²。旋梭组零件的转动惯量按实体算：

| | 转动惯量 |
|---|---|
| 旋梭轴上（旋梭、轴、小齿轮） | 9.0×10⁻⁶ kg·m² |
| 下轴上（轴、大齿轮、带轮） | 3.5×10⁻⁵ kg·m² |
| 上轴带轮 | 1.1×10⁻⁵ kg·m² |
| 折算到上轴（旋梭乘 4） | 8.1×10⁻⁵ kg·m² |

G2 选电机时，下轴、旋梭、带轮这部分估的是约 7.5×10⁻⁵，实体是 8.1×10⁻⁵，相差 8%，对电机选型没有影响。

**峰值力矩**：旋梭轴 0.26 N·m，下轴 1.03 N·m。稳态时只有 0.04 N·m 和 0.09 N·m。

## 五、机座里补的结构（下件）

- **旋梭轴座**：x 24…66，Ø24 凸台，孔 Ø14 H7 压进两个铜套，上面一道 5 mm 厚的筋连到机座顶板。孔铸出 Ø9（砂芯）。
- **下轴左轴承座**：x 88…104，Ø42 凸台，孔 Ø32 H7，6 mm 厚的筋连到顶板。
- **下轴右轴承座**：x 364…378，在同步带轮右边，筋在过带孔右边。
- **过带孔**：立柱脚下的机座顶板上，改为 x 340…364、y 0…50。带在 z 0 处的两边是 y 8…39。
- **立柱下左横筋（x 300…307）上的 Ø34 铸孔**：下轴从这里穿过；G5.2 镗下轴两孔时镗杆也从这里过。
- **立柱横隔板的带槽**（上件，z 55、115 两道）：改为 y −30…50（原来 −30…30，下轴在后面，带的后边超出了原来的槽）。
- **两个端壁工艺孔**：
  - 右端壁在下轴轴线上开 Ø34，镗下轴两孔时镗杆从这里进；
  - 左端壁在旋梭轴轴线上开 Ø20，镗旋梭轴孔用；
  - 装配后都用橡胶堵堵上。这些孔在 G5.2 合箱后精镗时加工。
- **重量和模态**：下件 8.38 → 8.59 kg，上件 15.73 → 15.69 kg（开横筋孔、加宽带槽之前是 8.63 / 15.73）。机壳模态 222 / 230 Hz（原来 221 / 229 Hz），没变；这个模态是开横筋孔、加宽带槽之前算的，后来只去掉了约 80 g 筋材，没有重算。
